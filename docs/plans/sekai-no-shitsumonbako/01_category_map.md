# カテゴリー採用判定表

会長CEO提供のカテゴリー一覧（オンラインコミュニティの公式カテゴリー体系／2026-09-02受領）を全件判定したもの。
**「観察してよいカテゴリー」＝Tier 1・Tier 2 のみ。Tier 3 は観察も記事化もしない。**

---

## 判定の考え方

| Tier | 意味 | 扱い |
|---|---|---|
| **Tier 1** | VVの本業ど真ん中。即開始 | 週2〜3本の主戦場。ここから8割 |
| **Tier 2** | 拡張余地あり。Tier 1が枯れたら投入 | 月1〜2本の変化球。ブランド適合を都度確認 |
| **Tier 3** | **対象外**。法務リスクまたはブランド不一致 | 観察もしない。理由は下表に明記 |

## Tier 1 ─ 主戦場（即開始）

| カテゴリー | VV棚 | 想定される質問の型 | 特記 |
|---|---|---|---|
| ファッションと美容 | **`beauty`**（スキンケア・メイク・ヘア） | 手順・順番・相性・保管・使用期限 | **薬機法チェック全件必須** |
| （同上・衣類側） | **`fashion`**（衣類・靴・バッグ・洗濯とお手入れ） | 素材・洗い方・保管・表示の読み方 | 薬機法は原則不要。製品表示に従う旨の注記 |
| ウェルネス／健康 | `health` | 睡眠・食習慣・運動・体調の素朴な疑問 | **非診断注記必須・出典必須** |
| 食べ物と飲み物／食べ物とレシピ | `trend` | 保存・下ごしらえ・栄養・飲み方 | 食品表示法・健康増進法に留意 |
| Q&Aと体験談 | 内容に応じ最適棚 | 生活全般の「みんなどうしてる？」 | **体験談の個別具体エピソードは扱わない**（一般化した疑問のみ） |
| 科学 | `health` または `trend` | 身体・食品・素材の仕組み | 一次論文まで当たれるものに限る |

> Tier 1だけで**年間100本以上**の質問が確保できる見込み。まずここを掘り切る。

## Tier 3 ─ 対象外（観察も記事化もしない）

| カテゴリー | 除外理由 |
|---|---|
| **株式と投資 / 個人ファイナンス** | **金商法リスク。**個別銘柄・投資判断に関する助言は投資助言業の登録が必要になりうる。**当社は上場企業。ここは触らない。** |
| **有名人** | **名誉毀損・パブリシティ権リスク。**実在個人を論評する必要が一切ない。 |
| **ニュース／テレビ・映画・音楽・ゲームのニュースとディスカッション** | 速報性で勝負する領域。この連載の趣旨（時間が経っても価値が落ちない疑問）と不一致。誤情報リスクも高い。 |
| **ミーム／笑い／残念な瞬間** | 他者の創作物・撮影物への依存度が高く、著作権ガードと構造的に相性が悪い。 |
| **各種ゲーム（アクション／RPG／戦略／シミュレーション／アドベンチャー／その他／ゲーム機と周辺機器）** | ブランド不一致。VVの読者と重ならない。 |
| **各種スポーツ（野球／バスケットボール／サッカー／ラケットスポーツ／モータースポーツ）** | 同上。「運動と体調」はウェルネス側で扱えるため、スポーツ枠は不要。 |
| **各種映像作品（アニメ映画／ホラー映画／ファンタジー映画／スーパーヒーロー映画／アニメとマンガ／漫画／ストリーミングサービス／動画配信者）** | 作品内容の紹介は著作権・引用リスクが高い。ブランド不一致。 |
| **車とトラック／航空／コンピューターとハードウェア／楽器と歌唱／履歴（歴史）** | ブランド不一致。 |
| **Reddit Meta** | プラットフォーム内部の話題。**当社が特定プラットフォームに言及しない方針と正面から矛盾する。** |
| **アジアの場所** | 地域コミュニティ固有の話題で、個人特定・地域偏見のリスクがある。 |

## 記事内でのカテゴリー表記ルール（重要）

**観察源のカテゴリー名を、そのままVVの記事タグに使わない。**

| 観察源の呼び方 | VVでの表記 |
|---|---|
| ファッションと美容 | `ビューティー`（beauty） / `ファッション`（fashion）— **2026-09-08 に棚を分割** |
| ウェルネス | `ウェルネス` |
| 食べ物とレシピ | `フード` |
| Q&Aと体験談 | （タグにしない。内容に応じた棚タグを付ける） |

- 理由1：**VVのブランドの言葉で語るため**。他社サービスの分類をそのまま持ち込むと「まとめサイト」に見える。
- 理由2：既存のVV棚タグ体系と整合させ、サイト内の回遊とAIの理解を助けるため。
- 記事本文で観察源に触れる場合の表現は**「海外のコミュニティで」「世界中で議論されている」まで**。プラットフォーム名・サブコミュニティ名・ユーザー名は一切書かない。
