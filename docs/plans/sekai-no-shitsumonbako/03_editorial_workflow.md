# 取材〜公開の標準手順＋公開前チェックリスト

---

## 標準フロー（1本あたり約3.5時間）

### STEP 1｜観察（週1回まとめて／30分）

1. Tier 1・Tier 2 のカテゴリーを、**編集部員が自分のブラウザで読む**。
2. **メモは「疑問の傾向」だけを日本語で書く。** 投稿本文・URL・ユーザー名は書き写さない。
   - ✅ 良いメモ例：「化粧水を何度も重ねる意味があるのか、という疑問が繰り返し出ている」
   - ❌ 悪いメモ例：投稿文のコピー、投稿URLの一覧
3. 1回の観察で**質問候補を10案**ストックする。

> **禁止**：自動収集ツール・スクリプト・API・自動化エージェントの使用（`02_legal_guard.md` A-3）。

### STEP 2｜3ソース確認（10分）

- 同じ疑問が**独立した3件以上**で確認できるか確かめる。
- 質問候補シートに記録：`確認件数 / 確認日 / 確認者`
- **3件未満は不採用。**

### STEP 3｜質問文の起草（20分）

- 編集部の言葉で、**日本の読者が自然に検索しそうな1文**に書き直す。
- 形式：`Q. ＜疑問文＞`（40字以内が目安）
- チェック：
  - [ ] 特定の投稿の言い回しが混ざっていないか
  - [ ] 1記事＝1つの疑問になっているか（複数の疑問を詰め込まない）
  - [ ] 日本語として自然な話し言葉に近いか（AI検索の自然文クエリに寄せる）

### STEP 4｜出典リサーチ（40分）

- 一次情報（政府機関・公的研究機関・学会・査読論文）を**2件以上**確保する。
- 見つからない場合は、**「確立した結論は出ていない」と正直に書く**か、テーマを差し替える。
- 出典は `機関名『資料名』（公表年）URL` の形で控える。

### STEP 5｜執筆（80分）

- テンプレート（`05_article_template.md`）に沿って書く。
- **結論ファースト**。冒頭40〜80字で答えを言い切る。
- ④VVの考え方への接続は**該当時のみ**（3本に1本以下）。

### STEP 6｜法務・表現チェック（30分）

- 下の公開前チェックリストを**全項目**通す。
- スキンケア棚・健康棚は**法務レビュー必須**。他棚は抜き取り。

### STEP 7｜公開実装（30分／CODE）

- 棚判定・URL付与・タグ付け・構造化データ・公開日/更新日の明示。
- 技術要件は `05_article_template.md` 参照。

### STEP 8｜計測（月次／情報戦略室）

- `04_kpi_measurement.md` に従いレポート。

## 公開前チェックリスト（全記事必須・1本ごとにコピーして使う）

### 著作権・規約

- [ ] 投稿本文の引用・翻訳・要約転載が**一切ない**
- [ ] スクリーンショット・画像の転載が**ない**
- [ ] プラットフォーム名・サブコミュニティ名・ユーザー名が**本文にもタグにも出ていない**
- [ ] 観察は人力のみで行った（自動収集を使っていない）
- [ ] 3ソース原則の確認記録が残っている
- [ ] 特定の1投稿・特定の個人のエピソードに依拠していない
- [ ] 回答本文が完全オリジナルである（他社記事の言い換えでない）

### 表現・法規

- [ ] 「治る」「改善する」「消える」等の**断定的な効能表現がない**
- [ ] 化粧品の効能表現が法定の範囲内に収まっている
- [ ] 疾病の治療・予防を目的とする表現がない
- [ ] 他社・他製品の固有名詞での比較・誹謗がない
- [ ] 実在個人・団体への評価的記述がない
- [ ] 投資・金銭・法律の助言に踏み込んでいない

### 品質・出典

- [ ] 出典が**一次情報**である（まとめサイト・他社記事を出典にしていない）
- [ ] 出典に `機関名・資料名・公表年・URL` が揃っている
- [ ] **出典URLを実際に開いて、記載内容と一致することを確認した**
- [ ] わからないことを「わからない」と書いている（曖昧にごまかしていない）
- [ ] 冒頭40〜80字で結論を言い切っている

### 健康・医療（該当時）

- [ ] 末尾に非診断注記がある
- [ ] 医療機関への相談を促す一文がある

### 商品誘導

- [ ] VV商品への誘導は「自然な場合のみ」に留まっている
- [ ] 直近3本のうち、誘導ありが2本以上になっていない
- [ ] 誘導が回答の結論を歪めていない

### 技術（CODE）

- [ ] URLに `/questions/` が含まれている（KPI計測の前提）
- [ ] タグ `世界の質問箱` ＋ カテゴリータグが付与されている
- [ ] 通し番号 `#n` が重複していない
- [ ] 公開日・更新日が明示されている
- [ ] 構造化データ（FAQPage）が入っている

## エスカレーション

- チェックリストに1つでも「いいえ」が残る → **公開しない**。差し戻し。
- 判断に迷う → 編集長 → 法務。**迷ったまま出さない。**
