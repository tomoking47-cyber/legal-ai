# 『世界にひらく郷土レシピ』企画設計書（多言語）

- 起案：会長CEO指示（2026-09-08）
- 連載名（案）：**世界にひらく郷土レシピ** ／ 英語表記：`Local Japanese Recipes, Opened to the World`
- 棚：`trend`（フード）
- ステータス：**GO（強く推奨）**

---

## 1. 結論

**これは3企画のなかで、最も勝ち筋が見えています。**

理由を4つ。

1. **レシピの「材料と手順」は、そもそも著作物ではない。** 表現ではなく事実・手順だからです。つまり**この企画は構造的に著作権リスクが最も低い**。詳細は3章。
2. **日本の地方特産品レシピは、公的機関がオープンデータとして公開している。** 農林水産省・自治体・観光協会などが、二次利用を前提に情報提供しています。**出典明記で堂々と使える一次情報が大量にある。**
3. **多言語化した瞬間、競合が消える。** 日本語の郷土レシピ記事は飽和していますが、**英語・中国語・スペイン語で「秋田のきりたんぽの作り方」を丁寧に説明しているページは、圧倒的に少ない。** 検索でもAI検索でも、勝てる余地が大きい。
4. **レシピは構造化データ（Recipe schema）が最も整備された領域。** 材料・手順・調理時間を機械可読な形で書けるため、**AI検索に引用されやすい構造をもともと持っている。** GEOとして本命です。

---

## 2. 【重要】「オープンで使われているサイト」の解釈について

ご指示の「cookingサイトで通常オープンで使われているサイト」について、1点だけ正確にしておきます。

> **「誰でも見られる」＝「自由に使える」ではありません。**

- 無料公開されていても、著作権は放棄されていません。
- 会員登録なしで読めることと、転載してよいことは別の話です。

**したがって、サイトを次の3つに分類して扱います。**

| 分類 | 例 | 扱い |
|---|---|---|
| **A. 二次利用が明示的に認められている** | 政府標準利用規約に基づく公的機関のデータ、CC BY表示のあるサイト | **条件を守れば利用可。出典明記。最優先で使う** |
| **B. 利用条件の記載がない一般サイト** | 個人ブログ、企業のレシピサイト | **閲覧のみ。材料と手順という「事実」は把握してよいが、文章・写真は一切使わない** |
| **C. 利用規約で転載・機械収集を禁止** | 大手レシピ投稿サイトの多くが該当 | **閲覧のみ。自動収集は絶対にしない** |

**運用ルール：Aを主軸に据える。B・Cは「そういう料理があると知る」ためだけに使う。**

## 3. なぜレシピは著作権リスクが低いのか

### 材料と手順は「事実」であって「表現」ではない

著作権が保護するのは**表現**であり、**アイデア・事実・手順は保護されません。**

- 「もち米をつぶして杉の棒に巻き、焼く」は**調理手順という事実**であり、誰かの独占物ではありません。
- 米国著作権局も、単なる材料の羅列（mere listing of ingredients）は著作権保護の対象外としています。
- **郷土料理はそもそも地域の共有財産**であり、特定の誰かが権利を持つものではありません。

### ただし、以下は著作物なので使えません

| ❌ 使えないもの | 理由 |
|---|---|
| レシピに添えられた**説明文・コツ・エッセイ**の文章 | 創作的表現 |
| **写真・動画・イラスト** | 著作物 |
| レシピ集の**選択・配列をまるごと真似る** | 編集著作物の侵害 |
| 上記文章を**翻訳して載せる** | 翻訳権・翻案権侵害 |
| 独創的なオリジナル創作料理を、考案者に無断で自社の考案として出す | 表現・信用の問題 |

### したがって正しい制作手順

```
① 郷土料理の存在と一般的な作り方を知る（公的機関の情報を主軸に）
   ↓
② 複数の情報源で材料・手順の「型」を確認する（3ソース原則）
   ↓
③ 【必須】VVが実際に作る
   ↓
④ 自分の分量・自分の言葉・自分の写真で書く
   ↓
⑤ 出典として公的機関・自治体を明記する
```

**③の「実際に作る」が、この企画の生命線です。** 作れば、
- 著作権リスクがゼロになる（自分の体験から書くため）
- 写真が自社素材になる（画像リスクもゼロ）
- 分量・火加減の記述が具体的になり、**記事の質が他社を上回る**

**作らずに書くなら、この企画はやらないほうがいい。** そこだけは譲らないでください。

## 4. 情報源の優先順位

| 優先 | 情報源 | 備考 |
|---|---|---|
| ★★★ | **農林水産省の郷土料理に関する情報提供サイト** | 都道府県別に郷土料理を網羅。利用条件を確認のうえ出典明記で使う ※URL・最新の公開状況を担当者が確認すること |
| ★★★ | **都道府県・市町村の公式サイト、公式観光サイト** | 政府標準利用規約に基づき二次利用可の場合が多い。要個別確認 |
| ★★☆ | **JA・漁協・生産者団体・地域の食文化保存会** | 取材依頼をすれば協力を得られる可能性が高い。**取材ベースが最も強い** |
| ★★☆ | **文化庁・観光庁の食文化に関する資料** | 背景・歴史の記述に有用 |
| ★☆☆ | 書籍・料理研究家の著作 | **参考にはするが、文章は一切使わない。** 背景知識の確認用 |
| ☆☆☆ | 一般のレシピ投稿サイト | **「そういう料理がある」と知るためだけ。** 転載・自動収集は禁止 |

> **最強の手は「取材」です。** 生産者や保存会に直接取材すれば、
> 一次情報・独自写真・独自エピソードがすべて手に入り、**著作権リスクはゼロ、記事の質は他社が真似できない水準**になります。
> 予算をかけるなら、ここにかけてください。

## 5. 多言語展開の設計

### 対象言語（第1フェーズは2言語に絞る）

| 優先 | 言語 | 理由 |
|---|---|---|
| 1 | **英語** | 訪日層・AI検索ともに最大。まずここ |
| 2 | **繁体字中国語** | 訪日リピーターが多く、日本の地方への関心が高い |
| 3 | 簡体字中国語 | 検索環境が異なるため、効果測定を分ける |
| 4 | 韓国語 | 訪日層が厚い |
| 5 | スペイン語 | 話者数が多く、日本食コンテンツの競合が少ない |

**第1フェーズは「日本語＋英語」の2言語で開始。** 手を広げる前に、1言語での勝ち筋を確定させます。

### 翻訳の品質ルール

- **機械翻訳をそのまま出さない。** 必ずネイティブまたはプロ翻訳者のチェックを入れる。
- **特に厳格にチェックする箇所：**
  - **アレルゲン表記**（そば、乳、卵、小麦、落花生、えび、かに 等）— **誤訳は健康被害に直結する**
  - **生食・半生に関する記述**（食中毒リスク）
  - **加熱温度・加熱時間**
  - **食材名**（同じ日本語名でも国によって指す魚が違うことがある）
- **食材の代替案を必ず併記する。** 海外で入手困難な食材は、現地で手に入る代替を示す。これが**実用性＝引用される理由**になります。

### 技術要件（CODE）

| # | 要件 |
|---|---|
| 1 | URLに `/recipes/` を含める（KPI計測の前提） |
| 2 | 言語ごとに**独立したURL**を持つ（`/en/recipes/...` 等）。同一ページ内での言語切替のみにしない |
| 3 | `hreflang` を正しく設定し、言語版どうしを相互に指定する |
| 4 | 構造化データ **`Recipe`** を実装（材料 `recipeIngredient`、手順 `recipeInstructions`、調理時間、分量） |
| 5 | 単位を**併記**（グラム／オンス、℃／℉） |
| 6 | 地域名に地図・地域紹介ページへの内部リンク |
| 7 | 撮影画像は自社素材のみ。`alt` テキストを言語ごとに用意 |

> **構造化データ `Recipe` はこの企画の武器です。** Q&AのFAQPageと違い、
> **Recipeは検索結果での表示・AIの理解の両面で、現在も実用的に機能している領域**です。
> ここは必ず実装してください。

## 7. ペース・KPI

### ペース

- **週1〜2本**（日本語＋英語の2言語で1本とカウント）。
- 実際に調理する工程が入るため、質問箱より工数が重い。
- 工数目安：リサーチ1.0h／調理・撮影2.5h／執筆1.5h／翻訳・監修1.5h／公開0.5h＝**約7.0h/本**
- 第1フェーズ＝**8週間 / 8〜16本**。まず**47都道府県のうち、特産品が明確な10県**から。

### KPI

| 指標 | 見るもの |
|---|---|
| **海外からのセッション比率** | この企画固有の主指標 |
| 言語別の表示回数・CTR（Search Console） | 英語版が日本語版を上回るか |
| AI検索での引用（Bing AIパフォーマンス／自社ログ） | 質問箱・いいニュースと同基準で比較 |
| 構造化データの有効性（Search Consoleの拡張レポート） | `Recipe` が正しく認識されているか |

### 判定（8週後）

| 判定 | 条件 | アクション |
|---|---|---|
| 拡大 | 英語版の海外セッションが日本語版の30%以上 | 言語を4言語に拡大。47都道府県制覇を計画化 |
| 継続 | 10〜30% | 2言語のまま本数を積む |
| 見直し | 10%未満 | 料理の選定（知名度の高いものへ）と翻訳品質を見直す |
