# 社内FAQ｜情報収集と著作権 — 編集部が迷ったら読む

> 会長CEOからの質問「情報を取りに行く行為は間違いか？なぜ引用できないのか？」への回答を、
> 編集部全員が同じ理解を持てるようFAQ化したもの。**新任者は必ず最初に読むこと。**

---

## Q1. 他社サイトを見に行って情報を集めるのは、いけないことですか？

**A. まったく問題ありません。むしろ取材の基本です。**

制限があるのは「見に行くこと」ではなく、**「見たものをどう使うか」**です。

| 段階 | 判定 |
|---|---|
| 見る・読む・調べる | ✅ 完全に自由 |
| 理解する・傾向をつかむ | ✅ 完全に自由 |
| **自分の言葉でゼロから書く** | ✅ 完全に自由 |
| 本文をコピーして載せる | ❌ 複製権侵害 |
| 本文を翻訳して載せる | ❌ 翻訳権・翻案権侵害 |
| スクリーンショットを載せる | ❌ 複製権侵害 |
| 機械で大量に取得・保存する | ❌ 利用規約違反（著作権とは別の問題） |

**覚え方：「頭に入れて持ち帰るのは自由。ファイルで持ち帰るのはダメ。」**

## Q2. 引用は法律で禁止されているのですか？

**A. いいえ。日本の著作権法は引用を認めています（著作権法32条）。**

適法な引用の要件（判例・実務上の整理）：

1. すでに**公表された**著作物であること
2. 引用部分が**明確に区別**されていること（カギカッコ、引用ブロック等）
3. **自社の文章が「主」、引用が「従」**であること（量・質の両面で）
4. 引用する**必然性**があること（なんとなく載せるのはダメ）
5. **出所を明示**すること（著作権法48条）

なお、引用の際に**翻訳して用いること自体は法律上認められています**（著作権法47条の6）。
つまり「翻訳したから違法」ではなく、**「引用の5要件を満たさない使い方」が違法**です。

## Q3. では、なぜVVは「引用ゼロ運用」にしているのですか？

**A. 法律上できないからではなく、運用上そのほうが安全だからです。理由は3つ。**

### 理由1｜週2〜3本の量産で、毎回5要件を判定するのは事故る

編集部員が判断を1回間違えるだけで、当社は上場企業として訴訟リスクを負います。
**「引用しない」というルールなら、判断ミスが起こりようがありません。**
判断が必要なルールより、判断が不要なルールのほうが、組織では強い。

### 理由2｜「主従関係」の判定は、実務では想像以上に難しい

「引用が従」であるかは、量だけでなく**質**でも判断されます。
記事の一番おいしい部分を引用に頼っていると、量が少なくても「従」と認められないことがあります。
これは専門家でも見解が割れる領域です。編集部が現場判断すべきことではありません。

### 理由3｜Redditには特有の事情がある

Reddit社は**投稿データを有償ライセンスとして販売する事業**を持っており（2024年にGoogle社・OpenAI社との契約を公表）、
無断利用に対して**実際に提訴しています**（2025年6月、Anthropic社を提訴）。
一般のWebサイトより厳しく見るべき相手です。

## Q4. じゃあ何も引用してはいけないのですか？

**A. いいえ。以下は積極的に使ってください。記事の信頼性が上がります。**

| 対象 | 扱い |
|---|---|
| 法令の条文 | **著作物ではない**（著作権法13条）。自由に使える |
| 公的機関の統計数値・研究データの数値 | **数値は事実であり著作物ではない**。自由に使える |
| 公的機関の資料からの短い引用 | **適法**。出典を明記して使う。むしろ推奨 |
| 政府標準利用規約に基づく公開データ | **出典明示で二次利用可**（CC BY 4.0互換） |
| クリエイティブ・コモンズ表示のある素材 | **ライセンス条件に従えば利用可**。条件を必ず読むこと |

**切り分けの原則：**
> **「出典として公的機関を引く」＝大歓迎。「他人が書いた文章を持ってくる」＝NG。**

## Q5. レシピの材料と手順は、著作物ですか？

**A. 材料の一覧と調理手順そのものは、原則として著作物ではありません。**

- 著作権が守るのは**「表現」**であって、**「アイデア・事実・手順」ではない**。
- 「じゃがいも2個、玉ねぎ1個を切って炒める」は**事実の記述**であり、誰かの独占物ではない。
- 米国著作権局も、単なる材料の羅列（mere listing of ingredients）は保護対象外としている。

**ただし、以下は著作物なので使ってはいけません。**

| ❌ 使えないもの | 理由 |
|---|---|
| レシピに添えられた**説明文・エッセイ・コツの文章** | 創作的表現 |
| **写真・動画・イラスト** | 著作物 |
| **レシピ集の選択・配列をまるごと真似る** | 編集著作物の侵害 |
| 上記文章を**翻訳して載せる** | 翻訳権・翻案権侵害 |

**したがって正しいやり方は：**
材料と手順という「事実」を把握 → **VVの厨房で実際に作って検証** → **自分の分量・自分の言葉・自分の写真**で書く。
これは合法であり、かつ**そのほうが記事の質が高くなります。**

## Q6. 「誰でも見られるサイト」なら自由に使えますか？

**A. いいえ。これは最も多い誤解です。**

- **無料で公開されている ≠ 著作権を放棄している。**
- 会員登録なしで読めることと、転載してよいことは、まったく別の話です。
- 各サイトの**利用規約と著作権表記を必ず読む**こと。「転載可」「CC BY」と明示されている場合のみ、その条件の範囲で使えます。

---

## Q7. ニュース記事の「事実」は使えますか？

**A. 事実そのものは使えます。ただし記事本文は使えません。**

- 著作権法10条2項は「**事実の伝達にすぎない雑報及び時事の報道**」を著作物から除いています。
- しかしこれは、人事異動・死亡記事のような**ごく短い事実の伝達**を想定した規定です。
- **記者が構成し、取材して書いた報道記事の本文は、通常は著作物です。** リライトも翻案になりえます。

**正しいやり方：**
「A社が新製品を発表した」という**事実**を掴んだら、
→ **A社の公式プレスリリース（一次情報）に当たる**
→ **VVが自分の言葉で書く**
→ **出典としてA社の公式発表にリンクする**

通信社・新聞社の記事を書き直すのではなく、**一次情報まで戻る**。これが唯一の正解です。

## 迷ったときの3つの質問

1. **これは「事実」か、それとも「誰かの表現」か？** → 事実なら使える。表現ならダメ。
2. **一次情報まで戻ったか？** → 戻っていないなら、まだ書き始めない。
3. **1件だけに頼っていないか？** → 1件依拠は翻案リスク。3件以上で確認する。

**3つとも自信を持って答えられないなら、編集長へ。編集長が迷ったら法務へ。迷ったまま出さない。**
