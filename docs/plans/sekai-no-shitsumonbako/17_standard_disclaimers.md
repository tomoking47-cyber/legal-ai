# 全連載共通｜定型文（出所の明示・自己判断の免責）

- 方針決定：会長CEO（2026-09-08）
  1. **「当社の情報は、あくまでも日本国民のアイデアです」と位置づけを明示すること**
  2. **記事の最後に、必ず「ご自身の判断で」という免責を入れること**
  3. **「100%」のような言い切りをしないこと**
- **本ファイルが定型文の唯一の正本です。** 各記事はここからコピーして使用すること。

---

## 1. 3つの原則

| # | 原則 | なぜ |
|---|---|---|
| **1** | **出所を偽らない** | VVは公的機関でも研究機関でもありません。**紹介しているのは「日本の生活者の知恵」です。** そう名乗ることが、いちばん誠実で、いちばん強い |
| **2** | **最終判断を読者に返す** | 読者の環境・体質・住まいはそれぞれ違います。**VVがすべてを引き受けることはできないし、引き受けるべきでもない** |
| **3** | **言い切らない** | 「100%」「絶対」「必ず効く」は、法令上の問題であると同時に、**嘘になります。** 嘘をつかないメディアであることが、長期の資産です |

> **この3つは、法務上の防御であると同時に、VVの編集姿勢そのものです。**
> 「守るために仕方なく書く文」ではなく、**「私たちはこう考えている」という表明**として書いてください。

## 2. 【必須】全記事の末尾に入れる定型文

### 日本語版

```
### この記事について

本記事で紹介しているのは、**日本の生活者の間で受け継がれてきた工夫やアイデア**です。
公的機関による推奨や、専門家による指導ではありません。

内容は一般的な情報として提供しているもので、効果や結果には個人差があり、
条件や環境によって異なります。

**実際に取り入れるかどうかは、ご自身の状況に応じてご自身の判断で決めてください。**
本記事の内容を実行したことにより生じた損害・不具合・怪我について、当社は責任を負いかねます。
```

### 英語版

```
### About this article

What we share here are **ideas and everyday practices passed down among people living in Japan.**
They are not official recommendations, and they are not professional instruction.

This is general information. Results vary from person to person and depend on your
own conditions and surroundings.

**Please decide for yourself, using your own judgement, whether any of this suits your situation.**
We cannot accept responsibility for any damage, loss or injury arising from following this article.
```

> **「your own judgement」という語は、機械チェック（`tools/translation_checker/`）の必須項目です。**
> **この語が英語版にないと、重大エラーとして公開が止まります。** 言い換えないでください。
> 日本語版も同様に、**「ご自身の判断」**という語を必ず含めてください。

## 3. 【追加】内容に応じて足す注記

上記の定型文に**加えて**、該当する場合は以下を足します。

### 3-1. 健康・医療に触れる場合

```
本記事は、特定の症状の診断・治療・予防を目的としたものではありません。
体調に不安がある場合は、自己判断せず医療機関にご相談ください。
```

```
This article is not intended to diagnose, treat, or prevent any condition.
If you have concerns about your health, please consult a healthcare professional.
```

### 3-2. 化粧品・スキンケアの場合

```
化粧品は疾病の治療・予防を目的とするものではありません。
肌に異常を感じた際は使用を中止し、皮膚科専門医にご相談ください。
```

```
Cosmetics are not intended to treat or prevent any condition.
If you notice any irritation, stop using the product and consult a dermatologist.
```

### 3-3. 食品・レシピの場合

```
食材によっては十分な加熱が必要です。生食は、生食用として流通しているものに限ってください。
アレルギーのある方は、原材料をご確認ください。
```

```
Some ingredients must be cooked thoroughly. Eat raw only what is sold for raw consumption.
If you have allergies, please check the ingredients carefully.
```

### 3-4. DIY・掃除・住まいの場合

```
使用する製品の表示に必ず従い、洗剤どうしを混ぜないでください。
目立たない場所で試してから行ってください。
賃貸住宅にお住まいの場合は、事前に貸主にご確認ください。
家具・家電に手を加えると、メーカーの保証を受けられなくなる場合があります。
```

```
Always follow the instructions on any product you use, and never mix cleaning products.
Test on an inconspicuous area first.
If you rent your home, check with your landlord before making any changes.
Modifying furniture or appliances may void the manufacturer's warranty.
```

### 3-5. 制度・法令・手続きに触れる場合

```
制度や規則は変更されることがあります。実際のお手続きの際は、必ず公式の最新情報をご確認ください。
```

```
Rules and procedures can change. Please confirm the latest official information before you act.
```

## 4. 【禁止】言い切り表現

**以下は、日本語・英語とも使用禁止です。** 機械チェックで検出され、公開が止まります。

### 日本語

| ❌ 禁止 | ✅ 言い換え |
|---|---|
| 100% / 絶対に / 確実に | 多くの場合／〜という報告があります |
| 治る／治ります／完治 | （使用不可。症状の話は扱わない） |
| 必ず効く／間違いなく効く | 〜と考えられています |
| 副作用はありません | （使用不可） |
| 日本一／世界一／No.1／最強 | （客観的根拠を示せない限り使用不可） |
| 永久に／一生 | 長く／繰り返し使えます |
| 誰でも必ず | 多くの方に |

### 英語

| ❌ 禁止 | ✅ 言い換え |
|---|---|
| guaranteed / 100% safe | generally / in many cases |
| cures / heals / treats | （使用不可） |
| clinically proven | one study reported that ...（出典必須） |
| best in Japan / superior to | （使用不可） |
| anti-aging / whitening | age care / brightening |
| eliminates / removes wrinkles | （使用不可） |

> **完全なリストは `tools/translation_checker/glossary.csv` にあります。**
> **事故が起きたら、必ずその語を用語集に追加してください。** 同じ事故は二度と起きなくなります。

## 6. 最後に — この定型文の意味

**免責文は、責任逃れのために書くのではありません。**

VVが伝えているのは、**科学的に証明された唯一の正解**ではなく、
**この国の人々が、暮らしのなかで見つけてきた工夫**です。

**そう名乗ったうえで、判断は読者に返す。**

それが、公的機関でも研究機関でもないVVが、
**世界の読者から長く信頼されるための、唯一の立ち位置**だと考えます。
