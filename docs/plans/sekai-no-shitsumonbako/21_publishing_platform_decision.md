# 公開基盤 決定書 — 600本をどこに、どう載せるか

- 起案：経営企画／情報戦略室
- 日付：2026-09-12
- 対象：『世界の質問箱』600本 × 5言語（3,000ページ）

- 関連：`13_implementation_spec.md`（URL設計）／`04_kpi_measurement.md`（計測）

---

## 1. 結論

**新しいサイトは作らない。既存の valuevillage.jp（Shopify）にブログとして載せる。**

理由は3つです。

1. **導線が切れないこと。** 訪日客が記事を読んで、そのまま商品にたどり着く。これが企画の核です。別ドメインに切り出すと、この導線が最初から失われます。
2. **ドメインの評価を分散させないこと。** 検索・AI検索の評価はドメイン単位で積み上がります。600本を別ドメインに置くと、ゼロから積み直しになります。
3. **開発コストと期間。** 自社サイトを新設すると、設計・開発・保守が発生します。Shopifyの標準機能で足ります。

**ただし、そのまま載せることはできません。** 実データを確認したところ、既存の設計書と現実が食い違う点が4つあります。

## 3. 決裁が必要な4件

### 決裁1｜URL構造を変更する必要があります

`13_implementation_spec.md` では `/questions/<スラッグ>` と確定していますが、**Shopifyではこの形のURLは作れません。** ブログ記事のURLは必ず `/blogs/<ブログ名>/<記事名>` になります。

| | 設計書 | Shopifyで実現可能な形 |
|---|---|---|
| 記事 | `/questions/cleansing` | `/blogs/questions/cleansing` |
| 一覧 | `/questions/` | `/blogs/questions` |
| 英語 | `/en/questions/cleansing` | `/en/blogs/questions/cleansing` |

> **計測設計への影響：ありません。** `04_kpi_measurement.md` はURLに含まれる文字列で絞り込む設計です。絞り込み文字列を `/questions/` から **`/blogs/questions/`** に変えれば、そのまま機能します。

**あわせて重要な判断がひとつ。**

600本を**専用のブログ1本（`questions`）にまとめる**か、既存の `health` `fashion` `trend` ブログに振り分けるか。

- **推奨：専用ブログ1本にまとめる。**
- 理由：既存の `health`（7記事）`fashion`（3記事）`trend`（5記事）には**別企画の記事が既に入っています。** そこへ混ぜると、**Q&A記事だけの数字を切り出せなくなり、この企画の検証そのものが成立しません。**
- 棚の分類は、URLではなく**タグ**（beauty / fashion / health / trend / inbound / wisdom）で持たせます。

**→ ご判断いただきたいこと：`/blogs/questions/` への変更と、専用ブログ方式で進めてよいか。**

### 決裁2｜中国語（繁体）と韓国語を追加する必要があります

600本 × 5言語を用意しましたが、**ストアに設定されているのは3言語だけ**です。

| 言語 | 原稿 | ストア設定 |
|---|---|---|
| 日本語 | 400本 | ✅ 公開中 |
| 英語 | 600本 | ✅ 公開中 |
| 中国語（簡体） | 600本 | ✅ 公開中 |
| **中国語（繁体）** | **600本** | ❌ **未設定** |
| **韓国語** | **600本** | ❌ **未設定** |

**このままでは1,200本分の原稿が使えません。** 追加自体はShopifyの管理画面での設定作業ですが、**プランごとに公開できる言語数の上限があります。** 現行プランで5言語まで公開できるかを、開発担当に確認させてください。

**→ ご判断いただきたいこと：繁体中国語・韓国語を追加してよいか。上限に達している場合、プラン変更まで踏み込むか。**

---

### 決裁3｜日本語版のない200本をどう扱うか

Shopifyは**「主言語（日本語）の記事が1件あり、そこに各言語の翻訳がぶら下がる」**という構造です。

ところが inbound（Japan Questions）と wisdom（Everyday Wisdom）の**200本は英語が原文で、日本語版がありません。** 訪日外国人向けに設計したためです。

選択肢は2つです。

| 案 | 内容 | 評価 |
|---|---|---|
| **A** | この200本の**日本語版を新たに作る** | 追加作業は発生しますが、構造がきれいになり、日本人読者にも届きます |
| **B** | 主言語の枠にも英語を入れる | 追加作業ゼロ。ただし日本語で検索した人に英語が出ます |

- **推奨：A。** 「日本人が当たり前すぎて書かない話」は、実は**日本人自身にも面白い**内容です。捨てるには惜しい200本です。作業は私が実行できます。

**→ ご判断いただきたいこと：A（日本語版を作る）／B（英語のまま載せる）。**
