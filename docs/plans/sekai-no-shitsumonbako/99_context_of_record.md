## 2. 役割分担（会長CEOより明示。2026-09-12）

```
会長CEO ──→ 弟様 ──→ 公開
（骨組みコンテンツを作る）　（デザイン・編集・アップ）
   ↑
情報戦略室（AI）＝ 会長CEOの手元で骨組みコンテンツを作る作業を担う
```

| 工程 | 担当 | 内容 |
|---|---|---|
| **骨組みコンテンツの作成** | **会長CEO**（実作業は情報戦略室＝AIが担う） | 記事の中身・多言語版・事実検証・法務準備 |
| **デザイン・編集・アップ** | **弟様** | `play.valuevillage.us` への実装、見た目、最終編集、公開作業 |
| 法務レビュー | 弁護士 | 薬機法・景表法 |

### この分担から導かれること（重要）

- **サイトの設計・URL構造・CMS選定・技術実装は、情報戦略室の担当範囲ではない。** 弟様の領域。
  - 2026-09-12、情報戦略室が公開基盤の決定書（`21_publishing_platform_decision.md`）を作成したのは**越権であり、前提も誤っていた。無効。**
- **情報戦略室の成果物は「弟様が受け取って、デザイン・編集・アップできる状態の原稿」まで。**
  - したがって重要なのは、①中身の正確さ ②法務上の安全性 ③**弟様が扱いやすい形で渡すこと**。
- **技術的な仕様書を弟様に指示する立場にはない。** 必要なら「参考情報」として渡すにとどめ、決めるのは弟様。

## 3. 会長CEOからの恒久的な指示（変更されるまで有効）

- 当社の情報は**あくまでも日本国民のアイディア**であると明記すること。
- 記事の最後に必ず**「ご自身の判断で」**という趣旨の断りを入れること。
- **「100%」「必ず効く」など断定的な表現は使わない。**
- 翻訳は**AIで2回、3回**実行して精度を上げること。
- **店舗はない。**
- 毎回確認を求めない。完了時にまとめて報告すること。
- **成果物はGitHubのリンクで渡すこと。**添付ファイル・アーティファクトは会長CEOの環境では開けない（2026-09-12 確認）。
