## 2. どうやって作ったか（再現手順）

### 2-1. 執筆

1バッチ10本、2棚ずつ（beauty/fashion → health/trend → inbound/wisdom）を回し、棚の本数を常に均等に保つ。
1話題1本。既出スラッグと重複する話題は書かない。
各バッチで原稿チェックを実行し、重大0件を確認してからコミット。

### 2-2. 翻訳（会長CEO方針「AIで2回、3回」）

「同じことを3回」ではなく「**違う角度から3回**」。詳細は [`16_translation_protocol.md`](16_translation_protocol.md)。

| STEP | 何を見つけるか | 誰が |
|---|---|---|
| 1. 翻訳 | — | AI（用語集を毎回プロンプトに貼る） |
| 2. **逆翻訳** | **誤訳・訳し漏れ・AIの創作** | AI＋**人が日本語同士を比較** |
| 3. 機械検査 | 法規表現・アレルゲン・数字 | `translation_checker` |
| 4. 敵対的推敲 | 不自然さ・失礼な表現 | AI（「必ず10個挙げろ」と指定する） |

中国語・韓国語には専用の禁止語チェッカーを別途作成：
`治愈/治癒/根治/保证/保證/100%/绝对安全/絕對安全/치료/완치/보장/반드시 효과/절대 안전`

### 2-3. 第2パス（事実確認）— 今回の主作業

**執筆したAIとは別のAIに、全文を読ませて事実確認させる**方式。3層構造です。

```
① レビュー層（100エージェント並列）
   500本を100バッチ（1バッチ5本）に分割
   → 各AIが全文を読み、数値・年次・法令名・出典URLをウェブ検索で照合
   → 【重要】レビュアーは記事を編集しない。
     「現在の文 → 修正文 → 根拠 → 出典URL」の形でJSONに報告するだけ
   → 深刻度を critical / major / minor で付与

② 反映層（33エージェント）
   critical と major のみを記事に反映
   → 1件ごとに5言語すべてへ展開
   → minor は反映せずCSVに退避（編集部の判断に委ねる）

③ 中央検査
   禁止語・表の構造・定型注記の有無を全2,800ファイルで再検査
```

**なぜレビューと反映を分けたか**：同じAIに「見つけて直せ」とやらせると、
自分の判断を検証せずに書き換えてしまいます。**報告と適用を別のAIに分けることで、
指摘の根拠がJSONに残り、後から検証できます。** JSONは `/tmp` のスクラッチパッドに
残っていましたが揮発します。**指摘の内容そのものは2つのCSVに保存済みです。**

> これらは**すべて正当な用法**です：
> - 定型注記の「化粧品は疾病の診断・**治療**・予防を目的としません」＝**否定文**
> - 「誤解：ジーンズは**絶対**に洗うな」＝**誤解の引用**
> - 「国が**保証**しているわけではない」＝**否定文**
> - `"absolutely safe"` ＝ **禁止される広告表現の列挙**
> - `100%` ＝ 当日キャンセル料100%、指定席稼働率100% という**事実の数値**
>
> **効能を断定する用法は1件もありません。** 自動チェッカーを書くときは
> 否定文・引用・数値を除外する ALLOW リストが必須です。

### 7-3. 作業のときのルール

- **1件ごとに5言語すべてへ展開する。** 片方だけ直すと言語間で数値が食い違います。

## 8. 会長CEOからの恒久的な指示（変更されるまで有効）

> **これらは `99_context_of_record.md` の正本から転記したものです。**

1. 当社の情報は**あくまでも日本国民のアイディア**であると明記すること。
2. 記事の最後に必ず**「ご自身の判断で」**という趣旨の断りを入れること。
3. **「100%」「必ず効く」など断定的な表現は使わない。**
4. 翻訳は**AIで2回、3回**実行して精度を上げること。
5. **店舗はない。**
6. 毎回確認を求めない。**完了時にまとめて報告する。**
7. **成果物はGitHubのリンクで渡す。** 添付ファイル・アーティファクトは開けない。

### 禁止語の一覧

| 言語 | 語 |
|---|---|
| 日本語 | 治る／完治／一生／100%／絶対／必ず効く／確実に効く／根治／保証 |
| 英語 | cures / treats / guaranteed / cure / remedy / 100% / absolutely safe |
| 中国語 | 治愈／治癒／根治／保证／保證／绝对安全／絕對安全 |
| 韓国語 | 치료／완치／보장／반드시 효과／절대 안전 |

**ただし**、否定文・誤解の引用・禁止表現の列挙・素材の配合率や料金の数値としての `100%` は
**違反ではありません**（第3-1節の注意書き参照）。

### 「言い切り」の判断基準（今回の運用実績）

| 表現 | 判定 | 理由 |
|---|---|---|
| 「AよりBのほうが確実です」 | ✅ 可 | 比較助言であって効能の断定ではない |
| 「Bの効果は確実です」 | ❌ 不可 | 効果そのものの断定 → 「Bのほうが〜しにくくなります」に言い換え |
| 「混用率100%」 | ✅ 可 | 素材の配合率。効能ではない |
| 「当日キャンセル料100%」 | ✅ 可 | 料金の事実 |
| 「誤解：〜は絶対に洗うな」 | ✅ 可 | 誤解の引用 |
| 「絶対に伸ばさず」 | △ 言い換え済 | 手入れの指示だが、紛れを避けて「引っ張らず」に変更 |
