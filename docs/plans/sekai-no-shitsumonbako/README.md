## 30秒サマリー

- **やること**：世界中のオンラインコミュニティで繰り返し出てくる疑問を編集部が観察し、**質問を一般化して立て直し**、VV編集部が完全オリジナルで回答するQ&A連載。
- **なぜ**：Q&A形式はAI検索（Copilot / ChatGPT検索 / Google AI Overviews等）が最も引用しやすい構造。GEO（生成AI最適化）で通常記事より高い引用率を狙う。
- **絶対NG**：投稿の引用・翻訳転載・スクショ掲載、**および自動収集（スクレイピング／API大量取得）**。
- **第1フェーズ**：週2〜3本 × 8週＝16〜24本。KPI比較後に本数判断。
- **第2フェーズ**：質問源をVV会員コミュニティに移行（→ そのために**今すぐ会員規約へUGC利用許諾条項を追加**）。
