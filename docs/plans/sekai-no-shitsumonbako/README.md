## 30秒サマリー

### 共通の設計思想

> **「取りに行く」のは自由。「持ち帰って載せる」のがNG。**
> 見る・読む・調べる・理解するのは完全に自由です。禁止しているのは
> ①本文のコピー・翻訳転載・スクショ ②機械での大量取得 の2つだけ。
> 詳細は `12_faq_copyright.md`。

### 3連載それぞれの勝ち筋

- **世界の質問箱**：Q&A構造はAI検索が引用しやすい。**仮説検証が主目的**。8週で判定。
- **世界のいいニュース**：VALUE VILLAGEという社名と完全に一致。**最大リスクは著作権ではなく事実誤認**。一次情報からしか書かない。
- **世界にひらく郷土レシピ**：**材料と手順は著作物ではない**ため構造的にリスクが低く、公的機関のオープンデータが豊富。**多言語化した瞬間に競合が消える**。3企画で最も勝ち筋が見えている。

### いますぐ動かすべきこと

1. **CODE**：3連載のURL設計を確定（`/questions/` `/goodnews/` `/recipes/`）。**連載開始前に。後から変えると計測が分断される**。→ `13_implementation_spec.md`
2. **CODE**：`robots.txt` でAI検索クローラーをブロックしていないか確認。**ブロックしていたら引用されようがない**。
3. **情報戦略室 / CODE**：自社データからの質問自動抽出 → **実装完了**。`tools/question_miner/README.md` の手順で実行。判断根拠は `14_data_sourcing_decision.md`
4. **法務**：VV会員規約にUGC利用許諾条項を追加（第2フェーズへの布石）。
5. **情報戦略室**：対照群となる通常記事を**開始時点で先に選定・記録**。

### 守る一線（3連載共通）

> **他社サイトの自動収集はしない。内容を変更して掲載することもしない。**
> 「少し変えれば大丈夫」は成立しません（翻案権侵害）。
> **自動化は、自社データに対して行います。** 判断根拠は `14_data_sourcing_decision.md`。
