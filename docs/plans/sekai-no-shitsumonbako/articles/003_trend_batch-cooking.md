# Q. 作り置きについて、よくある誤解は？｜世界の質問箱 #3

- 棚：`trend` ／ URL：`/questions/batch-cooking` ／ 要注意：制度・安全
- ステータス：**ドラフト（法務レビュー前・出典未検証）**

作り置きは世界中で実践されていますが、保存の考え方は国や家庭で大きく違います。日本の行政は、家庭での食中毒予防を**6つの場面と具体的な温度**で示しています。

## A. 最大の誤解は「冷蔵庫に入れれば安心」です。低温は傷みを止めるのではなく、遅くするだけです。

厚生労働省の「家庭でできる食中毒予防の6つのポイント」は、**冷蔵庫は10℃以下、冷凍庫は−15℃以下**を目安とし、それでも**「細菌は死なない」ため過信しない**ことを呼びかけています。

## 3つの原則と、6つの場面

食中毒予防の原則は**「つけない・増やさない・やっつける」**の3つ。これを家庭の6つの場面に分けたのが「6つのポイント」です。

| 場面 | 要点 |
|---|---|
| 1. 買い物 | 生鮮食品は最後に買い、寄り道せず帰る |
| 2. 家庭での保存 | 冷蔵**10℃以下**、冷凍**−15℃以下**。詰めすぎない |
| 3. 下準備 | 手洗い。生の肉・魚を扱った器具はそのつど洗う |
| 4. 調理 | **中心部を75℃で1分以上**加熱 |
| 5. 食事 | 温かいものは温かく、冷たいものは冷たく |
| 6. 残った食品 | 早く冷やし、清潔な器具で。**時間が経ちすぎたら捨てる** |

作り置きは、この**2・4・6**に集中する行為です。

## 誤解1｜冷蔵なら1週間もつ

もつ日数は料理によってまったく違います。水分が多いもの、加熱後に手で触れたもの、生の食材が混ざるものほど短くなります。**一律の日数で考えないでください。** 行政の資料でも、残った食品は「時間が経ちすぎたら、思い切って捨てる」とされています。

## 誤解2｜熱いまま冷蔵庫に入れてよい

温かいものを入れると庫内の温度が上がり、**他の食品の保存温度（10℃以下）を崩します。** 浅い容器に小分けにして早く冷ましてから入れる、というのが6つのポイントの「残った食品」の項で示された方法です。

## 誤解3｜一度冷ませば、あとは触ってよい

取り分けに使う箸やスプーンから細菌が入ります。**清潔な器具を使い、食べる分だけ取り出してください。**

## 誤解4｜温め直しは軽くでよい

残った食品を温め直すときも、**75℃以上を目安に十分に加熱**することが示されています。

## 誤解5｜においや見た目で必ず判断できる

見た目やにおいに変化がなくても、安全とは限りません。**日数の管理を優先し、少しでも異常を感じたら食べないでください。**

> **【要検証】** 温度・時間の目安（10℃以下／75℃1分など）は厚生労働省「家庭でできる食中毒予防の6つのポイント」の記述で確認してください。
