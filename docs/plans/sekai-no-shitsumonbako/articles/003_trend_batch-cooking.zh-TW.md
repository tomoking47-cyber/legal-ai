# Q. 關於常備菜（作り置き），人們常有哪些誤解？｜Japan Questions #3

- Shelf: `trend` ／ URL: `/zh-tw/trend/batch-cooking` ／ Status: **草稿 — 出處未核實**

常備菜——「作り置き」（tsukurioki），事先做好幾道菜放進冰箱保存——世界各地都在做，但關於保存的觀念在國家與家庭之間差異很大。日本政府把家庭中的食物中毒預防整理為**六個場景與具體溫度**。如果你在日本買菜、做飯，這些就是需要知道的數字。

## A. 最大的誤解是「放進冰箱就安全了」。低溫無法阻止食物變質，只能延緩。

厚生勞動省（厚生労働省）的手冊「家庭可做的食物中毒預防六要點」以**冷藏 10℃ 以下、冷凍 −15℃ 以下**為參考標準，並提醒不要過度依賴低溫，因為**「細菌不會死」**。

## 三個原則，六個場景

食物中毒預防的三原則是**「不沾附・不增殖・徹底消滅」**（つけない・増やさない・やっつける）。「六要點」就是把這三原則套用到家庭中的六個場景。

| 場景 | 重點 |
|---|---|
| 1. 採買 | 生鮮食品最後買，買完直接回家 |
| 2. 在家保存 | 冷藏 **10℃ 以下**、冷凍 **−15℃ 以下**。不要塞太滿 |
| 3. 前置準備 | 洗手。處理過生肉、生魚的器具每次都要清洗 |
| 4. 烹調 | 加熱到**中心達 75℃、持續 1 分鐘以上** |
| 5. 用餐 | 熱的東西保持熱，冷的東西保持冷 |
| 6. 剩餘食品 | 儘快冷卻，使用乾淨的器具。**放太久就丟掉** |

常備菜正是集中在**第 2、4、6 點**上的行為。

## 誤解1｜放冷藏可以放一週

一道菜能放多久，因菜色而完全不同。水分越多、做好後被觸碰得越多、生的食材含量越高，能放的時間就越短。**不要用單一的固定天數來思考。** 政府的資料本身對剩餘食品的說法是：「放太久就果斷丟掉。」

## 誤解2｜還熱著就可以放進冰箱

熱的食物會讓冰箱內部溫度上升，**破壞其他食品的保存溫度（10℃ 以下）。** 分裝到淺的容器裡快速冷卻後再放進去——這就是六要點中「剩餘食品」一項所示的方法。

## 誤解3｜只要放涼了，之後就可以隨意碰

細菌會從夾取用的筷子或湯匙進入。**請使用乾淨的器具，只取出要吃的份量。**

## 誤解4｜重新加熱時稍微熱一下就好

重新加熱剩餘食品時，同樣要**以 75℃ 以上為參考，充分加熱**。

## 誤解5｜靠氣味與外觀一定判斷得出來

即使外觀與氣味都沒有變化，食物也可能已經不安全。**請以計算天數為優先，只要覺得有任何不對勁，就不要吃。**

> **[待核實]** 溫度與時間的參考值（10℃ 以下、75℃ 1 分鐘等）請對照厚生勞動省手冊「家庭可做的食物中毒預防六要點」的記述確認。
