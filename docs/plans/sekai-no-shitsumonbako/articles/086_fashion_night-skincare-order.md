# Q. 夜のスキンケアは、どの順番でやればいいの？｜世界の質問箱 #86

- 棚：`fashion` ／ URL：`/questions/night-skincare-order` ／ 法務チェック：**必須**
- ステータス：**ドラフト（法務レビュー前）**

夜は工程が増えがちで、順番の議論もここに集中します。

## A. 一般的な目安は「落とす → 洗う → 水分の多いもの → 油分の多いもの」。ただし製品の使用方法が優先します。

夜の特徴は、**落とす工程がある**ことです。

## 一般的な流れ（目安）

1. 落とす（日焼け止めやメイクを使った日）
2. 洗う
3. 水分の多いもの
4. 油分の多いもの

## 誤解1｜落とす工程は毎日必ず必要

**その日に何を使ったかで変わります。** 使っていない日に同じ強さのものを使う必然性はありません。

## 誤解2｜時間をかけるほど効果がある

肌に触れる時間が長いほど、摩擦の負担は増えます。**製品の表示にある時間・量を守ってください。**

## 誤解3｜寝る直前に済ませるのがよい

**時刻より、こすらないこと・落とし残さないこと**のほうが実務的です。

## 誤解4｜朝と同じ品数が必要

夜に工程が多く、朝は少ない。**その逆も含めて、決まりはありません。**
