# Q. バッグの保管について、よくある誤解は？｜世界の質問箱 #104

- 棚：`fashion` ／ URL：`/questions/storing-bags` ／ ステータス：**ドラフト（法務レビュー前・出典未検証）**

革のバッグをどう保管すればよいか、という質問は各国の共通の悩みです。日本の住宅は湿度が高く、クローゼットの環境がバッグの寿命を左右します。

## A. 最大の誤解は「箱に入れて袋で密閉すれば安心」です。日本の住宅環境では湿気がたまり、カビと合皮の劣化を早めます。保管は「密閉」ではなく「型崩れ防止と通気」が基本です。

## 日本の住宅とカビの条件

- 東京の**年平均相対湿度は約60〜70%**、梅雨期（6〜7月）は**月平均で75%前後**に達します（気象庁 過去の気象データ）。
- カビは一般に**湿度70%以上・温度20〜30℃**で繁殖しやすいとされ、クローゼットの奥は室内より湿度が高くなりがちです。
- 合成皮革（ポリウレタン）は**加水分解**という、湿気による化学変化で表面がべたつき・剥がれます。製造から**数年で始まる**とされ、使用頻度に関係なく進みます。

| 保管の要点 | 理由 |
|---|---|
| 中に詰め物（不織布に包んだ紙など）を入れる | 型崩れ防止 |
| 不織布の袋に入れ、ビニールには入れない | 通気を保つ |
| クローゼットの下段ではなく中〜上段 | 湿気は下にたまる |
| 月に1回は袋から出して風を通す | 湿気・カビの予防 |
| 除湿剤（塩化カルシウム等）は直接触れさせない | 液漏れによる変色 |

> 【要検証】湿度の数値は気象庁「過去の気象データ検索」（東京・月別平年値）で確認してください。加水分解の年数はメーカー・素材によって異なるため、断定的な数値は避けています。

## 誤解1｜購入時の箱に入れておくのが一番

紙箱は湿気を吸い、密閉した箱内で放出します。**箱に入れるなら乾燥剤を併用し、定期的に開ける**ことが必要です。

## 誤解2｜ビニール袋で埃を防ぐ

**ビニールは湿気を閉じ込めます。** 通気性のある不織布袋が基本です。

## 誤解3｜合皮は本革より丈夫

合皮（ポリウレタン）は水に強い反面、**湿気による加水分解で本革より早く寿命が来る**素材です。乾燥した場所で保管しても進行は止まりませんが、遅らせることはできます。

## 誤解4｜革にはたっぷりクリームを

塗りすぎはべたつき・カビの栄養になります。**薄く、乾拭きしてから、目立たない場所で試す**のが基本です。スエード・ヌバックにはクリームは使えません。

## 誤解5｜防虫剤を一緒に入れておけば安心

衣類用防虫剤の一部（ピレスロイド系など）は**合皮・金具・ラメを変色させる**ことがあります。製品表示の「使用できないもの」を確認してください。
