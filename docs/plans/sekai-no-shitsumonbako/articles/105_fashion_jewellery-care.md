# Q. アクセサリーの手入れについて、よくある誤解は？｜世界の質問箱 #105

- 棚：`fashion` ／ URL：`/questions/jewellery-care` ／ ステータス：**ドラフト（法務レビュー前・出典未検証）**

「銀が黒くなった」「金メッキがはがれた」という質問は世界共通です。日本では貴金属の品位表示（造幣局のホールマーク）が普及しており、素材を確かめてから手入れを選べます。

## A. 最大の誤解は「金属なら全部同じ磨き方」です。純度・メッキ・石の有無で、使える方法が変わります。とくに研磨剤入りのクロスはメッキ品には使えません。

## まず素材を確かめる

日本で流通する貴金属製品には、任意の**造幣局の品位証明記号（ホールマーク）**が打刻されているものがあります。刻印の例：

| 刻印 | 意味 |
|---|---|
| K18 / 750 | 金75.0% |
| K10 / 417 | 金41.7% |
| SV925 / 925 | 銀92.5%（スターリングシルバー） |
| Pt900 / Pt950 | プラチナ90.0% / 95.0% |
| GP / GF | 金メッキ / 金張り（**中身は別の金属**） |

> 【要検証】品位区分と記号の詳細は、独立行政法人造幣局「貴金属製品の品位証明」ページで確認してください。

## 誤解1｜銀の黒ずみはサビ

黒ずみは**硫化**（空気中や汗の硫黄分との反応）で、サビ（酸化）とは別です。**表面だけの変化なので、銀磨きクロスや専用液で戻ります。** 温泉地では急速に進みます。

## 誤解2｜歯磨き粉で磨けばよい

研磨剤が粗く、**メッキ品ははがれ、真珠・オパール・トルコ石などの柔らかい石は傷つきます。** 銀の無垢（SV925）に限り、専用クロスのほうが安全です。

## 誤解3｜金は変色しない

純金（K24）はほぼ変色しませんが、**K18・K10は割金（銀・銅）が含まれるため、汗や化粧品で変色することがあります。** 使用後に柔らかい布で拭くのが基本です。

## 誤解4｜超音波洗浄機なら何でも洗える

超音波洗浄は**真珠・エメラルド・オパール・接着で留めた石**には向きません。石が緩んだり、割れたりするおそれがあります。ダイヤモンド・サファイア等の硬い石で、爪留めが確実なものに限られます。

## 誤解5｜つけたままお風呂・温泉に入っても大丈夫

温泉の**硫黄成分は銀を急速に黒くし、塩素（プールや漂白剤）は金の合金やメッキを傷めます。** 入浴・水泳・家事の前に外す習慣が、日本の生活者の間で広く共有されています。
