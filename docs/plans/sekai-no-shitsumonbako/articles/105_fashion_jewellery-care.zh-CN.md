# Q. 关于首饰保养，常见的误解有哪些？｜Japan Questions #105

- Shelf: `fashion` ／ URL: `/zh-cn/fashion/jewellery-care` ／ Status: **草稿 — 出处未核实**

“我的银饰变黑了”“镀金磨掉了”是全世界都会问的问题。在日本，贵金属制品上常见纯度印记（造币局的霍尔马克），所以在决定怎么保养之前，通常可以先确认手里的东西是什么。本文说明如何读懂这些印记，以及各种金属能承受什么。

## A. 最大的误解是“所有金属都用同样的方法打磨”。纯度、镀层以及有没有镶嵌宝石，都会改变哪些方法是安全的。特别是含研磨剂的擦拭布，绝不能用在镀层制品上。

## 首先，确认材质

在日本销售的部分贵金属制品带有**造币局（造幣局）的纯度霍尔马克**，这是自愿性的。你可能会看到的印记举例：

| 印记 | 含义 |
|---|---|
| K18 / 750 | 含金 75.0% |
| K10 / 417 | 含金 41.7% |
| SV925 / 925 | 含银 92.5%（925银／纯银） |
| Pt900 / Pt950 | 铂金 90.0% / 95.0% |
| GP / GF | 镀金／包金（**底下是另一种金属**） |

> **[待核实]** 请在造币局“贵金属制品的品位证明（霍尔马克）”页面确认纯度分类与印记。

## 误解1｜银变黑是生锈了

变黑是**硫化**（与空气或汗液中的硫发生反应），而不是生锈（氧化）。**这只是表面的变化，用银饰擦拭布或专用洗银液就能恢复。** 在温泉（onsen）地区，这个过程会很快发生。

## 误解2｜用牙膏打磨没问题

牙膏中的研磨剂颗粒较粗：**会磨掉镀层，也会划伤珍珠、欧泊、绿松石等较软的宝石。** 即使是纯银（SV925），使用专用擦拭布也更稳妥。

## 误解3｜黄金不会变色

纯金（K24）几乎不会变色，但**K18 和 K10 含有配合金属（银、铜），可能因汗液和化妆品而变色。** 佩戴后用软布擦拭是基本的习惯。

## 误解4｜超声波清洗机什么都能洗

超声波清洗**不适用于珍珠、祖母绿、欧泊以及用胶粘合的宝石**。宝石可能松动或开裂。只在钻石、蓝宝石等硬度高、且由爪镶牢固固定的宝石上使用。

## 误解5｜戴着首饰泡澡或泡温泉没关系

**温泉水中的硫会让银迅速变黑，而氯（泳池、漂白剂）会损伤金合金和镀层。** 在洗澡、游泳和做家务前把首饰摘下来，是在日本生活的人们普遍共有的习惯。
