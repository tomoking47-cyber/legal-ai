# Q. 關於首飾保養，常見的誤解有哪些？｜Japan Questions #105

- Shelf: `fashion` ／ URL: `/zh-tw/fashion/jewellery-care` ／ Status: **草稿 — 出處未核實**

「我的銀飾變黑了」「鍍金磨掉了」是全世界都會問的問題。在日本，貴金屬製品上常見純度印記（造幣局的霍爾馬克），所以在決定怎麼保養之前，通常可以先確認手上的東西是什麼。本文說明如何讀懂這些印記，以及各種金屬能承受什麼。

## A. 最大的誤解是「所有金屬都用同樣的方法擦拭」。純度、鍍層以及有沒有鑲嵌寶石，都會改變哪些方法是安全的。特別是含研磨劑的擦拭布，絕不能用在鍍層製品上。

## 首先，確認材質

在日本販售的部分貴金屬製品帶有**造幣局（造幣局）的純度霍爾馬克**，這是自願性的。你可能會看到的印記舉例：

| 印記 | 意義 |
|---|---|
| K18 / 750 | 含金 75.0% |
| K10 / 417 | 含金 41.7% |
| SV925 / 925 | 含銀 92.5%（925銀／純銀） |
| Pt900 / Pt950 | 白金 90.0% / 95.0% |
| GP / GF | 鍍金／包金（**底下是另一種金屬**） |

> **[待核實]** 請在造幣局「貴金屬製品的品位證明（霍爾馬克）」頁面確認純度分類與印記。

## 誤解1｜銀變黑是生鏽了

變黑是**硫化**（與空氣或汗水中的硫發生反應），而不是生鏽（氧化）。**這只是表面的變化，用銀飾擦拭布或專用洗銀液就能恢復。** 在溫泉（onsen）地區，這個過程會很快發生。

## 誤解2｜用牙膏擦拭沒問題

牙膏裡的研磨劑顆粒較粗：**會磨掉鍍層，也會刮傷珍珠、蛋白石、綠松石等較軟的寶石。** 即使是純銀（SV925），使用專用擦拭布也更穩妥。

## 誤解3｜黃金不會變色

純金（K24）幾乎不會變色，但**K18 與 K10 含有配合金屬（銀、銅），可能因汗水與化妝品而變色。** 配戴後用軟布擦拭是基本的習慣。

## 誤解4｜超音波清洗機什麼都能洗

超音波清洗**不適用於珍珠、祖母綠、蛋白石以及用膠黏合的寶石**。寶石可能鬆脫或裂開。只在鑽石、藍寶石等硬度高、且由爪鑲牢固固定的寶石上使用。

## 誤解5｜戴著首飾泡澡或泡溫泉沒關係

**溫泉水中的硫會讓銀迅速變黑，而氯（泳池、漂白劑）會傷害金合金與鍍層。** 在洗澡、游泳與做家事前把首飾取下，是在日本生活的人們普遍共有的習慣。
