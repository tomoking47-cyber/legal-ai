# Q. 關於衣櫃的濕氣，常見的誤解有哪些？｜Japan Questions #110

- Shelf: `fashion` ／ URL: `/zh-tw/fashion/closet-humidity` ／ Status: **草稿 — 出處未核實**

衣櫃裡的霉味與發霉，是所有潮濕地區共同的煩惱。在日本，夏季有些月份的平均濕度超過75%，一代代家庭因此累積了讓收納衣物保持乾燥的實用經驗。如果您來自較乾燥的氣候，藥妝店裡的那些產品（除濕盒、木條墊板）也許會讓您感到陌生。以下是這裡的人們使用它們的方法。

## A. 最大的誤解是「放個除濕盒問題就解決了」。除濕盒只能吸收有限空間內的水分；若不切斷濕氣的來源（沒乾透的衣物、外部空氣、地板），它是跟不上的。基礎是「乾透再收納」「留出間隙」「定期開門」。

## 關於濕度的數字

- 東京的月平均相對濕度，**6月、7月、9月在75%前後**，冬季則在**50%多**（氣象廳平年值）。
- 一般認為，黴菌在三個條件同時具備時容易繁殖：**濕度70%以上、溫度20〜30℃、養分（灰塵、皮脂）**。衣櫃很容易同時滿足這三點。
- 氯化鈣類除濕劑「除湿剤」（じょしつざい，除濕劑）會在標籤上標明**每個的吸濕量（例如400〜800mL左右）**與有效期限。

| 做法 | 理由 |
|---|---|
| 衣物完全乾透後再收納 | 避免把濕氣帶進去 |
| 衣物之間留一個手掌寬的間隙 | 讓空氣流動 |
| 每週一次打開櫃門通風（避開雨天） | 讓濕氣散出 |
| 除濕劑放低處，防蟲劑放高處 | 濕氣下沉；防蟲成分由上往下擴散 |
| 穿過的衣服不要馬上放回去，先掛一晚 | 讓汗濕蒸發 |

> **[待核實]** 請在氣象廳「過去的氣象資料檢索」中核對濕度平年值，並在東京都保健醫療局的資料中核對黴菌繁殖的條件。

## 誤解1｜除濕劑放得越多越有效

除濕劑**只在接近密閉的空間裡才有作用。** 若櫃門周圍縫隙很大，它就會不斷吸收室內空氣中的水分，很快就滿了。

## 誤解2｜電風扇或空氣循環扇沒有用

**光是讓空氣流動，就能減少落下附著的黴菌量。** 梅雨季節打開櫃門吹電風扇，是在日本生活的人們廣泛共享的做法。

## 誤解3｜木條墊板對地板的濕氣沒有用

直接放在地板上的收納箱下方會積聚濕氣。**用木條墊板「すのこ」（sunoko，木條墊板）把它們墊高幾公分，空氣就能從下面通過。** 這在租屋處也適用。

## 誤解4｜黴菌擦掉就好了

擦拭表面**會留下菌絲（根部）。** 衣物上的黴菌，請依照洗滌標籤清洗，並讓衣物曬到陽光。牆上的黴菌，**請使用消毒用乙醇「消毒用エタノール」（消毒用乙醇）或含氯除霉劑——兩者只能擇一，絕不可同時使用——並保持房間通風。** **切勿將含氯產品與酸性清潔劑混用。**

## 誤解5｜只有梅雨季節需要注意

**冬季的結露**同樣是濕氣來源。位於外牆一側的衣櫃，因為暖氣讓室內保持溫暖而牆體仍然冰冷，內側會產生結露。冬天也需要通風。
