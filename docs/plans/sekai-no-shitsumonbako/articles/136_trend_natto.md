# Q. 納豆の食べ方について、よくある誤解は？｜世界の質問箱 #136

- 棚：`trend` ／ URL：`/questions/natto` ／ ステータス：**ドラフト（法務レビュー前・出典未検証）**

納豆は海外で「日本で最も挑戦しにくい食べ物」として知られ、同時に「健康食」としても注目されています。食べ方・保存・表示について、日本の公的な情報を軸に整理します。

## A. 最大の誤解は「納豆は発酵食品だから期限を気にしなくてよい」です。納豆には賞味期限があり、冷蔵が前提です。期限を過ぎると発酵が進んで風味と匂いが強くなり、白い粒（チロシン）が増えますが、それ自体は腐敗ではありません。

## 判断の材料

| 項目 | 内容 |
|---|---|
| 保存 | **冷蔵（10℃以下）**。要冷蔵の表示あり |
| 賞味期限 | 製造から**1〜2週間程度**（製品による） |
| 冷凍 | 可。**自然解凍または冷蔵解凍**で食感がやや変わる |
| 表面の白い粒 | **チロシン**（アミノ酸の結晶）。無害 |
| 期限を過ぎたもの | 発酵が進み、**アンモニア臭・苦味**が強くなる。**判断に迷えば処分** |

- 納豆1パック（約40〜50g）は**たんぱく質約7〜8g、食物繊維約3g**を含みます（日本食品標準成分表 八訂）。
- **ワルファリン（抗凝固薬）を服用している人は、納豆を食べないでください。** 添付文書で摂取しないこととされています。納豆のビタミンKが薬の作用を弱めるだけでなく、**納豆菌が腸内でビタミンKを作り続ける**ため、量を減らす・時間をずらすといった方法も通用しません。クロレラ食品・青汁も同様です。**判断は必ず主治医・薬剤師に確認してください。**
- 納豆の表示は**食品表示法**に基づき、**原材料名に大豆の産地・遺伝子組換えの区分**が記載されます。

> 【要検証】栄養成分の数値は日本食品標準成分表（八訂）増補2023年で、遺伝子組換え表示の制度は消費者庁の「遺伝子組換え表示制度」（2023年4月改正）で確認してください。

## 誤解1｜混ぜる回数で栄養が変わる

混ぜる回数で**粘りと口当たり**は変わりますが、**栄養が増える根拠は確認されていません。** 好みの問題です。

## 誤解2｜熱いご飯にのせると栄養が壊れる

納豆菌の一部の酵素は熱に弱いとされますが、**ご飯の温度で全体の栄養価が大きく変わるという公的な根拠は確認できません。** 「食べ方は好みで」というのが実際のところです。

## 誤解3｜毎日たくさん食べれば健康になる

納豆は**大豆製品として食事のバランスの中で**位置づけるものです。**特定の疾病を予防する効果を表現することは、健康増進法・景表法上できません。** 1日1パック程度が一般的な目安として案内されています。

## 誤解4｜タレは全部入れるのが基本

タレ1袋の食塩相当量は**約0.5〜0.8g**です。減塩を意識する人は**半量にする、だしやしょうがで補う**という工夫をしています。

## 誤解5｜海外には持ち込めない

納豆は加工食品で、**多くの国で持ち込みは可能**ですが、国によって**肉エキス入りのタレ**が制限されることがあります。**渡航先の検疫ルールを確認**してください。
