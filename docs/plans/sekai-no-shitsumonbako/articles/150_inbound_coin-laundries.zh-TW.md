# Q. 關於日本的自助洗衣店，大家常有哪些誤解？｜Japan Questions #150

- Shelf: `inbound` ／ URL: `/zh-tw/questions/coin-laundries` ／ Status: **草稿 — 出處未核實**

只帶登機箱旅行兩週，全靠洗衣服。日本有密集的自助洗衣店網路，而且現代化的速度比多數旅客預想的快——但有幾條慣例會讓人跌一跤。

## A. 常見的誤解是，自助洗衣店是陰暗、只收現金、得守在旁邊等的地方。日本有大約27,000家自助洗衣店，很多24小時營業，支援App付款、有洗脫烘一體機，而且機器會自動投入洗劑。主要的陷阱是會把衣服烘縮的高溫烘衣機，以及預設使用冷水的洗衣機。

## 數字與使用方式

| 項目 | 數字 |
|---|---|
| 日本的自助洗衣店數量 | **約25,000–27,000家**，每年成長約5%（厚生勞動省調查） |
| 洗衣（最多約9 kg） | **¥300–600** |
| 烘乾（瓦斯烘衣機） | **每8–10分鐘 ¥100**；一整筒需要**30–40分鐘** |
| 洗脫烘一體機整套流程 | 一整筒 **¥800–1,400**（一般約 ¥1,200），約60分鐘 |
| 營業時間 | 很多**24小時**，無人看管 |

- **洗劑通常由機器自動投入**；您不需要自帶。請留意「洗剤自動投入」（洗劑自動投入）的標示。
- **洗衣水預設是冷水**；溫水洗的選項很少。洗劑本身是為冷水配方的。
- 烘衣機是**瓦斯式、溫度高**；羊毛和精細的合成纖維可能縮水。如有低溫設定請使用，或改為晾乾。
- 許多飯店設有**住客洗衣區**，有一兩台機器，往往比外面的洗衣店便宜。

> **[待核實]** 洗衣店數量請與厚生勞動省「コインオペレーションクリーニング営業施設」調查核對；價格為2025年觀察到的區間。

## 誤解1｜從家裡帶洗劑

大多數機器會自動添加，**再自己加會產生過多泡沫。** 倒任何東西之前，先看標示。

## 誤解2｜只收硬幣

較舊的店仍以硬幣為主，但連鎖店越來越多接受**IC卡（類似悠遊卡的交通卡）、QR Code付款和自家的App**（App還會通知您洗好了）。

## 誤解3｜烘衣機很溫和

日本自助洗衣店的烘衣機通常是**瓦斯烘衣機**，比家用電烘衣機更快、更熱。**羊毛、彈性纖維和印花T恤**會受損。請看洗標——參見關於看懂洗標的文章。

## 誤解4｜必須守在機器旁

無人店家預設您會**離開再回來**；如果需要用機器，把別人已洗好的衣物取出放到摺衣台上，一般被認為是可以接受的。洗完後請不要把衣物長時間留在機器裡。

## 誤解5｜鞋子放進洗衣機

許多洗衣店設有**專用的運動鞋洗衣機和烘衣機**（スニーカーランドリー）。用一般洗衣機洗鞋會惹人反感，店家也可能禁止。
