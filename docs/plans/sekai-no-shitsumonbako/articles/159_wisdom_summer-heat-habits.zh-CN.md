# Q. 关于日本的夏季防暑习惯，人们常有哪些误解？｜Japanese Everyday Wisdom #159

- Shelf: `wisdom` ／ URL: `/zh-cn/wisdom/summer-heat-habits` ／ Status: **草稿 — 出处未核实**

日本的夏天是 35°C 的高温加上 70–80% 的湿度，全国每年因中暑（熱中症）叫救护车的人数以数万计。日常的应对办法——从每间办公室都有的盐糖，到围在脖子上的湿毛巾——看起来像民间习俗。其实大多数都能直接对应到公共卫生指引。

## A. 常见的误解是认为日本的夏季习俗只是古趣。泼水（打ち水，uchimizu）、竹帘（簾，sudare）、脖子上的毛巾和手里的扇子，都是低成本的手段，针对的正是环境省防暑指引所针对的东西：辐射热、蒸发散热，以及让身体的散热机制正常运作。唯一值得放弃的习俗是"不开空调硬撑"。

## 习惯及其作用

| 习惯 | 机理 |
|---|---|
| **泼水（打ち水）**（傍晚在路面上洒水） | 让地面蒸发散热；在太阳离开地面后有效，正午无效 |
| **竹帘 / 苇帘（簾・葦簀，sudare / yoshizu）**（挂在窗外的帘子） | 在阳光到达玻璃 **之前** 就把它挡住——比室内的窗帘更有效 |
| **围脖毛巾、凉感毛巾** | 给靠近体表的血液降温；弄湿，再反复弄湿 |
| **盐糖、麦茶** | 补充随汗流失的钠和水分——麦茶不含咖啡因，是标准的夏季饮品 |
| **手扇（折扇 sensu / 团扇 uchiwa）** | 让空气流过出汗的皮肤；不用电池 |
| **浴衣、亚麻、宽松剪裁** | 通风与蒸发 |

## 误解1｜空调不健康，要忍着

**约 40% 的中暑转运来自家中**，且以老年人为多数。环境省表示要 **毫不犹豫地使用空调**，室温以 **28°C** 左右为目标，并要关照那些"不觉得热"的年长亲属。

## 误解2｜渴了再喝

口渴的感觉滞后于身体的需要，老年人尤其如此。指引：**定时喝水，一般情况下三餐之外每天约 1.2 L**，**大量出汗时补充盐分（0.1–0.2%）**。

## 误解3｜正午泼水能给街道降温

正午时水瞬间蒸发，湿度反而上升。家庭会 **在清晨和傍晚**、在有阴影的地面上泼水。

## 误解4｜窗帘能挡热

阳光一旦穿过玻璃，大部分热量就已经进了屋。**室外遮阳**——竹帘、遮阳篷、藤蔓植物做成的绿帘——正是老房子能熬过夏天的原因。

## 误解5｜婴儿车里的孩子在阴凉处

婴儿车座椅 **紧贴滚烫的路面**，往往比成年人头部高度的温度高出好几度，遮阳篷还会把热量困住。请使用 **透气的遮阳罩和湿毛巾，并摸一摸孩子的背部**。
