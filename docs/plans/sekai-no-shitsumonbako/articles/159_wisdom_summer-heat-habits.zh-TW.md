# Q. 關於日本的夏季消暑習慣，人們常有哪些誤解？｜Japanese Everyday Wisdom #159

- Shelf: `wisdom` ／ URL: `/zh-tw/wisdom/summer-heat-habits` ／ Status: **草稿 — 出處未核實**

日本的夏天是 35°C 的高溫加上 70–80% 的濕度，全國每年因中暑（熱中症）叫救護車的人數以數萬計。日常的應對方法——從每間辦公室都有的鹽糖，到圍在脖子上的濕毛巾——看起來像民間習俗。其實大多數都能直接對應到公共衛生指引。

## A. 常見的誤解是以為日本的夏季習俗只是古趣。灑水（打ち水，uchimizu）、竹簾（簾，sudare）、脖子上的毛巾和手裡的扇子，都是低成本的手段，針對的正是環境省防暑指引所針對的東西：輻射熱、蒸發散熱，以及讓身體的散熱機制正常運作。唯一值得放棄的習俗是「不開冷氣硬撐」。

## 習慣及其作用

| 習慣 | 機制 |
|---|---|
| **灑水（打ち水）**（傍晚在路面上灑水） | 讓地面蒸發散熱；在太陽離開地面後有效，正午無效 |
| **竹簾 / 葦簾（簾・葦簀，sudare / yoshizu）**（掛在窗外的簾子） | 在陽光到達玻璃 **之前** 就把它擋住——比室內的窗簾更有效 |
| **圍頸毛巾、涼感毛巾** | 給靠近體表的血液降溫；弄濕，再反覆弄濕 |
| **鹽糖、麥茶** | 補充隨汗流失的鈉和水分——麥茶不含咖啡因，是標準的夏季飲品 |
| **手扇（摺扇 sensu / 團扇 uchiwa）** | 讓空氣流過出汗的皮膚；不用電池 |
| **浴衣、亞麻、寬鬆剪裁** | 通風與蒸發 |

## 誤解1｜冷氣不健康，要忍著

**約 40% 的中暑送醫來自家中**，且以長者為多數。環境省表示要 **毫不猶豫地使用冷氣**，室溫以 **28°C** 左右為目標，並要關心那些「不覺得熱」的年長親人。

## 誤解2｜渴了再喝

口渴的感覺落後於身體的需要，長者尤其如此。指引：**定時喝水，一般情況下三餐之外每天約 1.2 L**，**大量出汗時補充鹽分（0.1–0.2%）**。

## 誤解3｜正午灑水能讓街道降溫

正午時水瞬間蒸發，濕度反而上升。家庭會 **在清晨和傍晚**、在有陰影的地面上灑水。

## 誤解4｜窗簾能擋熱

陽光一旦穿過玻璃，大部分熱量就已經進了屋。**室外遮陽**——竹簾、遮陽棚、藤蔓植物做成的綠簾——正是老房子能熬過夏天的原因。

## 誤解5｜嬰兒車裡的孩子在陰涼處

嬰兒車座椅 **緊貼滾燙的路面**，往往比成人頭部高度的溫度高出好幾度，遮陽罩還會把熱氣困住。請使用 **透氣的遮陽罩和濕毛巾，並摸一摸孩子的背部**。
