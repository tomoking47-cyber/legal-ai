# Q. 化粧筆・スポンジの洗い方について、よくある誤解は？｜世界の質問箱 #164

- 棚：`beauty` ／ URL：`/questions/cleaning-makeup-brushes` ／ ステータス：**ドラフト（法務レビュー前・出典未検証）**

メイク道具の衛生は、海外のコミュニティでは「どのくらいの頻度で洗うか」がよく問われ、日本では「どう洗えば傷まないか」が問われます。両方をまとめます。

## A. 最大の誤解は「道具は汚れて見えなければ洗わなくてよい」です。スポンジや筆には皮脂・ファンデ・皮膚の常在菌がたまり、肌荒れの原因になることがあります。目安は、リキッド用スポンジは使うたび〜数日、筆は週1回、完全に乾かしてから使うことです。

## 目安

| 道具 | 洗う頻度の目安 | 洗い方 | 乾かし方 |
|---|---|---|---|
| リキッド・クリーム用スポンジ | **毎回〜2、3回ごと** | 中性洗剤または専用洗浄剤で押し洗い | 風通しのよい場所で**完全に** |
| パウダー用ブラシ | **週1回程度** | ぬるま湯＋専用洗浄剤または薄めた中性洗剤。**根元を濡らさない** | 毛先を下に、寝かせて |
| リキッド用ブラシ | **数回ごと** | 同上。油分はクレンジング料で | 同上 |
| パフ（パウダー用） | **週1回** | 中性洗剤で押し洗い | 完全に乾かす |
| 買い替え | スポンジ：**1〜3か月**／筆：毛が抜ける・広がる・匂うとき | | |

- 湿ったスポンジを密閉ポーチに入れておくと**カビが生える**ことがあります。**乾いてから**しまいます。
- 使い捨てスポンジやコットンに切り替えるのも、日本の生活者の間で共有された衛生の工夫です。

> 【要検証】頻度・買い替え時期はメーカーの案内に基づく目安です。皮膚トラブルの事例は国民生活センターの相談事例で確認してください。

## 誤解1｜熱湯で消毒すればよい

熱湯は**接着剤を溶かし、天然毛を傷めます。** **ぬるま湯**が基本です。消毒したい場合は、**製品表示で可否を確認したうえで消毒用エタノール**を使う人がいますが、スポンジの劣化を早めます。

## 誤解2｜筆は根元までしっかり洗う

**根元（金具の部分）に水が入ると接着剤が緩み、毛が抜けます。** 毛先だけを洗浄液につけます。

## 誤解3｜ドライヤーで早く乾かす

熱で**毛がちりちりになり、スポンジは変形**します。**自然乾燥**で、扇風機の風程度にとどめます。

## 誤解4｜スポンジは洗えば何年でも使える

洗っても**弾力が落ち、細かい裂け目に汚れが残ります。** 1〜3か月が目安。**洗ってもにおいが残る・ぼろぼろ落ちる**なら替えます。

## 誤解5｜肌荒れの原因は化粧品だけ

**汚れた道具**が原因のことがあります。**化粧品を変えても改善しないとき、道具を洗う・替える**ことで変わる例が多く語られています。**症状が続くなら皮膚科**へ。
