# Q. ドライヤーの使い方について、よくある誤解は？｜世界の質問箱 #165

- 棚：`beauty` ／ URL：`/questions/using-a-hair-dryer` ／ ステータス：**ドラフト（法務レビュー前・出典未検証）**

「自然乾燥のほうが髪に優しい」という説は各国に根強くあります。日本では毎日入浴し夜に髪を洗う人が多く、寝る前に乾かす習慣とともに、ドライヤーの使い方の知恵が蓄積しています。

## A. 最大の誤解は「ドライヤーは髪を傷めるから自然乾燥がよい」です。濡れた髪は表面が開いて摩擦に弱く、濡れたまま寝ると枕との摩擦と頭皮の蒸れが問題になります。目安は、タオルでしっかり水気を取り、ドライヤーは15〜20cm離して動かしながら、根元から乾かし、最後に冷風です。

## 数字で見る

| 項目 | 目安 |
|---|---|
| 吹き出し口の温度 | 多くの製品で**100〜120℃前後**（近距離では髪の表面温度が急上昇） |
| 髪から離す距離 | **15〜20cm** |
| 髪の表面温度の目安 | **60〜70℃を超えない**ように動かし続ける（製品の説明書の考え方） |
| 順番 | **根元→中間→毛先**、最後に**冷風**で表面を整える |
| 時間短縮 | **タオルドライを丁寧に**（吸水性の高いタオルで押さえる）、**風量の大きい製品** |

- 電気用品安全法（PSE）の対象製品で、**吸込口のほこりの詰まり**は過熱・発火の原因になります。製品評価技術基盤機構（NITE）はドライヤーの**吸込口の清掃**と**コードのねじれ・断線**に注意喚起しています。
- 濡れた髪は**キューティクルが開き、こすれに弱い**とされます。濡れたまま寝ると、**摩擦による切れ毛・枕の湿気による頭皮環境の悪化**が指摘されています。

> 【要検証】温度・距離は主要メーカーの取扱説明書の目安です。事故事例はNITEの製品事故情報で確認してください。

## 誤解1｜自然乾燥が最も傷まない

**濡れた時間が長いほど、髪は摩擦に弱い状態が続きます。** 頭皮も蒸れます。**早く乾かす**ことのほうが髪と頭皮の負担を減らすとされています。

## 誤解2｜熱風で一気に乾かすのが効率的

同じ場所に熱風を当て続けると**表面温度が上がり、乾燥・ごわつき**につながります。**動かし続けて、髪全体に分散**させます。

## 誤解3｜毛先から乾かす

毛先は乾きやすく、**根元は最も乾きにくい**部分です。**根元から**乾かすと、毛先を乾かしすぎずに済みます。

## 誤解4｜冷風は意味がない

最後の冷風は**開いた表面を落ち着かせ、ツヤと持ち**に関わります。**熱がこもった頭皮を冷ます**意味もあります。

## 誤解5｜洗面所のコンセントに差したまま置いておけば便利

**水回りでの感電・コードの断線・吸込口のほこり**が事故の原因です。**使用後は抜き、コードは本体に巻きつけない**（根元の断線の原因）のがNITEの案内です。
