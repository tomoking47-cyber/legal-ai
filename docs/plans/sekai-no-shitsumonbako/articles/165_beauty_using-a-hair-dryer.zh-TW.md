# Q. 關於使用吹風機，人們常有哪些誤解？｜Japan Questions #165

- Shelf: `beauty` ／ URL: `/zh-tw/beauty/using-a-hair-dryer` ／ Status: **草稿 — 出處未核實**

「自然風乾對頭髮比較溫和」的觀念在許多國家根深蒂固。在日本，大多數人每天洗澡、晚上洗頭，因此睡前把頭髮吹乾是固定的習慣，圍繞吹風機也累積了大量實用的經驗。

## A. 最大的誤解是「吹風機會傷頭髮，所以自然風乾比較好」。濕髮的表面是張開的，很不耐摩擦；頂著濕髮入睡，等於讓頭髮在枕頭上摩擦，頭皮也一直悶著。參考做法是：用毛巾充分吸乾，吹風機距離 15～20 cm 並不斷移動，從髮根開始吹，最後以冷風收尾。

## 數字一覽

| 項目 | 參考 |
|---|---|
| 出風口的風溫 | 許多機型**約為 100～120℃**（距離近時，頭髮表面升溫非常快） |
| 與頭髮的距離 | **15～20 cm** |
| 頭髮表面溫度 | 讓吹風機保持移動，使其**不超過 60～70℃**（產品說明書採用的思路） |
| 順序 | **髮根 → 中段 → 髮尾**，最後用**冷風**撫平表面 |
| 縮短時間 | **仔細用毛巾吸乾**（用吸水性強的毛巾按壓）；**選擇風量大的機型** |

- 吹風機屬於《電氣用品安全法》（PSE 標章）的適用對象。**進風口被灰塵堵塞**可能引起過熱與起火。日本製品評價技術基盤機構（NITE）提醒大家**清潔進風口**，並注意**電線是否扭結或磨損。**
- 濕髮一般被描述為**毛鱗片張開、不耐摩擦。** 頂著濕髮睡覺，與**摩擦導致的斷髮**以及**枕頭潮濕造成的頭皮環境變差**有關。

> **[待核實]** 溫度與距離是主要廠商使用說明書中的參考值。事故案例請對照 NITE 的產品事故資料庫核對。

## 誤解1｜自然風乾傷害最小

**頭髮保持潮濕的時間越長，不耐摩擦的時間就越長。** 頭皮也一直是濕的。**盡快吹乾**一般被認為對頭髮與頭皮都比較友善。

## 誤解2｜用熱風猛吹最有效率

熱風對準一處不動，會**使表面溫度升高，導致乾燥與毛躁。** 請**不斷移動，讓熱量分散**到整個頭部。

## 誤解3｜從髮尾開始吹

髮尾容易乾；**最難吹乾的是髮根。** **從髮根開始**吹，可以避免髮尾被吹得過乾。

## 誤解4｜冷風功能沒有用

最後吹一陣冷風，**能撫平張開的表面，增加光澤與服貼度。** 還能**為積熱的頭皮降溫。**

## 誤解5｜插頭一直插在洗手台旁邊很方便

**靠近水的觸電、磨損的電線、進風口的灰塵**都是事故的原因。NITE 的建議是**用完拔掉插頭，不要把電線纏繞在機身上**（這是電線根部斷裂的原因）。
