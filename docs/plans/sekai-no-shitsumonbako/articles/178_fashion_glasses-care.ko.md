# Q. 안경 손질에 대해 사람들이 흔히 오해하는 것은?｜Japan Questions #178

- Shelf: `fashion` ／ URL: `/ko/fashion/glasses-care` ／ Status: **초안 — 출처 미확인**

셔츠로 렌즈를 닦는 습관은 세계 어디서나 볼 수 있고, 일본의 안경점이 가장 자주 지적하는 점이기도 합니다. 일본에는 큰 안경 산업이 있으며(후쿠이현 사바에시가 국내 안경테의 9할 이상을 생산합니다), 그 안에서 공유되는 손질의 기본을 정리합니다.

## A. 가장 큰 오해는 "렌즈는 부드러운 천이면 아무거나 괜찮다"입니다. 마른 채로 닦으면 렌즈에 앉은 먼지가 렌즈를 긁습니다. 기본은 "물로 헹군다 → 중성세제 → 헹군다 → 티슈로 물기를 눌러 뺀다 → 안경 닦이"입니다. 뜨거운 물과 알코올은 코팅을 손상시킵니다.

## 순서와 피해야 할 것

| 순서 | 방법 |
|---|---|
| 1 | **수돗물로 헹군다(따뜻한 물이 아니라 찬물)**. 먼지를 씻어 냅니다 |
| 2 | **중성세제(주방세제) 한 방울**을 손끝으로 부드럽게 문지릅니다 |
| 3 | 세제를 완전히 헹궈 냅니다 |
| 4 | **티슈로 물기를 눌러 뺍니다**(문지르지 않습니다) |
| 5 | 마무리는 **안경 닦이**로 |

| 피할 것 | 이유 |
|---|---|
| **뜨거운 물(40℃ / 104°F 이상)** | 코팅이 갈라집니다 |
| **알코올, 소독 물티슈, 아세톤** | 코팅을 손상시킬 수 있습니다 |
| **마른 채로 닦기** | 렌즈 위의 먼지가 렌즈를 긁습니다 |
| **비누, 알칼리성·산성 세정제** | 코팅과 테를 변색시킵니다 |
| 사우나, 차 안에 두기 | 열로 렌즈와 테가 변형됩니다 |

- 렌즈의 **코팅(반사 방지, 스크래치 방지)**은 여러 겹의 얇은 층이며, 공통된 약점은 **열과 화학물질**입니다.
- **코받침과 귀 뒤쪽 부품**에는 피지·땀·화장품이 쌓여 **녹청(구리의 녹색 부식)**과 변색의 원인이 됩니다. 안경점에서 정기적으로 교체하십시오(무료이거나 수백 엔인 경우가 많습니다).
- **일본 국내에서 만들어지는 안경테의 약 9할이 후쿠이현 사바에시**에서 생산됩니다(후쿠이현 통계).

> **[확인 필요]** 뜨거운 물의 온도 기준과 세제에 관한 안내는 렌즈 제조사 및 일본안경관련단체연합회(日本眼鏡関連団体連合会)의 자료와 대조해 주십시오. 사바에의 생산 비율은 후쿠이현이 공개한 자료와 대조해 주십시오.

## 오해 1｜안경 닦이로 마른 채 닦는 것이 올바른 방법이다

**안경 닦이는 마무리용입니다.** 먼지가 남은 상태로 닦으면 **흠집**이 생깁니다. **먼저 물로 헹구십시오.**

## 오해 2｜뜨거운 물이 피지를 더 잘 없앤다

**40℃ 이상의 뜨거운 물은 코팅을 갈라지게 합니다.** **반드시 찬물로.** 안경을 쓴 채 목욕하지 않는 것도 같은 이유입니다.

## 오해 3｜소독 물티슈로 닦으면 깨끗하게 유지된다

**알코올이 코팅을 손상시킬 수 있습니다.** **중성세제와 물**이면 충분합니다.

## 오해 4｜휘어진 테는 직접 편다

**플라스틱은 부러지고, 금속은 변형이 그대로 남습니다.** 안경점의 조정에 맡기십시오(무료인 경우가 많습니다).

## 오해 5｜렌즈는 흠집이 날 때까지 쓸 수 있다

**코팅의 열화와 미세한 흠집은 시야를 뿌옇게 하고 눈을 피로하게 합니다.** 안경점에서는 일반적으로 도수 재확인을 포함해 **2～3년마다 점검**할 것을 권합니다.
