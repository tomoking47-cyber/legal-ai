# Q. メガネの手入れについて、よくある誤解は？｜世界の質問箱 #178

- 棚：`fashion` ／ URL：`/questions/glasses-care` ／ ステータス：**ドラフト（法務レビュー前・出典未検証）**

メガネのレンズをシャツで拭く癖は世界共通で、日本の眼鏡店が最も注意する点でもあります。日本のメガネ産業（福井県鯖江市が国内フレームの9割超）で共有される手入れの基本を整理します。

## A. 最大の誤解は「レンズは柔らかい布なら何で拭いてもよい」です。乾いたまま拭くとほこりでレンズに傷がつきます。「まず水で流す→中性洗剤→水で流す→ティッシュで水気を取る→専用クロス」が基本で、お湯・アルコールはコーティングを傷めます。

## 手入れの手順と避けること

| 手順 | 内容 |
|---|---|
| 1 | **水道水（ぬるくない水）で流して**ほこりを落とす |
| 2 | **中性洗剤（食器用）**を1滴、指先で優しく |
| 3 | 水で洗剤を完全に流す |
| 4 | **ティッシュで水気を吸い取る**（こすらない） |
| 5 | **専用クロス**で仕上げ |

| 避けること | 理由 |
|---|---|
| **お湯（40℃以上）** | コーティングにひび（クラック）が入る |
| **アルコール・除菌シート・アセトン** | コーティングを傷めることがある |
| **乾拭き** | 付着したほこりで傷 |
| **石けん・アルカリ性・酸性洗剤** | コーティング・フレームの変色 |
| サウナ・車内放置 | 熱でレンズ・フレームが変形 |

- レンズの**コーティング（反射防止・傷防止）**は複数の薄い層で、**熱と薬品**に弱いのが共通の性質です。
- **鼻パッドと耳の部分**は皮脂・汗・化粧品がたまり、**緑青（銅の錆）**や変色の原因になります。定期的に眼鏡店で交換（多くは無料〜数百円）。
- 国内メガネフレームの**約9割が福井県鯖江市**で生産されています（福井県の統計）。

> 【要検証】お湯の温度の目安と洗剤の可否は、レンズメーカー・日本眼鏡関連団体連合会の案内で確認してください。鯖江の生産割合は福井県の公表資料で確認してください。

## 誤解1｜メガネ拭きで乾拭きするのが正しい

**専用クロスは仕上げ用**です。ほこりが付いた状態で拭くと**傷**になります。**水で流してから**。

## 誤解2｜お湯のほうが皮脂が落ちる

**40℃以上のお湯はコーティングにひびを入れます**（クラック）。**必ず水**で。お風呂にかけて入るのも同じ理由で避けます。

## 誤解3｜除菌シートで拭けば清潔

**アルコールがコーティングを傷める**ことがあります。**中性洗剤と水**で洗えば十分です。

## 誤解4｜曲がったフレームは自分で戻す

**プラスチックは折れ、金属は歪みが残ります。** 眼鏡店の調整（多くは無料）に任せます。

## 誤解5｜レンズは傷が入るまで使える

**コーティングの劣化・微細な傷は視界を曇らせ、目の疲れ**につながります。度数の見直しも含め、**2〜3年に一度の点検**が眼鏡店の一般的な案内です。
