# Q. 关于眼镜的保养，人们常有什么误解？｜Japan Questions #178

- Shelf: `fashion` ／ URL: `/zh-cn/fashion/glasses-care` ／ Status: **草稿 — 出处未核实**

用衬衫擦镜片是全世界通用的习惯，也是日本眼镜店最常提醒的一点。日本有着规模可观的眼镜产业（福井县鲭江市生产了全国90%以上的镜架），这里整理的是业内共享的保养基本功。

## A. 最大的误解是“擦镜片随便找块软布就行”。干擦时，附着在镜片上的灰尘会把镜片划伤。基本步骤是“用水冲 → 中性洗涤剂 → 冲净 → 用纸巾吸干 → 眼镜布”。热水和酒精会损伤镀膜。

## 步骤，以及要避免的做法

| 步骤 | 做法 |
|---|---|
| 1 | **用水龙头的水冲洗（凉水，不用温水）**，把灰尘冲掉 |
| 2 | **一滴中性洗涤剂（洗洁精）**，用指腹轻轻搓洗 |
| 3 | 把洗涤剂彻底冲净 |
| 4 | **用纸巾吸干水分**（不要来回擦） |
| 5 | 最后用**眼镜布**收尾 |

| 应避免 | 原因 |
|---|---|
| **热水（40℃／104°F以上）** | 镀膜会开裂 |
| **酒精、消毒湿巾、丙酮** | 可能损伤镀膜 |
| **干擦** | 镜片上的灰尘会划伤镜片 |
| **肥皂、碱性或酸性清洁剂** | 使镀膜和镜架变色 |
| 桑拿房、把眼镜留在车里 | 高温会让镜片和镜架变形 |

- 镜片的**镀膜（防反射、防划伤）**是好几层薄膜，它们共同的弱点是**高温与化学品**。
- **鼻托和耳后的部件**会积聚皮脂、汗水和化妆品，从而造成**铜绿（铜的绿色腐蚀物）**与变色。请定期到眼镜店更换（往往免费，或只需几百日元）。
- **日本国内生产的镜架约有90%来自福井县鲭江市**（福井县的统计）。

> **[待核实]** 热水的温度界限与洗涤剂的建议，请与镜片厂商及日本眼镜关联团体联合会（日本眼鏡関連団体連合会）核对。鲭江的生产占比请与福井县公开的资料核对。

## 误解1｜用眼镜布干擦才是正确做法

**眼镜布是用来收尾的。** 镜片上还有灰尘时去擦，会造成**划痕**。**请先用水冲。**

## 误解2｜热水更容易洗掉皮脂

**40℃以上的热水会让镀膜开裂。** **一律用凉水。** 戴着眼镜泡澡之所以要避免，也是同样的原因。

## 误解3｜用消毒湿巾能保持清洁

**其中的酒精可能损伤镀膜。** **中性洗涤剂加水**就足够了。

## 误解4｜镜架变形了自己掰回来

**塑料会折断，金属则会把变形固定下来。** 请交给眼镜店做调整（多为免费）。

## 误解5｜镜片可以一直用到划伤为止

**镀膜劣化和细微划痕会让视野发雾、让眼睛疲劳。** 眼镜店一般建议**每2～3年检查一次**，同时重新确认度数。
