# Q. 關於眼鏡的保養，人們常有什麼誤解？｜Japan Questions #178

- Shelf: `fashion` ／ URL: `/zh-tw/fashion/glasses-care` ／ Status: **草稿 — 出處未核實**

用襯衫擦鏡片是全世界共通的習慣，也是日本眼鏡行最常提醒的一點。日本有著規模可觀的眼鏡產業（福井縣鯖江市生產了全國90%以上的鏡框），這裡整理的是業界共享的保養基本功。

## A. 最大的誤解是「擦鏡片隨便找塊軟布就行」。乾擦時，附著在鏡片上的灰塵會把鏡片刮傷。基本步驟是「用水沖 → 中性洗劑 → 沖淨 → 用面紙吸乾 → 眼鏡布」。熱水與酒精會傷害鍍膜。

## 步驟，以及該避免的做法

| 步驟 | 做法 |
|---|---|
| 1 | **用水龍頭的水沖洗（冷水，不用溫水）**，把灰塵沖掉 |
| 2 | **一滴中性洗劑（洗碗精）**，用指腹輕輕搓洗 |
| 3 | 把洗劑徹底沖淨 |
| 4 | **用面紙吸乾水分**（不要來回擦） |
| 5 | 最後用**眼鏡布**收尾 |

| 應避免 | 原因 |
|---|---|
| **熱水與高溫**（鏡片從**60℃／140°F左右**起就有熱裂的風險） | 基材膨脹，鍍膜會龜裂 |
| **酒精、消毒濕紙巾、丙酮** | 可能傷害鍍膜 |
| **乾擦** | 鏡片上的灰塵會刮傷鏡片 |
| **肥皂、鹼性或酸性清潔劑** | 使鍍膜與鏡框變色 |
| 三溫暖、把眼鏡留在車內 | 高溫會讓鏡片與鏡框變形 |

- 鏡片的**鍍膜（抗反射、抗刮）**是好幾層薄膜，它們共同的弱點是**高溫與化學品**。
- **鼻墊與耳後的零件**會累積皮脂、汗水與化妝品，進而造成**銅綠（銅的綠色腐蝕物）**與變色。請定期到眼鏡行更換（通常免費，或只需幾百日圓）。
- **日本國內生產的鏡框約有95%來自福井縣**（以鯖江市、福井市為中心的產地）（福井縣的資料）。

> **[待核實]** 熱水的溫度界線與洗劑的建議，請與鏡片廠商及日本眼鏡關聯團體聯合會（日本眼鏡関連団体連合会）核對。鯖江的生產占比請與福井縣公開的資料核對。

## 誤解1｜用眼鏡布乾擦才是正確做法

**眼鏡布是用來收尾的。** 鏡片上還有灰塵時去擦，會造成**刮痕**。**請先用水沖。**

## 誤解2｜熱水比較容易洗掉皮脂

**高溫會讓鍍膜龜裂。** 一般以**60℃以上**為界，但視時間與環境，更低溫度下也可能發生。清洗時請用**冷水**。戴著眼鏡泡澡或進三溫暖之所以要避免，也是同樣的原因。

## 誤解3｜用消毒濕紙巾能保持乾淨

**其中的酒精可能傷害鍍膜。** **中性洗劑加水**就足夠了。

## 誤解4｜鏡框變形了自己扳回來

**塑膠會折斷，金屬則會把變形固定下來。** 請交給眼鏡行做調整（多半免費）。

## 誤解5｜鏡片可以一直用到刮傷為止

**鍍膜劣化與細微刮痕會讓視野發霧、讓眼睛疲勞。** 眼鏡行一般建議**每2～3年檢查一次**，同時重新確認度數。
