# Q. いびきについて、よくある誤解は？｜世界の質問箱 #182

- 棚：`health` ／ URL：`/questions/snoring` ／ ステータス：**ドラフト（法務レビュー前・出典未検証）**

いびきは「うるさい」だけの問題として扱われがちですが、日本では睡眠時無呼吸症候群（SAS）の潜在患者が数百万人と推計され、公的な情報も増えています。生活上の工夫と、医療機関に行くべき線を整理します。

## A. 最大の誤解は「いびきは体質で、健康とは関係ない」です。いびきの多くは気道が狭くなって起きる音で、「呼吸が止まる」「日中に強い眠気」「起床時の頭痛」が伴えば睡眠時無呼吸の可能性があり、医療機関の領域です。横向き寝・減量・寝る前の飲酒を避けることが生活側の基本です。

## 判断の材料

| 項目 | 内容 |
|---|---|
| いびきの仕組み | 睡眠中に**舌や軟口蓋が下がり、気道が狭くなる**ことで空気が振動して音が出る |
| 睡眠時無呼吸症候群（SAS） | 睡眠中に**10秒以上の呼吸停止が1時間に5回以上**。日本の潜在患者は**数百万人**と推計 |
| 受診の目安 | **呼吸が止まると言われる／日中の強い眠気／起床時の頭痛・口の渇き／夜間頻尿** |
| 検査 | **自宅でできる簡易検査**（保険適用）→必要なら入院検査 |
| 治療 | **CPAP（持続陽圧呼吸療法）**、マウスピース、生活改善など。**医師の判断** |

| 生活側の工夫 | 理由 |
|---|---|
| **横向きで寝る**（抱き枕・背中にクッション） | 仰向けは舌が落ち込みやすい |
| **寝る前の飲酒を避ける** | アルコールは筋肉を緩め、気道を狭くする |
| **体重管理** | 首まわりの脂肪が気道を狭くする |
| **鼻づまりの対処**（花粉・乾燥） | 口呼吸はいびきを強める |
| **枕の高さ**を見直す | 高すぎると気道が曲がる（枕の記事を参照） |

> 【要検証】SASの定義・推計患者数は厚生労働省 e-ヘルスネットおよび日本呼吸器学会の資料で確認してください。

## 誤解1｜いびきは熟睡している証拠

**気道が狭い状態で無理に呼吸している音**です。いびきが大きい人ほど**睡眠の質が低い**ことが多いとされます。

## 誤解2｜痩せていればいびきはかかない

日本人は**顎が小さく、気道が狭い骨格**の人が多く、**やせ型でもSASになる**ことが知られています。体重だけで判断できません。

## 誤解3｜いびき防止グッズで解決する

鼻腔拡張テープや口閉じテープは**軽いいびきの一部**に効くことがありますが、**無呼吸を伴う場合は医療の領域**です。グッズで隠すと発見が遅れます。

## 誤解4｜子どものいびきはかわいいだけ

子どものいびきは**アデノイドや扁桃の肥大**が原因のことがあり、**成長や集中力に影響**する場合があります。**続くなら小児科・耳鼻科**へ。

## 誤解5｜検査は入院が必要で大変

**自宅で一晩、指と鼻にセンサーをつける簡易検査**が保険適用で受けられます。**内科・耳鼻科・睡眠外来**で相談できます。
