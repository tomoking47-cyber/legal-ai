# Q. ラジオ体操について、よくある誤解は？｜世界の質問箱 #187

- 棚：`health` ／ URL：`/questions/radio-calisthenics` ／ ステータス：**ドラフト（法務レビュー前・出典未検証）**

ラジオ体操は日本で最も広く知られた運動で、夏休みの朝の風景として海外でも紹介されます。「子どもや高齢者向けの軽い体操」と見られがちですが、その設計と使い方には根拠があります。

## A. 最大の誤解は「軽すぎて運動にならない」です。ラジオ体操第一は約3分で13種類の動きを含み、全身の主要な関節を動かすよう設計されています。目的は筋力ではなく、日常の可動域の維持と生活のリズム作りにあり、毎日続けることで身体活動の目安の一部を満たします。

## 数字で見る

| 項目 | 内容 |
|---|---|
| 開始 | **1928年（昭和3年）**、逓信省簡易保険局が制定、NHKラジオで放送開始 |
| 現在の形 | **第一（1951年）**：13種類の運動、**約3分13秒**／**第二（1952年）**：13種類、約3分 |
| 放送 | **NHK AM**（2026年3月にラジオ第2が廃止され、AM波は1波に再編）で**毎朝6時30分**、テレビでも放送 |
| 運動強度 | **第一4.0メッツ／第二4.5メッツ**（速歩に相当） |
| 実施している人 | 各種調査で**成人の2〜3割が「時々〜毎日行う」** |

- 厚生労働省「身体活動・運動ガイド2023」は、成人に**1日60分以上の身体活動（3メッツ以上）**を勧めており、ラジオ体操第一・第二を続けて行えば**約6分、その一部**になります。
- **高齢者施設や職場の朝礼**で採用されているのは、**器具不要・省スペース・全身の関節を順に動かす**設計のためです。

> 【要検証】制定年・時間は、かんぽ生命「ラジオ体操の歴史」およびNHKの公表資料で確認してください。メッツ値は国立健康・栄養研究所「身体活動のメッツ表」に基づきます。

## 誤解1｜子どもと高齢者向けの体操

第一は**年齢を問わず行いやすいことを目指した**設計、第二は**やや強度が高く、働く世代向け**に作られています。**正しい動きで行うと、翌日に筋肉痛が出る**人も多いです。**持病や関節の痛みがある場合は、できない動きもあります。無理のない範囲で行い、不安があれば医師に相談してください。**

## 誤解2｜適当に動かしても同じ

**13の動きにはそれぞれ狙う関節・筋肉があります。** 腕を伸ばしきる・かかとを上げる・上体をひねる、など**動きを大きく**すると強度が変わります。

## 誤解3｜毎朝6時半にやらないと意味がない

**時間帯は自由**です。NHKの動画やアプリでいつでもできます。**仕事の合間の座りすぎ解消**に第一だけ行う人も多いです。

## 誤解4｜運動不足の解消にはこれだけで十分

ラジオ体操は**身体活動の目安の一部**です。ガイド2023は**歩行などの有酸素運動と、週2〜3回の筋力トレーニング**も勧めています。

## 誤解5｜昔の体操だから古い

第一の制定から70年以上、**動きは大きく変えられていません**が、**器具なしで全身の関節を約3分で動かす**という設計は、現在の柔軟性・可動域の考え方とも整合しています。
