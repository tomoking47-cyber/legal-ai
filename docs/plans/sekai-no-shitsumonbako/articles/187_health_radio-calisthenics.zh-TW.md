# Q. 關於「ラジオ体操」(rajio taisō，廣播體操)，人們常有哪些誤解？｜Japan Questions #187

- Shelf: `health` ／ URL: `/zh-tw/health/radio-calisthenics` ／ Status: **草稿 — 出處未核實**

「ラジオ体操」(rajio taisō，廣播體操) 是日本最廣為人知的運動，孩子們在暑假早晨做體操的畫面也常被介紹到海外。它容易被看成「給小孩和高齡者做的輕度體操」，但它的設計和用法都是有根據的。

## A. 最大的誤解是「太輕了，算不上運動」。廣播體操第一套約3分鐘，包含13種動作，設計上要活動全身的主要關節。它的目的不是練肌力，而是維持日常的活動範圍、替一天定下節奏；每天持續做，就能滿足建議身體活動量的一部分。

## 用數字來看

| 項目 | 內容 |
|---|---|
| 開始 | **1928年**，由遞信省簡易保險局制定，在NHK廣播開始播出 |
| 現在的形式 | **第一套（1951年）**：13種運動，**約3分13秒**／**第二套（1952年）**：13種，約3分鐘 |
| 播出 | NHK廣播第1頻道，**每天早上6點30分**；電視也有播出 |
| 運動強度 | **約3〜4梅脫（METs）**（相當於普通步行〜快走） |
| 做的人 | 各類調查顯示**成人中有20〜30%「偶爾做〜每天做」** |

- 厚生勞動省（厚生労働省）的**《身體活動・運動指引2023》**[身体活動・運動ガイド2023] 建議成人**每天進行60分鐘以上的身體活動（3梅脫以上）**；第一套和第二套連著做**約6分鐘，可以算作其中的一部分**。
- **高齡者照護機構和職場的朝會**之所以採用它，是因為它**不需要器材、不佔空間、能依序帶動全身的主要關節**。

> **[待核實]** 制定年份與時長請以簡保生命（かんぽ生命）「廣播體操的歷史」[ラジオ体操の歴史] 和NHK的公開資料核對。梅脫數值依據國立健康・營養研究所「身體活動的梅脫（METs）表」。

## 誤解1｜這是給小孩和高齡者做的體操

第一套的設計**以不分年齡、都容易做為目標**；第二套**強度稍高，是為在職世代做的**。**用正確的動作做下來，不少人隔天會肌肉痠痛。** **若有慢性疾病或關節疼痛，也會有做不了的動作。請在不勉強的範圍內進行，有疑慮時請諮詢醫師。**

## 誤解2｜隨便揮揮手臂都一樣

**這13個動作各有其針對的關節與肌肉。** 手臂完全伸直、抬起腳跟、扭轉上半身——**把動作做大**，強度就會改變。

## 誤解3｜不是每天早上6點半做就沒有意義

**什麼時段都可以。** 用NHK的影片和App隨時都能做。也有很多人只做第一套，**用來打斷上班日長時間的久坐**。

## 誤解4｜光靠它就能補足運動不足

廣播體操是**建議身體活動量的一部分**。《指引2023》同時還建議**走路等有氧運動，以及每週2〜3次的肌力訓練**。

## 誤解5｜是老早以前的體操，已經過時了

第一套定型至今70多年，**動作幾乎沒有改變**。但它的設計——**不用器材、約3分鐘帶動全身主要關節**——與現在關於柔軟度和活動範圍的想法是一致的。
