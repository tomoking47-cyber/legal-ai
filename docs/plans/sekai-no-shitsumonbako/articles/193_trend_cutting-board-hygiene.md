# Q. まな板の手入れについて、よくある誤解は？｜世界の質問箱 #193

- 棚：`trend` ／ URL：`/questions/cutting-board-hygiene` ／ ステータス：**ドラフト（法務レビュー前・出典未検証）**

まな板は台所で最も菌が残りやすい道具の一つで、「木がよいか、プラスチックがよいか」は各国で終わらない議論です。日本では厚生労働省の家庭での食中毒予防の考え方が、その答えの土台になります。

## A. 最大の誤解は「見た目がきれいなら清潔」です。まな板の傷には菌が残り、とくに生の肉・魚を切った後は洗剤で洗うだけでは不十分な場合があります。基本は「肉・魚用と野菜用を分ける（または順番を守る）」「使ったらすぐ洗う」「生の肉・魚を切った後は熱湯や塩素系漂白剤で消毒する」「完全に乾かす」です。

## 判断の材料

| 項目 | 内容 | 根拠 |
|---|---|---|
| 使い分け | **生の肉・魚用と、野菜・調理済み食品用を分ける**。1枚なら**野菜→肉・魚**の順に切る | 厚労省「家庭でできる食中毒予防の6つのポイント」（つけない） |
| 洗う | **使用後すぐ**、洗剤とスポンジで。**肉・魚の後は熱湯**をかける | 同上 |
| 消毒 | **生の肉・魚を切った後は、洗ってから熱湯**。**塩素系漂白剤は製品表示の濃度・時間で→十分にすすぐ** | 厚労省「6つのポイント」（やっつける）／漂白剤の製品表示 |
| 乾燥 | **立てて、風通しのよい場所で完全に** | 湿ったままは菌とカビ |
| 木のまな板 | **熱湯はOK、漂白剤は木を傷める製品あり**。洗ったら**すぐ拭いて立てる**。**反り・黒ずみ**が出たら削り直し | — |
| 買い替え | **深い傷・黒ずみ・反り**が目安 | — |

- 令和7年（2025年）の食中毒統計では、事件数の上位は**ノロウイルス（462件）、アニサキス（280件・魚）、カンピロバクター（220件・鶏肉）**です。**生の鶏肉を切ったまな板で野菜を切る**ことは、家庭での典型的な原因の一つです。
- **肉・魚は最後に切る**、または**牛乳パックを開いて使い捨てのまな板にする**のが、日本の生活者の間で広く共有された工夫です。

> 【要検証】6つのポイントの記載と、食中毒統計の原因物質順位を厚生労働省で確認してください。

## 誤解1｜木のまな板は不衛生

木には**傷の中の菌が乾燥とともに減る**という研究もあり、**プラスチックとの優劣は「手入れ次第」**とされています。**乾かせるかどうか**が要点です。

## 誤解2｜プラスチックなら漂白剤で完全に消毒できる

**傷の奥は漂白剤が届きにくく**、傷だらけのまな板は消毒しても菌が残ることがあります。**傷が目立ったら買い替え**が現実的です。

## 誤解3｜熱湯をかければ肉の後の汚れも落ちる

**たんぱく質は熱で固まり、こびりつきます。** **まず洗剤で洗ってから熱湯**、が順番です。

## 誤解4｜両面を使い分ければ1枚でよい

**側面と縫い目からの汚れの回り込み**があり、洗うときも混ざります。**色違いの2枚**か、**薄いまな板シートを肉・魚用に**が実践的です。

## 誤解5｜食洗機に入れれば消毒される

**木のまな板は反り・割れの原因**、プラスチックも**耐熱温度**を確認。食洗機対応の表示があれば、高温洗浄は有効です。
