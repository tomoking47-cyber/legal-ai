# Q. 关于土锅（「土鍋」）的保养，人们常有什么误解？｜Japan Questions #194

- Shelf: `trend` ／ URL: `/zh-cn/trend/donabe-care` ／ Status: **草稿 — 出处未核实**

土锅（「土鍋」，*donabe*，陶土砂锅）在火锅（「鍋」，*nabe*）季节最能发挥本领，如今在国外也直接以日语名字为人所知。这里我们从陶器本身的性质出发，回答“第一次用之前要做什么？”和“为什么会裂？”。

## A. 最大的误解是“土锅买回来就能直接用”。陶土的坯体布满细小的孔。第一次使用前如果不做「目止め」（*medome*，封孔处理）——用淘米水或米粥在锅里慢慢煮一次——锅就可能渗水、吸味，甚至开裂。使用时的基本原则是：锅底湿着不上火、不空烧、不骤冷。

## 可以依据的要点

| 情况 | 怎么做 | 为什么 |
|---|---|---|
| 第一次使用 | **目止め**：加水到八分满（约80%），放入**淘米水或剩饭**，小火煮成粥状，放凉后清洗 | 淀粉会填住坯体的孔 |
| 加热前 | **把锅底擦干** | 锅底湿着快速加热会导致开裂 |
| 加热 | **从小火开始**；**绝对不要空烧** | 温度骤变、过热 |
| 清洗 | **等它凉了之后**，用少量洗洁精，**不要浸泡** | 热锅遇水会裂；长时间浸泡会让水渗进去 |
| 晾干 | **锅底朝上，完全晾干** | 锅底是裸露的陶土，潮湿会发霉 |
| 收纳 | 干燥后再收。**锅与锅之间垫上报纸** | 湿气 |

- 大多数土锅**不能用于电磁炉（IH）**（只有**标明IH对应**的才可以）；**能否微波、能否进烤箱**也请确认产品标示。
- **裂纹**有时可以通过目止め暂时止住，但**如果一直渗水，就停止使用**——这是稳妥的一边。
- NITE（独立行政法人 制品评价技术基盘机构，日本的产品安全机构）曾报告过**土锅空烧或破裂导致的事故**。

> **[待核实]** 目止め的做法是根据各陶器产地与制造商的说明整理的一般步骤。事故案例请在NITE的产品事故信息中核实。

## 误解1｜目止め只需要做一次

**效果会随着使用而减弱。** 当渗水或气味开始让您在意时，就再做一次。

## 误解2｜气味一旦渗进去，就只能换新锅了

在日本生活的人们分享的做法包括**用茶叶或稀释的醋煮一次**，以减轻气味。**之后再做一次目止め**，通常就能解决。

## 误解3｜趁热把锅泡进水里，洗起来更快

**骤冷是开裂最主要的原因。** 请**等锅凉了之后**再洗。

## 误解4｜土锅放在什么燃气炉上都没问题

**在便携式卡式炉（「カセットこんろ」，*kasetto konro*）上放大号土锅，可能使气罐过热，很危险。** 请确认**炉具说明书上的尺寸上限**（消费者厅与NITE都发布过提醒）。

## 误解5｜土锅那么容易裂，还不如买带塑料手柄的金属锅划算

土锅在烹调上有它的长处——**受热柔和均匀、保温性高**——而且**只要好好保养，可以用上10年以上。** 开裂的原因大多来自三件可以避免的事：**骤冷、空烧、锅底带水**。
