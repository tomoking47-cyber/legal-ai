# Q. 關於土鍋（「土鍋」）的保養，人們常有什麼誤解？｜Japan Questions #194

- Shelf: `trend` ／ URL: `/zh-tw/trend/donabe-care` ／ Status: **草稿 — 出處未核實**

土鍋（「土鍋」，*donabe*，陶土砂鍋）在火鍋（「鍋」，*nabe*）季節最能發揮本領，如今在國外也直接以日文名字為人所知。這裡我們從陶器本身的性質出發，回答「第一次用之前要做什麼？」與「為什麼會裂？」。

## A. 最大的誤解是「土鍋買回來就能直接用」。陶土的胎體布滿細小的孔。第一次使用前如果不做「目止め」（*medome*，封孔處理）——用洗米水或米粥在鍋裡慢慢煮一次——鍋就可能滲水、吸味，甚至龜裂。使用時的基本原則是：鍋底濕著不上爐、不空燒、不驟冷。

## 可以依據的重點

| 情況 | 怎麼做 | 為什麼 |
|---|---|---|
| 第一次使用 | **目止め**：加水到八分滿，放入**洗米水或剩飯**，小火煮成粥狀，放涼後清洗 | 澱粉會填住胎體的孔 |
| 加熱前 | **把鍋底擦乾** | 鍋底濕著快速加熱會導致龜裂 |
| 加熱 | **從小火開始**；**絕對不要空燒** | 溫度驟變、過熱 |
| 清洗 | **等它涼了之後**，用少量洗碗精，**不要浸泡** | 熱鍋遇水會裂；長時間浸泡會讓水滲進去 |
| 晾乾 | **鍋底朝上，完全晾乾** | 鍋底是裸露的陶土，潮濕會發黴 |
| 收納 | 乾燥後再收。**鍋與鍋之間墊上報紙** | 濕氣 |

- 大多數土鍋**不能用於電磁爐（IH）**（只有**標明IH對應**的才可以）；**能否微波、能否進烤箱**也請確認產品標示。
- **裂痕**有時可以透過目止め暫時止住，但**如果一直滲水，就停止使用**——這是穩妥的一邊。
- NITE（獨立行政法人 產品評價技術基盤機構，日本的產品安全機構）曾通報過**土鍋空燒或破裂造成的事故**。

> **[待核實]** 目止め的做法是根據各陶器產地與製造商的說明整理的一般步驟。事故案例請在NITE的產品事故資訊中核實。

## 誤解1｜目止め只需要做一次

**效果會隨著使用而減弱。** 當滲水或氣味開始讓您在意時，就再做一次。

## 誤解2｜氣味一旦滲進去，就只能換新鍋了

在日本生活的人們分享的做法包括**用茶葉或稀釋的醋煮一次**，以減輕氣味。**之後再做一次目止め**，通常就能解決。

## 誤解3｜趁熱把鍋泡進水裡，洗起來更快

**驟冷是龜裂最主要的原因。** 請**等鍋涼了之後**再洗。

## 誤解4｜土鍋放在什麼瓦斯爐上都沒問題

**在卡式瓦斯爐（「カセットこんろ」，*kasetto konro*）上放大號土鍋，可能使瓦斯罐過熱，相當危險。** 請確認**爐具說明書上的尺寸上限**（消費者廳與NITE都發布過提醒）。

## 誤解5｜土鍋那麼容易裂，還不如買附塑膠握把的金屬鍋划算

土鍋在烹調上有它的長處——**受熱柔和均勻、保溫性高**——而且**只要好好保養，可以用上十年以上。** 龜裂的原因大多來自三件可以避免的事：**驟冷、空燒、鍋底帶水**。
