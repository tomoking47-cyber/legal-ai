# Q. 关于铁制平底锅的保养，人们常有什么误解？｜Japan Questions #195

- Shelf: `trend` ／ URL: `/zh-cn/trend/cast-iron-pan-care` ／ Status: **草稿 — 出处未核实**

铁制平底锅正在全世界重新流行，但很多人因为“会生锈”“什么都粘锅”而放弃。在日本，有两套已经确立的做法——「油ならし」（*abura-narashi*，开锅养油膜）和「油返し」（*abura-gaeshi*，每次下锅前的润油）。知道了这两件事，一口锅就能用上很多年。

## A. 最大的误解是“铁锅绝对不能用洗洁精洗”。最初开锅所养出的油膜，并不会因为用洗洁精轻轻一洗就大量脱落。要点是：下锅前先把锅烧热、让油在锅面转一圈（油返し）；用完立刻清洗，再放回火上把水分烤干，然后薄薄地抹上一层油。

## 一套流程

| 情况 | 怎么做 |
|---|---|
| 第一次使用（「油ならし」，开锅） | 洗净擦干 → **用中火空烧，把防锈涂层烧掉**（视产品而定）→ 倒入较多的油，**小火加热5分钟** → 把油倒出，擦拭。**再炒一次蔬菜的边角料**可以减轻铁腥味 |
| 每次下锅前（「油返し」） | **用中火加热，倒入较多的油，让油在整个锅面转一圈** → 把多余的油倒回油壶 → 开始烹调 |
| 烹调之后 | **趁热用热水和棕刷（「たわし」，*tawashi*）刷洗**（用一点洗洁精也没关系）→ **放回火上，把水分彻底烤干** → **薄薄地抹上一层油** |
| 生锈了 | **用钢丝球或去污粉刷掉** → 重新开锅养油膜 |
| 粘锅烧焦了 | **加满热水煮开，等焦垢泡软后刮掉** |

- 铁锅**能稳定维持较高的锅面温度，所以适合煎与爆炒**。但**长时间炖煮强酸性的菜（番茄、醋）**会溶出铁，既影响风味也影响锅面。
- 有人期待**额外补充膳食铁**，但**烹调中溶出的铁量因菜式与时间差异极大，不能当作可靠的营养来源。**

> **[待核实]** 上述流程是根据主要制造商使用说明书整理的一般做法，会因产品而异（有无防锈涂层、是否经过氮化处理等）。

## 误解1｜洗洁精会把油膜整个洗掉

**烤进去的油膜（聚合后的油）并不会因为洗洁精就大量脱落。** 如果不放心，**只用热水和棕刷**也已经足够。**用洗洁精洗过之后再抹一次油**，就没有问题。

## 误解2｜粘锅是因为锅是铁的

主要原因是**热得不够**。**先把锅充分烧热，再让油转一圈（油返し）**，粘锅就会大大减少。**冷的食材下冷锅**是最容易粘的。

## 误解3｜一旦生锈，这口锅就完了

**锈是可以去掉的。** 用钢丝球刷掉，重新开锅养油膜，锅就能恢复。除非**锈已经把锅面蚀出洞来**，否则都还能用。

## 误解4｜洗完不用擦干，抹油就能防锈

**在残留的水上抹油，等于让锈在油膜底下生成。** 顺序是**先放回火上，把水分彻底烤干**。

## 误解5｜铁锅太重，用起来不方便

**约1.6mm薄板的锅**，重量比同尺寸的氟树脂涂层铝锅重不了多少。**厚的（2.3mm以上）**蓄热更好，适合煎牛排和煎饺——这是在日本生活的人们分享的挑选方式。
