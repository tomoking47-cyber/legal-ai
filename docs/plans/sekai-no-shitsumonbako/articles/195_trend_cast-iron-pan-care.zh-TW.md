# Q. 關於鐵製平底鍋的保養，人們常有什麼誤解？｜Japan Questions #195

- Shelf: `trend` ／ URL: `/zh-tw/trend/cast-iron-pan-care` ／ Status: **草稿 — 出處未核實**

鐵製平底鍋正在全世界重新流行，但很多人因為「會生鏽」「什麼都黏鍋」而放棄。在日本，有兩套已經確立的做法——「油ならし」（*abura-narashi*，開鍋養油膜）與「油返し」（*abura-gaeshi*，每次下鍋前的潤油）。知道了這兩件事，一只鍋就能用上很多年。

## A. 最大的誤解是「鐵鍋絕對不能用洗碗精洗」。最初開鍋養出的油膜，並不會因為用洗碗精輕輕一洗就大量脫落。要點是：下鍋前先把鍋燒熱、讓油在鍋面轉一圈（油返し）；用完立刻清洗，再放回爐上把水分烘乾，然後薄薄地抹上一層油。

## 一套流程

| 情況 | 怎麼做 |
|---|---|
| 第一次使用（「油ならし」，開鍋） | 洗淨擦乾 → **用中火空燒，把防鏽塗層燒掉**（視產品而定）→ 倒入較多的油，**小火加熱5分鐘** → 把油倒出，擦拭。**再炒一次蔬菜的邊角料**可以減輕鐵腥味 |
| 每次下鍋前（「油返し」） | **用中火加熱，倒入較多的油，讓油在整個鍋面轉一圈** → 把多餘的油倒回油壺 → 開始烹調 |
| 烹調之後 | **趁熱用熱水和棕刷（「たわし」，*tawashi*）刷洗**（用一點洗碗精也沒關係）→ **放回爐上，把水分徹底烘乾** → **薄薄地抹上一層油** |
| 生鏽了 | **用鋼絲球或去污粉刷掉** → 重新開鍋養油膜 |
| 黏鍋燒焦了 | **加滿熱水煮開，等焦垢泡軟後刮掉** |

- 鐵鍋**能穩定維持較高的鍋面溫度，所以適合煎與大火快炒**。但**長時間燉煮強酸性的菜（番茄、醋）**會溶出鐵，既影響風味也影響鍋面。
- 有人期待**額外補充膳食鐵**，但**烹調中溶出的鐵量因菜色與時間差異極大，不能當作可靠的營養來源。**

> **[待核實]** 上述流程是根據主要製造商使用說明書整理的一般做法，會因產品而異（有無防鏽塗層、是否經過氮化處理等）。

## 誤解1｜洗碗精會把油膜整個洗掉

**烘進去的油膜（聚合後的油）並不會因為洗碗精就大量脫落。** 如果不放心，**只用熱水和棕刷**也已經足夠。**用洗碗精洗過之後再抹一次油**，就沒有問題。

## 誤解2｜黏鍋是因為鍋是鐵的

主要原因是**熱得不夠**。**先把鍋充分燒熱，再讓油轉一圈（油返し）**，黏鍋就會大幅減少。**冷的食材下冷鍋**是最容易黏的。

## 誤解3｜一旦生鏽，這只鍋就完了

**鏽是可以去掉的。** 用鋼絲球刷掉，重新開鍋養油膜，鍋就能恢復。除非**鏽已經把鍋面蝕出洞來**，否則都還能用。

## 誤解4｜洗完不用擦乾，抹油就能防鏽

**在殘留的水上抹油，等於讓鏽在油膜底下生成。** 順序是**先放回爐上，把水分徹底烘乾**。

## 誤解5｜鐵鍋太重，用起來不方便

**約1.6mm薄板的鍋**，重量比同尺寸的氟樹脂塗層鋁鍋重不了多少。**厚的（2.3mm以上）**蓄熱更好，適合煎牛排和煎餃——這是在日本生活的人們分享的挑選方式。
