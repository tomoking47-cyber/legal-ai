# Q. 關於水果的保存，人們常有哪些誤解？｜Japan Questions #197

- Shelf: `trend` ／ URL: `/zh-tw/trend/storing-fruit` ／ Status: **草稿 — 出處未核實**

「香蕉可以放冰箱嗎？」「蘋果會不會讓旁邊的水果壞掉？」——這是全世界都在問的問題。水果分成**採收後還會繼續成熟**的種類與不會的種類，這個差別決定了保存方式。

## A. 最大的誤解是「所有水果放冰箱都能放得更久」。香蕉、酪梨、奇異果、桃子、梨子屬於「更年性」（採後後熟型），在成熟之前冷藏會中止後熟，或造成傷害。蘋果釋放的乙烯會加速成熟，所以要讓蘋果遠離其他水果，或者反過來，刻意把它和想催熟的水果放在一起。

## 採後會後熟的水果與不會後熟的水果

| 採後會後熟（先常溫放熟，再冷藏） | 採後不後熟（買回來就冷藏） |
|---|---|
| 香蕉、酪梨、奇異果、桃子、梨子、芒果、洋香瓜、柿子（部分品種） | 草莓、葡萄、櫻桃、柑橘類、蘋果（已經成熟）、鳳梨、西瓜（切開前常溫即可） |

| 水果 | 保存參考 | 備註 |
|---|---|---|
| 香蕉 | **常溫**；熟了以後可以冷藏（皮會變黑，裡面仍可食用） | 13℃（55°F）以下會出現低溫障礙 |
| 蘋果 | **冷藏**（裝進塑膠袋） | **釋放大量乙烯。** 與其他水果分開放 |
| 草莓 | **冷藏，2〜3 天。** 要吃之前再洗 | 容易壞 |
| 柑橘類 | 陰涼的常溫至冷藏 | 防止乾燥失水 |
| 酪梨 | 常溫後熟 → 冷藏 | 切開後可用檸檬汁減緩褐變 |

- **乙烯**是水果釋放的植物荷爾蒙；**蘋果、香蕉、洋香瓜、桃子**釋放得多。**要讓它遠離不希望過熟的水果；想讓酪梨、奇異果快點熟，就把它們和一顆蘋果一起裝進袋子裡**——這是農林水產省（農林水産省）等單位介紹的做法。
- **低溫障礙**：香蕉、鳳梨、芒果等熱帶水果**在 10〜13℃（50〜55°F）以下可能變黑**。

> **[待核實]** 請對照農林水產省與農研機構（農研機構，NARO）的資料核對後熟分類與乙烯的說明，並依各資料核對溫度數值。

## 誤解1｜香蕉放冰箱會爛

**皮變黑**是低溫障礙，**果肉仍維持原本的成熟狀態。** 熟了以後再冷藏，香蕉比常溫**多放幾天**。

## 誤解2｜蘋果會讓其他水果爛掉

蘋果的乙烯是**加速成熟**，所以要讓蘋果遠離**不能過熟的水果**（草莓、葡萄）。**把它和想快點催熟的酪梨或奇異果放在一起**，它就成了幫手。

## 誤解3｜水果要洗過再保存

**清洗會洗掉表面的保護層，水分還會讓水果壞得更快。** 草莓與葡萄尤其應該**要吃之前再洗**。

## 誤解4｜切開的水果在常溫下放幾個小時沒關係

**切面上細菌容易繁殖。** 依照厚生勞動省（厚生労働省）的食物中毒預防思路，**水果切開後要馬上冷藏，不要長時間放在常溫下**。**切開的水果請當天吃完。**

## 誤解5｜冷凍會破壞營養

**冷凍不會大幅減少維生素 C 等營養成分；就長期保存而言，一般認為冷凍比冷藏更能保住營養。** 香蕉、莓果、芒果常被冷凍用來做冰沙等，這同時也能**減少食物浪費**。
