# Q. 일본 메뉴판 읽기에 대해 사람들이 흔히 오해하는 것은?｜Japan Questions #208

- Shelf: `inbound` ／ URL: `/ko/questions/reading-a-menu` ／ Status: **초안 — 출처 미확인**

메뉴판은 대부분의 방문객이 가장 막막해지는 순간이자, 일본이 가장 친절해지는 순간입니다. 사진 메뉴, 음식 모형, 식권 자판기, 정식 메뉴의 관례는 모두 여러분을 돕기 위해 있습니다. 작동 방식만 알면 됩니다.

## A. 흔한 오해는 주문하려면 일본어가 필요하다는 것입니다. 대부분의 음식점은 일본어가 거의 필요 없는 네 가지 시스템 중 하나를 씁니다. 사진 메뉴, 진열창의 음식 모형, 식권 자판기, 태블릿입니다. 실제로 중요한 어휘는 15개 정도입니다 — 정식, 곱빼기, 빼기, 그리고 알레르기 유발 식품.

## 네 가지 시스템

| 시스템 | 어디서 | 어떻게 |
|---|---|---|
| **식권 자판기(食券機 쇽켄키)** | 라멘, 카레, 소바, 규동 체인 | 현금을 넣거나 IC 카드를 대고, 버튼을 누른 뒤, 식권을 직원에게 건넵니다. **왼쪽 위 버튼이 보통 기본 메뉴** |
| **사진 메뉴／태블릿** | 체인점, 이자카야, 패밀리 레스토랑 | 누르거나 가리키면 됩니다; 태블릿에는 **영어 전환** 버튼이 있는 경우가 많음 |
| **음식 모형(食品サンプル 쇼쿠힌 산푸루)** | 백화점 식당가, 역 건물 | 진열창의 모형을 가리키면 직원이 어떤 메뉴인지 압니다 |
| **글자 메뉴만 있음** | 작은 동네 가게, 스시 카운터 | "오스스메"(おすすめ, 추천)나 "오마카세"(おまかせ, 맡김)를 청하고, 예산을 말하십시오 |

## 15개 단어

| 일본어 | 뜻 |
|---|---|
| 定食 테이쇼쿠 | **정식**: 메인, 밥, 미소시루, 절임 |
| セット 셋토 | 음료나 사이드가 딸린 세트 |
| 大盛り 오모리 ／ 特盛 토쿠모리 | 곱빼기／특곱빼기(무료 또는 ¥100 추가인 경우가 많음) |
| 小盛り 코모리 | 소량 |
| おかわり 오카와리 | 리필(일부 정식집에서는 밥 리필 무료) |
| 〜抜き -누키 | **빼기**(예: 玉ねぎ抜き, 양파 빼고) |
| 辛さ 카라사 | 맵기 단계 |
| 麺硬め 멘 카타메 | 면 단단하게(라멘) |
| ランチ 란치 | 런치 세트, 보통 저녁보다 저렴 |
| お会計 오카이케이 | 계산 |
| 別々 베츠베츠 | 각자 계산 |
| 持ち帰り 모치카에리 | 포장 |
| 店内 텐나이 | 매장 내 식사(편의점에서 세율 때문에 묻는 질문) |
| アレルギー 아레루기 | 알레르기 |
| 苦手 니가테 | 못 먹음／싫어함 |

> **[확인 필요]** 어휘는 표준적인 것입니다. 음식점 메뉴의 알레르기 유발 식품 표시는 자율 사항입니다(알레르기 표시 관련 글 참조).

## 오해 1｜영어 메뉴가 없는 가게는 외국인을 반기지 않는다

그런 가게는 **작고 바쁠 뿐**입니다. 옆 사람의 음식이나 진열창 모형을 가리키는 것은 흔한 일이며, "코레오 쿠다사이"(これをください, 이거 주세요)는 어디서나 통합니다.

## 오해 2｜식권 자판기는 장벽이다

**세상에서 가장 쉬운 시스템**입니다. 주문 대화도, 계산도, 팁도 없습니다. 기본은 현금이며, 지금은 IC 카드를 받는 곳도 많습니다.

## 오해 3｜정식은 관광객용 메뉴다

**테이쇼쿠는 직장인들이 점심에 먹는 것**이며, 일본에서 가장 가성비 좋은 식사입니다. 메인, 밥, 국, 절임이 **¥800~1,200**입니다.

## 오해 4｜자유롭게 바꿔 달라고 할 수 있다

재료를 빼는 것(**-누키**)은 대개 괜찮지만, **다른 재료로 바꾸는 것**은 이곳 문화에 없어 정중히 거절될 수 있습니다. 라멘집에서는 면의 단단함, 기름, 짠맛을 고르게 해 주는 경우가 많습니다 — 그것이 가게가 제공하는 맞춤 항목입니다.

## 오해 5｜카메라 번역 앱만 있으면 된다

글자는 읽어 주지만 **시스템**은 놓칩니다 — 기계가 돈을 먼저 요구한다는 것, 벽에 붙은 종이가 오늘의 특별 메뉴라는 것, 작은 숫자가 런치 가격이라는 것. 앞사람이 어떻게 하는지 지켜보십시오.
