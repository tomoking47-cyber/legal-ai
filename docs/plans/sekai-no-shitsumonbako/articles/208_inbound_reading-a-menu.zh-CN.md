# Q. 关于看懂日本的菜单，人们常有哪些误解？｜Japan Questions #208

- Shelf: `inbound` ／ URL: `/zh-cn/questions/reading-a-menu` ／ Status: **草稿 — 出处未核实**

菜单是多数游客最感到无助的时刻——也是日本最体贴的时刻。图片菜单、食物模型、餐券机和套餐惯例都是为了帮你，只要你知道它们是怎么运作的。

## A. 最常见的误解是点餐必须会日语。多数餐厅使用四种系统之一，几乎不需要日语：图片菜单、橱窗里的食物模型、餐券机，或平板电脑。真正需要的词汇大约只有 15 个——套餐、大份、去掉某样食材，以及过敏原。

## 四种系统

| 系统 | 在哪里 | 怎么用 |
|---|---|---|
| **餐券机（食券機 shokkenki）** | 拉面、咖喱、荞麦面、牛肉饭连锁店 | 投入现金或刷 IC 卡，按下按钮，把餐券交给店员。**左上角的按钮通常是招牌菜** |
| **图片菜单／平板** | 连锁店、居酒屋、家庭餐厅 | 点选或用手指；平板通常有**英文切换** |
| **食物模型（食品サンプル shokuhin sampuru）** | 百货商场餐厅楼层、车站大楼 | 指着橱窗里的模型即可；店员知道是哪一道 |
| **只有文字菜单** | 小型本地店、寿司柜台 | 问"osusume"（おすすめ，推荐）或"omakase"（おまかせ，交给店家）；说明预算 |

## 15 个词

| 日语 | 含义 |
|---|---|
| 定食 teishoku | **套餐**：主菜、米饭、味噌汤、腌菜 |
| セット setto | 配饮品或小菜的套餐 |
| 大盛り ōmori ／ 特盛 tokumori | 大份／特大份（常为免费或加 ¥100） |
| 小盛り komori | 小份 |
| おかわり okawari | 续添（有些定食店米饭免费续添） |
| 〜抜き -nuki | **去掉**（如 玉ねぎ抜き，不要洋葱） |
| 辛さ karasa | 辣度 |
| 麺硬め men katame | 面偏硬（拉面） |
| ランチ ranchi | 午市套餐，通常比晚餐便宜 |
| お会計 okaikei | 结账 |
| 別々 betsu-betsu | 分开结账 |
| 持ち帰り mochikaeri | 打包带走 |
| 店内 tennai | 店内用餐（便利店会问，涉及税率） |
| アレルギー arerugī | 过敏 |
| 苦手 nigate | 不能吃／不喜欢 |

> **[待核实]** 词汇为通用说法；餐厅菜单上的过敏原标示属自愿（参见过敏原标示一文）。

## 误解1｜没有英文菜单的餐厅不欢迎外国人

它们只是**店小、忙碌**。指一指邻座的菜或橱窗模型很正常，"kore o kudasai"（これをください，请给我这个）在哪里都管用。

## 误解2｜餐券机是个障碍

它是**世界上最简单的系统**：不用点餐对话，不用结账，不用小费。默认用现金；现在很多也能刷 IC 卡。

## 误解3｜套餐是给游客的菜单

**定食是上班族午餐吃的东西**，也是日本性价比最高的一餐：主菜、米饭、汤和腌菜，**¥800–1,200**。

## 误解4｜可以随意改菜

去掉某种食材（**-nuki**）通常没问题；**替换食材**不属于这里的习惯，可能会被礼貌地拒绝。拉面店常让你选择面的硬度、油量和咸度——那才是店家提供的定制项目。

## 误解5｜有拍照翻译 App 就够了

它能读出文字，却读不出**系统**——机器要先收钱、墙上的纸条是今日特餐、较小的那个数字是午市价格。看看前面那个人是怎么做的。
