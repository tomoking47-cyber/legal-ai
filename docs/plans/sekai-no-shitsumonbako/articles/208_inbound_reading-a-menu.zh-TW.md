# Q. 關於看懂日本的菜單，人們常有哪些誤解？｜Japan Questions #208

- Shelf: `inbound` ／ URL: `/zh-tw/questions/reading-a-menu` ／ Status: **草稿 — 出處未核實**

菜單是多數旅客最感到無助的時刻——也是日本最貼心的時刻。圖片菜單、食物模型、餐券機和套餐慣例都是為了幫你，只要你知道它們是怎麼運作的。

## A. 最常見的誤解是點餐必須會日語。多數餐廳使用四種系統之一，幾乎不需要日語：圖片菜單、櫥窗裡的食物模型、餐券機，或平板。真正需要的詞彙大約只有 15 個——套餐、大碗、去掉某樣食材，以及過敏原。

## 四種系統

| 系統 | 在哪裡 | 怎麼用 |
|---|---|---|
| **餐券機（食券機 shokkenki）** | 拉麵、咖哩、蕎麥麵、牛丼連鎖店 | 投入現金或感應 IC 卡，按下按鈕，把餐券交給店員。**左上角的按鈕通常是招牌菜** |
| **圖片菜單／平板** | 連鎖店、居酒屋、家庭餐廳 | 點選或用手指；平板通常有**英文切換** |
| **食物模型（食品サンプル shokuhin sampuru）** | 百貨公司餐廳樓層、車站大樓 | 指著櫥窗裡的模型即可；店員知道是哪一道 |
| **只有文字菜單** | 小型在地店、壽司吧檯 | 問「osusume」（おすすめ，推薦）或「omakase」（おまかせ，交給店家）；說明預算 |

## 15 個詞

| 日語 | 意思 |
|---|---|
| 定食 teishoku | **套餐**：主菜、白飯、味噌湯、醃菜 |
| セット setto | 附飲料或小菜的套餐 |
| 大盛り ōmori ／ 特盛 tokumori | 大碗／特大碗（常為免費或加 ¥100） |
| 小盛り komori | 小碗 |
| おかわり okawari | 續加（有些定食店白飯免費續加） |
| 〜抜き -nuki | **去掉**（如 玉ねぎ抜き，不要洋蔥） |
| 辛さ karasa | 辣度 |
| 麺硬め men katame | 麵偏硬（拉麵） |
| ランチ ranchi | 午間套餐，通常比晚餐便宜 |
| お会計 okaikei | 結帳 |
| 別々 betsu-betsu | 分開結帳 |
| 持ち帰り mochikaeri | 外帶 |
| 店内 tennai | 內用（便利商店會問，涉及稅率） |
| アレルギー arerugī | 過敏 |
| 苦手 nigate | 不能吃／不喜歡 |

> **[待核實]** 詞彙為通用說法；餐廳菜單上的過敏原標示屬自願（參見過敏原標示一文）。

## 誤解1｜沒有英文菜單的餐廳不歡迎外國人

它們只是**店小、忙碌**。指一指鄰座的菜或櫥窗模型很正常，「kore o kudasai」（これをください，請給我這個）在哪裡都管用。

## 誤解2｜餐券機是個障礙

它是**世界上最簡單的系統**：不用點餐對話，不用結帳，不用小費。預設用現金；現在很多也能感應 IC 卡。

## 誤解3｜套餐是給觀光客的菜單

**定食是上班族午餐吃的東西**，也是日本 CP 值最高的一餐：主菜、白飯、湯和醃菜，**¥800–1,200**。

## 誤解4｜可以隨意改菜

去掉某種食材（**-nuki**）通常沒問題；**替換食材**不屬於這裡的習慣，可能會被禮貌地拒絕。拉麵店常讓你選麵的硬度、油量和鹹度——那才是店家提供的客製項目。

## 誤解5｜有拍照翻譯 App 就夠了

它能讀出文字，卻讀不出**系統**——機器要先收錢、牆上的紙條是今日特餐、較小的那個數字是午間價格。看看前面那個人是怎麼做的。
