# Q. 關於「おしぼり」（oshibori，濕毛巾），人們常有哪些誤解？｜Japanese Everyday Wisdom #217

- Shelf: `wisdom` ／ URL: `/zh-tw/wisdom/oshibori` ／ Status: **草稿 — 出處未核實**

在日本幾乎每一家餐廳，菜單還沒送來，一條捲好的毛巾——冬天是熱的，夏天是涼的——就先到了。遊客有人拿來擦臉、擦脖子、擦桌子，也有人完全不用，同時納悶到底有沒有規矩。有，但比較寬鬆。

## A. 常見的誤解是把「おしぼり」當成擦臉的毛巾。它是用來擦手的，在一個用筷子、也常常直接用手進食（壽司、飯糰）的文化裡，餐前送上。年長的男性和小孩擦臉還能被容忍，其他人這麼做會被側目；擦桌子則完全不是它的用途。它也是一個產業：出租毛巾依照衛生標準統一清洗。

## 它是什麼

| 項目 | 說明 |
|---|---|
| 用途 | **餐前清潔雙手** |
| 溫度 | **寒冷月份為熱毛巾（約 50–60°C），夏天則是冰鎮的** |
| 種類 | **布製出租毛巾**（清洗後歸還供應商）或密封包裝的 **一次性紙質／不織布毛巾** |
| 用後 | **鬆鬆地摺好或捲好，放在餐盤旁邊**——店員會來收走；不要揉成一團，也不要當餐巾用 |
| 業界標準 | 出租「おしぼり」依照 **厚生勞動省指導與業界公會制定的衛生標準** 清洗，設有細菌數上限 |
| 便利商店 | 買便當時會附一條一次性毛巾——沒有的話可以問（**「おしぼりありますか？」oshibori arimasu ka?**） |

- 這個習慣可追溯到 **江戶時代**，當時旅店會為抵達的客人準備一桶水和幾塊布；出租「おしぼり」出現於 **1950 年代**。
- **全國おしぼり協同組合連合會** 估算，出租「おしぼり」的使用量 **每月達數億條**，每條毛巾經清洗後可重複使用 **數十次**。

> **[待核實]** 使用量數據請向全國おしぼり協同組合連合會（全国おしぼり協同組合連合会）核對；衛生標準請以厚生勞動省的出租おしぼり指導（貸おしぼりの衛生等管理要領）核對。

## 誤解1｜用它擦臉

**只擦手。** 擦臉（更糟的是擦脖子和腋下）是中年上班族的漫畫式形象，並不禮貌。

## 誤解2｜用餐時把它當餐巾用

它是 **餐前** 為擦手而送上的。留著在吃壽司的間隔擦擦手指是可以的；反覆擦嘴或拿來擦灑出來的東西就不行。請另外要紙巾。

## 誤解3｜用它擦桌子

桌子是餐廳的事。如果桌子髒了，請叫店員。

## 誤解4｜可以帶回家

布製「おしぼり」是要送回洗滌廠的 **出租物品**。一次性的可以留著。

## 誤解5｜它不過是一條毛巾

它是一種 **問候**。在寒冷的日子裡接過一條熱毛巾，或者在八月接過一條涼毛巾，是餐廳待客的第一個動作，也為整頓飯定下基調。
