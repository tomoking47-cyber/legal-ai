# Q. 關於店頭試用品與試用包，常見的誤解有哪些？｜Japan Questions #225

- Shelf: `beauty` ／ URL: `/zh-tw/beauty/tester-hygiene` ／ Status: **草稿 — 出處未核實**

不論是百貨公司還是藥妝店（松本清、Welcia 等），試用品都是日本化妝品專櫃的固定配置。「誰知道這個試用品被多少人用過——真的安全嗎？」這個問題在國外也一樣有人問。自 2020 年以來，多數企業改變了試用品的做法。

## A. 最大的誤解是「店家會照顧試用品，所以是乾淨的」。試用品會被數不清的人碰過，尤其口紅、睫毛膏與乳霜這類形態，細菌特別容易孳生。基本做法是：在手背上試、使用拋棄式眼影棒與挖杓，絕不把試用品直接塗到眼睛或嘴唇上。

## 需要留意的地方

| 試用品的類型 | 風險 | 試用方式 |
|---|---|---|
| **口紅（膏狀）** | 有接觸過嘴唇的痕跡；細菌 | **請店員擦拭表面後，用手指或棉花棒取一點抹在手背上。** 不要塗在嘴唇上 |
| **睫毛膏、液體眼線** | 共用刷頭 | 僅限有提供**拋棄式刷具或眼影棒**的情況。絕不直接用在眼睛上 |
| 罐裝乳霜 | 會用手指接觸 | **用挖杓取用**（可請店員協助） |
| 粉狀產品 | 相對較低 | 使用拋棄式眼影棒，或抹在手背上 |
| 化妝水、按壓瓶 | 相對較低 | 按壓到手背上 |
| **試用包（隨身包）** | 未開封時風險低 | 確認包裝上的日期；**一旦開封，請一次用完** |

- 化妝品中**未開封狀態下能穩定保存 3 年以上的，不需標示保存期限**，因此實際上**無法知道試用品是什麼時候開封的**。日本化妝品工業聯合會建議店家**定期更換並擦拭試用品**。
- **自 2020 年起**，許多店家**停止了「上妝服務」（把產品直接塗在顧客臉上），或改為預約制**，**提供拋棄式工具**已成為常態。
- 「試用包」**和販售的產品是同一件商品**，但**標示（成分、製造商）有時是簡略的**。若看不到完整的成分表，請查看貨架上的正裝產品。

> **[待核實]** 保存期限標示義務的範圍請對照《醫藥品醫療器材等法》第 61 條（日本關於化妝品與藥品的法律）核實，試用品衛生請對照日本化妝品工業聯合會的店頭衛生指南核實。

## 誤解1｜用試用品就能知道產品適不適合自己的膚質

**手背與臉的皮膚不一樣，試一次只能看出顏色與質地。****產品適不適合自己需要好幾天才判斷得出來**，所以**把試用包帶回家**才是可靠的做法。

## 誤解2｜擦過的口紅就是乾淨的

擦拭去掉的是表面，**滲進內部的細菌去不掉。****請不要直接塗在嘴唇上。**

## 誤解3｜試用品放了多久無所謂

**很久以前開封的試用品，在氣味、顏色與質地上都可能與真正的產品不同。** 如果已經**油水分離、變色或氣味改變**，那就得不到任何有用的資訊了。

## 誤解4｜試用包可以放很多年

**隨身包的試用包很薄，在光照與高溫下容易變質**，所以**請在一年左右內用掉，開封後一次用完**。日期無法辨識的，請丟棄。

## 誤解5｜請店員上妝最保險

上妝服務時，**刷具與海綿的衛生狀況因店家而異。** 請選擇接受預約、**使用拋棄式工具**的店家，或者**在自己的手背上試**——那是比較安全的選擇。
