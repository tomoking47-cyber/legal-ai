# Q. ヘアカラーのパッチテストについて、よくある誤解は？｜世界の質問箱 #226

- 棚：`beauty` ／ URL：`/questions/hair-dye-patch-test` ／ ステータス：**ドラフト（法務レビュー前・出典未検証）**

家庭用ヘアカラーは手軽ですが、日本では毎年、ヘアカラーによるかぶれの相談が寄せられ、消費者安全調査委員会が2015年に報告書を出しています。海外でも同じ成分（ジアミン）によるアレルギーが問題になっています。

## A. 最大の誤解は「前に使って大丈夫だったから、テストは要らない」です。ヘアカラーのアレルギーは、何度も使ううちに突然発症し、一度発症すると同じ成分を含む製品は使えなくなります。使用のたび、48時間前のパッチテストが製品表示で求められています。

## 判断の材料

| 項目 | 内容 |
|---|---|
| 主な原因成分 | **酸化染毛剤に含まれる パラフェニレンジアミン（PPD）などのジアミン系** |
| 症状 | 使用後**数時間〜48時間**で、頭皮・顔・首の**赤み・かゆみ・腫れ**。**まぶたの腫れ**が特徴的 |
| 制度 | 酸化染毛剤は**医薬部外品**。**使用前48時間のパッチテスト**が製品の使用上の注意に記載 |
| 消費者安全調査委員会 | **2015年10月**、「毛染めによる皮膚障害」の報告書。**一度かぶれた人は使用をやめる**ことを強く勧告 |
| 事故情報 | 消費者庁「事故情報データバンク」に**毛染めによる皮膚障害が毎年度200件程度**登録（2015年報告書時点） |

### パッチテストの手順（製品表示の例）

1. **使用の48時間前**、1剤と2剤を少量混ぜる
2. **腕の内側**に10円硬貨大に塗り、**自然乾燥**
3. **30分後と48時間後**に観察。**赤み・かゆみ・腫れ**があれば**使用しない**
4. 48時間の間は**その部分を洗わない**

> 【要検証】報告書の年月と内容は消費者庁 消費者安全調査委員会の公表資料で、相談件数は国民生活センターの資料で確認してください。

## 誤解1｜以前は大丈夫だったから今回も大丈夫

**ジアミンのアレルギーは「感作」が進んで突然出ます。** 何年も使っていた人が発症する例が多く、**毎回のテスト**が製品表示の求めるところです。

## 誤解2｜軽いかぶれなら次は少し気をつければよい

**一度アレルギーになると、以後はより重い症状が出る**ことがあります。調査委員会は**「一度でもかぶれたら、以後ジアミン系の染毛剤は使わない」**と勧告しています。

## 誤解3｜ヘアマニキュア・カラートリートメントも同じ

**酸性染毛料（ヘアマニキュア）やカラートリートメントはジアミンを含まないものが多く、化粧品区分**です。ただし、**「植物性」「ヘナ」をうたう製品でも酸化染料（ジアミン系）を含むものがあり**、国民生活センターは**2026年5月**、酸化染料を含むかつら用ヘナ製品による**アナフィラキシー**事例を公表しています。**表示成分を必ず確認**し、**染まり方は異なり、別の成分で反応する人もいます。**

## 誤解4｜美容室なら安全

**成分は同じ**です。美容室でも**過去のかぶれの経験を必ず伝えてください**。**一度でもかぶれた人は、酸化染毛剤を使わないこと**が製品の使用上の注意で求められており、**パッチテストも行いません**（テスト自体が強い反応を起こすおそれがあります）。染めたい場合は、酸化染料を含まない製品について皮膚科・美容師に相談してください。

## 誤解5｜生え際の赤みは薬剤がしみただけ

**刺激（その場でしみる）とアレルギー（数時間〜2日後に腫れる）は別**です。**時間がたって出てくる症状はアレルギー**の可能性があり、**皮膚科の受診**が必要です。**まぶたや顔の腫れ**は特に。
