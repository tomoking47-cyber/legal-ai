# Q. 關於泳衣的清洗，人們常有什麼誤解？｜Japan Questions #232

- Shelf: `fashion` ／ URL: `/zh-tw/fashion/washing-swimwear` ／ Status: **草稿 — 出處未核實**

「穿一季就鬆了」「顏色掉了」是全世界都聽得到的抱怨，原因多半出在洗法與晾法上。在日本，泳衣的三大敵人眾所周知：泳池的氯、海水的鹽、防曬乳。

## A. 最大的誤解是「泳衣本來就是下水穿的，用洗衣機正常洗就好」。泳衣裡的彈性纖維（聚氨酯，也叫彈性纖維、萊卡）會被氯、鹽、防曬乳裡的油分、高溫與用力搓揉破壞。基本流程是：用完立刻用清水沖 → 用中性洗劑輕輕手洗 → 用毛巾按壓吸水 → 陰乾。

## 可以參考的做法

| 步驟 | 做什麼 | 原因 |
|---|---|---|
| 用完立刻 | **用清水沖洗**（能在泳池或海邊沖最好） | 沖掉氯、鹽與沙。**不要濕著放著不管** |
| 清洗 | **用中性洗劑（「精緻衣物用」，日文標示為「おしゃれ着用」）在溫水（30℃／86°F 以下）中按壓清洗**。用洗衣機時：**洗衣袋＋弱水流＋短時間行程** | 聚氨酯會被**鹼性洗劑、漂白劑、柔軟精**破壞 |
| 去水 | **用毛巾夾住按壓。** **不要擰乾；脫水時間要短** | 纖維會被拉長 |
| 晾乾 | **整理好形狀後陰乾。** **不要陽光直射，不要用烘衣機** | 紫外線與高溫會讓顏色變淡、彈性變差 |
| 收納 | 徹底晾乾後，**不要留下明顯摺痕地收好**。掛衣架會把肩帶拉長，所以請平放 | — |

- 大多數泳衣是**尼龍或聚酯纖維加 10〜20% 的聚氨酯**，**聚氨酯會因氯、紫外線、高溫與時間而劣化**（使用壽命一般以**1〜3 年**為參考，視使用頻率而定）。
- **防曬乳，尤其是油性防曬乳，會讓接觸到的布料泛黃、變色。** **塗完之後隔一會兒再穿泳衣**，**補擦時也不要蹭到布料上**。
- 日本的洗滌標籤使用國際通用的 **JIS L0001** 符號。泳衣上常見的是**盆中有手（手洗）、不可漂白、不可烘乾、陰乾**這幾個符號。

> **[待核實]** 聚氨酯劣化與壽命的數值，是根據紡織業界團體與廠商資料的一般性參考。

## 誤解1｜游完泳晾乾就好了

**氯在乾燥後仍留在纖維裡，繼續侵蝕纖維。** 首先要做的是**當天就用清水沖洗**。

## 誤解2｜用漂白劑去掉氯的氣味

**漂白劑會破壞聚氨酯。** 用中性洗劑洗，**充分沖洗乾淨**，氣味就會減輕。

## 誤解3｜用烘衣機更快也更衛生

**高溫會毀掉聚氨酯的彈性。** 陰乾完全夠用；泳衣很薄，幾個小時就乾了。

## 誤解4｜掛在衣架上乾得更快

**濕泳衣掛在衣架上，肩帶與布料都會被拉長。** **請平放晾乾**，或者**攤在毛巾上**。

## 誤解5｜濕泳衣裝進塑膠袋帶回家就好

**密封住的濕氣幾個小時內就會引來黴菌與異味。** **先沖一沖，用毛巾包好，回到家馬上洗。** 真要用塑膠袋，也**只限於回家這段路**。
