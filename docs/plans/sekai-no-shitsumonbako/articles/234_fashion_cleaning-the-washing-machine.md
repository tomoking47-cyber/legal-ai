# Q. 洗濯機の洗濯槽の掃除について、よくある誤解は？｜世界の質問箱 #234

- 棚：`fashion` ／ URL：`/questions/cleaning-the-washing-machine` ／ ステータス：**ドラフト（法務レビュー前・出典未検証）**

「洗ったはずの洗濯物に黒いカスが付く」は世界共通の悩みで、原因は洗濯槽の裏側のカビです。日本の高温多湿では槽の裏がカビの温床になりやすく、掃除の知恵と専用洗浄剤が発達しました。

## A. 最大の誤解は「洗濯機は毎日水と洗剤が通るから清潔」です。洗濯槽の外側（見えない裏側）には洗剤の残りと皮脂、湿気でカビが育ちます。目安は月1回の槽洗浄（塩素系または酸素系の専用洗浄剤）、使用後はふたを開けて乾かす、洗剤は規定量を守る、です。

## 判断の材料

| 項目 | 内容 |
|---|---|
| カビが育つ場所 | **洗濯槽の外側と外槽の間、糸くずフィルター、洗剤投入口、ゴムパッキン（ドラム式）** |
| 掃除の頻度 | **月1回程度**の槽洗浄（メーカーの案内）。**槽乾燥機能**がある機種は週1回程度 |
| 洗浄剤の種類 | **塩素系（次亜塩素酸ナトリウム）**：カビを分解、短時間／**酸素系（過炭酸ナトリウム）**：カビを剥がして浮かせる、**縦型向き**で**40℃前後のお湯**で効きやすい |
| 使い方 | **製品表示と洗濯機の説明書の両方に従う**。ドラム式は**泡が出る酸素系は不可**の機種が多い |
| 日常の予防 | **使用後はふたを開ける**、**洗濯物を入れたまま放置しない**、**洗剤・柔軟剤は規定量**、**糸くずフィルターは毎回** |

- 洗剤の**入れすぎ**は、**溶け残りが槽の裏に付いてカビの栄養**になる最大の原因の一つです。
- **有毒な塩素ガスが出るのは「塩素系」と「酸性タイプ」の組み合わせ**です。**塩素系洗浄剤とクエン酸・酢・酸性タイプの洗浄剤を、同時にも同じ日にも使わないでください。** これが製品の「まぜるな危険」表示の意味です。
- 塩素系と酸素系も**併用せず、どちらか一方を単独で**使います（洗浄の仕組みが違い、混ぜても効果は上がりません）。**使用中は必ず換気**してください。
- **ドラム式のゴムパッキンの裏**は水がたまりやすく、**週1回拭く**のが各メーカーの案内です。

> 【要検証】掃除頻度と使える洗浄剤の種類は、お使いの洗濯機の取扱説明書で確認してください。塩素系の注意は東京都保健医療局の資料で確認してください。

## 誤解1｜黒いカスは洗剤の溶け残り

**槽の裏から剥がれたカビ**であることが多いです。カスが出たら**槽洗浄のサイン**です。

## 誤解2｜市販の槽クリーナーを入れて回せばすぐきれい

**酸素系は数時間のつけ置きが前提**の製品が多く、**浮いたカビを何度もすくう**必要があります。**塩素系は短時間ですが、においと衣類への影響に注意**。**説明書のコース（槽洗浄コース）**を使います。

## 誤解3｜熱いお湯を入れれば殺菌できる

**洗濯機の耐熱温度（多くは50℃以下）**を超えると、部品を傷めます。**40℃前後**が酸素系の効きやすい目安です。

## 誤解4｜洗剤を多めに入れるほど清潔

**溶け残りがカビの栄養**になり、**すすぎ残しが肌の刺激**にもなります。**規定量**を守り、汚れがひどいときは**予洗い**で対応します。

## 誤解5｜ふたを閉めておくほうがほこりが入らず清潔

**閉めると湿気がこもってカビが育ちます。** 使用後は**ふたを開けて乾かす**のが基本。**子どもが入り込む事故**（NITE報告）があるため、**チャイルドロックのある機種は使い、小さい子どもがいる家庭は閉めて槽乾燥機能を使う**という判断もあります。
