# Q. 洗剤の量について、よくある誤解は？｜世界の質問箱 #235

- 棚：`fashion` ／ URL：`/questions/how-much-detergent` ／ ステータス：**ドラフト（法務レビュー前・出典未検証）**

「洗剤は多めに入れたほうがきれいになる」は、洗濯に関する世界で最も根強い誤解の一つです。日本では洗剤の濃縮化が進み、キャップ1杯の意味が製品ごとに違うため、計量の仕方そのものが混乱の原因になっています。

## A. 最大の誤解は「洗剤は多いほど落ちる」です。洗剤は水量に対する規定量で設計されており、超えても洗浄力は上がらず、すすぎ残し・洗濯槽のカビ・肌の刺激が増えます。水量（または洗濯物の重さ）を確認し、製品の表示量を計って入れることが基本です。

## 判断の材料

| 項目 | 内容 |
|---|---|
| 洗剤の量の基準 | **水量（L）または洗濯物の重さ（kg）**に対して製品ごとに表示。**「水30Lに○mL」「洗濯物3kgに○g」** |
| 濃縮タイプ | **キャップ1杯が10〜25mL**と製品で大きく異なる。**別の製品のキャップで計らない** |
| 入れすぎの影響 | **すすぎ残し（肌の刺激・黄ばみ・においの原因）、洗濯槽のカビの栄養、泡による洗浄力低下** |
| 少なすぎの影響 | 汚れが落ちない、**再汚染**（落ちた汚れが戻る） |
| 汚れがひどいとき | 量を増やすより**予洗い・つけ置き・部分洗い** |
| 柔軟剤 | 洗剤と**同時に入れない**（自動投入口を使う）。規定量を守る |

- 洗剤は**家庭用品品質表示法**の対象で、**成分・液性・使用量の目安・使用上の注意**の表示が義務です。
- **自動投入機能**のある洗濯機は、**洗剤の種類（濃縮・通常）を設定**しないと量がずれます。
- **洗濯物の量が多すぎる**と、洗剤の量が合っていても**水が回らず落ちません**。洗濯機の容量の**7〜8割**が目安です。

> 【要検証】表示義務の項目は消費者庁「雑貨工業品品質表示規程」で確認してください。使用量は製品の表示が優先します。

## 誤解1｜泡が多いほど洗えている

**泡は洗浄力の指標ではありません。** 過剰な泡は**衣類同士のこすれを妨げ、洗浄力を下げ、すすぎを妨げます。** ドラム式ではセンサーが泡を検知して**すすぎ回数を増やし、水と時間の無駄**になります。

## 誤解2｜キャップ1杯はどの洗剤でも同じ

**製品ごとに10〜25mL以上の差**があります。**そのボトルのキャップの線**を見て、表示の水量に合わせます。

## 誤解3｜においが残らないのは洗剤が足りないから

**残り香は洗剤ではなく香料と柔軟剤**の話です。**洗剤の量を増やしても清潔さは増えません**（柔軟剤の記事を参照）。

## 誤解4｜つけ置きは洗剤を多く溶かすほど効く

つけ置きも**規定の濃度**で、**時間（30分〜数時間）**が働きます。濃くしても効果は増えず、**色柄物の色落ち**の原因になります。

## 誤解5｜洗剤を減らすのはケチ

**適量が最も清潔で、肌にも洗濯機にも負担が少ない**というのが各メーカーの案内です。**計量カップを洗濯機の横に置く**のが、日本の生活者の間で共有された工夫です。
