# Q. 關於洗劑用量，人們常有什麼誤解？｜Japan Questions #235

- Shelf: `fashion` ／ URL: `/zh-tw/fashion/how-much-detergent` ／ Status: **草稿 — 出處未核實**

「洗劑多加一點洗得更乾淨」，是全世界最根深蒂固的洗衣迷思之一。在日本，洗劑高度濃縮化，「一瓶蓋」對每個產品來說都是不同的量，於是量取本身就成了混亂的來源——如果看不懂日文標籤，就更是如此。

## A. 最大的誤解是「洗劑越多，洗得越乾淨」。洗劑是按「多少水配多少量」設計的，超過這個量並不會增加去污力，只會增加沖洗殘留、內槽黴菌與對皮膚的刺激。基本原則是：確認水量（或衣物重量），依產品上印的量來量取。

## 可以參考的做法

| 要點 | 內容 |
|---|---|
| 用量的依據 | 每個產品都依**水量（L）或衣物重量（kg）**標示：**「水 30 L 用 ○ mL」「衣物 3 kg 用 ○ g」** |
| 濃縮型 | **一瓶蓋從 10 到 25 mL 都有**，產品之間差別很大。**絕對不要用別的產品的瓶蓋來量** |
| 放太多 | **沖洗殘留（刺激皮膚、泛黃、異味）、內槽黴菌的養分、泡沫過多反而降低去污力** |
| 放太少 | 污垢洗不掉，**再沾染**（被洗下來的污垢又落回衣服上） |
| 重污漬 | 與其加量，不如：**預洗、浸泡或局部清洗** |
| 柔軟精 | **不要與洗劑同時投入**（請用自動投入口）。同樣要守住規定用量 |

- 洗劑適用日本的**《家庭用品品質標示法》**，必須在包裝上標明**成分、液性（酸性／中性／鹼性）、參考用量與使用注意事項**。
- 有**自動投入**功能的洗衣機，如果不**設定洗劑的種類（濃縮型或一般型）**，投出來的量就是錯的。
- **衣物塞太滿**時，即使洗劑的量正確，**水也轉不起來，污垢照樣留著**。參考值是洗衣機額定容量的**七到八成**。

> **[待核實]** 強制標示項目請對照消費者廳的《雜貨工業品品質標示規程》核實。產品標籤上的用量始終優先。

## 誤解1｜泡沫越多表示洗得越好

**泡沫不是去污力的量尺。** 泡沫過多會**妨礙衣物之間相互摩擦，降低去污力，也妨礙沖洗**。滾筒式洗衣機的感測器偵測到泡沫後，會**追加沖洗，白白浪費水與時間**。

## 誤解2｜一瓶蓋對哪種洗劑都一樣

**一瓶蓋的量因產品而異，大約在 10 到 25 mL 之間。** **請看那一瓶自己的瓶蓋上的刻度線**，對照標籤上的水量來量取。

## 誤解3｜洗完沒留下香味，是洗劑放太少了

**留香靠的是香精與柔軟精，不是洗劑。** **多放洗劑並不會讓衣服更乾淨**（參見本刊關於柔軟精的文章）。

## 誤解4｜浸泡時洗劑溶得越濃越有效

浸泡同樣依**規定濃度**，起作用的是**時間（30 分鐘到數小時）**。濃度更高沒有額外效果，反而**會讓印花與有色衣物褪色**。

## 誤解5｜少放洗劑是小氣

**正確的用量既洗得最乾淨，對皮膚與洗衣機也最溫和**——這是廠商自己的說明。**把量杯放在洗衣機旁邊**，是在日本生活的人們共有的習慣。
