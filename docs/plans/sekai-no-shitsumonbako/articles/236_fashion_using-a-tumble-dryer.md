# Q. 乾燥機の使い方について、よくある誤解は？｜世界の質問箱 #236

- 棚：`fashion` ／ URL：`/questions/using-a-tumble-dryer` ／ ステータス：**ドラフト（法務レビュー前・出典未検証）**

乾燥機は「縮む」「傷む」と敬遠されがちですが、洗濯表示に乾燥機の記号が加わった2016年以降、「乾燥機に入れてよい服」が表示で分かるようになりました。コインランドリーのガス乾燥機と家庭のドラム式は性質も異なります。

## A. 最大の誤解は「乾燥機はすべての衣類を縮ませる」です。縮むのは、表示で乾燥機が禁止されている素材（ウール・シルク・伸縮素材・プリント）を高温で乾かした場合です。表示の記号（四角に丸、中の点の数＝温度）を読み、対応する衣類を適切な温度で乾かせば、時間と衛生の面で利点があります。

## 乾燥機の記号（JIS L0001）

| 記号 | 意味 |
|---|---|
| 四角に丸、**点1つ** | **タンブル乾燥可、排気温度の上限60℃（低温）** |
| 四角に丸、**点2つ** | **タンブル乾燥可、排気温度の上限80℃（高温）** |
| 四角に丸に**×** | **タンブル乾燥禁止** |

| 種類 | 特徴 | 向く衣類 |
|---|---|---|
| **家庭用ドラム式（ヒートポンプ）** | **約60℃前後の低温**、電気代が少ない、時間は長め | 綿・化繊の日常着、タオル、シーツ |
| 家庭用ドラム式（ヒーター式） | 高温、電気代が高い、縮みやすい | 同上、低温設定で |
| **コインランドリーのガス乾燥機** | **高温・大風量・短時間**（80℃前後） | 綿のタオル・シーツ・布団。**化繊・プリントは低温設定** |

- 乾燥機のメリット：**ダニは50℃で20〜30分、60℃以上ならより短時間で死滅**するとされ、**布団・毛布・ぬいぐるみ**の対策として国民生活センターや自治体で紹介されています。
- 乾燥機に入れてはいけない代表：**ウール・シルク・レーヨン・ポリウレタン混（水着・レギンス）・転写プリント・革・ダウン（表示で可のものは低温で）**。
- **乾燥フィルターの掃除を毎回**行わないと、**乾燥時間の延長・電気代の増加・発火**の原因になります（NITEの事故報告）。

> 【要検証】記号の意味は消費者庁「洗濯表示」で、ダニの死滅条件は東京都・国民生活センターの資料で、事故事例はNITEで確認してください。

## 誤解1｜綿は乾燥機で縮まない

**綿は最初の数回で数%縮む**ことがあります（生地の緩和収縮）。**表示に乾燥機可の記号**があれば、想定の範囲内です。**Tシャツは乾燥機を使うなら最初から**、途中から使うと一度に縮んで感じます。

## 誤解2｜乾燥機を使うと生地が傷む

**高温と過乾燥**が原因です。**低温設定・乾きすぎる前に取り出す**ことで、傷みは大きく減ります。**糸くずフィルターにたまる綿ぼこりは、繊維が削れたもの**で、ゼロにはなりません。

## 誤解3｜乾燥機を使えばアイロンは不要

**乾燥後すぐに取り出して畳む・ハンガーに掛ける**としわは少ないですが、**入れたまま放置**するとしわが固定されます。シャツは**乾ききる前に出して吊るす**のが定番です。

## 誤解4｜コインランドリーの乾燥機は家庭用と同じ

**ガス乾燥機は高温・短時間**で、**化繊やプリントは縮み・溶けの原因**になります。**低温設定があれば使い、なければ綿製品だけ**にします。

## 誤解5｜フィルターは時々掃除すればよい

**毎回**です。**ほこりの詰まりは乾燥時間を延ばし、電気代を上げ、まれに発火**します。**乾燥機の排気ダクト**も年1回程度の点検が案内されています。
