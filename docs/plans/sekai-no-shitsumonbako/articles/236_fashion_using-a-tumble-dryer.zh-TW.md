# Q. 關於烘衣機的使用，人們常有什麼誤解？｜Japan Questions #236

- Shelf: `fashion` ／ URL: `/zh-tw/fashion/using-a-tumble-dryer` ／ Status: **草稿 — 出處未核實**

在日本，烘衣機常被當成「會縮水、會傷衣服」的東西而敬而遠之。但自 2016 年日本的洗滌標示加入烘乾符號之後，標示本身就能告訴你哪些衣服可以進烘衣機。另外也要注意，自助洗衣店（「コインランドリー」）的瓦斯烘衣機和家用的洗脫烘滾筒機性質相當不同。

## A. 最大的誤解是「烘衣機會把所有衣服都烘縮」。縮水發生在標示寫著不可烘乾的材質（羊毛、蠶絲、彈性布料、印花）被高溫烘乾的時候。看懂符號（方框裡一個圓，圓內點數代表溫度），把允許烘乾的衣服用對檔位來烘，烘衣機在時間與衛生這兩方面都划算。

## 烘乾符號（JIS L0001）

| 符號 | 含義 |
|---|---|
| 方框加圓，**一個點** | **可翻轉烘乾，排氣溫度上限 60℃（低溫）** |
| 方框加圓，**兩個點** | **可翻轉烘乾，排氣溫度上限 80℃（高溫）** |
| 方框加圓，**打叉** | **不可翻轉烘乾** |

| 類型 | 特性 | 適合 |
|---|---|---|
| **家用滾筒洗脫烘（熱泵式）** | **低溫，60℃ 前後**，電費低，時間較長 | 棉與化纖的日常衣物、毛巾、床單 |
| 家用滾筒洗脫烘（電熱式） | 高溫，電費較高，較易縮水 | 同上，用低溫檔 |
| **自助洗衣店的瓦斯烘衣機** | **高溫、大風量、時間短**（80℃ 前後） | 棉毛巾、床單、被褥。**化纖與印花請用低溫檔** |

- 烘衣機的優勢：**一般認為塵蟎在 50℃ 下 20～30 分鐘死亡，60℃ 以上則更快**，因此**被褥、毛毯與絨毛玩具**的除蟎，日本國民生活中心與各地方政府都推薦使用烘衣機。
- 典型的不可入機物品：**羊毛、蠶絲、嫘縈、含聚氨酯的混紡（泳衣、內搭褲）、燙印印花、皮革，以及羽絨（標示允許時也只能用低溫）**。
- **每烘一次都要清理烘衣機濾網。** 不清理的結果是**烘乾時間變長、電費上升，偶爾還會起火**（日本產品安全機構 NITE 的事故報告）。

> **[待核實]** 符號請對照消費者廳的洗滌標示指南，塵蟎的條件請對照東京都與日本國民生活中心的資料，事故案例請對照 NITE 核實。

## 誤解1｜棉在烘衣機裡不會縮水

**棉在最初幾次烘乾中可能縮水百分之幾**（布料的鬆弛收縮）。**只要標示上有可烘乾符號**，這就在廠商的預期範圍之內。**如果打算烘 T 恤，就從第一次洗的時候開始烘**；穿到一半才開始烘，縮水會一次全來。

## 誤解2｜用烘衣機會把衣服穿壞

罪魁禍首是**高溫與過度烘乾**。**用低溫檔，在完全乾透之前取出**，磨損就會大幅下降。**濾網裡的棉絮是從布料上磨下來的纖維**，這個量永遠不會是零。

## 誤解3｜有了烘衣機就不用燙衣服

**行程一結束就取出摺好或掛起來**，皺褶就很少；**放在滾筒裡不管**，皺褶就定型了。襯衫的標準做法是**在還略帶潮氣時取出並掛起來**。

## 誤解4｜自助洗衣店的烘衣機和家裡的一樣

**瓦斯烘衣機溫度高、速度快**，**化纖與印花可能縮水或熔化**。**有低溫檔就用低溫檔；沒有的話，只烘棉製品。**

## 誤解5｜濾網偶爾清一次就好

**每烘一次都要清。** **棉絮堵塞會延長烘乾時間、抬高電費，偶爾還會起火。** 廠商還建議**排氣管線**大約每年檢查一次。
