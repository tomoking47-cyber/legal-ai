# Q. クリーニングのトラブルについて、よくある誤解は？｜世界の質問箱 #237

- 棚：`fashion` ／ URL：`/questions/dry-cleaning-troubles` ／ ステータス：**ドラフト（法務レビュー前・出典未検証）**

「クリーニングに出したら縮んだ・色が変わった・ボタンがなくなった」という相談は、国民生活センターに毎年数千件寄せられています。海外でも同じ悩みは多く、日本には業界の「事故賠償基準」という独自の仕組みがあります。

## A. 最大の誤解は「クリーニング店に出せば何でも元どおりになる」です。クリーニングは洗濯表示の範囲で行われ、表示の範囲内でも素材の劣化や染料の性質で変化が起きることがあります。トラブル時の補償は業界の「クリーニング事故賠償基準」により、購入価格ではなく購入時期からの減価で算定されます。

## 数字と仕組み

| 項目 | 内容 |
|---|---|
| 相談件数 | 国民生活センター・消費生活センターへの**クリーニングに関する相談は年間4,000〜6,000件台**（2010年代〜） |
| 主な内容 | **変色・縮み・破損・紛失・シミが落ちない・受け取り遅延** |
| **クリーニング事故賠償基準** | 全国クリーニング生活衛生同業組合連合会が定める**業界の自主基準**。**購入価格×補償割合（購入からの経過期間で減価）**で算定 |
| 補償割合の例 | 購入から**1年未満：購入価格の約7〜10割**、**3年で約30〜50%**、**5年以上：約10〜20%**（品目の平均使用年数で異なる） |
| 受け取り後の申し出 | 基準では**受け取り後6か月以内**、**洗濯物の引き取りから1年**を超えると店の責任は問えない |

- クリーニング店は**クリーニング業法**に基づく届出制で、**洗濯表示に従って処理する義務**があります。**表示にない処理（ウェットクリーニングなど）は店の判断と説明が必要**です。
- **受け取り時にその場で確認**することが、トラブル解決の最大の鍵です。**ビニールを外して、色・形・付属品を見る**。

> 【要検証】相談件数と賠償基準の割合は、国民生活センターと全国クリーニング生活衛生同業組合連合会の最新資料で確認してください。

## 誤解1｜クリーニングに出せばどんなシミも落ちる

**時間のたったシミ・変色したシミは落ちないことがあります。** 受付時に**シミの種類と時期を伝える**と、対応できるかの判断が早くなります。

## 誤解2｜補償は購入価格の全額

**購入時期からの減価**で算定されます。**レシートや購入時期が分かるもの**があると計算が明確になります。**高価な品は受付時に申告し、保険や特別料金の有無を確認**します。

## 誤解3｜受け取ったビニールは家に帰ってから開ける

**受け取り後6か月を過ぎると申し出が難しくなります**が、実際には**その場で確認するのが最も確実**です。**ビニールは湿気を閉じ込めるので、家でも外します**。

## 誤解4｜ドライクリーニングなら何でも安全

ドライ（石油系・フッ素系溶剤）は**水洗いより縮みにくい**一方で、**汗などの水溶性の汚れは落ちにくく**、**接着剤・プリント・ボタンの一部が溶剤で傷む**ことがあります。表示の**円の記号（P/F）**が可否です。

## 誤解5｜トラブルは泣き寝入りしかない

**まず店に申し出、解決しなければ消費生活センター（188）に相談**できます。**業界の賠償基準**があり、多くの店がそれに基づいて対応します。
