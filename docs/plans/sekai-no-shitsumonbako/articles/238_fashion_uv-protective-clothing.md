# Q. UVカット衣類と日傘について、よくある誤解は？｜世界の質問箱 #238

- 棚：`fashion` ／ URL：`/questions/uv-protective-clothing` ／ ステータス：**ドラフト（法務レビュー前・出典未検証）**

日本の夏に日傘と長袖のUVカットウェアが多いのは、海外からも「なぜ暑いのに長袖なのか」と問われます。紫外線を布で防ぐことの効果には数値の指標があり、日焼け止めとの使い分けが公的資料で整理されています。

## A. 最大の誤解は「日焼け止めを塗れば衣類や日傘は要らない」です。環境省のマニュアルは、紫外線対策の基本を「日陰を利用する・帽子・衣類・日傘・サングラス・日焼け止め」の組み合わせとし、衣類と日傘は塗り直しの要らない確実な手段です。生地の紫外線遮蔽率は表示で分かります。

## 数字で見る

| 指標 | 内容 |
|---|---|
| **紫外線遮蔽率** | 布が紫外線を遮る割合（%）。**90%以上**で「UVカット」をうたう製品が多い。**JIS L1925**で測定 |
| UPF（海外の指標） | UPF15〜50+。**UPF50＝紫外線の1/50（2%）が透過** |
| 日傘 | **黒などの濃色・遮光率99%以上**の製品は、頭部への紫外線をほぼ遮る。**照り返しは防げない** |
| 普通の白いTシャツ | 紫外線遮蔽率**約80%**。**濡れると下がる** |
| 帽子 | **つば7cm以上**で顔への紫外線を**約60%**減らす（環境省マニュアル） |

- 環境省「紫外線環境保健マニュアル」は、**UVインデックス3以上で対策**、**8以上で日中の外出を控える**ことを目安としています。日本の夏は**UVインデックス8〜10**に達します。
- **色が濃く、織りが密で、厚い生地**ほど遮蔽率は高い。**ポリエステルは綿より紫外線を通しにくい**とされます。
- **「UVカット加工」は洗濯で徐々に落ちる製品**と、**繊維に練り込んで落ちない製品**があります。表示で確認します。
- **日傘の遮光率と遮熱**は別で、**遮光率99%でも日傘の下は涼しくはならない**が、**直射日光を遮ることで体感温度は下がる**（熱中症対策として環境省も推奨）。

> 【要検証】遮蔽率の測定法はJIS L1925、UVインデックスの目安は環境省マニュアル2020で確認してください。数値は一般的な目安です。

## 誤解1｜長袖は暑いだけで意味がない

**UVカットの長袖は、日焼け止めの塗り直しなしで確実に遮ります。** 薄手・通気性のある素材なら、直射日光が肌に当たらないため**日なたでは半袖より涼しく感じる**ことも多いです。

## 誤解2｜白い服のほうが涼しくて紫外線も防ぐ

**白は熱を反射しますが、紫外線は濃色より通しやすい**傾向があります。**「涼しさ」と「遮蔽」は別**で、UVカット加工の有無を見ます。

## 誤解3｜日傘は女性のもの

環境省は**熱中症対策として男性の日傘使用**を推奨しています（2019年〜の啓発）。日傘の下の**体感温度は数℃下がる**とされます。

## 誤解4｜UVカット加工は洗っても落ちない

**後加工タイプは洗濯で徐々に低下**します。表示に「洗濯○回まで」等の記載があるものも。**繊維練り込みタイプ**は落ちにくい。

## 誤解5｜日傘があれば日焼け止めは不要

**地面や壁からの照り返し（反射）は日傘では防げません**（砂浜で**10〜25%**、水面で**10〜20%**、雪で**80%以上**が反射）。**露出部には日焼け止め**を組み合わせるのが環境省マニュアルの考え方です。
