# Q. 關於抗UV衣物與陽傘，人們常有什麼誤解？｜Japan Questions #238

- Shelf: `fashion` ／ URL: `/zh-tw/fashion/uv-protective-clothing` ／ Status: **草稿 — 出處未核實**

夏天來日本的旅客常問：為什麼這麼熱還有這麼多人撐陽傘（「日傘」，higasa）、穿長袖的抗UV衣物？用布料阻擋紫外線是有可測量效果的，日本環境省也說明了衣物、陽傘與防曬乳之間該如何搭配。

## A. 最大的誤解是「擦了防曬乳就不需要衣物與陽傘了」。環境省的手冊把基本的紫外線防護描述為一個組合：利用陰涼處、帽子、衣物、陽傘、太陽眼鏡與防曬乳。衣物與陽傘是可靠的那一部分，因為它們不需要補擦。布料的紫外線遮蔽率會印在標籤上。

## 用數字來看

| 指標 | 內容 |
|---|---|
| **紫外線遮蔽率（紫外線遮蔽率）** | 布料阻擋紫外線的百分比。以「UV cut」名義販售的產品多數標稱 **90% 以上**。依 **JIS L1925** 測定 |
| UPF（國外使用的指標） | UPF 15～50+。**UPF 50 ＝ 紫外線的 1/50（2%）穿透** |
| 陽傘 | **黑色等深色、遮光率 99% 以上**的產品，能擋住幾乎所有到達頭部的紫外線。**但擋不住地面反射的紫外線** |
| 普通的白色 T 恤 | 紫外線遮蔽率**約 80%**。**濕掉之後會下降** |
| 帽子 | **帽簷 7cm 以上**可讓照到臉部的紫外線減少**約 60%**（環境省手冊） |

- 環境省《紫外線環境保健手冊》給出的參考標準是：**紫外線指數（UV Index）3 以上就要採取防護措施**，**8 以上則避免在中午時段外出**。日本的夏天可達到**紫外線指數 8～10**。
- **顏色越深、織得越密、布料越厚**，遮蔽效果越好。**一般認為聚酯纖維比棉更不易穿透紫外線。**
- **有些「UV cut 加工」產品的效果會隨著清洗逐漸減弱**；**另一些則把功能劑做進纖維裡，不會減弱。** 請看標籤。
- **陽傘的遮光率與遮熱是兩回事**：**即使遮光率 99%，傘下的空氣也不會變涼**，但**擋住直射陽光能降低體感溫度**（環境省也把陽傘當作中暑對策來推薦）。

> **[待核實]** 測定方法請對照 JIS L1925，紫外線指數的參考標準請對照環境省手冊（2020 年版）。這些數值是一般性的參考。

## 誤解1｜長袖只是熱，沒有意義

**抗UV的長袖不必補擦防曬乳就能可靠地遮擋。** 若是輕薄透氣的布料，因為直射陽光完全照不到皮膚，**很多人覺得在烈日下比短袖更涼快**。

## 誤解2｜白色衣服既涼快又能防紫外線

**白色反射熱量，但往往比深色更容易穿透紫外線。** **「涼快」與「遮蔽」是兩回事**，請找有 UV cut 加工的產品。

## 誤解3｜陽傘是女性用的

環境省**把陽傘當作中暑對策向男性推薦**（2019 年起的宣導）。一般認為**陽傘下的體感溫度會低幾攝氏度**。

## 誤解4｜UV cut 加工洗不掉

**表面塗層加工會隨著清洗逐漸減弱。** 有些標籤會寫明「可洗 ○ 次」。**做進纖維裡的加工**則耐久得多。

## 誤解5｜有了陽傘就不需要防曬乳

**陽傘擋不住從地面或牆面反射回來的紫外線**（沙地反射 **10～25%**，水面 **10～20%**，雪地 **80% 以上**）。環境省手冊的做法是：**撐傘的同時，在裸露的皮膚上擦防曬乳**。
