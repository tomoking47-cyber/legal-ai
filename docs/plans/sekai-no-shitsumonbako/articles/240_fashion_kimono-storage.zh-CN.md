# Q. 关于和服的保管，人们常有什么误解？｜Japan Questions #240

- Shelf: `fashion` ／ URL: `/zh-cn/fashion/kimono-storage` ／ Status: **草稿 — 出处未核实**

和服常被说成是可以代代相传的东西，但那要看保管得好不好。如今在日本买浴衣或和服的游客越来越多，“该怎么收起来？”成了从海外提出的问题。以下是为日本潮湿的气候而形成的传统保管知识。

## A. 最大的误解是“和服放进衣柜就能保存几十年”。丝质和服怕潮、怕虫、怕光。它需要每年一到两次的晾晒通风（虫干し，mushiboshi），每隔几年更换一次包装纸（たとう紙，tatōshi），以及谨慎使用防虫剂。穿过之后，先用和服衣架挂几个小时到一晚上，把湿气散出去，再叠起来收好。

## 保管的基本

| 要点 | 做法 | 原因 |
|---|---|---|
| 穿过之后 | **用和服衣架挂一晚（避开阳光直射）**，把汗和湿气散出去。**用刷子或软布掸掉灰尘** | 湿气会导致发霉和变色 |
| 折叠 | **本畳み**（本たたみ，沿着缝线的标准折法） | 折痕落在缝线上，所以看不出折印 |
| 包装 | 用**たとう紙**（和纸包装纸）包好。**每 1～3 年更换一次**（或一发黄就换） | 透气又防潮。旧的たとう紙会带湿气 |
| 放在哪里 | **桐木（桐，kiri）衣柜或透气的衣物箱**。**若用塑料收纳箱，请加干燥剂**。和服专用的干燥剂和防虫剂**不得接触布料** | 桐木调节湿度的能力好 |
| **晾晒通风（虫干し）** | **每年 1～2 次**（10～11 月连续晴天之后，或 1～2 月），**在通风良好的室内放半天到一天** | 排出湿气，同时检查有无虫蛀和霉 |
| 防虫剂 | **只用一种**，放在**衣物上方**。**对二氯苯（パラジクロロベンゼン）可能使金线、银线和箔变色** | 混用会溶化并留下污渍 |

- 丝是**动物性蛋白质**：会因**汗（氧化后变碱性）、皮脂和潮气**而发黄，也会被**衣蛾和皮蠹**啃食。
- **出汗的日子穿过的和服需要「汗抜き」（asenuki，去汗，和服专门店的一道工序）。** **一般认为，只做整件干洗（丸洗い，maruarai）会把汗的成分留在衣料里。**
- **衣柜上层的抽屉干燥，下层的抽屉容易积潮气。** 通常的做法是**丝绸放上层，棉麻放下层**。

> **[待核实]** 晾晒通风的时机与频率、たとう紙的更换周期，是根据和服业界与和服相关团体的建议整理的一般性参考。

## 误解1｜包进たとう紙就一直安全了

**たとう紙会吸潮、发黄，几年就到了使用寿命。** **发黄或有污渍时就换。** **绝对不要用塑料袋**（会闷住湿气）。

## 误解2｜脱下来马上叠好收起来

**带着汗和湿气叠起来，会导致发霉和发黄。** **挂一晚上让它干透**是基本原则。

## 误解3｜防虫剂放得多、放几种更放心

**混用不同种类会溶化并留下污渍**，而且**对二氯苯类可能使金线和箔变色**。**只用一种，按规定用量，放在衣物上方。**

## 误解4｜晾晒通风太麻烦，可以省略

**每年 1～2 次的晾晒通风，正是丝质和服能保存几十年的前提。** 一般认为，**只是打开衣柜抽屉、用电风扇通风**也有一定效果。

## 误解5｜棉质浴衣和和服的处理方式一样

**棉质浴衣可以在家清洗**（请看标签）。**洗好、完全晾干、叠好收起来。** 这和丝质和服是两回事：需要留心的是**潮气和发黄，而不是虫蛀**。
