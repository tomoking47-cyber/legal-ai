# Q. 時差ぼけについて、よくある誤解は？｜世界の質問箱 #241

- 棚：`health` ／ URL：`/questions/jet-lag` ／ ステータス：**ドラフト（法務レビュー前・出典未検証）**

時差ぼけは海外旅行者に共通の悩みで、日本と欧米の間では8〜14時間の時差があります。厚生労働省の睡眠ガイドが示す「体内時計は光と食事で動く」という考え方から、実践的な対策を整理します。

## A. 最大の誤解は「機内で寝れば時差ぼけは防げる」です。時差ぼけは体内時計と現地時刻のずれで、調整の主役は現地の朝の光と食事の時刻です。目安として、体内時計は1日に1〜1.5時間程度しか動かないため、時差の大きさによっては数日かかります。

## 数字で見る

| 項目 | 内容 |
|---|---|
| 体内時計の周期 | **約24時間より少し長い**（平均24時間10分前後）。**朝の光で毎日リセット** |
| 調整の速さ | **1日に約1〜1.5時間**。東京→ロンドン（8〜9時間差）なら**数日〜1週間** |
| 東向き（時間を進める）と西向き（遅らせる） | **東向きのほうがつらい**（体内時計は遅らせるほうが得意） |
| 光の使い方 | **現地の朝に強い光**を浴び、**現地の夜は光を避ける**（サングラス、画面の明るさ） |
| 食事 | **現地の朝食時刻に食べる**と、末梢の体内時計が動く |
| 昼寝 | **午後早め、30分以内**。長い昼寝は調整を遅らせる |

- 厚生労働省「健康づくりのための睡眠ガイド2023」は、**朝の光と規則的な食事・起床時刻**を体内時計の調整の基本としています。
- **メラトニン**は日本では**医薬品扱い**（小児用の処方薬のみ承認）で、**サプリメントとしての国内販売はありません。** 海外で購入したものの個人輸入は、**2か月分まで**などの規制があります（医薬品の持ち込みの記事を参照）。

> 【要検証】体内時計の調整速度は睡眠医学の一般的な記載です。メラトニンの国内の位置づけは厚生労働省の資料で確認してください。

## 誤解1｜機内でたくさん寝れば防げる

**寝る時刻を現地に合わせる**ことに意味があり、**単に長く寝ても体内時計は動きません。** 到着が朝なら機内で寝る、到着が夜なら機内では起きている、が目安です。

## 誤解2｜到着したら昼寝で回復

**長い昼寝や夕方以降の昼寝は、現地の夜に眠れなくなり、調整を遅らせます。** どうしても眠いなら**午後早めに30分以内**。

## 誤解3｜アルコールで寝つけば時差ぼけも軽い

**アルコールは睡眠の後半を浅くし、脱水も進めます。** 機内の乾燥と重なり、到着後の疲労を増します。

## 誤解4｜出発前に現地時刻に合わせるのは無理

**出発の2〜3日前から、就寝・起床を1時間ずつ現地方向にずらす**方法は、体内時計の性質に沿った対策です。とくに**東向きの旅行**で効果があるとされます。

## 誤解5｜若ければ時差ぼけはしない

**年齢とともに調整は遅くなる**傾向がありますが、若い人も影響を受けます。**旅行の初日に重要な予定を入れない**のが、日本の出張者の間で共有された工夫です。
