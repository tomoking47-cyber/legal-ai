# Q. 關於半夜醒來，人們常有哪些誤解？｜Japan Questions #243

- Shelf: `health` ／ URL: `/zh-tw/health/waking-in-the-night` ／ Status: **草稿 — 出處未核實**

「半夜醒過來就再也睡不著」是一種隨年齡增長而增加的困擾，也是各國論壇上最常見的睡眠問題之一。以下依據日本厚生勞動省（厚生労働省）發布的睡眠指南，以及睡眠醫學的一般看法來整理。

## A. 最大的誤解是「半夜醒來是不正常的」。睡眠以約 90 分鐘為週期反覆經過淺眠階段，短暫的醒來人人都有。會成為問題的是醒來後睡不著，或是白天因此受到影響。基本的對策是：不看時鐘、不在床上待太久、睡前避免酒精與咖啡因。

## 需要考慮的事

| 項目 | 內容 |
|---|---|
| 睡眠週期 | 深眠與淺眠（快速動眼睡眠）以**約 90 分鐘**為週期交替。**在週期的接縫處最容易醒來** |
| 年齡的影響 | **深眠減少、醒來增加**是自然的變化。**所需的睡眠時間也會變短**（一般認為高齡者 6 小時左右即可） |
| 半夜醒來的主要原因 | **睡前飲酒、咖啡因、夜間排尿、打鼾或呼吸中止、臥室的溫度、光線與噪音、壓力、在床上待得太久** |
| 醒來之後 | **不要看時鐘**；**如果 15～20 分鐘還睡不著，就離開床鋪**（在暗的房間裡安靜地待著，想睡了再回去） |
| 就醫的標準 | **每週 3 次以上、持續 3 個月以上**，並伴有**白天嗜睡等不適**（失眠症的一般定義） |

- 厚生勞動省《健康促進睡眠指南 2023》[健康づくりのための睡眠ガイド2023] 建議**不要讓待在床上的時間超過需要**，並建議**高齡者待在床上的時間不超過 8 小時**。**待在床上的時間越長，淺眠與醒來就越多。**
- **夜間排尿**是醒來的主因之一，檢視**睡前的水分、酒精與咖啡因**後可能會改善。**若經常發生，請至泌尿科（泌尿器科，hinyōkika）就診。**

> **[待核實]** 請核對《睡眠指南 2023》的敘述，以及失眠症的定義（日本睡眠學會）。

## 誤解1｜正常就該一覺睡滿八小時

**短暫的醒來在正常範圍之內。** **只要能再次入睡，就沒有問題。** 為「中斷」本身擔心，反而更難入睡。

## 誤解2｜早點上床就能睡得久

**當待在床上的時間超過所需的睡眠時，睡眠會變淺，醒來會增加。** 等到想睡了再上床。

## 誤解3｜醒來時用手機確認時間

**看時鐘會帶來「只剩 X 小時了」的慌張，螢幕的光還會讓人更清醒。** 把時鐘放在看不見的地方。**原則是不要把清醒的時間花在床上。**

## 誤解4｜是年紀的關係，沒辦法

**年齡確實有影響**，但**酒精、咖啡因、臥室環境與待在床上的時間**都是可以改變的。**打鼾、呼吸中止與頻繁的夜間排尿**則要交給醫師。

## 誤解5｜吃市售的助眠藥就能解決

日本市售的助眠藥（睡眠改善薬，suimin kaizen-yaku，在藥妝店販售，以抗組織胺成分為基礎）**適用於一時性的失眠**，**不建議連續服用。** **持續 3 個月以上的失眠要交給醫師處理。**
