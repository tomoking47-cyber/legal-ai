# Q. 体重の測り方について、よくある誤解は？｜世界の質問箱 #248

- 棚：`health` ／ URL：`/questions/weighing-yourself` ／ ステータス：**ドラフト（法務レビュー前・出典未検証）**

体重計は最も身近な健康機器ですが、「いつ測るか」「毎日測るべきか」「体脂肪率は信じてよいか」は各国で問われます。日本の家庭用体重計（体組成計）の普及を踏まえて整理します。

## A. 最大の誤解は「体重は1日のどこで測っても同じ」です。体重は1日で1〜2kg変動し、体脂肪率の家庭用推定は水分の状態で数%ずれます。同じ条件（朝、排尿後、朝食前、同じ服装）で毎日測り、日々の数字ではなく週単位の傾向を見ることが基本です。

## 判断の材料

| 項目 | 内容 |
|---|---|
| 1日の変動 | **約1〜2kg**（食事・水分・排泄・発汗） |
| 測る条件 | **朝、起床後・排尿後・朝食前**、同じ服装（下着）、**同じ体重計を同じ床（硬い平面）に** |
| 頻度 | **毎日**が、体重管理では変化に気づきやすいとされる。**日々の上下は気にせず週平均**を見る |
| 家庭用体脂肪率（インピーダンス法） | **体の水分量で数%変わる**。入浴後・運動後・食後は避ける。**同条件での推移**だけを見る |
| BMI | **体重(kg)÷身長(m)²**。日本の基準：**18.5未満やせ、18.5〜25未満普通、25以上肥満** |
| 目標 | 健康日本21（第三次）は**BMI 18.5〜24.9の人の割合**を目標に。**やせ（とくに若年女性・高齢者）も課題** |

- 家庭用体組成計は**「体重計」としてはJIS規格・計量法の対象**、体脂肪率などは**推定値**で医療機器ではありません。
- **国民健康・栄養調査**では、**20代女性のやせ（BMI18.5未満）の割合が約2割**で推移し、国の課題として挙げられています。**高齢者の低栄養**も同様です。

> 【要検証】BMIの区分は日本肥満学会の基準、やせの割合は国民健康・栄養調査の最新年で確認してください。

## 誤解1｜昨日より1kg増えたから太った

**1日の変動の範囲**です。**塩分の多い食事・水分・便通**で動きます。**1週間の平均**で判断します。

## 誤解2｜体脂肪率は正確な数字

家庭用は**推定値**です。**水分の状態で数%ずれる**ため、**同じ条件で測った推移**だけを見ます。

## 誤解3｜体重計は毎日乗ると気になりすぎるから月1回

**体重管理の研究では、毎日または週数回の測定が変化への気づきに有効**とされます。**数字に一喜一憂しない見方（週平均）**が前提です。

## 誤解4｜BMIが低ければ健康

**やせ（BMI18.5未満）は、骨量の低下・月経不順・低栄養**などのリスクと関連し、国の健康目標でも課題です。**「痩せているほどよい」は公的な見解ではありません。**

## 誤解5｜体重計はどこに置いても同じ

**カーペットや畳の上では正確に測れません。** **硬く平らな床**で。**電池の消耗**でもずれます。
