# Q. ヨーグルトの保存と開封後について、よくある誤解は？｜世界の質問箱 #252

- 棚：`trend` ／ URL：`/questions/storing-yogurt` ／ ステータス：**ドラフト（法務レビュー前・出典未検証）**

ヨーグルトは「発酵食品だから期限を気にしなくてよい」と思われがちな食品の代表です。開封後の扱い、表面の水、賞味期限切れの判断について、表示の仕組みから整理します。

## A. 最大の誤解は「ヨーグルトは発酵しているから腐らない」です。乳酸菌が多くても、開封後は空気中の菌やカビが入り、大容量パックは2〜3日で食べきるのが目安です。表面の透明な水（ホエイ）は栄養を含む正常な成分で、捨てる必要はありません。

## 判断の材料

| 項目 | 内容 |
|---|---|
| 保存 | **冷蔵（10℃以下）**。ドアポケットは温度が上がりやすいので避ける |
| 未開封の賞味期限 | 製造から**2〜3週間**が多い。**未開封で冷蔵なら、期限を数日過ぎても食べられることが多い**（状態を確認） |
| 開封後（大容量400g等） | **2〜3日**。**清潔なスプーンで取り分け、直接食べない** |
| 表面の水 | **ホエイ（乳清）**。たんぱく質・カルシウムを含む。**混ぜて食べる** |
| 処分のサイン | **酸味が強すぎる、苦味、ピンク・黒・緑の斑点（カビ）、膨らんだふた、アルコール臭** |
| 冷凍 | 可だが**食感が変わる**（分離）。フローズンヨーグルトとして食べる方法はある |

- ヨーグルトの多くは**「発酵乳」**（乳等命令〈旧・乳等省令〉で**無脂乳固形分8.0%以上・乳酸菌数または酵母数1mL中1,000万以上**）として表示されます。
- **「生きて腸まで届く」**などの表現は、**機能性表示食品・特定保健用食品（トクホ）**の許可・届出を受けた製品に限られ、**一般のヨーグルトでは表現できません**（健康増進法・景表法）。
- **賞味期限は「おいしく食べられる期限」**で、消費期限とは異なります（期限表示の記事を参照）。

> 【要検証】発酵乳の規格は「乳及び乳製品の成分規格等に関する省令」で、開封後の目安はメーカーの表示・Q&Aで確認してください。

## 誤解1｜表面の水は腐った証拠

**ホエイ**です。**捨てると栄養が減ります。** 混ぜるか、そのまま食べます。**水が濁って酸っぱいにおいが強い**場合は別です。

## 誤解2｜賞味期限を1日過ぎたら捨てる

**未開封・冷蔵なら、数日過ぎても食べられることが多い**です。**見た目・におい・味**で判断します。**開封後は期限に関係なく2〜3日**。

## 誤解3｜スプーンで直接食べて、残りを冷蔵庫へ

**口に触れたスプーンから菌が入り、劣化が早まります。** **取り分けてから**。

## 誤解4｜ヨーグルトを食べれば腸が整う、と言ってよい

**特定の効果は、許可・届出を受けた製品の表示に限られます。** 一般食品として「発酵食品の一つ」と位置づけるのが法律上の範囲です。

## 誤解5｜どのヨーグルトも同じ菌

**製品ごとに菌種が異なります**（ブルガリア菌・サーモフィルス菌・ビフィズス菌・ガセリ菌 等）。**合う・合わないは個人差**で、**続けやすいもの**を選ぶのが実践的です。
