# Q. オーブントースターの使い方について、よくある誤解は？｜世界の質問箱 #258

- 棚：`trend` ／ URL：`/questions/toaster-oven-safety` ／ ステータス：**ドラフト（法務レビュー前・出典未検証）**

オーブントースターは日本の台所に最も普及した調理家電の一つで、パンだけでなくグラタン・餅・冷凍食品に使われます。「アルミホイルは入れてよいか」「何が燃えるのか」という質問は多く、NITEは毎年事故を報告しています。

## A. 最大の誤解は「トースターは弱い熱源だから何を入れても安全」です。トースターのヒーターは数百℃で、食品の油やパンくずが接触すると発火します。基本は「受け皿のパンくずをこまめに捨てる」「油の多い食品はホイルや皿で受ける」「バターやマーガリンを塗ったパンは飛び散りに注意」「使用中は離れない」です。

## 判断の材料

| 項目 | 内容 |
|---|---|
| ヒーターの温度 | **石英管・ハロゲンヒーターは表面が数百℃**。**触れた食品・紙・ホイルの油は発火**しうる |
| **パンくず** | 受け皿にたまったくずと油が**発火の最も多い原因**（NITE）。**週1回は掃除** |
| **アルミホイル** | **使用可の機種が多い**が、**ヒーターに触れない・受け皿を覆わない**（熱がこもる）。**説明書で確認** |
| 餅 | **膨らんでヒーターに触れる**と発火。**低い位置・網の中央・目を離さない** |
| 紙・クッキングシート | **耐熱温度（多くは250℃）を超えると燃える**。**トースター使用不可と表示された製品あり** |
| 油の多い食品（ベーコン・から揚げ） | **油が落ちてヒーターに触れる**。**皿・ホイルで受ける** |
| 電源 | **消費電力1,000〜1,400W**。**延長コード・タコ足は避ける** |

- 製品評価技術基盤機構（NITE）には**オーブントースターの発火・発煙事故**が継続的に報告され、**「パンくずの蓄積」「餅や食品のヒーター接触」「使用中の放置」**が主な原因です。
- **電気用品安全法（PSE）**の対象製品で、**取扱説明書の禁止事項**（入れてはいけないもの）は製品ごとに異なります。

> 【要検証】事故の原因分類はNITEの製品事故情報で確認してください。ホイル・シートの可否はお使いの機種の取扱説明書に従ってください。

## 誤解1｜アルミホイルはトースターに入れてはいけない

**多くの機種で使用可**です。禁止されているのは、**ヒーターに触れる置き方**と**受け皿全体を覆うこと**。**電子レンジと混同**されがちですが、トースターは電熱なので金属自体は問題ありません。**説明書を確認**。

## 誤解2｜パンくずは焦げるだけで危なくない

**油を含んだくずが炭化して発火**するのが典型です。**受け皿は引き出して捨て、週1回は拭く**。

## 誤解3｜餅は焼き網にのせれば安全

**膨らんで上のヒーターに触れる**と燃えます。**アルミホイルの上・網の中央・目を離さず**、**膨らんだら一度扉を開けて確認**。

## 誤解4｜タイマーをセットすれば離れてよい

**タイマー中に発火した事例**があります。**数分の調理は目の届く範囲で**。

## 誤解5｜古いトースターも壊れるまで使える

**ヒーターの劣化、扉のガラスのひび、コードの傷み**は事故につながります。**異音・異臭・扉が閉まらない**は買い替えの目安。**リコール情報**（消費者庁リコール情報サイト）も確認します。
