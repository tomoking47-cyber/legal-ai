# Q. 關於小烤箱（烤麵包機）的使用，人們常有哪些誤解？｜Japan Questions #258

- Shelf: `trend` ／ URL: `/zh-tw/trend/toaster-oven-safety` ／ Status: **草稿 — 出處未核實**

小烤箱（「オーブントースター」，ōbun tōsutā）是日本廚房最普及的烹調家電之一，不只用來烤麵包，也用來做焗烤、烤麻糬（「餅」，mochi）和加熱冷凍食品。搬到日本住的話，租屋處多半就有一台。「可以放鋁箔紙嗎？」「到底是什麼東西會燒起來？」是常見的問題，而 NITE（日本製品評價技術基盤機構）每年都會報告這類事故。

## A. 最大的誤解是「小烤箱熱源弱，放什麼進去都安全」。加熱管的溫度有數百度，食物上的油脂或麵包屑一接觸就會起火。基本做法是：定期倒掉集屑盤裡的屑，油多的食物用鋁箔紙或盤子接著，塗了奶油或乳瑪琳的麵包要注意噴濺，使用中不要離開。

## 判斷的依據

| 項目 | 內容 |
|---|---|
| 加熱管的溫度 | **石英管、鹵素加熱管的表面溫度有數百度**。**沾了油脂的食物、紙或鋁箔碰到就可能起火** |
| **麵包屑** | 積在集屑盤裡的屑與油脂是**最常見的起火原因**（NITE）。**每週清理一次** |
| **鋁箔紙** | **多數機型可以使用**，但**不可碰到加熱管，也不可蓋住整個集屑盤**（熱氣會悶住）。**請查看說明書** |
| 麻糬（「餅」，mochi） | **膨脹後碰到加熱管**就會起火。**放低位、放在網架中央、不要移開視線** |
| 紙與烘焙紙 | **超過耐熱溫度（多為 250℃）就會燒起來**。**有些產品標明「不可用於小烤箱」** |
| 油多的食物（培根、日式炸雞「から揚げ」） | **油脂滴到加熱管上**。**用盤子或鋁箔接住** |
| 電源 | **耗電 1,000〜1,400 W**。**避免使用延長線與多孔插座** |

- NITE **持續收到小烤箱起火、冒煙的事故通報**，主要原因是**「麵包屑堆積」「麻糬等食物碰到加熱管」「使用中放著不管」**。
- 小烤箱屬於**電氣用品安全法（PSE 標示）**的對象產品，而**說明書上的禁止事項**（不可放入的東西）因機型而異。

> **[待核實]** 事故原因的分類請對照 NITE 的產品事故資訊確認。鋁箔與烘焙紙能否使用，請依您所使用機型的說明書。

## 誤解1｜絕對不能把鋁箔紙放進小烤箱

**多數機型是可以用的。** 被禁止的是**擺放成會碰到加熱管的位置**，以及**蓋住整個集屑盤**。大家**常與微波爐搞混**；小烤箱靠電熱加熱，所以金屬本身並不是問題。**請查看說明書。**

## 誤解2｜麵包屑只是烤焦，不危險

**吸了油的麵包屑會碳化並起火**，這正是典型的事故。**把集屑盤抽出來倒乾淨，每週擦一次。**

## 誤解3｜麻糬放在網架上很安全

**麻糬膨脹後會碰到上方的加熱管**而燒起來。**請放在鋁箔上、網架中央，並持續看著**；**一膨脹起來就打開門確認。**

## 誤解4｜設好計時器就可以走開

**有在計時器運轉期間起火的案例。** **加熱的這幾分鐘，請待在看得到的地方。**

## 誤解5｜舊的小烤箱只要還能用就沒問題

**加熱管老化、門玻璃有裂痕、電線破損**都可能引發事故。**異音、異味、門關不上**都是該換掉的訊號。也請查看**召回（回收）資訊**（消費者廳的召回資訊網站）。
