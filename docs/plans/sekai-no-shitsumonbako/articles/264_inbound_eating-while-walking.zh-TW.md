# Q. 關於在日本邊走邊吃，大家常有哪些誤解？｜Japan Questions #264

- Shelf: `inbound` ／ URL: `/zh-tw/questions/eating-while-walking` ／ Status: **草稿 — 出處未核實**

「在日本邊走邊吃很不禮貌」這個說法被當成了絕對的鐵律。它更接近於少數幾條街道上的地方條例，以及其他地方的一種普遍偏好——而且它與一個事實相衝突：日本的街頭小吃比以往任何時候都多。

## A. 最常見的誤解是邊走邊吃在任何地方都被禁止。在擁擠的商店街它不受歡迎，少數幾個觀光區（鎌倉的小町通自 2019 年起，京都錦市場的部分區域）有地方條例或張貼的告示勸阻這種行為——主要原因是垃圾和弄髒和服。可行的規則是：買了之後站到一旁，在買的地方吃完，包裝也在那裡處理掉。

## 規矩——如果算得上規矩的話

| 場合 | 慣例 |
|---|---|
| **商店街和市場** | **站在賣給你的攤位旁邊**吃；攤位會收回包裝。許多地方現在貼有「禁止邊走邊吃」的標示 |
| **鎌倉小町通** | **市條例（2019 年 4 月）**請旅客避免邊走邊吃——是請求，沒有罰款 |
| **京都錦市場** | 店家請顧客當場食用；自 2019 年起有「禁止邊走邊吃」的標示 |
| **祭典（祭り）** | 在小吃攤之間邊逛邊吃是**正常的** |
| **電車** | 一般電車：不行。**新幹線和長途特急：可以**，鐵路便當（駅弁）正是為此而生 |
| **一般街道** | 冰淇淋或飲料沒問題；一頓正餐會引來目光 |

- 現實原因：**公共垃圾桶很少**（參見垃圾桶一文）、**人多擁擠**，以及**和服租借旅客和店主對汙漬的投訴**。
- **便利商店**越來越多地設有**內用區**，正是為了這個需求；在店內用餐還會使稅率變為 10%（參見消費稅一文）。

> **[待核實]** 鎌倉條例的日期和措辭請向鎌倉市核對；錦市場的請求請向市場振興組合核對。

## 誤解1｜這是全國性法律

它是**少數幾個地方的地方條例，在其他地方則是一種社會慣例**。沒有人會被罰款；你可能會被請求停下來。

## 誤解2｜所以街頭小吃很少

日本的**街頭小吃比以往任何時候都多**——市場、祭典、車站小吃。慣例是**在買的地方吃**。

## 誤解3｜在任何電車上吃東西都沒問題

**通勤電車，不行**（擠滿人的車廂裡的氣味和碎屑）。**新幹線和有指定席的特急，可以**——鐵路便當（駅弁）就是為此而存在的。

## 誤解4｜隨便找張長椅就行

商業區的長椅很少。**公園、車站候車區、百貨公司的休息角落和便利商店的內用區**才是合適的地方。

## 誤解5｜這條規矩只關乎禮貌

它主要關乎**垃圾**。如果你在某處吃了東西，**把包裝拿回給賣家，或自己帶走**——垃圾桶很少，正是垃圾問題把一項慣例變成了條例。
