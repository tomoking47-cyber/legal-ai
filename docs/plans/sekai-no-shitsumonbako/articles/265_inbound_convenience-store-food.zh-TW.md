# Q. 關於便利商店食品和御飯糰，大家常有哪些誤解？｜Japan Questions #265

- Shelf: `inbound` ／ URL: `/zh-tw/questions/convenience-store-food` ／ Status: **草稿 — 出處未核實**

日本的便利商店食品享有全球聲譽，而且大多名副其實。旅客沒看到的是這套系統如何運作——每日配送、嚴格的日期標示、加熱櫃台、御飯糰包裝——以及什麼才是真正最划算的。

## A. 最常見的誤解是便利商店食品只是沒得選時的備案。這些食品每天最多配送三次，日期標示精確到小時，並被設計成在此之前食用；店員會為你加熱任何東西；御飯糰的包裝則是一件小小的設計品，在你拉開拉條之前一直讓海苔保持酥脆。真正的價值在於新鮮的冷藏貨架，而不是零食。

## 它是如何運作的

| 項目 | 細節 |
|---|---|
| 店鋪數 | 全國**約 56,000 家**；三大巨頭（7-Eleven、FamilyMart、Lawson）占約 90% |
| 配送 | 冷藏食品**每天 2–3 次**；御飯糰和便當標有**精確到時刻的消費期限**（消費期限） |
| 御飯糰 | **¥150–300**（2024–25 年價格大幅上漲；部分高級款超過 ¥300）；**三段式包裝**讓海苔與米飯分開——先把拉條 1 沿中間向下拉開，再把 2 和 3 向兩側拉開 |
| 加熱 | **「温めますか？」（atatamemasu ka，要加熱嗎？）**——在收銀台免費加熱；便當約 1–2 分鐘即可 |
| 熱食櫃台 | 收銀台旁的炸雞、可樂餅、關東煮（冬季） |
| 內用 | 許多店有內用區；**在店內用餐會使稅率變為 10%** |
| 折扣 | 部分連鎖店在晚間為**即期商品貼上 20–30% 折扣標籤** |

- 用漢字印在包裝上的常見御飯糰內餡：**鮭（鮭魚）、ツナマヨ（鮪魚美乃滋）、梅（梅乾）、昆布（昆布）、おかか（柴魚）、明太子（明太子）、高菜（醃芥菜）、赤飯（紅豆飯）**。
- **冷藏麵類、沙拉和三明治**在專門的工廠製作，**保存期限約 24–48 小時**——這就是它們吃起來新鮮的原因。
- 便利商店的**食物浪費**是一個公認的問題；自 2019 年以來，各連鎖店延長了部分商品的保存期限，並推出了晚間降價。

> **[待核實]** 店鋪數量請向日本連鎖加盟協會（Japan Franchise Association）核對；價格為 2025 年的區間。

## 誤解1｜這是垃圾食物

貨架上占主導的是**米飯、魚、蔬菜、豆腐、沙拉和湯**。零食區確實存在，但那不是重點。

## 誤解2｜日期標示只是個建議

御飯糰和便當標有**消費期限（消費期限）的日期和時刻**。請在此之前吃完。店員會在印刷的時刻**把商品從貨架上撤下**。

## 誤解3｜只能吃冷的

**請要求加熱**——任何便當、義大利麵或咖哩都可以。店員會用為包裝校準過的商用微波爐加熱。御飯糰也可以加熱（部分品項有相應標示）。

## 誤解4｜御飯糰包裝是個謎題

包裝上印有數字 **1、2、3**。**把 1 筆直向下拉**撕開薄膜，**然後把 2 和 3 向外拉**。這樣海苔就夾在米飯和你的手之間——酥脆。

## 誤解5｜價格和超市一樣

同類商品**大約貴 20–40%**（參見超市一文）。你付的是營業時間和地點的錢；只吃一頓午餐的話，這點差別無關緊要。
