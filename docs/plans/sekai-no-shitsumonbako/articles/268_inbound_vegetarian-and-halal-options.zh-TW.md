# Q. 關於日本的素食、純素與清真飲食，大家常有哪些誤解？｜Japan Questions #268

- Shelf: `inbound` ／ URL: `/zh-tw/questions/vegetarian-and-halal-options` ／ Status: **草稿 — 出處未核實**

日本看起來對蔬食很友善——豆腐、米飯、海藻——然後幾乎每道菜裡都放了魚湯。有飲食限制的旅客會發現這個國家比預想的更難應付，而原因是結構性的，並非出於不友善。

## A. 最常見的誤解是以為日本料理基本上是素食。用柴魚（魚）片熬的高湯（dashi）是大多數湯、醬汁和燉煮菜的底子，而「素食」並不是一個被廣泛理解的類別。選擇是有的——精進料理（寺院素食）、數量不斷增加的認證純素和清真餐廳，以及標示清楚的便利商店食品——但必須主動去找，並且要問得精確。

## 陷阱在哪裡

| 看起來是素的 | 通常含有 |
|---|---|
| 味噌湯 | **柴魚高湯**（魚） |
| 麵湯（蕎麥麵、烏龍麵） | 柴魚和/或**豚骨/雞骨**高湯 |
| 定食店的蔬菜天婦羅 | 天婦羅沾醬（**高湯**） |
| 豆腐料理（揚出豆腐、冷豆腐） | **高湯**底的醬汁、上面撒的**柴魚片** |
| 大阪燒、章魚燒 | **魚片、海鮮、豬肉**、雞蛋 |
| 「昆布」或「梅」御飯糰 | 通常沒問題；**注意柴魚（おかか）和高湯調味** |
| 咖哩 | **牛油/豬油或牛肉/豬肉高湯**，咖哩塊中有時含豬油 |

- 日本觀光廳估計素食/純素旅客**每年約 145–190 萬人**（2018 年估算），並發布了面向餐飲業者的**接待指南**（2020 年；2024 年 4 月更新為素食/純素/穆斯林接待指南）。
- **清真**：日本**沒有國家級清真認證機構**；認證由**民間組織**（如日本清真協會 Japan Halal Association、日本亞洲清真協會 Nippon Asia Halal Association）進行，因此標準各異。**「Muslim-friendly」（穆斯林友善）**標示表示有一定程度的照顧，而非完整認證。
- **精進料理**（佛教寺院料理）依傳統是**完全純素的**——京都和高野山是中心（一餐 ¥3,000–8,000）。
- **調味料中的酒精**：許多醬汁使用味醂和清酒；**醬油通常以小麥釀造，並含有發酵產生的微量酒精**。

> **[待核實]** 觀光廳的旅客估算和餐飲指南請與日本觀光廳核對；清真認證機構請與所列組織核對。

## 誤解1｜「素食」是被理解的

這個詞大家知道，但**類別的邊界**並不清楚。在日常用法中**魚往往不算「肉」**。說清楚你**不能吃什麼**：「sakana dame」（不吃魚）、「dashi mo dame」（魚高湯也不行）、「niku dame」（不吃肉）。隨身帶一張**日文卡片**（日本政府觀光局 JNTO 和多款 App 都有提供）。

## 誤解2｜點菜時要求去掉肉就好

去掉配料並不能去掉**高湯**。要問**湯或醬汁**裡是否含高湯或肉——「dashi wa nani desu ka?」（高湯是用什麼做的？）。

## 誤解3｜便利商店沒指望

便利商店**比餐廳更容易**，因為原料有標示。查看**過敏原標示行**（參見食品標示一文），選簡單的東西：**鹽味飯糰、昆布飯糰、毛豆、水果、不加醬的沙拉、豆漿**。有些連鎖店會標出**純素商品**。

## 誤解4｜清真意味著餐廳由穆斯林經營

認證是**民間的，標準各異**。查看店內展示的證書或認證機構的名單；**「Muslim-friendly」**可能意味著不用豬肉但供應酒精飲料。

## 誤解5｜你會挨餓

**精進料理、隨處可見的印度和尼泊爾餐廳、東京、京都和大阪的認證純素咖啡館，以及買超市食材自己下廚**，可以滿足大部分需求。寺院餐**請提前預約**；大城市以外可以直接走進去吃的純素選擇仍然很少。
