# Q. 關於用報紙擦窗戶，大家常有哪些誤解？｜Japanese Everyday Wisdom #273

- Shelf: `wisdom` ／ URL: `/zh-tw/wisdom/newspaper-for-windows` ／ Status: **草稿 — 出處未核實**

用揉皺的報紙擦玻璃，是日本家庭沿用了好幾代的方法，而且一直延續到了超細纖維布的時代。它常被當成民間傳說而被忽略。其實它有效是出於一個明確的原因，也有一個明確的限制。

## A. 常見的誤解是以為報紙能擦乾淨玻璃是因為油墨裡有什麼神奇成分。新聞紙之所以有用，是因為它是一種緻密、不掉棉絮、略帶吸水性的紙，能把玻璃擦乾而不留纖維，油墨中少量的油分又帶來淡淡的光澤。它對付不了厚重的污垢；它是給已經用水擦過的玻璃做最後的收尾。超細纖維布能做同樣的事而且更省事，但報紙的方法不花一毛錢，還利用了廢紙。

## 這個方法是怎麼起作用的

| 步驟 | 詳情 |
|---|---|
| 1. 擦拭 | 用濕布（清水，或滴一點清潔劑的水）帶走灰塵和污垢；用力擰乾 |
| 2. 乾擦拋光 | **揉皺的報紙**，乾的或略微潮濕，先畫圈再直線擦 |
| 3. 檢查 | 借光線的角度看有沒有水痕；用新的一張再擦一遍 |
| 時機 | **陰天或背陰處**——陽光直射會在你擦之前就把清潔液曬乾，留下水痕 |
| 頻率 | 室內每月一次；室外在**年終大掃除**（「大掃除」）時和花粉季之前 |

- 新聞紙是**未漂白、少棉絮、表面霧面的紙**；油墨中的油性成分會留下一層極薄的膜，**能在幾天內擋住細小灰塵**。彩色版面和亮面的夾頁效果不如普通版面。
- **現代的大豆油墨**較少沾到手上；老式油墨可能會弄髒白色窗框——窗框請另外用布擦。
- **玻璃刮刀**是專業工具；**（乾的）超細纖維布是現代家庭的對應物**；報紙是零成本版本，並且再利用了本來就要送去回收的廢紙。

> **[待核實]** 這一原理是家庭清潔類資料中被廣泛重複的解釋；報紙油墨的成分請向日本新聞協會核實。

## 誤解1｜報紙可以代替清潔劑

它是用來**收尾**的。污垢、指印和廚房油煙需要**先用水和少量清潔劑**處理；只用報紙只會越擦越花。

## 誤解2｜要把報紙充分弄濕

**略微潮濕或乾的就好。** 泡濕的新聞紙會散掉，留下紙漿。把它當作擦乾和拋光的那一步來用。

## 誤解3｜什麼紙都可以

**廚房紙巾和面紙會掉棉絮**；亮面雜誌會抹花。新聞紙的緻密才是關鍵。

## 誤解4｜油墨會弄髒玻璃

**不會**——那層極薄的膜正是光澤的來源，而且是看不見的。它可能會弄髒**白色 PVC 窗框和窗台**；那些地方請用布擦。

## 誤解5｜晴天最適合擦窗

陽光**會在你來得及擦之前就把水曬乾**，留下水痕和礦物質印。**陰天、乾燥的日子**——日本的十二月——最為理想，這也是為什麼擦窗是年終大掃除的一部分。
