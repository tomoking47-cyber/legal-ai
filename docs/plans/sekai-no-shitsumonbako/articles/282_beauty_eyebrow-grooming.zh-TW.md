# Q. 關於修眉，常見的誤解有哪些？｜Japan Questions #282

- Shelf: `beauty` ／ URL: `/zh-tw/beauty/eyebrow-grooming` ／ Status: **草稿 — 出處未核實**

眉毛決定一張臉的印象，而流行的眉形隨時代改變。本文談的不是流行，而是拔、刮、畫的安全問題與工具的衛生——包括日本法律把紋眉放在什麼位置。

## A. 最大的誤解是「拔得越多眉毛越整齊」。反覆拔毛會削弱毛囊，毛髮可能不再長出來。基本原則是：「只拔外側幾根雜毛，用剪刀和刮刀修形」「先保護皮膚，再用乾淨的刀片刮」「畫的時候只補缺的地方」。

## 方法與注意事項

| 方法 | 適用於 | 注意事項 |
|---|---|---|
| **拔（鑷子）** | 外側和眉間**明顯多餘的少數幾根** | **反覆拔會導致不再長出。** 毛囊發炎（毛囊炎）。**不要拔眉毛內側和下緣**（形狀無法復原） |
| **刮（修眉刀或電動修眉器）** | 眉周的細毛 | **用乾淨的刀片；先用保濕品或刮鬍凝膠保護皮膚。****不要在同一處來回刮。** 拋棄式刀片用幾次後就更換 |
| **修剪（修眉剪與眉梳）** | 修齊長度 | 把毛往上梳，**只剪出頭的部分**。剪過頭無法挽回 |
| **畫（眉筆或眉粉）** | 填補稀疏的部位 | **一根一根地補**；不要用線條勾出輪廓 |
| **染眉膏（eyebrow tint）或眉毛睫毛膏** | 改變顏色 | 已有因染料引起**皮膚炎**的報告。**請做貼布測試（patch test）** |
| **半永久紋眉「アートメイク」（āto meiku，半永久性眉部紋繡）** | 長時間維持顏色 | **屬於醫療行為**（用針把色素注入皮膚）。**無資格施作屬違法行為**；已有健康受害的報告 |

- 眉毛的**生長期短（約 1～2 個月）**，拔掉後重新長出需要**數週到數個月**。**反覆的刺激會讓毛囊進入休止狀態。**
- **紋眉在《醫師法》下屬於醫療行為**（厚生勞動省 2001 年通知，並由**2023 年通知**再次明示；2020 年最高法院裁定認定紋身師的刺青不屬於醫行為，但**半永久紋眉（畫眉、畫眼線）仍維持醫行為的定位**）。**2025 年厚生勞動省通知**指出，**除無資格者施作之外，缺少醫師診察、僅由護理師實施的施作也可能違法**。**在美容沙龍接受這項服務是違法的**，日本國民生活中心也接到過健康受害的申訴。

> **[待核實]** 半永久紋眉的法律定位請對照厚生勞動省通知（医政医発第105号，2001 年）核對，健康受害請以日本國民生活中心的公開資料核對。

## 誤解1｜拔毛才能修出最整齊的眉形

**外側只拔幾根就好。** 用**剪刀和刮刀**修形，才是可以反悔的方法。

## 誤解2｜刮刀傷皮膚，絕對不能用

**在使用乾淨刀片並塗上保護凝膠的前提下，一般認為刮比拔對皮膚和毛囊的負擔更小。****刀片用幾次後就更換**，並**在用後擦乾**。

## 誤解3｜拔掉眉下方的毛能讓眼睛顯大

**眉下方長回來的情況不好，眼睛與眉毛之間的距離無法復原。** 眉下方請用**刮刀或剪刀**處理到最低限度。

## 誤解4｜染眉膏是化妝品，所以是安全的

**染料可能引起皮膚炎。** 請**提前 48 小時做貼布測試**，並避免進入眼睛。如果**眼皮腫脹**，請就診皮膚科（適用日本的醫療保險）。

## 誤解5｜紋眉在美容沙龍很快就能做好

**用針把色素置入皮膚是醫行為**，只有**在醫師診察並給出指示的前提下，由醫師或護理師在醫療機構施作**才是合法的。2025 年厚生勞動省通知指出，**缺少醫師診察、僅由護理師實施的施作也可能違法**。**在美容沙龍或家庭沙龍施作屬違法行為，並已有感染、過敏與變色的報告。**
