# Q. 香水・フレグランスの保管について、よくある誤解は？｜世界の質問箱 #287

- 棚：`beauty` ／ URL：`/questions/storing-fragrance` ／ ステータス：**ドラフト（法務レビュー前・出典未検証）**

「香水は何年もつのか」「冷蔵庫に入れるべきか」は海外のフォーラムで繰り返し問われます。日本の高温多湿と直射日光を前提に、香りを保つ保管の考え方を整理します。

## A. 最大の誤解は「香水はアルコールだから腐らず、何年でも同じ」です。香料は光・熱・空気で酸化し、色が濃くなり香りが変わります。開封後は1〜3年が目安で、保管は「直射日光を避け、温度変化の少ない暗所、キャップをしっかり」が基本です。冷蔵庫は温度差による結露と食品への匂い移りの点で勧められません。

## 判断の材料

| 項目 | 内容 |
|---|---|
| 劣化の要因 | **紫外線・熱（30℃以上）・温度変化・空気（酸化）** |
| 保管場所 | **暗く、涼しく、温度が安定した場所**（クローゼット・引き出し）。**洗面所・窓辺・車内は不適** |
| 開封後の目安 | **1〜3年**（香りの種類と保管による）。**柑橘系は劣化が早く、ウッディ・オリエンタル系は長持ち**する傾向 |
| 劣化のサイン | **色が濃くなる（黄→琥珀）、トップノートが酢っぽい・酸っぱい、香りが平坦** |
| 箱 | **外箱に入れて保管**が光を遮る最も簡単な方法 |
| 使用期限の表示 | 化粧品は**3年以上安定なら表示義務なし**。**製造ロット番号（バッチコード）**で製造時期が推定できる場合がある |

- 香水は日本では**化粧品**（一部は雑貨）で、**全成分表示**の義務があります。**アルコール（エタノール）は防腐に寄与**しますが、**香料の酸化は止めません。**
- **アトマイザーに移す**と、**空気との接触と光で本体より早く劣化**します。**移すのは数週間で使う量**にとどめます。
- 香水は**消防法上の危険物（アルコール濃度による）**で、**火気の近くに置かない**、**航空機の機内持ち込みは100mL以下**、**アルコールを含む香水は日本郵便では送れません（郵便法上の禁制品）**。宅配便では陸送を条件に受け付ける会社があります（郵送の記事を参照）。

> 【要検証】開封後の目安は業界・メーカーの一般的な案内に基づきます。危険物の扱いは消防法・航空会社の規定、郵送の可否は日本郵便および各宅配会社の最新の案内で確認してください。

## 誤解1｜冷蔵庫に入れれば長持ちする

**出し入れの温度差で結露し、食品に匂いが移ります。** 常温の暗所で十分です。**ワインセラーのような一定温度の暗所**があれば理想ですが、必須ではありません。

## 誤解2｜洗面所に置くのが自然

**洗面所は湯気で高温多湿になり、窓があれば紫外線も**。香水の劣化条件がそろっています。**寝室の引き出し**へ。

## 誤解3｜色が濃くなったのは熟成

**酸化の色**で、香りは変わっています。**トップノートが酸っぱい**なら劣化。**肌につけず、ルームフレグランス代わり**にする人もいます。

## 誤解4｜一度開けたらすぐ使い切らないと

**1〜3年は保管次第で保ちます。** **キャップをしっかり閉め、箱に戻す**だけで差が出ます。

## 誤解5｜ミニボトル・アトマイザーは保管に便利

**本体からの小分けは劣化を早めます。** 持ち歩き用は**数週間分だけ**。**未開封のミニボトル**は別（未開封なら本体と同じ）。
