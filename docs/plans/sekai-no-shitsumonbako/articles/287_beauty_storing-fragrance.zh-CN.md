# Q. 关于香水与香氛的保管，常见的误解有哪些？｜Japan Questions #287

- Shelf: `beauty` ／ URL: `/zh-cn/beauty/storing-fragrance` ／ Status: **草稿 — 出处未核实**

「香水能放几年？」「要不要放冰箱？」是海外论坛上反复出现的问题。日本夏季高温潮湿、日照强烈，这个问题在这里更加现实。本文整理的是：怎样保管，香味才能保持住。

## A. 最大的误解是「香水是酒精，不会坏，放多少年都一样」。香料会因光、热、空气而氧化，颜色变深，香味也会改变。开封后以1〜3年为参考，保管的基本原则是「避开阳光直射，放在温度变化小的暗处，盖子拧紧」。冰箱并不推荐，因为温差会产生结露，香味也会串到食物上。

## 判断的要点

| 项目 | 内容 |
|---|---|
| 使香水劣化的因素 | **紫外线、热（30℃以上）、温度变化、空气（氧化）** |
| 保管场所 | **温度稳定的阴凉暗处**（衣柜、抽屉）。**浴室、窗边、车内都不合适** |
| 开封后的参考期限 | **1〜3年**（取决于香调种类与保管方式）。**柑橘调劣化最快，木质调与东方调相对更持久** |
| 劣化的迹象 | **颜色变深（黄→琥珀色）、前调发出醋味或酸味、香味变得平淡** |
| 外盒 | **连外盒一起保管**是最简单的遮光方法 |
| 使用期限的标注 | 化妆品**只要3年以上稳定就没有标注义务**。有时可以通过**生产批号（batch code）**推算生产时期 |

- 在日本，香水属于药机法下的**化妆品**（也有作为一般杂货销售的产品），**全成分标注**是强制的。**酒精（乙醇）有助于防腐**，但**并不能阻止香料氧化**。
- **分装到喷雾瓶里**会让液体**接触空气和光，因此比原瓶劣化更快**。**只分装几周内能用完的量。**
- 香水属于**消防法上的危险物（视酒精含量而定）**：**请远离明火**，**飞机随身行李每个容器限100mL**，**且不能通过航空邮寄**（参见寄包裹的那篇文章）。

> **[待核实]** 开封后的参考期限依据的是业界与厂商的一般说明。危险物的处理请对照消防法与航空公司规定核实。

## 误解1｜放冰箱能放得更久

**拿进拿出会因温差产生结露，香味也会串到食物上。** 常温的暗处就足够了。**像酒柜那样恒温的暗处**是理想选择，但并非必需。

## 误解2｜浴室是理所当然的存放地点

**水蒸气让浴室又热又潮，有窗户还会加上紫外线。** 劣化所需的条件一应俱全。请把它移到**卧室的抽屉里**。

## 误解3｜颜色变深说明它熟成了

那是**氧化的颜色**，香味已经变了。**前调发酸**就说明已经劣化。也有人**不再用于皮肤，改作室内香氛**。

## 误解4｜一旦开封就必须尽快用完

**保管得当的话，1〜3年都能保持。** 光是**把盖子拧紧、放回盒子里**就有差别。

## 误解5｜小样和分装瓶方便保管

**从原瓶分装会加快劣化。** 随身只带**几周的量**。**未开封的小样**则是另一回事（未开封时，与整瓶一样耐放）。
