# Q. 關於香水與香氛的保存，常見的誤解有哪些？｜Japan Questions #287

- Shelf: `beauty` ／ URL: `/zh-tw/beauty/storing-fragrance` ／ Status: **草稿 — 出處未核實**

「香水能放幾年？」「要不要放冰箱？」是海外論壇上一再出現的問題。日本夏天高溫潮濕、日照強烈，這個問題在這裡更加現實。本文要整理的是：怎麼保存，香味才留得住。

## A. 最大的誤解是「香水是酒精，不會壞，放多少年都一樣」。香料會因光、熱、空氣而氧化，顏色變深，香味也會改變。開封後以1〜3年為參考，保存的基本原則是「避開陽光直射，放在溫度變化小的暗處，蓋子鎖緊」。冰箱並不推薦，因為溫差會產生結露，香味也會沾染到食物上。

## 判斷的要點

| 項目 | 內容 |
|---|---|
| 使香水劣化的因素 | **紫外線、熱（30℃以上）、溫度變化、空氣（氧化）** |
| 保存場所 | **溫度穩定的陰涼暗處**（衣櫥、抽屜）。**浴室、窗邊、車內都不適合** |
| 開封後的參考期限 | **1〜3年**（取決於香調種類與保存方式）。**柑橘調劣化最快，木質調與東方調相對較持久** |
| 劣化的徵兆 | **顏色變深（黃→琥珀色）、前調出現醋味或酸味、香味變得平淡** |
| 外盒 | **連外盒一起保存**是最簡單的遮光方法 |
| 使用期限的標示 | 化妝品**只要3年以上穩定就沒有標示義務**。有時可以透過**製造批號（batch code）**推算製造時期 |

- 在日本，香水屬於藥機法下的**化妝品**（也有作為一般雜貨販售的產品），**全成分標示**是強制的。**酒精（乙醇）有助於防腐**，但**並不能阻止香料氧化**。
- **分裝到噴霧瓶裡**會讓液體**接觸空氣與光，因此比原瓶劣化更快**。**只分裝幾週內用得完的量。**
- 香水屬於**消防法上的危險物（視酒精含量而定）**：**請遠離明火**，**飛機隨身行李每個容器限100mL**，**含酒精的香水在日本郵政完全無法寄送**（屬於郵政法上的禁運品）。部分宅配公司會以陸運為條件受理（請參見寄包裹那篇文章）。

> **[待核實]** 開封後的參考期限依據的是業界與廠商的一般說明。危險物的處理請對照消防法與航空公司規定核實，能否寄送請對照日本郵政與各宅配公司的最新說明核實。

## 誤解1｜放冰箱能放得更久

**拿進拿出會因溫差產生結露，香味也會沾染到食物上。** 常溫的暗處就足夠了。**像酒櫃那樣恆溫的暗處**是理想選擇，但並非必要。

## 誤解2｜浴室是理所當然的擺放位置

**水蒸氣讓浴室又熱又潮，有窗戶還會再加上紫外線。** 劣化所需的條件一應俱全。請把它移到**臥室的抽屜裡**。

## 誤解3｜顏色變深代表它熟成了

那是**氧化的顏色**，香味已經變了。**前調發酸**就表示已經劣化。也有人**不再用在皮膚上，改當室內香氛**。

## 誤解4｜一旦開封就必須盡快用完

**保存得當的話，1〜3年都能維持。** 光是**把蓋子鎖緊、放回盒子裡**就有差別。

## 誤解5｜小樣與分裝瓶方便保存

**從原瓶分裝會加快劣化。** 隨身只帶**幾週的量**。**未開封的小樣**則是另一回事（未開封時，和整瓶一樣耐放）。
