# Q. 子どもの日焼け止めについて、よくある誤解は？｜世界の質問箱 #289

- 棚：`beauty` ／ URL：`/questions/sunscreen-for-children` ／ ステータス：**ドラフト（法務レビュー前・出典未検証）**

子どもに日焼け止めを塗るべきかは、各国で親の意見が分かれます。日本では環境省と日本臨床皮膚科医会・日本小児皮膚科学会が共同で見解を出しており、公的な立場がはっきりしています。

## A. 最大の誤解は「子どもは日焼けして強くなる」です。環境省と皮膚科の学会は、子どもの紫外線対策を推奨し、「適度な紫外線は骨のために必要」という主張について「日常の生活で十分に得られる」と説明しています。基本は「帽子・衣類・日陰」を優先し、露出部には子ども用（低刺激・SPF15〜30程度）の日焼け止めを、6か月未満は直射日光を避けることです。

## 公的な見解と数字

| 項目 | 内容 | 出典 |
|---|---|---|
| 子どもの紫外線対策 | **推奨**。生涯に浴びる紫外線の**相当部分を18歳までに浴びる**とされ、**皮膚がん・白内障の予防は子ども期から** | 環境省マニュアル、日本臨床皮膚科医会 |
| 「紫外線は骨に必要」への回答 | ビタミンD生成に必要な紫外線は**日常生活の短時間の露出で十分**（例：夏の晴天なら**両手の甲に数分〜十数分**） | 環境省・国立環境研究所 |
| 6か月未満 | **まず衣類・帽子・日陰・ベビーカーの幌で直射日光を避ける**。日本小児皮膚科学会は**「サンスクリーンは小さい赤ちゃんから使うことができる」**とし、避けられない露出部には低刺激のものを少量から | 日本小児皮膚科学会 |
| 6か月以降 | **子ども用（低刺激）を露出部に。日本小児皮膚科学会の目安は日常生活でSPF15〜20・PA++、海や山ではSPF20〜40・PA++〜+++** | 同上 |
| 優先順位 | **①日陰・時間帯（10〜14時を避ける）②帽子（つば7cm以上）③衣類 ④日焼け止め** | 環境省 |
| 学校 | 日本学校保健会「学校における水泳プールの保健衛生管理（平成28年度改訂）」は**日焼けしやすい児童生徒に日焼け止めを使用させるよう**記載。**プールでの使用可否は学校の判断**で対応は分かれる | 日本学校保健会／日本臨床皮膚科医会・日本小児皮膚科学会 |

- 日焼け止めは**化粧品（または医薬部外品）**で、**「子ども用」「ベビー用」は法律上の区分ではなく**、**低刺激設計・紫外線散乱剤主体・石けんで落とせる**などの特徴を指す表示です。
- **紫外線吸収剤・散乱剤ともに承認された成分**で、子どもに散乱剤主体が選ばれるのは**刺激の少なさ**の観点です。

> 【要検証】環境省マニュアルおよび日本臨床皮膚科医会・日本小児皮膚科学会の「こどもの紫外線対策に関する統一見解」の記載を確認してください。

## 誤解1｜子どもは日焼けして丈夫になる

**日焼けは皮膚の炎症**で、**子ども期の紫外線の蓄積が成人後のシミ・皮膚がんのリスク**と関連するとされます。学会は**子どもの紫外線対策を推奨**しています。

## 誤解2｜紫外線を避けると骨が弱くなる

**ビタミンDの生成に必要な紫外線は、日常生活の短時間で十分**というのが環境省の説明です。**食事（魚・きのこ）からも**とれます。

## 誤解3｜大人用の日焼け止めを薄く塗ればよい

**薄く塗ると効果が下がります。** **子ども用を規定量（顔で1円硬貨2枚分程度）**、**2〜3時間おきと汗・水の後に塗り直す**。

## 誤解4｜日焼け止めを塗れば帽子は要らない

**優先順位は日陰・帽子・衣類が先**、日焼け止めは**露出部の補助**です。**つば7cm以上の帽子で顔への紫外線を約60%減らす**とされます。

## 誤解5｜プールでは日焼け止めは禁止

**日本学校保健会「学校における水泳プールの保健衛生管理」（平成28年度改訂）は使用を認める記載**で、**学会は「耐水性のものを使えば水質は汚濁されない」**としています。ただし**対応は学校ごとに分かれている**ため、方針を確認します。**ラッシュガード（UVカットの水着用上着）**も広く使われています。
