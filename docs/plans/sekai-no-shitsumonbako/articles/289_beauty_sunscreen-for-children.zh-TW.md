# Q. 關於兒童的防曬，常見的誤解有哪些？｜Japan Questions #289

- Shelf: `beauty` ／ URL: `/zh-tw/beauty/sunscreen-for-children` ／ Status: **草稿 — 出處未核實**

要不要幫孩子擦防曬，在任何國家都會讓家長意見分歧。在日本，官方的立場卻異常明確：環境省、日本臨床皮膚科醫會與日本小兒皮膚科學會發布了統一見解。本文要整理的是這份見解說了什麼，以及它在學校與泳池代表什麼。

## A. 最大的誤解是「孩子曬黑了才強壯」。環境省與皮膚科的學會建議為兒童做紫外線防護，對於「骨骼需要一些紫外線」的說法，他們的回答是：日常生活中獲得的量已經足夠。基本原則是：先做到「帽子、衣物、樹蔭」；在裸露的皮膚上使用兒童用防曬（低刺激、SPF 15〜30左右）；未滿6個月的嬰兒避免陽光直射。

## 官方見解與數字

| 項目 | 內容 | 出處 |
|---|---|---|
| 兒童的紫外線防護 | **建議進行。** 一般的說法是**一生中相當大一部分的紫外線照射量在18歲前就已受到**，因此**皮膚癌與白內障的預防從兒童期開始** | 環境省手冊；日本臨床皮膚科醫會 |
| 對「骨骼需要紫外線」的回答 | 生成維生素D所需的紫外線，**在日常生活的短時間照射中就能取得**（例如夏季晴天，**雙手手背數分鐘至十幾分鐘**） | 環境省；國立環境研究所 |
| 未滿6個月 | **先以衣物、帽子、樹蔭與嬰兒車遮陽篷避開陽光直射**。日本小兒皮膚科學會表示**「防曬乳從很小的嬰兒起就可以使用」**，無法遮蓋的裸露部位可從少量低刺激產品開始 | 日本小兒皮膚科學會 |
| 6個月以上 | 在裸露的皮膚上使用**兒童用產品（低刺激）。日本小兒皮膚科學會的參考值是：日常生活 SPF 15〜20・PA++，海邊或山上 SPF 20〜40・PA++〜+++** | 同上 |
| 優先順序 | **1. 樹蔭與時段（避開10:00〜14:00） 2. 帽子（帽簷7cm以上） 3. 衣物 4. 防曬** | 環境省 |
| 學校 | 日本學校保健會《學校游泳池的保健衛生管理（2016年度修訂）》寫明**應讓容易曬傷的學生使用防曬**。**泳池能否使用由各學校自行決定**，做法不一 | 日本學校保健會／日本臨床皮膚科醫會・日本小兒皮膚科學會 |

- 防曬屬於**化妝品（或醫藥部外品——日本介於化妝品與藥品之間的類別）**，**「兒童用」「嬰兒用」並不是法律上的分類**。它們代表的是**低刺激配方、以礦物性（物理性）紫外線散射劑為主、可用肥皂洗淨**等特徵。
- **化學性紫外線吸收劑與礦物性散射劑都是獲准使用的成分**；為兒童選擇礦物性產品，理由是**刺激較低**。

> **[待核實]** 環境省手冊的措辭，以及日本臨床皮膚科醫會與日本小兒皮膚科學會《關於兒童紫外線對策的統一見解》的措辭，請核實。

## 誤解1｜孩子曬黑了才強壯

**曬傷是皮膚的發炎**，一般的說法是**兒童期累積的紫外線照射與成年後的色素沉澱及皮膚癌風險相關**。學會**建議為兒童做紫外線防護**。

## 誤解2｜避開紫外線會讓骨骼變弱

環境省的說明是，**維生素D所需的紫外線在日常生活的短時間照射中就能取得。** 它也**來自食物（魚、菇類）**。

## 誤解3｜把大人的防曬薄薄擦一層就好

**擦得太薄會降低防護效果。** 請使用**兒童用產品，並依標示的用量（臉部約為2枚1日圓硬幣的量——1日圓硬幣直徑2cm）**，並**每2〜3小時以及流汗、下水後補擦**。

## 誤解4｜擦了防曬就不用戴帽子

**樹蔭、帽子與衣物是第一順位**；防曬是**對裸露皮膚的補充**。一般的說法是，**帽簷7cm以上的帽子可以讓臉部的紫外線減少約60%。**

## 誤解5｜泳池禁止使用防曬

**日本學校保健會《學校游泳池的保健衛生管理》（2016年度修訂）寫明允許使用**，**學會也指出「使用耐水型產品不會汙染水質」。** 不過**各校做法仍有差異**，請確認自己學校的規定。**防曬水母衣（ラッシュガード——穿在泳裝外面的抗UV上衣）**也被廣泛使用。
