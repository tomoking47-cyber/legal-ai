# Q. 毛玉取り器の使い方について、よくある誤解は？｜世界の質問箱 #295

- 棚：`fashion` ／ URL：`/questions/using-a-lint-shaver` ／ ステータス：**ドラフト（法務レビュー前・出典未検証）**

毛玉取り器（電動の刃で毛玉を刈る道具）は日本の100円ショップから家電量販店まで並ぶ定番で、海外では「服に穴が開くのではないか」と警戒されます。安全に使う条件を整理します。

## A. 最大の誤解は「毛玉取り器を強く押し当てれば早く取れる」です。押し当てると生地の織り目まで刈り取り、穴や薄化の原因になります。基本は「平らな場所に生地を広げ、軽く浮かせて円を描くように動かす」「ニットの編み目が粗いもの・薄い生地には使わない」です。

## 判断の材料

| 道具 | 向く生地 | 注意 |
|---|---|---|
| **電動毛玉取り器（回転刃）** | **綿・アクリル・ポリエステルの平らな生地**（トレーナー・フリース・靴下） | **押し当てない、浮かせる**。**ボタン・ファスナー・刺しゅう**を避ける。**編み目の粗いニットは巻き込む** |
| **毛玉取りブラシ（獣毛）** | ウール・カシミヤのニット | 毛並みに沿って軽く。**繊維を整える**効果も |
| **小さなハサミ** | 大きな毛玉・少数 | **生地を引っ張らずに毛玉だけ**を切る |
| **T字カミソリ** | 平らな綿生地（応急） | 刃が新しいと切れすぎる。**軽く滑らせる**。危険 |
| **スポンジ（食器用の硬い面）** | 軽い毛玉 | こすりすぎない |

- 毛玉は**摩擦で表面の繊維が絡まり玉になる**もの（毛玉の記事を参照）。**取ると一時的にきれいになるが、原因（摩擦・洗濯時のこすれ）を減らさなければ再発**します。
- 電動毛玉取り器には**「生地の厚さ調整」や「高さ調整リング」**がある製品があり、**ニット用は高く、平らな生地は低く**設定します。**刃の交換・掃除**を怠ると切れずに引っかかります。
- **毛玉取り器で穴を開けた**という相談は、**押し当てすぎ・薄手の生地・ボタン付近**が典型です。

> 【要検証】製品の使い方は取扱説明書に従ってください。毛玉の仕組みは繊維団体の一般的な説明です。

## 誤解1｜押し当てるほどよく取れる

**織り目まで刈って穴が開きます。** **軽く浮かせて円を描く**。**取り残しは2回目で**。

## 誤解2｜どんな服にも使える

**薄手・編み目の粗いニット・伸縮生地・レース・刺しゅう部分**は巻き込みや穴の原因。**平らな中厚以上の生地**が向きます。

## 誤解3｜毛玉を取れば毛玉はできなくなる

**原因は摩擦**です。**裏返して洗う・ネット・バッグとのこすれを減らす**ことで再発を遅らせます。

## 誤解4｜100円の毛玉取り器は危険

**価格より使い方**です。**高さ調整のない製品は浮かせる加減が要る**ため、初めてなら**調整リング付き**が失敗が少ないです。

## 誤解5｜ニットの毛玉は手でむしる

**むしると周囲の繊維を引き出し、毛玉が増えます。** **ハサミで毛玉だけを切る**か、**ブラシで整える**。
