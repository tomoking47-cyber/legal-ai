# Q. 關於使用除毛球機，人們常有什麼誤解？｜Japan Questions #295

- Shelf: `fashion` ／ URL: `/zh-tw/fashion/using-a-lint-shaver` ／ Status: **草稿 — 出處未核實**

除毛球機（「毛玉取り器」，*kedama-tori-ki* —— 靠旋轉刀片刮掉毛球的電動工具）在日本隨處可見，從百元店到電器行都有賣。在海外，人們擔心它會「把衣服刮出洞」。以下是安全使用的條件。

## A. 最大的誤解是「用力壓著刮，效率更高」。用力壓會刮到布料本身，造成破洞與變薄。基本做法是：把布攤在平面上，輕輕拿著讓它浮著走，畫圈移動，不要用在鬆針織與薄布料上。

## 判斷依據

| 工具 | 適合的布料 | 注意事項 |
|---|---|---|
| **電動除毛球機（旋轉刀片）** | **平織的棉、壓克力纖維或聚酯纖維布料**（棉質上衣、刷毛衣、襪子） | **不要壓，讓它浮著。** 遠離**鈕扣、拉鍊與刺繡**。**鬆針織的布料會被捲進刀片** |
| **除毛球刷（動物毛）** | 羊毛、喀什米爾針織衫 | 順著毛流輕刷。還能**理順纖維** |
| **小剪刀** | 大顆、數量不多的毛球 | **只剪毛球，不要把布料拉起來** |
| **安全刮鬍刀（T 字型）** | 平織棉布（應急） | 新刀片會削得太深。**輕輕滑過。** 有風險 |
| **海綿（洗碗海綿粗糙的那一面）** | 輕微起毛球 | 別過度摩擦 |

- 毛球是**摩擦讓表面纖維纏成小球**而形成的（參見起毛球那篇）。**去掉它只是眼前把衣服整理乾淨；不減少成因（穿著與洗滌時的摩擦），它還會再長出來。**
- 有些電動除毛球機附**「布料厚度」段位或高度調節環**：**針織物調高，平織布料調低**。**疏於換刀片與清理**，它就削不動，反而會勾紗。
- **「除毛球機把衣服刮出洞」**的客訴，通常都牽涉到**壓得太用力、布料太薄，或者在鈕扣附近作業**。

> **[待核實]** 具體用法請遵循產品的使用說明書。關於起毛球的解釋，採用的是紡織相關團體的一般說法。

## 誤解1｜壓得越用力去得越多

**它會削到布料，刮出洞來。** **輕輕浮著，畫圈移動。** **剩下的，第二遍再收拾。**

## 誤解2｜什麼衣服都能用

**薄布料、鬆針織、彈性布料、蕾絲與有刺繡的部位**會被捲進去或刮破。**中等厚度以上的平織布料**才是它適合的對象。

## 誤解3｜毛球去掉了就不會再長

**成因是摩擦。** **翻面洗、用洗衣網袋，減少背包造成的摩擦**，可以延緩它再長出來。

## 誤解4｜百元店的除毛球機很危險

**手法比價格更重要。** **沒有高度調節的機型需要小心地浮著用**，所以第一次買的話，**帶調節環的**失敗更少。

## 誤解5｜針織衫的毛球用手揪掉就好

**一揪就會把周圍的纖維帶出來，反而長出更多毛球。** **用剪刀只剪掉毛球**，或者**用刷子理順**。
