# Q. 벨트 손질에 대한 흔한 오해는 무엇입니까?｜Japan Questions #296

- Shelf: `fashion` ／ URL: `/ko/fashion/belt-care` ／ Status: **초안 — 출처 미확인**

벨트는 매일 조이고 푸는, 대부분의 사람이 가진 가죽 제품 가운데 가장 혹사당하는 물건입니다. 갈라짐, 늘어난 구멍, 버클 주변의 변색은 세계 어디서나 나오는 불만입니다. 일본에서는 벨트의 수명을 늘리는 손질 습관이 서로 공유되고 있습니다.

## A. 가장 큰 오해는 "벨트는 소모품이지 손질하는 물건이 아니다"라는 것입니다. 가죽 벨트는 한 달에 한 번 닦고 크림을 발라 주고, 늘 같은 구멍만 쓰지 않고, 말아서 넣는 대신 걸어서 보관하면 수명이 몇 년 단위로 달라집니다. 버클 주변의 변색은 땀과 금속의 반응이며, 닦아 주면 진행이 느려집니다.

## 손질과 보관

| 항목 | 무엇을 | 왜 |
|---|---|---|
| **매일** | 벗은 뒤 **안쪽(땀)과 바깥쪽을 마른 천으로 닦기** | 땀 속의 염분과 피지가 갈라짐의 원인 |
| **매월** | **가죽 크림을 얇게 바른 뒤 마른 천으로 닦아 광내기** | 유분을 보충 |
| **구멍** | **늘 같은 구멍에만 채우지 않기**(체형 변화에 맞춰 양옆 구멍도 사용) | 한 구멍만 늘어나 찢어짐 |
| **보관** | **버클이 바깥으로 오게 걸어 두기**, 또는 **평평하게 놓기**. **말아서 서랍에 넣지 않기** | 말아 두면 꺾인 자국이 남고 갈라짐 |
| **번갈아 쓰기** | 두 개 이상을 번갈아 사용 | 가죽이 회복할 시간을 줌 |
| **버클** | **금속 광택제는 표면 도금을 벗겨낼 수 있으므로** **마른 천으로 닦는 것**이 원칙 | 변색은 땀과의 반응 |
| **합성 피혁** | 닦기만. **가수분해로 몇 년 안에 표면이 벗겨짐** | 소재의 성질 |

- **가죽 벨트의 갈라짐은 건조와 반복되는 굽힘에서 생깁니다.** **꺾이지 않는 보관**과 **유분 보충**이 예방책입니다.
- **버클 주변의 녹색 물질(녹청)**은 **구리가 들어간 금속과 땀의 반응**입니다. **천으로 닦여 나온다면** 문제 없습니다. **피부에 자극이 생긴다면** 금속 알레르기(니켈 등)일 수 있으니 피부과에서 확인하십시오(일본 건강보험 적용).
- 벨트는 **「家庭用品品質表示法」(가정용품 품질표시법, 잡화공업품)**의 대상이며 **소재 표시(소가죽, 합성 피혁 등)**가 붙어 있습니다.

> **[확인 필요]** 표시 의무의 범위는 소비자청 「잡화공업품 품질표시 규정」과, 금속 알레르기 설명은 일본피부과학회 자료와 대조하여 확인하십시오.

## 오해 1｜벨트는 손질하는 물건이 아니다

**가죽 벨트도 구두나 가방과 같은 가죽 제품입니다.** **한 달에 한 번의 크림**이 수명을 몇 년 늘려 줍니다.

## 오해 2｜늘 같은 구멍에 채우는 것이 맞다

**한 구멍만 늘어나서 찢어집니다.** **양옆 구멍을 번갈아 쓰고, 체중 변화에 맞춰 조정하십시오.**

## 오해 3｜말아서 서랍에 넣으면 부피가 작다

**꺾인 자국과 갈라짐**의 원인이 됩니다. **걸어 두거나**(벨트 행거나 고리) **평평하게 놓으십시오**.

## 오해 4｜버클은 금속 광택제로 닦아야 반짝인다

**대부분의 버클은 도금이며, 연마제가 든 광택제는 도금을 벗겨냅니다.** **마른 천으로 닦고, 때가 있으면 희석한 중성 세제를 묻힌 천을 쓰십시오.**

## 오해 5｜합성 피혁 벨트가 가죽보다 튼튼하다

**합성 피혁(폴리우레탄)은 습기로 가수분해되어, 한 번도 쓰지 않아도 몇 년 안에 표면이 벗겨집니다.** **저렴하고 비에 강하지만**, **오래 쓰려면 가죽을 고르십시오**.
