# Q. 關於皮帶的保養，人們常有什麼誤解？｜Japan Questions #296

- Shelf: `fashion` ／ URL: `/zh-tw/fashion/belt-care` ／ Status: **草稿 — 出處未核實**

皮帶每天都要繫上、解開——是多數人擁有的皮革物品中最辛勞的一件。龜裂、孔位被撐大、扣環周圍變色，是世界各地共通的煩惱。在日本，人們會分享延長皮帶壽命的保養習慣。

## A. 最大的誤解是「皮帶是消耗品，不是需要保養的東西」。皮帶只要每月擦拭一次並上一次皮革保養乳、不總是用同一個孔、吊掛而不是捲起來收納，壽命就能相差好幾年。扣環周圍的變色是汗與金屬的反應，擦拭可以延緩它。

## 保養與收納

| 項目 | 做什麼 | 為什麼 |
|---|---|---|
| **每天** | 取下時，**用乾布擦拭內側（汗）與外側** | 汗裡的鹽分與皮脂會造成龜裂 |
| **每月** | **薄薄塗一層皮革保養乳，再擦乾拋光** | 補充油分 |
| **孔位** | **不要總是繫在同一個孔上**（隨體型變化，換用兩邊的孔） | 單一個孔會被撐大並撕裂 |
| **收納** | **扣環朝外吊掛**，或者**平放**。**不要捲起來放進抽屜** | 捲放會留下摺痕並龜裂 |
| **輪替** | 兩條以上交替使用 | 讓皮革得以恢復 |
| **扣環** | **金屬拋光劑會磨掉表面鍍層**，所以**乾擦**是原則 | 變色是與汗的反應 |
| **合成皮** | 只能擦拭。**水解會讓它在幾年內起皮剝落** | 材質本身的性質 |

- **皮帶的龜裂來自乾燥與反覆彎折。** 預防方法是**避免摺痕的收納方式**與**補油**。
- **扣環周圍的綠色附著物（銅綠）**是**含銅金屬與汗的反應**。如果**用布能擦掉**，就沒有問題。如果**皮膚出現刺激症狀**，可能是金屬過敏（鎳等）——請到皮膚科就診（適用日本的健康保險）。
- 皮帶屬於**「家庭用品品質表示法」（家用品品質標示法，雜貨工業品）**的範圍，會附有**材質標示（牛皮、合成皮等）**。

> **[待核實]** 標示義務的適用範圍請對照消費者廳「雜貨工業品品質表示規程」確認，金屬過敏的說明請對照日本皮膚科學會的資料確認。

## 誤解1｜皮帶不是需要保養的東西

**皮帶和鞋子、包包一樣，是皮革製品。** **每月一次的保養乳**能為它增加好幾年壽命。

## 誤解2｜一直繫在同一個孔上才對

**單獨一個孔會被撐大並撕裂。** **在相鄰的孔之間交替使用，並隨體重變化調整。**

## 誤解3｜捲起來放抽屜裡比較省空間

這會造成**定型的摺痕與龜裂**。請**吊掛起來**（皮帶架或掛鉤），或者**平放**。

## 誤解4｜用金屬拋光劑把扣環擦亮

**大多數扣環都是鍍層的，有研磨作用的拋光劑會磨掉鍍層。** **乾擦即可；有髒污時，用沾了稀釋中性洗劑的布擦。**

## 誤解5｜合成皮的皮帶比真皮耐用

**合成皮（聚氨酯）在濕氣中會水解，即使一次都沒用過，表面也會在幾年內剝落。** 它**便宜、不怕雨**，但**要用得久，還是選真皮**。
