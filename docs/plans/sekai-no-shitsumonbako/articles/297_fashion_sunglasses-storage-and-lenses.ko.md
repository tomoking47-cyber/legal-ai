# Q. 선글라스 렌즈와 보관에 대한 흔한 오해는 무엇입니까?｜Japan Questions #297

- Shelf: `fashion` ／ URL: `/ko/fashion/sunglasses-storage-and-lenses` ／ Status: **초안 — 출처 미확인**

선글라스는 색이 진할수록 눈을 잘 보호한다고 여겨지곤 합니다. 그러나 눈을 지켜 주는 것은 렌즈의 색 농도가 아니라 자외선 차단율입니다. 일본에는 선글라스에 대한 JIS 규격이 있고, 그 표시를 읽는 법을 알면 고르는 기준이 달라집니다. 보관할 때 주의할 점도 함께 다룹니다.

## A. 가장 큰 오해는 "렌즈가 진할수록 자외선을 많이 막는다"는 것입니다. 자외선 차단은 렌즈의 소재와 코팅에서 나오며 색의 진하기와는 관계가 없습니다. 자외선 차단 기능이 없는 진한 렌즈는 오히려 더 나쁩니다. 동공이 더 크게 열려 자외선이 더 많이 들어오기 때문입니다. 표시(자외선 투과율 1.0% 이하, UV400 등)를 보고 고르고, 열과 흠집을 피해 보관하십시오.

## 표시 읽는 법(가정용품 품질표시법·JIS T 8141)

| 표시 | 의미 | 비고 |
|---|---|---|
| **자외선 투과율 1.0% 이하(「紫外線透過率1.0%以下」)** | **자외선을 99% 이상 차단.** 일본의 JIS 표시 | |
| **UV400** | **파장 400nm까지의 자외선을 차단**(국제·업계 표시) | |
| **가시광선 투과율(「可視光線透過率」)** | 렌즈의 **진하기**. **운전용은 8% 이상**(JIS: 8% 미만은 운전에 부적합), **야간 운전은 75% 이상** | |
| 편광(「偏光」) | 반사 눈부심(수면, 노면)을 줄임 | 액정 화면이 잘 안 보일 수 있음 |
| 조광(「調光」) | 자외선 양에 따라 색이 변함 | 차 안에서는 거의 변하지 않음(자외선 차단 유리) |

- **「家庭用品品質表示法」(가정용품 품질표시법, 잡화공업품 품질표시 규정 「五　선글라스」)**은 **품명, 렌즈 재질, 테 재질, 가시광선 투과율, 자외선 투과율, 사용상 주의**의 표시를 정하고 있습니다(투과율의 측정 방법은 **JIS T 8141**). **저렴한 패션 선글라스라도 투과율이나 「UVカット」(UV 컷, 자외선 차단) 표시가 있는지 확인하십시오.**
- 환경성 「자외선 환경보건 매뉴얼」은 자외선으로 인한 **백내장, 익상편**(눈 표면에 생기는 군살) 등의 위험을 들고, **자외선을 차단하는 선글라스와 모자**를 권하고 있습니다. **얼굴에 밀착되어 옆에서 들어오는 빛까지 막아 주는 형태**가 효과적입니다.
- **플라스틱 렌즈는 열에 약합니다(약 60℃).** **차 안 대시보드에 두면 코팅이 갈라지고 렌즈가 변형됩니다.**

> **[확인 필요]** 표시 항목과 수치는 JIS T 7333과, 문구는 환경성 매뉴얼 원문과 대조하여 확인하십시오.

## 오해 1｜렌즈가 진할수록 잘 막아 준다

**자외선 차단은 색의 진하기와 관계가 없습니다.** 차단 기능이 없는 진한 렌즈는 **동공을 열어 자외선을 더 들어오게 하므로** 오히려 나쁩니다. 표시에서 **「자외선 투과율 1.0% 이하」 또는 「UV400」**을 확인하십시오.

## 오해 2｜싼 선글라스는 자외선을 막지 못한다

**가격과 상관없이, 표시가 있으면 자외선을 차단합니다.** 차이는 **렌즈의 왜곡, 내구성, 프레임 품질**에 있습니다. **표시가 없는 제품은 피하십시오.**

## 오해 3｜운전 중 눈부심에는 아무 선글라스나 된다

**가시광선 투과율 8% 미만은 운전에 부적합합니다**(JIS). **진한 렌즈는 야간과 터널에서 위험합니다.** **편광 렌즈는 내비게이션 화면을 읽기 어렵게 만들 수 있습니다.**

## 오해 4｜차에 두면 편하다

**여름철 차 안은 60～70℃에 이르러**, **플라스틱 렌즈의 코팅이 갈라지고 프레임이 변형됩니다.** **케이스에 넣어 들고 다니십시오.**

## 오해 5｜렌즈는 옷으로 닦으면 된다

**먼지가 렌즈에 흠집을 내고 코팅이 벗겨집니다.** 안경과 마찬가지로 **먼저 물로 헹군 뒤 안경닦이를 쓰십시오**(안경 손질 글 참조). **케이스에 넣을 때 렌즈가 아래로 가지 않게 하십시오.**
