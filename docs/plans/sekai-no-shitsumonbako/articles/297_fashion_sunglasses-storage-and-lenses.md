# Q. サングラスのレンズと保管について、よくある誤解は？｜世界の質問箱 #297

- 棚：`fashion` ／ URL：`/questions/sunglasses-storage-and-lenses` ／ ステータス：**ドラフト（法務レビュー前・出典未検証）**

サングラスは「色が濃いほど目を守る」と思われがちですが、目を守るのは色ではなく紫外線カット率です。日本にはJIS規格があり、表示の読み方で選び方が変わります。保管の注意も合わせて整理します。

## A. 最大の誤解は「レンズの色が濃いほど紫外線を防ぐ」です。紫外線カットはレンズの素材・コーティングの性質で、色の濃さとは無関係です。濃い色で紫外線カットのないレンズは瞳孔が開いて紫外線を多く取り込む点で、かえって不利になります。表示（紫外線透過率1.0%以下、UV400など）を見て選び、保管は熱と傷を避けます。

## 表示の読み方（JIS T 7333）

| 表示 | 意味 |
|---|---|
| **紫外線透過率 1.0%以下** | **紫外線の99%以上をカット**。日本のJIS表示 |
| **UV400** | **波長400nmまでの紫外線をカット**（海外・業界表示） |
| **可視光線透過率** | レンズの**濃さ**。**運転には8%以上**（JIS：8%未満は運転不可）、**夜間運転は75%以上** |
| 偏光 | 反射光（水面・路面）を抑える | 液晶画面が見えにくくなることがある |
| 調光 | 紫外線量で色が変わる | 車内（UVカットガラス）では変わりにくい |

- **JIS T 7333（サングラス）**は、**紫外線透過率・可視光線透過率・運転適合性**などの表示を定めています。**ファッション用の安価なサングラスでも、JIS表示や「UVカット」の表示があるか**を確認します。
- 環境省「紫外線環境保健マニュアル」は、**紫外線による白内障・翼状片**などのリスクを挙げ、**サングラス（紫外線カット）と帽子**を勧めています。**顔にフィットし、横からの光を防ぐ形**が有効です。
- **プラスチックレンズは熱に弱く（60℃前後）**、**車のダッシュボード放置でコーティングのひび・変形**が起きます。

> 【要検証】JIS T 7333の表示項目と数値、環境省マニュアルの記載を確認してください。

## 誤解1｜色が濃いほど目を守る

**紫外線カットは色と無関係。** 濃いレンズで紫外線カットがないと、**瞳孔が開いて紫外線が多く入る**ため、かえって不利です。**「紫外線透過率1.0%以下」または「UV400」**の表示を見ます。

## 誤解2｜安いサングラスは紫外線カットがない

**価格と無関係に、表示があれば紫外線はカットされます。** 違いは**レンズの歪み・耐久性・フレームの品質**。**表示のないものは避ける**。

## 誤解3｜サングラスで運転すれば眩しくない、どれでも

**可視光線透過率8%未満は運転不可**（JIS）。**夜間・トンネルでは濃いレンズは危険**。**偏光レンズはカーナビの液晶が見えにくい**ことがあります。

## 誤解4｜車内に置いておくのが便利

**夏の車内は60〜70℃**になり、**プラスチックレンズのコーティングにひび、フレームの変形**が起きます。**ケースに入れて持ち出す**。

## 誤解5｜服でレンズを拭く

**ほこりで傷がつき、コーティングが剥がれます。** メガネと同じく**水で流してから専用クロス**（メガネの手入れの記事を参照）。**ケースはレンズを下にしない**。
