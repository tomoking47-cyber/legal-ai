# Q. 关于太阳镜的镜片与收纳，人们常有什么误解？｜Japan Questions #297

- Shelf: `fashion` ／ URL: `/zh-cn/fashion/sunglasses-storage-and-lenses` ／ Status: **草稿 — 出处未核实**

人们常以为太阳镜越深色，护眼效果越好。实际上保护眼睛的是紫外线阻隔率，而不是颜色深浅。日本有针对太阳镜的 JIS 标准，看懂它的标示会改变你的选购方式。本文也一并说明收纳时的注意事项。

## A. 最大的误解是「镜片颜色越深，挡住的紫外线越多」。紫外线防护来自镜片材质与镀膜，与颜色深浅无关。没有紫外线防护的深色镜片反而更糟：瞳孔会张得更大，让更多紫外线进入。请按标示来选（紫外线透过率 1.0% 以下、UV400 等），并避开高温与刮擦来收纳。

## 看懂标示（JIS T 7333）

| 标示 | 含义 | 备注 |
|---|---|---|
| **紫外线透过率 1.0% 以下（「紫外線透過率1.0%以下」）** | **阻隔 99% 以上的紫外线。** 日本的 JIS 标示 | |
| **UV400** | **阻隔波长 400nm 以下的紫外线**（国际／业界标示） | |
| **可见光透过率（「可視光線透過率」）** | 镜片的**深浅**。**开车用需 8% 以上**（JIS：低于 8% 不适合开车）；**夜间开车需 75% 以上** | |
| 偏光（「偏光」） | 减少反射眩光（水面、路面） | 液晶屏幕可能会看不清 |
| 调光（「調光」） | 颜色随紫外线量变化 | 在车内变化很小（车窗玻璃已阻隔紫外线） |

- **JIS T 7333（太阳镜）**规定了**紫外线透过率、可见光透过率、是否适合驾驶**等项目的标示。**即使是便宜的时尚太阳镜，也要确认有没有 JIS 标示或「UVカット」（UV cut，紫外线阻隔）标示。**
- 环境省《紫外线环境保健手册》列举了紫外线带来的**白内障、翼状胬肉**（眼球表面的增生）等风险，并建议**使用能阻隔紫外线的太阳镜与帽子**。**贴合脸型、能挡住侧面来光的形状**更有效。
- **树脂镜片不耐热（约 60℃）**；**放在车内仪表台上，镀膜会龟裂，镜片会变形**。

> **[待核实]** 标示项目与数值请对照 JIS T 7333 确认，环境省手册的措辞也请核对原文。

## 误解1｜镜片颜色越深，防护越好

**紫外线防护与颜色深浅无关。** 没有紫外线防护的深色镜片**会让瞳孔张大，反而让更多紫外线进入**，所以更糟。请在标示上找**「紫外线透过率 1.0% 以下」或「UV400」**。

## 误解2｜便宜的太阳镜挡不住紫外线

**无论价格高低，只要有标示，就能阻隔紫外线。** 差别在于**镜片的畸变、耐久性与镜架品质**。**请避开没有标示的产品。**

## 误解3｜挡开车时的眩光，什么太阳镜都行

**可见光透过率低于 8% 不适合驾驶**（JIS）。**深色镜片在夜间与隧道里很危险。** **偏光镜片可能让导航屏幕难以辨认。**

## 误解4｜放在车里很方便

**夏天车内温度可达 60～70℃**，会**让树脂镜片的镀膜龟裂、镜架变形**。**请随身带走，装进镜盒。**

## 误解5｜用衣服擦镜片

**灰尘会划伤镜片，镀膜也会剥落。** 与普通眼镜一样，**先用水冲，再用眼镜布擦**（参见眼镜保养的文章）。**放进镜盒时不要让镜片朝下。**
