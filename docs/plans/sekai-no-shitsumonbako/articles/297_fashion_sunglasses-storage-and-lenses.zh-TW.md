# Q. 關於太陽眼鏡的鏡片與收納，人們常有什麼誤解？｜Japan Questions #297

- Shelf: `fashion` ／ URL: `/zh-tw/fashion/sunglasses-storage-and-lenses` ／ Status: **草稿 — 出處未核實**

人們常以為太陽眼鏡顏色越深，護眼效果越好。實際上保護眼睛的是紫外線阻隔率，而不是顏色深淺。日本有針對太陽眼鏡的 JIS 標準，看懂它的標示會改變你的選購方式。本文也一併說明收納時的注意事項。

## A. 最大的誤解是「鏡片顏色越深，擋掉的紫外線越多」。紫外線防護來自鏡片材質與鍍膜，與顏色深淺無關。沒有紫外線防護的深色鏡片反而更糟：瞳孔會張得更大，讓更多紫外線進入。請依標示來挑選（紫外線穿透率 1.0% 以下、UV400 等），並避開高溫與刮傷來收納。

## 看懂標示（JIS T 7333）

| 標示 | 含義 | 備註 |
|---|---|---|
| **紫外線穿透率 1.0% 以下（「紫外線透過率1.0%以下」）** | **阻隔 99% 以上的紫外線。** 日本的 JIS 標示 | |
| **UV400** | **阻隔波長 400nm 以下的紫外線**（國際／業界標示） | |
| **可見光穿透率（「可視光線透過率」）** | 鏡片的**深淺**。**開車用需 8% 以上**（JIS：低於 8% 不適合開車）；**夜間開車需 75% 以上** | |
| 偏光（「偏光」） | 減少反射眩光（水面、路面） | 液晶螢幕可能會看不清楚 |
| 調光（「調光」） | 顏色隨紫外線量變化 | 在車內變化很小（車窗玻璃已阻隔紫外線） |

- **JIS T 7333（太陽眼鏡）**規定了**紫外線穿透率、可見光穿透率、是否適合駕駛**等項目的標示。**即使是便宜的流行款太陽眼鏡，也要確認有沒有 JIS 標示或「UVカット」（UV cut，紫外線阻隔）標示。**
- 環境省《紫外線環境保健手冊》列舉了紫外線帶來的**白內障、翼狀贅片**（眼球表面的增生）等風險，並建議**使用能阻隔紫外線的太陽眼鏡與帽子**。**貼合臉型、能擋住側面來光的形狀**更有效。
- **樹脂鏡片不耐熱（約 60℃）**；**放在車內儀表板上，鍍膜會龜裂，鏡片會變形**。

> **[待核實]** 標示項目與數值請對照 JIS T 7333 確認，環境省手冊的用詞也請核對原文。

## 誤解1｜鏡片顏色越深，防護越好

**紫外線防護與顏色深淺無關。** 沒有紫外線防護的深色鏡片**會讓瞳孔張大，反而讓更多紫外線進入**，所以更糟。請在標示上找**「紫外線穿透率 1.0% 以下」或「UV400」**。

## 誤解2｜便宜的太陽眼鏡擋不住紫外線

**無論價格高低，只要有標示，就能阻隔紫外線。** 差別在於**鏡片的變形、耐用度與鏡框品質**。**請避開沒有標示的產品。**

## 誤解3｜擋開車時的眩光，什麼太陽眼鏡都行

**可見光穿透率低於 8% 不適合駕駛**（JIS）。**深色鏡片在夜間與隧道裡很危險。** **偏光鏡片可能讓導航螢幕難以辨認。**

## 誤解4｜放在車上很方便

**夏天車內溫度可達 60～70℃**，會**讓樹脂鏡片的鍍膜龜裂、鏡框變形**。**請隨身帶走，裝進眼鏡盒。**

## 誤解5｜用衣服擦鏡片

**灰塵會刮傷鏡片，鍍膜也會剝落。** 與一般眼鏡一樣，**先用水沖，再用眼鏡布擦**（參見眼鏡保養的文章）。**放進眼鏡盒時不要讓鏡片朝下。**
