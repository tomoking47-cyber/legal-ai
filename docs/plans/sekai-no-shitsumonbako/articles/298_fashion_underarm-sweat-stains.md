# Q. 脇の汗じみと黄ばみについて、よくある誤解は？｜世界の質問箱 #298

- 棚：`fashion` ／ URL：`/questions/underarm-sweat-stains` ／ ステータス：**ドラフト（法務レビュー前・出典未検証）**

シャツの脇の黄ばみは世界共通の悩みで、「制汗剤が原因か、汗が原因か」が海外のフォーラムで繰り返し問われます。日本の夏の汗と制汗剤文化を踏まえて、原因と落とし方を整理します。

## A. 最大の誤解は「脇の黄ばみは汗の色」です。汗はほぼ無色で、黄ばみの主因は皮脂の酸化と、制汗剤のアルミニウム成分・皮脂・汗が繊維で反応したものです。予防は「着たらすぐ洗う」「制汗剤は乾いてから服を着る」、落とし方は「酸素系漂白剤のつけ置きまたはペースト」で、塩素系は避けます。

## 原因と対処

| 原因 | 仕組み | 対処 |
|---|---|---|
| **皮脂の酸化** | 洗い残した皮脂が時間とともに黄変 | **着用後すぐ洗う**、**脇を予洗い（中性洗剤を直接つけて軽くもむ）** |
| **制汗剤の成分** | アルミニウム塩＋汗＋皮脂が繊維に付着し、**黄ばみ・硬化** | **制汗剤が乾いてから着る**、**量を控える**、**寝る前に塗る（朝は薄く）** |
| **アポクリン汗** | 脇の汗腺（アポクリン腺）の汗はたんぱく質・脂質を含み、酸化で色づく | **汗取りパッド（衣類用・貼るタイプ）**、**インナー** |
| **繊維** | 綿は黄ばみやすい、ポリエステルは匂いが残りやすい | **白いシャツは酸素系漂白で定期的に** |

### 落とし方

| 段階 | 方法 |
|---|---|
| 軽い黄ばみ | **酸素系漂白剤（液体）を直接つけて30分→通常洗濯** |
| 定着した黄ばみ | **酸素系漂白剤（粉末）を40〜50℃のお湯に溶かし、30分〜2時間つけ置き**（**表示の温度と漂白記号を確認**） |
| 硬くなった制汗剤の付着 | **酸素系漂白剤の粉末＋重曹を少量の水でペースト→塗って30分→ブラシで軽く→洗濯** |
| 落ちない | **クリーニング店に「黄ばみ」と伝えて相談**。**塩素系は使わない**（色柄物は脱色、白物でも生地・ボタンが変色） |

> 【要検証】漂白記号の区分は消費者庁「洗濯表示」、制汗剤の成分は製品表示で確認してください。落とし方は洗剤メーカーの一般的な案内です。

## 誤解1｜黄ばみは汗の色だから汗を止めればよい

**汗はほぼ無色。皮脂と制汗剤の反応**が主因です。**制汗剤を減らして黄ばみが減った**という経験は多く語られています。

## 誤解2｜塩素系漂白剤なら確実に落ちる

**塩素系は制汗剤のアルミニウムと反応してかえって黄変・生地の傷み**を起こすことがあります。**酸素系**が基本。

## 誤解3｜制汗剤を多く塗るほど汗じみは防げる

**過量は繊維への付着と黄ばみ・硬化**を増やします。**適量を、乾いてから着る**。**夜塗り**は汗の少ない時間に働き、朝の量を減らせます（制汗剤の記事を参照）。

## 誤解4｜黄ばんだら捨てるしかない

**酸素系のつけ置きで多くは薄くなります。** **早いほど落ちやすい**。**衣替え前の一斉つけ置き**が日本の生活者の定番です。

## 誤解5｜汗取りパッドは大げさ

**貼るタイプの汗取りパッドはシャツの寿命を延ばす最も確実な予防**で、日本では日用品として定着しています。**インナー（脇汗パッド付き）**も同様。
