# Q. 靴のにおい対策について、よくある誤解は？｜世界の質問箱 #299

- 棚：`fashion` ／ URL：`/questions/shoe-odour` ／ ステータス：**ドラフト（法務レビュー前・出典未検証）**

靴を脱ぐ文化の日本では、靴のにおいは玄関で他人に知られる悩みです。「消臭スプレーで解決するか」「毎日同じ靴でよいか」は海外でも共通の質問で、においの原因を知ると対策が変わります。

## A. 最大の誤解は「においは足の汗そのものの臭い」です。汗はほぼ無臭で、においは靴の中の湿気と皮脂・角質を細菌が分解して出る物質（イソ吉草酸など）です。対策の順は「靴を乾かす（連日履かない、中敷きを外す）」「足を清潔に（指の間まで洗う、靴下は毎日）」「消臭・除湿は補助」です。

## 原因と対策

| 原因 | 仕組み | 対策 |
|---|---|---|
| **湿気** | 足は1日約200mLの汗。靴の中は**湿度90%・35℃前後**になる | **1日履いたら1〜2日乾かす**、**中敷きを外す**、**乾燥剤・新聞紙・木製シューキーパー** |
| **細菌** | 皮脂・角質を分解して**イソ吉草酸・酢酸など**を出す | **靴下は毎日替える**、**足の指の間・爪の間まで洗う**、**角質ケア**（かかとの記事を参照） |
| **素材** | 合皮・ゴムは通気性が低く乾きにくい | **通気性のある素材**、**ローテーション** |
| **靴下** | 化繊は速乾だが匂いが残る、綿は吸うが乾きにくい | **吸湿・速乾の混紡**、**5本指**、**替えの靴下を持つ** |
| 洗える靴 | スニーカー等 | **月1回洗って完全に乾かす**（スニーカーの記事を参照） |

- **消臭スプレー・消臭剤**は**においの物質を分解・吸着**する補助で、**細菌と湿気を減らさなければ翌日には戻ります。**
- **重曹**（弱アルカリ）は**酸性のイソ吉草酸を中和**するため、**布袋に入れて靴に入れる**方法が日本の生活者の間で共有されています。**粉を直接入れると白く残る**。
- **10円硬貨（銅）**を入れる方法は、**銅の抗菌性**に基づく俗説で、**効果は限定的**とされます。**一時的に湿気を取る新聞紙**のほうが確実です。
- **足のにおいが強く、皮がむける・かゆい**場合は**足白癬（水虫）**の可能性があり、皮膚科へ。

> 【要検証】発汗量・靴内の温湿度は一般的な記載です。においの成分は日本皮膚科学会・繊維団体の資料で確認してください。

## 誤解1｜消臭スプレーで解決

**においを一時的に抑えるだけ**です。**乾かす・洗う・靴下を替える**が先。

## 誤解2｜毎日同じ靴で問題ない

**靴の中は一晩で乾きません。** **2〜3足のローテーション**が最も効く対策です。

## 誤解3｜靴を天日で干せば殺菌できる

**直射日光は革を硬くし、合皮を劣化させます。** **風通しのよい日陰で、中敷きを外して**。**紫外線の殺菌効果は表面のみ**。

## 誤解4｜足を石けんで洗えば十分

**指の間・爪の周り・かかとの角質**に細菌が残ります。**指の間まで洗い、完全に乾かしてから靴下**。**爪は短く**。

## 誤解5｜においは体質だから仕方ない

**湿気と細菌の問題**で、**靴と靴下と洗い方**で大きく変わります。**改善しない・皮がむける・かゆい**なら**皮膚科**へ。
