# Q. マットレスの硬さについて、よくある誤解は？｜世界の質問箱 #303

- 棚：`health` ／ URL：`/questions/mattress-firmness` ／ ステータス：**ドラフト（法務レビュー前・出典未検証）**

「硬いマットレスが腰にいい」という説は日本で特に根強く、畳に敷布団の伝統と結びついています。海外では逆に「柔らかいほど快適」とされることも多い。腰痛の研究と業界の一般的な案内から、確かなことだけを整理します。

## A. 最大の誤解は「腰痛には硬いマットレスがよい」です。研究では、極端に硬いものより「中程度の硬さ」のほうが腰痛のある人の睡眠と痛みに良い結果が多く報告されています。基本は、横になったときに背骨が自然なS字を保ち、寝返りがしやすい硬さで、体重と寝姿勢で異なります。

## 判断の材料

| 項目 | 内容 |
|---|---|
| 研究 | **中程度の硬さ（medium-firm）**が、硬いものより腰痛患者の痛みと睡眠の質で優れたとする無作為化試験（Kovacs ら、Lancet 2003）が広く引用される |
| 目安 | **仰向けで腰と背中にすき間がない**、**横向きで背骨が床と平行**、**寝返りが楽** |
| 体重 | 体重が**軽い人は柔らかめ**、**重い人は硬め**が沈み込みの点で合いやすい |
| 寝姿勢 | **横向きが多い人は肩と腰が沈む柔らかさ**、**仰向けはやや硬め** |
| 敷布団（畳） | **薄いと硬すぎて腰・肩に圧が集中**。**3〜5cm以上の厚み**、または**マットレスを下に** |
| 買い替え | **へたり（体の跡が戻らない）、腰が沈む、朝の腰痛**。目安**7〜10年** |

- 日本の伝統的な**敷布団は薄く硬い**ため、「硬い＝腰にいい」の認識が生まれたとされますが、**現在の整形外科・寝具業界の一般的な案内は「中程度」**です。
- **日本整形外科学会**は腰痛に関して、**寝具は「体が沈み込まず、寝返りしやすいもの」**と案内しています。
- **枕との組み合わせ**で首と背骨の並びが決まります（枕の記事を参照）。

> 【要検証】研究の引用はKovacs FM et al., Lancet 2003; 362:1599-1604。整形外科学会の記載を確認してください。

## 誤解1｜腰痛には硬い床や板がよい

**硬すぎると腰・肩の一点に圧がかかり、寝返りが増えて眠りが浅くなります。** 研究では**中程度**が優位でした。

## 誤解2｜柔らかいほど快適で体にもよい

**沈み込みすぎると腰が曲がった姿勢で固定され、寝返りがしにくくなります。** 朝の腰の張りの原因の一つ。

## 誤解3｜高いマットレスほど体にいい

**価格と適合は別**です。**体重・寝姿勢・好み**で決まり、**店で10分以上横になって試す**、**返品保証のある製品を選ぶ**のが実践的。

## 誤解4｜マットレスは買い替え不要

**へたりで機能は落ちます。** **7〜10年**、または**体の跡が戻らなくなったら**。**定期的に上下・裏表を返す**と長持ちします。

## 誤解5｜敷布団は畳に直接敷くのが日本式で正しい

**薄い敷布団1枚は硬すぎる**ことが多く、**マットレスや厚めの敷パッドを下に敷く**のが現在の一般的な使い方です。**湿気対策（すのこ・上げる）**も必要です。
