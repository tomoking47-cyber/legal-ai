# Q. 關於炒菜的火候，人們常有哪些誤解？｜Japan Questions #317

- Shelf: `trend` ／ URL: `/zh-tw/trend/stir-fry-heat` ／ Status: **草稿 — 出處未核實**

「大火快炒」是從中式餐館的做菜方式流傳開來的常識，但家用爐具配平底鍋是另一回事。日本的瓦斯爐還裝有安全感應器，會自己把火轉小，這讓許多剛來的人一頭霧水。以下從家用爐具的火力、不沾塗層的耐熱溫度與油噴濺的成因來整理。

## A. 最大的誤解是「在家裡也要用大火一口氣炒好」。專業的中華爐火力是家用爐具的數倍；在家用爐的大火上照做，不沾塗層會劣化、油會冒煙，結果外面焦了裡面還是生的。在家裡要炒得爽脆，條件是：用中火充分預熱、食材不要一次放太多、把水分瀝乾。

## 以數字來看

| 項目 | 內容 |
|---|---|
| 家用瓦斯爐的火力 | **約 2,000〜4,200 kcal/h**（大火力爐頭）。營業用中華爐為 **10,000〜30,000 kcal/h** |
| IH 電磁爐 | **最大 2,000〜3,000 W**。只加熱鍋底，**側面不會變熱** |
| 不沾塗層的耐熱 | **約 260℃ 開始劣化**；乾燒或大火預熱時就會達到 |
| 食用油的發煙點 | **約 230〜250℃**（精製油） |
| 炒菜的適當溫度 | **170〜200℃**（油剛要輕微冒煙之前） |
| 食材的量 | **最多放到鍋底面積的 1/2〜2/3。** **放太多會使溫度下降、出水，變成用煮的** |

- **Si 感應器爐具（2008 年起裝在日本的瓦斯爐上）**會**在約 250℃ 時自動把火轉小**，所以**「明明開大火，火卻變弱」正是感應器在作用**。有些機型有**高溫熱炒模式**可暫時解除，但**這不適合不沾鍋**。
- **鐵製平底鍋**耐高溫，**適合大火熱炒**（參見本刊的鐵鍋文章）。**不沾塗層最多用中火。**
- **油噴濺的主因是水分。** **請把蔬菜的水瀝乾；冷凍食材請解凍或把霜敲掉。**

> **[待核實]** 火力數值請對照爐具製造商與日本瓦斯石油機器工業會（JGKA）的資料，Si 感應器的動作請對照經濟產業省的資料確認。

## 誤解1｜火越大越爽脆

**在家用爐具的火力下，「充分預熱＋少量分批」比大火更有效。** 食材放太多會**讓溫度下降、逼出水分**——這是炒菜變得軟爛的主因。

## 誤解2｜不沾鍋要用大火預熱

**空鍋用大火加熱會超過 260℃，使塗層劣化。** **請用中火預熱，加油之後再加熱。** **一冒煙就代表太熱了。**

## 誤解3｜爐具自己把火轉小是故障

**這是 Si 感應器在約 250℃ 時啟動了。** 這同時也是**油溫過高的訊號**。

## 誤解4｜IH 火力太弱，炒不了菜

**IH 的熱效率約 90%，瓦斯約 40〜55%，鍋底可以達到足夠的溫度。** **鍋一離開爐面就會停止加熱**，所以**請讓鍋貼著爐面翻炒**——這就是 IH 的做法。請使用**平底的 IH 對應鍋具**。

## 誤解5｜多放油就不會黏鍋

**黏鍋來自火力不足與水分過多。** **油約一大匙，並充分預熱。** **用鐵鍋時請做「油返し」（abura-gaeshi — 讓熱油在鍋內繞一圈後倒出）**（參見本刊的鐵鍋文章）。
