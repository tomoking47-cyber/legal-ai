# Q. 魚焼きグリルの使い方と掃除について、よくある誤解は？｜世界の質問箱 #318

- 棚：`trend` ／ URL：`/questions/fish-grill` ／ ステータス：**ドラフト（法務レビュー前・出典未検証）**

日本のガスこんろに付いている魚焼きグリルは、海外の人から「これは何のための引き出しか」と聞かれる装備です。使い方と、最も嫌われる掃除の方法、そして火災の注意を整理します。

## A. 最大の誤解は「魚焼きグリルは魚を焼く以外に使えず、掃除が大変だから使わない」です。グリルは高温の直火オーブンで、魚のほか、トースト・野菜・鶏肉・餅に使えます。掃除は「使用後すぐ、受け皿の水または専用シートを使う、網は重曹水につける」で楽になり、受け皿の油をためたままの使用は火災の原因です。

## 使い方と手入れ

| 項目 | 内容 |
|---|---|
| 種類 | **水あり**（受け皿に水を張る。油はねと煙を抑える）／**水なし**（受け皿に水不要、掃除は簡単だが油の処理が要） |
| 温度 | **両面焼きで約300〜400℃**。**予熱1〜2分** |
| 魚以外 | **トースト（1〜2分）、野菜（ピーマン・なす）、鶏肉、餅、油揚げ、焼きおにぎり** |
| 掃除（受け皿） | **使用後、冷めたらすぐ**。**水ありは水を捨てて洗剤で**、油が固まる前に。**アルミホイルや専用シートを敷く**と楽（**水ありグリルに敷く場合は説明書の可否を確認**） |
| 掃除（網） | **重曹水（40℃、水1Lに大さじ2）に30分つけて、スポンジで**。**焦げは重曹ペースト** |
| 掃除（庫内・扉） | 月1回、中性洗剤で。**魚のにおいは、使用後に茶葉やコーヒーかすを受け皿で焼く**という生活者の工夫 |

- **グリル火災**：東京消防庁は**受け皿にたまった油に火がつく**事故を毎年報告し、**「受け皿に油をためたまま使わない」「水ありグリルには規定量の水」「使用中に離れない」**を注意しています。
- **Siセンサーこんろのグリルには過熱防止機能・消し忘れタイマー**（多くは**15〜20分で自動消火**）があります。
- **グリルのにおい**は、**受け皿の油と網の焦げ**が主因。**使用後すぐの掃除**が最も効きます。

> 【要検証】火災事例は東京消防庁の火災統計、グリルの安全機能は日本ガス石油機器工業会・メーカーの資料で確認してください。

## 誤解1｜グリルは魚専用

**300℃以上の直火オーブン**で、**トーストは1〜2分**、野菜・鶏肉・餅に向きます。日本の生活者は**「トースターを置かずグリルで」**という使い方も多いです。

## 誤解2｜掃除は月に1回まとめて

**油は冷えると固まり、たまると火災の原因**です。**使用後、冷めたらすぐ**が唯一の楽な方法。**シートやホイルを敷く**（説明書で可否を確認）。

## 誤解3｜受け皿の水は省いてよい

**水ありグリルは、水が油はねと煙を抑え、火災を防ぐ設計**です。**規定量の水を必ず**。**水なしグリルは水を入れない**（逆に故障の原因）。

## 誤解4｜においは消臭剤でごまかす

**においの元は油と焦げ**です。**掃除が先**。**茶葉・コーヒーかすを焼く**のは、掃除後の仕上げ。

## 誤解5｜アルミホイルはどのグリルにも敷ける

**水ありグリルの受け皿にホイルを敷くと、水が蒸発しにくく、油が直接火に触れる**ことがあり、**禁止している機種**があります。**取扱説明書を確認**。**網にホイルを敷く場合は、穴を開けて油を落とす**。
