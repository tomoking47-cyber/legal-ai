# Q. 關於烤魚爐（魚焼きグリル）的使用與清潔，人們常有哪些誤解？｜Japan Questions #318

- Shelf: `trend` ／ URL: `/zh-tw/trend/fish-grill` ／ Status: **草稿 — 出處未核實**

日本瓦斯爐內建的烤魚爐，是讓外國訪客忍不住問「這個抽屜是做什麼用的？」的那個裝備。它是位在爐頭下方的小型直火烤箱，多數租屋的廚房都有。以下整理它的用法、大家最怕的清潔方法，以及隨之而來的火災提醒。

## A. 最大的誤解是「烤魚爐只能烤魚，清潔太麻煩，不如不要用」。烤爐是高溫的直火烤箱，除了魚，也能做吐司、蔬菜、雞肉與麻糬。清潔方面，只要用完馬上清、在承油盤裡放水或使用專用墊紙、把烤網泡在小蘇打水裡，就會變得輕鬆。承油盤積著油還繼續使用，是火災的原因之一。

## 用法與保養

| 項目 | 內容 |
|---|---|
| 種類 | **有水型**（在承油盤中加水；減少油噴濺與煙）／**無水型**（不需加水；清潔較簡單，但要處理油） |
| 溫度 | **雙面燒機型約 300〜400℃。** **預熱 1〜2 分鐘** |
| 魚以外 | **吐司（1〜2 分鐘）、蔬菜（青椒、茄子）、雞肉、麻糬（餅）、豆皮（油揚げ）、烤飯糰（焼きおにぎり）** |
| 清潔（承油盤） | **用完放涼後馬上清。** **有水型請倒掉水，趁油凝固前用清潔劑清洗。** **鋪上鋁箔紙或專用烤爐墊紙**會更輕鬆（**要鋪在有水型烤爐上時，請先確認說明書是否允許**） |
| 清潔（烤網） | **泡在小蘇打水（重曹，jūsō；40℃ ／ 104°F，每公升水 2 大匙）中 30 分鐘，再用海綿刷洗。** **焦垢用小蘇打糊** |
| 清潔（爐內與門） | 每月一次，用中性清潔劑。**魚腥味可在用完後把茶葉渣或咖啡渣放在承油盤裡烤一烤**——這是生活者的小撇步 |

- **烤爐火災**：東京消防廳每年都報告**承油盤中積存的油起火**的事故，並提醒：**「承油盤積著油時不要使用」「有水型烤爐請加規定量的水」「使用中不要離開」**。
- **搭載 Si 感應器的爐具，其烤爐具有過熱防止功能與忘記關火自動計時器**（多數**在 15〜20 分鐘後自動熄火**）。
- **烤爐的異味**主要來自**承油盤裡的油與烤網上的焦垢**。**用完馬上清潔**最有效。

> **[待核實]** 火災案例請對照東京消防廳的火災統計，烤爐的安全功能請對照日本瓦斯石油機器工業會（JGKA）與製造商資料確認。

## 誤解1｜烤爐只能烤魚

**它是 300℃ 以上的直火烤箱**：**吐司 1〜2 分鐘**就好，也適合蔬菜、雞肉與麻糬。日本很多人**不放烤麵包機，直接用烤爐**。

## 誤解2｜一個月集中清一次就好

**油會隨著冷卻凝固，積存的油還會引發火災。** **用完放涼後馬上清**，是唯一輕鬆的辦法。**在承油盤裡鋪墊紙或鋁箔**（請確認說明書）。

## 誤解3｜承油盤裡的水可以省

**有水型烤爐的設計前提，就是靠水抑制油噴濺與煙並防止火災。** **請務必加規定量的水。** **絕對不要對無水型烤爐加水**（會造成故障）。

## 誤解4｜用除臭劑蓋住味道

**氣味的來源是油與焦垢。** **請先清潔。** **烤茶葉渣或咖啡渣**是清潔之後的收尾。

## 誤解5｜任何烤爐都可以鋪鋁箔

**在有水型烤爐的承油盤鋪鋁箔，會妨礙水正常蒸發，還可能讓油直接接觸火焰**；**有些機型明令禁止**。**請查閱使用說明書。** **若要在烤網上鋪鋁箔，請戳孔讓油能流下去。**
