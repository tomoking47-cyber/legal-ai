# Q. 일본에서 오븐을 쓰는 것에 대해 흔히 하는 오해는 무엇입니까?｜Japan Questions #319

- Shelf: `trend` ／ URL: `/ko/trend/using-an-oven` ／ Status: **초안 — 출처 미확인**

일본 가정의 오븐은 전자레인지 일체형(オーブンレンジ, 오븐레인지)이 많아, 해외에서 흔한 대형 오븐과는 용량·온도·예열 속도가 다릅니다. 고향의 레시피대로 구웠는데 결과가 다른 이유는 대개 여기에 있습니다. 무엇이 결과를 바꾸는지, 그리고 어떻게 대처하면 되는지 정리합니다.

## A. 가장 큰 오해는 "레시피의 온도와 시간을 지키면 똑같이 구워진다"는 생각입니다. 기종에 따라 실제 고내 온도가 표시보다 10〜30℃ 어긋날 수 있고, 예열을 건너뛰는 것, 팬의 위치, 문을 여는 것 모두가 결과를 크게 바꿉니다. 기본은 예열을 반드시 하고 완료 신호 뒤에도 5〜10분 더 두는 것, 오븐용 온도계로 한 번 확인하는 것, 도중에 팬의 방향을 바꾸는 것, 그리고 색과 꼬치로 판단하는 것입니다.

## 판단의 근거

| 항목 | 내용 |
|---|---|
| 예열 | **반드시. 예열 완료 표시 후 5〜10분 더** 두면 고내 전체가 안정됩니다(레인지 일체형은 벽이 얇아 잘 식습니다) |
| 온도 오차 | **표시와 실제 온도가 10〜30℃ 어긋나는 기종**이 있습니다. **오븐용 온도계(수백 엔)로 한 번 확인** |
| 팬 | **검은 팬은 색이 진하게**, **밝은 팬은 연하게** 납니다. **위 칸은 색내기, 아래 칸은 천천히 속까지** |
| 문 | **열 때마다 고내 온도가 수십 도 떨어집니다.** **도중 확인은 최소한으로, 빠르게** |
| 열풍(컨벡션) 모드 | 온도는 **레시피보다 10〜20℃ 낮게** 잡는 것이 기준입니다(열이 강하게 닿습니다) |
| 전자레인지 일체형 | **오븐을 쓴 뒤에는 고내가 뜨거워 한동안 레인지 기능을 쓸 수 없습니다.** **고내가 작고 팬은 한 장** |
| 안전 | **오븐 사용 중과 직후의 문 유리는 200℃ 이상.** **어린이 화상**(소비자청), **내열이 아닌 용기(보통 유리, 플라스틱)는 넣을 수 없음** |

- 일본의 **전자레인지 일체형 오븐**은 **고내 용량 20〜30 L**가 주류로, 해외에서 흔한 **60〜70 L 거치형**보다 **작고 온도 변동이 큽니다**.
- **쿠킹 시트(クッキングシート, 내열 250℃ 정도)**는 **표시 온도를 넘으면 타므로**, **250℃ 이상의 레시피에는 쓰지 말고** **히터에 닿게 하지 마십시오**.
- **알루미늄 포일은 레인지 기능에서는 불가, 오븐 기능에서는 가능합니다**(일체형은 모드 전환에 주의).

> **[확인 필요]** 용량과 온도 특성은 각 제조사의 취급설명서를 따라 주십시오. 화상 사고는 소비자청 자료로 확인해 주십시오.

## 오해 1｜예열은 건너뛰어도 된다

**예열하지 않으면 반죽이 퍼지고 부풀지 않거나, 겉에 색이 나기 전에 속이 말라 버립니다.** **완료 신호 뒤에 몇 분 더 기다리는 것**이 일본 가정용 오븐의 현실입니다.

## 오해 2｜표시 온도는 정확하다

**기종에 따라 10〜30℃의 오차가 있다는 것은 잘 알려져 있습니다.** **오븐용 온도계로 한 번 확인해** 내 오븐의 「보정값」을 파악하십시오.

## 오해 3｜자주 문을 열어 확인한다

**열 때마다 온도가 떨어져 굽는 색이 고르지 않고 잘 부풀지 않습니다.** **창으로 보고, 굽는 시간이 끝나갈 무렵에 한 번만 여십시오.**

## 오해 4｜유리 그릇이면 무엇이든 오븐에 넣어도 된다

**내열 표시가 없는 유리·플라스틱과 일부 도자기는 깨집니다.** **「オーブン使用可」(오븐 사용 가능) 표시를 확인하십시오.** **뚝배기(土鍋)와 법랑은 대체로 괜찮습니다**(표시를 확인).

## 오해 5｜해외 레시피는 여기서도 똑같이 구워진다

**해외의 거치형 오븐과 일본의 일체형 오븐은 고내 크기와 열 안정성이 다릅니다.** **온도계로 확인하고, 팬의 위치와 방향을 조정하고, 색으로 판단하는 것** — 일본 가정에서 공유되는 방법입니다.
