# Q. オーブンの使い方について、よくある誤解は？｜世界の質問箱 #319

- 棚：`trend` ／ URL：`/questions/using-an-oven` ／ ステータス：**ドラフト（法務レビュー前・出典未検証）**

日本の家庭のオーブンは電子レンジ一体型が多く、海外の大型オーブンとは容量・温度・予熱の速さが異なります。レシピの温度どおりに焼いても違う結果になる理由と、対処を整理します。

## A. 最大の誤解は「レシピの温度と時間を守れば同じに焼ける」です。オーブンは機種によって実際の庫内温度が表示から10〜30℃ずれることがあり、予熱なし・天板の位置・扉の開閉で大きく変わります。基本は「予熱を必ず、表示より5〜10分余分に」「オーブン用温度計で一度確認」「途中で天板の向きを変える」「焼き色と竹串で判断」です。

## 判断の材料

| 項目 | 内容 |
|---|---|
| 予熱 | **必ず。表示の予熱完了後、さらに5〜10分**置くと庫内全体が安定（レンジ一体型は壁が薄く冷めやすい） |
| 温度のずれ | **表示と実温が10〜30℃ずれる機種**がある。**オーブン用温度計（数百円）で1回確認** |
| 天板 | **黒い天板は焼き色が濃く**、**明るい天板は薄い**。**上段は焼き色、下段はじっくり** |
| 扉 | **開けるごとに庫内温度が数十℃下がる**。**途中確認は最小限、素早く** |
| 熱風（コンベクション）モード | 温度は**表示より10〜20℃下げる**のが目安（熱の当たりが強い） |
| 電子レンジ一体型 | **オーブン使用後は庫内が熱く、レンジ機能が使えない時間**がある。**庫内が小さく、天板1枚** |
| 安全 | **オーブン使用中・直後の扉のガラスは200℃以上**。**子どものやけど**（消費者庁）、**耐熱でない容器（普通のガラス・プラスチック）は不可** |

- 日本の**電子レンジ一体型オーブン**は**庫内容量20〜30L**が主流で、海外の**60〜70Lの据置型**より**小さく、温度の変動が大きい**。
- **クッキングシート（耐熱250℃程度）**は**表示温度を超えると燃える**ため、**250℃以上のレシピでは使わない**、**ヒーターに触れさせない**。
- **アルミホイルは電子レンジ機能では不可、オーブン機能では可**（レンジ一体型は切り替えに注意）。

> 【要検証】容量・温度の特性は各メーカーの取扱説明書に従ってください。やけど事故は消費者庁の資料で確認してください。

## 誤解1｜予熱は省略してもよい

**予熱なしでは、生地が広がって膨らまない、外が焼ける前に中が乾く**などの失敗が起きます。**完了後さらに数分**待つのが日本の家庭オーブンの実際。

## 誤解2｜表示温度は正確

**機種によって10〜30℃ずれる**ことが知られています。**オーブン用温度計で一度確認**し、自分のオーブンの「補正値」を知る。

## 誤解3｜途中で何度も開けて確認する

**開けるごとに温度が下がり、焼きムラと膨らみ不足**の原因。**窓から見る、焼き時間の終盤に1回**。

## 誤解4｜どんなガラス容器もオーブンに入れられる

**耐熱表示のないガラス・プラスチック・一部の陶器は割れます。** **「オーブン使用可」の表示**を確認。**土鍋・ホーローは可のものが多い**（表示で）。

## 誤解5｜海外のレシピどおりに焼ける

**海外の据置型オーブンと日本のレンジ一体型では、庫内の大きさと熱の安定が違います。** **温度計で確認、天板の位置と向きを調整、焼き色で判断**が、日本の家庭で共有される実践です。
