# Q. 关于在日本使用烤箱，人们常有哪些误解？｜Japan Questions #319

- Shelf: `trend` ／ URL: `/zh-cn/trend/using-an-oven` ／ Status: **草稿 — 出处未核实**

日本家庭的烤箱大多是微波炉一体型的「オーブンレンジ」（ōbun renji，微波炉烤箱），在容量、温度和预热速度上都与国外常见的大型烤箱不同。从老家带来的食谱在这里做不出同样的结果，原因通常就在这里。以下梳理什么会改变结果，以及该怎么应对。

## A. 最大的误解是「按食谱的温度和时间做就能烤出一样的东西」。视机型而定，烤箱内的实际温度可能与显示相差 10〜30℃，而不预热、烤盘的位置和开门都会大幅改变结果。基本做法是：一定要预热，并在提示音之后再多等 5〜10 分钟；用烤箱温度计确认一次；中途把烤盘转个方向；靠上色和竹签来判断。

## 判断的依据

| 项目 | 内容 |
|---|---|
| 预热 | **务必进行。显示预热完成后，再等 5〜10 分钟**，让整个内腔稳定下来（微波炉一体型的壁薄，散热快） |
| 温度偏差 | **有些机型的实际温度与显示相差 10〜30℃。** **用烤箱温度计（几百日元）确认一次** |
| 烤盘 | **深色烤盘上色更深**，**浅色烤盘上色更浅**。**上层用于上色，下层用于慢慢烤透** |
| 门 | **每开一次，内腔温度就下降几十度。** **中途确认要尽量少、尽量快** |
| 热风（对流）模式 | 参考标准是**比食谱温度低 10〜20℃**（热量冲击更强） |
| 微波炉一体型 | **使用烤箱功能后内腔很热，有一段时间无法使用微波功能。** **内腔小，只有一张烤盘** |
| 安全 | **使用烤箱功能时及刚用完时，门玻璃在 200℃ 以上。** **儿童烫伤**（消费者厅）；**非耐热的容器（普通玻璃、塑料）不可放入** |

- 日本的**微波炉一体型烤箱**大多是**内腔容量 20〜30 L**，比国外常见的**60〜70 L 独立式烤箱**更**小，温度波动也更大**。
- **烘焙纸（クッキングシート，kukkingu shīto；耐热约 250℃）**在**超过标示温度时会燃烧**，因此**250℃ 以上的食谱不要使用**，并且**不要让它碰到加热管**。
- **铝箔：微波功能不可用，烤箱功能可用**（一体型机型在切换模式时请注意）。

> **[待核实]** 容量与温度特性请遵循各厂商的使用说明书。烫伤事故请对照消费者厅的资料核查。

## 误解1｜预热可以省略

**不预热的话，面团会摊开、发不起来，或者外面还没上色里面就干了。** **在提示音后再多等几分钟**，才是日本家用烤箱的实际情况。

## 误解2｜显示温度是准确的

**视机型有 10〜30℃ 的偏差，这是众所周知的。** **用烤箱温度计确认一次**，掌握自家烤箱的「修正值」。

## 误解3｜要常开门查看

**每开一次门温度就下降，导致烤色不均、膨发不良。** **请隔着窗口看；只在接近烤制结束时开一次。**

## 误解4｜任何玻璃器皿都能放进烤箱

**没有耐热标示的玻璃、塑料和部分陶瓷会开裂。** **请确认是否有「オーブン使用可」（可用于烤箱）的标示。** **砂锅（土鍋）和珐琅多数没问题**（请确认标示）。

## 误解5｜国外的食谱在这里也烤得一样

**国外的独立式烤箱与日本的一体型烤箱，在内腔大小和热稳定性上都不同。** **用温度计确认、调整烤盘的位置与方向、靠上色判断**——这是日本家庭之间共享的做法。
