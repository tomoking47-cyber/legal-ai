# Q. 關於在日本使用烤箱，人們常有哪些誤解？｜Japan Questions #319

- Shelf: `trend` ／ URL: `/zh-tw/trend/using-an-oven` ／ Status: **草稿 — 出處未核實**

日本家庭的烤箱多半是微波爐一體型的「オーブンレンジ」（ōbun renji，微波烤箱），在容量、溫度與預熱速度上都和國外常見的大型烤箱不同。從老家帶來的食譜在這裡做不出同樣的成果，原因通常就在這裡。以下整理有哪些因素會改變結果，以及該怎麼因應。

## A. 最大的誤解是「照食譜的溫度與時間做就會烤出一樣的東西」。依機型而定，爐內實際溫度可能與顯示相差 10〜30℃，而不預熱、烤盤的位置與開門都會大幅改變結果。基本做法是：一定要預熱，並在提示音之後再多等 5〜10 分鐘；用烤箱溫度計確認一次；中途把烤盤轉個方向；靠上色與竹籤判斷。

## 判斷的依據

| 項目 | 內容 |
|---|---|
| 預熱 | **務必進行。顯示預熱完成後，再等 5〜10 分鐘**，讓整個爐內穩定（微波爐一體型的壁薄，容易散熱） |
| 溫度誤差 | **有些機型的實際溫度與顯示相差 10〜30℃。** **用烤箱溫度計（幾百日圓）確認一次** |
| 烤盤 | **深色烤盤上色較深**，**淺色烤盤上色較淺**。**上層用來上色，下層用來慢慢烤透** |
| 門 | **每開一次，爐內溫度就下降數十度。** **中途確認要盡量少、盡量快** |
| 熱風（對流）模式 | 參考標準是**比食譜溫度低 10〜20℃**（熱的衝擊較強） |
| 微波爐一體型 | **用完烤箱功能後爐內很燙，有一段時間無法使用微波功能。** **爐內小，只有一張烤盤** |
| 安全 | **使用中與剛用完時門的玻璃溫度很高**（國民生活中心的試驗中，爐具烤爐門窗中心最高約 **150℃**，**用完後約 15 分鐘內仍在 50℃ 以上**）。**注意兒童燙傷**（國民生活中心）；**非耐熱的容器（普通玻璃、塑膠）不可放入** |

- 日本的**微波爐一體型烤箱**多為**爐內容量 20〜30 L**，比國外常見的 **60〜70 L 獨立式烤箱更小，溫度變動也更大**。
- **烘焙紙（クッキングシート，kukkingu shīto；耐熱約 250℃）**在**超過標示溫度時會燃燒**，因此**250℃ 以上的食譜請勿使用**，也**不要讓它碰到加熱管**。
- **鋁箔：微波功能不可，烤箱功能可以**（一體型機型切換模式時請留意）。

> **[待核實]** 容量與溫度特性請依各製造商的使用說明書。燙傷事故請對照消費者廳的資料確認。

## 誤解1｜預熱可以省略

**不預熱的話，麵團會攤開、發不起來，或是外面還沒上色裡面就乾了。** **在提示音之後再多等幾分鐘**，才是日本家用烤箱的實際情況。

## 誤解2｜顯示溫度是準確的

**依機型有 10〜30℃ 的誤差，這是眾所周知的。** **用烤箱溫度計確認一次**，掌握自家烤箱的「修正值」。

## 誤解3｜要常常開門查看

**每開一次門溫度就下降，造成上色不均與膨脹不良。** **請隔著窗口看；只在接近烘烤結束時開一次。**

## 誤解4｜任何玻璃器皿都能進烤箱

**沒有耐熱標示的玻璃、塑膠與部分陶瓷會裂開。** **請確認是否有「オーブン使用可」（可用於烤箱）的標示。** **土鍋與琺瑯多半沒問題**（請確認標示）。

## 誤解5｜國外的食譜在這裡也烤得一樣

**國外的獨立式烤箱與日本的一體型烤箱，在爐內大小與熱穩定性上都不同。** **用溫度計確認、調整烤盤的位置與方向、靠上色判斷**——這是日本家庭之間共享的做法。
