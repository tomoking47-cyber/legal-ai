# Q. 关于日本的马桶（温水洗净便座），人们常有哪些误解？｜Japan Questions #321

- Shelf: `inbound` ／ URL: `/zh-cn/questions/japanese-toilets` ／ Status: **草稿 — 出处未核实**

带控制面板的加热马桶座，是大多数游客接触到的第一件"日本"。它也是一系列特定错误的来源——按错按钮、冲水键不在预想的位置、拖鞋——只要读懂了面板，这些错误都很容易避免。

## A. 常见的误解是以为面板很复杂。其实要紧的只有四个按钮：停止、臀部洗净、前部洗净（妇洗），以及冲水（可能是水箱上的拉杆、墙上的按钮或感应器）。超过 80% 的日本家庭装有温水洗净便座，公共卫生间也遵循同样的逻辑。剩下的意外，是单独的卫生间拖鞋、模拟冲水声，以及仍存在于老旧车站里的蹲便器。

## 面板解读

| 符号／文字 | 含义 | 备注 |
|---|---|---|
| **止**（停止） | **停止**——要先找到的按钮 | 通常为橙色或红色 |
| **おしり**（oshiri） | 臀部洗净 | 位置与水压可调 |
| **ビデ**（bide） | 前部洗净（妇洗） | — |
| **やわらか**（yawaraka） | 柔和臀部洗净 | — |
| **乾燥**（kansō） | 温风烘干 | 并非所有机型都有 |
| **水勢 / 位置** | 水压／喷嘴位置 | −/+ 箭头 |
| **流す 大 / 小**（nagasu dai / shō） | **冲水** 大／小 | 可能是墙面面板、水箱拉杆、感应器，或**起身后自动冲水** |
| **音姫 / 擬音**（otohime） | 用来掩盖声音的**冲水音效** | 并不冲水 |
| **便座**（benza） | 座圈加热开／关 | — |

- **家庭普及率**：约 **82% 的两人及以上家庭**装有温水洗净便座（内阁府"消费动向调查"，2025 年 3 月）；车站、百货商店和便利店的公共卫生间大多也有。
- **喷嘴会在使用前后自动清洗**；水是**温水**，座圈**加热**。各品牌的机制相同。
- **卫生间拖鞋**：在家庭、旅馆（ryokan）和部分餐厅，卫生间门口放着一双专用拖鞋——**进门时换上，出来时再换回来**。穿着它走出去是经典错误。
- **蹲便器（和式）**仍存在于部分老旧车站和公园：面向**罩盖**，双脚分立两侧。许多公共卫生间现在会标注 **洋式（西式）／和式（日式）**。
- **厕纸直接扔进马桶**；垃圾桶只用于卫生用品。公共卫生间**提供厕纸，但很少提供擦手纸**（参见手帕一文）。

> **[待核实]** 家庭普及率请以内阁府"消费动向调查"（耐用消费品）核实；按钮标签因厂商而异。

## 误解1｜按钮很危险

坐下后按下洗净按钮之前，什么都不会喷出（**着座感应器**可防止对着空马桶喷水）。**先找到 止（停止）**，再慢慢尝试。

## 误解2｜冲水键在面板上

它往往是**水箱上的拉杆、身后墙上的按钮，或感应器**。找不到时，请找 **流す** 字样，或在感应板前挥一下手；有些会在**起身时自动冲水**。

## 误解3｜音效按钮能冲水

**音姫播放的是冲水声**，用于保护隐私。反复按它什么也冲不掉；请找 流す。

## 误解4｜拖鞋可穿可不穿

在家庭或旅馆里，**卫生间拖鞋在卫生间内必须穿，出了卫生间绝不能穿**。穿着它走进走廊，所有人都会注意到。

## 误解5｜蹲便器已经绝迹

它们仍留在**老旧车站、公园和学校**；扶好**扶手**，面向罩盖，并留意许多地方旁边就有标着 洋式 的**西式隔间**。
