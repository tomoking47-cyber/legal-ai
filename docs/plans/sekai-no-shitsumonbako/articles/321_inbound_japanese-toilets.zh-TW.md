# Q. 關於日本的免治馬桶，大家常有哪些誤解？｜Japan Questions #321

- Shelf: `inbound` ／ URL: `/zh-tw/questions/japanese-toilets` ／ Status: **草稿 — 出處未核實**

附有控制面板的加熱馬桶座，是大多數旅客接觸到的第一件「日本」。它也是一連串特定錯誤的來源——按錯按鈕、沖水鍵不在預想的位置、拖鞋——只要讀懂了面板，這些錯誤都很容易避免。

## A. 常見的誤解是以為面板很複雜。其實要緊的只有四個按鈕：停止、臀部洗淨、前部洗淨（婦洗），以及沖水（可能是水箱上的把手、牆上的按鈕或感應器）。超過 80% 的日本家庭裝有免治馬桶（温水洗浄便座），公共廁所也遵循同樣的邏輯。剩下的意外，是專用的廁所拖鞋、模擬沖水聲，以及仍存在於老舊車站裡的蹲式馬桶。

## 面板解讀

| 符號／文字 | 含義 | 備註 |
|---|---|---|
| **止**（停止） | **停止**——要先找到的按鈕 | 通常為橘色或紅色 |
| **おしり**（oshiri） | 臀部洗淨 | 位置與水壓可調 |
| **ビデ**（bide） | 前部洗淨（婦洗） | — |
| **やわらか**（yawaraka） | 柔和臀部洗淨 | — |
| **乾燥**（kansō） | 溫風烘乾 | 並非所有機型都有 |
| **水勢 / 位置** | 水壓／噴嘴位置 | −/+ 箭頭 |
| **流す 大 / 小**（nagasu dai / shō） | **沖水** 大／小 | 可能是牆面面板、水箱把手、感應器，或**起身後自動沖水** |
| **音姫 / 擬音**（otohime） | 用來掩蓋聲音的**沖水音效** | 並不沖水 |
| **便座**（benza） | 座圈加熱開／關 | — |

- **家庭普及率**：約 **82% 的兩人以上家庭**裝有免治馬桶（內閣府「消費動向調查」，2025 年 3 月）；車站、百貨公司和便利商店的公共廁所大多也有。
- **噴嘴會在使用前後自動清洗**；水是**溫水**，座圈**加熱**。各品牌的機制相同。
- **廁所拖鞋**：在家庭、旅館（ryokan）和部分餐廳，廁所門口放著一雙專用拖鞋——**進門時換上，出來時再換回來**。穿著它走出去是經典錯誤。
- **蹲式馬桶（和式）**仍存在於部分老舊車站和公園：面向**罩蓋**，雙腳分立兩側。許多公共廁所現在會標示 **洋式（西式）／和式（日式）**。
- **衛生紙直接丟進馬桶**；垃圾桶只放生理用品。公共廁所**提供衛生紙，但很少提供擦手紙**（參見手帕一文）。

> **[待核實]** 家庭普及率請以內閣府「消費動向調查」（耐久消費財）核實；按鈕標示因廠商而異。

## 誤解1｜按鈕很危險

坐下後按下洗淨按鈕之前，什麼都不會噴出（**著座感應器**可防止對著空馬桶噴水）。**先找到 止（停止）**，再慢慢嘗試。

## 誤解2｜沖水鍵在面板上

它往往是**水箱上的把手、身後牆上的按鈕，或感應器**。找不到時，請找 **流す** 字樣，或在感應板前揮一下手；有些會在**起身時自動沖水**。

## 誤解3｜音效按鈕能沖水

**音姫播放的是沖水聲**，用來保護隱私。反覆按它什麼也沖不掉；請找 流す。

## 誤解4｜拖鞋可穿可不穿

在家庭或旅館裡，**廁所拖鞋在廁所內必須穿，出了廁所絕不能穿**。穿著它走進走廊，所有人都會注意到。

## 誤解5｜蹲式馬桶已經絕跡

它們仍留在**老舊車站、公園和學校**；扶好**扶手**，面向罩蓋，並留意許多地方旁邊就有標著 洋式 的**西式隔間**。
