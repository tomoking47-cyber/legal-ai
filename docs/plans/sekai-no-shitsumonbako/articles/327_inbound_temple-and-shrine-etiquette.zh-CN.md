# Q. 关于寺庙与神社的参拜礼仪，人们常有哪些误解？｜Japan Questions #327

- Shelf: `inbound` ／ URL: `/zh-cn/questions/temple-and-shrine-etiquette` ／ Status: **草稿 — 出处未核实**

游客在日本停留时间最长的地方就是神社和寺庙，也最担心在那里做错什么。好消息是：这些场所习惯了接待游客，规则很少，而最大的错误其实是不知道自己身处的是哪一种。

## A. 最常见的误解是把神社和寺庙当成同一种场所、有同样的仪式。神社属于神道（鸟居、净手池、拍手两次）；寺庙属于佛教（有雕像的山门、香火、不拍手）。两者都要求安静、不进食、进入殿堂脱帽、只在允许的地方拍照。其他一切——投币、鞠躬、御守——都是可选的，做错也会被谅解。

## 神社 vs 寺庙

| | **神社（神社, jinja）** | **寺庙（寺, tera / -ji）** |
|---|---|---|
| 宗教 | 神道 | 佛教 |
| 入口 | **鸟居**（两根立柱、两根横梁）——鞠躬一次，沿参道一侧行走 | **山门**，常有护法神像 |
| 净手 | **手水舍（temizuya）**：右手持勺，先洗左手，换手洗右手，再把水倒入左手掌漱口（吐在池边），最后冲洗勺柄 | 部分寺庙也有同样的水池；在香炉前**焚香**——把烟往自己身上扇 |
| 参拜 | **投币 → 鞠躬两次 → 拍手两次 → 祈愿 → 鞠躬一次**（二拝二拍手一拝） | **投币 → 鞠躬、双手合十、不拍手** |
| 香油钱 | 金额随意；**5 日元（go-en，谐音「御缘」，意为「好缘分」）**是传统 | 相同 |
| 拍照 | 院内通常可以；**主殿内部不可**，不要拍参拜者；**部分区域有「撮影禁止」（禁止拍摄）标识** | 相同；**许多寺庙内部和佛像禁止拍摄** |
| 其他 | 御守（护身符）、绘马、御神签（抽到凶签系在架子上） | 相同，另有御朱印帐（**300–500 日元**） |

- 日本约有 **80,000 座神社和 77,000 座寺庙**（文化厅《宗教年鉴》）。
- **御朱印**（书法印章）是宗教记录，不是纪念品；请使用**专用的御朱印帐**，不要用笔记本。
- **京都祇园**于 **2019 年禁止在私人小巷拍照**，并在艺伎（geiko）遭骚扰后，**自 2024 年 4 月起完全禁止游客进入私人小巷**；告示注明 **10,000 日元**罚款。

> **[待核实]** 神社寺庙数量请以文化厅《宗教年鉴》为准；祇园规则请向当地协议会核实。

## 误解1｜在寺庙也要拍手

**拍手是神道的做法。**在寺庙，**双手合十、保持安静**。把两者弄反是最常见、最显眼的错误，但没有人会说什么。

## 误解2｜净手可以跳过——那只是形式

这是**标志着游客懂得尊重的礼仪**，只需 20 秒，做得不完美也没人在意。**不要直接用勺子喝水。**

## 误解3｜沿参道中央走

参道的中央**属于神明**；参拜者**沿一侧行走**。这是小事；当地居民会自然而然地这么做。

## 误解4｜什么都可以拍

**院内可以；内部和佛像往往不可以；正在祈祷的人，绝对不可以。**请留意标识。几乎所有场所都禁止无人机。

## 误解5｜香油钱要多

**5 日元是传统**，因为它与「缘」谐音；金额本身无关紧要。用力扔硬币或从远处扔才是失礼。
