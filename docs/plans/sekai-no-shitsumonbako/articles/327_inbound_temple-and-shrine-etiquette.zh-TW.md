# Q. 關於寺院與神社的參拜禮儀，大家常有哪些誤解？｜Japan Questions #327

- Shelf: `inbound` ／ URL: `/zh-tw/questions/temple-and-shrine-etiquette` ／ Status: **草稿 — 出處未核實**

旅客在日本停留最久的地方就是神社和寺院，也最擔心在那裡做錯什麼。好消息是：這些場所習慣了接待旅客，規則很少，而最大的錯誤其實是不知道自己身處的是哪一種。

## A. 最常見的誤解是把神社和寺院當成同一種場所、有同樣的儀式。神社屬於神道（鳥居、淨手池、拍手兩次）；寺院屬於佛教（有雕像的山門、香火、不拍手）。兩者都要求安靜、不進食、進入殿堂脫帽、只在允許的地方拍照。其他一切——投幣、鞠躬、御守——都是可有可無的，做錯也會被諒解。

## 神社 vs 寺院

| | **神社（神社, jinja）** | **寺院（寺, tera / -ji）** |
|---|---|---|
| 宗教 | 神道 | 佛教 |
| 入口 | **鳥居**（兩根立柱、兩根橫梁）——鞠躬一次，沿參道一側行走 | **山門**，常有護法神像 |
| 淨手 | **手水舍（temizuya）**：右手持杓，先洗左手，換手洗右手，再把水倒入左手掌漱口（吐在池邊），最後沖洗杓柄 | 部分寺院也有同樣的水池；在香爐前**焚香**——把煙往自己身上搧 |
| 參拜 | **投幣 → 鞠躬兩次 → 拍手兩次 → 祈願 → 鞠躬一次**（二拝二拍手一拝） | **投幣 → 鞠躬、雙手合十、不拍手** |
| 香油錢 | 金額隨意；**5 日圓（go-en，諧音「御緣」，意為「好緣分」）**是傳統 | 相同 |
| 拍照 | 境內通常可以；**本殿內部不可**，不要拍參拜者；**部分區域有「撮影禁止」（禁止拍攝）標示** | 相同；**許多寺院內部和佛像禁止拍攝** |
| 其他 | 御守（護身符）、繪馬、御神籤（抽到凶籤綁在架子上） | 相同，另有御朱印帳（**300–500 日圓**） |

- 日本約有 **80,000 座神社和 77,000 座寺院**（文化廳《宗教年鑑》）。
- **御朱印**（書法印章）是宗教紀錄，不是紀念品；請使用**專用的御朱印帳**，不要用筆記本。
- **京都祇園**於 **2019 年禁止在私人巷弄拍照**，並在藝妓（geiko）遭騷擾後，**自 2024 年 4 月起完全禁止旅客進入私人巷弄**；告示標明 **10,000 日圓**罰款。

> **[待核實]** 神社寺院數量請以文化廳《宗教年鑑》為準；祇園規則請向當地協議會核實。

## 誤解1｜在寺院也要拍手

**拍手是神道的做法。**在寺院，**雙手合十、保持安靜**。把兩者弄反是最常見、最明顯的錯誤，但沒有人會說什麼。

## 誤解2｜淨手可以跳過——那只是形式

這是**標誌著旅客懂得尊重的禮儀**，只需 20 秒，做得不完美也沒人在意。**不要直接用杓子喝水。**

## 誤解3｜沿參道中央走

參道的中央**屬於神明**；參拜者**沿一側行走**。這是小事；當地居民會自然而然地這麼做。

## 誤解4｜什麼都可以拍

**境內可以；內部和佛像往往不可以；正在祈禱的人，絕對不可以。**請留意標示。幾乎所有場所都禁止空拍機。

## 誤解5｜香油錢要多

**5 日圓是傳統**，因為它與「緣」諧音；金額本身無關緊要。用力丟硬幣或從遠處丟才是失禮。
