# Q. 关于入住日式旅馆（旅馆），人们常有哪些误解？｜Japan Questions #328

- Shelf: `inbound` ／ URL: `/zh-cn/questions/staying-at-a-ryokan` ／ Status: **草稿 — 出处未核实**

在传统旅馆住一晚几乎是所有行程的必选项，它引发的焦虑问题也比旅途中任何其他环节都多：穿什么、什么时候泡澡、为什么晚餐是 18:00、要不要给小费。旅馆其实是一套时间表，加上一间在整个傍晚被用作不同用途的房间——明白这一点，焦虑就消失了。

## A. 最常见的误解是把旅馆当成铺了榻榻米的酒店。它更像是一场有人款待的夜晚：15:00 左右入住，晚餐前泡澡，晚餐在客房或餐厅于固定的较早时间供应，同时您的房间从起居室变为卧室，早餐在固定时间，10:00 退房。价格按人计算，包含两餐。浴衣是您全程的着装。

## 一晚的流程

| 时间 | 发生什么 |
|---|---|
| **15:00–16:00** | 入住；在房间喝茶、吃点心；**在玄关脱鞋**，走廊穿拖鞋，**榻榻米上穿袜子或光脚** |
| **晚餐前** | 到公共浴场**泡澡**（参见温泉篇）；换上旅馆提供的**浴衣**——左襟压右襟，腰带系在腰际 |
| **18:00–19:00** | **晚餐**（会席料理，多道小菜）在房间或餐厅供应；**时间在入住时确定**；清酒和啤酒另收费 |
| 晚餐期间或之后 | 工作人员**铺好被褥（futon）**——起居室变为卧室 |
| 晚间 | 再泡一次澡很正常；部分浴场按时间段男女互换——请看标识 |
| **07:30–08:30** | **早餐**在固定时间（烤鱼、米饭、味噌汤、腌菜；许多旅馆有西式选项） |
| **10:00** | 退房 |

- **价格按人计算，含晚餐和早餐**——通常**每人 15,000–40,000 日元**，知名温泉地更高。双人房按两人计价。
- **浴衣**可以穿着去用餐、走廊、浴场，在温泉街还可以**穿上街**。冬天在外面套上**丹前（tanzen，棉袄式外套）**。
- **不需要给小费**；在高档旅馆，给客房服务人员一个装在信封里的小礼金（心付け，kokorozuke）是一种正在消失的习俗，完全可选。
- 饮食需求（**过敏、不吃鱼、清真**）必须**在预订时告知**；会席菜单是固定的，且提前准备。
- **超过晚餐时间迟到**意味着**没有晚餐，而且通常不退款**；如有延误请打电话。

> **[待核实]** 价格区间为典型值；惯例请向日本旅馆协会核实。

## 误解1｜18:00 的晚餐时间可以商量

**厨房为全馆客人同时开火**；您在入住时从 18:00 或 19:00 中选择。迟到就没有这一餐了。

## 误解2｜浴衣是在房间里穿的浴袍

它是**您整个住宿期间的着装**——用餐、走廊、浴场、温泉街的街道。**左襟压右襟**（右压左是给逝者穿的）。

## 误解3｜可以照菜单点菜

**会席是套餐**；没有菜单。**过敏和饮食限制请在预订时说明**，而不是在餐桌上。

## 误解4｜铺被褥会有人来打扰

工作人员会**在您用餐或泡澡时**铺好；如果在房间用餐，他们会在餐后立即进行，只需几分钟。这是流程的一部分，不是打扰。

## 误解5｜要给服务人员小费

**不需要。**晚餐后一句真诚的「ごちそうさまでした」（多谢款待）和退房时的「お世話になりました」（承蒙照顾）就是最好的回礼。
