# Q. 關於入住日式旅館（旅館），大家常有哪些誤解？｜Japan Questions #328

- Shelf: `inbound` ／ URL: `/zh-tw/questions/staying-at-a-ryokan` ／ Status: **草稿 — 出處未核實**

在傳統旅館住一晚幾乎是所有行程的必選項，它引發的焦慮問題也比旅途中任何其他環節都多：穿什麼、什麼時候泡澡、為什麼晚餐是 18:00、要不要給小費。旅館其實是一套時間表，加上一間在整個傍晚被當作不同用途的房間——明白這一點，焦慮就消失了。

## A. 最常見的誤解是把旅館當成鋪了榻榻米的飯店。它更像是一場有人款待的夜晚：15:00 左右入住，晚餐前泡澡，晚餐在客房或餐廳於固定的較早時間供應，同時您的房間從起居室變為臥室，早餐在固定時間，10:00 退房。價格按人計算，包含兩餐。浴衣是您全程的穿著。

## 一晚的流程

| 時間 | 發生什麼 |
|---|---|
| **15:00–16:00** | 入住；在房間喝茶、吃點心；**在玄關脫鞋**，走廊穿拖鞋，**榻榻米上穿襪子或光腳** |
| **晚餐前** | 到大浴場**泡澡**（參見溫泉篇）；換上旅館提供的**浴衣**——左襟壓右襟，腰帶繫在腰際 |
| **18:00–19:00** | **晚餐**（會席料理，多道小菜）在房間或餐廳供應；**時間在入住時確定**；清酒和啤酒另外計費 |
| 晚餐期間或之後 | 工作人員**鋪好被褥（futon）**——起居室變為臥室 |
| 晚間 | 再泡一次澡很正常；部分浴場按時段男女互換——請看標示 |
| **07:30–08:30** | **早餐**在固定時間（烤魚、白飯、味噌湯、醃菜；許多旅館有西式選項） |
| **10:00** | 退房 |

- **價格按人計算，含晚餐和早餐**——通常**每人 15,000–40,000 日圓**，知名溫泉地更高。雙人房按兩人計價。
- **浴衣**可以穿著去用餐、走廊、浴場，在溫泉街還可以**穿上街**。冬天在外面套上**丹前（tanzen，棉襖式外套）**。
- **不需要給小費**；在高檔旅館，給客房服務人員一個裝在信封裡的小禮金（心付け，kokorozuke）是一種正在消失的習俗，完全可有可無。
- 飲食需求（**過敏、不吃魚、清真**）必須**在訂房時告知**；會席菜單是固定的，且提前準備。
- **超過晚餐時間遲到**意味著**沒有晚餐，而且通常不退費**；如有延誤請打電話。

> **[待核實]** 價格區間為典型值；慣例請向日本旅館協會核實。

## 誤解1｜18:00 的晚餐時間可以商量

**廚房為全館客人同時開火**；您在入住時從 18:00 或 19:00 中選擇。遲到就沒有這一餐了。

## 誤解2｜浴衣是在房間裡穿的浴袍

它是**您整個住宿期間的穿著**——用餐、走廊、浴場、溫泉街的街道。**左襟壓右襟**（右壓左是給逝者穿的）。

## 誤解3｜可以照菜單點菜

**會席是套餐**；沒有菜單。**過敏和飲食限制請在訂房時說明**，而不是在餐桌上。

## 誤解4｜鋪被褥會有人來打擾

工作人員會**在您用餐或泡澡時**鋪好；如果在房間用餐，他們會在餐後立即進行，只需幾分鐘。這是流程的一部分，不是打擾。

## 誤解5｜要給服務人員小費

**不需要。**晚餐後一句真誠的「ごちそうさまでした」（多謝款待）和退房時的「お世話になりました」（承蒙照顧）就是最好的回禮。
