# Q. 關於重複利用洗澡水（「残り湯」），大家常有哪些誤解？｜Japanese Everyday Wisdom #333

- Shelf: `wisdom` ／ URL: `/zh-tw/wisdom/reusing-bath-water` ／ Status: **草稿 — 出處未核實**

一個日式浴缸大約裝 200 公升水，而且家裡每個人都是先在浴缸外洗淨身體再入浴，所以這缸水乾淨到可以再利用。日本市售的大多數洗衣機都配有從浴缸抽水的軟管。對旅客來說這聽起來不衛生；數字和規則可以解釋清楚。

## A. 常見的誤解是認為重複利用洗澡水很髒。因為每個人都先在浴缸外洗乾淨，泡完之後的水比西式浴缸裡的水乾淨得多，而且是溫的——這反而有利於洗滌。家庭只把它用於洗衣行程（不用於沖洗），當晚或隔天早上用掉，家裡有人生病的日子絕不用來洗內衣。每次洗衣可以節省約 50–100 公升水，還能省一點能源。

## 具體做法

| 項目 | 細節 |
|---|---|
| 浴缸容量 | 標準浴缸**約 180–220 L** |
| 洗衣機進水量 | 直立式洗衣機**每次 50–100 L**；洗衣機配有**「風呂水ポンプ」（furomizu pump，浴水抽水軟管）** |
| 用於哪個行程 | **僅洗衣行程**；**沖洗用自來水**——這是廠商和政府的建議 |
| 什麼時候用 | **當晚或隔天早上**；溫熱的靜置水在 24 小時內細菌會增加 |
| 不用於 | **嬰兒衣物、家裡有人生病時的內衣、希望沒有異味的毛巾** |
| 入浴劑 | **查看入浴劑的標示**——有些（含硫或乳白色成分的）標註「不可用於洗衣」；很多標註「可用於洗衣，不可用於沖洗」 |
| 其他用途 | **沖馬桶（用水桶）、擦地、澆花（無入浴劑時）、防災儲水**（見儲水篇） |
| 節省 | **每次洗衣 50–100 L；依東京水價，每次約 ¥15–30** 的水費與污水費 |

- **東京都水道局**把重複利用洗澡水列為家庭節水措施之一，並給出了「僅用於洗衣」的規則。
- 洗澡水中的**細菌數**過一夜**大約增加一千倍**——入浴後每毫升數百至數千個，到隔天可達數十萬個以上；正因如此，「僅用於洗衣」的規則和**自來水沖洗**才重要，當天用完也才是常規做法。
- **溫水（隔天早上約 30–35°C）**比冷水更能溶解洗衣精、去除油脂；日本的洗衣機在其他情況下**預設使用冷水**。
- 家庭會**整夜蓋著浴缸蓋**以保溫防塵；浴缸裡的水也是家裡在地震時的**防災用水**（200 L 可用於沖馬桶）。

> **[待核實]** 節水數據請向東京都水道局核實；細菌數據請對照消費者測試報告（如國民生活中心／Kokusen）；入浴劑指引以產品標示為準。

## 誤解1｜那是髒水

**家人入浴前都先洗淨身體**；這缸水是溫的、沒有肥皂、只是輕度使用過。它用於**洗衣**而不是沖洗，沖洗用的是自來水。

## 誤解2｜什麼都用它，包括沖洗

**沖洗用自來水**，這樣不會留下殘留物或氣味。「僅用於洗衣」是廠商、水道局與消費者機構共同的規則。

## 誤解3｜水放兩三天再用也沒關係

**細菌在溫熱的靜置水中會大量繁殖**；請在**當晚或隔天早上**用掉，然後放水、清潔浴缸。

## 誤解4｜入浴劑沒有影響

**有些入浴劑會讓衣物染色或損壞抽水泵。**查看入浴劑標示上關於洗衣的說明；很多產品都有明確標註。

## 誤解5｜省的那點水微不足道

**一家人每天每次洗衣省 50–100 L**，一年就是 20–35 立方公尺——在家庭用水中是不小的份額。而且溫水洗得更乾淨。
