# Q. 关于糠床（「ぬか床」，米糠腌渍床），人们常有哪些误解？｜Japanese Everyday Wisdom #335

- Shelf: `wisdom` ／ URL: `/zh-cn/wisdom/the-nukadoko-pickling-bed` ／ Status: **草稿 — 出处未核实**

厨房里一桶发酵中的米糠，每天用手翻搅，一夜之间就把黄瓜和茄子变成腌菜——糠床是日本家庭发酵传统中至今仍在日常使用的最古老的东西之一，也是在海外被误解最多的东西之一。

## A. 常见的误解是认为糠床是一项困难、气味难闻、只属于发烧友的工程。它其实就是米糠、盐和水，靠乳酸菌保持活性，只要求一件事：每天翻搅一次，让表面透气。蔬菜放进去几小时到一天。放在冰箱里的话，一周只需翻搅几次，一床糠床可以用上几十年。

## 它是如何运作的

| 要素 | 细节 |
|---|---|
| 糠床 | **米糠（糠）＋盐（约为米糠重量的 13%）＋水**，调到类似味噌的稠度；加昆布、辣椒，再放一块面包或蔬菜边角料作为起始 |
| 微生物 | 来自米糠和空气的**乳酸菌与酵母**；用"起始"蔬菜每天翻搅 **1–2 周**后糠床就成熟了 |
| 日常照料 | **每天用手从底部翻搅一到两次**——让糠床透气，并抑制表面酵母（异味的来源） |
| 放冰箱 | **每 2–3 天翻搅一次**；发酵变慢；大多数上班家庭都是靠冰箱来打理糠床 |
| 腌渍时间 | 黄瓜 **4–12 小时**，茄子 **12–24 小时**（加铁钉或明矾以保持颜色），胡萝卜 **1–2 天**，白萝卜 **1–2 天** |
| 盐 | 随着蔬菜出水使糠床变稀，适量补一点盐和米糠 |
| 状态判断 | **表面白膜＝酵母（搅进去或撇掉）**；**粉红、绿色或黑色斑点＝霉菌（带余量挖掉，或整床丢弃）**；**酒味＝过度发酵（加盐、翻搅、静置）** |

- 糠渍（ぬか漬け）是**乳酸发酵**食品；与浅渍不同，它带有活菌，米糠还会在蔬菜表面增添**B 族维生素**。
- 成品腌菜的**含盐量**约为 **2–3%**；几片就是一道配菜，不是沙拉。
- 糠床的**味道随家而变**——这家人的手、厨房温度和蔬菜——所以老糠床被当作传家宝对待。一些出售的糠床宣称有 **100 多年**的历史。
- **监管**：家庭腌渍不受监管；**自 2021 年起，商业腌菜生产需要许可**（见腌菜篇）。

> **[待核实]** 盐比例和时间为传统上的范围；食品安全指引请对照厚生劳动省的腌菜卫生规范。

## 误解1｜气味很难闻

健康的糠床闻起来**酸香、带坚果味**。难闻的气味意味着**疏于照料**：表面酵母或过度发酵，靠翻搅、加盐和静置一天就能纠正。

## 误解2｜必须每天翻搅，否则就会死掉

**常温下，是的**，夏天甚至要两次。**放冰箱的话，每 2–3 天一次**就够了；出门度假时，在表面盖一层厚厚的盐，然后冷藏。

## 误解3｜只要发霉就得整床扔掉

**白膜是酵母**，不是霉菌——搅进去或刮掉即可。**有颜色的霉菌**才是问题：大方地挖掉；如果反复出现，就重新做一床。

## 误解4｜只能腌黄瓜

茄子、白萝卜、胡萝卜、芹菜、芜菁、秋葵、**水煮蛋、豆腐、奶酪、牛油果**——任何质地紧实的食材都可以。肉和鱼要另用一小份糠床单独腌，腌完的米糠丢弃。

## 误解5｜这是农村的传统

冰箱让它变成了城市的东西。超市里有卖**装在密封袋里的现成糠床**；每天翻搅只需 30 秒，一床饭盒大小的糠床就够两口之家用。
