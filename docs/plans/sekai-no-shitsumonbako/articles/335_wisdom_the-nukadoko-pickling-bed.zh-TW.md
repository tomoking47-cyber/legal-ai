# Q. 關於糠床（「ぬか床」，米糠醃漬床），大家常有哪些誤解？｜Japanese Everyday Wisdom #335

- Shelf: `wisdom` ／ URL: `/zh-tw/wisdom/the-nukadoko-pickling-bed` ／ Status: **草稿 — 出處未核實**

廚房裡一桶發酵中的米糠，每天用手翻攪，一夜之間就把小黃瓜和茄子變成醃菜——糠床是日本家庭發酵傳統中至今仍在日常使用的最古老的東西之一，也是在海外被誤解最多的東西之一。

## A. 常見的誤解是認為糠床是一項困難、氣味難聞、只屬於玩家的工程。它其實就是米糠、鹽和水，靠乳酸菌保持活性，只要求一件事：每天翻攪一次，讓表面透氣。蔬菜放進去幾小時到一天。放在冰箱裡的話，一週只需翻攪幾次，一床糠床可以用上幾十年。

## 它是如何運作的

| 要素 | 細節 |
|---|---|
| 糠床 | **米糠（糠）＋鹽（約為米糠重量的 13%）＋水**，調到類似味噌的稠度；加昆布、辣椒，再放一塊麵包或蔬菜邊角料作為起始 |
| 微生物 | 來自米糠和空氣的**乳酸菌與酵母**；用「起始」蔬菜每天翻攪 **1–2 週**後糠床就成熟了 |
| 日常照料 | **每天用手從底部翻攪一到兩次**——讓糠床透氣，並抑制表面酵母（異味的來源） |
| 放冰箱 | **每 2–3 天翻攪一次**；發酵變慢；大多數上班族家庭都是靠冰箱來打理糠床 |
| 醃漬時間 | 小黃瓜 **4–12 小時**，茄子 **12–24 小時**（加鐵釘或明礬以保持顏色），紅蘿蔔 **1–2 天**，白蘿蔔 **1–2 天** |
| 鹽 | 隨著蔬菜出水使糠床變稀，適量補一點鹽和米糠 |
| 狀態判斷 | **表面白膜＝酵母（攪進去或撇掉）**；**粉紅、綠色或黑色斑點＝黴菌（連同周圍一起挖掉，或整床丟棄）**；**酒味＝過度發酵（加鹽、翻攪、靜置）** |

- 糠漬（ぬか漬け）是**乳酸發酵**食品；與淺漬不同，它帶有活菌，米糠還會在蔬菜表面增添**維生素 B 群**。
- 成品醃菜的**含鹽量**約為 **2–3%**；幾片就是一道配菜，不是沙拉。
- 糠床的**味道隨家而變**——這家人的手、廚房溫度和蔬菜——所以老糠床被當作傳家寶對待。一些出售的糠床宣稱有 **100 多年**的歷史。
- **法規**：家庭醃漬不受管制；**自 2021 年起，商業醃菜生產需要許可**（見醃菜篇）。

> **[待核實]** 鹽比例和時間為傳統上的範圍；食品安全指引請對照厚生勞動省的醃菜衛生規範。

## 誤解1｜氣味很難聞

健康的糠床聞起來**酸香、帶堅果味**。難聞的氣味意味著**疏於照料**：表面酵母或過度發酵，靠翻攪、加鹽和靜置一天就能修正。

## 誤解2｜必須每天翻攪，否則就會死掉

**常溫下，是的**，夏天甚至要兩次。**放冰箱的話，每 2–3 天一次**就夠了；出門度假時，在表面蓋一層厚厚的鹽，然後冷藏。

## 誤解3｜只要發霉就得整床丟掉

**白膜是酵母**，不是黴菌——攪進去或刮掉即可。**有顏色的黴菌**才是問題：大範圍挖掉；如果反覆出現，就重新做一床。

## 誤解4｜只能醃小黃瓜

茄子、白蘿蔔、紅蘿蔔、西洋芹、蕪菁、秋葵、**水煮蛋、豆腐、起司、酪梨**——任何質地緊實的食材都可以。肉和魚要另用一小份糠床單獨醃，醃完的米糠丟棄。

## 誤解5｜這是農村的傳統

冰箱讓它變成了城市的東西。超市裡有賣**裝在夾鏈袋裡的現成糠床**；每天翻攪只需 30 秒，一床便當盒大小的糠床就夠兩口之家用。
