# Q. 关于自制味噌和米曲（麹），人们常有哪些误解？｜Japanese Everyday Wisdom #336

- Shelf: `wisdom` ／ URL: `/zh-cn/wisdom/homemade-miso-and-koji` ／ Status: **草稿 — 出处未核实**

自 2010 年代以来，在家做味噌在日本重新流行起来——每年一月，"味噌制作工作坊"都座无虚席。在海外，这听起来像是高阶的发酵技艺。其实它就是大豆、盐和曲（麹）放着不管六个月；所谓技巧，无非是耐心，以及别让空气接触表面。

## A. 常见的误解是认为味噌很难做。原料只有三种，动手的活儿只需一个下午，剩下的就是在阴凉处放上六到十二个月不去管它。人们最容易弄错的一个变量是盐：太少会坏，太多则难以下口。曲（麹）——接种了米曲霉（Aspergillus oryzae）的米——是买现成的，活儿都由它来干。

## 配方与数字

| 步骤 | 详情 |
|---|---|
| 原料（典型的一批） | **大豆 1 kg（干）**、**米曲 1 kg**、**盐 400–450 g**——最终含盐量约 **11–12%** |
| 第 1 天 | 大豆浸泡 18 小时 → 煮 3–4 小时至可捏碎 → 捣碎 → 与米曲和盐混合 → 装入容器时**压出空气** → 表面撒盐 → 上面压重物 |
| 容器 | 搪瓷、食品级塑料或陶瓷；**切勿让金属**接触（盐会腐蚀） |
| 存放位置 | **阴凉、避光、温度稳定**（壁橱、楼梯下）；**不要放冰箱**（发酵太慢） |
| 等待 | **6 个月**（色浅、偏甜）到 **12 个月**（色深、味浓）；在 **1–2 月**开始，让夏天的热量来完成发酵 |
| 表面 | 渗出**「たまり」（深色液体）**是正常现象；**白色薄膜**是酵母——去除；**有颜色的霉**——连同周边一并去除 |
| 产量 | 约 **4 kg** 味噌 |
| 成品含盐量 | **10–13%**（市售白味噌为 5–7%，红味噌为 11–13%） |

- **曲（麹，kōji）**是用**米曲霉（Aspergillus oryzae）**培养的米（或大麦、大豆），日本酿造协会将其指定为日本的"国菌"。它的酶把淀粉分解成糖、把蛋白质分解成氨基酸——这正是味噌甜味与鲜味的来源。超市和网上都有售，分**生曲和干曲**两种。
- **盐曲（塩麹）**——米曲、盐和水发酵一周而成——是入门级产品：一种能让肉和鱼变嫩的腌料兼调味料。比例为**米曲 200 g：盐 60 g：水 300 mL**，每天搅拌一次，持续 **7–10 天**。
- **甘酒**（甜味曲饮）是米曲和米饭在 **55–60°C 下保温 8–10 小时**——家庭做法是用电饭锅的"保温"档，开着盖子。
- **安全**：**含盐量和排除空气的装填方式**就是防腐体系。低盐尝试会变质；室温熟成时**不建议低于 10%**。

## 误解1｜霉菌得自己培养

**曲是买来的。**在家制曲是另一项更讲究的爱好（35°C、48 小时、精确控湿）。做味噌是从买来的曲开始的。

## 误解2｜盐越少越健康

**盐就是防腐剂**；低于约 10%，整批在室温下就会变质。要减盐，请在**汤**里减，而不是在味噌里减。

## 误解3｜表面长霉就是失败

几个月之后**表面出现些酵母或霉是正常的**；连同周边一并刮掉即可。下面隔绝了空气的部分没有问题。装得紧实、表面撒盐，可以把它降到最少。

## 误解4｜必须冷藏保存

**室温熟成正是关键**；发酵需要夏天的温暖。冰箱是留给**做好之后**的，用来阻止它继续变深。

## 误解5｜曲只能用来做味噌

**盐曲**做腌料、**甘酒**做饮品，是最快见效的用法，分别只需一周和一夜——这也是每家超市的冷藏区都摆着曲的原因。
