# Q. 關於自製味噌和米麴（麹），大家常有哪些誤解？｜Japanese Everyday Wisdom #336

- Shelf: `wisdom` ／ URL: `/zh-tw/wisdom/homemade-miso-and-koji` ／ Status: **草稿 — 出處未核實**

自 2010 年代以來，在家做味噌在日本重新流行起來——每年一月，「味噌製作工作坊」都座無虛席。在海外，這聽起來像是進階的發酵技藝。其實它就是黃豆、鹽和麴放著不管六個月；所謂技巧，無非是耐心，以及別讓空氣接觸表面。

## A. 常見的誤解是認為味噌很難做。原料只有三種，動手的工作只需一個下午，剩下的就是在陰涼處放上六到十二個月不去管它。大家最容易弄錯的一個變數是鹽：太少會壞，太多則難以入口。麴——接種了米麴菌（Aspergillus oryzae）的米——是買現成的，工作都由它來完成。

## 配方與數字

| 步驟 | 細節 |
|---|---|
| 原料（典型的一批） | **黃豆 1 kg（乾）**、**米麴 1 kg**、**鹽 400–450 g**——最終含鹽量約 **11–12%** |
| 第 1 天 | 黃豆浸泡 18 小時 → 煮 3–4 小時至可捏碎 → 搗碎 → 與米麴和鹽混合 → 裝入容器時**壓出空氣** → 表面撒鹽 → 上面壓重物 |
| 容器 | 琺瑯、食品級塑膠或陶瓷；**切勿讓金屬**接觸（鹽會腐蝕） |
| 存放位置 | **陰涼、避光、溫度穩定**（儲物櫃、樓梯下）；**不要放冰箱**（發酵太慢） |
| 等待 | **6 個月**（色淺、偏甜）到 **12 個月**（色深、味濃）；在 **1–2 月**開始，讓夏天的熱度來完成發酵 |
| 表面 | 滲出**「たまり」（深色液體）**是正常現象；**白色薄膜**是酵母——去除；**有顏色的黴**——連同周邊一併去除 |
| 產量 | 約 **4 kg** 味噌 |
| 成品含鹽量 | **10–13%**（市售白味噌為 5–7%，赤味噌為 11–13%） |

- **麴（麹，kōji）**是用**米麴菌（Aspergillus oryzae）**培養的米（或大麥、黃豆），日本釀造協會將其指定為日本的「國菌」。它的酵素把澱粉分解成糖、把蛋白質分解成胺基酸——這正是味噌甜味與鮮味的來源。超市和網路上都買得到，分**生麴和乾麴**兩種。
- **鹽麴（塩麹）**——米麴、鹽和水發酵一週而成——是入門級產品：一種能讓肉和魚變嫩的醃料兼調味料。比例為**米麴 200 g：鹽 60 g：水 300 mL**，每天攪拌一次，持續 **7–10 天**。
- **甘酒**（甜味麴飲）是米麴和米飯在 **55–60°C 下保溫 8–10 小時**——家庭做法是用電子鍋的「保溫」功能，開著鍋蓋。
- **安全**：**含鹽量和排除空氣的填裝方式**就是防腐體系。低鹽嘗試會變質；室溫熟成時**不建議低於 10%**。

> **[待核實]** 比例為味噌業界協會公布的傳統範圍；市售味噌的含鹽範圍請向全國味噌工業協同組合連合會核實。

## 誤解1｜黴菌得自己培養

**麴是買來的。**在家製麴是另一項更講究的嗜好（35°C、48 小時、精確控濕）。做味噌是從買來的麴開始的。

## 誤解2｜鹽越少越健康

**鹽就是防腐劑**；低於約 10%，整批在室溫下就會變質。要減鹽，請在**湯**裡減，而不是在味噌裡減。

## 誤解3｜表面長黴就是失敗

幾個月之後**表面出現一些酵母或黴是正常的**；連同周邊一併刮掉即可。下面隔絕了空氣的部分沒有問題。裝得緊實、表面撒鹽，可以把它降到最少。

## 誤解4｜必須冷藏保存

**室溫熟成正是重點**；發酵需要夏天的溫暖。冰箱是留給**做好之後**的，用來阻止它繼續變深。

## 誤解5｜麴只能用來做味噌

**鹽麴**做醃料、**甘酒**做飲品，是最快見效的用法，分別只需一週和一夜——這也是每家超市的冷藏區都擺著麴的原因。
