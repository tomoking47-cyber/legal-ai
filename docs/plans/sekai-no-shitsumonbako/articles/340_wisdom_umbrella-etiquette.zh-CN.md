# Q. 关于日本的雨伞礼仪，人们常有哪些误解？｜Japanese Everyday Wisdom #340

- Shelf: `wisdom` ／ URL: `/zh-cn/wisdom/umbrella-etiquette` ／ Status: **草稿 — 出处未核实**

日本每年估计要用掉 1.2 亿到 1.3 亿把雨伞。到了雨天，整个国家都靠一套关于伞的惯例运转——伞放在哪里、怎么拿着走、滴下来的水怎么办——而刚来的人往往在毫无察觉的情况下就破了规矩。

## A. 常见的误解是把伞当作一件没有社交规则的私人物品。在日本，你一走进建筑物，它就变成了公共的东西：它要放进门口的伞架，或者套上伞袋；绝不在室内撑开，也绝不在电车地板上滴水；拿着走时伞尖朝下、贴近身体。而最难的一条是——哪怕外面正下着倾盆大雨，你也不能从伞架上拿走不属于你的伞。

## 这些惯例

| 场合 | 人们怎么做 |
|---|---|
| **进入商店、办公楼、餐厅** | **放进门口的伞架**（大型店铺的伞架常带锁和编号钥匙），或使用**塑料伞袋机**——进门前先套上伞袋 |
| **便利店与车站** | 伞袋机或沥水架；**绝不拎着滴水的伞穿过货架通道** |
| **在电车上** | **收拢，套上伞袋或用布包好**；伞尖朝下；不搁在座位上，也不碰到邻座的腿。**折叠伞要装进伞套**，再放进包里 |
| **走路时** | **伞尖朝下，贴近身体**；绝不拎着伞柄甩动，也不夹在腋下横着拿（伞尖正好在儿童的眼睛高度） |
| **在屋檐下与人错身** | 把伞向**远离对方的一侧**倾斜；走在外侧的人短暂地走进雨里 |
| **共撑一把伞** | **相合傘（あいあいがさ）**（两人共撑一把伞）是浪漫桥段，不是常规做法；与其共撑，不如借对方一把备用伞 |
| **别人的伞** | **不要拿走**，哪怕是 ¥700 的透明塑料伞；从伞架偷伞虽属小案，却普遍招人反感 |
| **用完之后** | **回家后撑开晾干**（见雨伞保养一文）；湿伞收拢过夜会生锈、发臭 |

- **消费量：每年约 1.2 亿到 1.3 亿把伞**，其中很大一部分是下雨时在便利店买的**约 ¥600–800 的透明塑料伞**——很多被随手丢弃；一些城市现在推出了**共享雨伞服务**（iKasa，在车站用 App 解锁，¥140/天）。
- 从伞架上**偷伞**常见到什么程度呢？人们会**在伞柄上贴胶带做记号**，或使用**带锁的伞架**；把一把好伞留在敞开的伞架上，会被看作粗心，而不是信任他人。
- 店门口的**塑料伞袋**是一个废弃物问题；许多连锁店作为自主减塑措施改用了**沥水架或可重复使用的伞袋**——伞袋并不在 2022 年该法指定的 12 种一次性用品之列。

## 误解1｜把伞带进去就好

**放进门口的伞架，或者套上伞袋。**湿伞靠在货架上、滴在餐厅地板上，是外来访客最常犯的小失礼。

## 误解2｜在门口里侧把伞撑开

**走出门外再撑开**——在室内撑伞会把水甩得满门口都是，还会打到你身后的人。先跨出去，再撑开。

## 误解3｜收好的伞夹在腋下横着拿

**这时伞尖朝后，正好在腰的高度——也就是孩子脸的高度。**要**竖着拿、伞尖朝下**，贴在身侧。

## 误解4｜伞架上便宜的透明伞谁拿都行

**不行。**留下它的人会回来取。要是你被雨困住了，就**自己买一把**——便利店里大约 ¥700；每家都有，这也正是伞架里满是这种伞的原因。

## 误解5｜和旁边的陌生人共撑一把伞

愿意为人遮雨是善意，但在日本文化里**相合傘（あいあいがさ）带有亲密意味**；自然的做法是**借给对方一把备用伞**，或者陪对方走到最近的店铺。读懂当下的场合，比记住规则更重要。
