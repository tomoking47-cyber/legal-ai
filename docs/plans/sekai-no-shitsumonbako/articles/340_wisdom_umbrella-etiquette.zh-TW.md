# Q. 關於日本的雨傘禮儀，大家常有哪些誤解？｜Japanese Everyday Wisdom #340

- Shelf: `wisdom` ／ URL: `/zh-tw/wisdom/umbrella-etiquette` ／ Status: **草稿 — 出處未核實**

日本每年估計要用掉 1.2 億到 1.3 億把雨傘。到了雨天，整個國家都靠一套關於傘的慣例運轉——傘放在哪裡、怎麼拿著走、滴下來的水怎麼辦——而剛來的人往往在毫無察覺的情況下就破了規矩。

## A. 常見的誤解是把傘當作一件沒有社交規則的私人物品。在日本，你一走進建築物，它就變成了公共的東西：它要放進門口的傘架，或者套上傘套；絕不在室內撐開，也絕不在電車地板上滴水；拿著走時傘尖朝下、貼近身體。而最難的一條是——哪怕外面正下著傾盆大雨，你也不能從傘架上拿走不屬於你的傘。

## 這些慣例

| 場合 | 大家怎麼做 |
|---|---|
| **進入商店、辦公大樓、餐廳** | **放進門口的傘架**（大型店家的傘架常附鎖與編號鑰匙），或使用**塑膠傘套機**——進門前先套上傘套 |
| **便利商店與車站** | 傘套機或瀝水架；**絕不提著滴水的傘穿過貨架走道** |
| **在電車上** | **收攏，套上傘套或用布包好**；傘尖朝下；不擱在座位上，也不碰到鄰座的腿。**折疊傘要裝進傘袋**，再放進包包裡 |
| **走路時** | **傘尖朝下，貼近身體**；絕不提著傘柄甩動，也不夾在腋下橫著拿（傘尖正好在兒童的眼睛高度） |
| **在屋簷下與人錯身** | 把傘往**遠離對方的一側**傾斜；走在外側的人短暫地走進雨裡 |
| **共撐一把傘** | **相合傘（あいあいがさ）**（兩人共撐一把傘）是浪漫橋段，不是常規做法；與其共撐，不如借對方一把備用傘 |
| **別人的傘** | **不要拿走**，哪怕是 ¥700 的透明塑膠傘；從傘架偷傘雖屬小案，卻普遍招人反感 |
| **用完之後** | **回家後撐開晾乾**（見雨傘保養一文）；濕傘收攏過夜會生鏽、發臭 |

- **消費量：每年約 1.2 億到 1.3 億把傘**，其中很大一部分是下雨時在便利商店買的**約 ¥600–800 的透明塑膠傘**——很多被隨手丟棄；一些城市現在推出了**共享雨傘服務**（iKasa，在車站用 App 解鎖，¥140／天）。
- 從傘架上**偷傘**常見到什麼程度呢？大家會**在傘柄上貼膠帶做記號**，或使用**附鎖的傘架**；把一把好傘留在敞開的傘架上，會被看作粗心，而不是信任他人。
- 店門口的**塑膠傘套**是一個廢棄物問題；許多連鎖店作為自主減塑措施改用了**瀝水架或可重複使用的傘套**——傘套並不在 2022 年該法指定的 12 種一次性用品之列。

> **[待核實]** 消費量數據請與日本洋傘振興協議會（JUPA）核對；共享服務的細節請與營運方核對。

## 誤解1｜把傘帶進去就好

**放進門口的傘架，或者套上傘套。**濕傘靠在貨架上、滴在餐廳地板上，是外來訪客最常犯的小失禮。

## 誤解2｜在門口裡側把傘撐開

**走出門外再撐開**——在室內撐傘會把水甩得滿門口都是，還會打到你身後的人。先跨出去，再撐開。

## 誤解3｜收好的傘夾在腋下橫著拿

**這時傘尖朝後，正好在腰的高度——也就是孩子臉的高度。**要**直著拿、傘尖朝下**，貼在身側。

## 誤解4｜傘架上便宜的透明傘誰拿都行

**不行。**留下它的人會回來取。要是你被雨困住了，就**自己買一把**——便利商店裡大約 ¥700；每家都有，這也正是傘架裡滿是這種傘的原因。

## 誤解5｜和旁邊的陌生人共撐一把傘

願意為人遮雨是善意，但在日本文化裡**相合傘（あいあいがさ）帶有親密意味**；自然的做法是**借給對方一把備用傘**，或者陪對方走到最近的店家。讀懂當下的場合，比記住規則更重要。
