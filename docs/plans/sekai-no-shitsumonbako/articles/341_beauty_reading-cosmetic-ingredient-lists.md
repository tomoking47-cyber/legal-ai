# Q. 化粧品の成分表示の読み方について、よくある誤解は？｜世界の質問箱 #341

- 棚：`beauty` ／ URL：`/questions/reading-cosmetic-ingredient-lists` ／ ステータス：**ドラフト（法務レビュー前・出典未検証）**

2001年から日本の化粧品には全成分表示が義務づけられ、パッケージには数十の成分名が並びます。「どこを見ればよいか」「順番に意味はあるか」は日本でも海外でも共通の疑問です。

## A. 最大の誤解は「成分の数が少ないほど安全、多いほど危険」です。成分表示は配合量の多い順（1%以下は順不同）で、最初の数行がその製品の性質を決めます。成分の数と刺激の有無に関係はなく、自分に合わない成分を知って避けることが、表示を読む実用的な目的です。

## 表示のルール

| ルール | 内容 |
|---|---|
| **全成分表示** | **2001年4月**から義務（医薬品医療機器等法第61条）。**すべての成分を表示** |
| **順番** | **配合量の多い順**。ただし**1%以下の成分は順不同**でよい。**着色剤は最後にまとめて** |
| 成分名 | **日本化粧品工業会の「化粧品の成分表示名称」**（INCIに準拠した日本語名）。例：水、グリセリン、BG、エタノール |
| 医薬部外品 | **有効成分を先に「有効成分：」として表示**、他は「その他の成分」。**全成分表示は自主基準**（多くのメーカーが実施） |
| キャリーオーバー | 原料に含まれる微量の防腐剤などは**表示義務なし**（原料の安定化目的） |
| 「無添加」「フリー」 | **法的定義なし**（無添加の記事を参照） |

### 読み方の要点

| 見る場所 | 分かること |
|---|---|
| **最初の3〜5行** | 製品の**土台**（水、グリセリン、BG、エタノール、油分など）。**エタノールが上位ならさっぱり系・刺激を感じる人も** |
| **中盤** | 保湿成分・整肌成分・増粘剤・乳化剤 |
| **1%以下（後半）** | 香料・防腐剤（フェノキシエタノール、パラベン）・**訴求成分（〇〇エキス）が多くここ** |
| **最後** | 着色剤（赤〇号、黄〇号、酸化鉄など） |

> 【要検証】表示義務の根拠と例外（1%以下の順序、キャリーオーバー）は厚生労働省の通知（医薬審発第163号ほか）と日本化粧品工業会の資料で確認してください。

## 誤解1｜成分が多い製品は危険

**数と刺激は無関係**です。**合わない成分を1つ知る**ほうが実用的。**かぶれた製品の成分表を写真に撮って皮膚科に持参**すると、原因の特定に役立ちます。

## 誤解2｜広告の「〇〇エキス配合」は主成分

多くは**1%以下の後半に表示**されます。**配合の事実は表示どおりでも、量は少ない**ことが普通です。**上位3〜5行**が製品の実体。

## 誤解3｜英語のINCI名と日本語表示は別の成分

**同じ成分の日本語名称**です（例：Butylene Glycol＝BG、Tocopherol＝トコフェロール）。**海外製品と比べるときは対応表**（日本化粧品工業会）で確認できます。

## 誤解4｜「アルコールフリー」ならエタノールは入っていない

**「アルコール」は化粧品ではエタノールを指すことが多い**ですが、**ステアリルアルコール・ベヘニルアルコール（高級アルコール、実質は油分）**は別物で、フリー表示の対象外のことがあります。**エタノールの表示位置**を見ます。

## 誤解5｜成分表示を読めば効果が分かる

**分かるのは組成**で、**効果の大小は配合量・処方・肌質**で決まります。**表示は「避ける」ために読む**のが、皮膚科でも案内される実用的な使い方です。
