# Q. 关于阅读化妆品全成分表，常见的误解有哪些？｜Japan Questions #341

- Shelf: `beauty` ／ URL: `/zh-cn/beauty/reading-cosmetic-ingredient-lists` ／ Status: **草稿 — 出处未核实**

自2001年起，在日本销售的所有化妆品都必须标注全部成分，因此包装上印着几十个名称——而且是日语。该看哪里、顺序有没有意义，这些问题在日本国内外都同样常被问到。本文说明日本的相关规定，以及在读不懂每一个词的情况下如何使用这份成分表。

## A. 最大的误解是「成分越少越安全，越多越有风险」。成分表按含量从多到少排列（含量在1%以下的成分可以任意顺序排列），开头几行就决定了这个产品是什么。成分的数量与是否刺激皮肤没有关联。阅读成分表的实际意义在于：知道并避开不适合自己的成分。

## 标注的规定

| 规定 | 内容 |
|---|---|
| **全成分标注** | **2001年4月**起成为义务（药机法第61条——日本关于化妆品与药品的法律）。**所有成分都必须列出** |
| **顺序** | **按含量从多到少排列。** 但**含量在1%以下的成分可以任意顺序排列**。**着色剂统一排在最后** |
| 成分名称 | **日本化妆品工业联合会（JCIA）的「化妆品成分标注名称」**（以INCI为基础的日语名称）。例如：水（水）、グリセリン（甘油）、BG（丁二醇）、エタノール（乙醇） |
| 医药部外品（医薬部外品——日本介于化妆品与药品之间的类别） | **有效成分先列在「有効成分」（有效成分）之下**，其余列在「その他の成分」（其他成分）之下。**全成分标注是业界的自主标准**（多数厂商遵循） |
| 携带成分（carry-over） | 原料中所含的微量防腐剂等**无需标注**（它们是为了稳定原料而存在的） |
| 「無添加」（无添加）与「フリー」（不含〜） | **没有法律定义**（参见关于无添加宣称的文章） |

### 怎么读

| 看哪里 | 能知道什么 |
|---|---|
| **开头3〜5行** | 产品的**基底**（水、甘油、BG、乙醇、油分）。**如果乙醇靠前，就属于清爽型，有些人会觉得刺痛** |
| **中段** | 保湿成分与肤感调理成分、增稠剂、乳化剂 |
| **1%以下（后半部分）** | 香料、防腐剂（苯氧乙醇、对羟基苯甲酸酯类），以及**广告主打的多数「明星」成分（〇〇エキス，「〇〇提取物」）** |
| **末尾** | 着色剂（赤〇号「红〇号」、黄〇号「黄〇号」、氧化铁） |

> **[待核实]** 标注的法律依据及其例外（1%以下成分的顺序、carry-over），请对照厚生劳动省的通知（医药审发第163号等）与日本化妆品工业联合会的资料核实。

## 误解1｜成分多的产品有风险

**成分的数量与刺激性无关。** **知道一个不适合自己的成分**要有用得多。**把让您起疹子的产品的成分表拍下来，带到皮肤科就诊（适用日本健康保险）**——这有助于查明原因。

## 误解2｜广告里的「含〇〇提取物」是主要成分

这类成分多数**出现在成分表后半、1%以下的部分。** **就标注而言这个说法没错，但含量通常很少。** **开头3〜5行**才是产品的实质。

## 误解3｜英文INCI名称和日语标注名称是不同的成分

它们是**同一批成分的日语名称**（例如 Butylene Glycol = BG，Tocopherol = トコフェロール）。**与本国的产品作比较时，请使用日本化妆品工业联合会的对照表。**

## 误解4｜「无酒精」就是不含乙醇

**在化妆品里，「酒精」通常指乙醇**，但**硬脂醇、山嵛醇（脂肪醇，实际上属于油分）**是不同的物质，有时不在「不含〜」宣称的范围内。**请看乙醇在成分表中的位置。**

## 误解5｜读成分表就能知道效果好不好

**您能知道的是组成**；**效果有多少，取决于含量、配方和您的皮肤。** **为了避开成分而读成分表**，才是皮肤科也推荐的实际用法。
