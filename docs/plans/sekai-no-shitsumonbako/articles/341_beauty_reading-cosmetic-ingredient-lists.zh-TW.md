# Q. 關於閱讀化妝品全成分表，常見的誤解有哪些？｜Japan Questions #341

- Shelf: `beauty` ／ URL: `/zh-tw/beauty/reading-cosmetic-ingredient-lists` ／ Status: **草稿 — 出處未核實**

自2001年起，在日本販售的所有化妝品都必須標示全部成分，因此包裝上印著幾十個名稱——而且是日文。該看哪裡、順序有沒有意義，這些問題在日本國內外都同樣常被問到。本文說明日本的相關規定，以及在讀不懂每一個字的情況下如何運用這份成分表。

## A. 最大的誤解是「成分越少越安全，越多越有風險」。成分表依含量由多至少排列（含量在1%以下的成分可以任意順序排列），開頭幾行就決定了這項產品是什麼。成分的數量與會不會刺激皮膚沒有關聯。閱讀成分表的實際意義在於：知道並避開不適合自己的成分。

## 標示的規定

| 規定 | 內容 |
|---|---|
| **全成分標示** | **2001年4月**起成為義務（藥機法第61條——日本關於化妝品與藥品的法律）。**所有成分都必須列出** |
| **順序** | **依含量由多至少排列。** 但**含量在1%以下的成分可以任意順序排列**。**著色劑統一排在最後** |
| 成分名稱 | **日本化妝品工業聯合會（JCIA）的「化妝品成分標示名稱」**（以INCI為基礎的日文名稱）。例如：水（水）、グリセリン（甘油）、BG（丁二醇）、エタノール（乙醇） |
| 醫藥部外品（医薬部外品——日本介於化妝品與藥品之間的類別） | **有效成分先列在「有効成分」（有效成分）之下**，其餘列在「その他の成分」（其他成分）之下。**全成分標示是業界的自主標準**（多數廠商遵循） |
| 帶入成分（carry-over） | 原料中所含的微量防腐劑等**不需標示**（它們是為了穩定原料而存在的） |
| 「無添加」（無添加）與「フリー」（不含〜） | **沒有法律定義**（參見關於無添加宣稱的文章） |

### 怎麼讀

| 看哪裡 | 能知道什麼 |
|---|---|
| **開頭3〜5行** | 產品的**基底**（水、甘油、BG、乙醇、油分）。**如果乙醇排得靠前，就屬於清爽型，有些人會覺得刺痛** |
| **中段** | 保濕成分與膚感調理成分、增稠劑、乳化劑 |
| **1%以下（後半部分）** | 香料、防腐劑（苯氧乙醇、對羥基苯甲酸酯類），以及**廣告主打的多數「明星」成分（〇〇エキス，「〇〇萃取物」）** |
| **末尾** | 著色劑（赤〇号「紅〇號」、黄〇号「黃〇號」、氧化鐵） |

> **[待核實]** 標示的法律依據及其例外（1%以下成分的順序、carry-over），請對照厚生勞動省的通知（醫藥審發第163號等）與日本化妝品工業聯合會的資料核實。

## 誤解1｜成分多的產品有風險

**成分的數量與刺激性無關。** **知道一個不適合自己的成分**要有用得多。**把讓您起疹子的產品的成分表拍下來，帶到皮膚科就診（適用日本健康保險）**——這有助於查明原因。

## 誤解2｜廣告裡的「含〇〇萃取物」是主要成分

這類成分多數**出現在成分表後半、1%以下的部分。** **就標示而言這個說法沒錯，但含量通常很少。** **開頭3〜5行**才是產品的實質。

## 誤解3｜英文INCI名稱和日文標示名稱是不同的成分

它們是**同一批成分的日文名稱**（例如 Butylene Glycol = BG，Tocopherol = トコフェロール）。**要與自己國家的產品做比較時，請使用日本化妝品工業聯合會的對照表。**

## 誤解4｜「無酒精」就是不含乙醇

**在化妝品裡，「酒精」通常指乙醇**，但**硬脂醇、山嵛醇（脂肪醇，實際上屬於油分）**是不同的物質，有時不在「不含〜」宣稱的範圍內。**請看乙醇在成分表中的位置。**

## 誤解5｜讀成分表就能知道效果好不好

**您能知道的是組成**；**效果有多少，取決於含量、配方與您的皮膚。** **為了避開成分而讀成分表**，才是皮膚科也推薦的實際用法。
