# Q. 關於化妝水該用化妝棉還是用手擦，常見的誤解有哪些？｜Japan Questions #342

- Shelf: `beauty` ／ URL: `/zh-tw/beauty/cotton-vs-hands-for-toner` ／ Status: **草稿 — 出處未核實**

「化妝棉還是用手？」是日本保養界持續最久的爭論。在日本以外，這個問題往往要往前推一步：化妝水（化粧水，keshōsui——洗臉後使用的水狀保養水）到底是做什麼用的？兩種方式各有各的道理，選哪一種取決於皮膚的狀態。

## A. 最大的誤解是「其中一種才是正確答案」。化妝棉能把化妝水推得均勻，也可以用來擦拭，但容易產生摩擦，也容易用掉過多產品。用手摩擦較少，用量也比較好拿捏，但可能擦不均勻。皮膚科普遍的建議是「哪一種都行——但要按壓，不要搓、不要拍」。乾性皮膚或敏感皮膚，用手是比較穩妥的選擇。

## 兩種方式的比較

| 項目 | 化妝棉 | 用手 |
|---|---|---|
| 均勻度 | **容易推開**，能顧到細節處（鼻翼兩側、眼下） | 容易有擦不到的地方 |
| 摩擦 | **順著纖維搓會造成刺激。** 若**以按壓取代滑動**則很小 | **最小** |
| 用量 | **化妝棉會吸收，所以用量較多**（**約500日圓硬幣大小的量，直到化妝棉整片浸透**） | **少量就夠**（從100日圓硬幣大小的量起） |
| 衛生 | **拋棄式，所以乾淨** | **請先洗手** |
| 擦拭 | **可以**（擦拭型化妝水本來就以化妝棉為前提） | 不行 |
| 適合的皮膚 | 中性或油性皮膚；用於擦拭 | **乾性、敏感或容易泛紅的皮膚** |
| 成本 | 化妝棉的錢 | 無 |

- 日本皮膚科學會等機構的一般說明指出，**保養造成的刺激大多來自「搓、敲、拍」**；**重點是「按壓讓它吸收」，而不是用什麼工具。**
- 在化妝品領域，依業界的廣告指南，**「滲透」（浸透）**指的是**到達角質層（皮膚最外層）為止**。**「化妝棉能把成分壓得更深」「手的體溫能把成分帶進去」這類說法沒有官方依據。**
- **化妝棉面膜（把化妝棉浸滿化妝水後敷幾分鐘）**，**一旦開始變乾就會反過來帶走皮膚的水分**，因此一般建議**約3分鐘**後取下（與面膜那篇文章的道理相同）。

> **[待核實]** 請核實日本皮膚科學會的說法，以及廣告指南對「滲透」的處理方式。用量為廠商的建議值。

## 誤解1｜用化妝棉能讓成分滲透得更好

**不管用哪一種工具，滲透都只到角質層為止。** **均勻**是化妝棉的優勢；**摩擦較少**是用手的優勢。

## 誤解2｜用手擦會把細菌帶到臉上

**洗過的手沒有問題。** 化妝品**本身就添加了防腐劑**，而**用乾淨的手**正是皮膚科醫師視為理所當然的做法。

## 誤解3｜拍打能促進血液循環

**拍打可能造成泛紅與色素沉澱**，皮膚科並不推薦。**請按壓。**

## 誤解4｜化妝棉面膜敷得越久越好

**一旦開始變乾，就會帶走皮膚的水分。** 請在**約3分鐘**後取下，並**用乳液（乳液，nyūeki）或乳霜封住。**

## 誤解5｜化妝棉隨便哪一種都行

**蓬鬆、偏硬或過薄的化妝棉會產生摩擦，還會留下纖維。** 請使用**化妝用化妝棉（較厚、不掉棉絮）**，並**把它放在皮膚上，而不是滑動。**
