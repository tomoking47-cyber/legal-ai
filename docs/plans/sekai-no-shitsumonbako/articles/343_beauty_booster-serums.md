# Q. 導入美容液（ブースター）について、よくある誤解は？｜世界の質問箱 #343

- 棚：`beauty` ／ URL：`/questions/booster-serums` ／ ステータス：**ドラフト（法務レビュー前・出典未検証）**

「化粧水の前に使う美容液」は日本で独自に広まった品目で、海外では「なぜ化粧水の前に何かを塗るのか」と問われます。役割と、法律上言えることの範囲を整理します。

## A. 最大の誤解は「導入美容液は肌に穴を開けて成分を奥まで届ける」です。化粧品の「浸透」は角層までと定義され、導入美容液が言えるのは「肌をやわらげ、次に使う化粧水をなじみやすくする」という範囲です。洗顔後の乾いた肌に水分やなじみをよくする成分を先に与える、という使い方の工夫であり、必須の品目ではありません。

## 位置づけ

| 項目 | 内容 |
|---|---|
| 使う順番 | **洗顔→導入美容液→化粧水→美容液→乳液・クリーム** |
| 役割（業界の慣用） | **角層をやわらげ、次の化粧水の「なじみ」をよくする**。保湿成分・エタノール・油分などで設計 |
| 法律上の区分 | **化粧品**（一部は医薬部外品）。効能は**56項目**の範囲：「皮膚をやわらげる」「皮膚にうるおいを与える」 |
| 「浸透」の表現 | **角層まで**（日本化粧品工業会 適正広告ガイドライン）。**「肌の奥へ」「真皮まで」は化粧品では言えない** |
| 必須か | **いいえ**。**化粧水のなじみが悪いと感じる人、乾燥が強い人**が足す品目 |
| 代替 | **洗顔後すぐ（30秒以内）に化粧水をつける**だけで、なじみは大きく変わるとされる |

- 「ブースター」「プレ化粧水」「先行美容液」「導入液」は**すべて同じ位置づけの製品の呼び名**で、**法的な定義はありません。**
- **エタノールを多く含む導入液**は、**さっぱり感と揮発でなじみをよくする**設計のものがあり、**乾燥肌・敏感肌には刺激**になることがあります。**成分表示の上位**を確認（成分表示の記事を参照）。
- **拭き取りタイプの導入液**は、**角質ケアの要素**を含み、**毎日の使用で乾燥する人**もいます（角質ケアの記事を参照）。

> 【要検証】56項目は薬食発0721第1号、「浸透」の扱いは適正広告ガイドラインで確認してください。

## 誤解1｜導入美容液で成分が奥まで届く

**化粧品の浸透は角層まで**で、それは導入液でも変わりません。**「奥まで」の表現は広告で使えません。**

## 誤解2｜導入美容液は全員に必要

**スキンケアの基本の順番（化粧水→乳液）に足す「もう1品」**です。**洗顔後すぐの化粧水**でなじみに不満がなければ不要。

## 誤解3｜高価な導入液ほど効果が高い

**言える効能は同じ56項目の範囲**。違いは**質感・成分**。**続けやすい価格**で選ぶのが実際的。

## 誤解4｜導入液を使えば化粧水は省ける

**導入液は化粧水の「前」に使う設計**で、**保湿の主役ではありません。** 省くなら導入液のほう。

## 誤解5｜ピリピリするのは効いている証拠

**刺激反応**です。**エタノール・角質ケア成分**が合わない可能性。**使用をやめ、続くなら皮膚科**。
