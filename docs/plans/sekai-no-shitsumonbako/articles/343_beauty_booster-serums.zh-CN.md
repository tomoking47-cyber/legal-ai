# Q. 关于导入精华（導入美容液），常见的误解有哪些？｜Japan Questions #343

- Shelf: `beauty` ／ URL: `/zh-cn/beauty/booster-serums` ／ Status: **草稿 — 出处未核实**

「在化妆水之前使用的精华」，是一个在日本发展起来的产品品类。来访者常问：为什么要在化妆水（化粧水，keshōsui——洗脸后使用的水状护肤水）之前再涂一样东西？本文说明这类产品的作用，以及日本法律允许它宣称什么。

## A. 最大的误解是「导入精华能打开皮肤，把成分送到深层」。在化妆品里，「渗透」的定义仅指到达角质层（皮肤最外层）为止，导入精华所能宣称的只是「柔软肌肤，帮助之后的化妆水延展与吸收」。它是先给刚洗完脸、发干的皮肤一些水分与延展性成分的做法，并不是必需品。

## 它的位置

| 项目 | 内容 |
|---|---|
| 使用顺序 | **卸妆洁面 → 导入精华 → 化妆水（化粧水） → 精华 → 乳液（乳液）或面霜** |
| 作用（业界惯例） | **柔软角质层，帮助之后的化妆水「吸收」。** 配有保湿成分、乙醇、油分等 |
| 法律分类 | **化妆品**（也有部分是医药部外品，医薬部外品——日本介于化妆品与药品之间的类别）。宣称限于**获准的56个项目**，例如「柔软肌肤」「滋润肌肤」 |
| 「渗透」的表述 | **到角质层为止**（日本化妆品工业联合会广告指南）。**化妆品不能说「深入皮肤内部」或「到达真皮层」** |
| 是必需品吗？ | **不是。** 这是**觉得化妆水不太好吸收、或皮肤非常干燥的人**追加的一项 |
| 替代做法 | **洗脸后立刻（30秒内）涂化妆水**，一般认为光是这一点就有很大差别 |

- 「导入精华」（booster）、「前导化妆水」（プレ化粧水）、「先行精华」（先行美容液）、「导入液」（導入液）**都是同一位置产品的不同叫法**，**没有一个有法律定义。**
- **乙醇含量高的导入精华**，可能是为了**带来清爽感、并借由挥发提升延展性**而设计的，**对干性或敏感皮肤可能造成刺激。** 请看**成分表的开头部分**（参见成分表那篇文章）。
- **擦拭型的导入精华**含有**去角质的成分**，**有些人每天使用会觉得干燥**（参见去角质那篇文章）。

> **[待核实]** 请对照药食发0721第1号核实56个项目，以及广告指南对「渗透」的处理方式。

## 误解1｜导入精华能把成分送到皮肤深层

**无论有没有用导入精华，化妆品的渗透都止于角质层。** **广告中不能使用「深入皮肤内部」这样的说法。**

## 误解2｜每个人都需要导入精华

它是在基础流程（化妆水 → 乳液）之上**「再加的一项」。** 如果**洗脸后立刻涂的化妆水**对您来说吸收得够好，那就不需要。

## 误解3｜导入精华越贵效果越好

**无论价格如何，允许宣称的都是同样的56个项目。** 差别在于**肤感与成分。** 选择**自己能长期负担的价格**才是务实的做法。

## 误解4｜用了导入精华就可以省掉化妆水

**导入精华的设计就是用在化妆水之前**，而且**它不是主要的保湿产品。** 如果要省掉一样，请省掉导入精华。

## 误解5｜有刺痛感说明起作用了

**那是刺激反应。** **乙醇或去角质成分**可能不适合您。**请停止使用；若情况持续，请到皮肤科就诊（适用日本健康保险）。**
