# Q. 關於導入精華（導入美容液），常見的誤解有哪些？｜Japan Questions #343

- Shelf: `beauty` ／ URL: `/zh-tw/beauty/booster-serums` ／ Status: **草稿 — 出處未核實**

「在化妝水之前使用的精華液」，是一個在日本發展起來的產品類別。來訪的人常問：為什麼要在化妝水（化粧水，keshōsui——洗臉後使用的水狀保養水）之前再擦一樣東西？本文說明這類產品的作用，以及日本法律允許它宣稱什麼。

## A. 最大的誤解是「導入精華能打開皮膚，把成分送到深層」。在化妝品裡，「滲透」的定義僅指到達角質層（皮膚最外層）為止，導入精華所能宣稱的只是「柔軟肌膚，幫助後續的化妝水延展與吸收」。它是先給剛洗完臉、發乾的皮膚一些水分與延展性成分的做法，並不是必需品。

## 它的位置

| 項目 | 內容 |
|---|---|
| 使用順序 | **卸妝洗臉 → 導入精華 → 化妝水（化粧水） → 精華液 → 乳液（乳液）或乳霜** |
| 作用（業界慣例） | **柔軟角質層，幫助後續的化妝水「吸收」。** 添加保濕成分、乙醇、油分等 |
| 法律分類 | **化妝品**（也有部分屬於醫藥部外品，医薬部外品——日本介於化妝品與藥品之間的類別）。宣稱限於**核准的56個項目**，例如「柔軟肌膚」「滋潤肌膚」 |
| 「滲透」的說法 | **到角質層為止**（日本化妝品工業聯合會廣告指南）。**化妝品不能說「深入皮膚內部」或「到達真皮層」** |
| 是必需品嗎？ | **不是。** 這是**覺得化妝水不太好吸收、或皮膚非常乾燥的人**追加的一項 |
| 替代做法 | **洗臉後立刻（30秒內）擦化妝水**，一般認為光是這一點就有很大差別 |

- 「導入精華」（booster）、「前導化妝水」（プレ化粧水）、「先行精華液」（先行美容液）、「導入液」（導入液）**都是同一個位置產品的不同叫法**，**沒有一個有法律定義。**
- **乙醇含量高的導入精華**，可能是為了**帶來清爽感、並藉由揮發提升延展性**而設計的，**對乾性或敏感皮膚可能造成刺激。** 請看**成分表的開頭部分**（參見成分表那篇文章）。
- **擦拭型的導入精華**含有**去角質的成分**，**有些人每天使用會覺得乾燥**（參見去角質那篇文章）。

> **[待核實]** 請對照藥食發0721第1號核實56個項目，以及廣告指南對「滲透」的處理方式。

## 誤解1｜導入精華能把成分送到皮膚深層

**不管有沒有用導入精華，化妝品的滲透都止於角質層。** **廣告中不能使用「深入皮膚內部」這樣的說法。**

## 誤解2｜每個人都需要導入精華

它是在基本流程（化妝水 → 乳液）之上**「再加的一項」。** 如果**洗臉後立刻擦的化妝水**對您來說吸收得夠好，那就不需要。

## 誤解3｜導入精華越貴效果越好

**不管價格如何，允許宣稱的都是同樣的56個項目。** 差別在於**膚感與成分。** 選擇**自己能長期負擔的價格**才是務實的做法。

## 誤解4｜用了導入精華就可以省掉化妝水

**導入精華的設計就是用在化妝水之前**，而且**它不是主要的保濕產品。** 如果要省掉一樣，請省掉導入精華。

## 誤解5｜有刺痛感表示正在發揮作用

**那是刺激反應。** **乙醇或去角質成分**可能不適合您。**請停止使用；若情況持續，請到皮膚科就診（適用日本健康保險）。**
