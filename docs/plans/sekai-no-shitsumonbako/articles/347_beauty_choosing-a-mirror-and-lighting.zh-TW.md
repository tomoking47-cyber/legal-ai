# Q. 關於化妝用的鏡子與燈光選擇，常見的誤解有哪些？｜Japan Questions #347

- Shelf: `beauty` ／ URL: `/zh-tw/beauty/choosing-a-mirror-and-lighting` ／ Status: **草稿 — 出處未核實**

「在家裡看起來很完美的妝，出門後就變了樣」是全世界共通的經驗。原因通常不在鏡子，而在光的顏色與方向。在日本，家中常見的偏藍白「晝光色」吸頂燈，以及洗面所「洗面所」(洗手台一帶)的照明，都扮演了角色。

## A. 最大的誤解是「妝畫得不好是鏡子的錯」。決定妝容效果的是光的色溫（偏藍的「晝光色」或偏暖的「電球色」）、亮度，以及方向（只從上方照，或從臉的正面照）。基本要點是「接近自然光的中性白（5,000K 左右）」「從臉的正面均勻照射」「最後在你將要示人的那種光線下確認一次」。

## 光的顏色與方向

| 項目 | 內容 |
|---|---|
| **色溫** | **電球色「電球色」(約 2,700〜3,000K)**：偏暖、黃色感強 → 粉底看起來較深，泛紅也不容易看出 ／ **晝白色「昼白色」(約 5,000K)**：接近自然光 → **適合化妝** ／ **晝光色「昼光色」(約 6,500K)**：偏藍白 → **在日本的洗面所與客廳很常見。** 會讓氣色看起來蒼白，於是腮紅容易上太多 |
| **方向** | **只有上方來光**：眼下與鼻子下方出現陰影 → 遮瑕容易上太多 ／ **正面來光**：沒有陰影，較接近實際 |
| **亮度** | 洗面所的照明常在 **300〜500 勒克斯** 左右。**化妝時臉部 500〜1,000 勒克斯** 是參考值（太亮反而看不出不均勻） |
| **演色性（Ra）** | **Ra 90 以上** 能準確呈現顏色。一般 LED 大約是 **Ra 80** |
| **鏡子** | **沒有變形的平面鏡**；**放大鏡只用於細節（眉毛、眼睛）。** 用放大鏡畫整張臉會畫得太重 |
| **在外面確認** | 在 **窗邊的自然光** 下，或在 **你要去的地方的光線（辦公室的晝白色、傍晚的街燈）** 下做最後確認 |

- 日本家庭普遍使用 **晝光色（偏藍白）的吸頂燈**，**洗面所也多為晝光色**；人們常說 **氣色看起來蒼白，於是紅色調上得太多。**
- **LED 燈的色溫與演色性會印在產品上**（依日本工業標準 JIS Z9112 分類）。**大多數「化妝鏡」是 Ra 90 以上、5,000K 左右。**
- **把洗面所的燈換成晝白色（5,000K），或在鏡子旁加一盞正面燈** —— 這是在日本生活的人們之間流傳開來的訣竅。

> **[待核實]** 請依 JIS Z9112 核對色溫分類，依 JIS Z9110 核對照度參考值。

## 誤解1｜買一面貴的鏡子就能解決

**一面沒有變形的平面鏡就夠了。** 真正造成差別的是 **光的顏色與方向。**

## 誤解2｜越亮越好

**太亮反而看不出不均勻與厚重感，出門後就顯得妝很厚。** **500〜1,000 勒克斯左右，均勻照射。**

## 誤解3｜晝光色（偏藍白的光）和自然光一樣

**晝光色是 6,500K，比白天實際的自然光（大約 5,000〜5,500K）更藍。** 氣色看起來蒼白，於是 **腮紅與口紅最後都上得太重。**

## 誤解4｜整張臉都用放大鏡畫完

**放大鏡是用於細節的。** 放大著看整張臉會導致 **上妝過重。** **整張臉用 1 倍鏡，眉毛與眼睛用放大鏡。**

## 誤解5｜在家裡完美，出門也完美

**戶外的光和家裡的光不一樣。** **在窗邊的自然光下** 做最後確認，或 **在你將要置身的色溫的光線下** 確認，才是可靠的做法。
