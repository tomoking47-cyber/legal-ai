# Q. 化粧品のサンプルとトラベルサイズについて、よくある誤解は？｜世界の質問箱 #348

- 棚：`beauty` ／ URL：`/questions/cosmetic-samples-and-travel-sizes` ／ ステータス：**ドラフト（法務レビュー前・出典未検証）**

旅行用に化粧品を詰め替える、サンプルをためて使う——どちらも日本の生活者の定番ですが、衛生と航空の規則に関わる注意があります。海外の人からは「日本のトラベルサイズはなぜ充実しているか」と問われます。

## A. 最大の誤解は「詰め替えた化粧品は本品と同じ品質が保たれる」です。詰め替えると空気・雑菌が入り、容器の材質で成分が変わることがあり、多くのメーカーは詰め替えを推奨していません。旅行用は「メーカーのトラベルサイズや個包装サンプル」が確実で、機内持ち込みの液体は100mL以下の容器を1Lの袋に、が国際ルールです。

## 判断の材料

| 項目 | 内容 |
|---|---|
| **詰め替え** | メーカーの多くは**非推奨**。**空気・雑菌の混入、容器の材質（ポリスチレン等）による成分の変化、防腐効果の低下**。**詰め替えるなら清潔な容器に、数日〜1週間で使い切る** |
| **サンプル（パウチ）** | **1回分**。**開封したら使い切る**。**未開封でも薄い包材で光と熱に弱く、1年程度が目安** |
| **トラベルサイズ（ミニボトル）** | メーカーが**本品と同じ処方・容器**で製造。**表示（成分・製造販売元）**があり、**衛生的** |
| **機内持ち込み（国際線）** | **液体・ジェル・エアロゾルは1容器100mL以下、合計1Lの透明袋に** |
| **機内持ち込み（日本の国内線）** | **100mLの制限なし**（ただし**エアロゾルは1容器0.5L・合計2Lまで**） |
| **エアロゾル（スプレー缶）** | **航空機は制限あり**、**郵送は航空便不可**（郵送の記事を参照） |

- 化粧品の**表示義務**（成分・製造販売元・使用期限等）は**容器または外箱**にあり、**詰め替えると表示が失われ、何が入っているか分からなくなる**ことも問題です（アレルギー時の特定が困難）。
- 日本の**トラベルサイズ市場**は、**出張・国内旅行の多さ**と**サンプルの文化（購入時に付く）**で発達し、**100均・ドラッグストアに専用コーナー**があります。
- **日焼け止めスプレー・制汗スプレー**は**エアロゾル**で、**国際線は100mL以下**、**国内線は0.5L以下**。

> 【要検証】航空機の液体・エアロゾル規制は国土交通省航空局の最新の案内、詰め替えの注意は日本化粧品工業会・メーカーの資料で確認してください。

## 誤解1｜詰め替えれば経済的で衛生面も同じ

**空気と雑菌が入り、防腐効果が薄まります。** **短期間で使い切る**前提で、**清潔な容器**に。**メーカーのトラベルサイズ**のほうが確実。

## 誤解2｜サンプルは何年もためておける

**パウチは薄く、光と熱で劣化**。**1年以内**を目安に、**開けたら1回で**。**分離・変色・においで処分**。

## 誤解3｜国内線も100mLの制限がある

**日本の国内線には液体の100mL制限はありません**（エアロゾルは別）。**国際線は100mL・1L袋**。

## 誤解4｜スプレー缶は化粧品だから制限なし

**エアロゾルは航空機で容量制限があり、郵送は航空便不可**。**貨物室でも制限**。

## 誤解5｜詰め替え容器は100均のもので十分

**材質（ポリスチレン等）によっては成分で変形・溶出**することがあります。**「化粧品用」「PP/PE」の表示**を選び、**同じ製品を入れ続けない**。
