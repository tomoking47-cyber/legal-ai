# Q. タオルの洗濯とにおいについて、よくある誤解は？｜世界の質問箱 #351

- 棚：`fashion` ／ URL：`/questions/washing-towels` ／ ステータス：**ドラフト（法務レビュー前・出典未検証）**

「洗ったのにタオルがにおう」「ごわごわになった」は世界共通の悩みで、日本の高温多湿では特に起きやすい。柔軟剤への誤解と、におい菌（モラクセラ菌）の知見から整理します。

## A. 最大の誤解は「タオルには毎回柔軟剤を使うほどふわふわで清潔になる」です。柔軟剤は繊維をコーティングして吸水性を下げ、汚れ落ちを妨げます。においの主因は洗濯後に残った菌（モラクセラ菌など）が湿ったまま増えることで、対策は「洗ったらすぐ干す」「40〜60℃の湯洗いか酸素系漂白剤」「乾燥機」「柔軟剤は数回に1回」です。

## 判断の材料

| 項目 | 内容 |
|---|---|
| においの原因 | **洗濯で落ちきらなかった皮脂・角質を、湿った状態で菌（モラクセラ菌等）が分解**。**生乾き臭の主因** |
| 洗剤 | **規定量**。**入れすぎはすすぎ残し→菌の栄養** |
| 柔軟剤 | **繊維をコーティング→吸水性低下・汚れ落ち低下**。**使うなら数回に1回、規定量** |
| 温度 | **40〜60℃のお湯**で菌と皮脂が落ちやすい（**表示の温度を確認**）。**酸素系漂白剤（粉末）のつけ置き**も有効 |
| 乾燥 | **洗い終わったらすぐ干す**（放置は菌の増殖）。**乾燥機（60℃以上）は菌を減らす** |
| 干し方 | **広げて、風を通す**。**パイルを立てるために、干す前に数回振る** |
| 買い替え | **洗っても匂いが戻る・吸水しない・ほつれ**。目安**1〜2年**（使用頻度による） |

- **モラクセラ菌**は皮脂を分解して**「雑巾のような臭い」**の原因物質を出すことが、洗剤メーカー等の研究で明らかにされ、**60℃以上の熱・酸素系漂白剤・乾燥**で減らせることが示されています。
- **ごわつき**は、**繊維のパイル（ループ）が寝る**ことと**洗剤・皮脂の残り**が原因。**柔軟剤で一時的にやわらかくなっても、根本は洗浄とすすぎ**。
- **タオルの洗濯表示**は多くが**桶に数字（40または60）、乾燥機可**。**60の表示があれば湯洗い可**。

> 【要検証】モラクセラ菌の説明は洗剤メーカー（花王・ライオン等）の研究発表に基づきます。記号は消費者庁「洗濯表示」で確認してください。

## 誤解1｜柔軟剤で清潔になる

**柔軟剤に洗浄力はありません。** **吸水性を下げ、汚れ落ちを妨げる**ため、タオルには**数回に1回**が目安。

## 誤解2｜においは洗剤を増やせば消える

**洗剤の入れすぎはすすぎ残しで逆効果**。**原因は残った菌**で、**熱・漂白・乾燥**が対策。

## 誤解3｜生乾き臭は乾かせば消える

**乾いても菌は残り、濡れると再び臭います。** **酸素系漂白剤のつけ置き（40〜50℃、30分〜1時間）または60℃の湯洗い**でリセット。

## 誤解4｜タオルは他の洗濯物と一緒でよい

**タオルは皮脂と角質が多く、他の衣類に菌を移す**ことがあります。**タオルだけまとめて湯洗い**が、日本の生活者の間で共有された方法。

## 誤解5｜ふわふわが戻らないのは寿命

**パイルが寝ている・洗剤が残っている**ことが多く、**すすぎを増やす・干す前に振る・乾燥機を短時間**で戻ることがあります。**吸水しなくなったら寿命**。
