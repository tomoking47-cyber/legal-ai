# Q. 关于洗毛巾和毛巾的异味，人们常有什么误解？｜Japan Questions #351

- Shelf: `fashion` ／ URL: `/zh-cn/fashion/washing-towels` ／ Status: **草稿 — 出处未核实**

“洗过了还是有味道”“毛巾洗得发硬”，这类抱怨到处都能听到。在日本又热又潮的气候里，它们尤其容易发生。本文梳理一个关于柔顺剂的常见误解，以及关于异味背后那类细菌（*Moraxella*，莫拉氏菌）目前已知的情况。

## A. 最大的误解是“每次都用柔顺剂，毛巾就会一直蓬松又干净”。柔顺剂会包覆纤维，降低吸水性，还会妨碍污垢被洗掉。异味的主要原因，是洗涤后残留的细菌（如 *Moraxella*）在毛巾保持潮湿的时候大量繁殖。解决办法是：洗完立刻晾出去；用 40–60°C 的水洗，或用氧系漂白剂浸泡；使用滚筒烘干机；柔顺剂只在每洗几次时用一回。

## 判断的依据

| 项目 | 内容 |
|---|---|
| 异味的成因 | **没被洗掉的皮脂和皮屑，在毛巾潮湿时被细菌（*Moraxella* 等）分解**。**这是“半干臭”（生乾き臭，namakawaki-shū）的主要原因** |
| 洗涤剂 | **按标示的用量**。**用量过多会在纤维里留下残渣，反而成为细菌的养分** |
| 柔顺剂 | **会包覆纤维，因此吸水性和去污力都下降**。**若要使用，每洗几次用一回，并按标示用量** |
| 水温 | **40–60°C（104–140°F）的热水**更容易去除细菌和皮脂（**请确认洗涤标签**）。**用粉状氧系漂白剂（酸素系漂白剤，sanso-kei hyōhakuzai）浸泡**同样有效 |
| 干燥 | **洗好后立刻晾出去**（放在洗衣机筒里会让细菌繁殖）。**滚筒烘干机（60°C 以上）可以减少细菌** |
| 晾晒方式 | **摊开，让空气流通**。**晾之前把毛巾抖几下，把绒毛抖立起来** |
| 更换时机 | **洗完异味又回来、不再吸水、起毛边**。大致标准是**1–2 年**（取决于使用频率） |

- 洗涤剂厂商的研究显示，***Moraxella*** 会分解皮脂，释放出造成**“旧抹布味”**的物质。**60°C 以上的高温、氧系漂白剂和彻底干燥**可以减少它。
- **发硬**来自**绒圈（毛圈）被压平**，以及**洗涤剂和皮脂残留在纤维里**。**柔顺剂能让毛巾一时手感变软，但真正的解决办法是好好洗、好好漂洗**。
- **大多数毛巾的洗涤标签（日本使用 JIS L0001 国际通用符号）**会标出**带数字（40 或 60）的水盆图案和滚筒烘干符号**。**如果标签写着 60，就可以用热水洗**。

> **[待核实]** 关于 *Moraxella* 的说明依据洗涤剂厂商（花王、狮王等）公开的研究。洗涤符号请对照消费者厅“洗涤标示”页面核对。

## 误解1｜柔顺剂能让毛巾变干净

**柔顺剂没有去污能力。** 因为它会**降低吸水性、妨碍污垢被去除**，毛巾的使用标准是**每洗几次用一回**。

## 误解2｜多放洗涤剂就能去掉异味

**洗涤剂放太多，漂洗后会留下残渣，反而更糟**。**原因是残留下来的细菌**，答案是**高温、漂白和干燥**。

## 误解3｜半干臭只要毛巾干了就会消失

**细菌留在干毛巾里，一沾水就又会发出气味。** 请用**氧系漂白剂浸泡（40–50°C，30 分钟到 1 小时）或 60°C 的洗涤**，让毛巾重新归零。

## 误解4｜毛巾可以和其他衣物一起洗

**毛巾带有大量皮脂和皮屑，可能把细菌传给其他衣物**。**把毛巾单独归在一起用热水洗**，是在日本生活的人们之间广泛流传的做法。

## 误解5｜蓬松感回不来，毛巾就报废了

通常是**绒圈被压平，或洗涤剂残留在纤维里**。只要**多加一次漂洗、晾之前抖一抖，或放进烘干机短暂烘一下**，往往就能恢复。**毛巾不再吸水时，才是它的寿命终点**。
