# Q. 關於洗毛巾和毛巾的異味，人們常有什麼誤解？｜Japan Questions #351

- Shelf: `fashion` ／ URL: `/zh-tw/fashion/washing-towels` ／ Status: **草稿 — 出處未核實**

「洗過了還是有味道」「毛巾洗得發硬」，這類抱怨到處都聽得到。在日本又熱又潮的氣候裡，它們特別容易發生。本文整理一個關於柔軟精的常見誤解，以及關於異味背後那類細菌（*Moraxella*，莫拉氏菌）目前已知的情況。

## A. 最大的誤解是「每次都用柔軟精，毛巾就會一直蓬鬆又乾淨」。柔軟精會包覆纖維，降低吸水性，還會妨礙污垢被洗掉。異味的主因，是洗滌後殘留的細菌（如 *Moraxella*）在毛巾維持潮濕時大量繁殖。解決方式是：洗完立刻晾出去；用 40–60°C 的水洗，或用氧系漂白劑浸泡；使用滾筒烘衣機；柔軟精只在每洗幾次時用一回。

## 判斷的依據

| 項目 | 內容 |
|---|---|
| 異味的成因 | **沒被洗掉的皮脂與皮屑，在毛巾潮濕時被細菌（*Moraxella* 等）分解**。**這是「半乾臭」（生乾き臭，namakawaki-shū）的主因** |
| 洗衣精 | **依照標示的用量**。**用量過多會在纖維裡留下殘渣，反而成為細菌的養分** |
| 柔軟精 | **會包覆纖維，因此吸水性與去污力都下降**。**若要使用，每洗幾次用一回，並依標示用量** |
| 水溫 | **40–60°C（104–140°F）的熱水**較容易去除細菌與皮脂（**請確認洗滌標籤**）。**用粉狀氧系漂白劑（酸素系漂白剤，sanso-kei hyōhakuzai）浸泡**同樣有效 |
| 乾燥 | **洗好後立刻晾出去**（放在洗衣機滾筒裡會讓細菌繁殖）。**滾筒烘衣機（60°C 以上）可以減少細菌** |
| 晾曬方式 | **攤開，讓空氣流通**。**晾之前把毛巾抖幾下，把絨毛抖立起來** |
| 更換時機 | **洗完異味又回來、不再吸水、起毛邊**。大致標準是**1–2 年**（視使用頻率而定） |

- 洗劑廠商的研究顯示，***Moraxella*** 會分解皮脂，釋出造成**「舊抹布味」**的物質。**60°C 以上的高溫、氧系漂白劑與徹底乾燥**可以減少它。
- **發硬**來自**絨圈（毛圈）被壓平**，以及**洗衣精與皮脂殘留在纖維裡**。**柔軟精能讓毛巾一時手感變軟，但真正的解決方式是好好洗、好好過水**。
- **大多數毛巾的洗滌標籤（日本使用 JIS L0001 國際通用符號）**會標出**帶數字（40 或 60）的水盆圖案和滾筒烘乾符號**。**如果標籤寫著 60，就可以用熱水洗**。

> **[待核實]** 關於 *Moraxella* 的說明依據洗劑廠商（花王、獅王等）公開的研究。洗滌符號請對照消費者廳「洗濯表示」頁面核對。

## 誤解1｜柔軟精能讓毛巾變乾淨

**柔軟精沒有去污能力。** 因為它會**降低吸水性、妨礙污垢被去除**，毛巾的使用標準是**每洗幾次用一回**。

## 誤解2｜多放洗衣精就能去掉異味

**洗衣精放太多，過水後會留下殘渣，反而更糟**。**原因是殘留下來的細菌**，答案是**高溫、漂白與乾燥**。

## 誤解3｜半乾臭只要毛巾乾了就會消失

**細菌留在乾毛巾裡，一沾水就又會發出氣味。** 請用**氧系漂白劑浸泡（40–50°C，30 分鐘到 1 小時）或 60°C 的洗滌**，讓毛巾重新歸零。

## 誤解4｜毛巾可以和其他衣物一起洗

**毛巾帶有大量皮脂與皮屑，可能把細菌傳給其他衣物**。**把毛巾單獨歸在一起用熱水洗**，是在日本生活的人們之間廣泛流傳的做法。

## 誤解5｜蓬鬆感回不來，毛巾就報廢了

通常是**絨圈被壓平，或洗衣精殘留在纖維裡**。只要**多加一次過水、晾之前抖一抖，或放進烘衣機短暫烘一下**，往往就能恢復。**毛巾不再吸水時，才是它的壽命終點**。
