# Q. 制服・学生服の手入れについて、よくある誤解は？｜世界の質問箱 #352

- 棚：`fashion` ／ URL：`/questions/washing-school-uniforms` ／ ステータス：**ドラフト（法務レビュー前・出典未検証）**

日本では中高生の大半が制服を着て、家庭が3〜6年間手入れをします。「洗えるのか」「毎日同じでよいのか」という質問は、子どもを持つ外国人の家庭から特に多く寄せられます。

## A. 最大の誤解は「制服はクリーニング専用で家では洗えない」です。近年の学生服の多くはポリエステル混で、洗濯表示に洗濯機記号があれば家庭で洗えます。要点は「表示の確認」「ネットと弱水流」「形を整えて干す」「テカリ対策」で、シーズンごとのクリーニングと日常のブラッシング・陰干しを組み合わせます。

## 手入れの目安

| 項目 | 内容 |
|---|---|
| 素材 | 現在の学生服は**ポリエステル主体（5割〜全量、ウール混あり）**が主流。**家庭洗濯可の表示（ウォッシャブル）**が多い |
| 洗う頻度 | **シャツ・ブラウス・ポロシャツは毎日**、**ズボン・スカートは週1回程度、ブレザーは月1回〜シーズンに数回** |
| 洗い方 | **表示に従い、ネット、弱水流、中性洗剤**。**プリーツスカートはプリーツに沿って畳んでネット** |
| 干し方 | **ブレザーは厚みのあるハンガー、ズボンは裾を挟んで吊るす、スカートはウエストを挟んで** |
| 日常 | **帰宅後にブラシと陰干し**（スーツと同じ）。**シャツの襟・袖は予洗い** |
| テカリ | **座る部分（お尻・ひじ）**。**スチームを浮かせてブラシで起こす** |
| クリーニング | **シーズン終わり（衣替え）**。**汗抜き**を頼む |
| サイズ | **成長期は年1回サイズ確認**。**袖と裾の縫い込み（あらかじめ長く仕立ててある）を出す** |

- 学生服も**家庭用品品質表示法**の対象で、**素材と洗濯表示**が付いています。**「ウォッシャブル」**表示の製品は洗濯機で洗えます。
- **ワイシャツの襟・袖の黄ばみ**（黄ばみの記事を参照）と**制汗剤の付着**（脇の黄ばみの記事を参照）は、成長期の子どもで特に出やすい。
- **学生服の価格は上下で3〜5万円**が一般的で、**3年間の手入れが家計に直結**します。**リユース（制服バンク・卒業生からの譲渡）**も広がっています。

> 【要検証】素材の傾向と価格は学生服メーカー・全国学校用品協会の資料、記号は消費者庁「洗濯表示」で確認してください。

## 誤解1｜制服は家で洗えない

**表示に洗濯機記号があれば洗えます。** 現在の学生服の多くはポリエステル混で、**ウォッシャブル**が主流。**ブレザーも表示次第で洗濯機可**。

## 誤解2｜毎日同じズボン・スカートで問題ない

**連日着ると膝・お尻が伸び、テカリと汗のにおい**。**2着あればローテーション**、1着なら**帰宅後にブラシと陰干し**。

## 誤解3｜プリーツスカートは洗うとプリーツが消える

**ポリエステルのプリーツは熱で固定されており、表示どおりに洗えば残ります。** **プリーツに沿って畳んでネット、脱水は短く、ウエストを挟んで吊るす**。**アイロンは低温で当て布**。

## 誤解4｜テカリは洗えば取れる

**テカリは繊維が押しつぶされた状態**で、洗濯では戻りません。**スチームを浮かせて当て、ブラシで起こす**。**予防はローテーションと座り方**。

## 誤解5｜制服は買い替えるしかない

**縫い込みを出す（袖・裾）**、**ウエストの調整**は多くの制服に想定されています。**制服リユース**も学校・自治体・保護者会で広がっています。
