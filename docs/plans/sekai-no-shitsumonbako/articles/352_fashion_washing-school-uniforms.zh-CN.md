# Q. 关于日本校服的保养，人们常有什么误解？｜Japan Questions #352

- Shelf: `fashion` ／ URL: `/zh-cn/fashion/washing-school-uniforms` ／ Status: **草稿 — 出处未核实**

日本大多数初中生和高中生都穿校服，一套校服要由家庭照料三到六年。“能在家洗吗？”“每天穿同一套没问题吗？”——这是我们从在日本上学的外国家庭那里听得特别多的问题。

## A. 最大的误解是“校服只能干洗，不能在家洗”。近年的校服大多是涤纶混纺，只要洗涤标签上有洗衣机符号，就可以在家洗。要点是：确认标签；使用洗衣袋和轻柔模式；晾之前整理版型；处理磨亮的部位。每季结束时干洗一次，再配合日常的刷理和阴干。

## 保养指南

| 项目 | 内容 |
|---|---|
| 面料 | 如今的校服**以涤纶为主（从 50% 到全涤纶，也有混羊毛的）**。大多带有**允许家庭洗涤的“可水洗”标签** |
| 洗涤频率 | **衬衫、女式衬衫和 Polo 衫每天洗**；**裤子和裙子约一周一次；西装外套一个月到一季几次** |
| 洗涤方法 | **遵循标签：洗衣袋、轻柔模式、中性（中性）洗涤剂**。**百褶裙先顺着褶子折好再放进洗衣袋** |
| 晾晒方式 | **西装外套用厚衣架；裤子夹住裤脚倒挂；裙子夹住腰头** |
| 日常保养 | **放学后刷理并阴干**（和西装一样）。**衬衫的领口和袖口先做预洗** |
| 磨亮的部位 | **孩子坐下时受力的地方（臀部和手肘）**。**用蒸汽熨斗悬在布料上方，再用刷子把纤维刷起来** |
| 干洗 | **在换季时（衣替え，换季整理）**。可要求做**去汗处理（汗抜き，ase-nuki）** |
| 尺码 | **孩子长身体期间，每年确认一次尺码**。**放长袖子和裤脚——校服在缝制时就多留了布料** |

- 校服适用**《家庭用品质量标示法》（日本的标示法规）**，因此带有**纤维成分标签和洗涤标签**。标注**“可水洗”（ウォッシャブル）**的产品可以用洗衣机洗。
- **衬衫领口和袖口发黄**（参见关于发黄的文章）和**止汗剂的堆积**（参见关于腋下发黄的文章），在成长期的孩子身上尤其常见。
- **一套校服的上衣加裤子或裙子通常合计 ¥30,000–50,000**，因此**三年的保养会直接影响家庭开支**。**再利用（校服银行、毕业生转让）**正在普及。

## 误解1｜校服不能在家洗

**只要标签上有洗衣机符号就可以。** 现在的校服大多是涤纶混纺，**可水洗**是常态。**即使是西装外套，视标签而定也可能可以机洗**。

## 误解2｜每天穿同一条裤子或裙子没问题

**天天穿，膝盖和臀部会被撑松、磨亮，还会沾上汗味**。**有两条就轮换着穿**；只有一条时，**放学后刷理并阴干**。

## 误解3｜百褶裙一洗褶子就没了

**涤纶的褶子是热定型的，按标签洗就不会消失。** **顺着褶子折好放进洗衣袋，短时间脱水，夹住腰头晾起来**。**熨烫时用低温并垫上烫布**。

## 误解4｜磨亮的部位洗一洗就好了

**磨亮是纤维被压平了**，洗涤无法复原。**用蒸汽熨斗悬在上方，再用刷子把纤维刷起来**。**预防的办法是轮换和注意孩子坐姿**。

## 误解5｜唯一的办法是买新校服

**放长袖子和裤脚**、**调整腰围**，大多数校服在设计上就预留了余地。**校服再利用**正通过学校、地方政府和家长会推广开来。
