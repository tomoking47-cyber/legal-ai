# Q. 關於日本制服的保養，人們常有什麼誤解？｜Japan Questions #352

- Shelf: `fashion` ／ URL: `/zh-tw/fashion/washing-school-uniforms` ／ Status: **草稿 — 出處未核實**

日本大多數國中生與高中生都穿制服，一套制服要由家庭照料三到六年。「可以在家洗嗎？」「每天穿同一套沒問題嗎？」——這是我們從在日本上學的外國家庭那裡聽得特別多的問題。

## A. 最大的誤解是「制服只能乾洗，不能在家洗」。近年的制服大多是聚酯纖維混紡，只要洗滌標籤上有洗衣機符號，就可以在家洗。重點是：確認標籤；使用洗衣袋與輕柔行程；晾之前整理版型；處理磨亮的部位。每季結束時乾洗一次，再搭配日常的刷理與陰乾。

## 保養指南

| 項目 | 內容 |
|---|---|
| 布料 | 現在的制服**以聚酯纖維為主（從 50% 到全聚酯，也有混羊毛的）**。大多附有**允許家庭洗滌的「可水洗」標籤** |
| 洗滌頻率 | **襯衫、女用襯衫與 Polo 衫每天洗**；**長褲與裙子約一週一次；西裝外套一個月到一季幾次** |
| 洗滌方式 | **依照標籤：洗衣袋、輕柔行程、中性（中性）洗劑**。**百褶裙先順著褶子折好再放進洗衣袋** |
| 晾曬方式 | **西裝外套用厚衣架；長褲夾住褲腳倒掛；裙子夾住腰頭** |
| 日常保養 | **放學後刷理並陰乾**（與西裝相同）。**襯衫的領口與袖口先做預洗** |
| 磨亮的部位 | **孩子坐下時受力的地方（臀部與手肘）**。**用蒸氣熨斗懸在布料上方，再用刷子把纖維刷起來** |
| 乾洗 | **在換季時（衣替え，換季整理）**。可要求做**去汗處理（汗抜き，ase-nuki）** |
| 尺寸 | **孩子長身體期間，每年確認一次尺寸**。**放長袖子與褲腳——制服在縫製時就多留了布料** |

- 制服適用**《家庭用品品質標示法》（日本的標示法規）**，因此附有**纖維成分標籤與洗滌標籤**。標示**「可水洗」（ウォッシャブル）**的產品可以用洗衣機洗。
- **襯衫領口與袖口發黃**（請參閱關於發黃的文章）與**止汗劑的堆積**（請參閱關於腋下發黃的文章），在成長期的孩子身上特別常見。
- **一套制服的上衣加長褲或裙子通常合計 ¥30,000–50,000**，因此**三年的保養會直接影響家庭開支**。**再利用（制服銀行、畢業生轉讓）**正在普及。

> **[待核實]** 布料趨勢與價格請對照制服廠商與全國學校用品相關團體核對；符號請對照消費者廳「洗濯表示」頁面核對。

## 誤解1｜制服不能在家洗

**只要標籤上有洗衣機符號就可以。** 現在的制服大多是聚酯纖維混紡，**可水洗**是常態。**即使是西裝外套，視標籤而定也可能可以機洗**。

## 誤解2｜每天穿同一條長褲或裙子沒問題

**天天穿，膝蓋與臀部會被撐鬆、磨亮，還會沾上汗味**。**有兩條就輪流穿**；只有一條時，**放學後刷理並陰乾**。

## 誤解3｜百褶裙一洗褶子就沒了

**聚酯纖維的褶子是熱定型的，依標籤洗就不會消失。** **順著褶子折好放進洗衣袋，短時間脫水，夾住腰頭晾起來**。**熨燙時用低溫並墊上燙布**。

## 誤解4｜磨亮的部位洗一洗就好了

**磨亮是纖維被壓平了**，洗滌無法復原。**用蒸氣熨斗懸在上方，再用刷子把纖維刷起來**。**預防的方法是輪流穿與注意孩子坐姿**。

## 誤解5｜唯一的辦法是買新制服

**放長袖子與褲腳**、**調整腰圍**，大多數制服在設計上就預留了餘地。**制服再利用**正透過學校、地方政府與家長會推廣開來。
