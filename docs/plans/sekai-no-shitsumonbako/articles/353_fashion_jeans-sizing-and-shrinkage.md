# Q. ジーンズのサイズと縮みについて、よくある誤解は？｜世界の質問箱 #353

- 棚：`fashion` ／ URL：`/questions/jeans-sizing-and-shrinkage` ／ ステータス：**ドラフト（法務レビュー前・出典未検証）**

「洗ったらきつくなった」「サイズ表記がブランドで違う」は世界共通ですが、日本のデニム（岡山・広島）は世界的に知られ、生デニム（未洗い）の文化があるため、縮みの知識が特に語られます。

## A. 最大の誤解は「ジーンズは洗うと必ず1サイズ縮む」です。縮むかどうかは生地の処理で決まり、防縮加工（サンフォライズ）済みの生地は1〜3%、未処理の生デニムは初回の洗いで5〜10%縮みます。サイズはインチ表記でもブランドごとの実寸が異なるため、ウエストの実寸（cm）を測って比べることが確実です。

## 数字で見る

| 項目 | 内容 |
|---|---|
| **防縮加工（サンフォライズ）済み** | 一般的な市販ジーンズ。**洗濯での縮みは1〜3%**（ウエスト80cmで1〜2cm） |
| **未防縮（生デニム・シュリンクトゥフィット）** | **初回の洗いで縮み率5〜10%**（ウエスト・丈で**3〜8cm**）。**縮み分を見込んで大きめを買う**のが前提 |
| インチ表記 | ウエスト**W28〜W36**など＝**約71〜91cm**。ただし**ブランドの実寸はインチ表記＋2〜5cm**が普通（「表記より大きい」） |
| 伸び | **着用で1〜3cm伸びる**（綿は伸びて戻りにくい）。**ストレッチ混（ポリウレタン1〜3%）はさらに** |
| 乾燥機 | **高温乾燥は縮みが大きく、ストレッチ素材は劣化** |
| 日本の産地 | **岡山県井原・倉敷（児島）、広島県福山**——**国内デニム生地の大半**。**セルビッジ（赤耳）デニム**で知られる |

- **サンフォライズ加工**は、**あらかじめ生地を機械的に縮ませて安定させる処理**（1930年代に米国で開発）。**未加工の「シュリンクトゥフィット」**は、**購入後に濡らして体に合わせて縮ませる**買い方で、日本の愛好家の間で定着しています。
- **サイズ表記は業界の慣用で、法的な統一規格はありません**（JIS L4004は身体寸法の区分で、製品の実寸は各社）。
- **家庭用品品質表示法**で**素材の組成（綿のみ、綿98%ポリウレタン2%など）と洗濯表示**は必須。**「防縮」の表示義務はない**ため、店員に確認するか、**タグの「洗濯で縮む場合があります」の注記**を見ます。

> 【要検証】縮み率は繊維業界・デニムメーカーの一般的な数値です。産地の情報は岡山県・広島県の産業資料で確認してください。

## 誤解1｜ジーンズは全部洗うと縮む

**防縮加工済みは1〜3%**で、着用で戻る範囲。**生デニムは5〜10%**で、買うときに見込む。**タグとブランドの説明**で確認。

## 誤解2｜W30なら実寸76cm

**インチ表記より2〜5cm大きい実寸**が普通で、**ブランドで異なります**。**手持ちのジーンズのウエストを平置きで測り（×2）**、そのcm数で比べる。

## 誤解3｜ぴったりを買えば伸びない

**綿は着用で1〜3cm伸び、戻りにくい**。**少しきつめが数日でなじむ**というのがデニムの慣用。**ストレッチ混は伸びやすく戻りやすい**。

## 誤解4｜縮んだら乾燥機で伸ばせる

**乾燥機は縮みを進めます。** **濡らして履く・引っ張りながら干す**で数cmは戻ることがある（**生デニムの縮みは戻らない**）。

## 誤解5｜日本製デニムは特別に縮む

**生地の処理の違い**で、**セルビッジの生デニムは未防縮が多い**ため縮みます。**サンフォライズ済みの日本製**なら他と同じ。**「ワンウォッシュ」表記**は一度洗って縮ませてある製品。
