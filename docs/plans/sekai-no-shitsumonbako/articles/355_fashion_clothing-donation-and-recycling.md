# Q. 古着の回収とリサイクルについて、よくある誤解は？｜世界の質問箱 #355

- 棚：`fashion` ／ URL：`/questions/clothing-donation-and-recycling` ／ ステータス：**ドラフト（法務レビュー前・出典未検証）**

日本では年間約48万トンの衣類が家庭から廃棄され、その大半が燃やされています。「古着はリサイクルされる」という認識と実態の差、そして家庭でできる出し方を、環境省の資料から整理します。

## A. 最大の誤解は「古着を回収に出せばリサイクルされる」です。環境省の推計では、手放される衣類の約6割が可燃ごみとして廃棄され、リユース・リサイクルは約3割、繊維から繊維への再生はごくわずかです。長く着る・リユースに出す・回収拠点を使う、の順が現実的で、自治体の分別ルールが最初の確認事項です。

## 数字で見る（環境省「サステナブルファッション」）

| 項目 | 数値 |
|---|---|
| 国内の衣類供給量 | **約80万トン／年** |
| 家庭から手放される衣類 | **約75万トン／年** |
| うち**可燃・不燃ごみとして廃棄** | **約48万トン（約64%）** |
| うち**リユース**（古着として再利用） | **約20万トン（約27%）** |
| うち**リサイクル**（ウエス・反毛など） | **約7万トン（約9%）** |
| **繊維から繊維への再生** | **1%未満** |
| 1人あたり年間購入 | **約18枚**、手放す**約15枚**、**着用されない服 約35枚**（平均） |
| 1着の平均着用年数 | **約3年** |

### 出し方

| 方法 | 内容 | 注意 |
|---|---|---|
| **自治体の資源回収（古布）** | **多くの自治体で「古布・古着」を資源回収**。**洗って乾かし、透明袋**。**雨の日は出さない** | **汚れ・破れ・下着・靴下・濡れたもの**は対象外の自治体が多い |
| **店頭回収** | アパレル各社・ショッピングセンターの回収ボックス | **自社製品限定**のことがある |
| **リユース（古着屋・フリマ）** | 状態のよいもの | — |
| **ウエス・反毛** | 資源回収のうちリユース不可のものが、**工業用ぞうきん（ウエス）や中綿**に | — |

> 【要検証】数値は環境省「サステナブルファッション」（2020〜2022年の調査に基づく推計）で最新値を確認してください。分別ルールはお住まいの自治体で確認してください。

## 誤解1｜回収に出せばリサイクルされる

**約6割は燃やされ、繊維から繊維への再生は1%未満**。**リユース（誰かが着る）**が最も価値の高い出し方。

## 誤解2｜古着回収に何でも入れてよい

**汚れ・破れ・濡れたもの・下着・靴下**は多くの自治体で対象外（ごみ）。**洗って乾かして**が前提。**雨の日に出すと全体がごみになる**。

## 誤解3｜捨てるより寄付が常にいい

**海外への古着輸出は、現地の繊維産業や廃棄の問題**と結びついていると指摘されています。**国内のリユース・回収拠点**を優先。

## 誤解4｜ファストファッションだけが問題

**1人年間18枚買い、35枚を着ていない**という平均は、**買い方と着用年数の問題**。**「1着を長く」**が環境省の第一のメッセージ。

## 誤解5｜個人でできることは小さい

**長く着る（手入れ・修理）、リユースに出す、着ないものを買わない**——環境省の推計では、**着用年数を1年延ばすだけで廃棄量が数万トン減る**とされます。この記事群の手入れの知恵は、そのためのものです。
