# Q. 일본 옷의 사이즈 표시에 대해 사람들이 가장 많이 오해하는 것은?｜Japan Questions #356

- Shelf: `fashion` ／ URL: `/ko/fashion/clothing-size-labels-japan` ／ Status: **초안 — 출처 미확인**

"일본의 M은 서양의 S보다 작다"는 것은 방일 외국인이 흔히 하는 불평입니다. 일본 소비자들도 헷갈리기는 마찬가지입니다. 같은 매대에 「9号」와 「M」과 「38」이 나란히 붙어 있기 때문입니다. 이 글에서는 JIS 규격이 어떻게 작동하는지, 그리고 실측 치수로 고르는 방법을 설명합니다.

## A. 가장 큰 오해는 "사이즈 표시(S/M/L, 9号, 38)는 하나의 공통 기준을 따르며 어느 브랜드에서나 같은 뜻이다"라는 생각입니다. 일본의 JIS 규격이 정하는 것은 인체 치수의 범위이고, 옷의 실제 치수(여유분)는 브랜드가 정하기 때문에 같은 M이라도 몇 센티미터씩 차이가 납니다. 믿을 수 있는 방법은 택이나 웹사이트에 적힌 「실측 치수」(총장, 가슴단면, 어깨너비, 허리둘레를 평평하게 놓고 잰 수치)를 이미 가지고 있는 옷과 비교하는 것입니다.

## 일본의 사이즈 표시가 작동하는 방식

| 표시 | 의미 | 근거 |
|---|---|---|
| **S / M / L / LL** | **JIS L4004와 L4005가 정한 인체 치수의 범위**(예: 여성복 M＝가슴둘레 79–87 cm, 키 154–162 cm) | JIS(임의 규격) |
| **7号 / 9号 / 11号 / 13号**(여성복) | JIS의 단수 표시 호수. **9号＝가슴둘레 83 cm, 엉덩이둘레 91 cm**, **R＝키 158 cm**(표기 예 「9R」). **2023년 3월 개정된 JIS L4005에서는 A·AB·B·Y 체형 구분이 폐지**되었습니다 | JIS L4005:2023 |
| **A / Y / AB / B 체형**(남성 정장) | **가슴둘레와 허리둘레의 차이**로 나눈 체형. **A＝12 cm 차이(표준), Y＝16 cm(슬림), AB＝10 cm, B＝8 cm, BB＝6 cm**. **2023년 3월 개정된 JIS L4004에서는 체형 구분 표시 자체가 폐지**되어, 지금은 업계 관행으로 남아 있는 표기입니다 | 구 JIS L4004:2001(현행은 JIS L4004:2023) |
| **36 / 38 / 40**(여성복) | 브랜드가 자체적으로 쓰는 표시로 **프랑스식 체계를 빌려온 것**. **JIS가 아닙니다** | 각 브랜드의 자체 표시 |
| **실측 치수**(총장, 가슴단면, 어깨너비, 소매길이) | **옷을 평평하게 놓고 잰 수치**. **가장 믿을 수 있는 기준** | 제조사별 자체 표시 |
| **법적 의무** | 「家庭用品品質表示法」(가정용품 품질표시법, 일본의 표시 관련 법)상 **사이즈는 의무 표시 항목이 아닙니다**(의무는 섬유 조성, 취급 표시, 표시자 이름) | 소비자청 |

- **JIS가 분류하는 것은 인체 치수**이고, **옷의 실제 치수(여유분)는 브랜드마다의 설계**입니다. **넉넉하게 만드는 브랜드의 S와 슬림한 브랜드의 M**이 같은 치수로 나오는 일은 흔합니다.
- **온라인 구매의 반품**에 대해, 일본의 **쿨링오프 규정은 통신판매에 적용되지 않으며 반품 조건은 판매자별 반품 특약으로 정해집니다**. **반품 특약이 표시되어 있지 않은 경우에 한해, 상품이 도착한 날을 포함해 8일 이내에 법적으로 반품할 수 있습니다**(반송료는 소비자 부담). **실측 치수로 사는 것**이 반품의 수고를 덜어 줍니다.
- 외국인용 사이즈 환산표는 **대략적인 참고일 뿐입니다**(영문판 사이즈 관련 글 참조).

> **[확인 필요]** JIS의 범위 수치는 일본규격협회의 JIS L4004／L4005에서 확인하십시오. 반품 약관에 관한 내용은 소비자청의 통신판매 자료를 근거로 합니다.

## 오해 1｜M은 어느 브랜드에서나 같다

**M은 인체 치수의 범위이고, 옷의 실제 치수는 브랜드가 정합니다.** **실측 치수(가슴단면, 총장)**를 비교하십시오.

## 오해 2｜9号는 "체구가 작은 사람용"이다

**9号는 일본 여성의 평균 체형(가슴둘레 83 cm)을 기준으로 한 "표준 사이즈"입니다**. 7号는 더 작고 11号는 더 큽니다.

## 오해 3｜38은 일본의 사이즈다

브랜드가 자체적으로 쓰는 표시로 **프랑스식 체계를 빌려온 것**이며 **JIS 규격이 아닙니다**. 해당 브랜드의 환산표를 확인하십시오.

## 오해 4｜온라인에서 산 옷은 맞지 않으면 반품할 수 있다

**통신판매에는 쿨링오프가 없고, 반품 가능 여부는 판매자별 약관(반품 특약)에 달려 있습니다**. 다만 **광고나 최종 주문 화면에 반품 특약이 표시되어 있지 않은 경우에는, 상품을 받은 날을 포함해 8일 이내라면 반품할 수 있습니다**(반송료는 소비자 부담). **입어 보았거나 택을 떼어 낸** 물건은 받지 않는 가게가 많습니다. **사기 전에 실측 치수와 반품 조건을 확인하십시오**.

## 오해 5｜사이즈 표시는 법으로 정해진 의무다

**「家庭用品品質表示法」상 사이즈는 의무 항목이 아닙니다**(의무는 섬유 조성, 취급 표시, 표시자). **사이즈가 아예 없는 제품도 있습니다**. **직접 재어 실측으로 고르십시오**.
