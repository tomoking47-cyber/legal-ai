# Q. 日本の衣類のサイズ表示について、よくある誤解は？｜世界の質問箱 #356

- 棚：`fashion` ／ URL：`/questions/clothing-size-labels-japan` ／ ステータス：**ドラフト（法務レビュー前・出典未検証）**

「日本のMは海外のSより小さい」は訪日客の定番の悩みですが、日本人自身も「9号」「Mサイズ」「38」が混在するサイズ表示に混乱しています。JIS規格の仕組みと、実寸で選ぶ方法を整理します。

## A. 最大の誤解は「サイズ表記（S/M/L、9号、38）は共通の規格で、どのブランドでも同じ」です。日本のJISは身体寸法の区分を定めていますが、製品の実寸（ゆとり）はブランドが決めるため、同じMでも数cm違います。確実なのは、タグやサイトの「実寸（着丈・身幅・肩幅・ウエストの平置き寸法）」で、手持ちの服の実寸と比べることです。

## 日本のサイズ表示の仕組み

| 表示 | 何を表すか | 根拠 |
|---|---|---|
| **S / M / L / LL** | **JIS L4004・L4005で定める身体寸法の区分**（例：女子M＝バスト79〜87cm、身長154〜162cm） | JIS（任意規格） |
| **7号・9号・11号・13号**（女性） | JISの単数表示の号数。**9号＝バスト83cm、ヒップ91cm**、**R＝身長158cm**（表記例「9R」）。**2023年3月改正のJIS L4005ではA・AB・B・Y体型の体型区分は廃止**された | JIS L4005:2023 |
| **A / Y / AB / B体**（男性スーツ） | **胸囲とウエストの差**で体型区分。**A体＝差12cm（標準）、Y体＝差16cm（細身）、AB体＝差10cm、B体＝差8cm、BB体＝差6cm**。**2023年3月改正のJIS L4004では体型区分表示そのものが廃止**され、現在は業界慣行として残る表記 | 旧JIS L4004:2001（現行はJIS L4004:2023） |
| **36 / 38 / 40**（レディース） | **フランス式の表示を流用**したブランド表記。**JISではない** | 各社の表示 |
| **実寸（着丈・身幅・肩幅・袖丈）** | **製品の平置きの寸法**。**最も確実** | 各社の表示 |
| **表示義務** | 家庭用品品質表示法では**サイズは義務ではない**（素材・洗濯表示・表示者が義務） | 消費者庁 |

- **JISは「体のサイズの区分」**であり、**服の実寸（ゆとり）は各ブランドの設計**。**ゆったりめのブランドのSと、細身のブランドのM**が同じ実寸のことは普通です。
- **オンライン購入の返品**は、日本では**通信販売にクーリングオフの適用がなく、返品条件は各社の返品特約**によります。**返品特約の表示がない場合に限り、商品到着日を含む8日以内の返品が法律上できます**（返送料は消費者負担）。**実寸を見て買う**ことが返品の手間を減らします。
- 訪日客向けの換算表は**目安**（サイズの記事・英語版を参照）。

> 【要検証】JISの区分値は日本規格協会のJIS L4004/L4005で確認してください。返品規約の扱いは消費者庁「通信販売」の資料に基づきます。

## 誤解1｜Mはどのブランドでも同じ

**Mは体の寸法区分で、服の実寸はブランドが決めます。** **実寸（身幅・着丈）**で比べる。

## 誤解2｜9号は「小さい人用」

**9号は日本の女性の標準体型（バスト83cm）を基準にした「標準サイズ」**です。7号が小さめ、11号が大きめ。

## 誤解3｜38は日本のサイズ

**フランス式の表記を流用**したブランド表示で、**JISの規格ではありません**。ブランドの換算表を見る。

## 誤解4｜ネット通販は合わなければ返品できる

**通信販売にクーリングオフはなく、返品は各社の規約（返品特約）次第**。ただし**広告や最終申込み画面に返品特約の表示がない場合は、商品を受け取った日を含む8日以内なら返品できます**（返送料は消費者負担）。**試着済み・タグを外した**ものは受け付けない店が多い。**購入前に実寸と返品条件**を確認。

## 誤解5｜サイズ表示は法律で義務

**家庭用品品質表示法でサイズは義務ではありません**（素材・洗濯表示・表示者が義務）。**サイズ表記のない製品**もあります。**実寸を測って選ぶ**。
