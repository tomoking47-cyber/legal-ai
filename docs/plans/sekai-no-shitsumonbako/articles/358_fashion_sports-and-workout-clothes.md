# Q. スポーツウェアの洗濯とにおいについて、よくある誤解は？｜世界の質問箱 #358

- 棚：`fashion` ／ URL：`/questions/sports-and-workout-clothes` ／ ステータス：**ドラフト（法務レビュー前・出典未検証）**

ランニングやジムの普及で、ポリエステルのスポーツウェアが「洗ってもにおう」という悩みが世界中で共有されています。素材の性質と、におい菌の知見から対策を整理します。

## A. 最大の誤解は「スポーツウェアは速乾素材だからにおいも残らない」です。ポリエステルは水を吸わない一方で皮脂（油）を吸着しやすく、そこに菌が増えてにおいが定着します。対策は「脱いだらすぐ洗う（放置しない）」「柔軟剤を使わない」「40℃前後のぬるま湯と、酸素系漂白剤か専用洗剤」「裏返して洗う」です。

## 判断の材料

| 項目 | 内容 |
|---|---|
| なぜにおう | **ポリエステルは疎水性で、皮脂（油）を吸着しやすい**。**綿は皮脂を水と一緒に離しやすい**が、ポリエステルは残る。残った皮脂を**菌が分解してにおい** |
| 放置 | **汗で濡れたウェアを袋やかごに数時間**が最も増える条件。**帰宅後すぐ洗う**、できなければ**広げて乾かす** |
| 洗剤 | **弱アルカリ性の液体洗剤または「スポーツウェア用」**（皮脂分解力）。**柔軟剤は不可**（コーティングで吸水性・吸着が悪化、においを閉じ込める） |
| 温度 | **40℃前後**（表示を確認。**ポリウレタン混は30℃以下**の表示が多い） |
| つけ置き | **酸素系漂白剤（液体）を溶かしたぬるま湯に30分**。**塩素系は不可**（色落ち・素材劣化） |
| 裏返す | **皮脂は内側に付く**。**裏返してネット** |
| 乾燥 | **速乾なので陰干しで数時間**。**乾燥機は伸縮素材を傷める**（表示を確認） |
| 消臭加工 | **「抗菌防臭」加工は洗濯で徐々に落ちる**（表示に洗濯回数の目安がある製品も） |

- **生乾き臭の主因はモラクセラ菌**とされる一方、**汗をかいた後のウェアの「着用汗臭」の主な原因菌はマイクロコッカス属細菌**で、においの成分は短鎖・中鎖の脂肪酸であることが、洗剤メーカーの研究で示されています（タオルの記事を参照）。
- **ポリウレタン混（ストレッチ）**は**熱と塩素で劣化**するため、**高温乾燥・塩素系漂白剤は不可**（水着の記事と同じ）。
- **重曹**（弱アルカリ）のつけ置きも皮脂に効きますが、**酸素系漂白剤のほうが菌にも働く**とされます。

> 【要検証】ポリエステルの皮脂吸着と菌の関係は繊維学・洗剤メーカーの研究に基づきます。記号は消費者庁「洗濯表示」で確認してください。

## 誤解1｜速乾素材はにおわない

**水は乾いても皮脂は残り、そこに菌が増えます。** **皮脂を落とす洗い方**が要点。

## 誤解2｜柔軟剤で嫌なにおいを香りでカバー

**柔軟剤は繊維をコーティングし、皮脂とにおいを閉じ込めます。** **スポーツウェアには使わない**が、メーカーの一般的な案内。

## 誤解3｜洗濯機に入れるまで袋に入れておく

**濡れた密閉は菌の増殖条件**。**帰宅後すぐ洗う**か、**広げて乾かしてから**洗濯かごへ。

## 誤解4｜熱いお湯で洗えば菌も皮脂も落ちる

**ポリウレタン混は30℃以下、ポリエステルでも40℃程度**が表示の上限のことが多く、**高温は伸縮性の劣化**。**表示の温度で、酸素系漂白剤を併用**。

## 誤解5｜においが取れなくなったら寿命

**酸素系漂白剤のつけ置きで多くはリセット**できます。**それでも戻るなら、繊維の奥に皮脂と菌が定着**しており、買い替えの目安。**予防（すぐ洗う・柔軟剤なし）**が最も効きます。
