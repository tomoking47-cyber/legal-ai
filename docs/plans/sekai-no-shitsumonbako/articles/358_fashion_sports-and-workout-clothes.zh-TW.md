# Q. 關於運動服的清洗和異味，人們最容易搞錯什麼？｜Japan Questions #358

- Shelf: `fashion` ／ URL: `/zh-tw/fashion/sports-and-workout-clothes` ／ Status: **草稿 — 出處未核實**

隨著跑步與上健身房的普及，「聚酯纖維的運動服洗過還是有味道」成了全世界共同的抱怨。本文從纖維本身的性質，以及關於異味來源細菌的已知資訊出發，來梳理解決的辦法。

## A. 最大的誤解是「運動服是快乾的，味道不會殘留」。聚酯纖維不吸水，卻很容易留住皮脂，細菌在這些皮脂上繁殖，氣味便固著在布料裡。解決的辦法是：脫下來就馬上洗（不要放著）；不用柔軟精；用 40℃ 左右的溫水加氧系漂白劑或運動服專用洗衣精；並且把衣服翻面來洗。

## 判斷的依據

| 項目 | 內容 |
|---|---|
| 為什麼會有味道 | **聚酯纖維不親水，卻很容易留住皮脂**。**棉會把皮脂隨水一起釋出**，聚酯纖維則留著它。**細菌分解殘留的皮脂，產生氣味** |
| 放著不洗 | **浸滿汗水的運動服在包包或洗衣籃裡放上幾個小時**，正是細菌繁殖的理想條件。**回到家就馬上洗**；做不到的話，**先攤開晾乾** |
| 洗衣精 | **弱鹼性的液體洗衣精或「運動服專用」洗衣精**（能分解皮脂）。**不要用柔軟精**（其包覆膜會降低吸水性、加重皮脂堆積，還會把氣味封在裡面） |
| 溫度 | **40℃（104°F）左右**（請看標示；**含聚氨酯／彈性纖維的混紡常標示 30℃ 以下**） |
| 浸泡 | **在溫水中溶入液體氧系漂白劑「酸素系漂白剤」（氧系漂白劑，sanso-kei hyōhakuzai），浸泡 30 分鐘**。**不要用氯系漂白劑**（褪色、損傷纖維） |
| 翻面洗 | **皮脂在內側**。**把衣服翻面，裝進洗衣袋** |
| 晾乾 | **快乾，在陰涼處晾幾個小時就夠了**。**滾筒式烘乾機會傷到彈性布料**（請看標示） |
| 防臭加工 | **「抗菌防臭」加工會隨著洗滌逐漸減弱**（有些標示會列出大致可洗的次數） |

- **室內晾乾的異味主要歸因於莫拉氏菌（*Moraxella*）**，而洗劑廠商的研究顯示，**流汗後穿著衣物產生的「著用汗臭」，主要原因菌是微球菌屬（*Micrococcus*）細菌**，氣味成分為短鏈與中鏈脂肪酸（請參閱關於毛巾的文章）。
- **含聚氨酯（彈性纖維）的混紡**會**因熱與氯而劣化**，所以**不要高溫烘乾，也不要用氯系漂白劑**（與泳衣相同，請參閱該篇文章）。
- **用小蘇打「重曹」（jūsō，弱鹼性）浸泡**對皮脂也有作用，不過**一般認為氧系漂白劑還能同時作用於細菌**。

> **[待核實]** 聚酯纖維留住皮脂與細菌之間的關聯，依據的是紡織科學與洗劑廠商的研究。洗滌標示符號請對照消費者廳的「洗濯表示」頁面核實。

## 誤解1｜快乾布料不會有味道

**水分乾了，皮脂卻留了下來，細菌就在上面繁殖。** 關鍵是**能洗掉皮脂的洗法**。

## 誤解2｜用柔軟精的香味把氣味蓋掉

**柔軟精會包覆纖維，把皮脂和氣味封在裡面。** **「請勿用於運動服」**是廠商通常的說明。

## 誤解3｜洗之前先放在包包裡

**密閉又潮濕正是細菌需要的條件**。**回到家就馬上洗**，或者**先攤開晾乾**，再放進洗衣籃。

## 誤解4｜用熱水就能連細菌帶皮脂一起去掉

**標示上的上限，聚氨酯混紡往往是 30℃ 以下，即使是聚酯纖維也在 40℃ 左右**；**熱會讓彈性劣化**。**依標示的溫度洗，再加氧系漂白劑**。

## 誤解5｜味道一旦洗不掉，這件衣服就沒救了

**用氧系漂白劑浸泡大多能把狀態拉回來**。**如果味道還是一再出現**，表示皮脂和細菌已經固著在纖維深處，那就該換新的了。**預防（馬上洗、不用柔軟精）**效果最好。
