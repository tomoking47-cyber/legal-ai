# Q. 炭酸水について、よくある誤解は？｜世界の質問箱 #361

- 棚：`health` ／ URL：`/questions/sparkling-water` ／ ステータス：**ドラフト（法務レビュー前・出典未検証）**

無糖の炭酸水は日本で2010年代に市場が急拡大し、「水の代わりに飲んでよいか」「骨や歯に悪いのか」という質問が増えました。海外でも同じ疑問があり、公的な資料で言えることを整理します。

## A. 最大の誤解は「炭酸水は骨を溶かす・歯を溶かす」です。無糖の炭酸水（水と二酸化炭素のみ）の酸性度は弱く、骨への影響を示す根拠は確認されていません。歯への影響も、糖や酸味料を含む炭酸飲料と比べればごく小さいとされます。注意点は「糖入り・酸味料入りの製品と区別する」「食前の大量摂取は満腹感で食事量に影響する」ことです。

## 判断の材料

| 項目 | 内容 |
|---|---|
| 無糖炭酸水のpH | **約4.5〜5.5**（弱酸性）。コーラ等は**約2.5〜3**、レモン果汁は**約2** |
| 歯への影響 | **エナメル質が溶け始めるpHは約5.5**とされる。無糖炭酸水は境界付近で、**糖・クエン酸入りの炭酸飲料とは影響の大きさが異なる**。**口に長く含まない・飲んだ後に水**で十分とする歯科の一般的な見解 |
| 骨への影響 | **炭酸そのものが骨密度を下げる根拠は確認されていない**。過去の研究でコーラの摂取と骨密度の関連が指摘されたが、**リン酸・カフェイン・牛乳の置き換え**が要因とされる |
| 水分補給 | **無糖なら水と同等**。**厚生労働省の「健康のため水を飲もう」の対象になる** |
| 胃 | 炭酸は**胃を膨らませ、一時的な満腹感**。**食前に多量は食事量が減る**、**少量は食欲を刺激する**とする研究がある（個人差） |
| 表示 | **「炭酸水」は無糖**、**「炭酸飲料」は糖・香料・酸味料を含む**ことが多い。**「レモンフレーバー」でも無糖なら炭酸水** |

- **無糖炭酸水の国内市場は2010年代に5倍以上に拡大**（飲料メーカー・業界推計）。**割り材から日常の飲み物へ**移った結果です。
- **「強炭酸」**は二酸化炭素の圧力（ガスボリューム）が高い製品で、**成分は同じ**。
- **胃食道逆流（胸やけ）**がある人は、**炭酸で症状が出やすい**ことがあり、医師に相談を。

> 【要検証】pHの数値は一般的な測定値、歯への影響は日本歯科医師会などの資料、骨への影響は栄養学の研究レビューで確認してください。

## 誤解1｜炭酸水は骨を溶かす

**二酸化炭素の炭酸に骨を溶かす作用を示す根拠は確認されていません。** 過去の研究のコーラの影響は、**リン酸・カフェイン・牛乳の代替**が要因とされます。

## 誤解2｜歯が溶ける

**無糖炭酸水のpHは弱酸性で、糖・クエン酸入りの炭酸飲料とは影響が大きく異なります。** **長時間口に含まない、寝る前は水**で十分。

## 誤解3｜水分補給には水でなければならない

**無糖なら水と同じ水分補給**になります。**カフェインもなく、常温でも**。

## 誤解4｜「フレーバー付き」なら糖が入っている

**無糖のフレーバー炭酸水**は多く、**表示の「糖類」「エネルギー」で確認**。**「炭酸飲料」は糖入りが多い**。

## 誤解5｜炭酸水は太る／痩せる

**無糖なら0kcal**で、太る要因はありません。**「痩せる」効果を示す根拠もなく**、食事量への影響は**量とタイミングで逆方向**に働きます。
