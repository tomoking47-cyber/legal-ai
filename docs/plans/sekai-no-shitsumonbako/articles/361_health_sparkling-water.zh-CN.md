# Q. 关于气泡水，人们常有哪些误解？｜Japan Questions #361

- Shelf: `health` ／ URL: `/zh-cn/health/sparkling-water` ／ Status: **草稿 — 出处未核实**

无糖气泡水（炭酸水，tansansui）在 2010 年代于日本流行起来，如今在每一家便利店和自动售货机都能见到。人们会问：它能不能代替白水？会不会伤害骨骼或牙齿？国外也有同样的疑问。以下是公开资料让我们可以说的内容。

## A. 最大的误解是「气泡水会溶解骨头和牙齿」。无糖气泡水（水加二氧化碳，别无其他）只是弱酸性，也未确认有证据表明它会影响骨骼。与含糖或含酸味剂的碳酸饮料相比，一般认为它对牙齿的影响非常小。需要留意的是两点：把它与加糖、加酸味剂的产品区分开；以及记住，餐前大量饮用会带来饱腹感，可能改变进食量。

## 需要权衡的几点

| 项目 | 内容 |
|---|---|
| 无糖气泡水的 pH | **约 4.5〜5.5**（弱酸性）。可乐等饮料**约为 2.5〜3**；柠檬汁**约为 2** |
| 牙齿 | **一般认为，牙釉质在 pH 约 5.5 时开始溶解。** 无糖气泡水处在这条界线附近，**其影响的大小与加了糖和柠檬酸的碳酸饮料不同**。牙科的一般建议是**不要长时间含在口中，喝完后再喝点水** |
| 骨骼 | **未确认有证据表明碳酸本身会降低骨密度。** 过去的研究曾把可乐的饮用量与骨密度联系起来，但被指出的因素是**磷酸、咖啡因，以及用可乐取代了牛奶** |
| 水分补给 | **只要是无糖的，就与水一样计入。** 它属于**厚生劳动省「为了健康来喝水」推进运动**（厚生労働省）所说的范围 |
| 胃 | 碳酸会**使胃扩张，带来暂时的饱腹感**。研究发现，**餐前大量饮用会减少进食量**，而**少量饮用则会刺激食欲**（因人而异） |
| 标示 | **「炭酸水」（tansansui，气泡水）是无糖的**；**「炭酸飲料」（tansan inryō，碳酸饮料）通常含有糖、香料和酸味剂**。**标着「柠檬风味」的产品，只要无糖，仍然是气泡水** |

- **日本的无糖气泡水市场在 2010 年代扩大到五倍以上**（饮料厂商与行业推算）。它**从调酒用的兑水饮料变成了日常饮品**。
- **「強炭酸」（kyō-tansan，「强碳酸」）** 指二氧化碳的压力（气容量）更高；**成分是一样的**。
- 有**胃食管反流（烧心）**的人，可能会觉得**碳酸更容易引发症状**。请咨询医生。

## 误解1｜气泡水会溶解骨头

**未确认有证据表明二氧化碳所形成的碳酸会溶解骨头。** 过去研究中看到的可乐的影响，被归因于**磷酸、咖啡因，以及用可乐取代了牛奶**。

## 误解2｜它会溶解牙齿

**无糖气泡水只是弱酸性，其影响与加了糖和柠檬酸的碳酸饮料相差很大。** **不要长时间含在口中，睡前喝点水。** 这样就够了。

## 误解3｜补水只能靠白水

**只要是无糖的，它和水一样能补充水分。** **它不含咖啡因，常温饮用也可以。**

## 误解4｜标着「风味」就含糖

**无糖的风味气泡水有很多。** **请查看营养成分标示上的「糖類」（糖类）和「エネルギー」（能量）。** **标示为「炭酸飲料」（碳酸饮料）的产品通常确实含糖。**

## 误解5｜气泡水会让人发胖／会让人变瘦

**只要是无糖的，它就是 0 kcal**，没有让人发胖的因素。**也没有证据表明它有减重效果**：它对进食量的影响**会因分量和时机而朝相反的方向起作用**。
