# Q. ハーブティーについて、よくある誤解は？｜世界の質問箱 #362

- 棚：`health` ／ URL：`/questions/herbal-teas` ／ ステータス：**ドラフト（法務レビュー前・出典未検証）**

ハーブティーは「ノンカフェインで体にやさしい」というイメージで広く飲まれていますが、日本ではハーブは「食品」「医薬品」「機能性表示食品・トクホ」に区分が分かれ、言える効能に線があります。妊娠中・服薬中の注意も含めて整理します。

## A. 最大の誤解は「ハーブは自然のものだから誰が飲んでも安全で、効能をうたえる」です。日本で食品として売られるハーブティーは、効能を表示できず（健康増進法・景表法）、一部のハーブ（セントジョーンズワート、リコリス、カモミールなど）は薬との相互作用や妊娠中の注意が知られています。「ノンカフェイン」であることと「体への作用がない」ことは別です。

## 区分と注意

| 区分 | 例 | 言えること |
|---|---|---|
| **食品（ハーブティー）** | カモミール、ルイボス、ペパーミント、ローズヒップ | **効能は表示できない**。「リラックスタイムに」など雰囲気の表現まで |
| **医薬品（生薬）** | ドクダミ茶（生薬として承認された製品）、センナ、カンゾウ（甘草） | 承認された効能。**センナは医薬品成分で食品に使えない**（茎は例外的に食品） |
| **機能性表示食品・トクホ** | 届出・許可を受けた製品のみ | 届出の範囲の機能 |

### 注意が知られている主なハーブ

| ハーブ | 注意 |
|---|---|
| **セントジョーンズワート** | **多くの薬の効果を弱める**（経口避妊薬、免疫抑制剤（シクロスポリン）、抗HIV薬（インジナビル）、ジゴキシン、テオフィリン、ワルファリンなど）。**抗うつ薬とは別にセロトニン症候群の注意**。厚生省が2000年5月に注意喚起 |
| **リコリス（甘草）** | 大量・長期で**血圧上昇・低カリウム**。**高血圧の人・服薬中は注意** |
| **カモミール** | **キク科アレルギー**（ブタクサ等）の人は反応。**妊娠中は大量を避ける**とする資料 |
| **ハイビスカス・ローズヒップ** | 酸味が強く、**歯・胃への刺激**、**血圧への影響**の報告 |
| **ミント** | **胃食道逆流**がある人は悪化することがある |
| **妊娠中一般** | **ラズベリーリーフ、ジャスミン、セージ、レモングラス等は避けるか少量**とする案内が多い。**産科医に確認** |

- **「ノンカフェイン」「カフェインゼロ」**は**カフェインを含まない**ことのみを意味し、**他の作用がないことを意味しません。**
- **国立健康・栄養研究所の「健康食品」の安全性・有効性情報**は、ハーブごとの**相互作用・注意**を公開しています。

> 【要検証】セントジョーンズワートの注意は厚生労働省の通知（2000年5月）、各ハーブの注意は国立健康・栄養研究所のデータベースで確認してください。

## 誤解1｜自然のものだから安全

**セントジョーンズワートは多くの薬の効果を弱め、リコリスは血圧に影響**します。**服薬中・妊娠中・持病がある人は医師・薬剤師に確認**。

## 誤解2｜ノンカフェインなら体に何も作用しない

**カフェインがないだけ**で、**ハーブの成分は体に作用**します（だからこそ相互作用がある）。

## 誤解3｜ハーブティーには効能がある、と言ってよい

**食品として売られるハーブティーは効能を表示できません**（健康増進法・景表法）。**「リラックス」「安眠」の断定は問題**。

## 誤解4｜妊娠中はハーブティーが最適

**避けるべきハーブ**があり、**「妊娠中OK」と書かれた製品でも産科医に確認**。**ルイボス・麦茶は一般に問題ないとされる**が、量は常識的に。

## 誤解5｜濃く・多く飲めばよく効く

**濃く長時間飲むほど、作用も相互作用も出やすくなります。** **1日1〜3杯程度**、体調の変化があればやめる。
