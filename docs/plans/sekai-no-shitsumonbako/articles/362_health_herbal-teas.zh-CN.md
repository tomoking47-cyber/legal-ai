# Q. 关于花草茶，人们常有哪些误解？｜Japan Questions #362

- Shelf: `health` ／ URL: `/zh-cn/health/herbal-teas` ／ Status: **草稿 — 出处未核实**

在日本，花草茶被广泛饮用，人们说它「不含咖啡因、对身体温和」。但在日本，一种草本只会归入三个法律类别之一：食品、药品，或医药部外品（介于化妆品与药品之间的日本特有类别）。类别决定了可以做出什么样的健康宣称。本文把这些梳理清楚，也包括孕期和正在服药者需要注意的事项。

## A. 最大的误解是「草本是天然的，所以谁都可以放心喝，宣传功效也没问题」。在日本作为食品销售的花草茶不能标示功效（依据健康增进法与景品表示法）。有些草本，例如贯叶连翘（圣约翰草）、甘草和洋甘菊，以与药物的相互作用或孕期注意事项而为人所知。「不含咖啡因」和「对身体没有作用」是两回事。

## 分类与注意事项

| 类别 | 例子 | 可以说什么 |
|---|---|---|
| **食品（花草茶）** | 洋甘菊、南非路易波士茶、胡椒薄荷、玫瑰果 | **不允许标示功效。** 只能用「为您的放松时刻」这类营造氛围的说法 |
| **药品（生药，生薬）** | 鱼腥草茶（作为生药获批的产品）、番泻叶、甘草（甘草根） | 获批的适应症。**番泻叶是药用成分，不能用于食品**（茎是例外，允许用于食品） |
| **功能性标示食品／特定保健用食品** | 仅限已备案或已获批的产品 | 备案范围内的功能 |

特定保健用食品（トクホ）是日本获批的「特定保健用途食品」制度；功能性标示食品（機能性表示食品）由厂商向消费者厅备案。

### 已知有注意事项的草本

| 草本 | 注意事项 |
|---|---|
| **贯叶连翘（圣约翰草）** | **会减弱许多药物的效果**（口服避孕药、抗抑郁药、免疫抑制剂、抗 HIV 药物等）。厚生劳动省（厚生労働省）曾于 2000 年发出提醒 |
| **甘草（甘草，kanzō）** | 大量或长期服用会**导致血压升高与低血钾**。**高血压患者或正在服药者需注意** |
| **洋甘菊** | 对**菊科过敏**（豚草等）的人可能出现反应。也有资料称**孕期应避免大量饮用** |
| **洛神花、玫瑰果** | 酸性较强，有**刺激牙齿与胃**以及**影响血压**的报告 |
| **薄荷** | 可能加重**胃食管反流** |
| **孕期总体** | 许多指导意见都说**覆盆子叶、茉莉、鼠尾草、香茅等应避免，或只可少量饮用**。**请与产科医生确认** |

- **「ノンカフェイン」（不含咖啡因）与「カフェインゼロ」（咖啡因零）** 只表示**产品中不含咖啡因**，**并不表示它没有其他作用**。
- **国立健康・营养研究所的「保健食品」安全性・有效性信息数据库**公布了**各种草本的相互作用与注意事项**。

> **[待核实]** 贯叶连翘的注意事项请对照厚生劳动省的通知（2000 年 5 月），各草本的注意事项请在国立健康・营养研究所的数据库中确认。

## 误解1｜天然的东西所以安全

**贯叶连翘会减弱许多药物的效果，甘草会影响血压。** **如果您正在服药、怀孕或有慢性疾病，请与医生或药剂师确认。**

## 误解2｜不含咖啡因就意味着对身体没有作用

**缺少的只是咖啡因而已。** **草本自身的成分会作用于身体**，正因如此才会存在相互作用。

## 误解3｜说花草茶有功效是没问题的

**作为食品销售的花草茶不能标示功效**（健康增进法；景品表示法）。**断言它能「放松」或「助眠」是有问题的。**

## 误解4｜孕期喝花草茶最合适

**有些草本应当避免。** **即使产品上写着「孕期可用」，也请与产科医生确认。** **南非路易波士茶和麦茶（麦茶，mugicha）一般被认为没有问题**，但饮用量要有分寸。

## 误解5｜泡得越浓、喝得越多越有效

**泡得越浓、喝得越久，作用与相互作用出现的可能性都越大。** **一天 1〜3 杯左右**；如果感觉身体有变化就停下来。
