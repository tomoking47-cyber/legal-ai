# Q. 深呼吸とリラックスについて、よくある誤解は？｜世界の質問箱 #363

- 棚：`health` ／ URL：`/questions/breathing-and-relaxation` ／ ステータス：**ドラフト（法務レビュー前・出典未検証）**

「深呼吸で落ち着く」は世界共通の助言で、日本では学校や職場のストレス対策にも取り入れられています。何が確かで、何が言いすぎかを、厚生労働省の資料と生理学の一般的な説明で整理します。

## A. 最大の誤解は「深呼吸で病気やストレスが解消する」です。深呼吸で確かなのは、ゆっくり長く吐くことで心拍と血圧が一時的に下がり、緊張がゆるむ感覚が得られることです。それは日常の「切り替え」の道具として有用ですが、続く不安・不眠・気分の落ち込みは医療の領域です。「腹式呼吸」「4秒吸って8秒吐く」など方法の違いより、続けられることが要点です。

## 判断の材料

| 項目 | 内容 |
|---|---|
| 仕組み | **ゆっくり吐く息が副交感神経を優位にし、心拍・血圧が一時的に下がる**。**呼吸は自律神経を意識的に動かせる唯一の入口**とされる |
| 方法の例 | **4秒吸って8秒吐く（吐く息を長く）**、**腹式呼吸（おなかがふくらむ）**、**1分間に6回程度のゆっくりした呼吸** |
| 時間 | **1〜3分**で体感の変化。**長時間や過度に深い呼吸は過換気（めまい・しびれ）**の原因 |
| 厚生労働省の位置づけ | 「こころの耳」（働く人のメンタルヘルスポータル）で**リラクセーションの方法**として呼吸法・筋弛緩法・ストレッチを紹介 |
| 限界 | **不安・不眠・抑うつが2週間以上続く、日常に支障**がある場合は**医療・相談機関**へ |
| 場面 | **会議の前、寝る前、電車の中、怒りを感じた時**——日本の生活者の間で「6秒待つ」「一呼吸」として共有 |

- **ゆっくりした呼吸（1分6回程度）が心拍変動を高め、リラックスに関わる**ことは複数の研究で示されていますが、**「病気を治す」「ストレスをなくす」効果を示すものではありません。**
- **過換気**：**速く深い呼吸を繰り返す**と血中の二酸化炭素が減り、**めまい・手のしびれ・動悸**が出ます。**「深く」より「ゆっくり、吐く息を長く」**が要点。
- **マインドフルネス・瞑想**も同じ系統の方法で、**研究では不安・ストレスの軽減に一定の効果**が示される一方、**治療の代替ではない**とされます。

> 【要検証】厚生労働省「こころの耳」のリラクセーションの記載を確認してください。生理学的な説明は一般的な記載です。

## 誤解1｜深呼吸でストレスがなくなる

**一時的に体の緊張をゆるめる**道具です。**ストレスの原因（仕事・人間関係）が変わるわけではなく、続く不調は相談・受診**。

## 誤解2｜深く大きく吸うほどよい

**「吸う」より「ゆっくり長く吐く」**が要点。**速く深い呼吸の繰り返しは過換気**で、かえってめまいや動悸が出ます。

## 誤解3｜正しい呼吸法（腹式・4-7-8など）でなければ効かない

**方法の差より、ゆっくり吐くこと・続けること**が共通の要素。**自分がやりやすい型**で。

## 誤解4｜深呼吸は気分の問題で、体には何も起きていない

**心拍・血圧が一時的に下がる**ことは測定できます。**「気の持ちよう」ではなく生理反応**。だからこそ限界もあります。

## 誤解5｜眠れないときは深呼吸を繰り返せば眠れる

**寝つきを助ける工夫の一つ**ですが、**「眠ろう」と頑張る呼吸は逆効果**なことも。**眠れなければ寝床を出る**（中途覚醒の記事を参照）。**続く不眠は医療の領域**。
