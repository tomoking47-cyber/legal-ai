# Q. 立ち仕事の疲れとむくみについて、よくある誤解は？｜世界の質問箱 #366

- 棚：`health` ／ URL：`/questions/standing-all-day` ／ ステータス：**ドラフト（法務レビュー前・出典未検証）**

販売・調理・医療・製造など立ち仕事は多く、「座り仕事より健康的」と思われがちです。長時間の立位には別の負担があり、脚のむくみ・腰痛・静脈瘤との関連が知られています。公的な資料と対策を整理します。

## A. 最大の誤解は「立っているほうが座るより常に健康的」です。座りすぎの問題は確かですが、動かずに立ち続けることも、脚の血流の停滞（むくみ・静脈瘤）、腰と足の負担につながります。要点は「同じ姿勢を続けない」で、立ち仕事では「足を動かす」「体重を左右に移す」「休憩で座る・足を上げる」「靴と床」が対策です。

## 判断の材料

| 項目 | 内容 |
|---|---|
| 立ち仕事の負担 | **脚の静脈に血液がたまり、むくみ・だるさ**。**長期には下肢静脈瘤のリスク**。**腰・足底（足底腱膜）・膝への負担** |
| 目安 | **1時間に数分は座る、または歩く**。**同じ位置で動かない立位を続けない** |
| その場でできること | **かかとの上げ下げ（ふくらはぎのポンプ）**、**体重を左右に移す**、**片足を低い台に乗せる**、**足指を動かす** |
| 休憩 | **座って足を心臓より高く**（台に乗せる）数分 |
| 靴 | **クッション性・かかとの安定・幅が合う**。**ヒールは3cm以下**が長時間には向く。**インソール**は補助（インソールの記事を参照） |
| 床 | **硬い床には疲労軽減マット**（厨房・レジで普及） |
| 着圧 | **医療用の弾性ストッキング**は静脈瘤の予防・症状緩和に使われる（**市販の着圧ソックスは雑貨で効能表示不可**、圧の弱いものが多い） |
| 受診の目安 | **片脚だけの腫れ・痛み・熱感**（血栓の可能性）、**血管の浮き・皮膚の変色**（静脈瘤） |

- 厚生労働省の**「職場における腰痛予防対策指針」**は、**立ち作業について、片足を台に乗せる・作業台の高さ・床のクッション・適宜の座位**を挙げています。
- **下肢静脈瘤**は**立ち仕事・妊娠・加齢・遺伝**が要因とされ、**女性に多い**。**予防はふくらはぎの運動と弾性ストッキング**が血管外科の一般的な案内。
- **座り仕事と立ち仕事のどちらが健康的か**ではなく、**「姿勢を変える頻度」**が要点というのが身体活動ガイド2023の考え方です。

> 【要検証】腰痛予防対策指針の立ち作業の記載、静脈瘤の説明は日本静脈学会等の資料で確認してください。

## 誤解1｜立ち仕事なら運動不足にならない

**動かない立位は身体活動として小さく**（約1.3〜2メッツ）、**脚の血流停滞**の面では座位と別の問題。**歩く・動く**が必要。

## 誤解2｜むくみは水を飲みすぎたから

**立ち仕事のむくみは重力で血液・水分が脚にたまる**もので、**水分制限は逆効果**（脱水で血液が濃くなる）。**ふくらはぎを動かす・足を上げる**。

## 誤解3｜市販の着圧ソックスで静脈瘤が防げる

**市販の着圧ソックスは雑貨で、効能は表示できず、圧も弱い**。**医療用の弾性ストッキングは医師・専門店で圧を選ぶ**もの。

## 誤解4｜疲れたら休憩で座れば十分

**座るだけより、足を心臓より高くする**のが脚のむくみには効きます。**数分でも**。

## 誤解5｜靴は見た目で選んでも慣れる

**長時間の立位で、合わない靴は足底・膝・腰の痛みの原因**。**クッション・幅・かかとの安定**。**ヒールは低く**。
