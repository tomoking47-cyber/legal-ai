# Q. 关于长时间站立工作带来的疲劳与浮肿，人们常有哪些误解？｜Japan Questions #366

- Shelf: `health` ／ URL: `/zh-cn/health/standing-all-day` ／ Status: **草稿 — 出处未核实**

在日本，很多工作是站着完成的：零售、厨房、医疗护理、工厂流水线。人们常常想当然地认为站着工作「比坐办公室更健康」。但长时间站立有它自身的负担，并与腿部浮肿、腰痛和下肢静脉曲张有关。这里整理了公开资料，以及您能做的事。

## A. 最大的误解是「站着总比坐着更健康」。久坐确实是个真实的问题，但长时间一动不动地站着同样会造成血液淤积在腿部（浮肿、静脉曲张），并加重腰与足部的负担。要点是「不要保持同一个姿势」。对于站立工作，对策是：活动双脚、把体重左右移动、休息时坐下或抬高双腿，以及选对鞋子和地面。

## 判断的依据

| 项目 | 内容 |
|---|---|
| 站立工作的负担 | **血液淤积在腿部静脉 → 浮肿与沉重感。** **长期来看，有下肢静脉曲张的风险。** **腰、足底（足底筋膜）与膝盖的负担** |
| 参考标准 | **每小时坐下或走动几分钟。** **不要一直站在同一个地方不动** |
| 当场能做的事 | **抬起放下脚跟（小腿泵）**、**把体重左右移动**、**把一只脚放在矮台阶上**、**动动脚趾** |
| 休息 | **让双脚高于心脏地坐着**（放在小凳子上）几分钟 |
| 鞋子 | **缓冲性、稳定的后跟杯与合适的宽度。** **鞋跟 3 cm 以下**适合长时间穿。**鞋垫**是补充手段（参见我们关于鞋垫的文章） |
| 地面 | **在硬地面上使用抗疲劳垫**（厨房工位与收银台常见） |
| 压力袜 | **医用弹力袜**用于预防下肢静脉曲张与缓解症状。**店里售卖的着压袜属于一般商品，不能标示健康功效**，大多压力较弱 |
| 何时就诊 | **只有一条腿出现浮肿、疼痛或发热**（可能是血栓）；**血管凸起或皮肤变色**（下肢静脉曲张） |

- 厚生劳动省《职场腰痛预防对策指针》针对站立工作列出了**把一只脚放在台阶上、作业面的高度、有缓冲的地面，以及以合适的间隔坐下休息**。
- **下肢静脉曲张**被归因于**站立工作、妊娠、年龄增长与遗传**，且**女性更为常见**。**小腿运动与弹力袜**是血管外科在预防上的标准建议。
- 《身体活动指南 2023》把问题的框架设定为**不是「坐着工作还是站着工作更健康」，而是「多久变换一次姿势」**。

## 误解1｜站着工作就不会运动不足

**一动不动的站立作为身体活动是很小的**（约 1.3〜2 METs），而在**腿部血流淤积**这一点上，它与久坐是两个不同的问题。**需要走动、需要活动。**

## 误解2｜腿浮肿是因为水喝多了

**站立工作造成的浮肿，是重力把血液与水分拉向腿部。** **限制饮水会适得其反**（脱水会让血液变得黏稠）。**活动小腿、抬高双腿。**

## 误解3｜店里买的着压袜能预防静脉曲张

**店里售卖的着压袜是一般商品：不能标示健康功效，压力也弱。** **医用弹力袜的压力由医生或专业店铺来选择。**

## 误解4｜累了在休息时坐下就够了

**把脚抬到高于心脏的位置，据说比单纯坐着更容易让腿部的浮肿缓和下来。** **哪怕只有几分钟。**

## 误解5｜鞋子按外观挑，穿着穿着就习惯了

**穿着不合脚的鞋长时间站立，会引起足底、膝盖与腰的疼痛。** **缓冲性、宽度与稳定的后跟。** **鞋跟保持低平。**
