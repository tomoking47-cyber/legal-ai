# Q. 關於長時間站立工作帶來的疲勞與水腫，人們常有哪些誤解？｜Japan Questions #366

- Shelf: `health` ／ URL: `/zh-tw/health/standing-all-day` ／ Status: **草稿 — 出處未核實**

在日本，很多工作是站著完成的：零售、廚房、醫療照護、工廠生產線。人們常常想當然地認為站著工作「比坐辦公室更健康」。但長時間站立有它自身的負擔，並與腿部水腫、腰痛和下肢靜脈曲張有關。這裡整理了公開資料，以及您能做的事。

## A. 最大的誤解是「站著總比坐著更健康」。久坐確實是個真實的問題，但長時間一動不動地站著同樣會造成血液鬱積在腿部（水腫、靜脈曲張），並加重腰與足部的負擔。要點是「不要維持同一個姿勢」。對於站立工作，對策是：活動雙腳、把體重左右移動、休息時坐下或抬高雙腿，以及選對鞋子和地面。

## 判斷的依據

| 項目 | 內容 |
|---|---|
| 站立工作的負擔 | **血液鬱積在腿部靜脈 → 水腫與沉重感。** **長期來看，有下肢靜脈曲張的風險。** **腰、足底（足底筋膜）與膝蓋的負擔** |
| 參考標準 | **每小時坐下或走動幾分鐘。** **不要一直站在同一個地方不動** |
| 當場能做的事 | **抬起放下腳跟（小腿幫浦）**、**把體重左右移動**、**把一隻腳放在矮台階上**、**動動腳趾** |
| 休息 | **讓雙腳高於心臟地坐著**（放在小凳子上）幾分鐘 |
| 鞋子 | **緩衝性、穩定的後跟杯與合適的寬度。** **鞋跟 3 cm 以下**適合長時間穿。**鞋墊**是補充手段（參見我們關於鞋墊的文章） |
| 地面 | **在硬地面上使用抗疲勞地墊**（廚房工作區與收銀台常見） |
| 壓力襪 | **醫療級彈性襪**用於預防下肢靜脈曲張與緩解症狀。**店裡販售的壓力襪屬於一般商品，不能標示健康功效**，多數壓力較弱 |
| 何時就醫 | **只有一條腿出現水腫、疼痛或發熱**（可能是血栓）；**血管凸起或皮膚變色**（下肢靜脈曲張） |

- 厚生勞動省《職場腰痛預防對策指針》針對站立工作列出了**把一隻腳放在台階上、作業面的高度、有緩衝的地面，以及以合適的間隔坐下休息**。
- **下肢靜脈曲張**被歸因於**站立工作、懷孕、年齡增長與遺傳**，且**女性較為常見**。**小腿運動與彈性襪**是血管外科在預防上的標準建議。
- 《身體活動指南 2023》把問題的框架設定為**不是「坐著工作還是站著工作更健康」，而是「多久變換一次姿勢」**。

> **[待核實]** 請核對腰痛預防指針中關於站立工作的部分，並對照日本靜脈學會等機構的資料核對下肢靜脈曲張的說明。

## 誤解1｜站著工作就不會運動不足

**一動不動的站立作為身體活動是很小的**（約 1.3〜2 METs），而在**腿部血流鬱積**這一點上，它與久坐是兩個不同的問題。**需要走動、需要活動。**

## 誤解2｜腿水腫是因為水喝太多

**站立工作造成的水腫，是重力把血液與水分拉向腿部。** **限制喝水會適得其反**（脫水會讓血液變得黏稠）。**活動小腿、抬高雙腿。**

## 誤解3｜店裡買的壓力襪能預防靜脈曲張

**店裡販售的壓力襪是一般商品：不能標示健康功效，壓力也弱。** **醫療級彈性襪的壓力由醫師或專業店家來挑選。**

## 誤解4｜累了在休息時坐下就夠了

**把腳抬到高於心臟的位置，據說比單純坐著更容易讓腿部的水腫緩和下來。** **哪怕只有幾分鐘。**

## 誤解5｜鞋子按外觀挑，穿著穿著就習慣了

**穿著不合腳的鞋長時間站立，會引起足底、膝蓋與腰的疼痛。** **緩衝性、寬度與穩定的後跟。** **鞋跟保持低平。**
