# Q. 発酵食品と腸について、よくある誤解は？｜世界の質問箱 #367

- 棚：`health` ／ URL：`/questions/fermented-foods-and-gut` ／ ステータス：**ドラフト（法務レビュー前・出典未検証）**

「発酵食品で腸内環境を整える」は日本で最も広く語られる健康の話題で、海外の「gut health」ブームとも重なります。何が言えて何が言えないかを、表示の制度と栄養学の一般的な説明から整理します。

## A. 最大の誤解は「発酵食品を食べれば腸内環境が整い、健康になる」と断定できることです。発酵食品は日本の食文化の柱で、食事の多様性に貢献しますが、特定の健康効果は、許可・届出を受けた製品（トクホ・機能性表示食品）の表示に限られます。一般の食品に「腸を整える」「免疫を高める」と表示することはできず、研究でも個人差が大きいことが示されています。

## 判断の材料

| 項目 | 内容 |
|---|---|
| 日本の発酵食品 | **味噌・しょうゆ・納豆・漬物（ぬか漬け等）・酢・みりん・日本酒・鰹節・ヨーグルト・チーズ** |
| 食事摂取基準の位置づけ | **「発酵食品」に固有の目標量はない**。**食物繊維（男性21g・女性18g以上）**が腸内細菌の栄養として重視される |
| 表示の制度 | **一般食品**：効能表示不可／**特定保健用食品（トクホ）**：「おなかの調子を整える」等の許可表示／**機能性表示食品**：届出の範囲。**「腸活」は法律用語ではない** |
| 研究の状況 | **特定の菌株で、特定の条件下の効果**が示されるものはあるが、**「発酵食品全般が健康を改善する」という一般化はできない**。**個人差が大きい** |
| 塩分 | **味噌・しょうゆ・漬物は塩分が高い**。1日7g未満の目標の中で（塩分の記事を参照） |
| 加熱 | **味噌汁の菌は加熱で大半が死ぬ**が、**食品としての価値（うま味・栄養）は変わらない** |

- **腸内細菌の多様性**は**食物繊維の摂取量と関連**するとされ、**野菜・豆・全粒穀物・海藻**が主な供給源です（食物繊維の記事を参照）。
- **プロバイオティクス（生きた菌）**は**製品により菌株が異なり、効果は菌株ごとに評価**されます。「ヨーグルトなら何でも同じ」ではありません（ヨーグルトの記事を参照）。
- **「免疫力を高める」**は**医学的に定義のない表現**で、**食品の広告では景表法・健康増進法上問題**になります。

> 【要検証】トクホ・機能性表示食品の制度は消費者庁、食物繊維の目標量は食事摂取基準2025年版で確認してください。

## 誤解1｜発酵食品を食べれば腸が整う

**一般の食品に「腸を整える」効能は表示できず、研究でも個人差が大きい**。**確かなのは、多様な食品の一部として価値がある**こと。

## 誤解2｜生きた菌でなければ意味がない

**味噌汁の菌は加熱で死にますが、味噌の栄養とうま味は残ります。** **菌そのものの効果は、菌株と製品ごとの評価**。

## 誤解3｜発酵食品は多いほどよい

**味噌・しょうゆ・漬物は塩分が高く**、量には上限があります。**1日の塩分目標（7g未満）**の中で。

## 誤解4｜「腸活」商品には根拠がある

**「腸活」は法律用語ではなく、表示の根拠を意味しません。** **トクホ・機能性表示食品のマークと表示**を見る。

## 誤解5｜発酵食品を食べれば食物繊維は要らない

**腸内細菌の栄養は食物繊維**で、**発酵食品と別に必要**。**野菜・豆・海藻・全粒穀物**。
