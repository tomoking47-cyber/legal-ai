# Q. 在宅勤務の健康管理について、よくある誤解は？｜世界の質問箱 #370

- 棚：`health` ／ URL：`/questions/working-from-home-health` ／ ステータス：**ドラフト（法務レビュー前・出典未検証）**

在宅勤務は2020年以降に定着し、「通勤がなくて楽」と同時に「腰痛・目の疲れ・運動不足・孤立」が課題になりました。厚生労働省のテレワークガイドラインと、家でできる環境の整え方を整理します。

## A. 最大の誤解は「在宅勤務は体への負担が少ない」です。通勤の歩行（1日数千歩）がなくなり、食卓やソファでの作業で姿勢が崩れ、休憩の区切りが消えることで、座位時間と目の負担は増えます。厚生労働省のテレワークガイドラインは、机・椅子・照明・画面の位置の目安と、1時間ごとの休憩を示しています。

## ガイドラインの目安（厚生労働省 テレワークガイドライン・情報機器作業ガイドライン）

| 項目 | 目安 |
|---|---|
| **椅子** | 高さ調整可、**足の裏が床につく**、背もたれあり。食卓の椅子なら**クッションと足台** |
| **机** | **肘が90度になる高さ**（目安**60〜72cm**）。低い食卓は**画面台**で補う |
| **画面** | **上端が目の高さより下**、**視距離40cm以上**、**ノートPCは外付けキーボードと台**で目線を上げる |
| **照明** | **作業面300ルクス以上**、画面への映り込みを避ける（窓に背を向けない） |
| **休憩** | **連続1時間以内、10〜15分の休止**。**座位を30分〜1時間で区切る** |
| **温湿度** | **室温18〜28℃、湿度40〜70%**（事務所衛生基準の目安） |
| **運動** | **通勤分の歩行（数千歩）が消える**→**意識的に散歩・階段**（身体活動ガイド2023） |
| **働き方** | **始業・終業の区切り、休憩の申告**、**長時間労働の防止**（テレワークガイドライン） |

- 厚生労働省「テレワークの適切な導入及び実施の推進のためのガイドライン」（2021年策定、**2025年7月改訂**）は、**作業環境の整備は事業者と労働者の双方で**とし、**自宅の環境チェックリスト**を示しています。
- **ノートPCをそのまま使う姿勢**が**首・肩の負担の最大の原因**（スマホ首の記事を参照）。**外付けキーボード＋画面を台に乗せる**だけで大きく変わります。
- **孤立・メンタル**：ガイドラインは**コミュニケーションの機会の確保**を求め、**相談窓口（産業医・こころの耳）**を案内しています。

> 【要検証】ガイドラインの数値（机の高さ・照度・温湿度）は厚生労働省の資料、情報機器作業ガイドラインで確認してください。

## 誤解1｜在宅勤務は体が楽

**通勤の歩行が消え、座位が増え、姿勢が崩れやすい**。**歩数・休憩・机と椅子**を意識的に。

## 誤解2｜食卓とノートPCで十分

**食卓は高く、椅子は低く、ノートPCは目線が下がる**——**首・肩・腰の負担の典型**。**画面台・外付けキーボード・足台**で数千円で改善。

## 誤解3｜休憩は自分で取れるから問題ない

**区切りがないほうが休憩は減る**ことが多い。**タイマーで1時間ごとに立つ**、**昼休みは外に出る**。

## 誤解4｜運動不足は週末に補える

**平日の座位時間は運動とは独立した問題**（座りすぎの記事を参照）。**毎日の散歩・階段・家事**で分散。

## 誤解5｜自宅の環境は自分の責任

**ガイドラインは事業者と労働者の双方の役割**を示し、**機器の貸与・費用負担のルール**を労使で定めることを求めています。**会社に相談できる事項**です。
