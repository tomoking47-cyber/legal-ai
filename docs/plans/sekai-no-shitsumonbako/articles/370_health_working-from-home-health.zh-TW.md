# Q. 關於在家工作時的健康，人們常有哪些誤解？｜Japan Questions #370

- Shelf: `health` ／ URL: `/zh-tw/health/working-from-home-health` ／ Status: **草稿 — 出處未核實**

在家工作從 2020 年起在日本固定下來。伴隨「不用通勤，真輕鬆」而來的，是腰痛、眼睛疲勞、運動不足與孤立感。本文整理厚生勞動省的遠距工作指南，以及如何在日本的住宅裡布置一個能用的工作空間——這裡的書桌和餐桌往往又小又矮。

## A. 最大的誤解是「在家工作對身體的負擔較小」。通勤的步行（一天幾千步）消失了，在餐桌或沙發上工作會讓姿勢垮掉，休息的自然節點也不見了，於是久坐時間和眼睛的負擔都增加了。厚生勞動省的遠距工作指南給出了書桌、椅子、照明與螢幕位置的參考標準，並要求每小時休息一次。

## 指南的參考標準（厚生勞動省 遠距工作指南・資訊設備作業指南）

| 項目 | 參考標準 |
|---|---|
| **椅子** | 高度可調，**腳掌能平放在地面**，有椅背。用餐椅時，加上**坐墊與腳凳** |
| **書桌** | **手肘能成 90 度的高度**（大致 **60〜72 cm**）。餐桌太矮時用**螢幕架**來彌補 |
| **螢幕** | **上緣低於視線**，**視距 40 cm 以上**，**筆記型電腦放在架上並外接鍵盤**以抬高視線 |
| **照明** | **作業面 300 勒克斯以上**；避免螢幕上的反光（不要背對窗戶而坐） |
| **休息** | **連續作業不超過 1 小時，然後休息 10〜15 分鐘。** **每 30 分鐘至 1 小時打斷一次久坐** |
| **溫度與濕度** | **室溫 18〜28℃（64〜82°F）、濕度 40〜70%**（以辦公室衛生標準為參考） |
| **活動量** | **通勤的步行（幾千步）沒有了** → **有意識地去散步、走樓梯**（《身體活動指南 2023》） |
| **工作方式** | **明確一天的開始與結束、回報休息時間**、**防止長時間工作**（遠距工作指南） |

- 厚生勞動省《為推動遠距工作妥善導入與實施的指南》（2021 年制定，**2025 年 7 月修訂**）指出，**工作環境的整備是雇主與勞工雙方的責任**，並提供了**居家環境的檢查清單**。
- **就那樣直接使用筆記型電腦**是**頸肩負擔最大的原因**（參見我們關於「手機頸」的文章）。**外接鍵盤加上把螢幕放在架上**，單是這一點就有很大差別。
- **孤立與心理健康**：指南要求**維持溝通的機會**，並指出了**諮詢窗口（產業醫師、心理健康入口網站「こころの耳」）**。

> **[待核實]** 指南中的數值（桌高、勒克斯、溫濕度）請對照厚生勞動省的資料與《資訊設備作業指南》核對。

## 誤解1｜在家工作身體輕鬆

**通勤的步行消失了，久坐增加，姿勢也會走樣。** **請有意識地關注步數、休息，以及書桌與椅子。**

## 誤解2｜餐桌加筆記型電腦就夠了

**桌子太高、椅子太矮，筆記型電腦又把視線拉低**——**這是頸、肩、腰負擔的典型組合**。**螢幕架、外接鍵盤與腳凳**，花幾千日圓就能解決。

## 誤解3｜休息我隨時都能取，所以沒問題

**沒有節點，休息通常是變少而不是變多。** **設個計時器每小時站起來一次**，**午休時到外面走走**。

## 誤解4｜運動不足可以在週末補回來

**平日的久坐時間與運動是兩個不同的問題**（參見我們關於久坐的文章）。**用每天的散步、樓梯與家務把它分散開。**

## 誤解5｜家裡的環境是我自己的責任

**指南規定了雇主與勞工雙方的角色**，並要求**關於設備出借與費用負擔的規則**由勞資雙方協商確定。**這是您可以向公司提出的事情。**
