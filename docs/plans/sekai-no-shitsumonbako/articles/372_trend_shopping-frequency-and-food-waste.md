# Q. 買い物の頻度と食品ロスについて、よくある誤解は？｜世界の質問箱 #372

- 棚：`trend` ／ URL：`/questions/shopping-frequency-and-food-waste` ／ ステータス：**ドラフト（法務レビュー前・出典未検証）**

「まとめ買いが節約」「毎日買うほうが新鮮」——買い物の頻度は各国で意見が分かれます。日本は冷蔵庫が小さく、スーパーが近く、共働きが多いという条件があり、食品ロスの観点から公的に整理されています。

## A. 最大の誤解は「まとめ買いは常に経済的」です。まとめ買いは単価を下げますが、冷蔵庫の容量を超えると使い切れずに廃棄が増え、家庭の食品ロスの主因（食べ残し・期限切れ・過剰除去）に直結します。日本の家庭では「週1〜2回の計画的な買い物＋不足分を近くで補う」が現実的で、冷蔵庫の中身を把握することが節約と食品ロス削減の両方に効きます。

## 数字で見る

| 項目 | 数値 | 出典 |
|---|---|---|
| 家庭の食品ロス | **約233万トン／年**（令和5年度推計）、**1人1日約50g（茶碗半分）** | 農林水産省・環境省 |
| 家庭ロスの内訳 | **食べ残し 約4割、直接廃棄（期限切れ等）約4割、過剰除去 約2割** | 消費者庁 |
| 買い物の頻度 | **週2〜3回**が最多（各種調査）。**毎日〜ほぼ毎日も約2割** | 民間調査 |
| 買いすぎの原因 | **冷蔵庫の中身を把握していない**（消費者庁の調査で「買ってあるのを忘れた」が上位） | 消費者庁 |
| 期限の考え方 | **賞味期限は「おいしさの目安」、消費期限は「安全の期限」** | 消費者庁 |

| 工夫 | 内容 |
|---|---|
| **買い物前に冷蔵庫を撮影・確認** | 重複買いを防ぐ |
| **買い物リスト、空腹で行かない** | 衝動買いを減らす |
| **「手前取り」** | 陳列の手前（期限の近いもの）から取る——すぐ使うなら。消費者庁・農水省が推進 |
| **冷蔵庫の「使い切りゾーン」** | 期限が近いものを一か所に |
| **週1回の在庫確認日** | 残り物で1食作る |
| **少量パック・バラ売り** | 少人数世帯は割高でも廃棄が減れば結果として安い |

> 【要検証】食品ロスの推計値は農林水産省・環境省の最新年度、ロスの内訳は消費者庁の資料で確認してください。

## 誤解1｜まとめ買いは節約

**単価は下がっても、使い切れなければ廃棄＝損失**。**冷蔵庫の容量と1週間の献立に合う量**が上限。

## 誤解2｜毎日買えば無駄がない

**毎日の買い物は衝動買いと交通・時間のコスト**が増えます。**週1〜2回の計画買い＋補充**が多くの家庭の実際。

## 誤解3｜期限が近いものは避けて奥から取る

**すぐ食べるなら手前（期限の近いもの）でよく、店の廃棄を減らします**（「手前取り」）。**家で使い切れる期限か**が判断基準。

## 誤解4｜安いときに買って冷凍すれば無駄はない

**冷凍しても「いつ買ったか分からない」ものは使われず、冷凍庫の奥で廃棄**されます。**日付を書く・冷凍は2〜3週間で使う**（冷凍の記事を参照）。

## 誤解5｜食品ロスは店や外食の問題

**家庭のロスは全体の約半分（233万トン／464万トン）**。**「買ってあるのを忘れた」が主因**で、冷蔵庫の把握が最も効く対策。
