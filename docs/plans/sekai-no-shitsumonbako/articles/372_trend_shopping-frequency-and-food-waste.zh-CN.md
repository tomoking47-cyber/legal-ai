# Q. 关于购物频率与食物浪费，常见的误解有哪些？｜Japan Questions #372

- Shelf: `trend` ／ URL: `/zh-cn/trend/shopping-frequency-and-food-waste` ／ Status: **草稿 — 出处未核实**

"囤货更省钱。""每天买更新鲜。"关于多久买一次菜，各国的看法各不相同。日本有自己的条件——冰箱小、超市就在附近、双职工家庭多——政府也从食品浪费（食品ロス，shokuhin rosu，日语中"食物浪费"的说法）的角度提出了这个问题。下面看看数字怎么说。

## A. 最大的误解是"囤货一定划算"。整箱买确实能拉低单价，但一旦超出冰箱的容量，食物就用不完而被丢掉——直接对应家庭食物浪费的主要成因（吃剩、过期丢弃、过度削切）。对日本家庭来说，"每周有计划地买一到两次，不够的就到附近补货"比较现实，而掌握冰箱里有什么，对省钱和减少浪费都有效。

## 用数字看

| 项目 | 数字 | 出处 |
|---|---|---|
| 家庭产生的食物浪费 | **每年约224万吨**（2024年度推算值），**每人每天约50 g（半碗米饭）** | 农林水产省（MAFF）／环境省 |
| 家庭浪费的构成 | **吃剩约40%，直接丢弃（过期等）约40%，过度削切约20%** | 消费者厅 |
| 购物频率 | **每周2–3次** 是最常见的回答（多项调查）。**每天或几乎每天：约20%** | 民间调查 |
| 买多了的原因 | **不知道冰箱里有什么**（"忘了已经买过"在消费者厅的调查中排名靠前） | 消费者厅 |
| 日期标示怎么看 | **赏味期限（賞味期限）是关于品质的"最佳食用"参考；消费期限（消費期限）是关于安全的"食用截止"界限** | 消费者厅 |

| 做法 | 含义 |
|---|---|
| **出门前拍下或确认冰箱** | 防止重复购买 |
| **列购物清单；不要饿着肚子买菜** | 减少冲动购买 |
| **「手前取り」(temae-dori，从前面拿)** | 从货架前排（日期最近的）拿——前提是你很快就会用掉。消费者厅与农林水产省都在推广 |
| **在冰箱里设一个"优先用完区"** | 把临近日期的东西集中放在一处 |
| **每周一天清点日** | 用剩下的食材做一顿饭 |
| **小包装与散装** | 对小家庭来说，即使单价高一些，只要不扔掉，最后反而更便宜 |

## 误解1｜囤货省钱

**即使单价更低，用不完扔掉就是损失。** 上限是**冰箱装得下、一周吃得完的量。**

## 误解2｜每天买菜就不会浪费

**每天买菜会增加冲动购买，还有交通和时间成本。** **每周有计划地买一到两次，再随时补货** 才是多数家庭实际的做法。

## 误解3｜避开临近日期的商品，要从后排拿

**如果很快就吃，拿前排（日期较近的）没问题，还能减少店铺的浪费**（「手前取り」）。判断标准是**自己家里能不能在到期前吃完。**

## 误解4｜便宜时买回来冷冻就不会浪费

**"想不起来什么时候买的"冷冻食品最终不会被吃掉，从冷冻室深处被扔掉。** **写上日期，冷冻食品在2–3周内吃完**（参见本站冷冻的文章）。

## 误解5｜食物浪费是商店和餐厅的问题

**家庭产生的约占总量的一半（461万吨中的224万吨）。** **"忘了已经买过"是主要原因，** 所以掌握冰箱里有什么是最有效的对策。
