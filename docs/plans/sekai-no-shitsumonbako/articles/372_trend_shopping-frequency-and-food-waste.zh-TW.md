# Q. 關於採買頻率與食物浪費，常見的誤解有哪些？｜Japan Questions #372

- Shelf: `trend` ／ URL: `/zh-tw/trend/shopping-frequency-and-food-waste` ／ Status: **草稿 — 出處未核實**

「囤貨比較省錢。」「每天買比較新鮮。」關於多久採買一次，各國看法都不一樣。日本有自己的條件——冰箱小、超市就在附近、雙薪家庭多——政府也從食品浪費（食品ロス，shokuhin rosu，日文中「食物浪費」的說法）的角度提出了這個問題。以下看看數字怎麼說。

## A. 最大的誤解是「囤貨一定划算」。整箱買確實能拉低單價，但一旦超出冰箱的容量，食物就用不完而被丟掉——直接對應家庭食物浪費的主要成因（吃剩、過期丟棄、過度削切）。對日本家庭來說，「每週有計畫地買一到兩次，不夠的就到附近補貨」比較實際，而掌握冰箱裡有什麼，對省錢和減少浪費都有效。

## 用數字看

| 項目 | 數字 | 出處 |

| 採買頻率 | **每週2–3次** 是最常見的回答（多項調查）。**每天或幾乎每天：約20%** | 民間調查 |
| 買太多的原因 | **不知道冰箱裡有什麼**（「忘了已經買過」在消費者廳的調查中名列前茅） | 消費者廳 |
| 日期標示怎麼看 | **賞味期限（賞味期限）是關於品質的「最佳食用」參考；消費期限（消費期限）是關於安全的「食用期限」界線** | 消費者廳 |

| 做法 | 意思 |
|---|---|
| **出門前拍下或確認冰箱** | 防止重複購買 |
| **列採買清單；不要餓著肚子買菜** | 減少衝動購買 |
| **「手前取り」(temae-dori，從前面拿)** | 從貨架前排（日期最近的）拿——前提是你很快就會用掉。消費者廳與農林水產省都在推廣 |
| **在冰箱裡設一個「優先用完區」** | 把接近期限的東西集中放在一處 |
| **每週一天盤點日** | 用剩下的食材做一頓飯 |
| **小包裝與散裝** | 對小家庭來說，即使單價高一些，只要不丟掉，最後反而更便宜 |

> **[待核實]** 食物浪費的推估值請核對農林水產省與環境省最新年度的數據，組成比例請核對消費者廳的資料。

## 誤解1｜囤貨省錢

**即使單價更低，用不完丟掉就是損失。** 上限是**冰箱裝得下、一週吃得完的量。**

## 誤解2｜每天買菜就不會浪費

**每天買菜會增加衝動購買，還有交通和時間成本。** **每週有計畫地買一到兩次，再隨時補貨** 才是多數家庭實際的做法。

## 誤解3｜避開接近期限的商品，要從後排拿

**如果很快就吃，拿前排（期限較近的）沒問題，還能減少店家的浪費**（「手前取り」）。判斷標準是**自己家裡能不能在期限前吃完。**

## 誤解4｜便宜時買回來冷凍就不會浪費

**「想不起來什麼時候買的」冷凍食品最後不會被吃掉，從冷凍庫深處被丟掉。** **寫上日期，冷凍食品在2–3週內吃完**（參見本站冷凍的文章）。

## 誤解5｜食物浪費是店家和餐廳的問題

**家庭產生的約占總量的一半（464萬公噸中的233萬公噸）。** **「忘了已經買過」是主要原因，** 所以掌握冰箱裡有什麼是最有效的對策。
