# Q. 关于一个人做饭，常见的误解有哪些？｜Japan Questions #373

- Shelf: `trend` ／ URL: `/zh-cn/trend/cooking-for-one` ／ Status: **草稿 — 出处未核实**

在日本，单人家庭约占全部家庭的38%（2020年国势调查），是最大的一类。如果您在这里独自生活，可能会觉得"做一人份比买着吃还贵"，或者"食材总是浪费掉"。我们用官方的营养思路和日本家庭实际的做法来回答。

## A. 最大的误解是"一个人做饭又贵又浪费，所以买现成的才理性"。浪费来自每次都想只做一人份。改成"一次做2–3人份，分装到冷藏和冷冻"以及"按能用完的组合买食材"，成本、营养和时间都会改善。营养方面，每餐做到食事平衡指南（食事バランスガイド）说的"主食、主菜、副菜"就够了。

## 数字与做法

| 项目 | 内容 | 出处 |
|---|---|---|
| 单人家庭 | **约2,115万户，占全部家庭的38.1%**（2020年） | 国势调查 |
| 单人家庭的饮食支出 | **每月约4万日元**（其中约40%用于外食和现成食品） | 家计调查（2023年） |
| 独居者的营养问题 | **蔬菜不足（平均每天约250 g；目标350 g）、不吃早餐、盐分过多（现成食品与外食）** | 国民健康・营养调查 |
| 一餐的构成 | **主食（shushoku，米饭或面包）、主菜（shusai）、副菜（fukusai）** 齐全（**加了蔬菜的汤可以算作副菜**） | 食事平衡指南（食事バランスガイド，Japanese Food Guide Spinning Top） |

| 做法 | 含义 |
|---|---|
| **一次多做、分装** | **米饭一次煮3–5人份并冷冻**；**每道菜做2–3人份**（参见本站常备菜的文章） |
| **能用完的组合** | 四分之一颗卷心菜 → 炒菜、味噌汤、沙拉 ／ 一块豆腐 → 一半做冷奴（hiyayakko，凉拌豆腐），一半放味噌汤 |
| **冷冻蔬菜与切好的蔬菜** | **即使单价高一些，只要不扔掉就更便宜。** 冷冻西兰花、菠菜、什锦蔬菜 |
| **料多的汤** | 味噌汤或汤里放蔬菜、豆腐、菌菇 → **同时当副菜和汤** |
| **一锅或一个平底锅搞定** | 少洗碗 |
| **现成食品（中食，nakashoku）怎么用** | **买主菜，自己加一道蔬菜副菜和一碗汤。** 注意**熟菜（惣菜，sōzai）的盐分** |
| **调味料买小包装** | 开封后会变质（参见本站调味料的文章） |

## 误解1｜一个人的话，买着吃更便宜

**主要依赖现成食品和外食的独居者，饮食支出往往高于以自己做饭为主的人**（家计调查）。**"一次多做、分装"** 能把自家做饭的单次成本降下来。

## 误解2｜不每次只做一人份就会浪费

**一次做2–3人份，冷藏（2–3天）或冷冻（2–3周）保存** 是独自做饭的标准模式。**每次现做反而会剩下更多食材。**

## 误解3｜一个人吃不完蔬菜

**冷冻蔬菜、切好的蔬菜和料多的汤** 能解决这个问题。**买一整颗卷心菜或胡萝卜，做成3–4道菜。**

## 误解4｜营养均衡很难做到

只要看**每餐有没有主食（米饭）、主菜（肉、鱼、蛋或豆腐）和副菜（蔬菜）** 就行。**把蔬菜放进味噌汤里，它就算副菜。**

## 误解5｜熟菜和便利店食品对身体不好

**买主菜，再加蔬菜和汤，** **营养上就没有问题。** 注意**盐分（每餐2–3 g为参考）和吃油炸食品的频率。**
