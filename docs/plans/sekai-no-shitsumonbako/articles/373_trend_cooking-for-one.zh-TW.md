# Q. 關於一個人開伙，常見的誤解有哪些？｜Japan Questions #373

- Shelf: `trend` ／ URL: `/zh-tw/trend/cooking-for-one` ／ Status: **草稿 — 出處未核實**

在日本，單人家庭約占全部家庭的38%（2020年國勢調查），是最大的一類。如果您在這裡獨自生活，可能會覺得「做一人份比買現成的還貴」，或者「食材總是浪費掉」。我們用官方的營養思路和日本家庭實際的做法來回答。

## A. 最大的誤解是「一個人開伙又貴又浪費，所以買現成的才理性」。浪費來自每次都想只做一人份。改成「一次做2–3人份，分裝到冷藏和冷凍」以及「按能用完的組合買食材」，成本、營養和時間都會改善。營養方面，每餐做到飲食平衡指南（食事バランスガイド）說的「主食、主菜、副菜」就夠了。

## 數字與做法

| 項目 | 內容 | 出處 |
|---|---|---|
| 單人家庭 | **約2,115萬戶，占全部家庭的38.1%**（2020年） | 國勢調查 |
| 單人家庭的飲食支出 | **每月約4萬日圓**（其中約40%用於外食和現成食品） | 家計調查（2023年） |
| 獨居者的營養問題 | **蔬菜不足（平均每天約250 g；目標350 g）、不吃早餐、鹽分過多（現成食品與外食）** | 國民健康・營養調查 |
| 一餐的組成 | **主食（shushoku，白飯或麵包）、主菜（shusai）、副菜（fukusai）** 齊全（**加了蔬菜的湯可以算作副菜**） | 飲食平衡指南（食事バランスガイド，Japanese Food Guide Spinning Top） |

| 做法 | 意思 |
|---|---|
| **一次多做、分裝** | **白飯一次煮3–5人份並冷凍**；**每道菜做2–3人份**（參見本站常備菜的文章） |
| **能用完的組合** | 四分之一顆高麗菜 → 炒菜、味噌湯、沙拉 ／ 一塊豆腐 → 一半做冷奴（hiyayakko，涼拌豆腐），一半放味噌湯 |
| **冷凍蔬菜與切好的蔬菜** | **即使單價高一些，只要不丟掉就更便宜。** 冷凍青花菜、菠菜、什錦蔬菜 |
| **料多的湯** | 味噌湯或湯裡放蔬菜、豆腐、菇類 → **同時當副菜和湯** |
| **一鍋或一個平底鍋搞定** | 少洗碗 |
| **現成食品（中食，nakashoku）怎麼用** | **買主菜，自己加一道蔬菜副菜和一碗湯。** 注意**熟食（惣菜，sōzai）的鹽分** |
| **調味料買小包裝** | 開封後會劣化（參見本站調味料的文章） |

> **[待核實]** 家庭戶數請核對2020年國勢調查，飲食支出請核對家計調查（單身家庭），營養數值請核對最新的國民健康・營養調查。

## 誤解1｜一個人的話，買現成的比較便宜

**主要依賴現成食品和外食的獨居者，飲食支出往往高於以自己開伙為主的人**（家計調查）。**「一次多做、分裝」** 能把自己開伙的單次成本降下來。

## 誤解2｜不每次只做一人份就會浪費

**一次做2–3人份，冷藏（2–3天）或冷凍（2–3週）保存** 是獨自開伙的標準模式。**每次現做反而會剩下更多食材。**

## 誤解3｜一個人吃不完蔬菜

**冷凍蔬菜、切好的蔬菜和料多的湯** 能解決這個問題。**買一整顆高麗菜或紅蘿蔔，做成3–4道菜。**

## 誤解4｜營養均衡很難做到

只要看**每餐有沒有主食（白飯）、主菜（肉、魚、蛋或豆腐）和副菜（蔬菜）** 就好。**把蔬菜放進味噌湯裡，它就算副菜。**

## 誤解5｜熟食和便利商店的食物對身體不好

**買主菜，再加蔬菜和湯，** **營養上就沒有問題。** 注意**鹽分（每餐2–3 g為參考）和吃油炸食物的頻率。**
