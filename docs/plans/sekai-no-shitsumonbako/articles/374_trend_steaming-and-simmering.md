# Q. 蒸し料理と煮物の基本について、よくある誤解は？｜世界の質問箱 #374

- 棚：`trend` ／ URL：`/questions/steaming-and-simmering` ／ ステータス：**ドラフト（法務レビュー前・出典未検証）**

蒸す・煮るは日本料理の基本の調理法ですが、「時間がかかる」「難しい」と敬遠されがちです。海外では蒸し器を持たない家庭が多く、「電子レンジと何が違うか」も問われます。加熱の仕組みと食品衛生の観点から整理します。

## A. 最大の誤解は「蒸し料理は専用の蒸し器が必要で、煮物は長時間煮るほどおいしい」です。蒸すことは、鍋と皿と水があればでき、フライパンに水を張ってふたをするだけでも成立します。煮物は「短時間で火を通し、冷ます間に味を含ませる」のが基本で、長時間の加熱は煮崩れと栄養の流出を招きます。どちらも「中心まで加熱（75℃1分）」が安全の線です。

## 蒸す

| 項目 | 内容 |
|---|---|
| 道具 | **蒸し器、または鍋＋耐熱皿を浮かせる台（小皿・アルミホイルの輪）＋ふた**。**フライパンに水1cm、ふた**でも |
| 仕組み | **100℃の蒸気で、水に成分が流れ出ない**。**油を使わない** |
| 向く食材 | 野菜（ブロッコリー・かぼちゃ・さつまいも）、魚、鶏肉、しゅうまい、茶碗蒸し、蒸しパン |
| 時間の目安 | ブロッコリー**3〜4分**、かぼちゃ（2cm角）**8〜10分**、鶏むね（200g）**12〜15分**、魚の切り身**8〜10分** |
| 電子レンジとの違い | **レンジは内部の水分を振動させて加熱（ムラ・乾燥しやすい）**、**蒸しは外から均一に、しっとり** |
| 安全 | **ふたを開けるとき蒸気でやけど**。**ふたを奥に向けて開ける** |

## 煮る

| 項目 | 内容 |
|---|---|
| 基本 | **だし・調味料で短時間煮て火を止め、冷ます間に味が入る**（**「冷めるときに味がしみる」**） |
| 落としぶた | **煮汁が少なくても全体に回り、煮崩れを防ぐ**（クッキングシート・アルミホイルでも） |
| 調味の順 | **「さしすせそ」（砂糖→塩→酢→しょうゆ→味噌）**は**分子の大きい砂糖を先に、香りの強いものを後に**という慣用 |
| 時間 | **根菜15〜20分、葉物・豆腐は数分**。**長時間は煮崩れ・ビタミンの流出** |
| 保存 | **煮物は水分が多く傷みやすい**。**当日〜翌日、冷蔵**。**再加熱は全体を沸かす**（ウェルシュ菌の記事を参照） |

> 【要検証】加熱時間は食材の大きさ・鍋で異なる目安です。食中毒予防の温度は厚生労働省の資料で確認してください。

## 誤解1｜蒸し器がないと蒸せない

**鍋と皿と水とふた**で十分。**フライパンに水1cmを張り、皿を置いてふた**でも。**電子レンジの蒸し機能・シリコンスチーマー**も。

## 誤解2｜電子レンジで温めれば蒸したのと同じ

**レンジは内部から加熱してムラと乾燥**が出やすく、**蒸しは外から均一にしっとり**。**ブロッコリーの色・食感**で差が分かります。

## 誤解3｜煮物は長く煮るほど味がしみる

**味は冷めるときに入ります。** **短時間で火を通し、火を止めて置く**のが基本。**長時間は煮崩れと栄養の流出**。

## 誤解4｜煮物は日持ちする

**水分が多く、常温放置は食中毒の原因**。**当日〜翌日に冷蔵、再加熱は全体を沸かす**。

## 誤解5｜「さしすせそ」は守らないと失敗する

**慣用の目安**で、**科学的にも砂糖を先にする理由（分子が大きく浸透が遅い）**はありますが、**厳密に守らなくても大きな差はない**とする料理研究者も多い。**しょうゆ・味噌は最後に香りを残す**のが実用的な要点。
