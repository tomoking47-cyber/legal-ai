# Q. 关于蒸与炖煮（煮物），常见的误解有哪些？｜Japan Questions #374

- Shelf: `trend` ／ URL: `/zh-cn/trend/steaming-and-simmering` ／ Status: **草稿 — 出处未核实**

蒸（mushi，蒸し）和炖煮（nimono，煮物）是日本料理最基本的加热方式，却常被认为"慢"或"难"而被敬而远之。国外很多家庭没有蒸锅，我们也常被问到蒸和微波炉有什么不同。下面说明热是怎么传递的，以及食品安全的界线在哪里。

## A. 最大的误解是"蒸必须有专用蒸锅，而炖煮的菜煮得越久越好吃"。蒸只需要一口锅、一个盘子和水——平底锅里加少量水盖上盖子就够了。炖煮的原理是"先快速加热熟透，再在放凉的过程中入味"；久煮会把食材煮散，也会让营养流失。两者的安全界线都是"中心加热到位（75°C持续1分钟）"。

## 蒸

| 项目 | 内容 |
|---|---|
| 器具 | **蒸锅，或锅＋垫高的耐热盘（用小碟子或卷成圈的锡纸垫）＋锅盖。** **平底锅加1 cm水盖上盖子** 也可以 |
| 原理 | **100°C（212°F）的蒸汽加热；成分不会溶到水里。** **不需要油** |
| 适合 | 蔬菜（西兰花、南瓜、红薯）、鱼、鸡肉、烧卖、茶碗蒸（咸味蛋羹）、包子 |
| 时间参考 | 西兰花 **3–4分钟**，南瓜（2 cm块）**8–10分钟**，鸡胸肉（200 g）**12–15分钟**，鱼块 **8–10分钟** |
| 与微波炉的区别 | **微波炉靠振动食物内部的水分加热（受热不均，容易变干）**；**蒸汽从外侧均匀加热，能让食材保持湿润** |
| 安全 | **掀盖时蒸汽会烫伤。** **把锅盖朝远离自己的方向倾斜打开** |

## 炖煮（煮物）

| 项目 | 内容 |
|---|---|
| 原理 | **在高汤（dashi）和调味料中短时间炖煮，关火后在放凉的过程中入味**（**"味道在放凉时进去"**） |
| 落盖（otoshibuta） | **直接压在食材上的盖子，少量汤汁也能遍及全部，食材不易散开**（用烘焙纸或锡纸也可以） |
| 调味顺序 | **「さしすせそ」(sa-shi-su-se-so：糖 → 盐 → 醋 → 酱油 → 味噌)** 是经验法则：**糖分子大，先放；香气强的调味料最后放** |
| 时间 | **根菜类15–20分钟；叶菜和豆腐几分钟。** **久煮会煮散食材，也会让维生素流失** |
| 保存 | **煮物汤汁多，容易变质。** **当天或第二天吃完，冷藏保存。** **重新加热要整锅煮沸**（参见本站产气荚膜梭菌的文章） |

> **[待核实]** 加热时间只是参考，会因食材大小和锅具而变。防止食物中毒的温度请核对厚生劳动省（MHLW）的资料。

## 误解1｜没有蒸锅就不能蒸

**一口锅、一个盘子、水和锅盖** 就够了。**平底锅加1 cm水，上面放盘子，盖上盖子** 也行。**微波炉的蒸汽功能或硅胶蒸锅** 同样可以。

## 误解2｜微波炉加热和蒸是一回事

**微波炉从内部加热，容易受热不均且变干**；**蒸汽从外侧均匀加热，能保持湿润。** **西兰花的颜色和口感** 最能看出差别。

## 误解3｜煮物煮得越久越入味

**味道是在放凉的过程中进去的。** 基本做法是**快速煮熟，关火后放着。** **久煮会把食材煮散，也会让营养流失。**

## 误解4｜煮物很耐放

**煮物汤汁多，放在常温下会引起食物中毒。** **请冷藏，并在当天或第二天吃完；重新加热时要整锅煮沸。**

## 误解5｜不按「さしすせそ」做菜就会失败

这是**经验法则。** **先放糖确实有科学理由（分子大，渗透慢）**，但**很多料理研究家表示严格的顺序影响不大。** 实用的重点是**酱油和味噌最后放，以保留香气。**
