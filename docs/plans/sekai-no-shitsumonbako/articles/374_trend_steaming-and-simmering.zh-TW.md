# Q. 關於蒸與燉煮（煮物），常見的誤解有哪些？｜Japan Questions #374

- Shelf: `trend` ／ URL: `/zh-tw/trend/steaming-and-simmering` ／ Status: **草稿 — 出處未核實**

蒸（mushi，蒸し）和燉煮（nimono，煮物）是日本料理最基本的加熱方式，卻常被認為「慢」或「難」而被敬而遠之。國外很多家庭沒有蒸鍋，我們也常被問到蒸和微波爐有什麼不同。以下說明熱是怎麼傳遞的，以及食品安全的界線在哪裡。

## A. 最大的誤解是「蒸一定要有專用蒸鍋，而燉煮的菜煮得越久越好吃」。蒸只需要一只鍋、一個盤子和水——平底鍋裡加少量水蓋上鍋蓋就夠了。燉煮的原理是「先快速加熱煮透，再在放涼的過程中入味」；久煮會把食材煮散，也會讓營養流失。兩者的安全界線都是「中心加熱到位（75°C持續1分鐘）」。

## 蒸

| 項目 | 內容 |
|---|---|
| 器具 | **蒸鍋，或鍋子＋墊高的耐熱盤（用小碟子或捲成圈的鋁箔紙墊）＋鍋蓋。** **平底鍋加1 cm水蓋上鍋蓋** 也可以 |
| 原理 | **100°C（212°F）的蒸氣加熱；成分不會溶到水裡。** **不需要油** |
| 適合 | 蔬菜（青花菜、南瓜、地瓜）、魚、雞肉、燒賣、茶碗蒸（鹹味蒸蛋）、包子 |
| 時間參考 | 青花菜 **3–4分鐘**，南瓜（2 cm塊）**8–10分鐘**，雞胸肉（200 g）**12–15分鐘**，魚片 **8–10分鐘** |
| 與微波爐的差別 | **微波爐靠振動食物內部的水分加熱（受熱不均，容易變乾）**；**蒸氣從外側均勻加熱，能讓食材保持濕潤** |
| 安全 | **掀蓋時蒸氣會燙傷。** **把鍋蓋朝遠離自己的方向傾斜打開** |

## 燉煮（煮物）

| 項目 | 內容 |
|---|---|
| 原理 | **在高湯（dashi）和調味料中短時間燉煮，關火後在放涼的過程中入味**（**「味道在放涼時進去」**） |
| 落蓋（otoshibuta） | **直接壓在食材上的蓋子，少量湯汁也能遍及全部，食材不易散開**（用烘焙紙或鋁箔紙也可以） |
| 調味順序 | **「さしすせそ」(sa-shi-su-se-so：糖 → 鹽 → 醋 → 醬油 → 味噌)** 是經驗法則：**糖分子大，先放；香氣強的調味料最後放** |
| 時間 | **根莖類15–20分鐘；葉菜和豆腐幾分鐘。** **久煮會煮散食材，也會讓維生素流失** |
| 保存 | **煮物湯汁多，容易變質。** **當天或隔天吃完，冷藏保存。** **重新加熱要整鍋煮沸**（參見本站產氣莢膜梭菌的文章） |

> **[待核實]** 加熱時間只是參考，會因食材大小和鍋具而異。防止食物中毒的溫度請核對厚生勞動省（MHLW）的資料。

## 誤解1｜沒有蒸鍋就不能蒸

**一只鍋、一個盤子、水和鍋蓋** 就夠了。**平底鍋加1 cm水，上面放盤子，蓋上鍋蓋** 也行。**微波爐的蒸氣功能或矽膠蒸鍋** 同樣可以。

## 誤解2｜微波爐加熱和蒸是一樣的

**微波爐從內部加熱，容易受熱不均且變乾**；**蒸氣從外側均勻加熱，能保持濕潤。** **青花菜的顏色和口感** 最能看出差別。

## 誤解3｜煮物煮得越久越入味

**味道是在放涼的過程中進去的。** 基本做法是**快速煮熟，關火後放著。** **久煮會把食材煮散，也會讓營養流失。**

## 誤解4｜煮物很耐放

**煮物湯汁多，放在常溫下會引起食物中毒。** **請冷藏，並在當天或隔天吃完；重新加熱時要整鍋煮沸。**

## 誤解5｜不照「さしすせそ」做菜就會失敗

這是**經驗法則。** **先放糖確實有科學理由（分子大，滲透慢）**，但**很多料理研究家表示嚴格的順序影響不大。** 實用的重點是**醬油和味噌最後放，以保留香氣。**
