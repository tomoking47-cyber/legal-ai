# Q. 包丁の安全な扱いと保管について、よくある誤解は？｜世界の質問箱 #380

- 棚：`trend` ／ URL：`/questions/kitchen-knife-safety-and-storage` ／ ステータス：**ドラフト（法務レビュー前・出典未検証）**

包丁の研ぎ方の記事とは別に、「切れる包丁は危ない」「どう保管するか」「子どもにいつから持たせるか」という安全の質問を整理します。日本の家庭の包丁の種類と、消費者庁の事故情報を踏まえます。

## A. 最大の誤解は「切れない包丁のほうが安全」です。切れない包丁は力が要り、滑って手を切る事故の原因になります。安全の基本は「よく切れる包丁を、正しい持ち方と猫の手で、安定したまな板で使う」「洗ったらすぐ乾かして刃を覆って保管」「子どもは大人の見守りで小学校低学年から」です。

## 判断の材料

| 項目 | 内容 |
|---|---|
| 切れ味と安全 | **切れない包丁は力が入り、滑って手を切る**。**よく切れる包丁は少ない力で制御しやすい** |
| 持ち方 | **柄を握り、人差し指を刃の背に添えない（一般家庭では握り持ち）**。**押さえる手は「猫の手」（指を丸めて第一関節で押さえる）** |
| まな板 | **安定した台、濡れ布巾を下に敷いて滑り止め**。**まな板の高さは、腕を伸ばして刃先が届く程度** |
| 洗う | **使ったらすぐ、刃を手前に向けず、スポンジで刃の背側から**。**シンクに放置しない**（見えない刃で手を切る事故の典型） |
| 乾かす・保管 | **すぐ拭いて乾かす**（錆）。**刃を覆う（包丁差し・シース・マグネットは刃を外向きにしない）**。**引き出しに裸で入れない** |
| 子ども | **小学校低学年から、大人が横で**。**子ども用包丁（刃先が丸い）**から。**「猫の手」を最初に教える** |
| 種類 | **三徳（万能）、菜切り、出刃（魚）、柳刃（刺身）、ペティ**。**ステンレスは錆びにくい、鋼はよく切れるが錆びる** |
| 廃棄 | **新聞紙で刃を包み「刃物」と書いて、自治体の分別（不燃・危険物）に** |

- 消費者庁の事故情報では、**台所の切り傷の多くが「洗い物中」「シンクに置いた包丁」「滑ったまな板」**で起きています。
- **食中毒予防**：**生肉・魚を切った包丁は洗剤で洗い、熱湯をかける**（まな板の記事と同じ）。**肉・魚と野菜で包丁を分ける**か、**野菜→肉・魚の順**。
- **銃刀法**：**刃渡り6cm超の刃物を正当な理由なく携帯**することは禁止。**購入した包丁を持ち帰るときは箱・包装のまま**、**アウトドアの持ち出しはケースに入れ、目的を明確に**。

> 【要検証】事故情報は消費者庁の資料、銃刀法の規定は警察庁の資料で確認してください。

## 誤解1｜切れない包丁が安全

**逆です。** **力が入って滑る**のが事故の型。**定期的に研ぐ**（研ぎ方の記事を参照）。

## 誤解2｜シンクに浸けておいて後で洗う

**見えない刃で手を切る事故の典型**。**使ったらすぐ洗って拭く**。

## 誤解3｜子どもには包丁を触らせない

**小学校低学年から、大人の見守りと子ども用包丁で**。**「猫の手」を最初に**。**触らせないほうが、後で扱いを知らない大人になる**という食育の考え方。

## 誤解4｜マグネットの包丁ホルダーは便利で安全

**刃が外向きに露出**する設置は危険。**刃を壁側に、手の届かない高さに**。**子どもがいる家庭は扉付きの包丁差し**。

## 誤解5｜使わない包丁はそのまま捨てる

**新聞紙で厚く包み「刃物」「キケン」と書いて、自治体の分別に**。**収集作業者の怪我を防ぐ**ための日本の共有ルール。
