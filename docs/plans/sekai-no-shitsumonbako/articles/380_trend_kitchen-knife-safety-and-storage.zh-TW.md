# Q. 關於菜刀的安全使用與收納，人們常有哪些誤解？｜Japan Questions #380

- Shelf: `trend` ／ URL: `/zh-tw/trend/kitchen-knife-safety-and-storage` ／ Status: **草稿 — 出處未核實**

與我們那篇談磨刀的文章不同，這一篇回答的是安全問題：「刀太利不是更危險嗎？」「該怎麼收納？」「孩子從幾歲開始可以用？」。內容根據日本家庭常見的刀具種類與消費者廳的事故資料，並附上日本關於攜帶刀具的法律說明。

## A. 最大的誤解是「鈍的刀比較安全」。鈍刀需要用力，容易打滑，是切到手的原因。安全的基本是：「用鋒利的刀，配上正確的握法與『貓爪』手勢，在穩固的砧板上使用」；「洗完立刻擦乾，收納時把刀刃蓋住」；以及「孩子可以從小學低年級開始，由大人在旁看顧」。

## 判斷的依據

| 項目 | 內容 |
|---|---|
| 鋒利與安全 | **鈍刀需要用力，容易打滑，會切到手。** **鋒利的刀幾乎不需要用力，也更好控制** |
| 握法 | **握住刀柄；不要把食指壓在刀背上（一般家庭用普通的握柄方式）。** **另一隻手做「貓爪」（「猫の手」，neko no te）：手指彎曲，用第一指節壓住食材** |
| 砧板 | **要放在穩固的檯面上；下面墊一條濕抹布可防滑。** **合適的高度是：手臂伸直時刀尖剛好構得到砧板** |
| 清洗 | **用完立刻洗，刀刃朝向外側，海綿從刀背那一側擦洗。** **絕不要把刀泡在水槽裡**（典型事故：被看不見的刀刃割傷手） |
| 擦乾與收納 | **立刻擦拭晾乾**（防鏽）。**把刀刃蓋住（刀架、刀鞘；用磁吸刀條時，刀刃絕不可朝外）。** **不要散放在抽屜裡** |
| 孩子 | **從小學低年級（約 6〜8 歲）開始，由大人在旁陪同。** 先從**兒童菜刀（刀尖是圓的）**開始。**先教「貓爪」** |
| 種類 | **三德刀（萬用）、菜切刀（蔬菜）、出刃刀（魚）、柳刃刀（生魚片）、水果刀（小型多用途）。** **不鏽鋼防鏽；碳鋼（「鋼」，hagane）更鋒利但會生鏽** |
| 丟棄 | **用報紙把刀刃包起來，寫上「刃物」（hamono，刀刃），依您所在市町村的不可燃垃圾或危險垃圾規定丟棄** |

- 事故資料（消費者廳的事故資訊資料庫、東京都的「潛藏在廚房裡的危險」驚險經驗調查等）顯示，廚房割傷多報告於**「洗碗時」「因為刀被留在水槽裡」或「砧板滑動時」**。
- **預防食物中毒**：**切完生肉或生魚後，用清潔劑洗刀並淋上熱水**（與我們的砧板文章相同）。**肉／魚與蔬菜分開用不同的刀**，或者**先切蔬菜，再切肉和魚**。
- **《槍砲刀劍類持有等取締法》（「銃刀法」，jūtōhō）第 22 條**：**無正當理由攜帶刃體長度超過 6 cm 的刀具**是被禁止的（**剪刀、折疊刀等依政令在刃體 8 cm 以下時除外**）。**剛買的菜刀請連盒子或包裝一起帶回家**，**帶去戶外使用時請裝在刀套裡，並能說清楚用途**。

> **[待核實]** 事故資料請對照消費者廳的資料，《槍砲刀劍類持有等取締法》的條文請對照警察廳的資料確認。

## 誤解1｜鈍的刀比較安全

**恰恰相反。** **先用力，然後打滑**就是事故的模式。**請定期磨刀**（請參見我們的磨刀文章）。

## 誤解2｜先泡在水槽裡，等一下再洗

**典型事故：被看不見的刀刃割傷手。** **用完立刻洗淨擦乾。**

## 誤解3｜不要讓孩子碰刀

**從小學低年級開始，由大人看顧，用兒童菜刀。** **先教「貓爪」。** 日本的食育觀念認為，**一個從不被允許碰刀的孩子，長大後就是一個不懂得怎麼用刀的大人。**

## 誤解4｜磁吸刀架方便又安全

如果裝成**刀刃外露且朝外**，那就危險了。**刀刃朝牆，裝在孩子構不到的高度。** **有孩子的家庭：選有門的刀架。**

## 誤解5｜不要的刀直接丟進垃圾桶就好

**用報紙厚厚地包起來，寫上「刃物」（刀刃）與「キケン」（危險），再依您所在市町村的分類規定丟棄。** 這是日本共通的規矩，**為的是不讓收垃圾的人受傷。**
