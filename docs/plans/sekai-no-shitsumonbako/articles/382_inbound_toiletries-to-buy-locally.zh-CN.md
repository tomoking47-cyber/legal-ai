# Q. 关于在日本购买洗漱用品，人们常有哪些误解？｜Japan Questions #382

- Shelf: `inbound` ／ URL: `/zh-cn/questions/toiletries-to-buy-locally` ／ Status: **草稿 — 出处未核实**

来日本不需要带半个行李箱的洗漱用品——几乎所有东西在任何便利店或药妆店都能买到，常有旅行装，而且往往更好用。只有少数几样东西确实难买到或与您习惯的不同，那些才值得放进行李。

## A. 常见的误解是，认为日本的洗漱用品会很陌生或难以找到。药妆店备有旅行者需要的一切，标签虽是日文，但从形状和图片就能认出来；酒店也会提供基本用品。值得自带的东西：如果您依赖强效止汗剂，带除臭剂；如果您习惯用导管式卫生棉条，带上它；如果您用特定品牌的隐形眼镜护理液，带上它；以及任何药物（见药品篇）。

## 好买 vs 值得自带

| 在这里买（任何药妆店或便利店） | 日文标签 | 备注 |
|---|---|---|
| 牙刷、牙膏 | 歯ブラシ / 歯磨き粉 | 牙刷**刷头小、刷毛软** |
| 洗发水、护发素、沐浴露 | シャンプー / コンディショナー / ボディソープ | **按压瓶和替换装**；便利店有旅行套装（トラベルセット） |
| 洗面奶、卸妆、化妆水、乳液 | 洗顔 / クレンジング / 化粧水 / 乳液 | 好用又便宜（见护肤品名称篇） |
| 防晒霜 | 日焼け止め | 世界顶级水准；见 SPF/PA 篇 |
| 剃须刀、剃须膏 | カミソリ / シェービング | 一次性剃须刀随处可见 |
| 卫生巾 | 生理用ナプキン | 种类丰富；**卫生棉条（タンポン）有，但品牌较少，多数无导管** |
| 润唇膏、护手霜 | リップクリーム / ハンドクリーム | 便宜、好用 |
| 棉签、化妆棉、纸巾、湿巾 | 綿棒 / コットン / ティッシュ / ウェットティッシュ | 车站常有免费发放的袖珍纸巾 |
| 隐形眼镜护理液 | コンタクト洗浄液 | 常见品牌都有；**您用的特定品牌未必有** |
| 止痛药、感冒药 | 頭痛薬 / 風邪薬 | 非处方药分类；见相关篇 |

| 值得自带 | 原因 |
|---|---|
| **除臭剂／止汗剂** | 日本产品**更温和**（以走珠和喷雾为主，强效膏体很少）。如果您依赖它，请自带 |
| **导管式卫生棉条** | 有售但选择有限；卫生巾占主导 |
| **特定品牌的隐形眼镜护理液或药品** | 品牌不同 |
| **大尺码鞋类／衣物** | 见尺码篇 |
| **适合极粗硬或卷曲头发的强定型产品** | 产品线以直发为主 |

- 便利店销售**一次性旅行装**（洗发水、牙刷套装、剃须刀），价格 **¥100–400**；酒店提供牙刷、剃须刀、梳子和洗发水（见酒店篇）。
- **药妆店连锁**在每条商业街上都有，营业**到 22:00 或更晚**；旅游区的许多店铺有**会说英语的员工和免税柜台**（见药妆店篇）。

> **[待核实]** 商品供应情况基于观察；免税规则请核对国税厅。

## 误解1｜什么都带上，这里什么都不熟悉

**所有基本用品都能买到**，从形状和图片就能辨认，而且往往比家里的质量更高。请针对**您的特定需求**打包，而不是按品类打包。

## 误解2｜日本的除臭剂和西方的止汗剂效果一样

**它更温和。**喷雾和走珠占主导，强效的铝盐膏体很少见。如果这对您很重要，**请自带**。

## 误解3｜女性用品会是个问题

**卫生巾非常好用且随处可买**；卫生棉条有（品牌较少，多为无导管型）。如果您偏好导管式卫生棉条，**请自带**。

## 误解4｜深夜只能靠酒店的洗漱用品

**便利店 24 小时营业**，各种旅行装都有。药妆店也关门很晚。

## 误解5｜买洗漱用品是浪费免税额度

洗漱用品在免税中属于**消耗品**（同日购买 ¥5,000 以上，按现行规则须密封至离境；包装要求将于 2026 年 11 月 1 日结束——见免税篇）。在药妆店大量采购护肤品和防晒霜是很常见的免税购物。
