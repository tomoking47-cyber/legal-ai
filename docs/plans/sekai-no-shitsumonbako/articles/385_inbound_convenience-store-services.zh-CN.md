# Q. 关于日本便利店能做什么，人们常有哪些误解？｜Japan Questions #385

- Shelf: `inbound` ／ URL: `/zh-cn/questions/convenience-store-services` ／ Status: **草稿 — 出处未核实**

食物吸引了所有注意力；但服务才是本地居民一周去便利店好几次的原因。对游客来说，同一个柜台和那几台机器能解决出乎意料多的旅行难题——打印、取现、购票、寄包裹——只要您知道它们存在。

## A. 常见的误解是，认为便利店只是一家商店。它同时还是一台可以用外国卡的 ATM、一个邮政柜台、一台打印机兼扫描仪、一个演唱会和长途大巴的售票点、一个缴费点、一个可以寄行李和退网购商品的包裹收寄点、一个免费厕所，以及热水和 Wi-Fi 的来源。只要知道该站在哪台机器前面，大部分服务不会日语也能用。

## 柜台和机器能做什么

| 服务 | 怎么用 | 备注 |
|---|---|---|
| **ATM（外国卡）** | Seven 银行 ATM（7-Eleven）以及罗森／日本邮政 ATM 接受 **Visa、Mastercard、Plus、Cirrus、银联**；**有英文菜单** | 每次取款手续费 ¥0–220，视卡组织而定（Seven 银行：Visa/Plus 按金额 ¥110/¥220，Mastercard/Cirrus 免费；罗森银行：统一 ¥110），另加您本国银行的费用；单次上限 Seven 银行 ¥100,000，罗森银行 ¥50,000 |
| **多功能复印机** | **从 U 盘或手机打印**（应用或二维码上传）、**复印、扫描到 U 盘、打印照片**；**打印登机牌和电子票** | 彩色 A4 约 ¥50–60；**通过 “netprint”／“PrintSmash” 应用打印 PDF** |
| **购票终端（Loppi／多功能复印机）** | **演唱会、主题公园、博物馆、高速大巴、部分体育赛事门票**；在柜台付款 | 部分需要日本手机号 |
| **包裹** | **寄送宅急便（TA-Q-BIN）行李托运**；**寄回网购退货**；**领取**寄到店里的包裹 | 见行李篇 |
| **缴费** | 水电煤账单、税款、带条形码单据的网购订单——**在柜台付现金** | 主要是居民使用 |
| **邮政** | **邮票和明信片**；许多店外有**邮筒** | 不办理国际包裹（请去邮局） |
| **厕所** | 免费、干净、通常可用（**先问一句：「トイレいいですか？」toire ii desu ka?**） | 部分市中心店铺有限制 |
| **热水、微波炉、餐具** | 供店内购买的方便面和便当使用 | 向柜台索取 |
| **Wi-Fi** | 注册后免费（各连锁的应用或邮箱） | 时好时坏，但有用 |
| **证件照** | 部分多功能复印机可打印**护照规格照片** | 用于在留卡更新等 |
| **店内用餐区** | 有桌椅；使用则**税率为 10% 而非 8%** | 见消费税篇 |

- 日本约有 **56,000 家便利店**；**仅 Seven 银行就运营着约 28,000 台 ATM（2025 年）**，是全国最可靠的外国卡取现渠道（见现金篇）。
- **用手机打印文件**：上传到该连锁的打印服务（7-Eleven 的 “netprint”，全家／罗森的 “PrintSmash” 或 “network print”），获得一个编号，在机器上输入——**除了英文菜单外不需要任何日语**。
- 柜台员工**不能**兑换外币，不是所有店铺都卖游客用 SIM 卡，也无法协助处理店外的失物。

> **[待核实]** ATM 手续费和限额请核对 Seven 银行／罗森银行；服务的有无因店铺和连锁而异。

## 误解1｜它只是一家商店

**ATM、打印机、购票机和包裹柜台**才是居民去便利店的原因。游客最需要的是 **ATM 和打印机**。

## 误解2｜不会日语就用不了复印机

**每台多功能复印机都有英文菜单。**通过该连锁的应用从手机打印，五分钟就能搞定。

## 误解3｜ATM 只接受日本的卡

**Seven 银行和日本邮政／罗森的 ATM 接受大多数外国卡**，有英文界面，几乎全天可用。您本国银行的手续费才是更大的成本。

## 误解4｜要把行李提前寄走得去邮局

**任何设有大和运输（黑猫宅急便）柜台的便利店**都能收下一个行李箱，次日送达酒店或机场。填好单据即可（店员会帮忙）。

## 误解5｜厕所只给顾客用

大多数店铺允许使用；**先问一句是礼貌**，买一瓶饮料是自然的答谢方式。**东京市中心的部分店铺会把厕所锁上**——留意标识。
