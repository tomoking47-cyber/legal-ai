# Q. 關於日本便利商店能做什麼，人們常有哪些誤解？｜Japan Questions #385

- Shelf: `inbound` ／ URL: `/zh-tw/questions/convenience-store-services` ／ Status: **草稿 — 出處未核實**

食物吸引了所有目光；但服務才是在地居民一週上便利商店好幾次的原因。對旅客來說，同一個櫃檯和那幾台機器能解決出乎意料多的旅行難題——列印、領現金、買票、寄包裹——只要您知道它們存在。

## A. 常見的誤解是，以為便利商店只是一家商店。它同時還是一台可用外國卡的 ATM、一個郵政櫃檯、一台印表機兼掃描器、一個演唱會與巴士的售票點、一個繳費點、一個可寄行李和退網購商品的包裹收寄點、一間免費廁所，以及熱水和 Wi-Fi 的來源。只要知道該站在哪台機器前面，大部分服務不會日語也能用。

## 櫃檯與機器能做什麼

| 服務 | 怎麼用 | 備註 |
|---|---|---|
| **ATM（外國卡）** | Seven 銀行 ATM（7-Eleven）以及 Lawson／日本郵政 ATM 接受 **Visa、Mastercard、Plus、Cirrus、銀聯**；**有英文選單** | 每次提款手續費 ¥0–220，依卡組織而異（Seven 銀行：Visa/Plus 依金額 ¥110/¥220，Mastercard/Cirrus 免費；Lawson 銀行：一律 ¥110），另加您本國銀行的費用；單次上限 Seven 銀行 ¥100,000，Lawson 銀行 ¥50,000 |
| **多功能影印機** | **從 USB 隨身碟或手機列印**（app 或 QR code 上傳）、**影印、掃描到 USB、列印照片**；**列印登機證與電子票券** | 彩色 A4 約 ¥50–60；**透過「netprint」／「PrintSmash」app 列印 PDF** |
| **售票終端機（Loppi／多功能影印機）** | **演唱會、主題樂園、博物館、高速巴士、部分運動賽事門票**；到櫃檯付款 | 部分需要日本手機號碼 |
| **包裹** | **寄送宅急便（TA-Q-BIN）行李託運**；**寄回網購退貨**；**領取**寄到店裡的包裹 | 見行李篇 |
| **繳費** | 水電瓦斯帳單、稅金、附條碼單據的網購訂單——**在櫃檯付現** | 主要是居民使用 |
| **郵政** | **郵票與明信片**；許多店外有**郵筒** | 不受理國際包裹（請到郵局） |
| **廁所** | 免費、乾淨、通常可用（**先問一句：「トイレいいですか？」toire ii desu ka?**） | 部分市中心店家有限制 |
| **熱水、微波爐、餐具** | 供店內購買的泡麵和便當使用 | 向櫃檯索取 |
| **Wi-Fi** | 註冊後免費（各連鎖的 app 或 email） | 時好時壞，但有用 |
| **證件照** | 部分多功能影印機可列印**護照規格照片** | 用於在留卡更新等 |
| **內用區** | 有桌椅；使用則**稅率為 10% 而非 8%** | 見消費稅篇 |

- 日本約有 **56,000 家便利商店**；**光是 Seven 銀行就營運約 28,000 台 ATM（2025 年）**，是全國最可靠的外國卡提款管道（見現金篇）。
- **用手機列印文件**：上傳到該連鎖的列印服務（7-Eleven 的「netprint」，全家／Lawson 的「PrintSmash」或「network print」），取得一組代碼，在機器上輸入——**除了英文選單外不需要任何日語**。
- 櫃檯店員**不能**兌換外幣，並非所有店家都賣旅客用 SIM 卡，也無法協助處理店外的失物。

> **[待核實]** ATM 手續費與限額請核對 Seven 銀行／Lawson 銀行；服務有無因店家與連鎖而異。

## 誤解1｜它只是一家商店

**ATM、印表機、售票機和包裹櫃檯**才是居民上門的原因。旅客最需要的是 **ATM 和印表機**。

## 誤解2｜不會日語就用不了影印機

**每台多功能影印機都有英文選單。**透過該連鎖的 app 從手機列印，五分鐘就能搞定。

## 誤解3｜ATM 只收日本的卡

**Seven 銀行和日本郵政／Lawson 的 ATM 接受大多數外國卡**，有英文介面，幾乎全天可用。您本國銀行的手續費才是更大的成本。

## 誤解4｜要把行李先寄出去得去郵局

**任何設有大和運輸（黑貓宅急便）櫃檯的便利商店**都能收下一個行李箱，隔日送達飯店或機場。填好單子即可（店員會幫忙）。

## 誤解5｜廁所只給顧客用

大多數店家允許使用；**先問一句是禮貌**，買一瓶飲料是自然的答謝方式。**東京市中心的部分店家會把廁所鎖上**——留意標示。
