# Q. 关于日本的地址和找地方，人们常有哪些误解？｜Japan Questions #386

- Shelf: `inbound` ／ URL: `/zh-cn/questions/japanese-addresses-and-finding-places` ／ Status: **草稿 — 出处未核实**

"在第二家便利店左转"在日本不是玩笑：大多数街道没有名字，地址描述的是一片区域、一个街区，以及一个按登记顺序而非位置排列的建筑编号。地图解决了大部分问题；剩下的只需要掌握一个概念。

## A. 最常见的误解是认为日本地址会告诉你建筑在某条街的哪个位置。它根本不写街名。它由大到小依次写出：都道府县 → 市或区 → 町（chō）→ 丁目（chōme）→ 番（ban）→ 号（gō）。丁目有编号，街区内的建筑按登记顺序编号，最后一个数字就是你要在建筑和电线杆上的小金属牌上寻找的号码。

## 读懂地址

| 要素 | 示例（由大到小书写） | 含义 |
|---|---|---|
| 都道府县 | **東京都** Tokyo-to | — |
| 市／区 | **千代田区** Chiyoda-ku | 区（东京23区）或市（-shi） |
| 町 | **丸の内** Marunouchi | 一片有名字的区域，不是街道 |
| **丁目（chōme）** | **1丁目** 1-chōme | 町内编号的街区组 |
| **番（ban）** | **9番** 9-ban | 一个街区或子街区 |
| **号（gō）** | **1号** 1-gō | 建筑；编号**按登记顺序绕街区排列**，而不是线性位置 |
| 楼名与房间号 | **〇〇ビル 3F / 302** | 公寓和办公室必不可少 |
| 简写 | **丸の内1-9-1** | 丁目-番-号用连字符连写；**这是粘贴到地图应用里最有用的字符串** |

- **邮政编码（〒 七位数，例如 100-0005）**标识町；在地图应用里输入邮编，可以把搜索范围缩小到几个街区。
- **街区表示牌「街区表示板」**——建筑和电线杆上的小型双色金属牌（常见蓝色或绿色，颜色因市町村而异）——标示**丁目-番**（例如 1-9）；**住居番号牌「住居番号表示板」**标示号。在街角与视线平齐的高度找。
- **街道名**只存在于少数主要道路（青山通、表参道）和**京都**——京都使用**以路口为基准的网格**（例如「四条河原町」），并有自己的方位后缀（上ル／下ル = 该路口以北／以南）。
- **地标导航**才是居民的做法：附有地区地图的派出所「交番」、便利店、车站和出口。**车站出口编号**（例如新宿「西口」、东京地铁「A5出口」）是城市中最重要的导航单位。

> **[待核实]** 地址制度请向总务省（総務省）核实（住居表示制度）；邮政编码请向日本邮政（日本郵便）核实。

## 误解1｜号码代表沿街走了多远

**街区内的建筑按登记顺序绕街区编号**，所以3号可能紧挨着10号。先找到街区（丁目-番），再绕着它走一圈看门牌。

## 误解2｜把罗马字地址粘贴到地图里

**请粘贴日文**，或至少粘贴**带町名的连字符数字**；罗马字拼写各不相同，而地图应用对日文的处理最好。**邮编**是最快的检索键。

## 误解3｜向路人打听街名

根本没有街名可问。**请问地标**（"セブンイレブンの近くですか？"——在7-Eleven附近吗？）或直接展示地图上的定位点。**「交番」派出所的职责就包括指路**，并且备有地区地图。

## 误解4｜车站就是一个地点

**大型车站有几十个出口**，相隔数百米。地址或预订信息中的**出口编号**（例如「B2出口」）能帮你省下在地下迷路的十分钟。

## 误解5｜京都和东京一样

**京都使用网格**：地址写的是一个路口和一个方位（其北／南／东／西），再加上历史街区名。当地人靠街道网格导航；编号系统是次要的。
