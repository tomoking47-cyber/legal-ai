# Q. 關於日本的地址與找路，人們常有哪些誤解？｜Japan Questions #386

- Shelf: `inbound` ／ URL: `/zh-tw/questions/japanese-addresses-and-finding-places` ／ Status: **草稿 — 出處未核實**

「在第二家便利商店左轉」在日本不是玩笑：大多數街道沒有名字，地址描述的是一片區域、一個街區，以及一個依登記順序而非位置排列的建物編號。地圖解決了大部分問題；剩下的只需要掌握一個概念。

## A. 最常見的誤解是以為日本地址會告訴你建物在某條街上的位置。它根本不寫街名。它由大到小依序寫出：都道府縣 → 市或區 → 町（chō）→ 丁目（chōme）→ 番（ban）→ 號（gō）。丁目有編號，街區內的建物依登記順序編號，最後一個數字就是你要在建物和電線桿上的小金屬牌上尋找的號碼。

## 讀懂地址

| 要素 | 範例（由大到小書寫） | 含義 |
|---|---|---|
| 都道府縣 | **東京都** Tokyo-to | — |
| 市／區 | **千代田区** Chiyoda-ku | 區（東京23區）或市（-shi） |
| 町 | **丸の内** Marunouchi | 一片有名字的區域，不是街道 |
| **丁目（chōme）** | **1丁目** 1-chōme | 町內有編號的街區群 |
| **番（ban）** | **9番** 9-ban | 一個街區或子街區 |
| **號（gō）** | **1号** 1-gō | 建物；編號**依登記順序繞街區排列**，而非直線位置 |
| 大樓名稱與房號 | **〇〇ビル 3F / 302** | 公寓與辦公室不可或缺 |
| 簡寫 | **丸の内1-9-1** | 丁目-番-號以連字號連寫；**貼進地圖 app 最好用的字串** |

- **郵遞區號（〒 七位數，例如 100-0005）**對應町；在地圖 app 輸入郵遞區號，可將搜尋範圍縮小到幾個街區。
- **街區標示牌「街区表示板」**——建物和電線桿上的小型雙色金屬牌（常見藍色或綠色，顏色依市町村而異）——標示**丁目-番**（例如 1-9）；**住居番號牌「住居番号表示板」**標示號。在街角視線高度的位置找。
- **街道名**只存在於少數主要道路（青山通、表參道）與**京都**——京都採用**以路口為基準的棋盤格**（例如「四条河原町」），並有自己的方位後綴（上ル／下ル = 該路口以北／以南）。
- **靠地標找路**才是居民的做法：附有地區地圖的派出所「交番」、便利商店、車站和出口。**車站出口編號**（例如新宿「西口」、東京地下鐵「A5出口」）是城市裡最重要的導航單位。

> **[待核實]** 地址制度請向總務省（総務省）核實（住居表示制度）；郵遞區號請向日本郵政（日本郵便）核實。

## 誤解1｜號碼代表沿街走了多遠

**街區內的建物依登記順序繞街區編號**，所以3號可能就在10號旁邊。先找到街區（丁目-番），再繞著它走一圈看門牌。

## 誤解2｜把羅馬拼音地址貼進地圖

**請貼日文**，或至少貼**帶町名的連字號數字**；羅馬拼音寫法各異，而地圖 app 對日文的處理最好。**郵遞區號**是最快的查詢鍵。

## 誤解3｜向路人問街名

根本沒有街名可問。**請問地標**（「セブンイレブンの近くですか？」——在 7-Eleven 附近嗎？）或直接秀出地圖上的定位點。**「交番」派出所本來就負責指路**，並備有地區地圖。

## 誤解4｜車站就是一個地點

**大型車站有數十個出口**，彼此相隔數百公尺。地址或訂位資訊中的**出口編號**（例如「B2出口」）能幫你省下在地下迷路的十分鐘。

## 誤解5｜京都和東京一樣

**京都採用棋盤格**：地址寫的是一個路口和一個方位（其北／南／東／西），再加上歷史街區名。當地人靠街道棋盤格找路；編號系統是次要的。
