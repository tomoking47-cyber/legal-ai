# Q. 關於在日本拍照的禮儀，人們常有哪些誤解？｜Japan Questions #390

- Shelf: `inbound` ／ URL: `/zh-tw/questions/photography-etiquette` ／ Status: **草稿 — 出處未核實**

日本是世界上被拍攝得最多的國家之一；而自 2019 年前後起，它也是在拍照造成問題的地方限制最積極的國家之一——藝伎街區、部分寺院、車站月台，以及任何以人為拍攝對象的場合。這些規則是法律、告示牌與禮節的混合體。

## A. 最常見的誤解是把「公共空間」等同於「可以隨便拍」。日本關於隱私與肖像權的判例，使得未經同意拍攝可辨識的個人構成民事風險；一些地點如今張貼了附罰則告示的禁止規定（祇園的私有小巷：告示牌警告收取 ¥10,000，由居民協議會張貼，而非法律規定）；實際的通行做法是拍地方，不拍人。拍任何人之前先徵得同意，看到「撮影禁止」(禁止拍攝) 的告示就把手機收起來，絕不要為了取景而踏入軌道、私有小巷或庭園。

## 界線在哪裡

| 情形 | 規則或慣例 |
|---|---|
| **公共場所中的人** | **民事判例下的肖像權（肖像権）**：可辨識的個人有權提出異議；**請先詢問**，特寫、兒童、店員以及藝伎（芸妓 geiko）／舞伎（舞妓 maiko）尤其如此 |
| **祇園（京都）** | **花見小路兩側的私有小巷自 2024 年起謝絕遊客進入**；**自 2019 年起禁止未經同意拍攝藝伎與舞伎**，告示牌註明 **¥10,000 罰金** |
| **寺院與神社** | 院內通常可拍；**殿內、佛像與祭壇常為「撮影禁止」**；多數場所**禁止閃光燈、禁止腳架**；**禁止無人機** |
| **美術館、博物館** | 許多館允許**不開閃光燈**拍攝常設展；特展往往不可；請留意圖示 |
| **車站月台** | **拍攝列車是允許的，但黃線就是界線**；**禁止對駕駛使用閃光燈**；在與鐵道迷有關的事件之後，JR 張貼了禮儀守則 |
| **餐廳與商店** | 食物可以；**店員與其他客人不可**；部分壽司吧檯與酒吧為維護氣氛而**禁止拍照** |
| **溫泉與更衣室** | **絕對不可攜帶相機或手機**——被視為偷拍（屬刑事問題） |
| **無人機** | **100 g 以上的無人機必須登錄（自 2022 年 6 月起）；依據航空法，在人口集中（DID）地區上空、夜間或在人群上空飛行，需取得國土交通省（MLIT）許可**；幾乎所有寺院、公園與祭典都禁飛 |
| **私人土地** | **不要為了拍照而進入庭園、門口或田地**；在旅客損壞農作物之後，日本鄉間已張貼告示 |

- **祇園協議會 2019 年的告示牌**，起因是舞伎受到騷擾（觸摸和服、擋路）；**鎌倉、富士河口湖町與美瑛**在人潮與擅闖問題之後增加了限制或撤除了觀景點。
- **拍攝明顯作為主體的陌生人**可能侵害肖像權；**沒有特定某人的人群場景**一般沒有問題。界定它的是**法院判決（依據憲法第 13 條與民法的侵權行為規定）**；並沒有單一的成文法條。
- **在裙下或廁所內拍攝或錄影**，依據 2023 年 7 月 13 日起施行的偷拍處罰法（性的姿態等撮影罪），屬於**刑事犯罪**，最高可處 3 年有期徒刑或最高 ¥300 萬罰金。

> **[待核實]** 祇園的規定請向祇園町的居民協議會與京都市核實；2023 年的偷拍處罰法請向法務省核實；無人機規定請向國土交通省核實。

## 誤解1｜在公共場所，任何人都可以拍

對於作為主體的可辨識個人，**日本的肖像權判例並非如此**。**先問；被拒絕就停下。**兒童與工作人員尤其如此。

## 誤解2｜藝伎和舞伎是表演者，拍她們理所當然

她們是**正要前往工作場合的職業從業者**，而祇園已**禁止未經許可的拍攝**並處以罰金，如今更關閉了私有小巷。**只在有組織的活動上或徵得同意後**拍攝她們。

## 誤解3｜沒有告示就等於可以拍

**在寺院殿堂內與美術館內，請預設為不可**，除非有告示允許。在藝術品與祭壇附近，閃光燈幾乎一律禁止。

## 誤解4｜為了最好的畫面，跨過繩索也值得

**擅闖庭園、田地以及越過月台黃線**，正是近年這些禁令與觀景點關閉的導火線。繩索就是畫框。

## 誤解5｜在溫泉更衣室隨手拍一張沒什麼大不了

**這屬於刑事問題**，無論動機為何都被視為偷拍。**手機請留在置物櫃裡**；有些浴場乾脆禁止把手機帶進更衣室。
