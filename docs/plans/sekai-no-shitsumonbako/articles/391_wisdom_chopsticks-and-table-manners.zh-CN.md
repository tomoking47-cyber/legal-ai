# Q. 关于筷子与日本餐桌礼仪，人们常有哪些误解？｜Japanese Everyday Wisdom #391

- Shelf: `wisdom` ／ URL: `/zh-cn/wisdom/chopsticks-and-table-manners` ／ Status: **草稿 — 出处未核实**

筷子是日本餐桌礼仪中访客最担心、却最少出错的部分——没有人会在意握法笨拙。真正重要的规则关乎筷子所代表的含义，而不是怎么拿：几个与死亡或贪心相关的动作，以及开饭和饭后的固定用语。

## A. 常见的误解是把功夫放在握筷子的技巧上。礼仪其实在于少数几条禁忌——把筷子竖插在米饭里（供奉亡者）、用筷子把食物直接夹给别人的筷子（葬礼仪式）、用筷子指人、戳食物、舔筷子、在菜上方犹疑不定——以及一餐前后的"框架"：饭前说「いただきます」（itadakimasu），饭后说「ごちそうさま」（gochisōsama），碗端到嘴边，汤直接从碗里喝。学会这些，握法怎样都可以原谅。

## 禁忌（「嫌い箸」，kirai-bashi）及其原因

| 不要 | 名称 | 原因 |
|---|---|---|
| **把筷子竖插在米饭碗里** | 立て箸（tate-bashi） | 这是葬礼上**供奉亡者**的方式 |
| **把食物从自己的筷子直接递到别人的筷子上** | 拾い箸／合わせ箸（hiroi-bashi / awase-bashi） | 模仿了葬礼上**传递火化后骨骸**的仪式。请放到盘子上 |
| 用筷子指人或指菜 | 指し箸（sashi-bashi） | 失礼 |
| 用筷子戳食物 | 突き箸（tsuki-bashi） | 幼稚 |
| 在菜上方犹疑不决 | 迷い箸（mayoi-bashi） | 贪心 |
| 舔或吮筷子 | ねぶり箸（neburi-bashi） | — |
| 把筷子横搭在碗上 | 渡し箸（watashi-bashi） | 表示"我吃完了" |
| 用筷子把盘子拉向自己 | 寄せ箸（yose-bashi） | — |
| 当作串签或鼓棒使用 | — | — |
| 把一次性筷子互相搓 | — | 暗示店家给的是便宜筷子 |

## 一餐的"框架"

| 时刻 | 做法 |
|---|---|
| 饭前 | **「いただきます」（itadakimasu，我领受了）**——常伴随微微低头；在家里，大家等齐了一起开始 |
| 用餐 | **饭碗拿在左手，端到胸前**；汤碗端到嘴边——**碗可以端起，盘子不端** |
| 汤 | **直接从碗里喝**；用筷子夹取汤里的料 |
| 共享菜盘 | 如有提供，使用**公筷（「取り箸」，toribashi）**；否则，**把自己的筷子倒过来用**是老一套做法，如今不再提倡——直接用自己的筷子即可 |
| 米饭 | 不要把酱油倒在白米饭上；不要剩饭粒（把饭吃完） |
| 寿司 | 用手或用筷子都可以；**蘸鱼的一面，不要蘸米饭**；一口吃掉 |
| 面 | **吸面出声是正常的**；有降温和带入空气的作用 |
| 饭后 | 筷子**放回筷架（「箸置き」，hashioki）或放回筷套**，摆放平行；对做饭的人或店员说**「ごちそうさまでした」（gochisōsama deshita）** |

- 日本每年使用约 **200 亿双一次性筷子**（约 97% 为进口）；家庭中通常使用可重复使用的筷子，每人有**自己专用的一双**。
- **孩子大约从 3 岁起**用训练筷学习；**握在靠近筷尖的位置**被认为不好看，**握在离顶端约三分之一处**是标准握法。

## 误解1｜技巧不好会得罪人

**没有人会因为握法笨拙而不快。** 让人皱眉的是把筷子竖插在米饭里，或用筷子直接把食物递给别人的筷子——因为它们所指向的含义。

## 误解2｜用筷子递食物给别人是好意

它**模仿了葬礼上传递骨骸的仪式**。请把那一块放到对方的盘子上。

## 误解3｜端起碗不礼貌

**碗本来就是要端起来的**——米饭和汤都端到嘴边。**盘子留在桌上。** 弯下身子凑近碗吃才是失礼的做法。

## 误解4｜从共享菜盘取菜时要把筷子倒过来

**这是旧时的建议，如今不再提倡**（你手握的那一端也并不干净）。如有**公筷**就用公筷；否则直接用自己的筷子，不必多虑。

## 误解5｜「いただきます」是祈祷

它是**对所有让这一餐得以成就的人与物的感谢**——农民、做饭的人、成为食材的动植物。不带宗教色彩；每个人都会说，在餐馆里也会轻声说。
