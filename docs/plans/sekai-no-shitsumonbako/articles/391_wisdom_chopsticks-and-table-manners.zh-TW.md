# Q. 關於筷子與日本餐桌禮儀，大家常有哪些誤解？｜Japanese Everyday Wisdom #391

- Shelf: `wisdom` ／ URL: `/zh-tw/wisdom/chopsticks-and-table-manners` ／ Status: **草稿 — 出處未核實**

筷子是日本餐桌禮儀中訪客最擔心、卻最少出錯的部分——沒有人會在意握法笨拙。真正重要的規則關乎筷子所代表的含意，而不是怎麼拿：幾個與死亡或貪心有關的動作，以及開飯和飯後的固定用語。

## A. 常見的誤解是把功夫放在握筷子的技巧上。禮儀其實在於少數幾條禁忌——把筷子直插在白飯裡（供奉亡者）、用筷子把食物直接夾給別人的筷子（喪禮儀式）、用筷子指人、戳食物、舔筷子、在菜上方猶疑不定——以及一餐前後的「框架」：飯前說「いただきます」（itadakimasu），飯後說「ごちそうさま」（gochisōsama），碗端到嘴邊，湯直接就著碗喝。學會這些，握法怎樣都可以被原諒。

## 禁忌（「嫌い箸」，kirai-bashi）及其原因

| 不要 | 名稱 | 原因 |
|---|---|---|
| **把筷子直插在飯碗裡** | 立て箸（tate-bashi） | 這是喪禮上**供奉亡者**的方式 |
| **把食物從自己的筷子直接遞到別人的筷子上** | 拾い箸／合わせ箸（hiroi-bashi / awase-bashi） | 模仿了喪禮上**傳遞火化後骨骸**的儀式。請放到盤子上 |
| 用筷子指人或指菜 | 指し箸（sashi-bashi） | 失禮 |
| 用筷子戳食物 | 突き箸（tsuki-bashi） | 幼稚 |
| 在菜上方猶疑不決 | 迷い箸（mayoi-bashi） | 貪心 |
| 舔或吮筷子 | ねぶり箸（neburi-bashi） | — |
| 把筷子橫放在碗上 | 渡し箸（watashi-bashi） | 表示「我吃完了」 |
| 用筷子把盤子拉向自己 | 寄せ箸（yose-bashi） | — |
| 當成串籤或鼓棒使用 | — | — |
| 把免洗筷互相搓 | — | 暗示店家給的是便宜筷子 |

## 一餐的「框架」

| 時刻 | 做法 |
|---|---|
| 飯前 | **「いただきます」（itadakimasu，我領受了）**——常伴隨微微點頭；在家裡，大家等到齊了一起開始 |
| 用餐 | **飯碗拿在左手，端到胸前**；湯碗端到嘴邊——**碗可以端起，盤子不端** |
| 湯 | **直接就著碗喝**；用筷子夾取湯裡的料 |
| 共享菜盤 | 如有提供，使用**公筷（「取り箸」，toribashi）**；否則，**把自己的筷子倒過來用**是老派做法，如今已不鼓勵——直接用自己的筷子即可 |
| 白飯 | 不要把醬油倒在白飯上；不要剩飯粒（把飯吃完） |
| 壽司 | 用手或用筷子都可以；**沾魚的那一面，不要沾飯**；一口吃掉 |
| 麵 | **吸麵出聲是正常的**；有降溫和帶入空氣的作用 |
| 飯後 | 筷子**放回筷架（「箸置き」，hashioki）或放回筷套**，擺放平行；對做菜的人或店員說**「ごちそうさまでした」（gochisōsama deshita）** |

- 日本每年使用約 **200 億雙免洗筷**（約 97% 為進口）；家庭中通常使用可重複使用的筷子，每人有**自己專用的一雙**。
- **小孩大約從 3 歲起**用學習筷練習；**握在靠近筷尖的位置**被認為不好看，**握在離頂端約三分之一處**是標準握法。

> **[待核實]** 消耗量數據請對照林野廳的木材利用統計核實；禮儀部分為約定俗成。

## 誤解1｜技巧不好會得罪人

**沒有人會因為握法笨拙而不快。** 讓人皺眉的是把筷子直插在白飯裡，或用筷子直接把食物遞給別人的筷子——因為它們所指向的含意。

## 誤解2｜用筷子遞食物給別人是好意

它**模仿了喪禮上傳遞骨骸的儀式**。請把那一塊放到對方的盤子上。

## 誤解3｜端起碗不禮貌

**碗本來就是要端起來的**——白飯和湯都端到嘴邊。**盤子留在桌上。** 彎下身子湊近碗吃才是失禮的做法。

## 誤解4｜從共享菜盤夾菜時要把筷子倒過來

**這是舊時的建議，如今已不鼓勵**（你手握的那一端也並不乾淨）。如有**公筷**就用公筷；否則直接用自己的筷子，不必多慮。

## 誤解5｜「いただきます」是祈禱

它是**對所有讓這一餐得以成就的人與物的感謝**——農民、做菜的人、成為食材的動植物。不帶宗教色彩；每個人都會說，在餐廳裡也會輕聲說。
