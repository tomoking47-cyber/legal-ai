# Q. 关于日本的家庭浴缸（お風呂），人们常有哪些误解？｜Japanese Everyday Wisdom #392

- Shelf: `wisdom` ／ URL: `/zh-cn/wisdom/the-home-bath-ofuro` ／ Status: **草稿 — 出处未核实**

日本的浴室围绕一个世界其他地方并不共有的理念来设计：浴缸是用来泡的，不是用来洗的；一缸热水供全家人依次使用。理解了这一点，浴室的布局、设备和礼仪就都说得通了。

## A. 常见的误解是把日本的浴缸当作浴室里的一个普通浴缸。它是一个泡澡用的浴缸——深而短，水温保持在 40°C 以上——设在一个可以淋湿的房间里，你要先在浴缸外洗净身体，这样水才能为下一个人保持干净，并可再用于洗衣。马桶在另一个单独的房间里。现代设备会自动加热和注水，浴缸有盖子，全家人在同一个晚上按顺序入浴。

## 它是怎么运作的

| 要素 | 详情 |
|---|---|
| **布局** | **地面有排水口的湿区（浴室）**；**浴缸**靠一面墙；**花洒和水龙头位置较低**，配有小凳；**更衣区**在外面；**马桶在独立的房间** |
| **浴缸** | **深（约 55–60 cm）而短**；屈膝坐下，水到肩膀。容量**约 200 L** |
| **水温** | 通常为 **40–42°C**；对老年人的安全指引是 **41°C 以下、10 分钟** |
| **顺序** | **在浴缸外彻底洗净并冲干净**（小凳、手持花洒）→ **泡澡** → 出来，不必再把浴缸水冲掉 |
| **家庭顺序** | 传统上父亲／客人先，然后是孩子，最后是烧水的人；如今是**谁准备好了谁先**；水是**共用的，不重新放** |
| **盖子** | 在两人入浴之间和过夜时保温（供洗衣再利用——见相关文章） |
| **控制面板** | 一键**自动注水和加热**（「追い焚き」，oidaki，再加热）；放好水时语音提示；**定时器**可在回家时让浴缸准备好 |
| **清洁** | 每天快速冲洗；**霉菌是大敌**：入浴时及之后 1–2 小时开着排风扇；**用刮水器刮墙**；每周刷洗一次 |

- **约 95% 的日本家庭有浴缸**；**大多数人每天入浴**，在晚上；**平均一缸水约 200 L**，**热水是日本家庭能源用途中最大的一项——约 29%，高于取暖的约 26%**（资源能源厅）。
- **入浴事故**：据估计每年约有 **19,000 人**在浴缸内或浴室周围死亡，大多是**冬季的老年人**，原因是温差冲击和过热；指引是**给更衣室加温、41°C 以下、10 分钟、告知家人**（见入浴水温的文章）。
- **浴缸水再利用**于洗衣，以及作为**应急用水**（地震后 200 L 可用于冲马桶）的角色，是浴缸水到下次入浴前不排掉的原因。

> **[待核实]** 浴缸拥有率和入浴习惯请对照住宅·土地统计调查及行业调查核实；事故估计数请对照消费者厅核实。

## 误解1｜在浴缸里洗身体

**千万不要。** 在浴缸**外**用手持花洒和小凳洗净，然后再泡。浴缸里的水是共用的，应保持干净。

## 误解2｜每个人都重新放一缸水

**一缸水供全家**在同一个晚上使用，靠盖子和再加热功能保温。用一次就排掉既浪费又少见。

## 误解3｜马桶在浴室里

几乎所有日本家庭都是**分开的房间**（小公寓和商务酒店里的整体浴室是例外）。湿区只用于入浴。

## 误解4｜越热越好

**42°C 以上加上长时间泡澡，正是入浴死亡事故的典型模式。** 40–41°C、10 分钟，冬天先给更衣室加温。

## 误解5｜泡澡是可以省掉的奢侈

对大多数家庭来说，晚上的泡澡是**每天的"重启"**：为入睡带来温暖（见入浴时间的文章）、家人相处的时间，以及 200 L 的储备用水。省掉它才会让人觉得是种煎熬。
