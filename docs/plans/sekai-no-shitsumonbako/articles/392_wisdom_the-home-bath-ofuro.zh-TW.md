# Q. 關於日本的家庭浴缸（お風呂），大家常有哪些誤解？｜Japanese Everyday Wisdom #392

- Shelf: `wisdom` ／ URL: `/zh-tw/wisdom/the-home-bath-ofuro` ／ Status: **草稿 — 出處未核實**

日本的浴室圍繞著一個世界其他地方並不共有的理念來設計：浴缸是用來泡的，不是用來洗的；一缸熱水供全家人依序使用。理解了這一點，浴室的格局、設備和禮儀就都說得通了。

## A. 常見的誤解是把日本的浴缸當成浴室裡的一個普通浴缸。它是一個泡澡用的浴缸——深而短，水溫保持在 40°C 以上——設在一個可以淋濕的空間裡，你要先在浴缸外洗淨身體，這樣水才能為下一個人保持乾淨，並可再用於洗衣。馬桶在另一個獨立的房間。現代設備會自動加熱和注水，浴缸有蓋子，全家人在同一個晚上依序入浴。

## 它是怎麼運作的

| 要素 | 詳情 |
|---|---|
| **格局** | **地面有排水孔的濕區（浴室）**；**浴缸**靠一面牆；**蓮蓬頭和水龍頭位置較低**，配有小板凳；**更衣區**在外面；**馬桶在獨立的房間** |
| **浴缸** | **深（約 55–60 cm）而短**；屈膝坐下，水到肩膀。容量**約 200 L** |
| **水溫** | 通常為 **40–42°C**；對年長者的安全指引是 **41°C 以下、10 分鐘** |
| **順序** | **在浴缸外徹底洗淨並沖乾淨**（小板凳、手持蓮蓬頭）→ **泡澡** → 出來，不必再把浴缸水沖掉 |
| **家庭順序** | 傳統上父親／客人先，然後是小孩，最後是燒水的人；如今是**誰準備好了誰先**；水是**共用的，不重新放** |
| **蓋子** | 在兩人入浴之間和過夜時保溫（供洗衣再利用——見相關文章） |
| **控制面板** | 一鍵**自動注水和加熱**（「追い焚き」，oidaki，再加熱）；放好水時語音提示；**定時器**可在回家時讓浴缸準備好 |
| **清潔** | 每天快速沖洗；**黴菌是大敵**：入浴時及之後 1–2 小時開著抽風機；**用刮刀刮牆**；每週刷洗一次 |

- **約 95% 的日本家庭有浴缸**；**大多數人每天入浴**，在晚上；**平均一缸水約 200 L**，**熱水是日本家庭能源用途中最大的一項——約 29%，高於暖房的約 26%**（資源能源廳）。
- **入浴事故**：據估計每年約有 **19,000 人**在浴缸內或浴室周圍死亡，大多是**冬季的年長者**，原因是溫差衝擊和過熱；指引是**先為更衣室加溫、41°C 以下、10 分鐘、告知家人**（見入浴水溫的文章）。
- **浴缸水再利用**於洗衣，以及作為**緊急用水**（地震後 200 L 可用來沖馬桶）的角色，是浴缸水到下次入浴前不排掉的原因。

> **[待核實]** 浴缸擁有率和入浴習慣請對照住宅·土地統計調查及業界調查核實；事故估計數請對照消費者廳核實。

## 誤解1｜在浴缸裡洗身體

**千萬不要。** 在浴缸**外**用手持蓮蓬頭和小板凳洗淨，然後再泡。浴缸裡的水是共用的，應保持乾淨。

## 誤解2｜每個人都重新放一缸水

**一缸水供全家**在同一個晚上使用，靠蓋子和再加熱功能保溫。用一次就排掉既浪費又少見。

## 誤解3｜馬桶在浴室裡

幾乎所有日本家庭都是**分開的房間**（小套房和商務旅館裡的整體衛浴是例外）。濕區只用於入浴。

## 誤解4｜越熱越好

**42°C 以上加上長時間泡澡，正是入浴死亡事故的典型模式。** 40–41°C、10 分鐘，冬天先為更衣室加溫。

## 誤解5｜泡澡是可以省掉的奢侈

對大多數家庭來說，晚上的泡澡是**每天的「重開機」**：為入睡帶來溫暖（見入浴時間的文章）、家人相處的時間，以及 200 L 的儲備用水。省掉它才會讓人覺得是種煎熬。
