# Q. 关于在家做饭团（御饭团），人们常有哪些误解？｜Japanese Everyday Wisdom #397

- Shelf: `wisdom` ／ URL: `/zh-cn/wisdom/making-onigiri-at-home` ／ Status: **草稿 — 出处未核实**

饭团（「おにぎり」onigiri）——把米饭捏在馅料外面、包上海苔——是日本的便当主食、便利店的畅销品，也是孩子最先学会做的食物。在国外，它常被当作寿司的近亲。它不是，而正是这些差别让它成立。

## A. 常见的误解是认为饭团就是把寿司饭捏成三角形。饭团用的是不加调味、刚煮好的白米饭——不加醋——捏得紧实但不压实，盐撒在外面，配少量耐放的馅料，并且是为几小时后在室温下食用而设计的。如今的卫生标准是隔着保鲜膜捏而不是用手直接捏；如果想让海苔保持酥脆，就在吃之前再包。

## 做法

| 步骤 | 细节 | 原因 |
|---|---|---|
| **米饭** | **日本短粒米**，刚煮好，比日常吃的**稍硬一点**；**热但能上手**；**不加醋也不加糖** | 寿司饭是另一种菜；饭团的米饭必须能成形，并以本味衬托馅料 |
| **手** | **手沾湿，掌心抹盐**——或者按现在的标准，**隔着保鲜膜捏** | **手上的葡萄球菌**是饭团食物中毒的典型途径；用保鲜膜可以避免 |
| **形状** | **三角形、圆形或俵形（圆柱形）**；**压到刚好成形，又松到米粒仍分明**——每面约**按压 3 次** | 压得过实的饭团发硬；压得不够会散 |
| **馅料** | **1 茶匙**咸味或经过保存处理的食材：**梅干、盐渍鲑鱼、昆布、おかか（酱油拌鲣鱼片）、金枪鱼蛋黄酱、鳕鱼子** | 盐和保存处理使其能安全放置几小时；湿的馅料会浸湿米饭 |
| **盐** | 撒在表面，**每个饭团约一小撮** | 调味兼轻度保存 |
| **海苔** | **吃之前再包**则酥脆；**做的时候就包**则柔软（传统做法） | 便利店的隔膜包装就是为此设计的 |
| **放凉** | **让蒸汽散掉后再用**保鲜膜或铝箔包起 | 蒸汽闷在里面 = 软塌；温热 = 细菌 |
| **保存** | **室温下放几小时**（这正是它的用途）；**冷藏后米饭会变硬**——万一必须冷藏，吃前用微波炉稍微加热；**冷冻**时不要包海苔，食用前加热 |

- **食品安全**：厚生劳动省关于便当的指导同样适用——**手要干净或用保鲜膜、馅料要做熟、封起来之前先放凉、避开高温**（参见便当一文）。**盐渍和腌渍的馅料**是传统的安全余量；**蛋黄酱类馅料在夏天需要冷藏**。
- **做饭团的米**通常**水稍微少放一点**；有些超市会以**“饭团米”**的名义出售。
- **烤饭团（yaki-onigiri）**（烤过后刷酱油或味噌）是处理隔夜饭的办法。

## 误解1｜用寿司饭

**白米饭，不加醋。** 饭团和寿司只有米是共通的，别无其他；加了醋的饭团在任何日本人吃来都不对味。

## 误解2｜直接用手捏才是传统，没问题

**传统是这样，但现在的卫生标准是用保鲜膜**——用手捏的饭团引发葡萄球菌食物中毒是已知的模式。如果坚持用手，就把手沾湿抹盐，并在几小时内吃完。

## 误解3｜把饭压得越紧越不会散

**每面用力按 3 次**，不要更多。压实的饭团又硬又难吃；应该还能看得见米粒。

## 误解4｜放冰箱明天吃

**冷饭会变硬**（淀粉老化）。饭团是为**当天在室温下吃**而做的。想留到明天，就**不包海苔冷冻**，再用微波炉加热。

## 误解5｜馅料要多才好

**一茶匙。** 米饭才是主食，馅料是调味。湿的或大的馅料会浸透米饭，饭团就散了。
