# Q. 關於在家做御飯糰，大家常有哪些誤解？｜Japanese Everyday Wisdom #397

- Shelf: `wisdom` ／ URL: `/zh-tw/wisdom/making-onigiri-at-home` ／ Status: **草稿 — 出處未核實**

御飯糰（「おにぎり」onigiri）——把米飯捏在餡料外面、包上海苔——是日本的便當主食、便利商店的暢銷品，也是小孩最先學會做的食物。在國外，它常被當成壽司的近親。它不是，而正是這些差別讓它成立。

## A. 常見的誤解是認為御飯糰就是把壽司飯捏成三角形。御飯糰用的是不調味、剛煮好的白飯——不加醋——捏得緊實但不壓實，鹽撒在外面，配少量耐放的餡料，並且是為幾小時後在室溫下食用而設計的。現在的衛生標準是隔著保鮮膜捏而不是直接用手捏；如果想讓海苔保持酥脆，就在吃之前再包。

## 做法

| 步驟 | 細節 | 原因 |
|---|---|---|
| **米飯** | **日本短粒米**，剛煮好，比平常吃的**稍硬一點**；**熱但能上手**；**不加醋也不加糖** | 壽司飯是另一道菜；御飯糰的米飯必須能成形，並以原味襯托餡料 |
| **手** | **手沾濕，掌心抹鹽**——或者按現在的標準，**隔著保鮮膜捏** | **手上的葡萄球菌**是御飯糰食物中毒的典型途徑；用保鮮膜可以避免 |
| **形狀** | **三角形、圓形或俵形（圓柱形）**；**壓到剛好成形，又鬆到米粒仍分明**——每面約**按壓 3 次** | 壓得過實的飯糰發硬；壓得不夠會散 |
| **餡料** | **1 茶匙**鹹味或經過保存處理的食材：**梅干、鹽漬鮭魚、昆布、おかか（醬油拌柴魚片）、鮪魚美乃滋、鱈魚卵** | 鹽和保存處理使其能安全放置幾小時；濕的餡料會浸濕米飯 |
| **鹽** | 撒在表面，**每個飯糰約一小撮** | 調味兼輕度保存 |
| **海苔** | **吃之前再包**則酥脆；**做的時候就包**則柔軟（傳統做法） | 便利商店的隔膜包裝就是為此設計的 |
| **放涼** | **讓蒸氣散掉後再用**保鮮膜或鋁箔包起 | 蒸氣悶在裡面 = 軟爛；溫熱 = 細菌 |
| **保存** | **室溫下放幾小時**（這正是它的用途）；**冷藏後米飯會變硬**——萬一必須冷藏，吃前用微波爐稍微加熱；**冷凍**時不要包海苔，食用前加熱 | 飯糰本來就是為幾小時後在室溫下食用而做的；讓米飯變硬的正是冷藏 |

- **食品安全**：厚生勞動省關於便當的指導同樣適用——**手要乾淨或用保鮮膜、餡料要煮熟、封起來之前先放涼、避開高溫**（參見便當一文）。**鹽漬和醃漬的餡料**是傳統的安全餘裕；**美乃滋類餡料在夏天需要冷藏**。
- **做御飯糰的米**通常**水稍微少放一點**；有些超市會以**「飯糰米」**的名義販售。
- **烤飯糰（yaki-onigiri）**（烤過後刷醬油或味噌）是處理隔夜飯的辦法。

> **[待核實]** 食品安全要點請對照厚生勞動省的六要點指導；其餘為通行做法。

## 誤解1｜用壽司飯

**白飯，不加醋。** 御飯糰和壽司只有米是共通的，其他毫無關係；加了醋的御飯糰在任何日本人吃來都不對味。

## 誤解2｜直接用手捏才是傳統，沒問題

**傳統是這樣，但現在的衛生標準是用保鮮膜**——用手捏的飯糰引發葡萄球菌食物中毒是已知的模式。如果堅持用手，就把手沾濕抹鹽，並在幾小時內吃完。

## 誤解3｜把飯壓得越緊越不會散

**每面用力按 3 次**，不要更多。壓實的飯糰又硬又難吃；應該還看得見米粒。

## 誤解4｜放冰箱明天吃

**冷飯會變硬**（澱粉老化）。御飯糰是為**當天在室溫下吃**而做的。想留到明天，就**不包海苔冷凍**，再用微波爐加熱。

## 誤解5｜餡料要多才好

**一茶匙。** 米飯才是主食，餡料是調味。濕的或大的餡料會浸透米飯，飯糰就散了。
