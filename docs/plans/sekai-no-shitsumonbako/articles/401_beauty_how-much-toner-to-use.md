# Q. 化粧水の量について、よくある誤解は？｜世界の質問箱 #401

- 棚：`beauty` ／ URL：`/questions/how-much-toner-to-use` ／ ステータス：**ドラフト（法務レビュー前・出典未検証）**

「化粧水はたっぷり使うほどよい」は日本のスキンケアで長く語られてきた助言で、海外からは「なぜ日本人はそんなに化粧水を使うのか」と問われます。量と効果の関係を、化粧品の効能の範囲と皮膚の仕組みから整理します。

## A. 最大の誤解は「化粧水は多く使うほど肌が潤う」です。化粧水が働くのは角層までで、角層が含める水分量には上限があります。適量は製品表示（多くは500円硬貨大〜2〜3プッシュ）で、それ以上は蒸発して乾燥を招くこともあります。要点は量より「洗顔後すぐ」「その後に乳液・クリームでふた」です。

## 判断の材料

| 項目 | 内容 |
|---|---|
| 適量 | **製品表示に従う**。多くは**500円硬貨大（約2〜3mL）〜2〜3プッシュ** |
| 角層の水分 | **角層（厚さ約0.02mm）が保持できる水分は限られ**、それ以上は**蒸発**する。**蒸発時に周囲の水分も奪う**（過乾燥）とする説明 |
| 「浸透」 | 化粧品の浸透は**角層まで**（適正広告ガイドライン）。**量を増やしても深くは入らない** |
| 重ねづけ | **2〜3回に分けて重ねる**方法は、**一度に大量より均一に**なりやすい。**回数を増やしても総量は適量の範囲で** |
| タイミング | **洗顔後すぐ（数分以内）**。洗顔後は角層が水分を失いやすい |
| 順番 | **化粧水→（美容液）→乳液・クリーム**。**ふたをしないと化粧水の水分は蒸発**する |
| コットンパック | **3分程度**まで（乾き始めると逆に奪う。シートマスクの記事参照） |

- 化粧水の主成分は**水（70〜90%）と保湿成分（グリセリン・BG等）**。**保湿成分が角層の水分を保持**する働きで、**水そのものが肌に貯まる**わけではありません。
- **「たっぷり使う」の由来**は、化粧水が**日本のスキンケアの中心品目**として発達し、**大容量・低価格の製品**が普及したことにあり、**皮膚科学の根拠**ではないとされます。
- **乾燥が気になる場合の優先順位**は、**化粧水の量**より**乳液・クリームの油分**、**洗顔の温度と回数**（入浴と肌の記事参照）。

> 【要検証】角層の厚さ・水分保持の説明は皮膚科学の一般的な記載、「浸透」は日本化粧品工業会の適正広告ガイドラインで確認してください。

## 誤解1｜多く使うほど潤う

**角層が含める水分には上限**があり、**余った分は蒸発**します。**適量＋ふた（乳液）**。

## 誤解2｜高い化粧水は少量、安い化粧水はたっぷり

**量は製品の設計（表示）で決まり、価格で決まりません。** 安い化粧水を大量に使うより、**適量を毎日、洗顔後すぐ**。

## 誤解3｜バシャバシャ使えば乳液は要らない

**化粧水の水分はふたをしなければ蒸発**します。**乳液・クリームを省くと、かえって乾く**というのが日本のスキンケアの基本の考え方（乳液の記事参照）。

## 誤解4｜パッティングで叩き込むと入る

**叩く刺激は赤みや色素沈着の原因**になることがあり、皮膚科では**押さえるように**が案内されます。**浸透の深さは変わりません**。

## 誤解5｜化粧水を使わないと肌が乾く

**海外では化粧水の習慣がない国が多く**、**乳液・クリーム1本で成り立つ**肌質の人も多い。**化粧水は「使ってもよい」品目で「必須」ではない**。
