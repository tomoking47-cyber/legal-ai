# Q. 关于化妆水该用多少，人们常有哪些误解？｜Japan Questions #401

- Shelf: `beauty` ／ URL: `/zh-cn/beauty/how-much-toner-to-use` ／ Status: **草稿 — 出处未核实**

「化妆水要用得多一点」是日本护肤界重复了几十年的说法，来访者也常问：为什么日本人化妆水用得这么多？日本的化妆水（「化粧水」，keshōsui）是一种水状的护肤液，洗完脸后立即使用，在乳液或面霜之前。这里我们借助「化妆品在法律上可以宣称什么」和「皮肤实际上如何运作」，来理清用量与效果之间的关系。

## A. 最大的误解是「化妆水用得越多，皮肤就越水润」。化妆水起作用的范围只到角质层（皮肤最外层），而这一层能含住的水分量存在上限。适量就是产品标签上写的量——通常是 500 日元硬币大小的一摊，或 2〜3 泵——超过的部分会蒸发，有时反而让皮肤更干。关键不在用量，而在「洗脸后立即使用」和「之后用乳液或面霜封住」。

## 要点

| 项目 | 内容 |
|---|---|
| 适量 | **遵循产品标签**。通常是 **500 日元硬币大小的一摊（约 2〜3 mL），或 2〜3 泵** |
| 角质层中的水分 | **角质层（厚约 0.02 mm）能含住的水分有限**，其余会**蒸发**。一种常见的解释是，**蒸发时还会带走周围的水分**（过度干燥） |
| 「渗透」 | 化妆品的渗透**只到角质层为止**（日本的化妆品广告准则）。**用得多也不会渗得更深** |
| 分层涂抹 | **分 2〜3 次薄薄地涂**，往往比**一次大量涂抹**更均匀。**即使分多次，总量仍在建议用量之内** |
| 时机 | **洗脸后立即（几分钟之内）**。洗脸后角质层的水分流失很快 |
| 顺序 | **化妆水 →（精华）→ 乳液或面霜**。**没有「盖子」，化妆水里的水分就会蒸发** |
| 化妆棉湿敷 | **最多 3 分钟左右**（化妆棉一旦开始变干，就会反过来吸走水分；参见本站面膜文章） |

- 化妆水的主要成分是**水（70〜90%）与保湿剂（甘油、BG 等）**。**保湿剂帮助角质层含住水分**；**水本身并不会储存在皮肤里**。
- **「要用得多」这个习惯**，一般被认为源自化妆水作为**日本护肤核心单品**的发展，以及**大容量低价瓶装**的普及，而非**皮肤科学证据**。
- **如果担心干燥，优先要看的**不是化妆水的用量，而是**乳液或面霜的油分含量**，以及**洗脸的水温与频率**（参见本站沐浴与皮肤文章）。

## 误解1｜用得越多越水润

**角质层能含住的水分有上限**，**多余的会蒸发**。**适量加上一层盖子（乳液）**。

## 误解2｜贵的化妆水省着用，便宜的化妆水随便用

**用量由产品的设计（标签）决定，而不是由价格决定。** 与其用廉价化妆水把脸泡透，不如**每天在洗脸后立即使用适量**。

## 误解3｜化妆水拍够了就可以不用乳液

**不封住的话，化妆水中的水分会蒸发**。**省掉乳液或面霜反而让皮肤更干**——这是日本护肤的基本思路（参见本站乳液文章）。

## 误解4｜拍打才能吸收

**拍打皮肤可能引起泛红和色素沉着**；皮肤科医生建议**轻轻按压**。**这并不会改变化妆水进入的深度**。

## 误解5｜不用化妆水皮肤就会干

**许多国家根本没有使用化妆水的习惯**，**很多人只用一支乳液或面霜也没有问题**。**化妆水是「可选项」，不是「必需品」**。
