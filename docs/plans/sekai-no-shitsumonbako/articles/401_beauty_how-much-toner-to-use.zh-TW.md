# Q. 關於化妝水該用多少，人們常有哪些誤解？｜Japan Questions #401

- Shelf: `beauty` ／ URL: `/zh-tw/beauty/how-much-toner-to-use` ／ Status: **草稿 — 出處未核實**

「化妝水要多用一點」是日本保養界重複了幾十年的說法，來訪的人也常問：為什麼日本人化妝水用這麼多？日本的化妝水（「化粧水」，keshōsui）是一種水狀的保養液，洗完臉後立刻使用，在乳液或乳霜之前。這裡我們藉由「化妝品在法令上可以宣稱什麼」與「皮膚實際上如何運作」，來釐清用量與效果之間的關係。

## A. 最大的誤解是「化妝水用得越多，皮膚就越水潤」。化妝水作用的範圍只到角質層（皮膚最外層），而這一層能含住的水分有上限。適量就是產品標示上寫的量——通常是 500 日圓硬幣大小的一攤，或 2〜3 壓——超過的部分會蒸發，有時反而讓皮膚更乾。關鍵不在用量，而在「洗臉後立刻使用」與「之後用乳液或乳霜蓋住」。

## 要點

| 項目 | 內容 |
|---|---|
| 適量 | **依照產品標示**。通常是 **500 日圓硬幣大小的一攤（約 2〜3 mL），或 2〜3 壓** |
| 角質層中的水分 | **角質層（厚約 0.02 mm）能含住的水分有限**，其餘會**蒸發**。一種常見的說法是，**蒸發時還會帶走周圍的水分**（過度乾燥） |
| 「滲透」 | 化妝品的滲透**只到角質層為止**（日本的化妝品廣告準則）。**用得多也不會滲得更深** |
| 分層塗抹 | **分 2〜3 次薄薄地塗**，往往比**一次大量塗抹**更均勻。**即使分多次，總量仍在建議用量之內** |
| 時機 | **洗臉後立刻（幾分鐘之內）**。洗臉後角質層的水分流失很快 |
| 順序 | **化妝水 →（精華液）→ 乳液或乳霜**。**沒有「蓋子」，化妝水裡的水分就會蒸發** |
| 化妝棉濕敷 | **最多 3 分鐘左右**（化妝棉一旦開始變乾，就會反過來吸走水分；參見本站面膜文章） |

- 化妝水的主要成分是**水（70〜90%）與保濕劑（甘油、BG 等）**。**保濕劑幫助角質層含住水分**；**水本身並不會儲存在皮膚裡**。
- **「要多用」這個習慣**，一般認為源自化妝水作為**日本保養核心單品**的發展，以及**大容量低價瓶裝**的普及，而非**皮膚科學證據**。
- **如果擔心乾燥，優先要看的**不是化妝水的用量，而是**乳液或乳霜的油分含量**，以及**洗臉的水溫與頻率**（參見本站沐浴與皮膚文章）。

> **[待核實]** 請對照皮膚科標準教科書核查角質層厚度與保水能力的描述，並對照日本化粧品工業聯合會的廣告準則核查「滲透」的說法。

## 誤解1｜用得越多越水潤

**角質層能含住的水分有上限**，**多餘的會蒸發**。**適量再加上一層蓋子（乳液）**。

## 誤解2｜貴的化妝水省著用，便宜的化妝水隨便用

**用量由產品的設計（標示）決定，而不是由價格決定。** 與其用便宜化妝水把臉泡透，不如**每天在洗臉後立刻使用適量**。

## 誤解3｜化妝水拍夠了就可以不用乳液

**不蓋住的話，化妝水中的水分會蒸發**。**省掉乳液或乳霜反而讓皮膚更乾**——這是日本保養的基本想法（參見本站乳液文章）。

## 誤解4｜拍打才會吸收

**拍打皮膚可能引起泛紅與色素沉澱**；皮膚科醫師建議**輕輕按壓**。**這並不會改變化妝水進入的深度**。

## 誤解5｜不用化妝水皮膚就會乾

**許多國家根本沒有使用化妝水的習慣**，**很多人只用一支乳液或乳霜也沒有問題**。**化妝水是「選配」，不是「必需品」**。
