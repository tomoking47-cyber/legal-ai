# Q. 关于颈部与前胸的护理，人们常有哪些误解？｜Japan Questions #403

- Shelf: `beauty` ／ URL: `/zh-cn/beauty/neck-and-decollete-care` ／ Status: **草稿 — 出处未核实**

「只顾着脸，忘了脖子」在哪里都成立，颈纹以及脸与脖子之间的色差，常被说是暴露年龄的地方。这里我们来看看颈部皮肤有什么不同，以及防晒、保湿，还有日本讨论得很多的「手机颈」姿势。

## A. 最大的误解是「颈部需要与面部不同的专用化妆品」。颈部和前胸是面部的延伸；对大多数人来说，只要把同一款防晒霜和保湿产品「一路涂到脖子」就够了。影响颈纹的是累积的紫外线照射、低头的姿势（手机颈）和枕头高度——这些都不是化妆品能消除的。

## 要点

| 项目 | 内容 |
|---|---|
| 颈部皮肤 | **比面部薄，皮脂腺更少，容易干燥**。**活动量大**，因此容易形成横向的纹路 |
| 紫外线 | **颈部与前胸接受的紫外线与面部相当，甚至更多**（领口敞开）。**防晒霜要涂到脖子、耳后和前胸** |
| 保湿 | **把面部的化妆水和乳液一路带到脖子**。不需要专用产品 |
| 姿势 | **低头的时间（手机、电脑）**一般被描述为颈部横纹的一个因素。**把屏幕放到视线高度**（参见本站手机颈文章） |
| 枕头 | **枕头过高会让下巴下压、脖子产生褶皱**（参见本站枕头文章） |
| 涂抹方式 | **由下往上，不要搓揉**。**颈部皮肤薄，按摩造成的摩擦可能引起色素沉着** |
| 化妆品可以宣称什么 | 最多到 **「滋润肌肤」和「使因干燥而产生的细纹变得不明显（经功效验证）」**。**「消除皱纹」「改善松弛」不是被允许的宣称** |
| 医疗选项 | **针对颈纹的注射、激光等属于美容医疗（「自由診療」，jiyū shinryō——自费，不在医疗保险范围内）**。**请向医生询问效果与风险** |

- **脖子晒黑**是因为**人们把防晒霜涂在脸上却忘了脖子**，于是出现**脸与脖子的色差**（「脖子发暗」）。**环境省的手册把「后颈与耳朵」列入容易遗漏的部位**。
- **「颈部护理」产品**属于化妆品，**其成分与面部产品基本相同**。多数只是**设计成较厚重的质地（面霜）**。
- **防紫外线的围巾或高领**能提供保护，**而且不需要补涂防晒霜**（参见本站防晒衣物文章）。

> **[待核实]** 请对照皮肤科标准教科书核查皮肤特性的描述，并对照环境省的手册核查容易遗漏的部位。

## 误解1｜脖子需要专用化妆品

**把面部的防晒霜和保湿产品一路涂到脖子**，就能覆盖大部分需求。**专用产品的差别主要在质地**。

## 误解2｜化妆品能消除颈纹

**化妆品最多只能宣称「使因干燥而产生的细纹变得不明显」**。**深的纹路和松弛属于美容医疗**；请向医生询问效果与风险。

## 误解3｜按摩能改善纹路和肤色

**颈部皮肤薄，摩擦会引起色素沉着**。**由下往上把产品推开，不要搓揉**。

## 误解4｜脸上涂了防晒霜就够了

**颈部、前胸和耳后接受的紫外线与面部相当，甚至更多**。这正是**脸与脖子色差**的主要原因。

## 误解5｜颈纹只是年龄问题，无计可施

**累积的紫外线与姿势**占很大比重，**因手机姿势产生的横纹在年轻人身上也有报告**。**防晒霜、屏幕高度和枕头**是预防的关键。
