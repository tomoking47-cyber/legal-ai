# Q. 關於頸部與前胸的保養，人們常有哪些誤解？｜Japan Questions #403

- Shelf: `beauty` ／ URL: `/zh-tw/beauty/neck-and-decollete-care` ／ Status: **草稿 — 出處未核實**

「只顧著臉，忘了脖子」在哪裡都成立，頸紋以及臉和脖子之間的色差，常被說是洩漏年齡的地方。這裡我們來看看頸部皮膚有什麼不同，以及防曬、保濕，還有日本討論得很多的「手機頸」姿勢。

## A. 最大的誤解是「頸部需要與臉部不同的專用化妝品」。頸部與前胸是臉部的延伸；對多數人來說，只要把同一款防曬乳與保濕產品「一路擦到脖子」就夠了。影響頸紋的是累積的紫外線曝曬、低頭的姿勢（手機頸）與枕頭高度——這些都不是化妝品能消除的。

## 要點

| 項目 | 內容 |
|---|---|
| 頸部皮膚 | **比臉部薄，皮脂腺較少，容易乾燥**。**活動量大**，因此容易形成橫向的紋路 |
| 紫外線 | **頸部與前胸接受的紫外線與臉部相當，甚至更多**（領口敞開）。**防曬乳要擦到脖子、耳後與前胸** |
| 保濕 | **把臉部的化妝水與乳液一路帶到脖子**。不需要專用產品 |
| 姿勢 | **低頭的時間（手機、電腦）**一般被描述為頸部橫紋的一個因素。**把螢幕放到視線高度**（參見本站手機頸文章） |
| 枕頭 | **枕頭過高會讓下巴下壓、脖子產生摺痕**（參見本站枕頭文章） |
| 塗抹方式 | **由下往上，不要搓揉**。**頸部皮膚薄，按摩造成的摩擦可能引起色素沉澱** |
| 化妝品可以宣稱什麼 | 最多到 **「滋潤肌膚」與「使因乾燥而產生的細紋變得不明顯（經功效驗證）」**。**「消除皺紋」「改善鬆弛」不是被允許的宣稱** |
| 醫療選項 | **針對頸紋的注射、雷射等屬於美容醫療（「自由診療」，jiyū shinryō——自費，不在健康保險給付範圍內）**。**請向醫師詢問效果與風險** |

- **脖子曬黑**是因為**人們把防曬乳擦在臉上卻忘了脖子**，於是出現**臉與脖子的色差**（「脖子暗一截」）。**「後頸與耳朵」是容易漏擦的部位**，多項關於防曬乳實際塗抹情況的調查反覆指出這一點。
- **「頸部保養」產品**屬於化妝品，**成分與臉部產品基本相同**。多數只是**設計成較厚重的質地（乳霜）**。
- **抗紫外線的圍巾或高領**能提供保護，**而且不需要補擦防曬乳**（參見本站防曬衣物文章）。

> **[待核實]** 請對照皮膚科標準教科書核查皮膚特性的描述，並對照環境省的手冊核查容易漏擦的部位。

## 誤解1｜脖子需要專用化妝品

**把臉部的防曬乳與保濕產品一路擦到脖子**，就能涵蓋大部分需求。**專用產品的差別主要在質地**。

## 誤解2｜化妝品能消除頸紋

**化妝品最多只能宣稱「使因乾燥而產生的細紋變得不明顯」**。**深的紋路與鬆弛屬於美容醫療**；請向醫師詢問效果與風險。

## 誤解3｜按摩能改善紋路與膚色

**頸部皮膚薄，摩擦會引起色素沉澱**。**由下往上把產品推開，不要搓揉**。

## 誤解4｜臉上擦了防曬乳就夠了

**頸部、前胸與耳後接受的紫外線與臉部相當，甚至更多**。這正是**臉與脖子色差**的主要原因。

## 誤解5｜頸紋只是年齡問題，無計可施

**累積的紫外線與姿勢**占很大比重，**因手機姿勢產生的橫紋在年輕人身上也有報告**。**防曬乳、螢幕高度與枕頭**是預防的關鍵。
