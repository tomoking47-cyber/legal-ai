# Q. ヘアアイロンの温度と髪について、よくある誤解は？｜世界の質問箱 #404

- 棚：`beauty` ／ URL：`/questions/hair-iron-temperature` ／ ステータス：**ドラフト（法務レビュー前・出典未検証）**

ヘアアイロン（ストレート・カール）は毎日使う人が多く、「何度に設定すべきか」「髪が傷むのは仕方ないか」が問われます。髪のたんぱく質の性質と、やけど事故の観点から整理します。

## A. 最大の誤解は「高温のほうが早く決まるから髪への負担も少ない」です。髪のたんぱく質（ケラチン）は約150℃を超えると変性が進み、200℃以上では表面が損傷します。目安は「乾いた髪に、140〜160℃、一か所に2〜3秒、1回で」で、濡れた髪への使用は水蒸気爆発で内部を傷めます。やけど事故（とくに子ども）も毎年報告されています。

## 数字で見る

| 項目 | 内容 |
|---|---|
| 髪の耐熱の目安 | **約150℃を超えるとケラチンの変性が進む**、**200℃以上で表面（キューティクル）の損傷が顕著** |
| 設定温度の目安 | **細い・傷んだ髪：120〜140℃**、**普通：140〜160℃**、**太い・硬い髪：160〜180℃**。**200℃以上は美容室の短時間の技術向け** |
| 当てる時間 | **一か所2〜3秒、同じ場所を繰り返さない**。**ゆっくり1回**より**素早く1回** |
| 濡れた髪 | **不可**。内部の水分が急激に蒸気になり**「水蒸気爆発」で髪の内部が空洞化**。**完全に乾かしてから** |
| 保護 | **ヘアオイル・ミルク（耐熱表示のあるもの）**を薄く。**つけすぎは熱で焦げる** |
| やけど | **プレート温度は200℃前後**。**顔・耳・首の接触やけど**、**子どもが触る事故**（NITE・消費者庁）。**使用後は耐熱マットに、コードを引っ張らない** |
| 自動オフ | **多くの製品に一定時間で電源オフ機能**。**ないものは切り忘れが火災の原因** |

- **ヘアアイロンによるやけど**は消費者庁の事故情報で継続的に報告され、**5歳以下の子どもが使用後の本体に触れる**事例が多い。**床に置かない、手の届かない場所で冷ます**。
- **毎日の使用**は**表面の摩耗と乾燥**を進めます。**週に数日は使わない日**、**温度を下げる**、**トリートメント**（コンディショナーの記事参照）。**傷んだ髪は元に戻らない**（ヘアオイルの記事参照）。
- **PSE（電気用品安全法）**の対象。**海外製品を日本で使う場合は電圧（100V）とPSEマークを確認**。

> 【要検証】ケラチンの変性温度は毛髪科学の一般的な記載、事故事例はNITE・消費者庁の資料で確認してください。

## 誤解1｜高温で一気にやれば負担が少ない

**150℃超で変性が進み、200℃で損傷が顕著**。**140〜160℃で素早く1回**のほうが負担が少ない。

## 誤解2｜少し湿った髪のほうがまとまる

**濡れた髪への熱は水蒸気爆発で内部を空洞化**させ、最も傷む使い方。**完全に乾かしてから**。

## 誤解3｜ヘアオイルをたっぷりつけてから

**耐熱表示のあるオイルを薄く**。**つけすぎると熱で焦げ、べたつく**。

## 誤解4｜毎日使っても手入れすれば戻る

**傷んだ髪は再生しません。** **使わない日を作る、温度を下げる**が唯一の予防。

## 誤解5｜使い終わったらそのまま棚に

**200℃のプレートは数分間高温**。**耐熱マットの上で冷ます、子どもの手の届かない場所に、自動オフの有無を確認**。
