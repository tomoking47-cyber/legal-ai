# Q. 关于卷发棒／直发夹的温度与头发损伤，人们常有哪些误解？｜Japan Questions #404

- Shelf: `beauty` ／ URL: `/zh-cn/beauty/hair-iron-temperature` ／ Status: **草稿 — 出处未核实**

很多人每天都在用直发夹或卷发棒，反复出现的问题有两个：「温度该设成多少？」「损伤是不是无法避免？」这里我们来看看头发里的蛋白质在高温下会发生什么，以及日本的消费者安全机构每年都会通报的烫伤事故。文中还有一段关于「在国外买的卷发棒能不能在日本用」的说明。

## A. 最大的误解是「温度越高定型越快，所以对头发反而更温和」。头发中的蛋白质（角蛋白）在约 150℃（302°F）以上开始变性，200℃（392°F）以上表面会出现明显损伤。参考标准是「在干发上，140〜160℃，同一处 2〜3 秒，只过一次」。在湿发上使用会通过所谓的「水蒸气爆炸」损伤头发内部。烫伤事故（尤其涉及儿童）每年都有通报。

## 数字

| 项目 | 内容 |
|---|---|
| 头发的耐热参考 | **约 150℃ 以上角蛋白变性会加剧**；**200℃ 以上表面（毛鳞片）的损伤明显** |
| 建议温度 | **细软或受损发质：120〜140℃**；**普通发质：140〜160℃**；**粗硬发质：160〜180℃**。**200℃ 以上适用于美容院的短时间技术操作** |
| 接触时间 | **同一处 2〜3 秒，不要在同一位置反复**。**快速过一次**胜过**缓慢过一次** |
| 湿发 | **绝对不可**。内部的水分骤然汽化，**「水蒸气爆炸」会把头发内部掏空**。**先彻底吹干** |
| 保护 | 薄薄一层**标示有耐热（护热）功能的发油或发乳**。**涂太多会在高温下焦化** |
| 烫伤 | **发热板温度在 200℃ 前后**。**面部、耳朵、颈部的接触烫伤**，以及**儿童触碰机身的事故**（NITE・消费者厅）。**使用后放在耐热垫上，不要拉扯电源线** |
| 自动断电 | **很多机型会在设定时间后自动关闭**。**没有这项功能时，忘记关机是起火原因之一** |

- **卷发棒造成的烫伤**在消费者厅的事故信息中持续被通报，其中**5 岁以下儿童在使用后触碰机身**的案例很多。**不要放在地板上，要在孩子够不到的地方放凉**。
- **每天使用**会加快**表面磨损与干燥**。**每周留出几天不使用**、**调低温度**、**使用护发素**（参见本站护发素文章）。**受损的头发不会复原**（参见本站发油文章）。
- 卷发棒属于 **PSE（电气用品安全法，日本的电气安全法规）**的对象。**如果要在日本使用国外购买的产品，请确认电压（日本为 100 V）并查看 PSE 标志**。

## 误解1｜用高温一次搞定反而负担更小

**150℃ 以上变性会加剧，200℃ 时损伤明显**。**用 140〜160℃ 快速过一次**造成的负担更小。

## 误解2｜稍微湿一点的头发更好造型

**在湿发上加热会通过水蒸气爆炸把内部掏空**——这是最伤头发的用法。**先彻底吹干**。

## 误解3｜先涂厚厚一层发油再夹

**薄薄一层标示有耐热功能的发油即可**。**涂太多会焦化并变得油腻**。

## 误解4｜每天用也没关系，好好护理就能恢复

**受损的头发不会再生。** **留出不使用的日子、调低温度**等，减少热负担就是预防。

## 误解5｜用完直接放回架子上

**200℃ 的发热板会持续高温数分钟**。**放在耐热垫上冷却，置于儿童够不到的地方，并确认是否有自动断电功能**。
