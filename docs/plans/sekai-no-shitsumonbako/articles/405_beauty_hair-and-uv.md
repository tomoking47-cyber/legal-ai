# Q. 髪の紫外線対策について、よくある誤解は？｜世界の質問箱 #405

- 棚：`beauty` ／ URL：`/questions/hair-and-uv` ／ ステータス：**ドラフト（法務レビュー前・出典未検証）**

肌の紫外線対策は定着しましたが、髪と頭皮は忘れられがちです。「髪が紫外線で傷むのか」「髪用の日焼け止めは必要か」を、毛髪の性質と環境省の紫外線マニュアルの考え方から整理します。

## A. 最大の誤解は「髪は死んだ細胞だから紫外線は関係ない」です。髪は再生しませんが、紫外線でキューティクルが傷み、色素が分解されて色が抜け、パサつきが進みます。頭皮は皮膚で、日焼けもします。対策の基本は帽子と日傘で、髪用UVスプレーは補助です。

## 判断の材料

| 項目 | 内容 |
|---|---|
| 髪への影響 | **紫外線でキューティクルのたんぱく質が損傷**、**メラニンが分解されて色が抜ける（赤茶ける）**、**カラーの退色**、**乾燥・切れ毛** |
| 頭皮への影響 | **皮膚と同じく日焼け（炎症）**。**分け目・つむじ**が焼けやすい。**頭皮の日焼けは抜け毛の一因**とする説明もある |
| 最も確実な対策 | **帽子（つば7cm以上）・日傘**（環境省マニュアル）。**UVカットの帽子**は遮蔽率で選ぶ |
| 髪用UVスプレー | **化粧品**（「毛髪を保護する」等）。**SPF/PA表示は肌用の基準**で、**髪への効果の測定基準はない**。**補助** |
| 日焼け止め（肌用）を頭皮に | **分け目に塗る**人もいるが、**べたつきと洗い残し**。**スプレータイプの頭皮用**もある |
| 海・プール | **塩素・塩＋紫外線で退色と乾燥が加速**。**濡れた髪は紫外線の影響を受けやすい**。**帽子、真水で流す** |
| 洗い方 | **紫外線を浴びた日は、しっかり保湿（トリートメント）** |

- 環境省マニュアルは**「帽子・日傘・衣類・日焼け止め・サングラス」**を紫外線対策の基本とし、**頭部・目**を守る手段として帽子・日傘を挙げています。**髪そのものへの言及は限定的**。
- **ヘアカラーの退色**は、**紫外線と洗浄（シャンプー）**が主因。**夏のカラーは退色が早い**という美容業界の一般的な説明。
- **髪用UVスプレー**は**日本の夏の定番商品**ですが、**SPF値の表示は「皮膚に対する測定」**であり、**髪への防御の数値ではない**点を理解して補助として使います。

> 【要検証】環境省マニュアルの該当箇所、髪への紫外線の影響は毛髪科学の一般的な記載で確認してください。

## 誤解1｜髪は紫外線で傷まない

**キューティクルの損傷・退色・乾燥**が起きます。**再生しないからこそ、予防**。

## 誤解2｜髪用UVスプレーのSPF50は髪を50倍守る

**SPFは皮膚に対する測定基準**で、**髪への効果の数値ではありません**。**帽子・日傘が確実**、スプレーは補助。

## 誤解3｜黒髪は紫外線に強い

**メラニンが多いため肌の日焼けと同様に「変色しにくい」面はありますが、損傷は起きます**。**カラーした髪は退色が早い**。

## 誤解4｜頭皮は髪で守られている

**分け目・つむじ・薄い部分は日焼け**します。**帽子**、または**頭皮用スプレー**。**赤み・かゆみ・皮むけ**は日焼けの症状。

## 誤解5｜海で濡れれば紫外線は防げる

**濡れた髪は紫外線を通しやすく、塩・塩素が重なって最も傷む条件**。**帽子と真水で流す**。
