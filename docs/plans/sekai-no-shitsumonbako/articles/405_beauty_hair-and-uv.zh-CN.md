# Q. 关于头发的紫外线防护，人们常有哪些误解？｜Japan Questions #405

- Shelf: `beauty` ／ URL: `/zh-cn/beauty/hair-and-uv` ／ Status: **草稿 — 出处未核实**

皮肤的防晒如今已成常规，但头发和头皮却容易被忘记。日本的夏天，药妆店（松本清、Welcia 等）的每一排货架上都摆着头发用的防晒喷雾，于是问题来了：「紫外线真的会伤头发吗？」「头发也需要防晒霜吗？」这里我们来看看头发的表现，以及环境省紫外线手册所采取的思路。

## A. 最大的误解是「头发是死细胞，所以紫外线无所谓」。头发确实不会再生，但紫外线会损伤毛鳞片、分解色素使发色褪去，并让头发变得干燥毛躁。头皮是皮肤，会晒伤。基本的防护是帽子和阳伞；头发用防晒喷雾是补充手段。

## 要点

| 项目 | 内容 |
|---|---|
| 对头发的影响 | **紫外线会损伤毛鳞片的蛋白质**；**黑色素分解、发色褪去（变成偏红棕）**；**染发的颜色褪得更快**；**干燥与断裂** |
| 对头皮的影响 | **和其他皮肤一样会晒伤（发炎）**。**发缝和头顶**最容易晒伤。也有说法把**头皮晒伤描述为脱发的原因之一** |
| 最可靠的防护 | **帽子（帽檐 7 cm 以上）与阳伞**（环境省手册）。**防紫外线的帽子**要按遮蔽率来挑选 |
| 头发用防晒喷雾 | 属于**化妆品**（「保护秀发」等）。**SPF／PA 的评级是针对皮肤的标准**；**头发的防护并没有测定标准**。**属于补充手段** |
| 把皮肤用防晒霜涂在头皮上 | 有人会**沿着发缝涂**，但**油腻且不易洗掉**。市面上有**头皮专用的喷雾型产品** |
| 海边与泳池 | **氯与盐分加上紫外线，会加快褪色与干燥**。**湿着的头发更易受紫外线影响**。**戴帽子，并用清水冲洗** |
| 清洗 | **在有紫外线照射的日子，要充分做保湿（护发素／护理产品）** |

- 环境省的手册把 **「帽子、阳伞、衣物、防晒霜、太阳镜」** 列为紫外线防护的基本项，并把帽子与阳伞列为保护**头部与眼睛**的手段。**关于头发本身则着墨甚少**。
- **发色褪色**主要由**紫外线与清洗（洗发水）**造成。**夏天褪色更快**是美发业界常见的说法。
- **头发用防晒喷雾**是**日本夏季的标准商品**，但请在了解 **SPF 数值是「在皮肤上的测定值」**、**并非头发防护数值**的前提下，把它当作补充手段使用。

> **[待核实]** 请核查环境省手册的相关段落，并对照毛发科学的标准文献核查紫外线对头发的影响。

## 误解1｜紫外线不会伤头发

**毛鳞片损伤、褪色和干燥**都会发生。**正因为头发不会再生，预防才是关键**。

## 误解2｜SPF50 的头发喷雾能把头发保护 50 倍

**SPF 是针对皮肤的测定标准**，**不是头发防护的数值**。**帽子和阳伞才可靠**；喷雾是补充。

## 误解3｜黑发不怕紫外线

**黑色素多，确实「颜色变化较慢」，就像皮肤晒黑一样，但损伤照样发生**。**染过的头发褪色更快**。

## 误解4｜有头发就能保护头皮

**发缝、头顶和头发稀疏的部位是会晒伤的**。**戴帽子**，或**使用头皮喷雾**。**泛红、发痒和脱皮**都是晒伤的症状。

## 误解5｜在海里泡湿了反而能防紫外线

**湿着的头发更容易让紫外线穿透，再加上盐分或氯，是最伤头发的组合**。**戴帽子，并用清水冲洗**。
