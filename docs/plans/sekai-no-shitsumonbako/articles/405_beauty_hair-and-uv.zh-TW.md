# Q. 關於頭髮的紫外線防護，人們常有哪些誤解？｜Japan Questions #405

- Shelf: `beauty` ／ URL: `/zh-tw/beauty/hair-and-uv` ／ Status: **草稿 — 出處未核實**

皮膚的防曬如今已是日常，但頭髮與頭皮卻容易被忘記。日本的夏天，藥妝店（松本清、Welcia 等）每一排貨架上都擺著頭髮用的防曬噴霧，於是問題來了：「紫外線真的會傷頭髮嗎？」「頭髮也需要防曬乳嗎？」這裡我們來看看頭髮的變化，以及環境省紫外線手冊採取的思路。

## A. 最大的誤解是「頭髮是死細胞，所以紫外線無所謂」。頭髮確實不會再生，但紫外線會傷害毛鱗片、分解色素使髮色褪去，並讓頭髮變得乾燥毛躁。頭皮是皮膚，會曬傷。基本的防護是帽子與陽傘；頭髮用防曬噴霧是輔助手段。

## 要點

| 項目 | 內容 |
|---|---|
| 對頭髮的影響 | **紫外線會傷害毛鱗片的蛋白質**；**黑色素分解、髮色褪去（轉為偏紅褐）**；**染髮的顏色褪得更快**；**乾燥與斷裂** |
| 對頭皮的影響 | **和其他皮膚一樣會曬傷（發炎）**。**髮線分邊處與頭頂**最容易曬傷。也有說法把**頭皮曬傷描述為掉髮的原因之一** |
| 最可靠的防護 | **帽子（帽簷 7 cm 以上）與陽傘**（環境省手冊）。**抗紫外線的帽子**要依遮蔽率挑選 |
| 頭髮用防曬噴霧 | 屬於**化妝品**（「保護秀髮」等）。**SPF／PA 的標示是針對皮膚的標準**；**頭髮的防護並沒有測定標準**。**屬於輔助手段** |
| 把皮膚用防曬乳擦在頭皮上 | 有人會**沿著分線擦**，但**油膩且不易洗掉**。市面上有**頭皮專用的噴霧型產品** |
| 海邊與泳池 | **氯與鹽分加上紫外線，會加速褪色與乾燥**。**濕的頭髮更容易受紫外線影響**。**戴帽子，並用清水沖洗** |
| 清洗 | **在有紫外線曝曬的日子，要充分保濕（護髮／護理產品）** |

- 環境省的手冊把 **「帽子、陽傘、衣物、防曬乳、太陽眼鏡」** 列為紫外線防護的基本項目，並把帽子與陽傘列為保護**頭部與眼睛**的方法。**關於頭髮本身則著墨甚少**。
- **髮色褪色**主要由**紫外線與清洗（洗髮精）**造成。**夏天褪色更快**是美髮業界常見的說法。
- **頭髮用防曬噴霧**是**日本夏季的標準商品**，但請在了解 **SPF 數值是「在皮膚上的測定值」**、**並非頭髮防護數值**的前提下，把它當作輔助手段使用。

> **[待核實]** 請核查環境省手冊的相關段落，並對照毛髮科學的標準文獻核查紫外線對頭髮的影響。

## 誤解1｜紫外線不會傷頭髮

**毛鱗片受損、褪色與乾燥**都會發生。**正因為頭髮不會再生，預防才是關鍵**。

## 誤解2｜SPF50 的頭髮噴霧能把頭髮保護 50 倍

**SPF 是針對皮膚的測定標準**，**不是頭髮防護的數值**。**帽子與陽傘才可靠**；噴霧是輔助。

## 誤解3｜黑髮不怕紫外線

**黑色素多，確實「顏色變化較慢」，就像皮膚曬黑一樣，但損傷照樣發生**。**染過的頭髮褪色更快**。

## 誤解4｜有頭髮就能保護頭皮

**分線處、頭頂與頭髮稀疏的部位是會曬傷的**。**戴帽子**，或**使用頭皮噴霧**。**泛紅、發癢與脫皮**都是曬傷的症狀。

## 誤解5｜在海裡泡濕了反而能防紫外線

**濕的頭髮更容易讓紫外線穿透，再加上鹽分或氯，是最傷頭髮的組合**。**戴帽子，並用清水沖洗**。
