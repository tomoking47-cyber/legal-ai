# Q. 세탁망(그물 세탁 주머니) 사용에 대해 흔한 오해는 무엇입니까?｜Japan Questions #412

- Shelf: `fashion` ／ URL: `/ko/fashion/using-laundry-nets` ／ Status: **초안 — 출처 미확인**

세탁망(洗濯ネット, 센타쿠 넷토 — 지퍼가 달린 그물 세탁 주머니)은 일본에서 가장 널리 쓰이는 세탁 도구 중 하나입니다. 일본 사람들은 왜 무엇이든 세탁망에 넣느냐고 방문객들이 자주 묻습니다. 여기서는 섬유와 세탁기가 어떻게 움직이는지에서 출발해, 세탁망이 무엇을 지켜 주고 무엇을 방해하는지 정리합니다.

## A. 가장 큰 오해는 "세탁망에 넣으면 무엇이든 보호되고, 그러면서도 깨끗하게 빨린다"는 것입니다. 세탁망은 마찰, 엉킴, 늘어짐, 보풀, 올 걸림을 줄이기 위한 도구이며, 실제로는 세정력을 떨어뜨립니다. 요점은 세탁망 하나에 옷 한 벌(가득 채우지 않기), 옷에 맞는 크기 고르기, 심하게 더러운 옷은 넣지 않거나 애벌빨래하기, 용도에 맞는 그물코 굵기 고르기입니다.

## 따져 볼 점

| 항목 | 내용 |
|---|---|
| 세탁망이 하는 일 | **마찰(보풀, 색빠짐)을 줄이고, 엉킴(소매, 끈)을 막고, 늘어짐과 모양 변형을 막고, 장식(비즈, 레이스)을 보호하고, 지퍼나 후크가 다른 옷에 걸리는 것을 막습니다** |
| 세정력 | **망 안에서는 물살이 약해 때가 덜 빠집니다**. **땀과 피지가 많은 옷(속옷, 양말)은 망에 넣지 말거나 애벌빨래를 하십시오** |
| 과다 투입 | **망 용량의 절반에서 70%까지**. **망 하나에 옷 한 벌**(니트, 블라우스). 가득 채우면 빨리지도 않고 구김이 생깁니다 |
| 크기 | **옷을 접었을 때 딱 들어가는 크기**. 너무 크면 안에서 움직이며 마찰이 생깁니다 |
| 그물코 굵기 | **가는 그물코**: 니트, 스타킹, 레이스, 브래지어 ／ **굵은 그물코**: 티셔츠, 셔츠(세정력을 유지) |
| 브래지어 | **입체 형태의 브래지어 전용 망**은 컵이 변형되는 것을 막아 줍니다. 후크는 채워 주십시오 |
| 건조기 | **망에 넣은 채로 두면 건조기에서 잘 마르지 않습니다**. **먼저 꺼내십시오** |
| 세탁망 자체 | **더러워지고 보풀과 먼지가 쌓입니다**. 가끔 빨아 주고, 찢어지면 교체하십시오(풀린 망 실이 옷에 엉킵니다) |

- **취급 표시에서 세탁조 기호 아래의 선(약한 세탁)**은 "기계적 작용을 줄이라"는 뜻이며, **세탁망이 그렇게 하는 데 도움이 됩니다**. 일본은 국제 규격인 JIS L0001 취급 표시를 사용합니다. 일부 제품에는 **"세탁망 사용"이라는 표시**가 붙어 있습니다.
- 일본에서 세탁망이 보편화된 것은 **통돌이(세로형) 세탁기가 주류이고**(옷끼리 세게 비벼집니다), **"섬세한 옷"을 집에서 빠는 일이 널리 퍼졌기 때문**입니다. **드럼 세탁기는 옷을 들어 올렸다 떨어뜨리며 빨기 때문에 마찰이 달라, 세탁망의 효과도 조금 달라집니다**.
- **지퍼는 잠그고 단추는 풀기**(단추를 채운 채로 두면 당겨져 떨어집니다)가 세탁망과 함께 지켜야 할 기본 원칙입니다.

> **[확인 필요]** 기호의 의미는 소비자청 「취급 표시」 페이지에서 확인하십시오. 사용법에 관한 내용은 세제·세탁기 제조사의 일반적인 안내입니다.

## 오해 1｜망에 넣으면 무엇이든 보호된다

**막아 주는 것은 마찰, 엉킴, 모양 변형입니다**. **땀과 피지는 덜 빠지므로**, 더러운 옷은 망에 넣지 마십시오.

## 오해 2｜모든 옷을 한 망에 몰아넣는다

**가득 채우면 빨리지 않고, 구김이 생기며, 옷끼리 마찰합니다**. **망 하나에 옷 한 벌, 절반에서 70%까지만**.

## 오해 3｜망은 클수록 편하다

**옷이 안에서 움직이며 마찰합니다**. **접었을 때 딱 들어가는 크기를 쓰십시오**.

## 오해 4｜세탁망 자체는 빨 필요가 없다

**망은 보풀과 먼지, 때를 머금었다가 옷에 다시 옮깁니다**. **가끔 빨아 주고, 찢어지면 교체하십시오**.

## 오해 5｜건조기에 넣을 때도 망에 그대로 둔다

**잘 마르지 않고 구김이 생깁니다**. **건조기에 넣기 전에 망에서 꺼내거나, 널어서 말리십시오**.
