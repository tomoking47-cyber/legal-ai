# Q. 洗濯ネットの使い方について、よくある誤解は？｜世界の質問箱 #412

- 棚：`fashion` ／ URL：`/questions/using-laundry-nets` ／ ステータス：**ドラフト（法務レビュー前・出典未検証）**

洗濯ネットは日本の洗濯で最も普及した道具の一つで、海外からは「なぜ何でもネットに入れるのか」と問われます。何を守り、何を妨げるのかを、繊維と洗濯機の仕組みから整理します。

## A. 最大の誤解は「ネットに入れれば何でも守られ、汚れも落ちる」です。ネットは摩擦・絡まり・型崩れ・毛玉・引っかかりを減らす道具で、洗浄力はむしろ下がります。要点は「1枚に1着（詰め込まない）」「サイズを合わせる」「汚れの強いものは入れない、または予洗い」「目の細かさを用途で選ぶ」です。

## 判断の材料

| 項目 | 内容 |
|---|---|
| ネットの役割 | **摩擦を減らす（毛玉・色落ち）、絡まりを防ぐ（袖・ひも）、型崩れ・伸び防止、装飾（ビーズ・レース）の保護、他の衣類への引っかかり防止（ファスナー・フック）** |
| 洗浄力 | **ネットの中は水流が弱まり、汚れ落ちは下がる**。**汗・皮脂の多いもの（肌着・靴下）は入れない、または予洗い** |
| 詰め込み | **ネットの容量の半分〜7割**。**1枚に1着**（ニット・ブラウス）。詰めると洗えず、しわ |
| サイズ | **衣類を畳んでぴったり入るサイズ**。大きすぎると中で動いて摩擦 |
| 目の細かさ | **細目**：ニット・ストッキング・レース・ブラジャー／**粗目**：Tシャツ・シャツ（洗浄力を保つ） |
| ブラジャー | **専用の立体ネット**でカップの変形を防ぐ。ホックを留めて |
| 乾燥機 | **ネットのまま乾燥機に入れると乾きが悪い**。**取り出してから** |
| 洗濯ネット自体 | **汚れる・毛玉がつく**。時々洗う、破れたら交換（ネットのほつれた糸が衣類に絡む） |

- **洗濯表示の桶の下の線（弱い処理）**が示す「機械力を弱める」ことを、**ネットが補助**します。**表示に「ネット使用」の注記**がある製品も。
- **日本でネットが普及した背景**には、**縦型洗濯機（衣類同士のこすれが強い）の普及**と、**おしゃれ着の家庭洗濯の広がり**があります。**ドラム式は叩き洗いで摩擦が異なり、ネットの効果も少し変わる**。
- **ファスナーは閉め、ボタンは外す**（ボタンは留めたままだと引っ張られて取れる）は、ネット使用と合わせた基本。

> 【要検証】記号の意味は消費者庁「洗濯表示」で確認してください。使い方は洗剤・洗濯機メーカーの一般的な案内です。

## 誤解1｜ネットに入れれば何でも守られる

**守るのは摩擦・絡まり・型崩れ**。**汗・皮脂の汚れ落ちは下がる**ため、汚れ物は入れない。

## 誤解2｜1つのネットにまとめて入れる

**詰め込むと洗えず、しわになり、衣類同士がこすれる**。**1着1枚、容量の半分〜7割**。

## 誤解3｜大きいネットのほうが便利

**中で衣類が動いて摩擦**。**畳んでぴったりのサイズ**。

## 誤解4｜ネットは洗わなくてよい

**ネット自体に糸くず・毛玉・汚れが付き、衣類に戻ります**。**時々洗い、破れたら替える**。

## 誤解5｜乾燥機もネットのまま

**乾きが悪く、しわになる**。**ネットから出して乾燥機、または干す**。
