# Q. 关于洗衣网（网眼洗衣袋）的使用，常见的误解有哪些？｜Japan Questions #412

- Shelf: `fashion` ／ URL: `/zh-cn/fashion/using-laundry-nets` ／ Status: **草稿 — 出处未核实**

洗衣网（「洗濯ネット」sentaku netto，带拉链的网眼洗衣袋）是日本使用最广泛的洗衣工具之一。外国访客常常问，日本人为什么什么都要装进洗衣网里。本文从纤维的性质和洗衣机的工作方式出发，说明洗衣网能保护什么、又会妨碍什么。

## A. 最大的误解是「装进洗衣网里，什么都能得到保护，而且照样洗得干净」。洗衣网是用来减少摩擦、缠绕、变形、起球和勾丝的工具，它实际上会降低洗净力。要点是：一个网只装一件衣服（不要塞满）；网的尺寸要与衣物相配；污渍重的衣物不要装网，或先预洗；根据用途选择网眼的粗细。

## 需要权衡的要点

| 项目 | 详情 |
|---|---|
| 洗衣网的作用 | **减少摩擦（起球、掉色），防止缠绕（袖子、抽绳），防止拉伸变形，保护装饰（珠子、蕾丝），防止拉链和挂钩勾住其他衣物** |
| 洗净力 | **网内的水流较弱，污渍不容易洗掉**。**汗渍和皮脂重的衣物（内衣、袜子）不要装网，或先预洗** |
| 塞得过满 | **装到网容量的一半至七成**。**一个网装一件衣服**（针织衫、衬衫）。塞满了洗不干净，还会满是褶皱 |
| 尺寸 | **衣物折好后刚好放得下的尺寸**。太大的话衣物会在里面晃动摩擦 |
| 网眼粗细 | **细网眼**：针织衫、丝袜、蕾丝、文胸 ／ **粗网眼**：T恤、衬衫（保持洗净力） |
| 文胸 | **立体成型的文胸专用网**可防止罩杯变形。要扣好挂钩 |
| 烘干机 | **留在网里放进烘干机，衣物很难烘干**。**先取出来** |
| 洗衣网本身 | **也会变脏，积聚棉绒和毛球**。要时不时清洗；破了就更换（网上的线头会缠住衣物） |

- **洗涤标签上洗衣盆图案下方的横线（柔和洗涤）**的意思是「减弱机械作用」，**使用洗衣网有助于做到这一点**。日本采用国际通用的JIS L0001洗涤标识。有些产品的标签上会**注明「请使用洗衣网」**。
- 洗衣网在日本普及，是因为**波轮式洗衣机（衣物之间摩擦强烈）是主流**，而且**在家洗涤「精细衣物」的做法变得普遍**。**滚筒式洗衣机是把衣物提起再落下来洗涤，摩擦方式不同，洗衣网的效果也略有差异**。
- **拉上拉链、解开纽扣**（纽扣扣着会被拉扯而脱落）是与洗衣网搭配的基本规则。

## 误解1｜装进网里什么都能得到保护

**它能防的是摩擦、缠绕和变形**。**汗渍和皮脂不容易洗掉**，所以脏污重的衣物不要装网。

## 误解2｜把所有衣物都装进一个网里

**塞满了洗不干净，会起褶皱，衣物之间还会互相摩擦**。**一个网装一件衣服，装到一半至七成**。

## 误解3｜网越大越方便

**衣物会在里面晃动摩擦**。**要用衣物折好后刚好放得下的尺寸**。

## 误解4｜洗衣网本身不需要清洗

**网会沾上棉绒、毛球和污垢，再把它们传回衣物上**。**要时不时清洗；破了就更换**。

## 误解5｜烘干时也留在网里

**很难烘干，还会起褶皱**。**放进烘干机前从网里取出，或者晾起来**。
