# Q. 關於洗衣網（網狀洗衣袋）的使用，常見的誤解有哪些？｜Japan Questions #412

- Shelf: `fashion` ／ URL: `/zh-tw/fashion/using-laundry-nets` ／ Status: **草稿 — 出處未核實**

洗衣網（「洗濯ネット」sentaku netto，附拉鍊的網狀洗衣袋）是日本使用最廣泛的洗衣工具之一。外國旅客常常問，日本人為什麼什麼都要裝進洗衣網裡。本文從纖維的性質與洗衣機的運作方式出發，說明洗衣網能保護什麼、又會妨礙什麼。

## A. 最大的誤解是「裝進洗衣網裡，什麼都能受到保護，而且照樣洗得乾淨」。洗衣網是用來減少摩擦、纏繞、變形、起毛球與勾紗的工具，它其實會降低洗淨力。重點是：一個網只裝一件衣服（不要塞滿）；網的尺寸要與衣物相配；髒污重的衣物不要裝網，或先預洗；依用途選擇網目的粗細。

## 需要權衡的重點

| 項目 | 詳情 |
|---|---|
| 洗衣網的作用 | **減少摩擦（起毛球、褪色），防止纏繞（袖子、抽繩），防止拉伸變形，保護裝飾（珠子、蕾絲），防止拉鍊與掛勾勾到其他衣物** |
| 洗淨力 | **網內的水流較弱，髒污比較洗不掉**。**汗漬與皮脂重的衣物（內衣、襪子）不要裝網，或先預洗** |
| 塞得太滿 | **裝到網容量的一半至七成**。**一個網裝一件衣服**（針織衫、襯衫）。塞滿了洗不乾淨，還會皺成一團 |
| 尺寸 | **衣物摺好後剛好放得下的尺寸**。太大的話衣物會在裡面晃動摩擦 |
| 網目粗細 | **細網目**：針織衫、絲襪、蕾絲、內衣 ／ **粗網目**：T恤、襯衫（維持洗淨力） |
| 內衣 | **立體成型的內衣專用網**可防止罩杯變形。要扣好背扣 |
| 烘衣機 | **留在網裡放進烘衣機，衣物很難烘乾**。**先取出來** |
| 洗衣網本身 | **也會變髒，累積棉絮與毛球**。要不時清洗；破了就更換（網上鬆脫的線頭會纏住衣物） |

- **洗滌標示上洗衣盆圖案下方的橫線（緩和洗滌）**的意思是「減弱機械作用」，**使用洗衣網有助於做到這一點**。日本採用國際通用的JIS L0001洗滌標示。有些產品的標籤上會**註明「請使用洗衣網」**。
- 洗衣網在日本普及，是因為**直立式洗衣機（衣物之間摩擦強烈）是主流**，而且**在家清洗「精緻衣物」的做法變得普遍**。**滾筒式洗衣機是把衣物舉起再落下來洗滌，摩擦方式不同，洗衣網的效果也略有差異**。
- **拉上拉鍊、解開鈕扣**（鈕扣扣著會被拉扯而脫落）是與洗衣網搭配的基本原則。

> **[待核實]** 標示的含義請對照消費者廳「洗滌標示」頁面核實。使用建議為清潔劑與洗衣機廠商的一般性指南。

## 誤解1｜裝進網裡什麼都能受到保護

**它能防的是摩擦、纏繞與變形**。**汗漬與皮脂比較洗不掉**，所以髒污重的衣物不要裝網。

## 誤解2｜把所有衣物都裝進一個網裡

**塞滿了洗不乾淨，會起皺，衣物之間還會互相摩擦**。**一個網裝一件衣服，裝到一半至七成**。

## 誤解3｜網越大越方便

**衣物會在裡面晃動摩擦**。**要用衣物摺好後剛好放得下的尺寸**。

## 誤解4｜洗衣網本身不需要清洗

**網會沾上棉絮、毛球與髒污，再把它們傳回衣物上**。**要不時清洗；破了就更換**。

## 誤解5｜烘乾時也留在網裡

**很難烘乾，還會起皺**。**放進烘衣機前先從網裡取出，或者晾起來**。
