# Q. 关于晾衣服（更快晾干、避免褶皱），常见的误解有哪些？｜Japan Questions #413

- Shelf: `fashion` ／ URL: `/zh-cn/fashion/hanging-laundry-to-dry-faster` ／ Status: **草稿 — 出处未核实**

晾衣服的方法是日本在家务中钻研得最深的一项，外国访客常常问日本人为什么这么讲究。在日本，洗好的衣物通常不用烘干机，而是晾在阳台或室内。本文从空气如何流动、纤维如何变化出发，说明决定晾干速度与成品效果的因素。

## A. 最大的误解是「怎么晾都一样，晒太阳就干得快」。决定晾干速度的，与其说是阳光，不如说是风（空气交换），再加上衣物之间的间距和残留水分的多少（脱水程度、毛巾厚度）。基本做法是：衣物之间留出10〜15厘米；长短衣物交错排列（「拱形晾晒」）；厚的挂两边、薄的挂中间；晾之前抖开褶皱；让空气流动起来。

## 决定晾干速度的因素

| 因素 | 详情 | 诀窍 |
|---|---|---|
| **风（空气交换）** | 潮湿空气从衣物旁边移走得越快，干得越快。**风比太阳更管用** | **电风扇或空气循环扇**（参见室内晾衣的文章），**留出间距** |
| **间距** | **10〜15厘米**以上 | 挤在一起，每件衣物都会被旁边的衣物弄潮 |
| **排列** | **拱形晾晒**：长而厚的挂两边，短而薄的挂中间 → 下方形成通风的通道 | 方形晾衣架（「角ハンガー」kaku hangā，带许多夹子的长方形架子） |
| **形状** | **晾成筒状**（把T恤和裤子撑开成筒状，让空气通过）；**牛仔裤翻面，晾成筒状** | 口袋也能晾干 |
| **脱水** | 充分脱水（**标签要求柔和脱水的衣物除外**） | 水分越少，干得越快 |
| **厚度** | **毛巾要摊开，不要重叠**；**连帽衫：把帽子单独提起来（倒挂）** | 让不易干的部分露出来 |
| **时间段** | **早上晾，下午收**。**在傍晚湿气上来之前** | — |

## 防止褶皱

| 诀窍 | 详情 |
|---|---|
| **晾之前抖一抖** | **用力抖两三下把褶皱抖开**。**沿着缝线拉一拉，把形状定住** |
| **马上晾出去** | 洗完后放着不管会产生褶皱和异味 |
| **衣架的形状** | **与肩宽相配的厚衣架**。铁丝衣架会在肩部留下痕迹 |
| **拍平** | **用手掌轻轻拍打**，抚平褶皱 |
| **在完全干透前收进来** | 衬衫**在快干时收进来熨烫**（参见褶皱的文章） |

- **阳光的作用**，**与其说是晾干，不如说是杀菌、除臭和漂白**（白色衣物）。**有颜色的衣物在阴处晾**（紫外线会使其褪色）。
- **室内晾衣的异味**来自**晾干时间过长**（参见毛巾的文章与室内晾衣的文章）。通常引用的经验法则是**「5小时内晾干」**。

> **[待核实]** 晾晒方法的效果，为基于厂商（洗涤剂、洗衣机、晾衣架）测试的一般性指南。

## 误解1｜晒太阳就干得快

**风更管用。** **有微风的阴天能晾干；没有风的晴天反而慢**。**即使在室内，用电风扇几个小时也能搞定**。

## 误解2｜挤紧一点就能一次晾更多

**没有间隙，每件衣物都会被旁边的衣物弄潮，这会产生异味**。**间隔10〜15厘米，拱形晾晒**。

## 误解3｜有颜色的衣物也放到太阳下杀菌

**紫外线会使其褪色**。**有颜色的衣物晾在阴处或翻面晾；白色衣物和毛巾晾在太阳下**。

## 误解4｜熨斗能把褶皱熨掉，所以怎么晾都无所谓

**抖开、定形、马上晾出去，能大幅减少熨烫的工夫**。**在快干时收进来**还能进一步帮上忙。

## 误解5｜晚上晾比较凉快、效率高

**傍晚的湿气和高湿度会拖慢晾干速度并产生异味**。**早上晾，下午收**；**晚上就在室内配合电风扇晾**。
