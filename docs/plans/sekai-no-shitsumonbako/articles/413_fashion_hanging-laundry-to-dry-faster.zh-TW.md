# Q. 關於晾衣服（更快晾乾、避免皺褶），常見的誤解有哪些？｜Japan Questions #413

- Shelf: `fashion` ／ URL: `/zh-tw/fashion/hanging-laundry-to-dry-faster` ／ Status: **草稿 — 出處未核實**

晾衣服的方法是日本在家事中鑽研得最深的一項，外國旅客常常問日本人為什麼這麼講究。在日本，洗好的衣物通常不用烘衣機，而是晾在陽台或室內。本文從空氣如何流動、纖維如何變化出發，說明決定晾乾速度與成品效果的因素。

## A. 最大的誤解是「怎麼晾都一樣，曬太陽就乾得快」。決定晾乾速度的，與其說是陽光，不如說是風（空氣交換），再加上衣物之間的間距與殘留水分的多寡（脫水程度、毛巾厚度）。基本做法是：衣物之間留出10〜15公分；長短衣物交錯排列（「拱形晾曬」）；厚的掛兩邊、薄的掛中間；晾之前抖開皺褶；讓空氣流動起來。

## 決定晾乾速度的因素

| 因素 | 詳情 | 訣竅 |
|---|---|---|
| **風（空氣交換）** | 潮濕空氣從衣物旁邊帶走得越快，乾得越快。**風比太陽更管用** | **電風扇或空氣循環扇**（參見室內晾衣的文章），**留出間距** |
| **間距** | **10〜15公分**以上 | 擠在一起，每件衣物都會被旁邊的衣物弄濕 |
| **排列** | **拱形晾曬**：長而厚的掛兩邊，短而薄的掛中間 → 下方形成通風的通道 | 方形晾衣架（「角ハンガー」kaku hangā，附許多夾子的長方形架子） |
| **形狀** | **晾成筒狀**（把T恤與褲子撐開成筒狀，讓空氣通過）；**牛仔褲翻面，晾成筒狀** | 口袋也能晾乾 |
| **脫水** | 充分脫水（**標示要求緩和脫水的衣物除外**） | 水分越少，乾得越快 |
| **厚度** | **毛巾要攤開，不要重疊**；**連帽衫：把帽子單獨提起來（倒掛）** | 讓不易乾的部分露出來 |
| **時段** | **早上晾，下午收**。**在傍晚濕氣上來之前** | — |

## 防止皺褶

| 訣竅 | 詳情 |
|---|---|
| **晾之前抖一抖** | **用力抖兩三下把皺褶抖開**。**沿著縫線拉一拉，把形狀定住** |
| **馬上晾出去** | 洗完後放著不管會產生皺褶與異味 |
| **衣架的形狀** | **與肩寬相配的厚衣架**。鐵絲衣架會在肩部留下痕跡 |
| **拍平** | **用手掌輕輕拍打**，撫平皺褶 |
| **在完全乾透前收進來** | 襯衫**在快乾時收進來熨燙**（參見皺褶的文章） |

- **陽光的作用**，**與其說是晾乾，不如說是殺菌、除臭與漂白**（白色衣物）。**有顏色的衣物在陰處晾**（紫外線會使其褪色）。
- **室內晾衣的異味**來自**晾乾時間過長**（參見毛巾的文章與室內晾衣的文章）。一般引用的經驗法則是**「5小時內晾乾」**。

> **[待核實]** 晾曬方法的效果，為基於廠商（清潔劑、洗衣機、曬衣架）測試的一般性指南。

## 誤解1｜曬太陽就乾得快

**風更管用。** **有微風的陰天能晾乾；沒有風的晴天反而慢**。**即使在室內，用電風扇幾個小時也能搞定**。

## 誤解2｜擠緊一點就能一次晾更多

**沒有間隙，每件衣物都會被旁邊的衣物弄濕，這會產生異味**。**間隔10〜15公分，拱形晾曬**。

## 誤解3｜有顏色的衣物也放到太陽下殺菌

**紫外線會使其褪色**。**有顏色的衣物晾在陰處或翻面晾；白色衣物與毛巾晾在太陽下**。

## 誤解4｜熨斗能把皺褶燙掉，所以怎麼晾都無所謂

**抖開、定形、馬上晾出去，能大幅減少熨燙的工夫**。**在快乾時收進來**還能進一步幫上忙。

## 誤解5｜晚上晾比較涼快、效率高

**傍晚的濕氣與高濕度會拖慢晾乾速度並產生異味**。**早上晾，下午收**；**晚上就在室內搭配電風扇晾**。
