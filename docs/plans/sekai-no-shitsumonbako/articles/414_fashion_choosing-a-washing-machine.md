# Q. 洗濯機の選び方（縦型・ドラム式）について、よくある誤解は？｜世界の質問箱 #414

- 棚：`fashion` ／ URL：`/questions/choosing-a-washing-machine` ／ ステータス：**ドラフト（法務レビュー前・出典未検証）**

日本の洗濯機は縦型が主流で、ドラム式が増えているという構成で、海外（ドラム式が標準）とは逆です。「どちらが汚れが落ちるか」「電気代・水道代は」「乾燥は」を、家電製品協会・資源エネルギー庁の資料から整理します。

## A. 最大の誤解は「ドラム式のほうが新しくて何でも優れている」です。縦型はたっぷりの水でこすり洗いをするため泥・皮脂の汚れ落ちに強く、本体が安い。ドラム式は少ない水で叩き洗いをするため節水で衣類への摩擦が少なく、乾燥（ヒートポンプ）が得意で電気代が安い。家庭の条件（乾燥機能を使うか、設置スペース、汚れの種類）で選ぶものです。

## 比較（家電製品協会・メーカー資料に基づく一般的な整理）

| 項目 | 縦型 | ドラム式 |
|---|---|---|
| 洗い方 | **たっぷりの水で、衣類同士をこすり合わせる（もみ洗い）** | **少ない水で、持ち上げて落とす（叩き洗い）** |
| 汚れ落ち | **泥・皮脂・泥汚れに強い** | **皮脂には強いが、泥・固形汚れはやや弱い**とされる |
| 衣類への負担 | **摩擦が大きい**（毛玉・色落ち→ネットの記事） | **摩擦が少ない** |
| 水の使用量 | **約100〜150L／回** | **約60〜90L／回**（乾燥なし） |
| 乾燥 | **ヒーター式が多く、電気代が高い**（1回約60〜70円）、シワになりやすい | **ヒートポンプ式が主流、電気代が安い**（1回約20〜30円）、**乾燥機能を毎日使うならドラム式** |
| 本体価格 | **安い**（5〜15万円） | **高い**（15〜30万円） |
| 設置 | **奥行きが浅く、幅60cm前後**。**上から出し入れ** | **奥行き・幅が大きい**、**扉の開閉スペース**、**防水パンのサイズ**を確認。**前から出し入れ（腰の負担が少ない）** |
| 洗濯槽の手入れ | 槽洗浄（洗濯槽の記事参照） | **ゴムパッキンの裏のカビ**、フィルター |
| 国内シェア | **約75%**（2024年度） | **約25%で増加中**（ドラム式洗濯乾燥機は5年連続で出荷台数が過去最高） |

- **資源エネルギー庁「省エネ性能カタログ」**で**機種ごとの年間消費電力量・水量**が比較できます。**乾燥を使うかどうか**で電気代の差が大きい。
- **ヒートポンプ乾燥（ドラム式）**は**約60℃の低温**で衣類に優しく、**ヒーター式（縦型に多い）**は高温で縮みやすい（乾燥機の記事参照）。
- **洗濯容量**：**1人1日約1.5kg**が目安。**4人家族で7〜8kg**、**毛布を洗うなら7kg以上**（毛布の記事参照）。

> 【要検証】水量・電気代・シェアの数値は家電製品協会・資源エネルギー庁・業界統計の最新値で確認してください。

## 誤解1｜ドラム式のほうが何でも優れている

**汚れ落ち（泥・固形）と価格は縦型が有利、節水・乾燥・衣類への優しさはドラム式**。**条件で選ぶ**。

## 誤解2｜ドラム式は節水だから水道代が大きく減る

**1回あたり数十Lの差**で、**年間数千円程度**。**本体価格の差（10万円以上）を回収するのは長い**。**乾燥の電気代**のほうが差が大きい。

## 誤解3｜乾燥機能はどちらも同じ

**ヒートポンプ（ドラム式）は低温・低電力、ヒーター式（縦型）は高温・高電力**。**毎日乾燥機を使うならドラム式**が一般的な結論。

## 誤解4｜大きい容量ほどよい

**容量に対して少ない量で回すと、水と電気の無駄**。**家族の人数×1.5kg＋余裕**。**毛布・布団を洗うなら7kg以上**。

## 誤解5｜設置は業者に任せれば入る

**防水パンのサイズ、蛇口の高さ、搬入経路（階段・廊下の幅）、扉の開く方向**を事前に測る。**ドラム式は搬入できずに返品**の事例が多い。
