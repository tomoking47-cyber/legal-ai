# Q. 关于洗衣机的选择（波轮式还是滚筒式），常见的误解有哪些？｜Japan Questions #414

- Shelf: `fashion` ／ URL: `/zh-cn/fashion/choosing-a-washing-machine` ／ Status: **草稿 — 出处未核实**

在日本，波轮式洗衣机（「縦型」tategata）是主流，滚筒式（「ドラム式」doramu-shiki）正在扩大份额——这与滚筒式为标配的许多其他国家正好相反。哪种洗得更干净，电费水费各是多少，烘干效果如何：本文依据家电制品协会与资源能源厅的资料来说明。

## A. 最大的误解是「滚筒式更新，所以样样都更好」。波轮式用大量的水让衣物互相揉搓，因此对付泥污和皮脂很有力，机器本身也更便宜。滚筒式用少量的水把衣物提起再落下，因此节水、摩擦小，而且擅长烘干（热泵式），电费也更低。请根据自家的情况来选：是否会使用烘干功能、有多大空间、要对付什么样的污渍。

## 对比（基于家电制品协会与厂商资料的概括）

| 项目 | 波轮式 | 滚筒式 |
|---|---|---|
| 洗涤方式 | **水量大，衣物互相揉搓（揉搓洗）** | **水量少，衣物被提起再落下（翻滚洗）** |
| 洗净力 | **对付泥污、皮脂和顽固污渍很有力** | 一般说法是**对皮脂有力，但对泥污和固体污渍稍弱** |
| 对衣物的损耗 | **摩擦较大**（起球、掉色 → 参见洗衣网的文章） | **摩擦较小** |
| 用水量 | **每次约100〜150升** | **每次约60〜90升**（不含烘干） |
| 烘干 | **多为加热器式，电费高**（每次约60〜70日元），容易起褶皱 | **多为热泵式，电费低**（每次约20〜30日元）；**如果每天都要用烘干功能，就选滚筒式** |
| 机器价格 | **便宜**（5〜15万日元） | **贵**（15〜30万日元） |
| 安装 | **进深浅，宽度60厘米左右**。**从上方取放** | **进深与宽度都更大**；要确认**门开合所需的空间**与**防水底盘（「防水パン」bōsui pan，日本多数住宅中放在洗衣机下面的塑料托盘）的尺寸**。**从前方取放（腰部负担小）** |
| 机器的清洁 | 洗衣槽清洁行程（参见洗衣槽的文章） | **门口橡胶密封圈内侧的霉菌**、过滤网 |
| 在日本的份额 | **约 75%**（2024年度） | **约 25%，正在增加**（滚筒式洗干一体机的出货量连续 5 年创新高） |

- **资源能源厅的「节能性能目录」**可以**按机型比较年度耗电量与用水量**。**是否使用烘干功能**对电费的影响最大。
- **热泵烘干（滚筒式）**在**约60℃的低温**下工作，对衣物温和；**加热器式烘干（波轮式常见）**温度高，衣物更容易缩水（参见烘干机的文章）。
- **容量**：以**每人每天约1.5公斤**为参考。**四口之家7〜8公斤**，**想洗毛毯则需7公斤以上**（参见毛毯的文章）。

## 误解1｜滚筒式样样都更好

**在洗净力（泥污、固体污渍）和价格上波轮式占优；在节水、烘干和对衣物温和上滚筒式占优**。**请根据自身情况选择**。

## 误解2｜滚筒式节水，所以水费会大幅下降

**每次的差距是几十升**，折算下来**一年几千日元**。**要收回机器的差价（10万日元以上）需要很长时间**。**烘干的电费**差距更大。

## 误解3｜两者的烘干功能是一样的

**热泵式（滚筒式）低温、低耗电；加热器式（波轮式）高温、高耗电**。**如果每天都要烘干，就选滚筒式**，这是通常的结论。

## 误解4｜容量越大越好

**在大容量机器里洗少量衣物，会浪费水和电**。**家庭人数×1.5公斤，再留一点余量**。**想洗毛毯和被子则需7公斤以上**。

## 误解5｜安装交给送货师傅就一定装得下

请事先测量：**防水底盘、水龙头的高度、搬运路线（楼梯、走廊宽度）以及门的开启方向**。**滚筒式洗衣机搬不进去只好退货**是常有的事。
