# Q. 關於洗衣機的選擇（直立式還是滾筒式），常見的誤解有哪些？｜Japan Questions #414

- Shelf: `fashion` ／ URL: `/zh-tw/fashion/choosing-a-washing-machine` ／ Status: **草稿 — 出處未核實**

在日本，直立式洗衣機（「縦型」tategata）是主流，滾筒式（「ドラム式」doramu-shiki）正在擴大市佔——這與滾筒式為標準配備的許多其他國家正好相反。哪一種洗得更乾淨、電費水費各是多少、烘乾效果如何：本文依據家電製品協會與資源能源廳的資料來說明。

## A. 最大的誤解是「滾筒式比較新，所以樣樣都更好」。直立式用大量的水讓衣物互相搓揉，因此對付泥污與皮脂很有力，機器本身也比較便宜。滾筒式用少量的水把衣物舉起再落下，因此節水、摩擦小，而且擅長烘乾（熱泵式），電費也更低。請依自家的情況來選：是否會使用烘乾功能、有多大空間、要對付什麼樣的髒污。

## 比較（依家電製品協會與廠商資料整理的概要）

| 項目 | 直立式 | 滾筒式 |
|---|---|---|
| 洗滌方式 | **水量大，衣物互相搓揉（搓揉洗）** | **水量少，衣物被舉起再落下（翻滾洗）** |
| 洗淨力 | **對付泥污、皮脂與頑固髒污很有力** | 一般說法是**對皮脂有力，但對泥污與固體髒污稍弱** |
| 對衣物的耗損 | **摩擦較大**（起毛球、褪色 → 參見洗衣網的文章） | **摩擦較小** |
| 用水量 | **每次約100〜150公升** | **每次約60〜90公升**（不含烘乾） |
| 烘乾 | **多為加熱器式，電費高**（每次約30〜50日圓），容易起皺 | **多為熱泵式，電費低**（每次約15〜30日圓）；**如果每天都要用烘乾功能，就選滾筒式** |
| 機器價格 | **便宜**（5〜15萬日圓） | **貴**（15〜30萬日圓） |
| 安裝 | **深度淺，寬度60公分左右**。**從上方取放** | **深度與寬度都更大**；要確認**門開合所需的空間**與**防水底盤（「防水パン」bōsui pan，日本多數住宅中放在洗衣機下面的塑膠托盤）的尺寸**。**從前方取放（腰部負擔較小）** |
| 機器的清潔 | 洗衣槽清潔行程（參見洗衣槽的文章） | **門口橡膠密封圈內側的黴菌**、濾網 |
| 在日本的市佔 | **約七成**（2020年代） | **約三成，持續增加** |

- **資源能源廳的「節能性能型錄」**可以**依機型比較年度耗電量與用水量**。**是否使用烘乾功能**對電費的影響最大。
- **熱泵烘乾（滾筒式）**在**約60℃的低溫**下運作，對衣物溫和；**加熱器式烘乾（直立式常見）**溫度高，衣物比較容易縮水（參見烘衣機的文章）。
- **容量**：以**每人每天約1.5公斤**為參考。**四口之家7〜8公斤**，**想洗毛毯則需7公斤以上**（參見毛毯的文章）。

> **[待核實]** 用水量、電費與市佔率的數字，請對照家電製品協會、資源能源廳及產業統計的最新數值核實。

## 誤解1｜滾筒式樣樣都更好

**在洗淨力（泥污、固體髒污）與價格上直立式佔優；在節水、烘乾與對衣物溫和上滾筒式佔優**。**請依自身情況選擇**。

## 誤解2｜滾筒式節水，所以水費會大幅下降

**每次的差距是幾十公升**，換算下來**一年幾千日圓**。**要回收機器的價差（10萬日圓以上）需要很長時間**。**烘乾的電費**差距更大。

## 誤解3｜兩者的烘乾功能是一樣的

**熱泵式（滾筒式）低溫、低耗電；加熱器式（直立式）高溫、高耗電**。**如果每天都要烘乾，就選滾筒式**，這是一般的結論。

## 誤解4｜容量越大越好

**在大容量機器裡洗少量衣物，會浪費水與電**。**家庭人數×1.5公斤，再留一點餘裕**。**想洗毛毯與棉被則需7公斤以上**。

## 誤解5｜安裝交給送貨師傅就一定裝得下

請事先測量：**防水底盤、水龍頭的高度、搬運路線（樓梯、走廊寬度）以及門的開啟方向**。**滾筒式洗衣機搬不進去只好退貨**是常有的事。
