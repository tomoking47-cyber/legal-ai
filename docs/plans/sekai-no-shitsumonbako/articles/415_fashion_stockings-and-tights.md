# Q. ストッキング・タイツの扱いについて、よくある誤解は？｜世界の質問箱 #415

- 棚：`fashion` ／ URL：`/questions/stockings-and-tights` ／ ステータス：**ドラフト（法務レビュー前・出典未検証）**

ストッキングは「1回で伝線した」が世界共通の不満で、日本では通勤・制服での着用が多いため、長持ちさせる知恵が共有されています。素材の性質（ナイロン・ポリウレタン）と、洗い方・履き方から整理します。

## A. 最大の誤解は「ストッキングは消耗品で、伝線は運」です。伝線の多くは、履くときの爪・指輪・かかとの角質、洗濯機での絡まり、乾燥機の熱が原因で、避けられます。基本は「履く前に手を保湿し爪を整える」「たぐって足先から」「手洗いかネットで洗濯」「乾燥機不可」「予備を1足持つ」です。

## 判断の材料

| 項目 | 内容 |
|---|---|
| 素材 | **ナイロン＋ポリウレタン**。**ポリウレタンは熱・塩素・紫外線・経年で劣化**（2〜3年） |
| 伝線の原因 | **爪・指輪・ささくれ、かかと・ひじの角質（かかとの記事参照）、靴の内側の縫い目、洗濯機での絡まり、乾燥機** |
| 履き方 | **手を保湿し、爪を整え、指輪を外す**。**つま先から、たぐって少しずつ**。**かかとを合わせてから引き上げる** |
| デニール | **数字が大きいほど厚い**：**20〜30デニール**はストッキング（透ける）、**40〜80**は薄手タイツ、**110以上**は厚手 |
| 洗い方 | **手洗い（押し洗い）または洗濯ネット（細目）で弱水流**。**中性洗剤**。**他の衣類のフックと絡ませない** |
| 乾かす | **陰干し、乾燥機不可**（熱でポリウレタンが劣化・縮む） |
| 保管 | **丸めて引き出し**。**直射日光を避ける** |
| 補修 | **伝線の始まりにマニキュアのトップコートまたは接着剤を少量**で広がりを止める（応急） |
| 寿命 | **ストッキングは数回〜10回程度、タイツは1シーズン**が目安 |

- **家庭用品品質表示法**で**素材（ナイロン・ポリウレタンの%）と洗濯表示**が義務。**「伝線しにくい」加工**は表示があり、**編み方（交編）**で差が出ます。
- **足のむくみ**と**着圧ストッキング**：**市販の着圧製品は雑貨で効能表示不可**（立ち仕事の記事参照）。**医療用弾性ストッキングは別**。
- **冬のタイツと静電気**：**ナイロンはプラスに帯電**しやすく、**アクリルのスカートと組み合わせると静電気**（静電気の記事参照）。

> 【要検証】素材の性質は繊維団体の一般的な説明、表示義務は消費者庁の資料で確認してください。

## 誤解1｜伝線は運

**爪・指輪・角質・靴の縫い目・洗濯**が主因。**履く前の準備**で大きく減る。

## 誤解2｜洗濯機にそのまま入れてよい

**他の衣類のフック・ファスナーに絡んで伝線**。**細目のネットで弱水流、または手洗い**。

## 誤解3｜乾燥機で早く乾く

**ポリウレタンが熱で劣化・縮み、伝線しやすくなる**。**陰干し**。

## 誤解4｜高いストッキングは伝線しない

**編み方と加工で差はある**が、**履き方と洗い方の影響のほうが大きい**。**予備を1足バッグに**が実践的。

## 誤解5｜デニール数は品質

**デニールは糸の太さ（厚さ）**で、品質ではありません。**季節と用途で選ぶ**（20〜30で透け、80以上で防寒）。
