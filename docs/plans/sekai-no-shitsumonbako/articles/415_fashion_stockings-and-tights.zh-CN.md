# Q. 关于丝袜与连裤袜，常见的误解有哪些？｜Japan Questions #415

- Shelf: `fashion` ／ URL: `/zh-cn/fashion/stockings-and-tights` ／ Status: **草稿 — 出处未核实**

「第一次穿就抽丝了」是全世界共同的抱怨。在日本，丝袜广泛用于通勤和制服搭配，因此关于如何让丝袜更耐穿，人们分享了不少心得。本文从纤维（尼龙与聚氨酯）出发，结合洗涤与穿着的方法来说明。

## A. 最大的误解是「丝袜是消耗品，抽丝全看运气」。大多数抽丝来自穿的时候的指甲、戒指和粗糙的脚后跟皮肤，来自在洗衣机里的缠绕，以及来自烘干机的高温——这些都是可以避免的。基本做法是：穿之前给手保湿、修剪指甲；把袜子聚拢起来，从脚尖开始穿；手洗或使用洗衣网；不要用烘干机；随身备一双。

## 需要权衡的要点

| 项目 | 详情 |
|---|---|
| 纤维 | **尼龙加聚氨酯（弹性纤维）**。**聚氨酯会因高温、氯、紫外线和时间而劣化**（2〜3年） |
| 抽丝的原因 | **指甲、戒指、倒刺；脚后跟与手肘的粗糙皮肤（参见脚后跟的文章）；鞋子内侧的缝线；在洗衣机里缠绕；烘干机** |
| 穿着方法 | **给手保湿、修剪指甲、摘下戒指**。**从脚尖开始，把袜腿聚拢起来，一点一点往上提**。**先把脚后跟位置对准，再往上拉** |
| 丹尼数 | **数字越大越厚**：**30丹以下**是透明丝袜，**30〜80丹**是薄连裤袜，**80丹以上**是厚连裤袜（分界线因厂家而异，在 20〜30 丹之间） |
| 洗涤 | **手洗（轻轻按压）或用细网眼洗衣网走柔和行程**。**中性洗涤剂（「中性洗剤」chūsei senzai）**。**要远离其他衣物上的挂钩** |
| 晾干 | **在阴处晾干；不要用烘干机**（高温会使聚氨酯劣化并收缩） |
| 收纳 | **卷起来放在抽屉里**。**避开阳光直射** |
| 修补 | **在抽丝起点处点上一点透明指甲油面油或胶水**，可以阻止它蔓延（应急措施） |
| 使用寿命 | 参考值：**丝袜穿几次到约10次；连裤袜一季** |

- 根据**《家庭用品品质表示法》**，**纤维成分（尼龙百分比、聚氨酯百分比）与洗涤标识**是强制标注的。**「抗抽丝」加工**会有标注，**编织方式（混纤编织）**也会带来差异。
- **腿部浮肿**与**压力袜**：**商店销售的压力产品属于一般商品，不得宣称任何功效**（参见站立工作的文章）。**医用弹力袜属于另一个类别**。
- **冬季连裤袜与静电**：**尼龙容易带正电**，**与腈纶裙子搭配穿会积聚静电**（参见静电的文章）。

## 误解1｜抽丝全看运气

**指甲、戒指、粗糙的皮肤、鞋子的缝线和洗涤**是主要原因。**穿之前做好准备**能大幅减少抽丝。

## 误解2｜可以直接扔进洗衣机

**会被其他衣物的挂钩和拉链缠住而抽丝**。**用细网眼洗衣网走柔和行程，或者手洗**。

## 误解3｜烘干机能很快烘干

**高温会使聚氨酯劣化并收缩，反而更容易抽丝**。**在阴处晾干**。

## 误解4｜贵的丝袜不会抽丝

**编织方式和加工确实有一定影响**，但**穿着和洗涤的方法影响更大**。**在包里备一双**才是实际的办法。

## 误解5｜丹尼数是品质的标准

**丹尼数是纱线的粗细（布料有多厚）**，不是品质。**请按季节和用途选择**（20〜30丹用于透明感，80丹以上用于保暖）。
