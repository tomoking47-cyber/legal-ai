# Q. 關於絲襪與褲襪，常見的誤解有哪些？｜Japan Questions #415

- Shelf: `fashion` ／ URL: `/zh-tw/fashion/stockings-and-tights` ／ Status: **草稿 — 出處未核實**

「第一次穿就勾破了」是全世界共同的抱怨。在日本，絲襪廣泛用於通勤與制服搭配，因此關於如何讓絲襪更耐穿，人們分享了不少心得。本文從纖維（尼龍與聚氨酯）出發，結合清洗與穿著的方法來說明。

## A. 最大的誤解是「絲襪是消耗品，勾紗全看運氣」。大多數的抽絲來自穿的時候的指甲、戒指與粗糙的腳跟皮膚，來自在洗衣機裡的纏繞，以及來自烘衣機的高溫——這些都是可以避免的。基本做法是：穿之前為手保濕、修剪指甲；把襪子聚攏起來，從腳尖開始穿；手洗或使用洗衣網；不要用烘衣機；隨身備一雙。

## 需要權衡的重點

| 項目 | 詳情 |
|---|---|
| 纖維 | **尼龍加聚氨酯（彈性纖維）**。**聚氨酯會因高溫、氯、紫外線與時間而劣化**（2〜3年） |
| 抽絲的原因 | **指甲、戒指、倒刺；腳跟與手肘的粗糙皮膚（參見腳跟的文章）；鞋子內側的縫線；在洗衣機裡纏繞；烘衣機** |
| 穿著方法 | **為手保濕、修剪指甲、取下戒指**。**從腳尖開始，把襪筒聚攏起來，一點一點往上提**。**先把腳跟位置對準，再往上拉** |
| 丹尼數 | **數字越大越厚**：**30丹以下**是透明絲襪，**30〜80丹**是薄褲襪，**80丹以上**是厚褲襪（分界線因廠商而異，在 20〜30 丹之間） |
| 清洗 | **手洗（輕輕按壓）或用細網目洗衣網走緩和行程**。**中性清潔劑（「中性洗剤」chūsei senzai）**。**要遠離其他衣物上的掛勾** |
| 晾乾 | **在陰處晾乾；不要用烘衣機**（高溫會使聚氨酯劣化並收縮） |
| 收納 | **捲起來放在抽屜裡**。**避開陽光直射** |
| 修補 | **在抽絲起點處點上一點透明指甲油亮油或膠水**，可以阻止它蔓延（應急措施） |
| 使用壽命 | 參考值：**絲襪穿幾次到約10次；褲襪一季** |

- 依據**《家庭用品品質表示法》**，**纖維成分（尼龍百分比、聚氨酯百分比）與洗滌標示**是強制標注的。**「抗勾紗」加工**會有標示，**編織方式（混纖編織）**也會造成差異。
- **腿部浮腫**與**壓力襪**：**店面販售的壓力產品屬於一般商品，不得宣稱任何功效**（參見久站工作的文章）。**醫療用彈性襪屬於另一個類別**。
- **冬季褲襪與靜電**：**尼龍容易帶正電**，**與壓克力纖維裙子搭配穿會累積靜電**（參見靜電的文章）。

> **[待核實]** 纖維特性請對照纖維產業團體的一般性說明核實，標示義務請對照消費者廳的資料核實。

## 誤解1｜勾紗全看運氣

**指甲、戒指、粗糙的皮膚、鞋子的縫線與清洗**是主要原因。**穿之前做好準備**能大幅減少抽絲。

## 誤解2｜可以直接丟進洗衣機

**會被其他衣物的掛勾與拉鍊纏住而抽絲**。**用細網目洗衣網走緩和行程，或者手洗**。

## 誤解3｜烘衣機能很快烘乾

**高溫會使聚氨酯劣化並收縮，反而更容易抽絲**。**在陰處晾乾**。

## 誤解4｜貴的絲襪不會勾紗

**編織方式與加工確實有一定影響**，但**穿著與清洗的方法影響更大**。**在包包裡備一雙**才是實際的辦法。

## 誤解5｜丹尼數是品質的標準

**丹尼數是紗線的粗細（布料有多厚）**，不是品質。**請依季節與用途選擇**（20〜30丹用於透明感，80丹以上用於保暖）。
