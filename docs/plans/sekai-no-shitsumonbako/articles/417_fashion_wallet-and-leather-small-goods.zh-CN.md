# Q. 关于钱包和皮革小物的保养，人们最容易搞错什么？｜Japan Questions #417

- Shelf: `fashion` ／ URL: `/zh-cn/fashion/wallet-and-leather-small-goods` ／ Status: **草稿 — 出处未核实**

钱包、名片夹、钥匙包，是您每天都会摸到的皮革制品，手上的油脂加上不断的摩擦，让它们比您拥有的任何东西变得都快。在日本，这种变化被当作乐趣来欣赏，称为「经年变化」（経年変化，keinen henka）——看着皮革一点点变深、泛出光泽的文化。本文按皮革种类和保养方式，划出「养出味道」和「单纯磨损」之间的界线。

## A. 最大的误解是「皮革小物靠手上的油脂就能自然滋养，什么都不用做」。手上的油脂分布不均，而且还会带来脏污、色斑和发黑的油垢。基本功是：每月用干布擦一次，再薄薄涂一层保养霜；沾湿了立刻擦干并阴干；不要塞得太满（会变形，也会让缝线吃力）；不要让金属（钥匙、硬币）长时间压在同一个位置。漂亮的经年变化，是建立在这些保养之上的。

## 皮革的种类与保养方式

| 皮革 | 特性 | 保养 | 经年变化 |
|---|---|---|---|
| **原色皮（ヌメ革，植鞣、未涂饰）** | **在阳光和手上的油脂作用下变深**，转为焦糖色。**沾水就容易留印** | **每月：干擦，然后薄薄涂一层保养霜**。有些人**一开始会特意晒太阳**，让颜色变得均匀 | 变化最大。**沾水要立刻擦掉** |
| **铬鞣、颜料涂饰** | 颜色稳定，比较耐水 | **干擦；脏了用布蘸少量稀释的中性洗涤剂** | 变化很小 |
| **马臀皮（Cordovan）** | 光泽强，怕水 | **干擦，用少量专用保养霜** | 光泽会更深 |
| **压纹皮、漆皮（珐琅）** | 表面有涂层 | 只需擦拭 | 几乎不变 |
| **合成皮革（合皮，gōhi）** | 会因水解而剥落（几年后） | 只需擦拭 | 只有劣化 |

| 日常保养 | 为什么 |
|---|---|
| **不要塞得太满**（卡片、硬币、小票） | **变形、缝线吃力、拉链损坏** |
| **不要放在后袋里坐着** | 弯折、变形、绷开缝线 |
| **不要让硬币或钥匙长时间压着** | 金属印痕和发黑的油垢 |
| **沾湿了立刻用干布按压，然后阴干** | 水渍、霉 |
| **一年涂几次保养霜，薄薄的** | 涂太多会发黏，还会养霉 |
| **放进透气的袋子里，加干燥剂** | 防霉（参见皮革制品那篇） |

- **经年变化**是发生在**植鞣皮**上的变化；**颜料涂饰的皮革几乎不会变**。**并不是所有皮革都会「越用越有味道」**。
- **皮革小物缝线开裂、拉链坏掉，都是可以修的**（参见保修与修理那篇）。**在厂家或皮革修理店花几千日元**是常见的行情。
- 根据**《家庭用品品质表示法》（杂货工业品品质表示规程）**，标示义务的对象是**「箱包」（牛、马、猪、羊、山羊皮占外表面积 60% 以上者）以及皮革衣物、皮手套和鞋**，**钱包、名片夹等袋物并不在适用范围内**。**因此是「真皮」（本革，honkawa）还是「合成皮革」（合皮），要看厂商自行标注的吊牌或向店家确认，而非法定标示**。

## 误解1｜手上的油脂就能自然滋养

**油脂分布不均会造成脏污和色斑**。**干擦一遍，再薄薄涂一层保养霜**，才能均匀。

## 误解2｜所有皮革都会越用越有味道

**只有原色皮这类植鞣皮才会**。**颜料涂饰和铬鞣的皮革几乎不变；合成皮革只会劣化**。**请看标签**。

## 误解3｜保养霜涂得越多用得越久

**涂太多会发黏、养霉，还会让颜色发闷**。**取米粒大小，薄薄推开，一年几次**。

## 误解4｜钱包应该尽量多装

这是**变形、缝线绷开、拉链损坏**的主要原因。**只带需要的卡片，小票每天拿出来**。**不要放在后袋里坐着**。

## 误解5｜坏了就买新的

**缝线、拉链、按扣通常都能修**。**在修理店花几千日元**。**把皮革小物修一修用上十年**，是日本人常见的用法。
