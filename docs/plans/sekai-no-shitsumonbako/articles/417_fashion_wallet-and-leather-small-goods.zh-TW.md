# Q. 關於皮夾與皮革小物的保養，人們最容易搞錯什麼？｜Japan Questions #417

- Shelf: `fashion` ／ URL: `/zh-tw/fashion/wallet-and-leather-small-goods` ／ Status: **草稿 — 出處未核實**

皮夾、名片夾、鑰匙包，是您每天都會摸到的皮革製品，手上的油脂加上不斷的摩擦，讓它們比您擁有的任何東西都變得快。在日本，這種變化被當成樂趣來欣賞，稱為「經年變化」（経年変化，keinen henka）——看著皮革一點一點變深、透出光澤的文化。本文依皮革種類與保養方式，畫出「養出味道」與「單純磨損」之間的界線。

## A. 最大的誤解是「皮革小物靠手上的油脂就會自然滋養，什麼都不用做」。手上的油脂分布不均，而且還會帶來髒污、色斑與發黑的油垢。基本功是：每月用乾布擦一次，再薄薄塗一層保養乳霜；沾濕了立刻擦乾並陰乾；不要塞得太滿（會變形，也會讓車線吃力）；不要讓金屬（鑰匙、硬幣）長時間壓在同一個位置。漂亮的經年變化，是建立在這些保養之上的。

## 皮革的種類與保養方式

| 皮革 | 特性 | 保養 | 經年變化 |
|---|---|---|---|
| **原色皮（ヌメ革，植鞣、未塗飾）** | **在陽光與手上的油脂作用下變深**，轉為焦糖色。**沾水就容易留印** | **每月：乾擦，然後薄薄塗一層保養乳霜**。有些人**一開始會刻意曬太陽**，讓顏色變得均勻 | 變化最大。**沾水要立刻擦掉** |
| **鉻鞣、顏料塗飾** | 顏色穩定，較耐水 | **乾擦；髒了用布沾少量稀釋的中性洗劑** | 變化很小 |
| **馬臀皮（Cordovan）** | 光澤強，怕水 | **乾擦，用少量專用保養乳霜** | 光澤會更深 |
| **壓紋皮、漆皮（琺瑯）** | 表面有塗層 | 只需擦拭 | 幾乎不變 |
| **合成皮革（合皮，gōhi）** | 會因水解而剝落（幾年後） | 只需擦拭 | 只有劣化 |

| 日常保養 | 為什麼 |
|---|---|
| **不要塞得太滿**（卡片、硬幣、發票） | **變形、車線吃力、拉鍊損壞** |
| **不要放在後口袋裡坐著** | 彎折、變形、繃開車線 |
| **不要讓硬幣或鑰匙長時間壓著** | 金屬印痕與發黑的油垢 |
| **沾濕了立刻用乾布按壓，然後陰乾** | 水漬、黴 |
| **一年塗幾次保養乳霜，薄薄的** | 塗太多會發黏，還會養黴 |
| **放進透氣的袋子裡，加乾燥劑** | 防黴（參見皮革製品那篇） |

- **經年變化**是發生在**植鞣皮**上的變化；**顏料塗飾的皮革幾乎不會變**。**並不是所有皮革都會「愈用愈有味道」**。
- **皮革小物車線開裂、拉鍊壞掉，都是可以修的**（參見保固與修理那篇）。**在原廠或皮革修理店花幾千日圓**是常見的行情。
- 依據**《家庭用品品質標示法》（雜貨工業品品質標示規程）**，標示義務的對象是**「包款」（牛、馬、豬、羊、山羊皮佔外表面積 60% 以上者）以及皮革衣物、皮手套與鞋**，**皮夾、名片夾等袋物並不在適用範圍內**。**因此是「真皮」（本革，honkawa）還是「合成皮革」（合皮），要看廠商自行標註的吊牌或向店家確認，而非法定標示**。

> **[待核實]** 標示義務的適用範圍請對照消費者廳《雜貨工業品品質標示規程》核實，保養建議請對照日本皮革產業聯合會的資料核實。

## 誤解1｜手上的油脂就會自然滋養

**油脂分布不均會造成髒污與色斑**。**乾擦一遍，再薄薄塗一層保養乳霜**，才會均勻。

## 誤解2｜所有皮革都會愈用愈有味道

**只有原色皮這類植鞣皮才會**。**顏料塗飾與鉻鞣的皮革幾乎不變；合成皮革只會劣化**。**請看標示**。

## 誤解3｜保養乳霜塗得愈多用得愈久

**塗太多會發黏、養黴，還會讓顏色發悶**。**取米粒大小，薄薄推開，一年幾次**。

## 誤解4｜皮夾應該盡量多裝

這是**變形、車線繃開、拉鍊損壞**的主因。**只帶需要的卡片，發票每天拿出來**。**不要放在後口袋裡坐著**。

## 誤解5｜壞了就買新的

**車線、拉鍊、壓釦通常都能修**。**在修理店花幾千日圓**。**把皮革小物修一修用上十年**，是日本人常見的用法。
