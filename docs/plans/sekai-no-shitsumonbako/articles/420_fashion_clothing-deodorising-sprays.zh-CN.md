# Q. 关于衣物除臭喷雾和除菌喷雾，人们最容易搞错什么？｜Japan Questions #420

- Shelf: `fashion` ／ URL: `/zh-cn/fashion/clothing-deodorising-sprays` ／ Status: **草稿 — 出处未核实**

「洗不了的衣服就喷一喷」是日本的日常习惯，Febreze（ファブリーズ）和 Reset（リセッシュ）这类织物喷雾在游客中也很受欢迎。本文说明它们能做什么、不能做什么，标签上的「除菌」（jokin）和「消臭」（shōshū）在法规上是怎么管的，以及怎样安全使用。

## A. 最大的误解是「喷雾能顶洗衣服」。喷雾是把产生气味的化合物分解或吸附掉，有些还能减少表面的细菌，但汗和皮脂本身仍然留在纤维里。它们的位置是「洗之前的临时办法」。「除菌（减少细菌）」和「抗菌」作为一般商品的宣称是受限制的，而「杀菌」和「消毒」只能出现在医药品和医药部外品（日本介于化妆品与医药品之间的一个类别）上。

## 标签用语与背后的规则

| 标签用语 | 类别 | 含义 | 法规 |
|---|---|---|---|
| **消臭（除臭）** | 一般商品 | 用化学方式分解或中和气味化合物，或者把它们吸附掉 | 《景品表示法》（不得作无依据的宣称）。**业界自主基准（日本肥皂洗涤剂工业会等）** |
| **除菌（减少细菌）** | 一般商品 | **减少细菌**（针对哪些细菌、在什么条件下，取决于厂家自己的试验） | 业界自主基准要求**加注「并非去除所有细菌」** |
| **抗菌** | 一般商品 | 抑制细菌繁殖的加工 | 同上 |
| **杀菌／消毒** | **仅限医药品与医药部外品** | 杀灭细菌 | **不得用于一般商品**（《药机法》，日本关于药品与化妆品的法律） |
| **病毒** | 一般商品**只能使用有试验依据的有限措辞**，例如「减少病毒」 | — | 已有依据《景品表示法》发出的措施命令 |

## 使用方法

| 要点 | 说明 |
|---|---|
| 定位 | **洗之前的临时办法**。**汗和皮脂会留下** → **要定期清洗或干洗** |
| 面料 | **请看标签**。**真丝、人造丝、皮革、和服以及防水加工可能会留印或变色**。**先在不显眼处试** |
| 距离与用量 | **距离 20–30 厘米，在整件衣服上均匀轻喷**。**绝对不要喷到湿透**（会留印、留水渍圈） |
| 干燥 | **穿之前或收起来之前要阴干**。**带着湿气收起来会招霉** |
| 火源 | **含酒精（乙醇）的配方易燃**。**不要在明火附近使用或存放** |
| 吸入 | **要通风**。**不要朝着脸喷**。**不要在儿童或宠物附近大量使用** |
| 食物与皮肤 | **不要把衣物喷雾用在皮肤、食物或口罩内侧**（这些另有专门产品） |

- 消费者厅曾**依据《景品表示法》，对没有依据却宣称「除菌」或「去除病毒」的一般商品发出措施命令**（2020 年以来有数起案例）。**请确认试验条件**。
- **「衣物用」「房间用」「鞋子用」配方各不相同**。**超出用途使用，可能会让面料留印，或者效果变差**。
- **气味的来源是细菌的代谢产物**（莫拉克氏菌等；参见毛巾那篇）。**喷雾能暂时减少它们，但只要有湿气和污垢，气味就会回来**。

> **[待核实]** 标示规则请对照消费者厅（景品表示法）与厚生劳动省（药机法）的资料核实，业界自主基准请对照日本肥皂洗涤剂工业会等团体的资料核实。

## 误解1｜喷一喷等于洗过了

**污垢还留在那里**。**这是洗之前的临时办法**；**出了汗的衣服要洗**。

## 误解2｜「除菌」和「杀菌」是一回事

**「杀菌」和「消毒」是医药品与医药部外品专用的用语**。**一般商品上的「除菌」意思是「减少细菌」，针对哪些细菌、在什么条件下，取决于厂家的试验**。

## 误解3｜什么衣服都能喷

**真丝、人造丝、皮革和防水加工可能会留印或变色**。**请看标签，并先在不显眼处试**。

## 误解4｜喷得越多效果越好

**喷到湿透会留印、留水渍圈，带着湿气收起来还会招霉**。**轻轻一层雾，然后晾干**。

## 误解5｜含酒精，所以用在哪儿都安全

**易燃**——请远离明火。**不要吸入，也不要用在皮肤或食物上**。**请按标示的用途使用**。
