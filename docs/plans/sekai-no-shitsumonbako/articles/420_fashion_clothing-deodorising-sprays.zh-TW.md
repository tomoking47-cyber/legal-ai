# Q. 關於衣物除臭噴霧與除菌噴霧，人們最容易搞錯什麼？｜Japan Questions #420

- Shelf: `fashion` ／ URL: `/zh-tw/fashion/clothing-deodorising-sprays` ／ Status: **草稿 — 出處未核實**

「洗不了的衣服就噴一噴」是日本的日常習慣，Febreze（ファブリーズ）與 Reset（リセッシュ）這類布料噴霧在旅客之間也很受歡迎。本文說明它們能做什麼、不能做什麼，標示上的「除菌」（jokin）與「消臭」（shōshū）在法規上是怎麼管的，以及該怎麼安全使用。

## A. 最大的誤解是「噴霧可以代替洗衣服」。噴霧是把產生氣味的化合物分解或吸附掉，有些還能減少表面的細菌，但汗與皮脂本身仍然留在纖維裡。它們的定位是「洗之前的權宜之計」。「除菌（減少細菌）」與「抗菌」作為一般商品的宣稱是受限制的，而「殺菌」與「消毒」只能出現在醫藥品與醫藥部外品（日本介於化妝品與醫藥品之間的一個類別）上。

## 標示用語與背後的規則

| 標示用語 | 類別 | 含意 | 法規 |
|---|---|---|---|
| **消臭（除臭）** | 一般商品 | 以化學方式分解或中和氣味化合物，或者把它們吸附掉 | 《景品標示法》（不得作無依據的宣稱）。**業界自主基準（日本肥皂洗劑工業會等）** |
| **除菌（減少細菌）** | 一般商品 | **減少細菌**（針對哪些細菌、在什麼條件下，取決於廠商自己的試驗） | 業界自主基準要求**加註「並非去除所有細菌」** |
| **抗菌** | 一般商品 | 抑制細菌繁殖的加工 | 同上 |
| **殺菌／消毒** | **僅限醫藥品與醫藥部外品** | 殺滅細菌 | **不得用於一般商品**（《藥機法》，日本關於藥品與化妝品的法律） |
| **病毒** | 一般商品**只能使用有試驗依據的有限措辭**，例如「減少病毒」 | — | 已有依《景品標示法》發出的措施命令 |

## 使用方式

| 重點 | 說明 |
|---|---|
| 定位 | **洗之前的權宜之計**。**汗與皮脂會留下** → **要定期清洗或送乾洗** |
| 布料 | **請看標示**。**絲、嫘縈、皮革、和服以及防潑水加工可能會留印或變色**。**先在不顯眼處試** |
| 距離與用量 | **距離 20–30 公分，在整件衣服上均勻輕噴**。**絕對不要噴到濕透**（會留印、留水漬圈） |
| 乾燥 | **穿之前或收起來之前要陰乾**。**帶著濕氣收起來會招黴** |
| 火源 | **含酒精（乙醇）的配方易燃**。**不要在明火附近使用或存放** |
| 吸入 | **要通風**。**不要朝著臉噴**。**不要在兒童或寵物附近大量使用** |
| 食物與皮膚 | **不要把衣物噴霧用在皮膚、食物或口罩內側**（這些另有專門產品） |

- 消費者廳曾**依據《景品標示法》，對沒有依據卻宣稱「除菌」或「去除病毒」的一般商品發出措施命令**（2020 年以來有數起案例）。**請確認試驗條件**。
- **「衣物用」「房間用」「鞋子用」配方各不相同**。**超出用途使用，可能會讓布料留印，或者效果變差**。
- **氣味的來源是細菌的代謝產物**（莫拉氏菌等；參見毛巾那篇）。**噴霧能暫時減少它們，但只要有濕氣與污垢，氣味就會回來**。

> **[待核實]** 標示規則請對照消費者廳（景品標示法）與厚生勞動省（藥機法）的資料核實，業界自主基準請對照日本肥皂洗劑工業會等團體的資料核實。

## 誤解1｜噴一噴等於洗過了

**髒污還留在那裡**。**這是洗之前的權宜之計**；**流過汗的衣服要洗**。

## 誤解2｜「除菌」與「殺菌」是同一回事

**「殺菌」與「消毒」是醫藥品與醫藥部外品專用的用語**。**一般商品上的「除菌」意思是「減少細菌」，針對哪些細菌、在什麼條件下，取決於廠商的試驗**。

## 誤解3｜什麼衣服都能噴

**絲、嫘縈、皮革與防潑水加工可能會留印或變色**。**請看標示，並先在不顯眼處試**。

## 誤解4｜噴得愈多效果愈好

**噴到濕透會留印、留水漬圈，帶著濕氣收起來還會招黴**。**輕輕一層霧，然後晾乾**。

## 誤解5｜含酒精，所以用在哪裡都安全

**易燃**——請遠離明火。**不要吸入，也不要用在皮膚或食物上**。**請依標示的用途使用**。
