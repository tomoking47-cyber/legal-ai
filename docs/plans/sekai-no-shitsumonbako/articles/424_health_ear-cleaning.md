# Q. 耳掃除について、よくある誤解は？｜世界の質問箱 #424

- 棚：`health` ／ URL：`/questions/ear-cleaning` ／ ステータス：**ドラフト（法務レビュー前・出典未検証）**

耳掃除は日本で「習慣」として定着し、耳かき（竹製）は日用品です。一方で、耳鼻科は「耳掃除は基本的に不要」と繰り返し伝えています。耳垢の仕組みと、事故（外耳道炎・鼓膜損傷）の観点から整理します。

## A. 最大の誤解は「耳垢は汚れだから定期的に取るべき」です。耳垢は皮膚の一部と分泌物からできた保護膜で、あごの動きで自然に外へ運ばれます。日本耳鼻咽喉科頭頸部外科学会は「耳掃除は基本的に不要、するなら月1〜2回、入口から1cm程度まで」と案内し、綿棒で奥に押し込むこと・耳かきによる外耳道の傷が最も多いトラブルです。

## 判断の材料

| 項目 | 内容 | 出典 |
|---|---|---|
| 耳垢の役割 | **皮膚を保護し、細菌・ほこりを防ぐ**。**弱酸性で抗菌性** | 日本耳鼻咽喉科頭頸部外科学会 |
| 自然排出 | **あごの動き（会話・食事）で外耳道の皮膚が外側へ移動し、耳垢も運ばれる** | 同上 |
| 掃除の目安 | **基本的に不要**。するなら**月1〜2回、入口から1cm程度まで、入浴後に柔らかい綿棒で軽く** | 同上 |
| 耳垢の種類 | **乾性（日本人の約7〜8割）**と**湿性**（遺伝）。湿性はたまりやすく、耳鼻科での除去が向く | 同上 |
| トラブル | **綿棒で奥に押し込む→耳垢栓塞（詰まる）**、**耳かきで外耳道を傷つける→外耳道炎**、**子どもが動いて鼓膜損傷** | 同上・消費者庁 |
| 耳鼻科での除去 | **保険適用**（耳垢除去）。**数分で、痛みなく** | — |
| 受診の目安 | **聞こえにくい・詰まった感じ・痛み・かゆみが続く・耳だれ** | — |

- **消費者庁**は、**子どもの耳掃除中の事故（動いた・ぶつかった・兄弟が突いた）**で鼓膜損傷が起きていると注意喚起しています。**子どもは動くので耳鼻科で**。
- **耳かき文化**：竹の耳かき・梵天は日本の日用品ですが、**耳鼻科は「見えない場所を硬い道具で触らない」**と案内します。**外耳道の皮膚は薄く、傷から細菌感染（外耳道炎）**が多い。
- **イヤホン・補聴器を長時間使う人**は、**耳垢が押し込まれやすく、湿気で外耳道炎**も。**清潔に、時々外す**。

> 【要検証】学会の案内（頻度・深さ）と乾性・湿性の割合、事故事例は日本耳鼻咽喉科頭頸部外科学会・消費者庁の資料で確認してください。

## 誤解1｜耳垢は汚れだから毎日取る

**保護膜で、自然に排出される**。**基本的に不要、するなら月1〜2回**。

## 誤解2｜綿棒で奥まで掃除すればきれい

**綿棒は耳垢を奥に押し込み、詰まらせる**。**入口から1cmまで**。

## 誤解3｜耳かきで取れる感触が気持ちよいから正しい

**外耳道の皮膚は薄く、傷から炎症**。**「取れた」感触は皮膚を削っている**ことも。

## 誤解4｜子どもの耳掃除は親の仕事

**動いて鼓膜損傷の事故**があります。**子どもは耳鼻科で**（保険適用、数分）。

## 誤解5｜耳が詰まったら自分で取る

**耳垢栓塞は自分で取ると奥へ**。**耳鼻科で除去（保険）**。**聞こえにくさが続けば受診**。
