# Q. 爪の切り方と巻き爪について、よくある誤解は？｜世界の質問箱 #425

- 棚：`health` ／ URL：`/questions/nail-cutting-and-ingrown-nails` ／ ステータス：**ドラフト（法務レビュー前・出典未検証）**

爪の切り方は教わる機会が少なく、「丸く短く」が世界中で当然とされています。ところがそれが巻き爪・陥入爪の主因の一つで、日本皮膚科学会・日本フットケア学会は「スクエアオフ」を勧めています。

## A. 最大の誤解は「足の爪は短く丸く切るのが清潔で安全」です。足の爪を短く丸く切ると、爪の角が皮膚に食い込む陥入爪や、巻き爪の原因になります。基本は「指先と同じ長さに、まっすぐ（スクエア）、角だけ少し落とす（スクエアオフ）」で、入浴後の柔らかい爪を、深爪しないことです。

## 切り方の基本

| 項目 | 足の爪 | 手の爪 |
|---|---|---|
| 形 | **スクエアオフ**：**まっすぐ切り、角を少しだけやすりで丸める** | 丸めてもよいが**深爪しない** |
| 長さ | **指先と同じか、わずかに長く**（0〜1mm） | 指先より少し短く |
| タイミング | **入浴後（柔らかい）** | 同じ |
| 道具 | **爪切り（直線刃）またはニッパー**。**一気に切らず、数回に分けて** | 爪切り |
| やすり | **一方向に**、往復させない | 同じ |
| 頻度 | **月1回程度**（足の爪は手の半分の速さで伸びる） | 週1回 |
| 甘皮 | **無理に取らない**。押し戻す程度 | 同じ |

| トラブル | 内容 | 対処 |
|---|---|---|
| **陥入爪** | **爪の角が皮膚に食い込み、赤み・痛み・化膿** | **深爪をやめ、スクエアオフ**。**痛み・化膿は皮膚科・形成外科**（テーピング、ワイヤー矯正、手術） |
| **巻き爪** | **爪が横に丸く巻く**。深爪・合わない靴・加齢・歩き方 | **靴のサイズ（靴の履き方の記事参照）**、**矯正（自由診療が多い）** |
| **爪白癬（爪の水虫）** | **厚く、白〜黄色に濁る、もろい** | **皮膚科**（内服・外用、数か月） |
| **高齢者の爪** | 厚く硬く、自分で切れない | **フットケア（看護・介護）、皮膚科** |

- 日本皮膚科学会・日本フットケア・足病医学会は、**陥入爪の主因は深爪と靴**であり、**予防はスクエアオフ**と案内しています。
- **糖尿病の人**は、**足の小さな傷から感染・壊死**のリスクがあり、**爪切りは慎重に、医療機関のフットケア**が推奨されます。
- **爪切りの共有**は**爪白癬（水虫）の感染経路**になります。**家族でも1人1つ**、または使用後に消毒。

> 【要検証】スクエアオフの推奨は日本皮膚科学会・日本フットケア・足病医学会の資料で確認してください。

## 誤解1｜足の爪は短く丸く切る

**陥入爪・巻き爪の主因**。**指先と同じ長さに、まっすぐ、角だけ落とす**。

## 誤解2｜爪の角が食い込んだら角を深く切る

**さらに食い込む悪循環**。**伸ばしてスクエアオフに戻す**。**痛み・化膿は皮膚科・形成外科**。

## 誤解3｜爪切りは家族で共有してよい

**爪白癬（水虫）の感染経路**。**1人1つ、または消毒**。

## 誤解4｜厚く濁った爪は年のせい

**爪白癬の可能性**。**皮膚科で検査（数分）**、治療は数か月。**放置すると足の水虫に**。

## 誤解5｜巻き爪は靴とは無関係

**先の細い靴・小さい靴・ヒール**は巻き爪と陥入爪の主因の一つ。**つま先に余裕、かかとを合わせて履く**（靴の記事参照）。
