# Q. 關於剪指甲和嵌甲，常見的誤解是什麼？｜Japan Questions #425

- Shelf: `health` ／ URL: `/zh-tw/health/nail-cutting-and-ingrown-nails` ／ Status: **草稿 — 出處未核實**

幾乎沒有人被教過怎麼剪指甲，「剪短、剪成圓弧」在全世界都被當作理所當然。然而這正是捲甲和嵌甲的主要原因之一。日本皮膚科學會與日本下肢病學會（足部照護與足病醫學）推薦的是「方形修剪」（square-off）。

## A. 最大的誤解是「腳趾甲要剪短、剪成圓弧，這樣才乾淨又安全」。把腳趾甲剪短剪圓，會讓指甲的角陷進皮膚（嵌甲，陥入爪，kannyūsō），並造成指甲往兩側彎曲的捲甲（巻き爪，makizume）。基本做法是：與腳趾尖齊平、橫向平剪（方形），只把兩個角用銼刀稍微磨圓（square-off）。請在洗澡後指甲變軟時進行，絕對不要剪得太短。

## 剪法

| 項目 | 腳趾甲 | 手指甲 |
|---|---|---|
| 形狀 | **方形修剪**：**橫向平剪，只把兩角用銼刀稍微磨圓** | 剪成圓弧沒問題，但**不要剪得太短** |
| 長度 | **與腳趾尖齊平或稍長一點**（0～1 mm） | 比指尖稍短一點 |
| 時機 | **洗澡後（指甲較軟）** | 同上 |
| 工具 | **直刃指甲剪或指甲鉗（nail nipper）。****分幾次小口剪，不要一刀剪斷** | 指甲剪 |
| 打磨 | **朝一個方向**，不要來回銼 | 同上 |
| 頻率 | **約每月 1 次**（腳趾甲的生長速度是手指甲的一半） | 每週 1 次 |
| 甲上皮 | **不要硬撕。**最多輕輕往後推 | 同上 |

| 問題 | 是什麼 | 怎麼辦 |
|---|---|---|
| **嵌甲（陥入爪）** | **指甲的角陷進皮膚：發紅、疼痛、化膿** | **停止剪短，改用方形修剪。****若疼痛或化膿，請就診皮膚科或整形外科**（貼布固定、金屬線矯正、手術） |
| **捲甲（巻き爪）** | **指甲往兩側彎曲。**剪得太短、鞋子不合腳、年齡增長、走路方式 | **鞋子的尺寸（參見本站關於穿鞋的文章）**；**矯正（多數情況健康保險不適用）** |
| **甲癬（爪白癬，灰指甲）** | **變厚、混濁呈白到黃色、易碎** | **皮膚科**（口服或外用藥，需要數個月） |
| **年長者的指甲** | 又厚又硬，自己剪不動 | **足部照護（護理、照護服務）、皮膚科** |

- 日本皮膚科學會與日本下肢病學會說明，**嵌甲的主要原因是剪得太短和鞋子**，而**預防的方法是方形修剪**。
- **糖尿病患者**有**因腳部的小傷口引發感染和組織壞死**的風險；建議**小心地剪指甲，並在醫療機構接受專業的足部照護**。
- **共用指甲剪**是**甲癬（香港腳）的傳染途徑**。**即使在家庭內部也要一人一把**，或者用後消毒。

> **[待核實]** 請對照日本皮膚科學會與日本下肢病學會的資料，核對方形修剪的建議。

## 誤解1｜腳趾甲要剪短剪圓

**這是嵌甲與捲甲的主要原因。****與腳趾尖齊平、橫向平剪，只處理兩角。**

## 誤解2｜角陷進去了就把角剪得更深

**這是惡性循環：只會陷得更深。****讓它長出來，回到方形修剪。****若疼痛或化膿，請就診皮膚科或整形外科。**

## 誤解3｜指甲剪可以在家庭內共用

**這是甲癬（香港腳）的傳染途徑。****一人一把，或者消毒。**

## 誤解4｜指甲又厚又混濁只是年齡的關係

**也可能是甲癬。****皮膚科可以做檢查（幾分鐘）**；藥物則需要數個月。**放著不管，會以香港腳的形式擴散到腳上。**

## 誤解5｜捲甲和鞋子沒有關係

**尖頭鞋、太小的鞋和高跟鞋**是捲甲與嵌甲的主要原因之一。**腳趾處要留出空間，腳跟要貼合**（參見本站關於鞋子的文章）。
