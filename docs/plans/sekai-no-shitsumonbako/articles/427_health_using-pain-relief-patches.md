# Q. 湿布の使い方について、よくある誤解は？｜世界の質問箱 #427

- 棚：`health` ／ URL：`/questions/using-pain-relief-patches` ／ ステータス：**ドラフト（法務レビュー前・出典未検証）**

湿布（貼り薬）は日本で最も身近な鎮痛薬で、家庭に常備され、海外からは「なぜ日本人はこんなに湿布を使うのか」と問われます。温感・冷感の違い、成分の区分、光線過敏症、そして「効く場所」の誤解を整理します。

## A. 最大の誤解は「冷感湿布は冷やし、温感湿布は温める」です。湿布の温度感は成分（メントール・カプサイシン）による皮膚の感覚で、実際の温度はほとんど変わりません。効くのは鎮痛消炎成分（サリチル酸系、ジクロフェナク、ロキソプロフェン等）で、痛みの時期（急性は冷感、慢性は温感が好まれる）と好みで選びます。ケトプロフェン等の一部成分は光線過敏症の注意があり、貼った部位を日光にさらさないことが表示で求められています。

## 種類と選び方

| 項目 | 内容 |
|---|---|
| **冷感・温感** | **感覚の違い**（メントール＝冷感、カプサイシン・ノニル酸ワニリルアミド＝温感）。**皮膚の温度はほぼ変わらない**。**急性（ぶつけた・ひねった直後）は冷感、慢性のこりは温感**が一般的な使い分け（好み） |
| **鎮痛消炎成分（第一世代）** | **サリチル酸メチル・グリコール**：軽い痛み。**第3類医薬品**が多い |
| **鎮痛消炎成分（第二世代）** | **ジクロフェナク・ロキソプロフェン・フェルビナク・インドメタシン・ケトプロフェン**：より強い。**第2類医薬品**。**1日の枚数制限は製品・サイズごとに違う**（例：ロキソプロフェンテープは1日1回で、通常サイズ4枚・Lサイズ2枚・ミニサイズ8枚が上限。**2週間以上の連用は避ける**） |
| **光線過敏症** | **ケトプロフェン**（一部フェルビナク等）は**貼付部位を日光に当てると発疹・かぶれ**（**剥がした後4週間程度も注意**）。**表示に従い、屋外では覆う** |
| **貼る時間** | 製品表示（**8〜12時間、または1日1回**）。**長時間の貼りっぱなしはかぶれ** |
| **使えない人・部位** | **妊娠後期（NSAIDs含有）、喘息の既往、傷・湿疹のある部位、15歳未満（一部）**——表示を確認 |
| **効く場所** | **貼った部位の皮膚から吸収**して局所に働く。**内臓の痛み・全身には効かない** |

- 湿布は**医薬品（第2類・第3類）**で、**用法・用量と注意**が表示されています。**「腰痛の原因を取り除く」のではなく、痛みと炎症を抑える**もの。
- **ケトプロフェンの光線過敏症**は厚生労働省・PMDAが繰り返し注意喚起し、**「貼っている間と剥がした後4週間は、貼った部位を日光にさらさない」**が添付文書の注意。
- **かぶれ（接触皮膚炎）**は湿布のトラブルで最多。**同じ場所に連続で貼らない、剥がした後は洗う、赤みが出たら中止**。
- **子どもの誤飲・誤貼**、**高齢者の貼りすぎ（枚数超過）**も注意。

> 【要検証】各成分の区分と1日の枚数制限、光線過敏症の注意は製品の添付文書（PMDA）で確認してください。

## 誤解1｜冷感は冷やす、温感は温める

**感覚の違い**で温度はほぼ同じ。**効くのは鎮痛消炎成分**。**急性は冷感、慢性は温感**は好みの範囲。

## 誤解2｜何枚貼っても外用だから安全

**第二世代の成分は1日の枚数制限**があり、**大量に貼ると内服と同様の副作用（胃・腎）**の可能性。**表示の枚数**。

## 誤解3｜貼ったまま日に当たっても大丈夫

**ケトプロフェン等は光線過敏症**。**貼った部位を衣類で覆う、剥がした後も4週間程度は注意**。

## 誤解4｜長く貼るほど効く

**表示の時間（8〜12時間）を超えるとかぶれ**。**剥がして皮膚を休ませる**。

## 誤解5｜湿布で腰痛の原因がなくなる

**痛みと炎症を抑える**もので、**原因は変わりません**。**動く・姿勢・温める**（腰の張りの記事参照）と併用し、**赤旗症状は受診**。
