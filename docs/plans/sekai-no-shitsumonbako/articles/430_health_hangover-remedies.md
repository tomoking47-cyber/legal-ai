# Q. 二日酔いの対処について、よくある誤解は？｜世界の質問箱 #430

- 棚：`health` ／ URL：`/questions/hangover-remedies` ／ ステータス：**ドラフト（法務レビュー前・出典未検証）**

二日酔いの「特効薬」は世界中で語られ、日本ではしじみの味噌汁・梅干し・ウコンドリンクが定番です。何が確かで、何に根拠がないかを、厚生労働省の飲酒ガイドライン（2024年）と生理学の一般的な説明から整理します。

## A. 最大の誤解は「二日酔いに効く食べ物・ドリンクがある」です。二日酔いの主因は脱水・低血糖・アセトアルデヒド・睡眠の質の低下で、確かなのは時間と水分・糖分・休息です。市販のドリンクやサプリメントに二日酔いを防ぐ・治す効能を表示することはできず、迎え酒は症状を先送りするだけです。予防は飲む量と、飲みながらの水です。

## 二日酔いの仕組みと対処

| 原因 | 症状 | 対処 |
|---|---|---|
| **脱水** | 頭痛・のどの渇き・だるさ（アルコールの利尿作用） | **水・経口補水液・スポーツドリンクを少しずつ**（経口補水液の記事参照） |
| **低血糖** | ふらつき・冷や汗・脱力 | **糖分（果物・おかゆ・はちみつ）** |
| **アセトアルデヒド** | 吐き気・動悸・顔のほてり。**分解酵素の働きは遺伝**（日本人の約4割は弱い） | **時間**（分解を待つ）。**迎え酒は分解をさらに遅らせる** |
| **胃の炎症** | 胃痛・吐き気 | **消化のよいもの少量、胃薬（市販）は用法どおり** |
| **睡眠の質の低下** | 眠気・集中力低下 | **休む**（アルコールと睡眠の記事参照） |
| **アセトン・炎症性物質** | 全身のだるさ | 時間 |

| 語られる「対策」 | 評価 |
|---|---|
| **しじみの味噌汁** | **水分・塩分・アミノ酸の補給として合理的**。**「オルニチンが肝臓を助ける」効果を食品で表示することはできず、二日酔いを治す根拠は確認されていない** |
| **ウコン（クルクミン）ドリンク・サプリ** | **二日酔いの予防・改善を示す十分な根拠はない**（国立健康・栄養研究所）。**肝機能障害の報告**もあり、**肝疾患の人は注意** |
| **迎え酒** | **症状を一時的にごまかし、分解を遅らせる**。**アルコール依存のリスク** |
| **サウナ・運動で汗を出す** | **脱水を悪化させ、危険**（サウナの記事参照） |
| **コーヒー** | **カフェインで一時的に覚醒、利尿で脱水が進む**。少量なら |
| **市販の頭痛薬** | **アセトアミノフェンはアルコールと併用で肝臓への負担**。**用法を守り、飲酒直後は避ける** |

- 厚生労働省「健康に配慮した飲酒に関するガイドライン」（2024年）は、**純アルコール量の把握**と**「飲酒前・飲酒中に食事と水」**を勧め、**二日酔いは「飲みすぎのサイン」**としています。
- **日本人の約40%はアセトアルデヒド分解酵素（ALDH2）の働きが弱く**、顔が赤くなりやすい。**この体質の人は少量でも二日酔いしやすく、食道がん等のリスクも高い**とされます。
- **「二日酔いに効く」「肝臓を守る」**などの表示は、**一般食品・サプリでは健康増進法・景表法上できません**。**機能性表示食品でも「二日酔い」を直接うたうものはない**。

> 【要検証】飲酒ガイドライン（2024年）の記載、ウコンの評価は国立健康・栄養研究所の「健康食品」データベース、ALDH2の割合は e-ヘルスネットで確認してください。

## 誤解1｜二日酔いに効くドリンクがある

**効能を表示できる製品はなく、根拠も確認されていない**。**水分・糖分・時間**。

## 誤解2｜迎え酒で楽になる

**分解を遅らせ、症状を先送り**。**依存の入口**とされます。

## 誤解3｜汗をかいてアルコールを出す

**アルコールは汗からほとんど出ず、脱水が進んで危険**。**サウナ・激しい運動は不可**。

## 誤解4｜ウコンを飲んでおけば予防できる

**十分な根拠はなく、肝機能障害の報告もある**。**予防は飲む量と、飲みながらの水と食事**。

## 誤解5｜頭痛薬を飲んでもう一杯

**アセトアミノフェンとアルコールの併用は肝臓に負担**。**飲酒直後の鎮痛薬は避け、翌朝に用法どおり**。**頭痛が激しい・嘔吐が止まらない・意識がおかしい**は救急（急性アルコール中毒の可能性）。
