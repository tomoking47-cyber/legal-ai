# Q. 关于应对宿醉，人们常有哪些误解？｜Japan Questions #430

- Shelf: `health` ／ URL: `/zh-cn/health/hangover-remedies` ／ Status: **草稿 — 出处未核实**

每个国家都有自己的「宿醉神器」。在日本，经典之选是「しじみ」(shijimi，蚬子) 味噌汤、「梅干」(umeboshi，腌梅) 和「ウコン」(ukon，姜黄) 饮料。以下依据厚生劳动省（厚生労働省）2024 年的饮酒指南与生理学的一般说法，梳理哪些站得住脚、哪些没有依据。

## A. 最大的误解是「有某种食物或饮料对宿醉有效」。宿醉的主要成因是脱水、低血糖、乙醛以及睡眠质量下降；能可靠帮上忙的是时间、水分、糖分与休息。市售饮料与保健品不得标示预防或缓解宿醉，而「迎え酒」(mukae-zake，回魂酒) 只是把症状往后推。预防在于喝多少，以及边喝边补水。

## 宿醉的机制与应对

| 原因 | 症状 | 应对 |
|---|---|---|
| **脱水** | 头痛、口渴、乏力（酒精有利尿作用） | **水、口服补液盐或运动饮料，少量多次**（参见本站关于口服补液盐的文章） |
| **低血糖** | 头晕站不稳、冷汗、无力 | **糖分（水果、粥、蜂蜜）** |
| **乙醛** | 恶心、心悸、面部潮红。**分解能力由遗传决定**（约 40% 的日本人分解酶较弱） | **时间**（等待分解）。**回魂酒会进一步减慢分解** |
| **胃部炎症** | 胃痛、恶心 | **少量易消化的食物；市售胃药按用法服用** |
| **睡眠质量下降** | 困倦、注意力下降 | **休息**（参见本站关于酒精与睡眠的文章） |
| **丙酮与炎症性物质** | 全身乏力 | 时间 |

| 常被提到的「对策」 | 评价 |
|---|---|
| **「しじみ」(shijimi，蚬子) 味噌汤** | **作为补充水分、盐分与氨基酸是合理的。****食品不得标示「鸟氨酸有助于肝脏」，缓解宿醉的依据也未获确认** |
| **「ウコン」(ukon，姜黄／姜黄素) 饮料与保健品** | **没有充分依据表明可以预防或改善宿醉**（国立健康·营养研究所）。**存在肝功能障碍的报告**，**有肝病的人请注意** |
| **「迎え酒」(mukae-zake，回魂酒)** | **只是暂时掩盖症状，并减慢分解。****有酒精依赖的风险** |
| **靠桑拿或运动出汗排酒** | **会加重脱水，很危险**（参见本站关于桑拿的文章） |
| **咖啡** | **咖啡因能让人暂时清醒；利尿作用会加重脱水。** 少量则无妨 |
| **市售头痛药** | **对乙酰氨基酚与酒精同服会加重肝脏负担。****请遵守用法，饮酒后不要马上服用** |

- 厚生劳动省《关于顾及健康的饮酒指南》（2024 年）建议**掌握纯酒精的摄入克数**以及**「饮酒前与饮酒中要进食并补水」**，并把宿醉描述为**「喝多了的信号」**。
- **约 40% 的日本人乙醛分解酶（ALDH2）的作用较弱**，容易脸红。**一般认为这类体质的人少量饮酒也容易宿醉，食道癌等疾病的风险也更高。**
- **「对宿醉有效」「保护肝脏」**之类的标示，**在日本的健康增进法与景品表示法（不正当赠品及不实标示防止法）下，普通食品与保健品是不允许使用的**。**即使是「機能性表示食品」(功能性标示食品，日本的一种标示类别)，也没有直接宣称「宿醉」的产品。**

## 误解1｜有对宿醉有效的饮料

**没有产品可以标示这样的功效，依据也未获确认。****水分、糖分、时间。**

## 误解2｜喝回魂酒会舒服些

**它会减慢分解，把症状往后推。** 一般认为这是**通向依赖的入口**。

## 误解3｜出汗就能把酒精排出去

**几乎没有酒精是通过汗液排出的；脱水反而加重，很危险。****不要蒸桑拿，不要做剧烈运动。**

## 误解4｜事先喝姜黄就有保护

**依据不充分，而且有肝功能障碍的报告。****预防在于喝多少，以及边喝边补水与进食。**

## 误解5｜吃片头痛药再接着喝

**对乙酰氨基酚与酒精同服会加重肝脏负担。****饮酒后不要马上吃止痛药；第二天早上按用法服用。****剧烈头痛、呕吐不止或意识模糊**属于紧急情况（在日本请拨打 119 叫救护车）：可能是急性酒精中毒。
