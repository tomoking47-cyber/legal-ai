# Q. 關於宿醉的因應方式，人們常有哪些誤解？｜Japan Questions #430

- Shelf: `health` ／ URL: `/zh-tw/health/hangover-remedies` ／ Status: **草稿 — 出處未核實**

每個國家都有自己的「解宿醉神物」。在日本，經典的選擇是「しじみ」(shijimi，蜆) 味噌湯、「梅干」(umeboshi，鹹梅乾) 與「ウコン」(ukon，薑黃) 飲料。以下依據厚生勞動省（厚生労働省）2024 年的飲酒指南與生理學的一般說法，整理哪些站得住腳、哪些沒有根據。

## A. 最大的誤解是「有某種食物或飲料對宿醉有效」。宿醉的主要成因是脫水、低血糖、乙醛以及睡眠品質下降；能確實幫上忙的是時間、水分、糖分與休息。市售飲料與保健食品不得標示預防或緩解宿醉，而「迎え酒」(mukae-zake，回魂酒) 只是把症狀往後推。預防在於喝多少，以及邊喝邊補水。

## 宿醉的機制與因應

| 原因 | 症狀 | 因應 |
|---|---|---|
| **脫水** | 頭痛、口渴、倦怠（酒精有利尿作用） | **水、口服電解質液或運動飲料，少量多次**（參見本站關於口服電解質液的文章） |
| **低血糖** | 頭暈站不穩、冷汗、無力 | **糖分（水果、粥、蜂蜜）** |
| **乙醛** | 噁心、心悸、臉部發熱潮紅。**分解能力由遺傳決定**（約 40% 的日本人分解酵素較弱） | **時間**（等待分解）。**回魂酒會讓分解更慢** |
| **胃部發炎** | 胃痛、噁心 | **少量好消化的食物；市售胃藥依用法服用** |
| **睡眠品質下降** | 想睡、專注力下降 | **休息**（參見本站關於酒精與睡眠的文章） |
| **丙酮與發炎性物質** | 全身倦怠 | 時間 |

| 常被提到的「對策」 | 評價 |
|---|---|
| **「しじみ」(shijimi，蜆) 味噌湯** | **作為補充水分、鹽分與胺基酸是合理的。****食品不得標示「鳥胺酸有助於肝臟」，緩解宿醉的根據也未獲確認** |
| **「ウコン」(ukon，薑黃／薑黃素) 飲料與保健食品** | **沒有充分根據顯示可以預防或改善宿醉**（國立健康·營養研究所）。**也有肝功能障礙的報告**，**有肝病的人請留意** |
| **「迎え酒」(mukae-zake，回魂酒)** | **只是暫時掩蓋症狀，並讓分解變慢。****有酒精成癮的風險** |
| **靠三溫暖或運動流汗排酒** | **會讓脫水惡化，很危險**（參見本站關於三溫暖的文章） |
| **咖啡** | **咖啡因能讓人暫時清醒；利尿作用會讓脫水加重。** 少量則無妨 |
| **市售頭痛藥** | **乙醯胺酚與酒精併用會加重肝臟負擔。****請遵守用法，飲酒後不要馬上服用** |

- 厚生勞動省《關於顧及健康的飲酒指南》（2024 年）建議**掌握純酒精的攝取公克數**以及**「飲酒前與飲酒中要進食並補水」**，並把宿醉描述為**「喝太多的訊號」**。
- **約 40% 的日本人乙醛分解酵素（ALDH2）的作用較弱**，容易臉紅。**一般認為這種體質的人少量飲酒也容易宿醉，食道癌等疾病的風險也較高。**
- **「對宿醉有效」「保護肝臟」**之類的標示，**在日本的健康增進法與景品表示法（不當贈品及不實標示防止法）之下，一般食品與保健食品是不被允許的**。**即使是「機能性表示食品」(功能性標示食品，日本的一種標示類別)，也沒有直接宣稱「宿醉」的產品。**

> **[待核實]** 2024 年飲酒指南的記述、薑黃的評價（國立健康·營養研究所「健康食品」資料庫）以及 ALDH2 的比例（e-健康net），請分別核實。

## 誤解1｜有對宿醉有效的飲料

**沒有產品可以標示這樣的功效，根據也未獲確認。****水分、糖分、時間。**

## 誤解2｜喝回魂酒會舒服一點

**它會讓分解變慢，把症狀往後推。** 一般認為這是**通往成癮的入口**。

## 誤解3｜流汗就能把酒精排出去

**幾乎沒有酒精是經由汗水排出的；脫水反而惡化，很危險。****不要泡三溫暖，不要做劇烈運動。**

## 誤解4｜事先喝薑黃就有保護

**根據不充分，而且有肝功能障礙的報告。****預防在於喝多少，以及邊喝邊補水與進食。**

## 誤解5｜吃顆頭痛藥再繼續喝

**乙醯胺酚與酒精併用會加重肝臟負擔。****飲酒後不要馬上吃止痛藥；隔天早上依用法服用。****劇烈頭痛、吐不停或意識不清**屬於緊急狀況（在日本請撥打 119 叫救護車）：可能是急性酒精中毒。
