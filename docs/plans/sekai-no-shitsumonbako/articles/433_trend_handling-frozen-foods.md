# Q. 冷凍食品の扱いについて、よくある誤解は？｜世界の質問箱 #433

- 棚：`trend` ／ URL：`/questions/handling-frozen-foods` ／ ステータス：**ドラフト（法務レビュー前・出典未検証）**

冷凍食品は日本の家庭で消費が増え続け、「解凍したものを再冷凍してよいか」「霜がついたら捨てるか」「賞味期限が切れても食べられるか」が問われます。冷凍食品の規格と、家庭の冷凍庫の限界から整理します。

## A. 最大の誤解は「冷凍食品は冷凍庫に入れておけば何年でも品質が変わらない」です。−18℃以下で菌は増えませんが、乾燥（冷凍焼け）と脂の酸化は進み、家庭の冷凍庫は開閉で温度が上下します。目安は「表示の賞味期限内に、開封後は1か月程度で」「一度解凍したものは再冷凍しない」「霜は品質低下のサインだが安全上の問題ではない」「加熱調理用は必ず加熱」です。

## 判断の材料

| 項目 | 内容 | 出典 |
|---|---|---|
| 冷凍食品の定義 | **前処理→急速凍結→−18℃以下で保管・流通**、**包装**された食品。**−18℃以下は日本冷凍食品協会とCodex（国際規格）の基準**で、**食品衛生法の保存基準は−15℃以下** | 日本冷凍食品協会（食品衛生法の保存基準は−15℃以下） |
| 家庭の冷凍庫 | **−18℃前後**が目標だが、**開閉で温度が上下**し、**ドア側は高め** | 家電製品協会 |
| 賞味期限 | **未開封で−18℃以下なら表示の期限（多くは1年〜1年半）**。**開封後は1か月程度**で使い切る（乾燥・酸化） | 日本冷凍食品協会 |
| 霜・冷凍焼け | **袋の中の霜＝一度温度が上がって再凍結した、または開封で湿気**。**白く乾いた部分＝冷凍焼け**。**安全上は食べられるが品質は落ちる** | 同上 |
| 再冷凍 | **一度解凍したものの再冷凍は品質低下と菌の増殖のリスク**。**「再冷凍しないでください」の表示**が多い | 同上 |
| 加熱 | **「加熱してお召し上がりください」の表示は、凍結前に加熱していないか、加熱が前提**。**「解凍してそのまま」は生食可** | 食品表示 |
| 電子レンジ | **表示のW数と時間を守る**。**中心が冷たいのは加熱不足**（食中毒の原因） | 同上 |
| 持ち帰り | **買い物の最後に、保冷バッグで、すぐ冷凍庫**。**夏は30分で表面が溶ける** | 同上 |

- 日本の**冷凍食品の国内消費量は年間約303万トン（2025年）で調査開始以来初めて300万トン台に達し、1人あたりの年間消費量は約24.6kg**と過去最高（日本冷凍食品協会、2026年4月発表の速報）。
- **冷凍食品の食中毒**は**加熱不足**が主因。**「加熱してお召し上がりください」の表示の製品を解凍だけで食べた**事例が報告されています。
- **自家製の冷凍**（作り置き・肉・野菜）は、**急速凍結ではないため品質の劣化が早く、2〜3週間〜1か月**が目安（冷凍のコツの記事参照）。

> 【要検証】消費量は日本冷凍食品協会の統計、表示の意味は食品表示基準で確認してください。

## 誤解1｜冷凍庫に入れておけば何年でも同じ

**乾燥と酸化は進み、家庭の冷凍庫は温度が安定しない**。**表示の期限内、開封後1か月**。

## 誤解2｜霜がついたら危険

**品質低下のサイン**で、**安全上は食べられる**ことが多い。**大量の霜・袋の破れ・変色・においがあれば処分**。

## 誤解3｜解凍して余ったら再冷凍

**品質低下と菌の増殖**。**使う分だけ取り出す**設計の製品が多い（小分け）。

## 誤解4｜冷凍食品は加熱済みだから温めるだけ

**「加熱してお召し上がりください」は加熱が前提**。**表示を確認し、中心まで熱く**。

## 誤解5｜買い物の途中で買って車に置いておく

**夏の車内では30分で表面が溶け、再凍結で品質低下**。**買い物の最後に、保冷バッグで、すぐ冷凍庫**。
