# Q. 關於冷凍食品的處理，常見的誤解有哪些？｜Japan Questions #433

- Shelf: `trend` ／ URL: `/zh-tw/trend/handling-frozen-foods` ／ Status: **草稿 — 出處未核實**

冷凍食品在日本家庭中的消費量持續上升，同樣的問題也一再出現：「解凍過的東西可以再冷凍嗎？」「結了霜就要丟掉嗎？」「過了賞味期限還能吃嗎？」這裡來看日本如何定義冷凍食品，以及家用冷凍室的極限。

## A. 最大的誤解是「冷凍食品放在冷凍室裡幾年都不會變」。在−18℃（0°F）以下細菌不會繁殖，但乾燥（凍傷）與油脂氧化仍在持續，而且家用冷凍室每次開門都會回溫再降溫。實用的原則是：「在賞味期限內吃完，開封後約一個月內吃完」「解凍過的東西絕不再冷凍」「結霜是品質下降的訊號，不是安全問題」「標示要加熱後食用的，就要加熱」。

## 判斷的依據

| 項目 | 內容 | 出處 |
|---|---|---|
| 冷凍食品的定義 | **經過前處理、急速冷凍，在−18℃以下保存與流通**，並且**經過包裝** | 日本冷凍食品協會；食品衛生法 |
| 家用冷凍室 | 目標是**−18℃前後**，但**每次開門溫度都會波動**，而且**靠門的一側溫度較高** | 家電製品協會 |
| 賞味期限「賞味期限」(shōmi-kigen，品質保持期限) | **未開封且保存在−18℃以下時，以包裝上的日期為準（通常為1年至1年半）。****開封後請在約一個月內吃完**（乾燥、氧化） | 日本冷凍食品協會 |
| 結霜與凍傷 | **袋內結霜＝溫度曾經上升後再凍結，或開封時進入了水分。****發白、乾硬的部分＝凍傷。****可以吃，但品質下降** | 同上 |
| 再冷凍 | **把解凍過的東西再冷凍，會造成品質下降與細菌繁殖的風險。** 多數產品都標有**「再冷凍しないでください」(請勿再冷凍)** | 同上 |
| 加熱 | **「加熱してお召し上がりください」(請加熱後食用) 表示該食品在冷凍前未經加熱，或以加熱為前提。****「解凍してそのまま」(解凍後直接食用) 表示不加熱也可以吃** | 食品標示 |
| 微波爐 | **請遵照包裝上的瓦數與時間。****中心是涼的就表示加熱不足**（食物中毒的原因之一） | 同上 |
| 帶回家 | **冷凍品最後再買，使用保冷袋，回家後立刻放進冷凍室。****夏天30分鐘內表面就會解凍** | 同上 |

- 日本**國內的冷凍食品消費量約為每年290萬公噸（2023年），人均約23 kg**，並呈上升趨勢（日本冷凍食品協會）。
- **冷凍食品引起的食物中毒**主要原因是**加熱不足。** 曾有報告指出，**標示「請加熱後食用」的產品，被人只解凍就吃了。**
- **自家冷凍**（做好的常備菜、肉、蔬菜）**不是急速冷凍，所以品質下降更快：2〜3週至1個月**是參考標準（參見關於冷凍技巧的那篇文章）。

## 誤解1｜放在冷凍室裡幾年都一樣

**乾燥與氧化仍在持續，而且家用冷凍室的溫度並不穩定。****請在期限內、開封後一個月內吃完。**

## 誤解2｜結霜就代表危險

**那是品質下降的訊號**，**通常仍然可以吃。****如果結霜嚴重、袋子破損、變色或有異味，就請丟掉。**

## 誤解3｜解凍後沒吃完可以放回冷凍室

**會造成品質下降與細菌繁殖。** 很多產品的設計就是**讓你只取出需要的份量**（小份包裝）。

## 誤解4｜冷凍食品都是熟的，只要加熱一下就好

**「請加熱後食用」代表以加熱為前提。****請確認標示，加熱到中心變熱為止。**

## 誤解5｜購物途中先買好，放在車裡也沒關係

**夏天車內30分鐘表面就會解凍，再凍結會降低品質。****請最後再買，使用保冷袋，回家後立刻冷凍。**
