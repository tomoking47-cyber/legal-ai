# Q. 野菜の洗い方（土・残留農薬・生食）について、よくある誤解は？｜世界の質問箱 #437

- 棚：`trend` ／ URL：`/questions/washing-vegetables` ／ ステータス：**ドラフト（法務レビュー前・出典未検証）**

「野菜は洗剤で洗うべきか」「残留農薬は洗えば落ちるか」「カット野菜は洗わなくてよいか」は各国で問われ、日本では専用の「野菜洗い」製品もあります。食品衛生と残留農薬の制度から整理します。

## A. 最大の誤解は「残留農薬が怖いから、野菜は洗剤や専用品で洗わなければならない」です。日本で流通する農産物は残留農薬基準（ポジティブリスト制度）の下にあり、流水で丁寧に洗うことが厚生労働省・農林水産省の案内です。洗う目的は土・虫・微生物（食中毒菌）を落とすことで、洗剤は不要です。カット野菜は洗浄済みですが、生食するなら軽く洗う人も多く、表示に従います。

## 判断の材料

| 項目 | 内容 | 出典 |
|---|---|---|
| 残留農薬の制度 | **ポジティブリスト制度（2006年〜）**：**基準を超える農薬が残留する食品の販売禁止**。**基準は生涯にわたって食べ続けても影響がない量（ADI）に基づく** | 厚生労働省・食品安全委員会 |
| 洗う目的 | **土・ほこり・虫・微生物（O157、サルモネラ等）を落とす**。**残留農薬は基準内なので、流水で十分** | 厚労省・農水省 |
| 洗剤 | **不要**。**食品用洗剤（野菜・果物用の表示）は使えるが、すすぎ残しの心配**。**台所用洗剤の多くは「野菜・果物」の用途表示がある**が、農水省は流水を案内 | 同上 |
| 洗い方 | **流水で30秒程度、こすり洗い**。**葉物は1枚ずつ、根元の土を落とす**。**ボウルの水で振り洗い→流水** | 同上 |
| 生食 | **生で食べる野菜（サラダ・薬味）は特に丁寧に**。**大葉・ミント等の香草も**（ハーブの記事参照） | 同上 |
| カット野菜 | **洗浄・殺菌済み**（次亜塩素酸ナトリウム等で殺菌後すすぎ）。**「洗わずに食べられます」の表示**が多い。**開封後はすぐ** | 食品表示 |
| 皮 | **皮に栄養が多い野菜（にんじん・大根・じゃがいも）は洗ってそのまま**。**残留農薬が気になるなら皮をむく**選択も | — |
| 湯通し・ゆでる | **ほうれん草等のアクや、加熱で減る農薬成分**もある | 農水省 |

- **食中毒の観点**：**生野菜による腸管出血性大腸菌（O157）の集団食中毒**（2012年の浅漬け事件など）があり、**土や堆肥由来の菌を流水で落とす**ことが重要。
- **「野菜洗い専用洗剤」「ホタテパウダー」**は雑貨または食品添加物で、**流水以上の効果を示す公的な根拠は限定的**。**すすぎ残し**の懸念もある。
- **農薬の残留量は、洗浄・調理でさらに減る**ことが農水省の資料で示されています（水洗いで**数割**、ゆでるとさらに）。

> 【要検証】ポジティブリスト制度は厚生労働省、洗浄による残留農薬の減少は農林水産省の資料、カット野菜の殺菌工程は厚生労働省の衛生規範で確認してください。

## 誤解1｜洗剤で洗わないと農薬が残る

**流通する農産物は基準内**で、**流水で十分**というのが公的な案内。**洗剤はすすぎ残しの心配**。

## 誤解2｜洗う目的は農薬を落とすこと

**主目的は土・虫・食中毒菌**。**生食の野菜こそ丁寧に**。

## 誤解3｜カット野菜は不衛生

**洗浄・殺菌済み**で、**「洗わずに食べられます」の表示**。**開封後は早く**。**むしろ家庭の洗い方より徹底している**ことも。

## 誤解4｜皮はむけば安全

**皮に栄養が多く、基準内なら洗ってそのまま**が農水省の案内。**皮をむくかは好み**。

## 誤解5｜無農薬・有機なら洗わなくてよい

**土・虫・菌は農薬の有無と無関係**。**有機農産物こそ堆肥由来の菌に注意**し、**流水で洗う**。
