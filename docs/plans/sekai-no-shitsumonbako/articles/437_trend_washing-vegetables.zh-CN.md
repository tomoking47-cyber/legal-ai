# Q. 关于洗蔬菜（泥土、农药残留、生吃），人们常有哪些误解？｜Japan Questions #437

- Shelf: `trend` ／ URL: `/zh-cn/trend/washing-vegetables` ／ Status: **草稿 — 出处未核实**

「蔬菜要用洗涤剂洗吗？」「洗能去掉农药残留吗？」「切好的净菜还需要洗吗？」——这些问题在每个国家都有人问。日本甚至有专门的「蔬果清洗剂」在售，很多日本的餐具洗涤剂也把「蔬菜、水果」列在用途里。这里说明日本的食品安全与农药残留制度是怎么运作的。

## A. 最大的误解是「农药残留很可怕，所以蔬菜必须用洗涤剂或专用产品洗」。在日本销售的农产品受肯定列表制度（ポジティブリスト制度）的农药残留限量约束，厚生劳动省（厚生労働省）与农林水产省（農林水産省）的指引是用流水仔细冲洗。洗的目的是去除泥土、虫子和微生物（食物中毒细菌），并不需要洗涤剂。切好的净菜已经清洗过，不过很多人在生吃前还是会再冲一下。请按标签说明操作。

## 判断的依据

| 项目 | 内容 | 出处 |
|---|---|---|
| 残留制度 | **肯定列表制度（2006 年起）**：**农药残留超过限量的食品不得销售。** **限量以终生每日摄取也不产生影响的量（ADI）为基础** | 厚生劳动省；食品安全委员会 |
| 为什么要洗 | **为了去除泥土、灰尘、虫子和微生物（O157、沙门氏菌等）。** **农药残留在限量之内，用流水冲洗就足够** | 厚生劳动省；农林水产省 |
| 洗涤剂 | **不需要。** **食品用洗涤剂（标注可用于蔬菜、水果）可以使用，但要注意冲洗残留。** **多数日本餐具洗涤剂把「蔬菜、水果」列为用途**，但农林水产省的指引是流水冲洗 | 同上 |
| 怎么洗 | **在流水下约 30 秒，边搓边冲。** **叶菜一片一片洗；根部的泥土要去掉。** **在盛水的盆里晃洗，再用水龙头冲净** | 同上 |
| 生吃 | **生吃的蔬菜（沙拉、配菜）需要特别小心。** **紫苏（大葉）、薄荷等香草也一样**（参见香草一文） | 同上 |
| 净菜（切好的蔬菜） | **已清洗并杀菌**（次氯酸钠等，之后冲洗）。多数标注**「无需清洗即可食用」（洗わずに食べられます）。** **开封后请尽快食用** | 食品标示 |
| 果皮 | **皮有营养的蔬菜（胡萝卜、白萝卜、土豆）可以洗净后带皮使用。** **若担心残留，削皮也是一种选择** | — |
| 焯水、水煮 | **部分涩味（如菠菜）和部分农药成分会随加热而减少** | 农林水产省 |

- **关于食物中毒**：曾发生**因生蔬菜引起的肠出血性大肠杆菌（O157）事件**（例如 2012 年的浅渍（浅漬け）事件），因此**用流水冲掉来自泥土和堆肥的细菌**很重要。
- **「蔬果清洗剂」和「扇贝壳粉」（ホタテパウダー）**作为日用品或食品添加剂销售，**公开证据中，它们优于流水冲洗的依据有限。** **冲洗残留**也是一个顾虑。
- **清洗与烹调会进一步降低农药残留**，农林水产省资料显示（用水冲洗**可降低数十个百分点**，水煮后进一步下降）。

> **[待核实]** 请向厚生劳动省核查肯定列表制度，对照农林水产省资料核查清洗对残留的降低效果，并对照厚生劳动省的卫生规范核查净菜的杀菌工序。

## 误解1｜不用洗涤剂，农药就洗不掉

**在售农产品在限量之内**，官方指引是**流水冲洗就足够。** **使用洗涤剂反而带来冲洗残留的顾虑。**

## 误解2｜洗的目的就是去农药

**主要目的是泥土、虫子和食物中毒细菌。** **生吃的蔬菜最需要留心。**

## 误解3｜净菜不卫生

**它们经过清洗和杀菌**，并标注**「无需清洗即可食用」。** **开封后请尽快食用。** **其工序可能比在家清洗更彻底。**

## 误解4｜削皮才安全

**皮里含有大量营养，农林水产省的指引是：在残留处于限量之内时，洗净后带皮使用。** **削皮属于个人偏好。**

## 误解5｜有机蔬菜或无农药蔬菜不用洗

**泥土、虫子和细菌与是否使用农药无关。** **有机农产品尤其要注意来自堆肥的细菌**：**请用流水冲洗。**
