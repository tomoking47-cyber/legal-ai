# Q. 關於洗蔬菜（泥土、農藥殘留、生吃），人們常有哪些誤解？｜Japan Questions #437

- Shelf: `trend` ／ URL: `/zh-tw/trend/washing-vegetables` ／ Status: **草稿 — 出處未核實**

「蔬菜要用洗潔精洗嗎？」「洗得掉農藥殘留嗎？」「切好的生菜沙拉包還需要洗嗎？」——這些問題在每個國家都有人問。日本甚至有專門的「蔬果清洗劑」在賣，許多日本的餐具洗潔精也把「蔬菜、水果」列在用途裡。這裡說明日本的食品安全與農藥殘留制度是怎麼運作的。

## A. 最大的誤解是「農藥殘留很可怕，所以蔬菜一定要用洗潔精或專用產品洗」。在日本販售的農產品受正面表列制度（ポジティブリスト制度）的農藥殘留限量規範，厚生勞動省（厚生労働省）與農林水產省（農林水産省）的指引是用流水仔細沖洗。洗的目的是去除泥土、蟲子與微生物（食物中毒細菌），並不需要洗潔精。切好的生菜已經清洗過，不過很多人在生吃前還是會再沖一下。請依照標示說明操作。

## 判斷的依據

| 項目 | 內容 | 出處 |
|---|---|---|
| 殘留制度 | **正面表列制度（2006 年起）**：**農藥殘留超過限量的食品不得販售。** **限量以終生每日攝取也不產生影響的量（ADI）為基礎** | 厚生勞動省；食品安全委員會 |
| 為什麼要洗 | **為了去除泥土、灰塵、蟲子與微生物（O157、沙門氏菌等）。** **農藥殘留在限量之內，用流水沖洗就足夠** | 厚生勞動省；農林水產省 |
| 洗潔精 | **不需要。** **食品用洗潔劑（標示可用於蔬菜、水果）可以使用，但要注意沖洗殘留。** **多數日本餐具洗潔精把「蔬菜、水果」列為用途**，但農林水產省的指引是流水沖洗 | 同上 |
| 怎麼洗 | **在流水下約 30 秒，一邊搓一邊沖。** **葉菜一片一片洗；根部的泥土要去掉。** **在裝水的盆裡晃洗，再用水龍頭沖淨** | 同上 |
| 生吃 | **生吃的蔬菜（沙拉、配菜）需要特別小心。** **紫蘇（大葉）、薄荷等香草也一樣**（參見香草一文） | 同上 |
| 切好的生菜（カット野菜） | **已清洗並殺菌**（次氯酸鈉等，之後沖洗）。多數標示**「無需清洗即可食用」（洗わずに食べられます）。** **開封後請盡快食用** | 食品標示 |
| 果皮 | **皮有營養的蔬菜（紅蘿蔔、白蘿蔔、馬鈴薯）可以洗淨後帶皮使用。** **若擔心殘留，削皮也是一種選擇** | — |
| 汆燙、水煮 | **部分澀味（如菠菜）與部分農藥成分會隨加熱而減少** | 農林水產省 |

- **關於食物中毒**：曾發生**因生蔬菜引起的腸出血性大腸桿菌（O157）事件**（例如 2012 年的淺漬（浅漬け）事件），因此**用流水沖掉來自泥土與堆肥的細菌**很重要。
- **「蔬果清洗劑」與「扇貝殼粉」（ホタテパウダー）**以日用品或食品添加物的形式販售，**公開證據中，它們優於流水沖洗的依據有限。** **沖洗殘留**也是一項顧慮。
- **清洗與烹調會進一步降低農藥殘留**，農林水產省資料顯示（用水沖洗**可降低數十個百分點**，水煮後進一步下降）。

> **[待核實]** 請向厚生勞動省核查正面表列制度，對照農林水產省資料核查清洗對殘留的降低效果，並對照厚生勞動省的衛生規範核查切好生菜的殺菌工序。

## 誤解1｜不用洗潔精，農藥就洗不掉

**在售農產品在限量之內**，官方指引是**流水沖洗就足夠。** **使用洗潔精反而帶來沖洗殘留的顧慮。**

## 誤解2｜洗的目的就是去農藥

**主要目的是泥土、蟲子與食物中毒細菌。** **生吃的蔬菜最需要留意。**

## 誤解3｜切好的生菜不衛生

**它們經過清洗與殺菌**，並標示**「無需清洗即可食用」。** **開封後請盡快食用。** **其工序可能比在家清洗更徹底。**

## 誤解4｜削皮才安全

**皮裡含有大量營養，農林水產省的指引是：在殘留處於限量之內時，洗淨後帶皮使用。** **削皮屬於個人偏好。**

## 誤解5｜有機蔬菜或無農藥蔬菜不用洗

**泥土、蟲子與細菌與是否使用農藥無關。** **有機農產品尤其要注意來自堆肥的細菌**：**請用流水沖洗。**
