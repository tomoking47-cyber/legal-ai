# Q. 食器洗いと食洗機について、よくある誤解は？｜世界の質問箱 #438

- 棚：`trend` ／ URL：`/questions/dishwashing-and-dishwashers` ／ ステータス：**ドラフト（法務レビュー前・出典未検証）**

食器洗いは毎日の家事で、「手洗いのほうが節水」「食洗機は洗い残す」「予洗いはどこまで」という論争が各国であります。日本では食洗機の普及率が約3割と低く、手洗いの知恵と食洗機の正しい使い方の両方を整理します。

## A. 最大の誤解は「手洗いのほうが食洗機より節水・省エネ」です。資源エネルギー庁の試算では、手洗い（ため洗い）は1回約40〜80Lの水を使い、食洗機（5人分）は約10Lで、給湯の光熱費を含めると食洗機のほうが安くなることが多い。手洗いの要点は「ため洗い・ゴム手袋・お湯は使いすぎない」、食洗機は「予洗いは残飯を落とすだけ」「専用洗剤」「詰め方」です。

## 数字で見る（資源エネルギー庁の試算）

| 項目 | 手洗い | 食洗機 |
|---|---|---|
| 水の使用量（1回・5人分） | **約40〜80L**（流し洗い） | **約10〜12L** |
| 年間の光熱費（給湯含む） | **約2万5,000円**（給湯40℃で流し洗い） | **約1万7,000円**（電気＋水道） |
| 洗浄温度 | **40℃前後**（手が耐える温度） | **60〜80℃**（高温で油汚れ・菌に有利） |
| 普及率（日本） | — | **約30%**（欧米は60〜70%） |

## 手洗いの要点

| 工夫 | 理由 |
|---|---|
| **ため洗い**（洗い桶）→**まとめてすすぐ** | 流し洗いの半分以下の水 |
| **油汚れは紙で拭き取ってから** | 油を排水に流さない・洗剤を減らす |
| **洗剤は水で薄めてスポンジに**、規定量 | 入れすぎはすすぎに水 |
| **お湯は必要なときだけ** | 給湯が光熱費の大半 |
| **ゴム手袋** | 手荒れ（手荒れの記事参照） |
| **洗う順番：ガラス→箸・皿→油汚れ→鍋** | 油を広げない |

## 食洗機の要点

| 工夫 | 理由 |
|---|---|
| **予洗いは残飯・骨・種を落とすだけ**。**こすり洗いは不要** | 食洗機のセンサーは汚れを検知して洗う。過度な予洗いは水と時間の無駄 |
| **食洗機専用洗剤**（台所用は泡が出て故障） | — |
| **詰め方：水流を遮らない、重ねない、口を下に** | 洗い残しの主因は詰め方 |
| **入れられないもの：木製・漆・アルミ（黒変）・クリスタル・金彩・耐熱でないプラ・鉄鍋** | 表示（食洗機可）を確認 |
| **フィルター掃除を毎回〜週1回** | においと洗浄力 |
| **まとめて1日1〜2回** | 少量を何度も回すより効率的 |

> 【要検証】水量・光熱費の試算は資源エネルギー庁「省エネ性能カタログ」「家庭の省エネ徹底ガイド」、普及率は内閣府消費動向調査で確認してください。

## 誤解1｜手洗いのほうが節水

**流し洗いは食洗機の4〜8倍の水**。**手洗いならため洗い**、**食洗機はまとめて回す**。

## 誤解2｜食洗機は洗い残す

**洗い残しの主因は詰め方と予洗いの過不足**。**水流を遮らず、専用洗剤、フィルター掃除**。

## 誤解3｜食洗機に入れる前にしっかり手で洗う

**残飯を落とすだけで十分**。**二度洗いは水と時間の無駄**で、センサーが汚れを検知しにくくなる機種も。

## 誤解4｜何でも食洗機に入れられる

**木・漆・アルミ・クリスタル・金彩・鉄鍋は不可**。**「食洗機対応」表示**を確認。

## 誤解5｜手洗いは冷たい水でもよい

**油汚れは40℃前後のお湯で落ちやすい**が、**給湯は光熱費の大半**。**油は紙で拭いてから、お湯は必要なときだけ**。
