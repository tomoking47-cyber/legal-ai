# Q. 关于洗碗和洗碗机，人们常有哪些误解？｜Japan Questions #438

- Shelf: `trend` ／ URL: `/zh-cn/trend/dishwashing-and-dishwashers` ／ Status: **草稿 — 出处未核实**

洗碗是每天都要做的家务，而「手洗是不是更省水」「洗碗机洗不干净吧」「要预冲洗到什么程度」这类争论在每个国家都有。在日本，家庭洗碗机普及率不到四成（2025 年 3 月为 37.3%），远低于欧美，租住的公寓也常常没有放置空间。这里既讲手洗的门道，也讲洗碗机的正确用法。

## A. 最大的误解是「手洗比洗碗机更省水省能源」。按资源能源厅（資源エネルギー庁）的估算，开着水龙头手洗一次约用水 65 L，而洗碗机（5 人份）约 7.5–11 L；把热水成本算进去后，洗碗机通常更便宜。手洗的要点是「用洗碗盆洗、戴橡胶手套、别滥用热水」；洗碗机的要点是「预冲洗只需去掉残渣」「使用洗碗机专用洗涤剂」「摆放要正确」。

## 数字（资源能源厅估算）

| 项目 | 手洗 | 洗碗机 |
|---|---|---|
| 每次用水量（5 人份） | **约 40–80 L**（开着水龙头冲） | **约 10–12 L** |
| 每年水电燃气费（含热水） | **约 ¥25,000**（40℃ 流水） | **约 ¥17,000**（电费＋水费） |
| 洗涤温度 | **40℃ 左右**（手能承受的热度） | **60–80℃**（高温有助于对付油污和细菌） |
| 普及率（日本） | — | **37.3%**（2025 年 3 月・内阁府消费动向调查；欧美约为 70%，德国约 75%） |

## 手洗的要点

| 做法 | 原因 |
|---|---|
| **用洗碗盆（洗い桶，arai-oke）洗** → **最后一起冲净** | 用水不到开着水龙头冲的一半 |
| **先用纸把油污擦掉** | 让油不进下水道，也减少洗涤剂用量 |
| **在海绵上用水稀释洗涤剂**，按标示用量使用 | 用得太多，冲洗又要更多水 |
| **只在需要时用热水** | 加热水占了费用的大部分 |
| **橡胶手套** | 防止手粗糙皲裂（参见护手一文） |
| **顺序：玻璃杯 → 筷子和盘子 → 油腻的餐具 → 锅** | 避免油污扩散 |

## 洗碗机的要点

| 做法 | 原因 |
|---|---|
| **预冲洗只需去掉残渣、骨头和籽。** **不需要刷洗** | 洗碗机的传感器会检测脏污并相应清洗。过度预洗浪费水和时间 |
| **只用洗碗机专用洗涤剂**（普通餐具洗涤剂会起泡并导致故障） | — |
| **摆放：不要挡住喷水、不要叠放、开口朝下** | 摆放不当是洗不干净的主要原因 |
| **不要放入：木制品、漆器、铝（会发黑）、水晶玻璃、描金瓷器、不耐热塑料、铁锅** | 请确认可用洗碗机的标记（食洗機可） |
| **每次到每周清洗一次滤网** | 关系到异味和清洗力 |
| **装满再开，一天一到两次** | 比分几次小批量清洗更高效 |

## 误解1｜手洗更省水

**开着水龙头冲，用水量是洗碗机的 4–8 倍。** **手洗的话请用洗碗盆**；**有洗碗机的话请装满再开。**

## 误解2｜洗碗机洗不干净

**主要原因是摆放不当，以及预冲洗过多或过少。** **不要挡住喷水，使用洗碗机专用洗涤剂，并清洗滤网。**

## 误解3｜放进去之前要先用手好好洗一遍

**去掉残渣就够了。** **洗两遍浪费水和时间**，而且在某些机型上，传感器反而难以检测脏污。

## 误解4｜什么都能放进洗碗机

**木制品、漆器、铝、水晶玻璃、描金瓷器和铁锅不行。** **请找「可用洗碗机」（食洗機対応）的标记。**

## 误解5｜手洗用冷水就行

**在 40℃ 左右油污更容易洗掉**，但**加热水占了费用的大部分。** **先用纸把油污擦掉，只在需要时用热水。**
