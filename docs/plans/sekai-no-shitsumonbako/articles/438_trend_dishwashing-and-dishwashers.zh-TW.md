# Q. 關於洗碗與洗碗機，人們常有哪些誤解？｜Japan Questions #438

- Shelf: `trend` ／ URL: `/zh-tw/trend/dishwashing-and-dishwashers` ／ Status: **草稿 — 出處未核實**

洗碗是每天都要做的家事，而「手洗是不是比較省水」「洗碗機洗不乾淨吧」「要預先沖到什麼程度」這類爭論，每個國家都有。在日本，家用洗碗機普及率不到四成（2025 年 3 月為 37.3%），遠低於歐美，租來的公寓也常常沒有擺放空間。這裡既談手洗的訣竅，也談洗碗機的正確用法。

## A. 最大的誤解是「手洗比洗碗機更省水省能源」。依資源能源廳（資源エネルギー庁）的估算，開著水龍頭手洗一次約用水 65 L，而洗碗機（5 人份）約 7.5–11 L；把熱水成本算進去後，洗碗機通常比較便宜。手洗的重點是「用洗碗盆洗、戴橡膠手套、別浪費熱水」；洗碗機的重點是「預沖只要去掉殘渣」「使用洗碗機專用洗劑」「擺放要正確」。

## 數字（資源能源廳估算）

| 項目 | 手洗 | 洗碗機 |
|---|---|---|
| 每次用水量（5 人份） | **約 40–80 L**（開著水龍頭沖） | **約 10–12 L** |
| 每年水電瓦斯費（含熱水） | **約 ¥25,000**（40℃ 流水） | **約 ¥17,000**（電費＋水費） |
| 洗滌溫度 | **40℃ 左右**（手能承受的熱度） | **60–80℃**（高溫有助於對付油汙與細菌） |
| 普及率（日本） | — | **37.3%**（2025 年 3 月・內閣府消費動向調查；歐美約為 70%，德國約 75%） |

## 手洗的重點

| 做法 | 原因 |
|---|---|
| **用洗碗盆（洗い桶，arai-oke）洗** → **最後一起沖乾淨** | 用水不到開著水龍頭沖的一半 |
| **先用紙把油汙擦掉** | 讓油不流進排水管，也減少洗劑用量 |
| **在菜瓜布上用水稀釋洗劑**，依標示用量使用 | 用太多，沖洗又要更多水 |
| **只在需要時用熱水** | 加熱水佔了費用的大部分 |
| **橡膠手套** | 防止手粗糙龜裂（參見護手一文） |
| **順序：玻璃杯 → 筷子與盤子 → 油膩的餐具 → 鍋子** | 避免油汙擴散 |

## 洗碗機的重點

| 做法 | 原因 |
|---|---|
| **預沖只要去掉殘渣、骨頭與籽。** **不需要刷洗** | 洗碗機的感測器會偵測髒汙並據以清洗。過度預洗浪費水與時間 |
| **只用洗碗機專用洗劑**（一般餐具洗潔精會起泡並導致故障） | — |
| **擺放：不要擋住噴水、不要疊放、開口朝下** | 擺放不當是洗不乾淨的主因 |
| **不要放入：木製品、漆器、鋁（會發黑）、水晶玻璃、描金瓷器、不耐熱塑膠、鐵鍋** | 請確認可用洗碗機的標示（食洗機可） |
| **每次到每週清洗一次濾網** | 關係到異味與清洗力 |
| **裝滿再開，一天一到兩次** | 比分成幾次小批清洗更有效率 |

> **[待核實]** 請對照資源能源廳的「節能性能型錄」與「家庭節能徹底指南」核查用水量與費用估算，並對照內閣府消費動向調查核查普及率。

## 誤解1｜手洗比較省水

**開著水龍頭沖，用水量是洗碗機的 4–8 倍。** **手洗的話請用洗碗盆**；**有洗碗機的話請裝滿再開。**

## 誤解2｜洗碗機洗不乾淨

**主因是擺放不當，以及預沖過多或過少。** **不要擋住噴水，使用洗碗機專用洗劑，並清洗濾網。**

## 誤解3｜放進去之前要先用手好好洗一遍

**去掉殘渣就夠了。** **洗兩遍浪費水與時間**，而且在某些機型上，感測器反而不容易偵測髒汙。

## 誤解4｜什麼都能放進洗碗機

**木製品、漆器、鋁、水晶玻璃、描金瓷器與鐵鍋不行。** **請找「可用洗碗機」（食洗機対応）的標示。**

## 誤解5｜手洗用冷水就好

**在 40℃ 左右油汙比較容易洗掉**，但**加熱水佔了費用的大部分。** **先用紙把油汙擦掉，只在需要時用熱水。**
