# Q. キッチンの排水口の掃除について、よくある誤解は？｜世界の質問箱 #439

- 棚：`trend` ／ URL：`/questions/cleaning-the-kitchen-drain` ／ ステータス：**ドラフト（法務レビュー前・出典未検証）**

排水口は台所で最も嫌われる掃除場所で、「ぬめり」「におい」「詰まり」の悩みは世界共通です。日本の排水口の構造（ゴミ受け・トラップ）と、日々の手入れ、洗剤の安全な使い方を整理します。

## A. 最大の誤解は「排水口の掃除は月1回、強い洗剤でまとめてやるもの」です。ぬめりとにおいは数日でできるため、毎日ゴミ受けを空にして乾かし、週1回ブラシで洗うほうが、月1回の強い洗剤より効きます。塩素系（ぬめり・カビ）と酸性・クエン酸系（水垢）は絶対に同時に使わず、油は排水に流さないことが詰まり予防の基本です。

## 構造と手入れ

| 部位 | 内容 | 頻度 | 方法 |
|---|---|---|---|
| **ゴミ受け（バスケット）** | 生ごみ・野菜くずを受ける | **毎日**空にして洗う。**夜に乾かす** | **ネット（水切り袋）**を使い、寝る前に捨てる |
| **トラップ（椀・カップ）** | 水をためて下水のにおい・虫を防ぐ（封水） | **週1回** | 外して**中性洗剤とブラシ**、ぬめりは**塩素系（薄めて数分）→よく流す** |
| **排水口の内側・ふた** | ぬめり・黒カビ | 週1回 | 同上 |
| **排水管** | 油・石けんかすの付着→詰まり | **月1回程度** | **パイプ用洗浄剤（表示どおり）**、または**お湯（50〜60℃）を流す**（**熱湯は配管を傷める**） |
| **三角コーナー** | 生ごみの一時置き | 毎日 | 使わない家庭が増加（ネットで直接捨てる） |

| 安全 | 内容 |
|---|---|
| **混ぜるな危険** | **塩素系（カビ・ぬめり）と酸性（クエン酸・酢・一部のパイプ洗浄剤）を同時に使わない**。**有毒な塩素ガス**。**別の日に、よく流してから** |
| **換気** | 塩素系使用時は窓を開ける、ゴム手袋 |
| **熱湯** | **一般的な塩ビ排水管（VP）の耐熱は約60℃**。**60℃を超えるお湯は管の変形・継手の劣化の原因**（耐熱塩ビHT管でも上限90℃）。**流すなら50〜60℃**まで |
| **油** | **絶対に流さない**（拭き取る・固める）。**排水管の詰まりと下水処理の負荷**（揚げ油の記事参照） |

- **ぬめり**は**細菌のバイオフィルム**で、**生ごみと湿気**が条件。**毎日空にして乾かす**ことが最大の予防。
- **重曹＋クエン酸の発泡**は、**汚れを浮かせる補助**にはなるが、**混ぜた後はほぼ中和されて洗浄力は弱い**（重曹とクエン酸の記事参照）。**塩素系とは絶対に混ぜない**。
- **においが取れない**場合は、**トラップの封水が切れている**（長期不在・蒸発）ことも。**水を流せば戻る**。

> 【要検証】混ぜるな危険の注意は東京都保健医療局、配管の耐熱は住宅設備メーカーの資料で確認してください。

## 誤解1｜月1回の強い洗剤で十分

**ぬめりは数日でできる**。**毎日ゴミ受けを空にして乾かす、週1回ブラシ**のほうが効く。

## 誤解2｜塩素系とクエン酸を一緒に使えば強力

**有毒ガス**。**別の日に、よく流してから**。

## 誤解3｜熱湯を流せば油も菌も一掃

**一般的な塩ビ管（VP）の耐熱は約60℃で、60℃を超えるお湯は配管とパッキンを傷める**。**流すなら50〜60℃**。**油は流さない**が前提。

## 誤解4｜重曹とクエン酸の発泡で完全に洗浄

**発泡は補助で、中和後の洗浄力は弱い**。**ぬめりは塩素系（単独）かブラシ**、**水垢はクエン酸（単独）**。

## 誤解5｜においは排水口の汚れとは別

**トラップの封水切れ、ゴミ受けの残り、ぬめり**が主因。**水を流す・空にする・洗う**の順で確認。
