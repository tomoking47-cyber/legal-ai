# Q. 生ごみのにおい対策について、よくある誤解は？｜世界の質問箱 #440

- 棚：`trend` ／ URL：`/questions/kitchen-waste-odour` ／ ステータス：**ドラフト（法務レビュー前・出典未検証）**

生ごみのにおいは夏の台所の最大の悩みで、収集日が週2回の日本では「次の収集日までどう保管するか」が生活の知恵として蓄積されています。においの原因と、冷凍・水切り・処理機まで整理します。

## A. 最大の誤解は「においは消臭剤やふた付きのゴミ箱で防ぐもの」です。においの原因は生ごみの水分と温度で細菌が増えることで、対策の順は「水気を切る（最大の要因）」「新聞紙で包んで水分を吸わせる」「肉・魚は収集日まで冷凍」「ゴミ箱は風通しのよい場所、内側を拭く」で、消臭剤は補助です。自治体の生ごみ処理機の補助金や、コンポストも選択肢です。

## 原因と対策

| 原因 | 内容 | 対策 |
|---|---|---|
| **水分** | 生ごみの**約8割は水分**。水分が多いほど細菌が増え、においとコバエ | **三角コーナー・ネットでしっかり水切り**、**新聞紙・古紙に包む**（吸水）、**茶殻・コーヒーかすは乾かす** |
| **温度** | **夏の台所（25〜35℃）**で急増 | **肉・魚のトレー・骨・皮は袋に密閉して冷凍**、収集日の朝に出す |
| **空気（好気）と密閉（嫌気）** | 密閉しすぎると**嫌気性の菌で強いにおい** | **袋の口を軽く閉め、ゴミ箱は風通しのよい場所**。**ふた付きなら内側を拭く** |
| **酸性のにおい** | 腐敗で酸性に | **重曹をふりかける**（アルカリで中和） |
| **コバエ** | 生ごみ・果物の皮・排水口 | **果物の皮は袋に密閉**、**排水口の掃除**（前の記事） |
| **ゴミ袋** | 自治体指定袋 | **二重にする**、**口を結ぶ** |

| 減らす・処理する | 内容 |
|---|---|
| **生ごみ処理機（乾燥式・バイオ式）** | **多くの自治体が購入費の1/2〜2/3（上限2〜3万円）を補助** |
| **コンポスト（ベランダ・段ボール）** | 都市部でも**段ボールコンポスト・密閉容器**が普及。自治体の講習 |
| **ディスポーザー** | **設置に自治体の許可・専用の処理槽が必要**（多くの自治体で単体設置は不可） |
| **食品ロス削減** | **買いすぎない・使い切る**（食品ロスの記事参照）が根本 |

- **家庭の生ごみは可燃ごみの約3〜4割（重量）**で、**その8割が水分**。**水切りだけで自治体の焼却の負担と燃料を減らす**（環境省・各自治体の啓発）。
- **生ごみの冷凍**は、**「冷凍庫に生ごみ」に抵抗があるが、密閉すれば衛生上の問題はない**とする自治体の案内が多く、**夏の定番の知恵**。
- **ゴミ箱の内側を週1回拭き、乾かす**。**消臭剤・防臭袋**は補助。

> 【要検証】生ごみの割合・水分率は環境省・自治体の資料、処理機の補助金はお住まいの自治体で確認してください。ディスポーザーの設置可否も自治体ごとに異なります。

## 誤解1｜においは消臭剤とふたで防ぐ

**原因は水分と温度**。**水切り・新聞紙・冷凍**が先、消臭剤は補助。

## 誤解2｜密閉すればにおわない

**密閉しすぎると嫌気性の菌で強いにおい**。**軽く閉めて風通しのよい場所、内側を拭く**。

## 誤解3｜生ごみを冷凍庫に入れるのは不衛生

**密閉すれば衛生上の問題はない**とする自治体が多く、**夏の肉・魚は冷凍が定番**。**専用の袋・場所を決める**。

## 誤解4｜ディスポーザーがあれば解決

**単体設置は多くの自治体で不可**（下水処理の負荷）。**専用処理槽付きの許可制**。

## 誤解5｜生ごみ処理機は高い

**自治体の補助（1/2〜2/3、上限2〜3万円）**があることが多い。**段ボールコンポスト**は数百円から。
