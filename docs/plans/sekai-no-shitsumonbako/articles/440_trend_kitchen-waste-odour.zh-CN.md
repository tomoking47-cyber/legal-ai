# Q. 关于处理厨余异味，人们常有哪些误解？｜Japan Questions #440

- Shelf: `trend` ／ URL: `/zh-cn/trend/kitchen-waste-odour` ／ Status: **草稿 — 出处未核实**

厨余的气味是日本厨房夏天最头疼的问题。可燃垃圾（可燃ごみ，kanen-gomi，包含厨余）通常一周只收两次，因此围绕「怎么撑到下一个收运日」，积累了大量的家庭生活智慧。这里讲异味的成因，以及从沥水、冷冻到厨余处理机的各种办法。

## A. 最大的误解是「用除臭剂或带盖垃圾桶就能止住气味」。气味来自细菌在厨余的水分和温度中大量繁殖。行动的顺序是：「沥掉水分（最关键的一步）」「用报纸包起来吸水」「肉和鱼冷冻到收运日」「垃圾桶放在通风处并擦拭内壁」；除臭剂只是辅助。市区町村对厨余处理机的补贴，以及堆肥，是进一步的选择。

## 成因与对策

| 成因 | 内容 | 怎么做 |
|---|---|---|
| **水分** | **厨余约 80% 是水。** 越湿细菌繁殖越快，带来异味和果蝇 | **在三角滤篮或网袋里彻底沥水**，**用报纸或废纸包起来**（吸水），**茶叶渣和咖啡渣晾干** |
| **温度** | 细菌在**夏天的厨房（25–35℃）**里繁殖很快 | **把肉鱼的托盘、骨头和皮装袋密封后冷冻**；收运日早上再拿出去 |
| **通气（好氧）与密封（厌氧）** | 密封得太严实，**厌氧菌会产生更强烈的气味** | **袋口松松地合上，垃圾桶放在通风处。** **有盖子的话，擦拭内侧** |
| **酸臭味** | 腐败会变酸 | **撒一点小苏打**（碱性，可中和） |
| **果蝇** | 厨余、果皮、下水口 | **把果皮装袋密封**，**清洁下水口**（参见上一篇文章） |
| **垃圾袋** | 市区町村指定袋（指定袋） | **套两层袋**，**扎紧袋口** |

| 减量与处理 | 内容 |
|---|---|
| **厨余处理机（干燥式或生物式）** | **许多市区町村补贴购买价格的 1/2 到 2/3（上限 ¥20,000–30,000）** |
| **堆肥（阳台或纸箱）** | **纸箱堆肥和密闭容器**在城市里也很常见。市区町村会开办讲座 |
| **厨余粉碎机（ディスポーザー）** | **安装需要市区町村许可和专用处理槽**（多数市区町村不允许单体安装） |
| **减少食物浪费** | **少买、吃完**（参见食物浪费一文）才是根本的答案 |

- **家庭厨余按重量约占可燃垃圾的 30–40%**，**其中 80% 是水。** **仅仅沥水就能减轻市区町村焚烧设施的负担和燃料消耗**（环境省与各市区町村的宣传）。
- **冷冻厨余**：许多市区町村说明，**虽然人们对「把厨余放进冷冻室」有抵触，但只要密封好就没有卫生问题**，而且这是**夏天的常规做法。**
- **每周擦拭一次垃圾桶内侧并晾干。** **除臭剂和防臭垃圾袋**是辅助手段。

> **[待核实]** 请对照环境省与各市区町村资料核查厨余的占比与含水率，并向所在市区町村确认处理机补贴。厨余粉碎机是否获准安装也因市区町村而异。

## 误解1｜除臭剂加盖子就能止住气味

**成因是水分和温度。** **先沥水、用报纸包、冷冻**；除臭剂是辅助。

## 误解2｜密封起来就不会臭

**密封得太严实，厌氧菌反而产生更强烈的气味。** **松松地合上，放在通风处，擦拭内侧。**

## 误解3｜把厨余放进冷冻室不卫生

**许多市区町村说明，只要密封好就没有卫生问题**，而且**夏天冷冻肉鱼类厨余是常规做法。** **请专门准备一个袋子和一个位置。**

## 误解4｜装个厨余粉碎机就能解决一切

**多数市区町村不允许单体安装**（会加重污水处理厂的负担）。**需要许可，并配备专用处理槽。**

## 误解5｜处理机太贵

**市区町村补贴（1/2 到 2/3，上限 ¥20,000–30,000）**很常见。**纸箱堆肥**几百日元就能开始。
