# Q. 關於處理廚餘異味，人們常有哪些誤解？｜Japan Questions #440

- Shelf: `trend` ／ URL: `/zh-tw/trend/kitchen-waste-odour` ／ Status: **草稿 — 出處未核實**

廚餘的氣味是日本廚房夏天最令人頭痛的問題。可燃垃圾（可燃ごみ，kanen-gomi，包含廚餘）通常一週只收兩次，因此圍繞著「怎麼撐到下一個收運日」，累積了大量的家庭生活智慧。這裡談氣味的成因，以及從瀝水、冷凍到廚餘處理機的各種辦法。

## A. 最大的誤解是「用除臭劑或有蓋垃圾桶就能止住氣味」。氣味來自細菌在廚餘的水分與溫度中大量繁殖。行動的順序是：「瀝掉水分（最關鍵的一步）」「用報紙包起來吸水」「肉與魚冷凍到收運日」「垃圾桶放在通風處並擦拭內壁」；除臭劑只是輔助。市區町村對廚餘處理機的補助，以及堆肥，是進一步的選擇。

## 成因與對策

| 成因 | 內容 | 怎麼做 |
|---|---|---|
| **水分** | **廚餘約 80% 是水。** 越濕細菌繁殖越快，帶來異味與果蠅 | **在三角濾網籃或網袋裡徹底瀝水**，**用報紙或廢紙包起來**（吸水），**茶葉渣與咖啡渣晾乾** |
| **溫度** | 細菌在**夏天的廚房（25–35℃）**裡繁殖很快 | **把肉魚的托盤、骨頭與皮裝袋密封後冷凍**；收運日早上再拿出去 |
| **通氣（好氧）與密封（厭氧）** | 密封得太緊，**厭氧菌會產生更強烈的氣味** | **袋口鬆鬆地合上，垃圾桶放在通風處。** **有蓋子的話，擦拭內側** |
| **酸臭味** | 腐敗會變酸 | **撒一點小蘇打**（鹼性，可中和） |
| **果蠅** | 廚餘、果皮、排水口 | **把果皮裝袋密封**，**清潔排水口**（參見上一篇文章） |
| **垃圾袋** | 市區町村指定袋（指定袋） | **套兩層袋**，**綁緊袋口** |

| 減量與處理 | 內容 |
|---|---|
| **廚餘處理機（乾燥式或生物式）** | **許多市區町村補助購買價格的 1/2 到 2/3（上限 ¥20,000–30,000）** |
| **堆肥（陽台或紙箱）** | **紙箱堆肥與密閉容器**在都市裡也很常見。市區町村會開辦講座 |
| **廚餘絞碎機（ディスポーザー）** | **安裝需要市區町村許可與專用處理槽**（多數市區町村不允許單體安裝） |
| **減少食物浪費** | **少買、吃完**（參見食物浪費一文）才是根本的答案 |

- **家庭廚餘依重量約占可燃垃圾的 30–40%**，**其中 80% 是水。** **光是瀝水就能減輕市區町村焚化設施的負擔與燃料消耗**（環境省與各市區町村的宣導）。
- **冷凍廚餘**：許多市區町村說明，**雖然大家對「把廚餘放進冷凍庫」有抗拒，但只要密封好就沒有衛生問題**，而且這是**夏天的常規做法。**
- **每週擦拭一次垃圾桶內側並晾乾。** **除臭劑與防臭垃圾袋**是輔助手段。

> **[待核實]** 請對照環境省與各市區町村資料核查廚餘的占比與含水率，並向所在市區町村確認處理機補助。廚餘絞碎機是否獲准安裝也因市區町村而異。

## 誤解1｜除臭劑加蓋子就能止住氣味

**成因是水分與溫度。** **先瀝水、用報紙包、冷凍**；除臭劑是輔助。

## 誤解2｜密封起來就不會臭

**密封得太緊，厭氧菌反而產生更強烈的氣味。** **鬆鬆地合上，放在通風處，擦拭內側。**

## 誤解3｜把廚餘放進冷凍庫不衛生

**許多市區町村說明，只要密封好就沒有衛生問題**，而且**夏天冷凍肉魚類廚餘是常規做法。** **請專門準備一個袋子與一個位置。**

## 誤解4｜裝個廚餘絞碎機就能解決一切

**多數市區町村不允許單體安裝**（會加重污水處理廠的負擔）。**需要許可，並配備專用處理槽。**

## 誤解5｜處理機太貴

**市區町村補助（1/2 到 2/3，上限 ¥20,000–30,000）**很常見。**紙箱堆肥**幾百日圓就能開始。
