# Q. 關於帶孩子在日本旅行，人們常有哪些誤解？｜Japan Questions #441

- Shelf: `inbound` ／ URL: `/zh-tw/questions/travelling-with-children` ／ Status: **草稿 — 出處未核實**

日本是全世界最安全、對兒童最友善的旅遊目的地之一，而且針對兒童的設施——哺乳室、兒童餐、男廁裡的尿布台——很容易被忽略，因為它們不會用英文宣傳。例外只是電車和餐廳裡的幾條規矩。

## A. 最常見的誤解是以為日本人多又講究禮節，帶小孩會很辛苦。百貨公司和購物中心都有備有熱水和尿布台的哺乳室，6 歲以下兒童搭電車免費，大多數餐廳有兒童餐具和兒童餐，便利商店買得到尿布和嬰兒副食品。需要事先規劃的是：尖峰時段電車上的嬰兒車、吧檯式餐廳沒有兒童椅，以及去哪家藥局買兒童用藥。

## 實用資訊

| 項目 | 詳情 |
|---|---|
| **電車票價** | **6 歲以下：免費**（每位付費乘客最多可帶兩名；第三名幼兒付兒童票價）；**6–11 歲：半價**；12 歲以上：成人票。新幹線：6 歲以下不佔座免費，若單獨佔用指定席則付半價 |
| **嬰兒車** | 所有電車均可攜帶；尖峰時段請**收折或使用輪椅空間**；**幾乎所有車站都有電梯**（車站地圖有標示）；部分車廂貼有**優先空間貼紙** |
| **哺乳室（授乳室）** | **百貨公司、購物中心、大型車站、機場、部分公園**；通常備有**熱水、尿布台、微波爐、洗手台**；有 App（如「Mamamap」）可查詢 |
| **尿布台** | 設在**女廁和許多男廁**內，以及多功能（無障礙）廁所內 |
| **餐廳** | 家庭餐廳和百貨公司餐廳樓層有**兒童餐（お子様ランチ）**；幾乎所有地方都可索取**兒童餐具**；家庭餐廳有**兒童椅**，**吧檯式餐廳和居酒屋則沒有** |
| **用品** | 藥妝店和許多便利商店有售**尿布、濕紙巾、嬰兒副食品、配方奶（奶粉，2019 年起也有液態奶）、兒童用藥** |
| **藥品** | **兒童用乙醯胺酚、感冒藥、口服電解質液（ORS）**為非處方藥；夜間／週末可撥打 **#8000** 諮詢（日語；時間因都道府縣而異，通常為 19:00–08:00）；**小兒科診所**遍布各地 |
| **飯店** | **6 歲以下兒童與大人同床通常免費**（親子同睡在日本很普遍）；3 人以上可選**家庭房和日式旅館**；請盡早預約**嬰兒床（ベビーベッド）** |
| **優惠** | **大多數博物館 6 歲以下免費**，12 歲或 15 歲以下有折扣 |

- **日本的兒童死亡率和受傷率位居全球最低之列**；旅途中的主要風險是**夏季高溫**、**老車站的樓梯**，以及**沒有人行道的窄巷車流**。
- **禮節**：孩子是受歡迎的，但**在電車上和安靜的餐廳裡出聲**是唯一會引來目光的事（參見電車禮儀一文）。**家庭餐廳和美食街**是壓力最小的選擇。
- **刺青、溫泉與兒童**：**兒童可以進溫泉**；部分浴場對**男女混浴設有年齡上限（多為 6–7 歲）**；穿尿布的嬰兒在大多數公共浴池不得入浴。

> **[待核實]** 票價規則請向 JR 東日本及各營運公司確認；#8000 請向厚生勞動省確認；飯店兒童政策各有不同。

## 誤解1｜日本沒有為兒童做準備

**哺乳室、尿布台、兒童餐和 6 歲以下免費搭車**都是標準配備，只是標示用的是日文。百貨公司是可靠的據點。

## 誤解2｜嬰兒車在電車上不實用

**每個大站都有電梯**；規矩是**避開 7:30–9:00，在擠滿人的車廂裡收折**。離峰時段很輕鬆。

## 誤解3｜兒童用藥需要醫師處方

每家藥妝店都有**兒童用非處方藥**；**#8000 在夜間和週末提供電話諮詢**；**小兒科診所**數量多，在國民醫療制度下費用低廉（旅客需全額自付，但費用不高）。

## 誤解4｜餐廳不歡迎小孩

**家庭餐廳、百貨公司餐廳樓層、美食街和大多數一般餐廳**都歡迎小孩，並提供兒童餐。**吧檯壽司店、高級懷石料理和夜間的居酒屋**才是小孩不合適的場所。

## 誤解5｜飯店按兒童人數收費

商務飯店和城市飯店**6 歲以下與大人同床通常免費**；請確認政策。**日式旅館按人頭收費並含餐**——可詢問兒童餐價格。
