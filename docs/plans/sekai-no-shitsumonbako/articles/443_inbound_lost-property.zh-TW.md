# Q. 關於在日本遺失物品，人們常有哪些誤解？｜Japan Questions #443

- Shelf: `inbound` ／ URL: `/zh-tw/questions/lost-property` ／ Status: **草稿 — 出處未核實**

日本「掉了皮夾也能找回來」的名聲名副其實，而且它靠的是一套制度，不只是誠實：拾得物品有依法送交的義務，有全國性的警察遺失物資料庫，車站和商店也都有確實執行的流程。了解這套制度的旅客能找回東西；先認定找不回來的人則從不去問。

## A. 最常見的誤解是以為掉了的東西就沒了。在日本，大多數遺失物都會被送交——東京警方每年收到約 400 萬件物品，皮夾和手機大多能歸還失主——因為《遺失物法》要求拾得者送交並給予報酬，也因為車站、計程車公司和商店都有流程。步驟是：當天沿原路找並向現場詢問，接著到警察遺失物中心（東京有線上查詢，但只有日文），護照則到本國駐外館處辦理。

## 制度如何運作

| 步驟 | 地點 | 詳情 |
|---|---|---|
| **1. 當天** | **現場**（車站辦公室、商店、餐廳、計程車公司） | 物品在移交警方前會在現場保管**幾天到一週**；**JR 東日本設有英語失物招領電話和線上表單** |
| **2. 數日內** | **警察遺失物中心（遺失物センター）**或任何一處**派出所（交番）** | 提交遺失申報（遺失届）；**東京警視廳有英文指南頁面，但其拾得物線上查詢只有日文**（可用瀏覽器翻譯或到派出所詢問）；其他都道府縣請電話洽詢 |
| **3. 護照** | 警方報案證明 → **本國駐外館處**申辦緊急護照 | 另外保存一份影本 |
| **4. 信用卡和手機** | **發卡銀行**；現場 | 掛失卡片；**手機通常找得到**——使用定位 App，並注意拾得者常把手機交給現場 |
| 報酬 | 拾得者依法有權獲得物品價值的 **5–20%**（若在車站、商店等設施內拾得，則減半為 2.5–10%，另一半歸該設施）；**大多數人會婉拒** | 《遺失物法》第 28 條 |
| 保管期 | 警方保管 **3 個月**；無人認領的貴重物品歸拾得者或都道府縣 | 《遺失物法》 |

- **東京警視廳**在 **2023 年**受理了約 **410 萬件拾得物申報（440 萬件物品）**，較前一年增加 19%；**送交的現金達到創紀錄的 44 億日圓**，其中約**四分之三歸還了失主**。
- **《遺失物法》（2007 年修訂）**要求拾得者盡速送交物品，建立了警察資料庫，並允許儘快處置易腐品和低價值物品；拾得者的報酬權和可保留無人認領物品的選項是誘因。
- **電車**：在電車上發現的物品會在**終點站**取下，保管在該站或該路線的失物招領處；**記住搭乘的列車、車廂和時間**能加快查找。
- **計程車**：收據上有**公司名稱和車輛編號**；直接聯絡該公司。

> **[待核實]** 東京的數據請核對東京警視廳的年度遺失物統計；保管期請核對《遺失物法》。

## 誤解1｜皮夾掉了就沒了

**大多數都會被送交。** 當天先向現場詢問，再去警察中心。現金往往原封不動地歸還。

## 誤解2｜直接去警察局

**先找現場**——物品會在車站或商店停留幾天後才移交。警察中心是第二站，而**線上查詢**可以省下一趟。

## 誤解3｜失物招領櫃檯沒人聽得懂你說話

**主要車站和機場有英語服務**（東京地下鐵飯田橋失物中心可處理英語、中文和韓語）；**東京警方中心的電話專線只有日語**，請準備翻譯 App 或會日語的人。手機裡存一張**遺失物的照片**幫助極大。

## 誤解4｜應該給一筆可觀的酬金

**5–20% 是法定權利**；**大多數拾得者會拒絕**。禮貌地致謝是應有的；堅持給酬金反而可能讓對方尷尬。

## 誤解5｜手機掉了只能買新的

**手機是歸還率最高的物品之一。** 定位它、聯絡現場、等一天——它很可能就在某個車站辦公室或派出所裡。
