# Q. 关于在日本购买电子产品和相机，人们常有哪些误解？｜Japan Questions #446

- Shelf: `inbound` ／ URL: `/zh-cn/questions/buying-electronics-and-cameras` ／ Status: **草稿 — 出处未核实**

秋叶原和各大电器连锁店出现在很多人的行程里，而大家普遍以为日本的电子产品在日本买更便宜。有时确实如此；但更多时候，优势在于品类齐全、免税和海外版机型——而陷阱则是电压、保修和语言。

## A. 常见的误解是：电子产品在日本一定更便宜。相机和镜头在免税（省去10%）之后价格往往有竞争力，也有日本限定机型，但很多手机和笔记本电脑价格持平甚至更贵，而且国内版机型可能只有日文菜单、日文键盘和100 V插头。请确认机型是国际版、确认保修覆盖您的国家，并凭护照到免税柜台办理。

## 需要确认的事项

| 项目 | 详情 |
|---|---|
| **免税** | 单笔超过¥5,000的商品**免除10%消费税**（至2026年10月31日）；**自2026年11月1日起，需在收银台先付税款，离境时海关查验商品后再退税**，一般商品／消耗品的区分和¥500,000上限也将取消（参见免税篇）。大型连锁店设有专门柜台 |
| **价格** | **相机、镜头、部分音响和游戏产品**往往性价比不错；**手机、笔记本电脑、平板电脑**通常**不比**美国／欧盟便宜。请先在网上比价 |
| **机型版本** | **国内版（国内モデル）**可能**只有日文菜单、日文键盘（JIS布局）、仅支持100 V的充电器、没有英文说明书，以及日本特有的功能**（例如日本市场手机的快门声无法关闭）。请询问**「海外版」（海外モデル）**，或在店内确认包装盒上标注的菜单语言 |
| **保修** | **厂商保修往往仅限日本国内**；部分品牌提供**国际保修**（请查看保修卡）。零售商的延长保修仅限日本 |
| **电压／插头** | **日本为100 V、A型插头**（参见插头篇）。标注100–240 V的充电器在国外可用；**电吹风、电热水壶和部分家电仅支持100 V** |
| **频段** | 手机：请核对您所在国家的**LTE/5G频段**；日本市场的手机可能缺少部分频段 |
| **区域锁** | **蓝光／DVD区码**（日本为A区／2区）；游戏机如今大多不锁区，但**软件可能只有日文** |
| **行李中的电池** | **锂电池只能随身携带**，备用电池须做好防短路保护；**超过160 Wh的移动电源**禁止携带，100–160 Wh限带两个且需航空公司许可；自2025年7月起，日本往返航班上的移动电源须随身保管（不得放入头顶行李架） |
| **二手** | **新宿／银座的相机店对二手器材分级严格**（A/B/C）；价格不议价，但品质可靠；**秋叶原的二手电脑配件**亦然 |

- 大型连锁店的**积分制度（10%「积分」）在大多数情况下游客无法使用**，但免税可以；**有些店铺可将游客优惠券（5–7%）与免税叠加**——不妨问一问。
- **日本的快门声**：**国内版手机会强制开启相机快门声**（运营商的惯例）；海外版则没有。
- **回国时的关税**：回国时适用**您所在国家的免税额度**（参见海关篇）；一台¥300,000的相机可能需要缴纳关税。

> **[待核实]** 免税流程请向国税厅（国税庁）确认；电池规定请向您的航空公司确认；具体机型细节请向厂商确认。

## 误解1｜秋叶原什么都更便宜

**相机和镜头往往如此；手机和笔记本电脑很少。** 出发前先在网上比价；**免税加游客优惠券**才是省钱之处。

## 误解2｜什么机型回国都能用

**国内版机型可能只有日文菜单和键盘、仅支持100 V，或缺少您需要的LTE频段。** 请询问海外版，或确认语言设置。

## 误解3｜保修是全球通用的

**往往仅限日本。** 请确认是否附有国际保修卡；否则出了故障就得寄回日本。

## 误解4｜日本手机和国际版一样

**国内版手机可能有强制快门声、运营商预装软件和不同的频段。** 请购买**无锁（SIM-free）海外版**，或核对规格。

## 误解5｜二手电子产品风险大

**日本的二手相机店和电脑配件店分级、检测严格**，并提供短期保修；价格不议价，但成色可靠。这正是在日本购物的较好理由之一。
