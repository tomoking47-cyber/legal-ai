# Q. 關於在日本購買電子產品和相機，大家常有哪些誤解？｜Japan Questions #446

- Shelf: `inbound` ／ URL: `/zh-tw/questions/buying-electronics-and-cameras` ／ Status: **草稿 — 出處未核實**

秋葉原和各大電器連鎖店出現在很多人的行程裡，而大家普遍以為日本的電子產品在日本買比較便宜。有時確實如此；但更多時候，優勢在於品項齊全、免稅和海外版機型——而陷阱則是電壓、保固和語言。

## A. 常見的誤解是：電子產品在日本一定比較便宜。相機和鏡頭在免稅（省下10%）之後價格往往有競爭力，也有日本限定機型，但很多手機和筆電價格持平甚至更貴，而且國內版機型可能只有日文選單、日文鍵盤和100 V插頭。請確認機型是國際版、確認保固涵蓋您的國家，並持護照到免稅櫃檯辦理。

## 需要確認的事項

| 項目 | 詳情 |
|---|---|
| **免稅** | 單筆超過¥5,000的商品**免除10%消費稅**（至2026年10月31日）；**自2026年11月1日起，需在結帳時先付稅款，出境時海關查驗商品後再退稅**，一般商品／消耗品的區分和¥500,000上限也將取消（參見免稅篇）。大型連鎖店設有專門櫃檯 |
| **價格** | **相機、鏡頭、部分音響和遊戲產品**往往划算；**手機、筆電、平板**通常**不比**美國／歐盟便宜。請先上網比價 |
| **機型版本** | **國內版（国内モデル）**可能**只有日文選單、日文鍵盤（JIS配置）、僅支援100 V的充電器、沒有英文說明書，以及日本特有的功能**（例如日本市場手機的快門聲無法關閉）。請詢問**「海外版」（海外モデル）**，或在店內確認包裝盒上標示的選單語言 |
| **保固** | **原廠保固往往僅限日本國內**；部分品牌提供**國際保固**（請查看保固卡）。零售商的延長保固僅限日本 |
| **電壓／插頭** | **日本為100 V、A型插頭**（參見插頭篇）。標示100–240 V的充電器在國外可用；**吹風機、快煮壺和部分家電僅支援100 V** |
| **頻段** | 手機：請核對您所在國家的**LTE/5G頻段**；日本市場的手機可能缺少部分頻段 |
| **區碼鎖** | **藍光／DVD區碼**（日本為A區／2區）；遊戲主機如今大多不鎖區，但**軟體可能只有日文** |
| **行李中的電池** | **鋰電池只能隨身攜帶**，備用電池須做好防短路保護；**超過160 Wh的行動電源**禁止攜帶，100–160 Wh限帶兩個且需航空公司許可；自2025年7月起，日本往返航班上的行動電源須隨身保管（不得放入頭頂置物櫃） |
| **二手** | **新宿／銀座的相機店對二手器材分級嚴格**（A/B/C）；價格不二價，但品質可靠；**秋葉原的二手電腦零組件**亦然 |

- 大型連鎖店的**點數制度（10%「點數」）在大多數情況下旅客無法使用**，但免稅可以；**有些店家可將旅客優惠券（5–7%）與免稅疊加**——不妨問一問。
- **日本的快門聲**：**國內版手機會強制開啟相機快門聲**（電信業者的慣例）；海外版則沒有。
- **回國時的關稅**：回國時適用**您所在國家的免稅額度**（參見海關篇）；一台¥300,000的相機可能需要繳納關稅。

> **[待核實]** 免稅流程請向國稅廳（国税庁）確認；電池規定請向您的航空公司確認；具體機型細節請向製造商確認。

## 誤解1｜秋葉原什麼都比較便宜

**相機和鏡頭往往如此；手機和筆電很少。** 出發前先上網比價；**免稅加旅客優惠券**才是省錢之處。

## 誤解2｜什麼機型回國都能用

**國內版機型可能只有日文選單和鍵盤、僅支援100 V，或缺少您需要的LTE頻段。** 請詢問海外版，或確認語言設定。

## 誤解3｜保固是全球通用的

**往往僅限日本。** 請確認是否附有國際保固卡；否則出了故障就得寄回日本。

## 誤解4｜日本手機和國際版一樣

**國內版手機可能有強制快門聲、電信業者預載軟體和不同的頻段。** 請購買**無鎖（SIM-free）海外版**，或核對規格。

## 誤解5｜二手電子產品風險大

**日本的二手相機店和電腦零組件店分級、檢測嚴格**，並提供短期保固；價格不二價，但成色可靠。這正是在日本購物的較好理由之一。
