# Q. 關於在日本購買伴手禮（お土産）和請店家包裝禮品，大家常有哪些誤解？｜Japan Questions #450

- Shelf: `inbound` ／ URL: `/zh-tw/questions/gift-wrapping-and-omiyage-etiquette-for-visitors` ／ Status: **草稿 — 出處未核實**

為同事和家人帶回可食用的紀念品——お土産（omiyage，伴手禮）——是一項日本習俗，旅客常常不知其規則便照做：獨立包裝、地方特色、裝盒，再由店家包裝一遍。百貨公司的包裝櫃檯是最後一個陌生的環節。

## A. 常見的誤解是：お土産是買給自己的紀念品。お土産是「一個地方的禮物」——裝在盒子裡的獨立包裝地方點心，送給留在家裡的人——整個零售體系都圍繞它組織：6、8、10或12入的盒子、兩週以上的保存期限、每位收禮人一個紙袋，以及免費包裝。對旅客來說，它也是最不易碎、最容易被接受的帶回家的禮物。

## お土産是怎麼運作的

| 要素 | 詳情 |
|---|---|
| **是什麼** | **獨立包裝、裝盒的地方點心或零食**（如東京香蕉 Tokyo Banana、博多通りもん、白色戀人、京都八橋）；也有地方醬菜、茶、清酒 |
| **在哪買** | **車站和機場的伴手禮店**、百貨公司的食品樓層、目的地的店家；出發地附近的車站有本地區的全部品項 |
| **盒裝數量** | **6、8、10、12、16入**——按辦公室人數選擇；正式送禮**避開4和9**（與「死」「苦」諧音） |
| **保存期限** | **盒裝伴手禮通常可保存1–4週**——請核對日期，因為有些名品（如東京香蕉，約一週）期限短；**生點心（生菓子）不適合攜帶**（參見和菓子篇） |
| **包裝** | **百貨公司和許多店家免費**；說**「プレゼントで」（purezento de，作為禮物）**或**「お土産で」（omiyage de）**；正式場合可要求**「のし」紙** |
| **提袋** | 店家會提供**每位收禮人一個紙袋**；可要求「小袋」（kobukuro）——日本人會連店家的袋子一起送出 |
| **價格標準** | 送同事**每盒¥1,000–3,000**；送寄宿家庭¥3,000–5,000 |
| **帶回國** | **密封點心幾乎在任何地方都沒問題**；**肉製品、新鮮水果、乳製品**受限（參見帶食品回國篇）；超過¥5,000可**免稅**（消耗品須密封在免稅袋中，至2026年10月31日；自2026年11月1日起改為出境時退稅，密封袋規定終止） |

- 伴手禮市場估計**每年超過¥1兆**；僅東京的車站店家每天就售出數千盒。這一習俗起源於**江戶時代的朝聖者帶回參拜神社的憑證**。
- **獨立包裝**是關鍵：盒子**在辦公室打開，每人分一個**；一袋散裝餅乾行不通。
- **包裝禮儀**：店家**用自家的包裝紙**包裝（出處很重要）；**不要用自己的紙重新包裝**；喜慶且可重複的場合用**可重新繫結蝴蝶結的「のし」**（參見禮品篇）。
- **不要送**：**刀具、梳子、四個一組的東西**，探病不要送**盆栽**。點心是安全之選。

> **[待核實]** 市場規模估算為業界數據；海關規定請向目的地確認。

## 誤解1｜お土産是買給自己的紀念品

**它是送給他人的禮物**——同事、家人、鄰居——來自您到訪的地方。也可以買給自己，但盒子不是為此而設計的。

## 誤解2｜一大袋同一種餅乾最划算

**收禮人的辦公室期待的是裝在盒子裡的獨立包裝**；散裝或大包裝無法分發。

## 誤解3｜包裝要額外收費

**百貨公司和大多數店家免費**；說明是送禮，並要求每位收禮人一個小袋。

## 誤解4｜一盒裝幾個都行

送一般同事，可以。**正式送禮要避開4和9**；6、8、10、12入的盒子正因此而存在。

## 誤解5｜看到第一家店就買

**出發的車站或機場有本地區的全部品項**，價格相同；在離開時購買，免得在包包裡被壓一週。**對照您的行程日期核對保存期限。**
