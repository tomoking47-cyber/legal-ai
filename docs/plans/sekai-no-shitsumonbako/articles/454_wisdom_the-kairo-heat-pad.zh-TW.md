# Q. 關於暖暖包（カイロ，拋棄式暖暖包），大家常有哪些誤解？｜Japanese Everyday Wisdom #454

- Shelf: `wisdom` ／ URL: `/zh-tw/wisdom/the-kairo-heat-pad` ／ Status: **草稿 — 出處未核實**

日本一個冬天大約用掉15億片拋棄式暖暖包。每家便利商店、每個通勤族的口袋、每個書包裡都有它，而它上面印的燙傷警語，大多數使用者從沒讀過。它是什麼、放在哪裡，以及兩條安全規則，就說完了。

## A. 常見的誤解是以為暖暖包（カイロ）「只是溫的，不是熱的」，所以無害。暖暖包峰值可達50–60°C，並在8–20小時內維持40–50°C——正是低溫燙傷的溫度區間——所以兩條規則是：絕不直接貼皮膚，絕不在睡覺時使用。用對了（貼在外層、腰部、腹部或肩胛骨之間），它能溫暖全身，是最便宜的取暖方式。

## 產品本身

| 項目 | 細節 |
|---|---|
| 原理 | **鐵粉與空氣接觸氧化**，食鹽作催化劑，蛭石和活性碳用來保持水分與空氣；封在透氧的袋子裡 |
| 溫度 | **平均50–55°C，峰值可達60–65°C**，持續**8–20小時**，視類型而定（標籤上兩者都有標示） |
| 類型 | **貼式（貼る）**貼在衣服上；**手握式（貼らない）**放口袋；**鞋用（くつ用）**，溫度較低；**蒸氣眼罩與頸部型**（原理不同） |
| 貼在哪裡（貼式） | **最內層衣物的外側**——腰部、腹部、兩肩胛骨之間或腎臟部位；**「三個頸」（頸、手腕、腳踝）加腰部**可溫暖核心 |
| 絕不 | **直接貼皮膚**；**睡覺時使用**；**用在嬰兒、感覺遲鈍的長者、糖尿病／血液循環有問題的人身上而不加留意**；**受壓時（腰帶下、坐在上面）**；**與其他熱源同時用**（被爐、電熱毯） |
| 丟棄 | **冷卻後，依市町村規定丟入一般垃圾（可燃或不可燃）**；內容物是鐵——有些市町村另行回收 |
| 重複使用 | **不能重複使用**；封進塑膠袋只能暫停，不能重置 |

- 消費者廳每年冬天都會接到暖暖包造成的**低溫燙傷**通報；典型案例包括**貼著睡覺、隔著襪子直接貼在皮膚上、長者使用者**。時間－溫度表（44°C≈3–4小時；46°C≈30–60分鐘）同樣適用（見熱水袋一文）。
- 暖暖包是日本發明的（**1978年，樂天「Hokkairo」**），至今仍是日本的外銷商品；**鞋用型**溫度較低（約40°C），因為腳部空氣流通較少。
- **成本**：**每片¥30–60**；整個冬天每天用，大約¥3,000–5,000——比任何電暖器都便宜，而且隨身攜帶。

> **[待核實]** 溫度與持續時間數字請向產品標籤及日本衛生材料工業聯合會核實；燙傷警示請向消費者廳核實。

## 誤解1｜只是溫的，所以不會燙傷

**50–60°C持續數小時，正是低溫燙傷的區間。** 暖暖包讓人覺得舒服的同時，正在傷害皮膚。

## 誤解2｜貼在皮膚上效果更好

**貼在內層衣物的外側**，絕不貼皮膚。用在襪子上時，貼襪子外側——不要貼著腳。

## 誤解3｜帶著它睡一個暖和的夜

**這是最常見的嚴重燙傷情境。** 睡前取下；改用寢具和（睡前拿走的）熱水袋。

## 誤解4｜手腳是最佳位置

**溫暖核心——腰、腹、肩胛骨——能間接、更安全地溫暖手腳。** 鞋用型正因此做成低溫類型。

## 誤解5｜它只是個小玩意

**一年15億片**，在書包裡，在建築工地上；世上最便宜的隨身熱源。用得尊重，它是日本冬季裝備中最好的東西之一。
