# Q. 關於急須（日本茶壺）與日常茶具，大家常有哪些誤解？｜Japanese Everyday Wisdom #455

- Shelf: `wisdom` ／ URL: `/zh-tw/wisdom/the-kyuusu-teapot-and-tea-tools` ／ Status: **草稿 — 出處未核實**

這種側把、自帶濾網的茶壺是日本廚房裡的主力工具，而遊客卻把它當成禮儀性的器物。它是為一件具體的事而設計的實用器具——快速、反覆地沖泡散裝綠茶，而且不必另外準備濾網——並且伴隨著幾個使用習慣。

## A. 常見的誤解是以為喝日本茶需要茶道那一整套器具。日常喝茶需要的是急須（一把帶側把與細濾網的小壺）、一種把水降到70–80°C的方法，以及小茶杯；側把是為了一隻手倒茶、另一隻手按住壺蓋，而容量小（200–360毫升）是因為綠茶要短時間、多次沖泡。清潔的規矩比沖泡的規矩更重要：絕不要把濕茶葉留在壺裡。

## 茶具

| 器具 | 是什麼 | 為什麼 |
|---|---|---|
| **急須（急須）** | 側把壺，**200–360毫升**，壺嘴處**自帶金屬網或陶製濾網**，或配可取出的濾籃 | 小，是因為煎茶要**沖泡2–3次、每次時間短**；側把讓你一隻手倒茶並按住壺蓋；有濾網就不必另外準備工具 |
| **湯冷（湯冷まし）** | 一個小的敞口分茶器 | 把沸水倒進去可**降溫約10°C**；再倒一次又降一次——這是不用溫度計就能達到70–80°C的標準做法 |
| **茶碗／湯吞（湯呑）** | 小杯子，**80–150毫升** | 茶是小口喝的，輪流循環著倒，好讓每一杯濃淡一致 |
| **茶筒** | 密封茶葉罐 | 茶葉一旦開封，幾週內就會氧化（參見綠茶那篇文章） |
| **土瓶／寶瓶（宝瓶）** | 提梁在上方的大壺；寶瓶沒有把手（用於已放涼的水） | 家庭用量或玉露 |
| **鐵瓶** | 鑄鐵煮水壺 | 用來煮水，**不用來泡茶**（與國外販售的琺瑯「鐵茶壺」不同） |
| 材質 | **常滑燒（紅泥）**、**萬古燒（紫泥）**、瓷器（有田、波佐見） | 據說陶土能讓茶湯變得柔和；瓷器則中性，也最容易清洗 |

- **沖泡**：放入茶葉（**每人2–3公克**），倒入降溫後的水，**60–90秒**，輪流倒入各杯並**倒到最後一滴**；第二泡水溫略高、時間更短。兩泡之間絕不要讓茶葉泡在水裡。
- **清潔**：**最後一泡後倒掉茶葉，只用清水沖洗，開蓋倒扣晾乾**。不使用清潔劑（陶土會吸附氣味）；濾網堵塞時**用刷子刷洗**。留著濕茶葉過夜的壺會發臭並長黴。
- **常滑**（愛知縣）生產了日本大部分的急須；手工製作的一把要**¥3,000–20,000**，一般的一把**¥1,000**。

> **[待核實]** 沖泡參數請向日本茶業中央會核實；產地細節請向常滑燒的同業團體核實。

## 誤解1｜一定要有一整套茶道器具

**抹茶需要茶筅與茶碗；葉茶需要急須與茶杯。** 茶道是另一回事。

## 誤解2｜壺越大，茶越多

**小是刻意的**：第二泡與第三泡本身就是這杯茶的一部分。大壺會泡過頭。

## 誤解3｜用清潔劑洗壺

**只用清水沖洗後晾乾**；陶土會留住清潔劑的氣味。濾網用刷子清理。

## 誤解4｜國外賣的鐵茶壺是日本茶具

**鐵瓶是煮水壺**；在沒有琺瑯內襯的鐵器裡泡茶會毀了茶。琺瑯「鐵茶壺」是外銷商品，不是日本家庭的用品。

## 誤解5｜把茶葉留著下一杯用可以省事

**這會把茶悶壞，還會長黴。** 泡好、徹底倒淨，然後要麼盡快再泡，要麼把壺清空。
