# Q. 關於日本住家的紗窗（網戸・amido），大家常有哪些誤解？｜Japanese Everyday Wisdom #456

- Shelf: `wisdom` ／ URL: `/zh-tw/wisdom/window-screens-amido` ／ Status: **草稿 — 出處未核實**

日本的每一扇窗和陽台門都配有橫拉式防蟲紗窗，居民從 5 月到 10 月理所當然地使用它。來自沒有紗窗的國家的旅客根本不會注意到它；來自使用固定式紗窗的國家的旅客則不知道它可以滑動、可以拆下，而且需要清洗。

## A. 常見的誤解是認為紗窗是窗戶上固定不動的部件。日本的紗窗（網戸）在自己的軌道上滑動，可以提起取下清洗，也正是它讓窗戶在蚊子季節可以保持敞開。相關習慣：只要開窗就把紗窗關好；把紗窗對準窗戶正確的那一半，讓窗框處不留縫隙；春秋各清洗一次；紗網破了就自己換（約 ¥1,000 的 DIY 工作）。

## 紗窗是怎麼運作的

| 項目 | 說明 |
|---|---|
| 位置 | **在最外側的軌道上滑動**；一次只遮住窗口的**一半**。**只開紗窗所遮那一側的窗扇**；若開另一側，中央窗框處就會出現縫隙 |
| 拆卸 | **把紗窗向上提起，再把底部向外擺出**（有些在頂部有釋放卡榫）。請選無風的日子操作；紗窗會從陽台掉落 |
| 清洗 | **春季和秋季**：用水管或蓮蓬頭沖洗，軟刷，溫和清潔劑，裝回前晾乾。不拆下時：**兩塊海綿（兩面各一塊）或紗窗滾刷**；灰塵和花粉可用**帶刷頭的吸塵器**吸除 |
| 紗網 | **灰色或黑色聚丙烯，18–24 目**；**黑色透視更清楚**，灰色反射更多陽光；**更細的（24–30 目）能擋住小蟲和部分花粉** |
| 更換 | **紗網、壓條膠繩和滾輪工具：約 ¥1,000–1,500**，任何居家修繕中心（home center）都有；30 分鐘；**租屋友善**（不會損壞窗框） |
| 寵物 | 有**防寵物紗網**（更厚）和**紗窗鎖**；貓會把紗窗頂出去 |
| 陽台門 | 若門沒有內建紗窗，可用**磁吸紗門簾** |

- **蚊子季節**為 **5–10 月**；2014 年東京的登革熱傳播（約 160 例，代代木公園）使紗窗和清除積水成為公共衛生建議（見蟲害一文）。
- 紗窗也能擋住夏天飛進來的**較大的蟑螂和飛蛾**，並讓家庭在溫和的夜晚**不開冷氣也能通風**（見通風一文）。
- **中央窗框處的縫隙**——紗窗在左邊、窗戶卻開在右邊——是一戶人家「裝了紗窗卻還是有蚊子」最常見的原因。

> **[待核實]** 2014 年登革熱疫情以厚生勞動省資料為準；紗網規格以製造商資料為準。

## 誤解1｜紗窗是固定的，不用管

**它可以滑動、可以提起取下，而且每年需要清洗兩次。** 到 6 月，花粉和都市灰塵就會把它堵住。

## 誤解2｜想開窗戶哪一半都行

**開紗窗所遮的那一半。** 否則兩扇窗之間的窗框會留下一道蚊子大小的縫隙——這是最典型的錯誤。

## 誤解3｜紗窗破了就得找房東

**重新換紗網是一項約 ¥1,000 的 DIY 工作**，用滾輪工具即可；房東通常期望租客自己處理，居家修繕中心就在紗網旁邊賣整套工具。

## 誤解4｜灰色紗網是標配，所以最好

**黑色紗網的透視效果明顯更好**；灰色隔熱略強一點。依房間用途選擇。

## 誤解5｜紗窗只是為了防蚊

**正是紗窗讓日本住家在潮濕的月份裡既能通風又不進蟲**——這是其他文章中所述通風與防霉習慣的前提。
