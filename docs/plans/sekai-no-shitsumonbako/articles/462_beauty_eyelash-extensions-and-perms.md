# Q. まつ毛エクステやまつ毛パーマは、目に悪くない？｜世界の質問箱 #462

- 棚：`beauty` ／ URL：`/questions/eyelash-extensions-and-perms` ／ ステータス：**ドラフト（法務レビュー前・出典未検証）**

目元を大きく見せるまつ毛エクステ（エクステンション）とまつ毛パーマ。日本では施術に美容師免許が必要で、目のトラブル相談も一定数寄せられています。安全に受けるための確認点を整理します。

## A. 受ける前に確認すべきことは3つ。①施術者が美容師免許を持つ店か（法律上、まつ毛エクステは美容師の業務）、②グルー（接着剤）やパーマ液のパッチテストをしてくれるか、③施術後に目の赤み・かゆみ・腫れが出たら、店ではなくまず眼科へ。まつ毛パーマ用として国に承認された薬剤は存在しない点も知っておくべきです。

## 知っておきたい数値と制度

| 項目 | 内容 |
|---|---|
| **資格** | まつ毛エクステンションは**美容師法上の「美容」**にあたり、**美容師免許が必要**（厚生労働省通知、2008年） |
| **危害相談** | 国民生活センターには**まつ毛エクステによる危害情報が5年間で599件**（2010〜2014年度、2015年公表）。目の痛み・充血・腫れ・かゆみが中心 |
| **接着剤** | 多くは**シアノアクリレート系**。硬化時の揮発成分が目にしみることがあり、まぶたの皮膚のかぶれ（接触皮膚炎）の報告がある |
| **まつ毛パーマ液** | **頭髪用以外の用途で承認された医薬部外品のパーマネント・ウェーブ用剤はなく**（承認基準は頭髪用に限定／薬生発0628第10号、令和3年6月28日）、市販のまつ毛カール剤は「化粧品」として流通。システアミン塩酸塩配合品は2024年3月末以降、取扱いが変更されました |
| **持続期間** | エクステ：**3〜4週間**で自まつ毛の生え替わりとともに脱落。パーマ：**1〜2か月** |
| **自まつ毛の周期** | 生え替わりの周期は**約3〜5か月**、長さは平均**6〜8mm**程度 |

- **パッチテストの依頼**：初めての店・初めての接着剤では、腕の内側などに少量を付けて**48時間**様子を見る方法があります。断られる店は避けるのが賢明です。
- **施術中は目を閉じ続ける**：目を開けると接着剤の揮発成分が角膜に触れ、痛みや充血の原因になります。
- **装着後24時間は水にぬれないよう**にとされる製品が多く、**オイルクレンジングは接着剤を溶かす**ため、目元はオイルフリーの製品で。
- **自分でエクステを付ける・外す**のは危険です。外す際はリムーバーを使う施術者に任せてください。
- **異常が出たら**：赤み・痛み・目やに・まぶたの腫れが続く場合は**眼科**へ。まぶたの皮膚のかぶれは**皮膚科**へ。店に戻る前に受診が先です。

> **【要検証】** 危害情報の件数（599件／5年間）、まつ毛の周期・長さの数値は出典資料の年版により変わります。公開前に最新の統計で確認してください。

## 誤解1｜エステサロンや自宅サロンでも受けられる

**施術者に美容師免許が必要です。** 無資格施術はトラブルが起きても対応が十分でないことが多く、行政も無資格営業に注意喚起をしています。店に美容所の届出・美容師免許の掲示があるかを見てください。

## 誤解2｜「低刺激グルー」なら安全

**「低刺激」は法律上の定義がある表示ではありません。** シアノアクリレート系は程度の差こそあれ揮発成分を含み、体質によりかぶれます。パッチテストが唯一の確認手段です。

## 誤解3｜まつ毛パーマは液を目に入れないから大丈夫

**医薬部外品として承認されたまつ毛用のパーマ剤は存在せず**、市販のまつ毛カール剤は「化粧品」の扱いです。頭髪用薬剤の流用には国が注意を促してきました。まぶたの皮膚は薄く、液の付着で皮膚炎や結膜炎の相談が寄せられています。

## 誤解4｜取れかけたエクステは自分で引っぱって外す

**自まつ毛ごと抜けます。** まつ毛の毛根を繰り返し傷めると、生えてくるまつ毛が細く短くなることがあります。リムーバーでの除去を。

## 誤解5｜目が赤くても数日で治まるから様子見でいい

**痛み・目やに・視界のかすみが伴うなら、その日のうちに眼科へ。** 角膜の傷は放置すると悪化することがあります。「様子見」は軽いかゆみだけの場合に限ります。
