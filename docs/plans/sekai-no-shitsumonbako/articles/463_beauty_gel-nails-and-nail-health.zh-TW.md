# Q. 一直做光療指甲，自己的指甲會變薄嗎？｜Japan Questions #463

- Shelf: `beauty` ／ URL: `/zh-tw/beauty/gel-nails-and-nail-health` ／ Status: **草稿 — 出處未核實**

光療指甲，也就是「ジェルネイル」(jeru neiru，凝膠美甲)，在日本非常流行：可以維持 3–4 週，顏色也不容易變暗。但持續有人反映「指甲變薄了」或「起疹子了」。本文從指甲的構造講起，說明想長期做光療時該怎麼讓指甲休息。

## A. 凝膠本身不會溶解指甲。指甲變薄的主因是每次補做時打磨過度，以及硬把凝膠撕下來。請選擇把打磨（磨甲面）控制到最少的店家，絕對不要自己把凝膠剝掉。每 3–4 個月讓指甲休息 2–4 週。如果縫隙進水、指甲變綠，請停下來去看皮膚科。一旦對凝膠成分（丙烯酸酯類）過敏，之後很難再做光療，所以不要對搔癢或腫脹掉以輕心。

## 指甲與凝膠的基本數字

| 項目 | 參考值 |
|---|---|
| **手指甲的生長速度** | **一天約 0.1mm，一個月約 3mm。** 從甲根到甲尖全部換新需要**約 6 個月** |
| **健康指甲的厚度** | **約 0.3–0.5mm。** 打磨過度而變薄的話，指甲會彎曲，可能會痛 |
| **補做的間隔** | **3–4 週。** 放得更久，水會從甲根處的縫隙滲進去 |
| **卸除方法** | 用丙酮（去光水的成分）浸泡 **10–15 分鐘**，再輕輕掀起。硬撕會連甲板（指甲堅硬的表層）一層層剝下來 |
| **燈** | UV 燈或 LED 燈。固化時間依產品而異為 **30–60 秒**。有些人會用防曬或手套保護手背 |
| **休息期** | 做了 3–4 個月光療之後，休息 **2–4 週**是實際的做法 |

- **綠指甲**：凝膠與指甲之間出現縫隙時，水和綠膿桿菌（*Pseudomonas*）會進入，指甲變綠。日本國民生活中心收到過這類申訴。**看到變色，請卸掉凝膠並去皮膚科**（皮膚科，hifuka——日本健康保險適用）。絕對不要蓋上去繼續塗。
- **丙烯酸酯過敏**：由凝膠主要成分（如 HEMA）引起的接觸性皮膚炎，不只出現在指尖，也可能出現在**眼瞼與脖子**。一旦致敏，有些人對牙科材料與醫療膠帶也會起反應；日本皮膚科學會曾就此提出警示。
- **在家做光療**：如果未固化的凝膠留在皮膚上就開燈，致敏風險會升高。鐵則是**固化前把沾到皮膚上的凝膠擦掉**。
- **打磨過度的訊號**：指甲發白且會彎、按壓會痛，或甲尖看起來薄而透明。只要符合其中一項，就該休息了。

> **[待核實]** 指甲生長速度、厚度與固化時間的數字都是一般參考值。請確認日本國民生活中心關於光療指甲危害資訊的公布年份與件數，並反映到文中。

## 誤解1｜凝膠會溶解指甲，讓指甲變薄

**變薄的主因是打磨過度與硬撕卸除。** 凝膠本身不會溶解指甲。選擇使用「免打磨」（non-sanding）底膠的店家，或盡量少打磨的美甲師，會有幫助。

## 誤解2｜一開始翹邊就可以用指甲摳掉

**甲板的表層會跟著一起被剝下來。** 反覆如此，指甲會明顯變薄。請用丙酮卸除，或到店裡處理。

## 誤解3｜指甲要呼吸，一直不讓它休息就會「死掉」

**指甲不會呼吸**（它靠甲根的血液供應獲得養分）。休息的意義在於讓被打磨過的部分有時間長出來，也讓你有機會發現皮膚或指甲的問題。

## 誤解4｜我只是對某個牌子過敏，換個牌子就沒事

**丙烯酸酯類成分是大多數凝膠共通的**，所以一旦出現過敏，往往對其他廠商的產品也會起反應。請先讓皮膚科醫師確定是哪種成分引起的。

## 誤解5｜變綠了可以再塗一層蓋住

**那會把細菌封在裡面，讓情況更糟。** 綠指甲的第一步是卸掉凝膠並保持指甲乾燥。之後請到皮膚科接受診治。
