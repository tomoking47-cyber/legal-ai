# Q. 喝胶原蛋白对皮肤好，这是真的吗？｜Japan Questions #470

- Shelf: `beauty` ／ URL: `/zh-cn/beauty/collagen-supplements-and-skin` ／ Status: **草稿 — 出处未核实**

胶原蛋白饮料、粉末和果冻在日本是随处可见的「美容食品」——任何一家便利店（konbini）都买得到。有人说「反正会被消化掉，没有意义」，也有人说「我的皮肤变紧致了」。本文从日本食品标示制度和研究两方面，来看哪一种说法站得住脚。

## A. 口服的胶原蛋白会被分解为氨基酸和小分子肽，所以并不存在「喝下去的胶原蛋白直接变成你的皮肤」这回事。不过，确实有一部分肽会进入血液，也有临床试验和荟萃分析报告称皮肤含水量与弹性的指标有所改善，因此也不能一句「没有意义」就打发。在日本，部分产品以「有助于维持皮肤弹性」这类措辞注册为机能性表示食品，这就是现行制度所允许的上限。「斑点消失」「返老还童」之类的宣称，对食品是不被允许的。

## 目前的制度与研究

| 项目 | 内容 |
|---|---|
| **法律定位** | 胶原蛋白是**食品**。类似药品的措辞，即声称让某种症状消失或「改善」它，是不被允许的 |
| **机能性表示食品（機能性表示食品）** | 部分产品由厂商自负其责**向消费者厅申报**，标示「有助于维持皮肤弹性」「有助于保持皮肤水分」等内容。**国家并未审查或批准其效果** |
| **研究现状** | 汇总口服胶原蛋白肽临床试验的荟萃分析（如2023年对26项试验、1,721人的分析，更新的还有2025年的报告）报告称，**皮肤含水量与弹性有所改善**。同时也指出局限：试验规模小，且多由厂商出资 |
| **研究中常用的量** | 每天 **2.5～10 克**，持续 **8～12 周** |
| **作为蛋白质的营养价值** | 胶原蛋白缺少一种必需氨基酸（色氨酸），因此是**不完全的蛋白质来源**。它无法取代日常饮食中的蛋白质（女性推荐摄入量：每天 50 克） |
| **安全性** | 一般认为是安全的，但也有**对鱼源或猪源产品过敏**的报告，以及少见的肠胃不适 |

- **国立健康・营养研究所的「健康食品」安全性・有效性信息数据库**同时列出了两类内容：一条写明关于口服胶原蛋白「未能找到充分可靠的人体有效性数据」，以及若干个别试验的报告。公立机构的立场是，**目前还无法断定它「有效」或「无效」**。
- **如何分辨产品**：如果包装上写有「機能性表示食品」（机能性表示食品）并标有申报编号（「届出番号」），就可以在消费者厅的数据库中查到其宣称内容与支持它的论文。没有机能性表示的产品，不得对皮肤作出任何宣称。
- **费用**：每天一瓶 **150～300 日元**的胶原蛋白饮料，一个月是 **4,500～9,000 日元**。把同样的预算花在防晒、保湿和睡眠上，对皮肤而言依据更为扎实。
- **从食物中摄取**：鸡翅、软骨、鱼皮和明胶富含胶原蛋白。**维生素C**是合成胶原蛋白所需的营养素，这一点证据明确。

## 误解1｜喝下去的胶原蛋白会变成皮肤里的胶原蛋白

**消化会把它分解为氨基酸和肽。** 研究所提示的是「部分肽有可能作用于皮肤细胞」，而不是它「变成了皮肤」。

## 误解2｜那喝了就毫无意义

**报告皮肤含水量与弹性指标有所改善的临床试验和荟萃分析确实存在。** 研究质量有其局限，但也没有依据断言它「毫无意义」。

## 误解3｜既然是机能性表示食品，就说明国家认可了它的效果

**机能性表示食品是由厂商自负其责的申报制度**，并不是由国家审查并批准效果的制度。（由国家审查的是「特定保健用食品」，即特保／tokuho。）

## 误解4｜喝得越多越有效

**研究中使用的量约为每天 2.5～10 克**，没有证据表明超过这个量效果会增加。有些产品还意味着摄入过多的热量与糖分。

## 误解5｜喝胶原蛋白能让斑点和皱纹消失

**这类宣称对食品是不被允许的，也没有证据支持。** 斑点和皱纹属于防晒与皮肤科的领域。
