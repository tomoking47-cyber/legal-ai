# Q. 喝膠原蛋白對皮膚好，這是真的嗎？｜Japan Questions #470

- Shelf: `beauty` ／ URL: `/zh-tw/beauty/collagen-supplements-and-skin` ／ Status: **草稿 — 出處未核實**

膠原蛋白飲、粉末與果凍在日本是隨處可見的「美容食品」——任何一家便利商店（konbini）都買得到。有人說「反正會被消化掉，沒有意義」，也有人說「我的皮膚變緊實了」。本文從日本食品標示制度與研究兩方面，來看哪一種說法站得住腳。

## A. 口服的膠原蛋白會被分解為胺基酸與小分子胜肽，所以並不存在「喝下去的膠原蛋白直接變成你的皮膚」這回事。不過，確實有一部分胜肽會進入血液，也有臨床試驗與統合分析報告指出皮膚含水量與彈性的指標有所改善，因此也不能一句「沒有意義」就打發。在日本，部分產品以「有助於維持皮膚彈性」這類措辭登錄為機能性標示食品，這就是現行制度所允許的上限。「斑點消失」「返老還童」之類的宣稱，對食品是不被允許的。

## 目前的制度與研究

| 項目 | 內容 |
|---|---|
| **法律定位** | 膠原蛋白是**食品**。類似藥品的措辭，也就是聲稱讓某種症狀消失或「改善」它，並不被允許 |
| **機能性標示食品（機能性表示食品）** | 部分產品由廠商自負其責**向消費者廳申報**，標示「有助於維持皮膚彈性」「有助於保持皮膚水分」等內容。**國家並未審查或核准其效果** |
| **研究現況** | 彙整口服膠原蛋白胜肽臨床試驗的統合分析（2019～2021年）指出，**皮膚含水量與彈性有所改善**。同時也點出侷限：試驗規模小，且多由廠商出資 |
| **研究中常用的量** | 每天 **2.5～10 公克**，持續 **8～12 週** |
| **作為蛋白質的營養價值** | 膠原蛋白缺少一種必需胺基酸（色胺酸），因此是**不完全的蛋白質來源**。它無法取代日常飲食中的蛋白質（女性建議攝取量：每天 50 公克） |
| **安全性** | 一般認為是安全的，但也有**對魚類或豬源產品過敏**的報告，以及少見的腸胃不適 |

- **國立健康・營養研究所的「健康食品」安全性・有效性資訊資料庫**同時並列了兩類內容：一則寫明關於口服膠原蛋白「找不到充分可靠的人體有效性資料」，以及若干個別試驗的報告。公家機構的立場是，**目前還無法斷定它「有效」或「無效」**。
- **如何分辨產品**：如果包裝上寫有「機能性表示食品」（機能性標示食品）並標有申報編號（「届出番号」），就可以在消費者廳的資料庫中查到其宣稱內容與支持它的論文。沒有機能性標示的產品，不得對皮膚做出任何宣稱。
- **費用**：每天一瓶 **150～300 日圓**的膠原蛋白飲，一個月是 **4,500～9,000 日圓**。把同樣的預算花在防曬、保濕與睡眠上，對皮膚而言依據更為扎實。
- **從食物中攝取**：雞翅、軟骨、魚皮與明膠富含膠原蛋白。**維生素C**是合成膠原蛋白所需的營養素，這一點證據明確。

> **[待核實]** 請核實統合分析的最新發表年份與受試人數，以及機能性標示食品申報的現行內容。國立健康・營養研究所的條目會更新，請引用發布時點的敘述。

## 誤解1｜喝下去的膠原蛋白會變成皮膚裡的膠原蛋白

**消化會把它分解為胺基酸與胜肽。** 研究所提示的是「部分胜肽有可能作用於皮膚細胞」，而不是它「變成了皮膚」。

## 誤解2｜那喝了就毫無意義

**報告皮膚含水量與彈性指標有所改善的臨床試驗與統合分析確實存在。** 研究品質有其侷限，但也沒有依據斷言它「毫無意義」。

## 誤解3｜既然是機能性標示食品，就代表國家認可了它的效果

**機能性標示食品是由廠商自負其責的申報制度**，並不是由國家審查並核准效果的制度。（由國家審查的是「特定保健用食品」，即特保／tokuho。）

## 誤解4｜喝得越多越有效

**研究中使用的量約為每天 2.5～10 公克**，沒有證據顯示超過這個量效果會增加。有些產品還意味著攝取過多的熱量與糖分。

## 誤解5｜喝膠原蛋白能讓斑點與皺紋消失

**這類宣稱對食品並不被允許，也沒有證據支持。** 斑點與皺紋屬於防曬與皮膚科的領域。
