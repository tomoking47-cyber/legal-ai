# Q. 真珠のネックレスは、どう手入れして保管すればいい？｜世界の質問箱 #471

- 棚：`fashion` ／ URL：`/questions/pearl-care` ／ ステータス：**ドラフト（法務レビュー前・出典未検証）**

冠婚葬祭で必ず出番がある真珠のネックレス。日本では母から娘へ受け継がれることも多い品ですが、真珠は宝石の中でもとくにデリケートで、「しまい方」を間違えると数年で光沢が落ちます。

## A. 使ったその日に、柔らかい乾いた布で汗と化粧品を拭き取ってから、他の宝石と触れないように別にしてしまう。これだけで光沢の寿命は大きく変わります。真珠は主成分が炭酸カルシウムで硬度が低く（モース硬度2.5〜4.5）、酸・汗・香水・ヘアスプレーに弱い。超音波洗浄機は使わない、糸は毎年使うなら1〜2年、たまに使うなら数年に一度は張り替え、乾燥し過ぎる場所（金庫の中の乾燥剤の隣など）も避けてください。

## 真珠の弱点と手入れの目安

| 項目 | 内容 |
|---|---|
| **成分・硬度** | 炭酸カルシウム（アラゴナイト）とたんぱく質（コンキオリン）の層。**モース硬度2.5〜4.5**（ダイヤモンド10、水晶7、指の爪が約2.5） |
| **弱いもの** | **酸（汗・果汁・酢）、香水、ヘアスプレー、化粧品、塩素（プール・漂白剤）、高温、極度の乾燥** |
| **使用後** | **柔らかい乾いた布で拭く**（メガネ拭き・専用クロス）。汚れが強ければ**ぬるま湯で軽く湿らせた布**で拭き、すぐ乾いた布で水気を取る |
| **禁止** | **超音波洗浄機、洗剤、アルコール、酸性の洗浄液、蒸気** |
| **糸の張り替え** | 毎日〜週1使うなら**1〜2年**、冠婚葬祭のみなら**3〜5年**。**珠と珠の間に隙間**が見える、糸が伸びて垂れる、変色したら替え時 |
| **保管** | **他の宝石と別に**、柔らかい布や専用ケースへ。**乾燥剤の隣・密閉容器に長期**は避ける（ひび割れの原因）。**直射日光・高温**を避ける |

- **付ける順番**：**身支度の最後に付け、帰宅したら最初に外す**。香水・ヘアスプレー・化粧が終わったあとに付けることで、真珠への付着を減らせます。
- **汗をかいた日**は、拭くだけでなく**湿らせた布で汗を取ってから乾拭き**。汗の塩分と酸が光沢を鈍らせます。
- **糸の種類**：絹糸は伸びやすく、切れるとほどけて珠が散らばるため、「オールノット（珠と珠の間に結び目）」の仕立てなら散らばりにくい。張り替え費用は**3,000〜8,000円**程度が相場とされます（長さと結び方で変動）。
- **変色・光沢低下**は元に戻りにくいため、**予防がほぼすべて**です。
- **長期保管**では、たまに（数か月に一度）取り出して**空気に触れさせ、布で拭く**と乾燥ひび割れの予防になると言われています。

> **【要検証】** モース硬度、張り替え費用の相場、乾燥によるひび割れの説明は業界団体の説明を参照しています。出典で確認してください。

## 誤解1｜宝石だから丈夫で、他のアクセサリーと一緒にしまっていい

**真珠は爪でも傷が付くほど柔らかい**部類です。ダイヤモンドや金属と触れると擦り傷が付き、光沢が鈍ります。単独で保管を。

## 誤解2｜たまにしか使わないから糸は替えなくていい

**使わなくても糸は経年で劣化します。** 数年に一度は隙間・垂れ・変色を確認し、張り替えを。切れたときの被害が大きいのは真珠です。

## 誤解3｜汗は水で洗い流せば安心

**水に長く浸けるのは糸を傷めます。** 湿らせた布で拭き、すぐ乾拭き。濡らしたまま放置しないこと。

## 誤解4｜金庫や密閉ケースで乾燥剤と一緒に保管すれば安全

**極度の乾燥は真珠の層のひび割れを招く**とされ、宝石店では乾燥剤との同居を避けるよう案内されることが多いです。

## 誤解5｜超音波洗浄機で新品のようにきれいになる

**真珠・糸・接着部を傷める代表的な失敗**です。真珠には使わないでください。汚れが取れないときは購入店・宝石店へ。
