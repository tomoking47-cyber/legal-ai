# Q. 珍珠项链该怎么保养和收纳？｜Japan Questions #471

- Shelf: `fashion` ／ URL: `/zh-cn/fashion/pearl-care` ／ Status: **草稿 — 出处未核实**

在日本，珍珠项链是婚礼、葬礼和各种正式仪式（「冠婚葬祭」kankonsōsai，人生大事的仪式）上的标准配饰，而且常常由母亲传给女儿。但珍珠也是所有宝石中最娇嫩的一种。收纳方式不对，光泽几年之内就会黯淡下去。

## A. 佩戴的当天，就用柔软的干布擦去汗水和化妆品，然后单独收好，不让它接触任何其他首饰。仅此一点，光泽能保持多久就大不相同。珍珠的主要成分是碳酸钙，质地柔软（莫氏硬度2.5–4.5），怕酸、汗、香水和发胶。绝对不要使用超声波清洗机。经常佩戴的话每1–2年换一次串线，只是偶尔佩戴的话每几年换一次。也要避开过于干燥的地方，比如保险柜里干燥剂的旁边。

## 珍珠怕什么，又该怎么保养

| 项目 | 详情 |
|---|---|
| **成分与硬度** | 碳酸钙（霰石 aragonite）与蛋白质（贝壳硬蛋白 conchiolin）交替形成的层。**莫氏硬度2.5–4.5**（钻石10、水晶7、指甲约2.5） |
| **怕** | **酸（汗水、果汁、醋）、香水、发胶、化妆品、氯（泳池、漂白剂）、高温、极度干燥** |
| **佩戴之后** | **用柔软的干布擦拭**（眼镜布或首饰专用布）。脏得比较厉害时，用**蘸温水后拧干的布**擦，再立刻用干布擦干 |
| **绝对不可以** | **超声波清洗机、洗涤剂、酒精、酸性清洁液、蒸汽** |
| **换线** | 每天到每周都戴：**每1–2年**。只在仪式场合戴：**每3–5年**。当珠子之间**出现空隙**、线被拉长而下垂、或者线已变色时，就该换线了 |
| **收纳** | **与其他首饰分开**，放在软布或专用盒里。避免**长期紧挨着干燥剂或放在密封容器中**（会导致开裂）。避免**阳光直射和高温** |

- **穿戴顺序**：**珍珠最后戴上，回家后最先摘下。** 在香水、发胶和妆容都完成之后再戴，能减少附着在珍珠上的东西。
- **出过汗的日子**，不要只用干布擦：**先用湿布把汗带走，再擦干。** 汗中的盐分和酸会让光泽变暗。
- **串线的种类**：丝线容易伸长，一旦断了珠子就会散落。采用「オールノット」（all-knotted，每两颗珠子之间打一个结）方式串的项链，散落的可能性小得多。换线费用一般说是**¥3,000–8,000**左右（因长度和打结方式而异）。
- **变色和光泽的流失很难挽回**，所以**预防几乎就是全部。**
- **长期收纳时**，隔一段时间（每几个月一次）把珍珠拿出来**透透气、用布擦一擦**，业内认为这有助于防止因干燥而开裂。

## 误解1｜是宝石，所以很结实，可以和其他饰品放在一起

**珍珠软到用指甲就能划伤。** 与钻石或金属接触会留下划痕，让光泽变暗。请单独收纳。

## 误解2｜我很少戴，所以线不用换

**即使不戴，线也会随着时间老化。** 每隔几年检查一次有没有空隙、下垂和变色，该换就换。线一旦断掉，受损最大的正是珍珠。

## 误解3｜出了汗，用水冲一下就行

**长时间泡水会损伤串线。** 用湿布擦，然后立刻擦干。绝对不要让它一直湿着。

## 误解4｜放在保险柜或带干燥剂的密封盒里最安全

**极度干燥被认为会让珍珠的层状结构开裂**，珠宝店通常也不建议把珍珠放在干燥剂旁边。

## 误解5｜用超声波清洗机就能焕然一新

**这是损坏珍珠、串线和粘接部位的典型做法。** 珍珠绝对不能用。如果污渍怎么都去不掉，请拿到购买的店铺或珠宝店处理。
