# Q. 珍珠項鍊該怎麼保養與收納？｜Japan Questions #471

- Shelf: `fashion` ／ URL: `/zh-tw/fashion/pearl-care` ／ Status: **草稿 — 出處未核實**

在日本，珍珠項鍊是婚禮、喪禮與各種正式典禮（「冠婚葬祭」kankonsōsai，人生大事的儀式）上的標準配件，而且常常由母親傳給女兒。但珍珠也是所有寶石中最嬌貴的一種。收納方式不對，光澤幾年內就會黯淡下來。

## A. 配戴的當天，就用柔軟的乾布擦去汗水與化妝品，然後單獨收好，不讓它碰到任何其他首飾。光是這一點，光澤能維持多久就大不相同。珍珠的主成分是碳酸鈣，質地柔軟（莫氏硬度2.5–4.5），怕酸、汗、香水與髮膠。絕對不要使用超音波清洗機。經常配戴的話每1–2年換一次串線，只是偶爾配戴的話每幾年換一次。也要避開過於乾燥的地方，例如保險箱裡乾燥劑的旁邊。

## 珍珠怕什麼，又該怎麼保養

| 項目 | 詳情 |
|---|---|
| **成分與硬度** | 碳酸鈣（霰石 aragonite）與蛋白質（貝殼硬蛋白 conchiolin）交替形成的層。**莫氏硬度2.5–4.5**（鑽石10、水晶7、指甲約2.5） |
| **怕** | **酸（汗水、果汁、醋）、香水、髮膠、化妝品、氯（游泳池、漂白劑）、高溫、極度乾燥** |
| **配戴之後** | **用柔軟的乾布擦拭**（眼鏡布或首飾專用布）。髒得較嚴重時，用**沾溫水後擰乾的布**擦，再立刻用乾布擦乾 |
| **絕對不可以** | **超音波清洗機、清潔劑、酒精、酸性清潔液、蒸氣** |
| **換線** | 每天到每週都戴：**每1–2年**。只在典禮場合戴：**每3–5年**。當珠子之間**出現空隙**、線被拉長而下垂，或線已變色時，就該換線了 |
| **收納** | **與其他首飾分開**，放在軟布或專用盒裡。避免**長期緊鄰乾燥劑或放在密封容器中**（會導致龜裂）。避免**陽光直射與高溫** |

- **穿戴順序**：**珍珠最後戴上，回家後最先取下。** 在香水、髮膠與妝容都完成之後再戴，能減少附著在珍珠上的東西。
- **流過汗的日子**，不要只用乾布擦：**先用濕布把汗帶走，再擦乾。** 汗中的鹽分與酸會讓光澤變暗。
- **串線的種類**：絲線容易伸長，一旦斷了珠子就會散落。以「オールノット」（all-knotted，每兩顆珠子之間打一個結）方式串成的項鍊，散落的機率小得多。換線費用一般說是**¥3,000–8,000**左右（依長度與打結方式而異）。
- **變色與光澤的流失很難挽回**，所以**預防幾乎就是一切。**
- **長期收納時**，隔一段時間（每幾個月一次）把珍珠拿出來**透透氣、用布擦一擦**，業界認為這有助於防止因乾燥而龜裂。

> **[待核實]** 莫氏硬度、換線的行情價，以及乾燥導致龜裂的說明，依據的是業界團體的解釋。請對照出處核實。

## 誤解1｜是寶石，所以很堅固，可以和其他飾品放在一起

**珍珠軟到用指甲就能刮傷。** 與鑽石或金屬接觸會留下刮痕，讓光澤變暗。請單獨收納。

## 誤解2｜我很少戴，所以線不用換

**即使不戴，線也會隨著時間老化。** 每隔幾年檢查一次有沒有空隙、下垂與變色，該換就換。線一旦斷掉，受損最大的正是珍珠。

## 誤解3｜流了汗，用水沖一下就好

**長時間泡水會損傷串線。** 用濕布擦，然後立刻擦乾。絕對不要讓它一直濕著。

## 誤解4｜放在保險箱或附乾燥劑的密封盒裡最安全

**極度乾燥被認為會讓珍珠的層狀結構龜裂**，珠寶店通常也不建議把珍珠放在乾燥劑旁邊。

## 誤解5｜用超音波清洗機就能煥然一新

**這是損壞珍珠、串線與黏合部位的典型做法。** 珍珠絕對不能用。如果髒污怎麼都去不掉，請拿到購買的店家或珠寶店處理。
