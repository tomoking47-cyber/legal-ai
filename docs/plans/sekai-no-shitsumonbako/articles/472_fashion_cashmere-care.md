# Q. カシミヤのセーターやマフラー、家で洗える？長持ちさせるには？｜世界の質問箱 #472

- 棚：`fashion` ／ URL：`/questions/cashmere-care` ／ ステータス：**ドラフト（法務レビュー前・出典未検証）**

ふつうのウールより細くて軽く、暖かいカシミヤ。値段が高いだけに「クリーニングに出すべき？」「毛玉ができた」「1シーズンで毛羽立った」という悩みが多い素材です。繊維の性質から、手入れと保管の目安をまとめます。

## A. 洗濯表示に手洗いマークがあれば家で洗えます。30℃以下のぬるま湯におしゃれ着用（中性）洗剤を溶かし、押し洗い1〜2分、すすぎ2回、洗濯機の脱水は30秒程度、平干し。カシミヤは繊維が細く（14〜16μm）摩擦と熱に弱いため、もみ洗い・お湯・ドライヤーは避ける。長持ちのコツは「連日着ない（1日休ませる）」「着たあとブラッシング」「シーズンオフは洗ってから防虫剤と一緒に保管」の3つです。

## カシミヤの基本と手入れの目安

| 項目 | 内容 |
|---|---|
| **繊維の細さ** | **14〜16μm**（ウールは一般に20μm以上）。細いほど柔らかいが、摩擦で切れて毛玉・毛羽立ちになりやすい |
| **産出量** | カシミヤ山羊1頭から採れる産毛は**年150〜200g**。セーター1着に**3〜4頭分**とされ、価格が高い理由 |
| **洗い（手洗い可の表示がある場合）** | **30℃以下**のぬるま湯、**中性のおしゃれ着用洗剤**、**押し洗い1〜2分**。もまない・こすらない |
| **すすぎ・脱水** | すすぎ**2回**、洗濯機の脱水は**30秒程度**か、タオルで水気を取る |
| **乾燥** | **平干し**（ハンガーは伸びる）。日陰、風通しの良い場所。**ドライヤー・乾燥機は禁止** |
| **表示が「家庭洗濯不可」** | クリーニング店へ。**ドライクリーニング**か**ウェットクリーニング**の可否を表示で確認 |
| **休ませる** | **連日着ない**。1日着たら**1〜2日**休ませ、繊維の回復を待つ |
| **毛玉** | **はさみで根元から切る**か、毛玉取り器を軽く。引っぱらない |

- **着たあとのブラッシング**：豚毛や馬毛の**洋服ブラシ**で、毛並みに沿って上から下へ。ほこりと、絡んだ繊維をほどき、毛玉の予防になります。
- **保管**：シーズンオフは**必ず洗ってから**（皮脂と食べこぼしが虫を呼ぶ）。**たたんで**、**防虫剤**と一緒に。ハンガー吊りは肩が伸びます。**カシミヤは虫害（カツオブシムシ・イガ）に最も遭いやすい素材**のひとつです。
- **混率表示**：家庭用品品質表示法では、カシミヤは「毛（カシミヤ）」のように表示され、**混率5%未満の場合は「カシミヤ」表記に制限**があります。国民生活センターは過去に「カシミヤ100」表記の製品で混率不足を指摘した事例を公表しています。
- **白いカシミヤの黄ばみ**は皮脂と汗の酸化。**着たら早めに洗う**のが予防です。

> **【要検証】** 繊維径、1頭あたりの産出量、混率表示のルールは業界資料・法令の最新版で確認してください。

## 誤解1｜カシミヤは家で洗えない

**手洗いマークがあれば洗えます。** むしろ長期間洗わずに保管する方が虫害・黄ばみの原因になります。表示が洗濯不可ならクリーニング店へ。

## 誤解2｜おしゃれ着用洗剤なら普通のコースで洗濯機に入れていい

**カシミヤは摩擦に弱く、普通コースでは毛玉・縮み・フェルト化**を起こします。手洗いか、洗濯機なら「手洗い」「ドライ」コース＋ネット、脱水は短時間で。

## 誤解3｜毛玉は引っぱって取る

**周囲の繊維まで引き抜いて薄くなります。** 小さなはさみで根元から切るか、毛玉取り器を軽く。

## 誤解4｜ハンガーで干せば形が保てる

**濡れたニットはハンガーの重みで肩と裾が伸びます。** 平干しネットか、バスタオルの上で形を整えて。

## 誤解5｜高いカシミヤは丈夫だからシーズン中ずっと着られる

**細い繊維ほど摩擦に弱く、連日着ると回復が追いつきません。** 休ませ、ブラシをかけることで、見た目の寿命は数年単位で変わります。
