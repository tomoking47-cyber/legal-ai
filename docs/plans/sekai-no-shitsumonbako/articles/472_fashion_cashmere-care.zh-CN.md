# Q. 羊绒衫或羊绒围巾能在家里洗吗？怎样才能用得久？｜Japan Questions #472

- Shelf: `fashion` ／ URL: `/zh-cn/fashion/cashmere-care` ／ Status: **草稿 — 出处未核实**

羊绒比普通羊毛更细、更轻、更暖。正因为价格昂贵，围绕它的疑问也最多：「是不是该送干洗店？」「起球了」「穿了一季就起毛了」。下面从纤维本身的特性出发，介绍保养与收纳的方法，并附上您会用到的日本洗涤标签与店内用语。

## A. 如果洗涤标签（日本使用国际通用的 JIS L0001 符号）上有手洗标志，就可以在家里洗。把中性的「おしゃれ着用洗剤」（oshareki-yō senzai，精细衣物专用洗涤剂）溶于30°C（86°F）以下的温水中，轻轻按压洗1–2分钟，漂洗两次，用洗衣机脱水约30秒，然后平铺晾干。羊绒纤维非常细（14–16 μm），怕摩擦和高温，所以不要搓揉、不要用热水、不要用吹风机。三个习惯能让它更耐久：不要连续两天穿（让它休息一天）、穿过之后用刷子刷、换季收纳前先洗净并放入防虫剂。

## 羊绒的基础知识与保养指南

| 项目 | 详情 |
|---|---|
| **纤维细度** | **14–16 μm**（羊毛一般在20 μm以上）。越细越柔软，但纤维在摩擦下容易断裂，变成球和毛絮 |
| **产量** | 一只羊绒山羊一年产**150–200 g**绒毛。据说一件毛衣需要**3–4只羊的量**，这就是它价格高的原因 |
| **洗涤（标签允许手洗时）** | **30°C以下**的温水、**中性精细衣物洗涤剂**、**按压洗1–2分钟**。不要揉搓 |
| **漂洗与脱水** | 漂洗**两次**；洗衣机脱水**约30秒**，或用毛巾按压吸干水分 |
| **晾干** | **平铺晾干**（挂衣架会拉长）。放在通风的阴凉处。**不用吹风机，不用烘干机** |
| **标签写着「不可家庭洗涤」** | 送到干洗店。请看标签确认允许的是**干洗**还是**湿洗（wet cleaning）** |
| **休息** | **不要连续两天穿。** 穿一天后让它休息**1–2天**，让纤维恢复 |
| **起球** | **用剪刀从根部剪掉球**，或轻轻使用去球器。不要用手拽 |

- **穿过之后刷一刷**：使用猪鬃或马毛的**衣物刷**（「洋服ブラシ」yōfuku burashi），顺着绒毛方向从上往下刷。它能带走灰尘、理顺缠在一起的纤维，有助于防止起球。
- **收纳**：换季时**一定要先洗**（皮脂和食物残渣会招虫）。**折叠**存放，并放入**防虫剂**（「防虫剤」bōchūzai，药妆店和百元店有售）。挂着会把肩部拉变形。**羊绒是最容易被衣蛾和皮蠹侵害的材料之一。**
- **成分标签**：根据日本《家庭用品品质标示法》，羊绒标示为「毛（カシミヤ）」（毛（羊绒））。**含量不足10%的纤维有两种以上时，可以合并标示为「其他」**；此外，**兽毛的含量允许误差（标示100%时为-3%，其他情况为±5%）。** 东京都过去曾对网购的羊绒制品进行商品测试，公布了标示为「カシミヤ100%」（羊绒100%）却未达到标示含量的案例。
- **白色羊绒发黄**是皮脂和汗水氧化所致。**穿过后尽早清洗**可以预防。

> **[待核实]** 纤维直径、每只山羊的产量以及成分标示的规则，请对照最新的业界资料与法规确认。

## 误解1｜羊绒不能在家洗

**只要标签上有手洗标志，就可以洗。** 反而是几个月不洗就收起来，才是虫蛀和发黄的更大原因。如果标签禁止水洗，请交给干洗店。

## 误解2｜用了精细衣物洗涤剂，就可以用普通洗涤程序

**羊绒怕摩擦，普通程序会导致起球、缩水和毡化。** 请手洗，或把衣物放进洗衣袋，使用洗衣机的「手洗」或「干洗」程序并缩短脱水时间。

## 误解3｜起球直接揪掉就好

**这样会把周围的纤维一起拽出来，让面料变薄。** 请用小剪刀从根部剪断，或轻轻使用去球器。

## 误解4｜挂在衣架上晾能保持版型

**湿的针织衫挂在衣架上，会因自身重量在肩部和下摆被拉长。** 请使用平铺晾晒网，或在浴巾上整理好形状晾干。

## 误解5｜贵的羊绒结实，可以整个季节天天穿

**纤维越细，越经不起摩擦，天天穿也没有恢复的时间。** 让它休息、给它刷一刷，几年之后的外观会完全不同。
