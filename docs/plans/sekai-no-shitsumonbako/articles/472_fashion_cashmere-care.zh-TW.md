# Q. 喀什米爾毛衣或圍巾可以在家洗嗎？怎麼做才能用得久？｜Japan Questions #472

- Shelf: `fashion` ／ URL: `/zh-tw/fashion/cashmere-care` ／ Status: **草稿 — 出處未核實**

喀什米爾（cashmere）比一般羊毛更細、更輕、更保暖。正因為價格昂貴，相關的疑問也最多：「是不是該送洗？」「起毛球了」「穿一季就起毛了」。以下從纖維本身的特性出發，介紹保養與收納的方法，並附上您會用到的日本洗滌標籤與店內用語。

## A. 如果洗滌標籤（日本使用國際通用的 JIS L0001 符號）上有手洗標誌，就可以在家洗。把中性的「おしゃれ着用洗剤」（oshareki-yō senzai，精緻衣物專用洗劑）溶於30°C（86°F）以下的溫水中，輕輕按壓洗1–2分鐘，清洗兩次，用洗衣機脫水約30秒，然後平放晾乾。喀什米爾纖維非常細（14–16 μm），怕摩擦與高溫，所以不要搓揉、不要用熱水、不要用吹風機。三個習慣能讓它更耐用：不要連續兩天穿（讓它休息一天）、穿過之後用刷子刷、換季收納前先洗淨並放入防蟲劑。

## 喀什米爾的基礎知識與保養指南

| 項目 | 詳情 |
|---|---|
| **纖維細度** | **14–16 μm**（羊毛一般在20 μm以上）。越細越柔軟，但纖維在摩擦下容易斷裂，變成毛球與毛屑 |
| **產量** | 一隻喀什米爾山羊一年產**150–200 g**絨毛。據說一件毛衣需要**3–4隻羊的量**，這就是價格高昂的原因 |
| **洗滌（標籤允許手洗時）** | **30°C以下**的溫水、**中性精緻衣物洗劑**、**按壓洗1–2分鐘**。不要揉搓 |
| **清洗與脫水** | 清洗**兩次**；洗衣機脫水**約30秒**，或用毛巾按壓吸乾水分 |
| **晾乾** | **平放晾乾**（用衣架會被拉長）。放在通風的陰涼處。**不用吹風機，不用烘衣機** |
| **標籤寫著「不可家庭洗滌」** | 送洗。請看標籤確認允許的是**乾洗**還是**濕洗（wet cleaning）** |
| **休息** | **不要連續兩天穿。** 穿一天後讓它休息**1–2天**，讓纖維恢復 |
| **起毛球** | **用剪刀從根部剪掉毛球**，或輕輕使用除毛球機。不要用手拉 |

- **穿過之後刷一刷**：使用豬鬃或馬毛的**衣物刷**（「洋服ブラシ」yōfuku burashi），順著絨毛方向由上往下刷。可以帶走灰塵、理順糾結的纖維，有助於防止起毛球。
- **收納**：換季時**一定要先洗**（皮脂與食物殘渣會招蟲）。**摺疊**存放，並放入**防蟲劑**（「防虫剤」bōchūzai，藥妝店與百圓店有售）。吊掛會把肩線拉變形。**喀什米爾是最容易被衣蛾與皮蠹蟲啃食的材質之一。**
- **成分標示**：依日本《家庭用品品質標示法》，喀什米爾標示為「毛（カシミヤ）」（毛（喀什米爾））。**含量未滿5%時，標籤上使用「カシミヤ」（喀什米爾）一詞受到限制。** 日本國民生活中心過去曾公布過標示為「カシミヤ100」（全喀什米爾）的商品實際含量不足的案例。
- **白色喀什米爾泛黃**是皮脂與汗水氧化所致。**穿過後盡早清洗**即可預防。

> **[待核實]** 纖維直徑、每隻山羊的產量以及成分標示的規定，請對照最新的業界資料與法規確認。

## 誤解1｜喀什米爾不能在家洗

**只要標籤上有手洗標誌，就可以洗。** 反而是好幾個月不洗就收起來，才是蟲蛀與泛黃的更大原因。若標籤禁止水洗，請送洗。

## 誤解2｜用了精緻衣物洗劑，就可以用一般洗程

**喀什米爾怕摩擦，一般洗程會造成起毛球、縮水與氈化。** 請手洗，或把衣物放進洗衣袋，使用洗衣機的「手洗」或「乾洗」洗程並縮短脫水時間。

## 誤解3｜毛球直接拉掉就好

**這樣會把周圍的纖維一起拉出來，讓布料變薄。** 請用小剪刀從根部剪斷，或輕輕使用除毛球機。

## 誤解4｜掛在衣架上晾可以保持版型

**濕的針織衫掛在衣架上，會因自身重量在肩線與下襬被拉長。** 請使用平放式曬衣網，或在浴巾上整理好形狀晾乾。

## 誤解5｜貴的喀什米爾很堅固，整季天天穿也沒關係

**纖維越細，越禁不起摩擦，天天穿也沒有恢復的時間。** 讓它休息、幫它刷一刷，幾年後的外觀會完全不同。
