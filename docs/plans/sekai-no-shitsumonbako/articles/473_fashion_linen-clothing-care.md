# Q. リネン（麻）の服は、どう洗ってどう干せばシワや縮みを防げる？｜世界の質問箱 #473

- 棚：`fashion` ／ URL：`/questions/linen-clothing-care` ／ ステータス：**ドラフト（法務レビュー前・出典未検証）**

夏の定番になったリネン（麻）のシャツやワンピース。涼しくて速乾ですが、「洗ったら縮んだ」「シワが取れない」「日に当てたら色が抜けた」という声も多い素材です。麻の性質を知ると、シワとの付き合い方が変わります。

## A. リネンは洗えば洗うほど柔らかくなる素材で、洗うこと自体は問題ありません。縮みとシワを抑えるコツは「洗濯ネットに入れて弱水流」「脱水は1分以内」「濡れているうちに手で叩いてシワを伸ばし、形を整えて吊り干し」の3つ。初回洗濯で2〜5%程度縮むのが普通なので、買うときにその分を見込む。濡れた状態でのアイロンが効きます。濃色は日光で色あせしやすいため陰干しにします。

## リネンの性質と洗い方の目安

| 項目 | 内容 |
|---|---|
| **素材の性質** | 亜麻（フラックス）の繊維。**吸水・放湿が速く**、水にぬれると強度が上がる。**しわになりやすい**が、洗うほど柔らかくなる |
| **表示上の「麻」** | 家庭用品品質表示法で「麻」と表示できるのは**亜麻（リネン）と苧麻（ラミー）のみ**。ジュートやヘンプは「指定外繊維」表記 |
| **縮み** | **初回で2〜5%程度**縮むのが一般的。お湯・強い脱水・乾燥機で縮みが大きくなる |
| **水温** | **30〜40℃以下**（表示に従う）。洗剤は普通の洗濯用でも可、濃色は中性洗剤が色落ちしにくい |
| **コース** | **ネットに入れて弱水流（手洗い・おしゃれ着コース）**。脱水は**30秒〜1分** |
| **干し方** | 脱水後すぐ取り出し、**濡れているうちに手でパンパンと叩いてシワを伸ばし**、縫い目を引いて形を整え、**太めのハンガーで吊り干し**。濃色は**陰干し** |
| **アイロン** | **高温（麻表示・180〜210℃）、湿らせて**、または霧吹き。乾いた状態では取れにくい |
| **乾燥機** | 縮みとシワの原因。**使わない**のが無難 |

- **シワを「味」として着る**のがリネンの本来の楽しみ方で、完全に取ろうとするほど手間が増えます。**襟・前立て・袖口だけアイロン**をかけると全体が整って見えます。
- **色落ち**：濃紺・黒・カラーの麻は**水に色が出やすく**、初回は単独で洗う。**日光で退色**もしやすいため、干すときは裏返して陰干し。
- **白い麻の黄ばみ**は皮脂。**酸素系漂白剤（40℃程度）に30分**が目安。塩素系は生地を傷めます。
- **保管**：湿気に強い素材ですが、**ハンガーで長期保管すると肩に跡**が付きます。オフシーズンはたたむか、太いハンガーで。
- **麻の毛羽**：黒い服に白い繊維が付くことがありますが、洗うと落ち着きます。

> **【要検証】** 縮み率、アイロン温度は繊維業界の一般的な説明値です。表示規程の「麻」の定義は消費者庁の資料で確認してください。

## 誤解1｜麻は縮むから洗わずにクリーニングに出すべき

**麻は水洗いに向く丈夫な素材です。** 初回に少し縮むのは前提として、家で洗って問題ないものが多いです。表示に従ってください。

## 誤解2｜シワは乾いてからアイロンをかければ取れる

**麻のシワは乾いた状態では取れにくく、濡らして高温**が基本です。脱水後すぐに手で伸ばすだけでもかなり違います。

## 誤解3｜しっかり脱水した方が早く乾く

**強い脱水はシワを固定します。** 麻は乾きが速いので、30秒〜1分の短い脱水でも十分乾きます。

## 誤解4｜日当たりのよい場所で干すのが一番

**濃色の麻は日光で色あせします。** 風通しのよい日陰で、裏返して干すのが無難です。

## 誤解5｜「麻」と書いてあれば全部同じ

**日本の表示規程で「麻」と書けるのはリネンとラミーだけ**で、ヘンプやジュートは別表記です。同じ「麻」でも、ラミーはリネンより張りがあって硬めです。
