# Q. 亚麻衣物怎么洗、怎么晾，才不会缩水和起皱？｜Japan Questions #473

- Shelf: `fashion` ／ URL: `/zh-cn/fashion/linen-clothing-care` ／ Status: **草稿 — 出处未核实**

在日本潮湿闷热的夏天，亚麻衬衫和连衣裙已经成了必备单品。它凉爽、干得快，但抱怨也不少：「洗完缩水了」「褶皱怎么都弄不平」「晒太阳后掉色了」。只要了解亚麻纤维的特性，您就能和褶皱和平共处。

## A. 亚麻越洗越柔软，所以洗涤本身完全没问题。三个习惯能减少缩水和褶皱：放进洗衣袋用轻柔程序洗、脱水不超过1分钟、趁衣物还湿的时候用手把褶皱拍平、整理好形状再挂起来晾。第一次洗涤缩水2–5%左右是正常的，购买时请把这一点考虑进去。熨烫在布料还潮湿时效果最好。深色在阳光下会褪色，所以请在阴凉处晾干。

## 亚麻的特性与洗涤方法

| 项目 | 详情 |
|---|---|
| **纤维** | 取自亚麻（flax）植物。**吸湿放湿都快**，而且湿的时候更结实。**容易起皱**，但每洗一次就更柔软 |
| **标签上的「麻」（asa）** | 根据日本《家庭用品品质标示法》，只有**亚麻（linen）和苎麻（ramie）**可以标示为「麻」。黄麻和大麻则标示为「指定外纤维」（指定外繊維） |
| **缩水** | **第一次洗涤缩水2–5%左右**是正常的。热水、强力脱水和烘干机会让缩水加剧 |
| **水温** | **30–40°C（86–104°F）以下**（遵循标签）。普通洗衣液即可；深色衣物用中性洗涤剂可减少掉色 |
| **程序** | **放进洗衣袋，用轻柔程序（手洗或精细衣物）**。脱水**30秒到1分钟** |
| **晾干** | 脱水结束后立刻取出。**趁还湿的时候用手用力把褶皱拍平**，把接缝拉直，**挂在较粗的衣架上**。深色请**在阴凉处** |
| **熨烫** | **高温（亚麻档，180–210°C），布料要湿润**或用喷雾瓶喷湿。干着的时候褶皱很难去掉 |
| **烘干机** | 会造成缩水和起皱。**最保险的是不用** |

- **把褶皱当作造型的一部分**，才是亚麻应有的享受方式；越想把褶皱全部弄平，越费工夫。**只熨领子、门襟和袖口**，整件衣服看上去就很整齐。
- **掉色**：深藏青、黑色和有颜色的亚麻**在水中容易掉色**，第一次请单独洗。它们**在阳光下也会褪色**，所以请翻面后在阴凉处晾干。
- **白色亚麻发黄**是皮脂造成的。参考做法是**在约40°C的「酸素系漂白剤」（sanso-kei hyōhakuzai，氧系漂白剂）中浸泡30分钟。** 氯系漂白剂会损伤面料。
- **收纳**：亚麻不怕潮湿，但**长期挂着存放会在肩部留下痕迹。** 换季时请折叠收纳，或使用较粗的衣架。
- **亚麻的飞絮**：深色衣物上可能出现白色纤维；多洗几次就会好转。

> **[待核实]** 缩水率和熨烫温度是纺织行业常用的一般数值。「麻」在标示规程中的定义，请对照消费者厅的资料确认。

## 误解1｜亚麻会缩水，所以该送干洗而不是水洗

**亚麻是很结实、很适合水洗的纤维。** 第一次接受一点缩水就好，大多数单品都可以在家洗。请遵循标签。

## 误解2｜等干了再熨一次，褶皱就没了

**亚麻的褶皱干着很难去掉，原则是布料潮湿加高温。** 哪怕只是在脱水后立刻用手抚平，效果也大不相同。

## 误解3｜脱水时间长一点，干得更快

**强力脱水会把褶皱定型。** 亚麻本来就干得快，脱水30秒到1分钟就够了。

## 误解4｜阳光最好的地方最适合晾亚麻

**深色亚麻在阳光下会褪色。** 通风的阴凉处、衣物翻面，才是稳妥的选择。

## 误解5｜标签上写着「麻」，那就都一样

**根据日本的标示规定，只有亚麻和苎麻可以写成「麻」**；大麻和黄麻的标示方式不同。即使同样是「麻」，苎麻也比亚麻更挺、更硬。
