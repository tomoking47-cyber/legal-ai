# Q. 亞麻衣物該怎麼洗、怎麼晾，才不會縮水與起皺？｜Japan Questions #473

- Shelf: `fashion` ／ URL: `/zh-tw/fashion/linen-clothing-care` ／ Status: **草稿 — 出處未核實**

在日本潮濕悶熱的夏天，亞麻襯衫與洋裝已經成為必備單品。它涼爽、乾得快，但抱怨也不少：「洗完縮水了」「皺褶怎麼都弄不平」「曬過太陽就褪色了」。只要了解亞麻纖維的特性，您就能與皺褶和平共處。

## A. 亞麻越洗越柔軟，所以清洗本身完全沒問題。三個習慣能減少縮水與皺褶：放進洗衣袋用輕柔洗程、脫水不超過1分鐘、趁衣物還濕的時候用手把皺褶拍平、整理好形狀再掛起來晾。第一次清洗縮水2–5%左右是正常的，購買時請把這一點考慮進去。熨燙在布料還潮濕時效果最好。深色在陽光下會褪色，所以請在陰涼處晾乾。

## 亞麻的特性與清洗方式

| 項目 | 詳情 |
|---|---|
| **纖維** | 取自亞麻（flax）植物。**吸濕與放濕都快**，而且濕的時候更堅韌。**容易起皺**，但每洗一次就更柔軟 |
| **標籤上的「麻」（asa）** | 依日本《家庭用品品質標示法》，只有**亞麻（linen）與苧麻（ramie）**可以標示為「麻」。黃麻與大麻則標示為「指定外纖維」（指定外繊維） |
| **縮水** | **第一次清洗縮水2–5%左右**是正常的。熱水、強力脫水與烘衣機會讓縮水加劇 |
| **水溫** | **30–40°C（86–104°F）以下**（依標籤）。一般洗衣精即可；深色衣物用中性洗劑可減少褪色 |
| **洗程** | **放進洗衣袋，用輕柔洗程（手洗或精緻衣物）**。脫水**30秒到1分鐘** |
| **晾乾** | 脫水結束後立刻取出。**趁還濕的時候用手用力把皺褶拍平**，把接縫拉直，**掛在較粗的衣架上**。深色請**在陰涼處** |
| **熨燙** | **高溫（亞麻檔，180–210°C），布料要潮濕**或用噴霧瓶噴濕。乾的時候皺褶很難去除 |
| **烘衣機** | 會造成縮水與起皺。**最保險的是不要用** |

- **把皺褶當成造型的一部分**，才是享受亞麻的方式；越想把皺褶全部弄平，就越費工。**只熨領子、前門襟與袖口**，整件衣服看起來就很俐落。
- **褪色**：深藍、黑色與有顏色的亞麻**在水中容易掉色**，第一次請單獨洗。它們**在陽光下也會褪色**，所以請翻面後在陰涼處晾乾。
- **白色亞麻泛黃**是皮脂造成的。參考做法是**在約40°C的「酸素系漂白剤」（sanso-kei hyōhakuzai，氧系漂白劑）中浸泡30分鐘。** 氯系漂白劑會傷害布料。
- **收納**：亞麻不怕潮濕，但**長期吊掛存放會在肩部留下痕跡。** 換季時請摺疊收納，或使用較粗的衣架。
- **亞麻的飛絮**：深色衣物上可能出現白色纖維；多洗幾次就會改善。

> **[待核實]** 縮水率與熨燙溫度是紡織業常用的一般數值。「麻」在標示規程中的定義，請對照消費者廳的資料確認。

## 誤解1｜亞麻會縮水，所以該送洗而不是自己洗

**亞麻是很堅韌、很適合水洗的纖維。** 第一次接受一點縮水就好，大多數單品都可以在家洗。請依照標籤。

## 誤解2｜等乾了再熨一次，皺褶就會不見

**亞麻的皺褶乾的時候很難去除，原則是布料潮濕加高溫。** 就算只是在脫水後立刻用手撫平，效果也大不相同。

## 誤解3｜脫水久一點，乾得比較快

**強力脫水會把皺褶定型。** 亞麻本來就乾得快，脫水30秒到1分鐘就夠了。

## 誤解4｜陽光最好的地方最適合晾亞麻

**深色亞麻在陽光下會褪色。** 通風的陰涼處、衣物翻面，才是穩當的選擇。

## 誤解5｜標籤上寫「麻」，那就都一樣

**依日本的標示規定，只有亞麻與苧麻可以寫成「麻」**；大麻與黃麻的標示方式不同。即使同為「麻」，苧麻也比亞麻更挺、更硬。
