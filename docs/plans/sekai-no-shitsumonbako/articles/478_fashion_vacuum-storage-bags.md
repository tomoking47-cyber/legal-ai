# Q. 布団や冬服の圧縮袋、入れてはいけないものはある？｜世界の質問箱 #478

- 棚：`fashion` ／ URL：`/questions/vacuum-storage-bags` ／ ステータス：**ドラフト（法務レビュー前・出典未検証）**

押し入れの容量を稼ぐ圧縮袋は、日本の狭い住宅で長く使われてきた道具です。ただ、「羽毛布団がふっくら戻らない」「ダウンがぺしゃんこに」「半年後にシワとカビ」という失敗も多い。素材と期間で「入れてよいもの」が決まります。

## A. 圧縮袋に向くのは、ポリエステルわたの布団・毛布・綿の衣類。羽毛布団・ダウンジャケット・ウールのニットは繊維が折れて復元しにくくなるため、入れないか、入れても軽く空気を抜く程度にとどめる。どの素材も「洗って完全に乾かしてから」「6か月以内に一度は出す」が原則。体積は3分の1程度に減りますが、詰め込み過ぎると圧縮袋自体が破れて意味がなくなります。

## 圧縮してよいもの・避けるもの

| 品目 | 圧縮 | 理由・注意 |
|---|---|---|
| **ポリエステルわたの布団・毛布** | **可** | 復元しやすい。**6か月以内**に一度取り出して干す |
| **綿の衣類（Tシャツ・トレーナー）** | **可** | シワは付く。取り出したら干すかアイロン |
| **羽毛布団** | **避ける／軽く抜く程度** | 羽枝が折れ、**保温力（かさ高）が戻らない**。日本羽毛製品協同組合も**強い圧縮は非推奨** |
| **ダウンジャケット** | **避ける** | 同上。しまうなら**ゆったりした不織布カバー** |
| **ウール・カシミヤのニット** | **避ける／短期のみ** | 繊維の折れとシワ、**防虫剤の効きが変わる** |
| **革・合皮製品** | **不可** | 折れ跡、ひび割れ、表面の変質 |
| **低反発・ウレタン製品** | **不可** | 復元しない。素材が崩れる |
| **湿ったもの・洗っていないもの** | **不可** | **カビ・においを密閉して増やす** |

- **圧縮の目安**：**体積が3分の1程度**まで。「ぺしゃんこ」まで抜くと繊維の折れとシワが強く出ます。**袋の8割まで**の量にとどめ、詰め込みは袋の破れの原因。
- **入れる前に**：**洗ってから完全に乾燥**。皮脂と湿気を残すとカビと虫の温床に。**防虫剤を圧縮袋に入れる場合**は、**「圧縮袋対応」と表示のあるもの**を。多くの防虫剤は成分が気化して働くため、密閉状態では設計通りに効かない、または成分が布に濃く付着する場合があります。
- **期間**：**半年に一度は袋から出して干す**。圧縮袋の多くは**完全密封ではなく、数か月で少し空気が入る**のが普通。1年以上放置はシワ・カビ・においの主因。
- **取り出したあと**：**天日干しまたは陰干しで半日〜1日**かけて空気を含ませる。ポリエステルわたは軽く叩くと戻ります。羽毛は戻りにくい。
- **代わりの方法**：羽毛・ダウン・ニットは**不織布のケース**か**通気性のある収納袋**に、**8割の詰め方**で。空間の節約は、圧縮より「収納する量を見直す」方が効果的、という声も。

> **【要検証】** 羽毛製品への圧縮の可否については、日本羽毛製品協同組合の見解を確認してください。防虫剤の「圧縮袋対応」表示は各メーカーの説明に基づきます。

## 誤解1｜羽毛布団も圧縮袋でぺしゃんこにして問題ない

**羽枝が折れ、かさ高（保温力）が戻りません。** 羽毛布団は圧縮しないか、軽く空気を抜く程度で、6か月以内に出す。

## 誤解2｜圧縮袋は密閉だからカビ・虫の心配がない

**湿気を閉じ込めれば中でカビが増えます。** 完全に乾かしてから入れることが前提。密閉も完全ではなく、数か月で空気が入ります。

## 誤解3｜防虫剤を一緒に入れれば安心

**多くの防虫剤は密閉空間では設計通りに働きません。** 「圧縮袋対応」の製品を使い、取扱説明に従って。

## 誤解4｜空気を抜けるだけ抜くほど収納効率がよい

**繊維の折れとシワが強く出て、袋も破れやすくなります。** 3分の1程度で止める。

## 誤解5｜一度入れたら次の冬まで開けなくていい

**半年に一度は出して干す**のが目安。シワ・におい・カビは「放置期間」に比例します。
