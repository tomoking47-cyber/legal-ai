# Q. 棉被與冬衣用的真空壓縮袋：有什麼東西是不能放進去的嗎？｜Japan Questions #478

- Shelf: `fashion` ／ URL: `/zh-tw/fashion/vacuum-storage-bags` ／ Status: **草稿 — 出處未核實**

用吸塵器抽氣或用手捲平的真空壓縮袋（「圧縮袋」，asshuku-bukuro），因為能空出「押入れ」（oshiire，日式深壁櫥）的空間，長久以來一直是日本狹小住宅的必備品。但它帶來的懊惱也不少：「我的羽絨被再也蓬不起來了」「羽絨外套變成一張餅」「半年後打開：摺痕加黴斑」。能不能放進去，取決於材質與存放的時間。

## A. 壓縮袋適合聚酯纖維的棉被、毛毯與棉質衣物。羽絨被、羽絨外套與羊毛針織衫不要放，或者最多只抽掉一點空氣，因為纖維會斷裂且無法恢復。所有材質通用的規則是：先洗淨並徹底晾乾，且至少在6個月內取出一次。體積會減到約三分之一，但裝得太滿袋子會破，那就本末倒置了。

## 什麼能壓縮，什麼不能

| 物品 | 可否壓縮？ | 理由與注意事項 |
|---|---|---|
| **聚酯纖維棉被與毛毯** | **可以** | 恢復良好。請**在6個月內**取出通風 |
| **棉質衣物（T恤、大學T）** | **可以** | 會有摺痕。取出後通風或熨燙 |
| **羽絨被** | **避免，或只抽掉一點空氣** | 羽絨的絨枝會折斷，**蓬鬆度（保暖性）無法恢復。** 日本羽毛製品協同組合也**不建議強力壓縮** |
| **羽絨外套** | **避免** | 同上。請改用**寬鬆的不織布收納套**保存 |
| **羊毛與喀什米爾針織衫** | **避免，或僅限短期** | 纖維斷裂與摺痕；密封袋內**防蟲劑的作用方式會不同** |
| **皮革與合成皮革** | **不可** | 摺痕、龜裂、表面損傷 |
| **記憶棉與聚氨酯製品** | **不可** | 無法恢復；材質會劣化 |
| **潮濕或未清洗的物品** | **不可** | **會把黴菌與氣味封在裡面並讓它們繁殖** |

- **壓縮到什麼程度**：壓到**約三分之一的體積。** 抽到「扁得像煎餅」會造成嚴重的纖維斷裂與摺痕。袋子裝到**不超過80%**；裝得過滿是破裂的主因。
- **放進去之前**：**先洗，再徹底晾乾。** 殘留的皮脂與水分會滋生黴菌與蟲。**若要在壓縮袋裡放防蟲劑**，請使用**標示可用於壓縮袋（「圧縮袋対応」）**的產品。多數防蟲劑靠揮發發揮作用，在密封袋內可能無法按設計方式作用，或有效成分會在布料上累積。
- **存放期限**：**每六個月取出通風一次。** 多數壓縮袋**並非完全密封，幾個月內就會進氣。** 放置超過一年是摺痕、黴菌與異味的主因。
- **取出之後**：**在日光下或陰涼處放半天到一天**，讓空氣重新回到纖維中。聚酯纖維輕輕拍打即可恢復。羽絨則不易恢復。
- **替代方案**：羽絨、羽毛與針織衫請放入**不織布收納盒**或**透氣收納袋**，裝到**不超過80%。** 也有人說，真正省空間的方法不是壓縮，而是少擁有一些東西。

> **[待核實]** 請確認日本羽毛製品協同組合對壓縮羽絨製品的立場。防蟲劑「可用於壓縮袋」的標示依據各廠商的說明。

## 誤解1｜羽絨被壓扁在壓縮袋裡也沒關係

**絨枝會折斷，蓬鬆度（保暖性）無法恢復。** 羽絨被不要壓縮，或只抽掉一點空氣，並在6個月內取出。

## 誤解2｜壓縮袋是密封的，不用擔心黴菌與蟲

**把水分封在裡面，黴菌就在裡面長。** 放進去之前必須完全乾燥。而且密封並不完美：幾個月內就會進空氣。

## 誤解3｜袋子裡放防蟲劑就安全了

**多數防蟲劑在密封空間裡無法按設計方式作用。** 請使用標示可用於壓縮袋的產品，並遵循其說明。

## 誤解4｜抽掉的空氣越多，收納效率越高

**纖維會斷裂，摺痕會定型，袋子也更容易破。** 壓到約三分之一就停手。

## 誤解5｜裝好之後可以一直封到明年冬天

**每六個月取出通風一次。** 摺痕、氣味與黴菌都與放置時間成正比。
