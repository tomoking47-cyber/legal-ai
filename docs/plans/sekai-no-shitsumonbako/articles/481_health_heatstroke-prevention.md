# Q. 熱中症は、家の中でもなるって本当？予防と初期対応は｜世界の質問箱 #481

- 棚：`health` ／ URL：`/questions/heatstroke-prevention` ／ ステータス：**ドラフト（法務レビュー前・出典未検証）**

日本の夏、熱中症で救急搬送される人は年間10万人前後。「屋外で運動する若者」のイメージがありますが、実際には搬送者の半数以上が高齢者で、発生場所の最多は「住居」です。予防の基本と、症状が出たときの見極めを整理します。

## A. 熱中症の4割前後は家の中で起きています。予防の柱は「室温28℃以下・湿度60%以下に保つ（エアコンをためらわない）」「のどが渇く前にこまめに水分、汗を多くかいたら塩分も」「暑さ指数（WBGT）が28以上の日は外出・運動を控える」の3つ。めまい・立ちくらみ・筋肉のけいれんなら涼しい場所で体を冷やし水分補給、頭痛・吐き気・ぐったりしていれば医療機関へ、呼びかけに反応が鈍い・自分で水が飲めないなら迷わず119番です。

## 数字で見る熱中症

| 項目 | 数値（目安） |
|---|---|
| **救急搬送者数** | **年間約10万人**（5〜9月、総務省消防庁。2025年は過去最多の100,510人、2024年は97,578人） |
| **年齢** | 搬送者の**約57%が65歳以上**（2025年は57,433人・57.1%） |
| **発生場所** | **住居が最多で約4割**。次いで道路、屋外の作業場、運動場 |
| **死亡者数** | **年間1,500〜2,000人超**（人口動態統計。2023年は1,651人、2024年は過去最多の2,160人）。**8割以上が65歳以上**、屋内での死亡例の多くは**エアコン未使用** |
| **暑さ指数（WBGT）** | **25以上：警戒、28以上：厳重警戒（激しい運動は中止）、31以上：危険（外出を避ける）**。**33以上**で「熱中症警戒アラート」、**35以上**（都道府県内の全地点）で2024年4月に新設された「熱中症特別警戒アラート」が発表 |
| **室内環境** | **室温28℃以下、湿度60%以下**が目安。高齢者は暑さを感じにくいため**温湿度計**を置いて数値で判断 |
| **水分** | 食事以外で**1日1.2L**が目安（環境省）。汗を多くかいたら**0.1〜0.2%の塩分**（スポーツドリンク、経口補水液） |

## 重症度と対応（日本救急医学会「熱中症診療ガイドライン2024」の分類を簡略化）

> 2024年の改訂で、III度のうち**深部体温40℃以上かつ重い意識障害（GCS 8以下）**のものを**IV度（最重症）**として新設しました。市民が行う応急処置はIII度と同じ（すぐ119番・全身を冷やす）です。

| 段階 | 症状 | 対応 |
|---|---|---|
| **I度（軽症）** | めまい、立ちくらみ、筋肉痛・こむら返り、大量の汗 | **涼しい場所へ移動、衣服をゆるめ、首・わきの下・足の付け根を冷やす、水分と塩分**。改善しなければ医療機関 |
| **II度（中等症）** | **頭痛、吐き気、嘔吐、体がだるい、集中できない** | **医療機関へ**。自分で水が飲めなければ119番 |
| **III度（重症）** | **意識がおかしい、返事がおかしい、けいれん、まっすぐ歩けない、体が熱い** | **すぐ119番**。到着まで全身を冷やす（濡らしたタオル＋扇風機、氷で首・わき・足の付け根） |

- **暑さに慣れる（暑熱順化）**には**数日〜2週間**かかります。梅雨明け直後や、急に暑くなった日が最も危険。**5〜6月から**、汗をかく軽い運動や入浴で体を慣らす方法が推奨されています。
- **高齢者**は①暑さ・のどの渇きを感じにくい ②体内の水分量が少ない ③エアコンを我慢しがち、の3点でリスクが高い。**離れて暮らす親には「エアコンを付けたか」を電話で確認**する家庭も多いです。
- **子ども**は身長が低く地面の照り返しを受けやすく、体温調節も未熟。**車内に残さない**（外気35℃で車内は**15分で危険域**）。
- **服装**：通気性・吸湿速乾の素材、**帽子・日傘**、屋外では**日陰を選ぶ**。
- **アルコールは利尿作用で脱水を進める**ため、水分補給になりません。

> **【要検証】** 搬送者数・年齢構成・発生場所の割合は年ごとに変わります。公開時の直近年の消防庁データに更新してください。WBGTの区分は環境省「熱中症予防情報サイト」の記述を確認してください。

## 誤解1｜熱中症は外で運動する人がなるもの

**発生場所の最多は住居で、搬送者の半数以上が高齢者**です。窓を閉め切った部屋、就寝中、入浴後も要注意です。

## 誤解2｜のどが渇いたら飲めば十分

**渇きを感じた時点で軽い脱水**が始まっています。高齢者は渇きを感じにくいため、**時間を決めて飲む**のが確実です。

## 誤解3｜扇風機があればエアコンはいらない

**室温が高いと扇風機は熱風を動かすだけ**です。環境省・厚労省ともに「エアコンの使用をためらわない」と呼びかけています。電気代より命を優先してください。

## 誤解4｜水だけたくさん飲めば安心

**大量の汗で塩分も失われており、水だけを大量に飲むと血液中の塩分が薄まって体調を崩す**ことがあります。汗を多くかく日は塩分も。

## 誤解5｜少し休めば治まるから病院はいらない

**頭痛・吐き気・ぐったりは中等症のサイン**で、医療機関を受診する段階です。**呼びかけへの反応が鈍い、自分で水が飲めない**なら119番。判断を誤ると命に関わります。
