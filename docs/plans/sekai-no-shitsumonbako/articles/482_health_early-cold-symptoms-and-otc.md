# Q. 風邪のひきはじめ、市販薬で済ませていい？病院に行く目安は｜世界の質問箱 #482

- 棚：`health` ／ URL：`/questions/early-cold-symptoms-and-otc` ／ ステータス：**ドラフト（法務レビュー前・出典未検証）**

のどがイガイガ、鼻水、微熱——「風邪かな」と思ったとき、日本ではドラッグストアの総合感冒薬で様子を見る人が多数派です。それで問題ないことも多いのですが、「抗生物質をもらいに行く」「薬を重ねて飲む」など、避けたい行動もはっきりしています。

## A. 風邪（かぜ症候群）の大半はウイルスが原因で、抗生物質（抗菌薬）は効きません。市販の風邪薬も「症状を和らげる」ものであり、風邪そのものを早く終わらせる薬は基本的にありません。休養・水分・睡眠が中心で、市販薬は「つらい症状を軽くして休むため」に使う。ただし、38.5℃以上の熱が3日以上続く、息苦しい、水分が取れない、症状が1週間以上悪化する、高齢者・乳幼児・持病がある場合は受診してください。総合感冒薬と解熱剤を重ねると成分（アセトアミノフェンなど）が重複しやすい点も要注意です。

## 市販薬でできること・できないこと

| 項目 | 内容 |
|---|---|
| **風邪の原因** | **9割前後がウイルス**（ライノウイルス、コロナウイルス、RSウイルスなど**200種以上**）。細菌性は少数 |
| **抗生物質（抗菌薬）** | **ウイルスには効かない**。厚生労働省「抗微生物薬適正使用の手引き」は、**普通の風邪には抗菌薬を投与しないことを推奨**。不要な使用は**耐性菌**を増やす |
| **総合感冒薬（市販）** | 解熱鎮痛・鼻水・咳止めなど**複数成分の組み合わせ**。**症状を和らげる**が、治癒を早める根拠はない |
| **成分の重複** | 総合感冒薬＋解熱剤＋鎮痛剤を併用すると**アセトアミノフェン・イブプロフェンが重複**しやすい。市販薬のアセトアミノフェンは**1日900mgまで**が目安（製品表示に従う） |
| **経過** | 多くは**3〜7日**でピークを越え、**10日程度**で軽快。咳だけは**2〜3週間**残ることがある |
| **受診の目安** | **38.5℃以上が3日以上**、**息苦しさ・胸の痛み**、**水分が取れない**、**1週間以上たって悪化**、**強い頭痛・首の硬直**、**高齢者・乳幼児・妊婦・持病（糖尿病、心臓・肺・腎臓）** |

- **家でできること**：**睡眠と休養**、**水分**（湯・スープ・経口補水液。のどが痛ければ常温〜温かいもの）、**室内湿度40〜60%**、**のどの痛みにはハチミツ**（1歳以上）や**うがい**。
- **市販薬の選び方**：**つらい症状だけに効く単剤**（のど→鎮痛、鼻水→抗ヒスタミン、咳→鎮咳）を選ぶと、余分な成分と眠気を避けられます。薬剤師・登録販売者に症状を伝えて相談してください。
- **解熱剤の使い方**：**発熱自体は体の防御反応**。38.5℃を超えてつらい時、眠れない時に使うのが目安。**子どもにはアスピリン系は使わない**（ライ症候群の危険）。
- **インフルエンザ・新型コロナ**が疑われる場合（**急な高熱、強い倦怠感、関節痛、流行期、周囲に患者**）は、発症後**48時間以内**なら抗ウイルス薬の選択肢があるため、早めに受診する意味があります。
- **人にうつさない**：**マスク、手洗い、咳エチケット**。発熱・咳があるうちは出勤・登校を控えるのが今の日本の標準です。

> **【要検証】** 「抗微生物薬適正使用の手引き」の最新版（第三版、2023年）の記述と、市販アセトアミノフェンの用量上限は公開前に確認してください。

## 誤解1｜早めに抗生物質を飲めば早く治まる

**風邪の原因のほとんどはウイルスで、抗生物質は効きません。** 不要な使用は副作用と耐性菌のリスクだけを増やします。医師が処方しないのは正しい判断です。

## 誤解2｜市販の風邪薬を飲めば風邪が早く終わる

**市販薬は症状を和らげるだけ**で、風邪の期間は基本的に変わりません。「楽にして休む」ための道具です。

## 誤解3｜熱はすぐ下げた方がいい

**発熱は免疫が働いているサイン**で、無理に下げる必要はありません。つらい時・眠れない時に、用量を守って使う。

## 誤解4｜風邪薬と解熱剤を一緒に飲めばよく効く

**同じ成分が重複し、肝臓への負担や胃の副作用の危険**が上がります。併用は薬剤師に確認を。

## 誤解5｜1週間たっても治らないのは体力がないから

**1週間以上たって悪化、または高熱が続くなら、細菌性の副鼻腔炎・肺炎・別の病気の可能性**があります。受診の目安に当たるかを確認してください。
