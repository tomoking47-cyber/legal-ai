# Q. 「血糖値スパイク」って何？健診で正常でも気にした方がいい？｜世界の質問箱 #488

- 棚：`health` ／ URL：`/questions/post-meal-blood-sugar-spikes` ／ ステータス：**ドラフト（法務レビュー前・出典未検証）**

健康診断の空腹時血糖は正常なのに、食後だけ血糖が急上昇する——「血糖値スパイク（食後高血糖）」という言葉がテレビ番組を通じて日本で広く知られました。用語は俗称ですが、背景にある「食後高血糖」は医学的にも重要視されています。何を指し、誰が気にすべきかを整理します。

## A. 「血糖値スパイク」は医学用語ではなく、食後に血糖が140mg/dLを超えて急上昇し、その後急降下する状態を指す俗称です。空腹時血糖が正常でも食後高血糖が隠れている人はおり、糖尿病の前段階や血管への負担の指標になります。ただし健康な人でも食後に多少の上下はあり、「スパイク＝病気」ではありません。対策は野菜・たんぱく質から食べる、精製された炭水化物を減らす、食後に15分歩く、朝食を抜かない、の4つ。家族に糖尿病がいる、健診でHbA1cが5.6%以上、肥満、食後の強い眠気がある人は、医師に食後血糖の検査（75g糖負荷試験など）を相談する価値があります。

## 数字で見る食後血糖

| 項目 | 数値 |
|---|---|
| **正常な食後血糖** | 食後2時間で**140mg/dL未満** |
| **境界型（耐糖能異常）** | 75g糖負荷試験の2時間値**140〜199mg/dL** |
| **糖尿病型** | 2時間値**200mg/dL以上**、または空腹時**126mg/dL以上**、またはHbA1c **6.5%以上** |
| **HbA1c（過去1〜2か月の平均血糖の指標）** | **5.6%以上**で特定健診の保健指導対象、**6.0〜6.4%**は糖尿病が否定できない |
| **日本の糖尿病人口** | 「糖尿病が強く疑われる人」**約1,100万人**、「可能性を否定できない人」**約700万人**（国民健康・栄養調査 令和6年＝2024年、2025年12月公表） |
| **健診の落とし穴** | 特定健診は**空腹時血糖とHbA1cのみ**が多く、食後高血糖だけの人は**見逃されることがある** |

## 食後の血糖を穏やかにする方法（根拠のあるもの）

| 方法 | 内容 | 根拠の程度 |
|---|---|---|
| **食べる順番** | **野菜・きのこ・海藻 → 肉・魚・大豆 → ご飯・パン**。野菜を5分ほど先に | 日本の複数の臨床研究で食後血糖の上昇抑制を確認 |
| **食後の軽い運動** | 食後**15〜30分に10〜15分歩く** | 食後血糖の上昇を抑える報告が多い |
| **精製炭水化物を減らす** | 白米→玄米・雑穀混ぜ、菓子パン・清涼飲料を減らす | 食物繊維が糖の吸収を遅らせる |
| **朝食を抜かない** | 朝食を抜くと**昼食後の血糖上昇が大きくなる** | 日本人対象の研究あり |
| **よく噛む・ゆっくり** | **1食20分以上** | 早食いと糖尿病リスクの関連が報告されている |
| **睡眠** | **6時間未満**の睡眠は翌日のインスリンの働きを悪くする | 実験研究あり |

- **市販の血糖測定器・持続血糖測定（CGM）**：健康な人が自己判断で装着し、「スパイクがあった」と不安になるケースが増えています。**健康な人の食後の上下は正常な反応**であり、数値の解釈は医師と。
- **食後の強い眠気・だるさ**は食後高血糖の一つのサインとされますが、他の原因（睡眠不足、食べ過ぎ）でも起きます。
- **検査を相談する目安**：**HbA1c 5.6%以上**、**家族（親・兄弟）に糖尿病**、**BMI 25以上**、**妊娠糖尿病の経験**、**40歳以上で運動習慣なし**。

> **【要検証】** 診断基準の数値は日本糖尿病学会「糖尿病診療ガイドライン2024」および「糖尿病治療ガイド」で確認してください。糖尿病人口の推計は国民健康・栄養調査の最新年に更新を。

## 誤解1｜健診で血糖が正常なら糖尿病の心配はない

**空腹時血糖とHbA1cだけでは、食後高血糖のみの段階は見逃されることがあります。** リスクが高い人は糖負荷試験を医師に相談。

## 誤解2｜血糖値スパイクは病名

**俗称です。** 医学的には「食後高血糖」と言い、それ自体が病気ではなく、糖尿病や血管への負担の**指標**です。

## 誤解3｜炭水化物を完全に抜けばスパイクは起きない

**極端な糖質制限は長期の安全性が確立しておらず、日本糖尿病学会も推奨していません。** 量と質（精製度・食物繊維）と順番を変えるのが現実的です。

## 誤解4｜甘いものを食べなければ大丈夫

**白米・パン・麺・果物・清涼飲料も血糖を上げます。** 甘さではなく炭水化物の量と吸収の速さが決めます。

## 誤解5｜血糖測定器で自分の「スパイク」をチェックすれば安心

**健康な人でも食後の上下は普通に起き、数値だけで不安になる人が増えています。** 測るなら結果の解釈は医師と一緒に。
