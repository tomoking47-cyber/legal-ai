# Q. 什么是「血糖尖峰」？体检正常也需要在意吗？｜Japan Questions #488

- Shelf: `health` ／ URL: `/zh-cn/health/post-meal-blood-sugar-spikes` ／ Status: **草稿 — 出处未核实**

年度体检（健康診断，kenkō shindan——日本大多数上班族都会接受的检查）的空腹血糖正常，饭后血糖却急速上升。日本的电视节目让「血糖值尖峰」（血糖値スパイク，kettōchi supaiku）这个说法广为人知。这个词是俗称，但它背后的状态「餐后高血糖」在医学上同样受到重视。以下整理它指的是什么，以及谁应该留意。

## A. 「血糖尖峰」不是医学用语。它是一个俗称，指饭后血糖急速升到140mg/dL以上、随后又急速下降的状态。有些人空腹血糖正常，却隐藏着餐后高血糖，这是糖尿病前期以及血管负担的一个指标。但健康的人饭后也会有一定的起伏，「出现尖峰不等于疾病」。对策有四条：先吃蔬菜和蛋白质、减少精制碳水化合物、饭后走15分钟、不要不吃早餐。如果家里有糖尿病患者、体检时HbA1c在5.6%以上、肥胖，或饭后有强烈困意，那么值得向医生咨询餐后血糖的检查（例如75g口服葡萄糖耐量试验）。

## 用数字看餐后血糖

日本以mg/dL表示血糖（140mg/dL约为7.8mmol/L）。

| 项目 | 数值 |
|---|---|
| **正常的餐后血糖** | 饭后2小时**低于140mg/dL** |
| **临界型（糖耐量异常）** | 75g葡萄糖耐量试验的2小时值**140〜199mg/dL** |
| **糖尿病型** | 2小时值**200mg/dL以上**，或空腹**126mg/dL以上**，或HbA1c **6.5%以上** |
| **HbA1c（过去1〜2个月平均血糖的指标）** | **5.6%以上** 即成为特定健诊（特定健診，面向40〜74岁的代谢综合征体检）保健指导的对象；**6.0〜6.4%** 表示不能排除糖尿病 |
| **日本的糖尿病** | 「强烈怀疑患有糖尿病」的约**1000万**人，「不能排除」的约**1000万**人（2016年国民健康・营养调查） |
| **体检的盲点** | 特定健诊多数只测**空腹血糖和HbA1c**，因此仅有餐后高血糖的人**可能被漏掉** |

## 减缓餐后血糖上升的方法（有证据的）

| 方法 | 内容 | 证据强度 |
|---|---|---|
| **进食顺序** | **蔬菜、菌菇、海藻 → 肉、鱼、大豆 → 米饭、面包。** 先吃蔬菜，提前约5分钟开始 | 日本的多项临床研究确认餐后上升幅度更小 |
| **饭后的轻度运动** | **饭后15〜30分钟，走10〜15分钟** | 多份报告显示餐后上升幅度更小 |
| **减少精制碳水化合物** | 白米 → 糙米或杂粮；少吃甜面包和含糖饮料 | 膳食纤维减慢糖的吸收 |
| **不要不吃早餐** | 不吃早餐会**让午餐后的上升幅度更大** | 以日本人为对象的研究 |
| **细嚼慢咽** | **每餐20分钟以上** | 吃得快与糖尿病风险相关联 |
| **睡眠** | 睡眠**不足6小时**会让第二天胰岛素的作用变差 | 实验性研究 |

- **家用血糖仪与持续葡萄糖监测（CGM）**：越来越多健康的人自行佩戴，然后担心「我出现尖峰了」。**健康的人餐后的起伏是正常反应。** 请与医生一起解读数值。
- **饭后强烈的困意或身体发沉**，一般被说成是餐后高血糖的一个信号，但也可能出于其他原因（睡眠不足、吃得过多）。
- **咨询检查的参考条件**：**HbA1c 5.6%以上**、**父母或兄弟姐妹有糖尿病**、**BMI 25以上**、**有妊娠糖尿病史**、**40岁以上且没有运动习惯**。

## 误解1｜体检血糖正常，就不用担心糖尿病

**仅凭空腹血糖和HbA1c，可能漏掉只有餐后血糖偏高的阶段。** 风险高的人请向医生咨询葡萄糖耐量试验。

## 误解2｜血糖尖峰是一种病的名字

**它是俗称。** 医学上叫「餐后高血糖」，它本身不是疾病，而是糖尿病与血管负担的一个**指标**。

## 误解3｜彻底断掉碳水化合物就不会有尖峰

**极端限制碳水化合物的长期安全性尚未确立，日本糖尿病学会也不推荐。** 调整数量、质量（精制程度、纤维）和顺序才是现实的路径。

## 误解4｜只要不吃甜食就没问题

**白米饭、面包、面条、水果和含糖饮料同样会升高血糖。** 关键不在甜不甜，而在碳水化合物的量和吸收的快慢。

## 误解5｜用血糖仪自己查「尖峰」能让人安心

**健康的人饭后也有正常的起伏，只看数字反而让越来越多人焦虑。** 如果测量，请与医生一起解读结果。
