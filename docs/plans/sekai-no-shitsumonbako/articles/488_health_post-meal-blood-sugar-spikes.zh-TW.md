# Q. 什麼是「血糖尖峰」？健檢正常也需要在意嗎？｜Japan Questions #488

- Shelf: `health` ／ URL: `/zh-tw/health/post-meal-blood-sugar-spikes` ／ Status: **草稿 — 出處未核實**

年度健檢（健康診断，kenkō shindan——日本多數上班族都會接受的檢查）的空腹血糖正常，飯後血糖卻急速上升。日本的電視節目讓「血糖值尖峰」（血糖値スパイク，kettōchi supaiku）這個說法廣為人知。這個詞是俗稱，但它背後的狀態「餐後高血糖」在醫學上同樣受到重視。以下整理它指的是什麼，以及誰該留意。

## A. 「血糖尖峰」不是醫學用語。它是俗稱，指飯後血糖急速升到140mg/dL以上、隨後又急速下降的狀態。有些人空腹血糖正常，卻隱藏著餐後高血糖，這是糖尿病前期以及血管負擔的一項指標。但健康的人飯後也會有一定的起伏，「出現尖峰不等於生病」。對策有四項：先吃蔬菜與蛋白質、減少精製碳水化合物、飯後走15分鐘、不要不吃早餐。若家人有糖尿病、健檢時HbA1c在5.6%以上、肥胖，或飯後有強烈睡意，就值得向醫師諮詢餐後血糖的檢查（例如75g口服葡萄糖耐量試驗）。

## 用數字看餐後血糖

日本以mg/dL表示血糖（140mg/dL約為7.8mmol/L）。

| 項目 | 數值 |
|---|---|
| **正常的餐後血糖** | 飯後2小時**低於140mg/dL** |
| **臨界型（葡萄糖耐受不良）** | 75g葡萄糖耐量試驗的2小時值**140〜199mg/dL** |
| **糖尿病型** | 2小時值**200mg/dL以上**，或空腹**126mg/dL以上**，或HbA1c **6.5%以上** |
| **HbA1c（過去1〜2個月平均血糖的指標）** | **5.6%以上** 即成為特定健診（特定健診，針對40〜74歲的代謝症候群健檢）保健指導的對象；**6.0〜6.4%** 表示無法排除糖尿病 |
| **日本的糖尿病** | 「強烈懷疑罹患糖尿病」者約**1000萬**人，「無法排除」者約**1000萬**人（2016年國民健康・營養調查） |
| **健檢的盲點** | 特定健診多半只測**空腹血糖與HbA1c**，因此只有餐後高血糖的人**可能被漏掉** |

## 減緩餐後血糖上升的方法（有證據的）

| 方法 | 內容 | 證據強度 |
|---|---|---|
| **進食順序** | **蔬菜、菇類、海藻 → 肉、魚、大豆 → 白飯、麵包。** 先吃蔬菜，提早約5分鐘開始 | 日本的多項臨床研究確認餐後上升幅度較小 |
| **飯後的輕度運動** | **飯後15〜30分鐘，走10〜15分鐘** | 多份報告顯示餐後上升幅度較小 |
| **減少精製碳水化合物** | 白米 → 糙米或雜糧；少吃甜麵包與含糖飲料 | 膳食纖維減緩糖的吸收 |
| **不要不吃早餐** | 不吃早餐會**讓午餐後的上升幅度更大** | 以日本人為對象的研究 |
| **細嚼慢嚥** | **每餐20分鐘以上** | 吃得快與糖尿病風險有關聯 |
| **睡眠** | 睡眠**不足6小時**會讓隔天胰島素的作用變差 | 實驗性研究 |

- **家用血糖機與連續血糖監測（CGM）**：越來越多健康的人自行配戴，然後擔心「我出現尖峰了」。**健康的人餐後的起伏是正常反應。** 請和醫師一起解讀數值。
- **飯後強烈的睡意或身體沉重**，一般被說成是餐後高血糖的一個訊號，但也可能出於其他原因（睡眠不足、吃太多）。
- **諮詢檢查的參考條件**：**HbA1c 5.6%以上**、**父母或兄弟姊妹有糖尿病**、**BMI 25以上**、**有妊娠糖尿病病史**、**40歲以上且沒有運動習慣**。

> **[待核實]** 請對照日本糖尿病學會《糖尿病診療指引2024》[糖尿病診療ガイドライン2024] 及其《糖尿病治療指引手冊》[糖尿病治療ガイド] 核對診斷閾值。糖尿病人數的推估請更新為最新的國民健康・營養調查。

## 誤解1｜健檢血糖正常，就不用擔心糖尿病

**只憑空腹血糖與HbA1c，可能漏掉只有餐後血糖偏高的階段。** 風險高的人請向醫師諮詢葡萄糖耐量試驗。

## 誤解2｜血糖尖峰是一種病名

**它是俗稱。** 醫學上叫「餐後高血糖」，它本身不是疾病，而是糖尿病與血管負擔的一項**指標**。

## 誤解3｜完全戒掉碳水化合物就不會有尖峰

**極端限制碳水化合物的長期安全性尚未確立，日本糖尿病學會也不建議。** 調整份量、品質（精製程度、纖維）與順序才是務實的路徑。

## 誤解4｜只要不吃甜食就沒問題

**白飯、麵包、麵條、水果與含糖飲料同樣會升高血糖。** 關鍵不在甜不甜，而在碳水化合物的量與吸收的快慢。

## 誤解5｜用血糖機自己查「尖峰」會讓人安心

**健康的人飯後也有正常的起伏，光看數字反而讓越來越多人焦慮。** 若要測量，請和醫師一起解讀結果。
