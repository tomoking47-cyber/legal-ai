# Q. 歩数より「歩く速さ」が大事って本当？どのくらいの速さが目安？｜世界の質問箱 #490

- 棚：`health` ／ URL：`/questions/walking-speed-and-health` ／ ステータス：**ドラフト（法務レビュー前・出典未検証）**

「1日1万歩」から「速歩き20分」へ——日本の健康づくりの指標は、歩数だけでなく「強度」を重視する方向に変わってきました。厚生労働省の2023年のガイドでも、歩行に加えて「息が弾む程度の運動」を求めています。「速く歩く」とは、何をどのくらい速くすることなのかを数値で整理します。

## A. 目安は「隣の人と会話はできるが、歌は歌えない」「少し息が上がる」速さで、1分間に100歩前後、時速5〜6km、運動強度で3.5〜4メッツ程度。厚生労働省の「身体活動・運動ガイド2023」は、成人に「1日60分以上（約8,000歩）の歩行以上の活動」に加えて「週60分以上の息が弾む運動」を推奨しています。群馬県中之条町の高齢者調査では「1日8,000歩、うち中強度（速歩き）20分」が、多くの病気の予防と関連する目安として示されました。速歩きは同じ歩数の普通歩行より心肺と血管への効果が大きく、死亡率の低下との関連も海外の大規模研究で報告されています。

## 「速歩き」の目安と根拠

| 項目 | 数値・内容 |
|---|---|
| **速さの目安** | **1分間に100〜110歩**、**時速5〜6km**、**3.5〜4メッツ**（安静時の3.5〜4倍のエネルギー消費） |
| **体感** | 「**会話はできるが、歌えない**」「少し息が上がる」「軽く汗ばむ」 |
| **国のガイド（2023年）** | 成人：**歩行以上の身体活動を1日60分以上（約8,000歩）**＋**息が弾み汗をかく運動を週60分以上**＋**筋トレ週2〜3日**。高齢者：**1日40分以上（約6,000歩）**＋多要素の運動週3日 |
| **中之条研究（群馬県中之条町、65歳以上5,000人、2000年〜）** | **8,000歩／中強度20分**：高血圧・糖尿病・脂質異常症・メタボの予防と関連。**5,000歩／7.5分**：要支援・要介護・認知症・心疾患・脳卒中の予防と関連。**1万2,000歩／40分以上は効果が頭打ち** |
| **海外の大規模研究** | 英国約5万人の追跡（Stamatakis ら、2018年）：**ゆっくり歩く人に比べ、普通の速さで歩く人は全死亡リスクが約20%、速歩きの人は約24%低い**。60歳以上では心血管死のリスクが**普通の速さで約46%、速歩きで約53%低い** |
| **歩幅** | **身長×0.45**程度が速歩きの目安（身長160cmなら約72cm）。歩幅を広げると自然に速くなる |

- **速歩きのフォーム**：**背筋を伸ばし、目線は10〜15m先**、**腕を後ろに引く**意識、**かかとから着地してつま先で蹴る**。歩幅を広げることを意識すると、腕も自然に振れます。
- **時間の分割**：**10分×2回でも合計20分で効果**は変わらないとされます。通勤の駅一つ分、昼休みの10分、で達成できます。
- **計測**：スマートフォンの歩数計は**「歩数」だけでなく「歩行速度」や「ケイデンス（歩／分）」**を表示するアプリが増えています。腕時計型なら**心拍数が最大心拍（220−年齢）の60〜70%**が中強度の目安。
- **注意**：**膝・足首に痛みがある、心臓の病気、高血圧の治療中**の人は、速さを上げる前に医師に相談。**夏は熱中症**、**朝晩の暗い時間は反射材**。
- **「1日1万歩」との関係**：1万歩は否定されたわけではなく、「**歩数の目標の中に、20分の速歩きを含める**」のが現在の考え方。8,000歩＋速歩き20分は「1万歩ゆっくり」より効果が高いとされます。

> **【要検証】** 中之条研究の数値（8,000歩／20分）は東京都健康長寿医療センターの公表資料で、国のガイドの数値は「健康づくりのための身体活動・運動ガイド2023」で確認してください。Stamatakis ら（Br J Sports Med 2018）の数値は原著で確認を。

## 誤解1｜歩数が多いほど健康になる

**歩数だけで強度が低いと、心肺・血管への効果は限定的**です。8,000歩に速歩き20分を含めるのが根拠のある目安。

## 誤解2｜速歩きは走るくらい速く

**「会話はできるが歌えない」程度で十分**です。走る必要はなく、息が上がり過ぎる速さは続きません。

## 誤解3｜毎日1万2,000歩以上歩けばさらに良い

**中之条研究では1万2,000歩・40分以上で効果が頭打ち**とされ、膝や足への負担が増えます。適量があります。

## 誤解4｜20分続けて歩かないと意味がない

**10分×2回でも合計時間で効果は同等**とされています。細切れで積み上げてください。

## 誤解5｜高齢者は無理せずゆっくり歩けばいい

**高齢者も「1日6,000歩、うち少し息が上がる歩行」が要介護予防と関連**しています。ただし膝・心臓に問題があれば医師に相談し、速さは徐々に。
