# Q. カビが生えた食品、カビの部分だけ取れば食べられる？｜世界の質問箱 #492

- 棚：`trend` ／ URL：`/questions/mouldy-food-what-to-discard` ／ ステータス：**ドラフト（法務レビュー前・出典未検証）**

パンの端に緑の点、みかんに白いふわふわ、チーズに青い斑点。「もったいないから、そこだけ取って」と思うのは自然ですが、カビは見えている部分より広く根（菌糸）を伸ばしています。加熱で壊れない「カビ毒」を作る種類もあり、「見た目で取れば安全」とは言えません。食品ごとに判断を分けます。

## A. 原則は「柔らかい食品・水分の多い食品は、カビが少しでも生えたら全部捨てる」。パン、ご飯、果物（いちご・桃・みかん）、ジャム、ヨーグルト、豆腐、ハム、ナッツ、調理済みのおかずが該当します。カビの菌糸は見えないところまで入り込み、水分が多いほど広がりが速いからです。例外的に、硬いチーズ・硬い野菜（にんじん・キャベツの外葉）・干し物は、カビの部分から2.5cm以上を大きく切り落とせば食べられる、というのが米国農務省などの整理。ナッツ・穀類・香辛料のカビは発がん性のあるアフラトキシンを作ることがあり、加熱でも壊れないため必ず廃棄します。

## 食品別の判断

| 食品 | カビが生えたら | 理由 |
|---|---|---|
| **パン、ご飯、もち、麺** | **全部捨てる**（袋の中の他のパンも） | 多孔質で菌糸が内部に広がる。胞子が袋内に飛んでいる |
| **果物（柔らかい）：いちご、桃、ぶどう、みかん** | **その1個を捨て、接していた周りも確認**。傷んでいれば捨てる | 水分が多く広がりが速い。みかんは1個から箱全体に移る |
| **果物・野菜（硬い）：にんじん、キャベツ、ピーマン、りんご** | **カビの部分から2.5cm以上大きく切り落とせば可** | 密度が高く菌糸が入りにくい |
| **ジャム、はちみつ以外の甘いもの、ソース類** | **全部捨てる**（スプーンでカビだけ取るのは不可） | 液体中に毒素が広がる可能性 |
| **チーズ（硬い：パルメザン、チェダー）** | **カビの部分から2.5cm以上切り落とせば可**。ナイフをカビに触れさせない | 硬く菌糸が入りにくい |
| **チーズ（柔らかい：カッテージ、クリーム、スライス）** | **全部捨てる** | 水分が多い |
| **ブルーチーズ・カマンベール** | **本来の青カビ・白カビは食用**。それ以外の色（黒・ピンク・緑の綿毛）は捨てる | 意図した菌以外は別物 |
| **ハム、ベーコン、ソーセージ、調理済みおかず** | **全部捨てる** | 水分・栄養が多く危険 |
| **ナッツ、穀類、豆、香辛料、乾燥果物** | **全部捨てる** | **アフラトキシン**（強い発がん性、**加熱で壊れない**）を作るカビが生えやすい |
| **みそ・しょうゆの表面の白い膜** | **白い膜（産膜酵母）は取れば可**。青・黒・綿毛のカビは捨てる | 産膜酵母は無害。見分けが付かなければ廃棄 |

- **カビ毒（マイコトキシン）**：カビが作る有害な代謝物で、**300種以上**が知られています。代表が**アフラトキシン**（ナッツ・穀類）、**パツリン**（傷んだりんごのジュース）、**デオキシニバレノール**（麦）。**通常の加熱では分解されない**ため、「焼けば大丈夫」は成り立ちません。
- **冷蔵庫でもカビは生えます**（低温でゆっくり増える）。**冷凍庫（−18℃）では増えない**が、死ぬわけでもない。
- **予防**：**パンは3日以上なら冷凍**、**果物は傷んだものを取り除いてから保存**、**開封した瓶詰め・ジャムは清潔なスプーンで取り分けて冷蔵**、**冷蔵庫の中は詰め込み過ぎず、月1回拭く**。
- **カビを嗅がない**：胞子を吸い込むとアレルギー症状の原因になり得ます。袋ごと密閉して捨てる。
- **食べてしまったら**：健康な人が少量食べた場合、多くは問題を起こしません。**吐き気・下痢・アレルギー症状**が出たら受診。**乳幼児・高齢者・免疫が低下している人**は注意。

> **【要検証】** 「2.5cm（1インチ）」の目安は米国農務省（USDA FSIS）の資料に基づきます。かび毒の種類・加熱安定性は農林水産省の「食品中のかび毒」ページで確認してください。

## 誤解1｜カビの部分だけ取れば大丈夫

**柔らかい食品では菌糸が見えない部分に広がっています。** 硬いチーズ・硬い野菜以外は全部捨てるのが原則。

## 誤解2｜加熱すればカビ毒も消える

**主なかび毒は加熱で分解されません。** ナッツ・穀類のカビは特に危険で、加熱しても食べられません。

## 誤解3｜冷蔵庫に入れていればカビは生えない

**冷蔵でもゆっくり生えます。** 長期保存は冷凍を。

## 誤解4｜みそに白いものが浮いていたら捨てる

**表面の白い膜は産膜酵母で、取り除けば問題ありません。** 青・黒・綿毛状のカビとの見分けが付かない場合は廃棄を。

## 誤解5｜ブルーチーズを食べているから、他のカビも平気

**食用のカビは選ばれた特定の菌株**です。自然に生えたカビはまったく別物で、毒素を作る種類が含まれます。
