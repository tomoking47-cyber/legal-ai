# Q. 食物长霉了，把发霉的部分切掉，剩下的还能吃吗？｜Japan Questions #492

- Shelf: `trend` ／ URL: `/zh-cn/trend/mouldy-food-what-to-discard` ／ Status: **草稿 — 出处未核实**

面包边上的绿点、蜜柑（日本柑橘）上的白色绒毛、奶酪上的蓝斑。会想「太浪费了，把那一块切掉就好」是很自然的，但霉菌的菌丝会伸展到你看得见的范围之外。有些种类还会产生加热也不会消失的「霉菌毒素」，所以「把看得见的切掉就安全」并不成立。这里我们按食物逐一来看。

## A. 原则是：**柔软或含水量高的食物，一旦发霉就整份丢弃。** 这包括面包、米饭、水果（草莓、桃子、蜜柑）、果酱、酸奶、豆腐、火腿、坚果和做好的配菜。霉菌菌丝会伸进你看不见的地方，水分越多蔓延越快。例外是硬质奶酪、质地硬的蔬菜（胡萝卜、卷心菜的外层叶）和干货：据美国农业部等的说明，这些在霉斑周围留出至少 2.5 厘米的余量切除后可以食用。坚果、谷物和香辛料上的霉菌可能产生黄曲霉毒素，那是一种加热也无法破坏的致癌物质，所以这些必须一律丢弃。

## 按食物分类

| 食物 | 长霉了怎么办 | 原因 |
|---|---|---|
| **面包、米饭、年糕、面条** | **全部丢弃**（包括袋子里的其他片） | 多孔，菌丝会在内部蔓延。孢子已经散布到袋子里 |
| **软质水果：草莓、桃子、葡萄、蜜柑** | **丢弃那一个，并检查与它接触的那些**。有损伤的也丢弃 | 水分多，霉菌蔓延快。一个蜜柑能传染整箱 |
| **质地硬的果蔬：胡萝卜、卷心菜、彩椒、苹果** | **在霉斑周围切除至少 2.5 厘米即可食用** | 组织致密，菌丝渗透较少 |
| **果酱、蜂蜜以外的甜抹酱、酱汁** | **全部丢弃**（用勺子把霉舀掉是不够的） | 毒素可能已扩散到液体中 |
| **硬质奶酪（帕玛森、切达）** | **在霉斑周围切除至少 2.5 厘米即可食用**。不要让刀碰到霉 | 质地硬，菌丝渗透较少 |
| **软质奶酪（茅屋、奶油奶酪、切片）** | **全部丢弃** | 水分多 |
| **蓝纹奶酪、卡门贝尔** | **作为工艺一部分的蓝霉或白霉可以食用**。若出现其他颜色（黑色、粉红色、绿色绒毛）则丢弃 | 工艺菌种以外的都是不同的生物 |
| **火腿、培根、香肠、做好的配菜** | **全部丢弃** | 水分和养分都多，危险 |
| **坚果、谷物、豆类、香辛料、干果** | **全部丢弃** | 容易长出产生**黄曲霉毒素**的霉（**强致癌性**，**加热无法破坏**） |
| **味噌或酱油表面的白膜** | **白色的膜（产膜酵母）可以去掉后继续使用**。若是蓝色、黑色或绒毛状的霉则丢弃 | 产膜酵母无害。若分辨不出来就丢弃 |

- **霉菌毒素（真菌毒素）**：霉菌产生的有害物质，已知**300 多种**。主要有**黄曲霉毒素**（坚果、谷物）、**展青霉素**（受损苹果榨的果汁）和**脱氧雪腐镰刀菌烯醇**（小麦、大麦）。**普通烹调不会将其分解**，所以「烤过就没事」并不成立。
- **冰箱里霉菌也会长**（低温下长得慢）。**在冷冻室（−18℃）不会生长**，但也不会死。
- **预防**：**面包如果 3 天内吃不完就冷冻**；**保存前先把有损伤的水果挑出来**；**果酱等开封后的瓶罐要用干净的勺子取用并冷藏**；**冰箱不要塞太满，每月擦一次内部**。
- **不要凑近闻霉**：吸入孢子可能引发过敏症状。请密封在袋子里再丢弃。
- **如果已经吃了**：健康的人吃了少量通常不会有问题。若出现**恶心、腹泻或过敏症状**请就医。**婴幼儿、老年人和免疫力低下的人**要格外注意。

> **[待核实]**「2.5 厘米（1 英寸）」这一标准依据美国农业部（USDA FSIS）的资料。霉菌毒素的种类及其耐热性请对照农林水产省《食品中的霉菌毒素》页面核实。

## 误解1｜把发霉的部分切掉就够了

**在柔软的食物中，菌丝已经蔓延到你看不见的部分。** 除硬质奶酪和质地硬的蔬菜外，原则是整份丢弃。

## 误解2｜加热也能破坏霉菌毒素

**主要的霉菌毒素不会被热分解。** 坚果和谷物上的霉尤其危险，加热并不能让它们变得可以吃。

## 误解3｜放冰箱里的食物不会发霉

**在冰箱里它仍然会长，只是慢一些。** 要长期保存请冷冻。

## 误解4｜味噌上浮着白色的东西，就该扔掉

**表面的白膜是产膜酵母，去掉之后味噌仍可食用。** 若无法与蓝色、黑色或绒毛状的霉区分，则丢弃。

## 误解5｜我吃蓝纹奶酪，所以别的霉也伤不了我

**可食用的霉是特定的、经过筛选的菌株。** 自然长出来的霉完全是另一回事，其中包括产毒素的种类。
