# Q. 食物發霉了，把發霉的部分切掉，剩下的還能吃嗎？｜Japan Questions #492

- Shelf: `trend` ／ URL: `/zh-tw/trend/mouldy-food-what-to-discard` ／ Status: **草稿 — 出處未核實**

吐司邊上的綠點、蜜柑（日本橘子）上的白色絨毛、起司上的藍斑。會想「太浪費了，把那一塊切掉就好」是很自然的，但黴菌的菌絲會延伸到你看得見的範圍之外。有些種類還會產生加熱也不會消失的「黴菌毒素」，所以「把看得見的切掉就安全」並不成立。這裡我們按食物逐一來看。

## A. 原則是：**柔軟或含水量高的食物，一旦發霉就整份丟棄。** 這包括麵包、白飯、水果（草莓、水蜜桃、蜜柑）、果醬、優格、豆腐、火腿、堅果與做好的配菜。黴菌菌絲會伸進你看不見的地方，水分越多蔓延越快。例外是硬質起司、質地硬的蔬菜（紅蘿蔔、高麗菜的外層葉）與乾貨：據美國農業部等的說明，這些在黴斑周圍留出至少 2.5 公分的餘量切除後可以食用。堅果、穀物與辛香料上的黴菌可能產生黃麴毒素，那是一種加熱也無法破壞的致癌物質，所以這些必須一律丟棄。

## 按食物分類

| 食物 | 發霉了怎麼辦 | 原因 |
|---|---|---|
| **麵包、白飯、麻糬、麵條** | **全部丟棄**（包括袋子裡的其他片） | 多孔，菌絲會在內部蔓延。孢子已經散布到袋子裡 |
| **軟質水果：草莓、水蜜桃、葡萄、蜜柑** | **丟棄那一顆，並檢查與它接觸的那些**。有損傷的也丟棄 | 水分多，黴菌蔓延快。一顆蜜柑能傳染整箱 |
| **質地硬的蔬果：紅蘿蔔、高麗菜、甜椒、蘋果** | **在黴斑周圍切除至少 2.5 公分即可食用** | 組織緻密，菌絲滲透較少 |
| **果醬、蜂蜜以外的甜抹醬、醬汁** | **全部丟棄**（用湯匙把黴舀掉是不夠的） | 毒素可能已擴散到液體中 |
| **硬質起司（帕瑪森、切達）** | **在黴斑周圍切除至少 2.5 公分即可食用**。不要讓刀碰到黴 | 質地硬，菌絲滲透較少 |
| **軟質起司（茅屋、奶油起司、切片）** | **全部丟棄** | 水分多 |
| **藍紋起司、卡門貝爾** | **作為工藝一部分的藍黴或白黴可以食用**。若出現其他顏色（黑色、粉紅色、綠色絨毛）則丟棄 | 工藝菌種以外的都是不同的生物 |
| **火腿、培根、香腸、做好的配菜** | **全部丟棄** | 水分與養分都多，危險 |
| **堅果、穀物、豆類、辛香料、果乾** | **全部丟棄** | 容易長出產生**黃麴毒素**的黴（**強致癌性**，**加熱無法破壞**） |
| **味噌或醬油表面的白膜** | **白色的膜（產膜酵母）可以去掉後繼續使用**。若是藍色、黑色或絨毛狀的黴則丟棄 | 產膜酵母無害。若分辨不出來就丟棄 |

- **黴菌毒素（真菌毒素）**：黴菌產生的有害物質，已知**300 多種**。主要有**黃麴毒素**（堅果、穀物）、**展青黴素**（受損蘋果榨的果汁）與**去氧雪腐鐮刀菌烯醇**（小麥、大麥）。**一般烹調不會將其分解**，所以「烤過就沒事」並不成立。
- **冰箱裡黴菌也會長**（低溫下長得慢）。**在冷凍庫（−18℃）不會生長**，但也不會死。
- **預防**：**麵包如果 3 天內吃不完就冷凍**；**保存前先把有損傷的水果挑出來**；**果醬等開封後的瓶罐要用乾淨的湯匙取用並冷藏**；**冰箱不要塞太滿，每月擦一次內部**。
- **不要湊近聞黴**：吸入孢子可能引發過敏症狀。請密封在袋子裡再丟棄。
- **如果已經吃了**：健康的人吃了少量通常不會有問題。若出現**噁心、腹瀉或過敏症狀**請就醫。**嬰幼兒、年長者與免疫力低下的人**要格外注意。

> **[待核實]**「2.5 公分（1 英吋）」這一標準依據美國農業部（USDA FSIS）的資料。黴菌毒素的種類及其耐熱性請對照農林水產省《食品中的黴菌毒素》頁面核實。

## 誤解1｜把發霉的部分切掉就夠了

**在柔軟的食物中，菌絲已經蔓延到你看不見的部分。** 除硬質起司與質地硬的蔬菜外，原則是整份丟棄。

## 誤解2｜加熱也能破壞黴菌毒素

**主要的黴菌毒素不會被熱分解。** 堅果與穀物上的黴尤其危險，加熱並不能讓它們變得可以吃。

## 誤解3｜放冰箱裡的食物不會發霉

**在冰箱裡它仍然會長，只是慢一些。** 要長期保存請冷凍。

## 誤解4｜味噌上浮著白色的東西，就該丟掉

**表面的白膜是產膜酵母，去掉之後味噌仍可食用。** 若無法與藍色、黑色或絨毛狀的黴區分，則丟棄。

## 誤解5｜我吃藍紋起司，所以別的黴也傷不了我

**可食用的黴是特定的、經過篩選的菌株。** 自然長出來的黴完全是另一回事，其中包括產毒素的種類。
