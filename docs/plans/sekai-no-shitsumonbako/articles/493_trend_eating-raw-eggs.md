# Q. 卵かけご飯やすき焼きの生卵、日本では安全？海外の人が驚く理由｜世界の質問箱 #493

- 棚：`trend` ／ URL：`/questions/eating-raw-eggs` ／ ステータス：**ドラフト（法務レビュー前・出典未検証）**

卵かけご飯、すき焼きの溶き卵、月見うどん。日本では生卵を食べる文化が根付いていますが、海外の多くの国では「生卵は危険」が常識です。日本で生食が成り立っている理由と、それでも守るべき条件を整理します。

## A. 日本の卵は「生で食べること」を前提に、農場での衛生管理と、出荷施設（GPセンター）での洗浄・殺菌・検卵が制度化されており、賞味期限も「生で安全に食べられる期限」として設定されています。それでも条件があります。賞味期限内で、殻にひびがなく、冷蔵（10℃以下）で保存されたものを、割ったらすぐ食べる。割ったまま置く「割り置き」は厳禁。賞味期限を過ぎた卵は加熱（70℃1分以上、または黄身も白身も固まるまで）して食べる。2歳以下の乳幼児、高齢者、妊娠中の人、免疫が低下している人は、生食を避けるのが厚生労働省の姿勢です。

## 日本の卵が生食できる仕組み

| 項目 | 内容 |
|---|---|
| **主なリスク** | **サルモネラ属菌**（とくにサルモネラ・エンテリティディス）。**殻の表面**と、まれに**卵の中**に存在 |
| **農場での対策** | 親鶏のワクチン接種、鶏舎の衛生管理、ネズミ対策 |
| **GPセンター（洗卵選別包装施設）** | **洗浄・殺菌（次亜塩素酸ナトリウムなど）**、**検卵（ひび・血卵の除去）**、**パック詰め**。1998年11月の食品衛生法施行規則等の改正（1999年11月施行）で**卵の表示（生食できる賞味期限・保存方法・加熱の注意）が義務化** |
| **賞味期限の考え方** | 「**生で食べられる期限**」。サルモネラが増え始めるまでの日数を温度別に計算した理論値（**夏期16日、春秋25日、冬期57日**）を基に、多くは**パック後2週間程度**で設定 |
| **保存** | **10℃以下で冷蔵**。**冷蔵庫の扉ではなく庫内**へ（温度変化が小さい）。**とがった方を下**に |
| **賞味期限後** | **加熱（中心70℃で1分以上、または黄身・白身が固まるまで）**して食べる。生食はしない |
| **割ったら** | **すぐ食べる**。**割り置き（溶いた卵を常温で置く）は厳禁**。殻に触れた手で他の食材を触らない |

- **世界との違い**：**米国は洗卵と冷蔵を義務化**、**EUは洗卵しない代わりに親鶏のワクチンを重視し、常温で売る店も多い**、といった違いがあり、**「生食を前提に賞味期限を設定」している国は少数**。海外で日本と同じように生卵を食べるのは避けた方が無難です。
- **食中毒の実態**：サルモネラ食中毒は1990年代に年間**数百件・患者1万人超**の年もありましたが、GPセンターの整備と表示義務化以降**大幅に減少**。現在は年間**20〜30件前後**で、多くは**加熱不足の料理・割り置き・ひび卵**が原因。
- **ひび卵**：殻にひびがあると菌が入りやすい。**買った時点でひびがあるものは生食しない**。
- **生食を避けるべき人**：**2歳以下の乳幼児、高齢者、妊娠中、免疫が低下している人**（厚生労働省）。これらの人には**しっかり加熱した卵料理**を。
- **すき焼きの溶き卵**：**個人ごとに割り、食べる直前に**。長時間テーブルに置いた溶き卵は菌が増えます。
- **温泉卵・半熟卵**：中心温度が70℃に達していないため**「加熱済み」とは言えず、生食に準じた扱い**（賞味期限内・冷蔵・すぐ食べる）が必要。

> **【要検証】** 賞味期限の理論値（夏期16日等）は日本卵業協会の説明に基づく数値で、サルモネラ食中毒の件数は厚生労働省食中毒統計の最新年に更新してください。

## 誤解1｜日本の卵なら生でも心配いらない

**制度によってリスクは大きく下がっていますが、ゼロではありません。** 賞味期限内・ひびなし・冷蔵・すぐ食べる、の条件がそろって初めて成り立ちます。

## 誤解2｜賞味期限は「おいしさ」の目安だから過ぎても生で食べられる

**卵の賞味期限は「生で安全に食べられる期限」**として設定されています。過ぎたら加熱して食べる。

## 誤解3｜溶き卵は作っておいて後で使えばいい

**割った卵は殻の菌が中に入り、常温で急速に増えます。** 割り置きは食中毒の典型原因。使う直前に割る。

## 誤解4｜海外でも日本と同じように卵かけご飯を食べられる

**海外の卵は生食を前提に流通していない**ことが多く、避けた方が無難です。

## 誤解5｜子どもにも早くから生卵を

**2歳以下の乳幼児には生卵（うずら卵を含む）を避ける**よう厚生労働省が案内しています。加熱した卵料理から。
