# Q. カレーやシチューは一晩置いた方がおいしい？常温放置は危ない？｜世界の質問箱 #495

- 棚：`trend` ／ URL：`/questions/storing-curry-and-stews` ／ ステータス：**ドラフト（法務レビュー前・出典未検証）**

「カレーは二日目がおいしい」は日本の家庭の常識ですが、「鍋のまま一晩コンロに置いておく」習慣は、食中毒の原因として毎年のように注意喚起されています。原因はウェルシュ菌。加熱しても死なず、大鍋の中でゆっくり冷める間に増える菌です。おいしさと安全を両立する保存の手順を整理します。

## A. カレー・シチュー・煮物を作ったら、「粗熱を取るために鍋のまま放置」は避け、調理後2時間以内に小分けして急冷し、冷蔵庫へ。ウェルシュ菌の芽胞は100℃でも死なず、鍋の中が冷める12〜50℃の間で活発に増えます（最適温度43〜47℃で10分に1回分裂）。しかも酸素を嫌うため、大鍋の底は理想的な環境です。翌日食べるときは、よくかき混ぜながら中心まで沸騰させる（75℃以上で1分以上）。冷蔵で2〜3日、冷凍で1か月が目安。じゃがいも・にんじんは冷凍で食感が悪くなるので取り除くか潰します。

## ウェルシュ菌とカレーの関係

| 項目 | 内容 |
|---|---|
| **菌の正体** | **ウェルシュ菌**（クロストリジウム・パーフリンジェンス）。**土・水・人や動物の腸**に広く存在し、**肉・魚・野菜**に付いてくる |
| **なぜ加熱で死なないか** | **芽胞**（熱に強い殻）を作り、**100℃で数時間加熱しても生き残る**。加熱後に鍋が冷める過程で芽胞から発芽して増殖 |
| **増える温度** | **12〜50℃**。**最適は43〜47℃**で、**約10分に1回分裂**（一晩で数百万倍） |
| **酸素** | **酸素を嫌う（嫌気性）**。とろみのある大鍋の底・中心は酸素が届かず、菌にとって好条件 |
| **症状** | 食後**6〜18時間**で**腹痛・下痢**。発熱・嘔吐は少なく、多くは**1〜2日で回復**。ただし高齢者・子どもは脱水に注意 |
| **統計** | 国内で**年間20〜30件前後**の食中毒事件、**患者数は1,000〜2,000人**。**1件あたりの患者が多い**（給食・仕出し・イベントの大鍋調理）。「**給食病**」とも呼ばれる |

## 安全な保存の手順

1. **調理後2時間以内に、粗熱を取って冷蔵庫へ**。「粗熱を取る」は放置ではなく、**急冷**：
   - **小分け**（浅い容器・保存袋に薄く）→ **鍋底を氷水に当てる**、**保冷剤を鍋の周りに** → **かき混ぜて空気を入れながら冷ます**。
   - 目安：**20℃以下に2時間以内、10℃以下に4時間以内**。
2. **冷蔵（10℃以下）で2〜3日**、**冷凍（−18℃以下）で1か月**。
3. **食べる前の再加熱**：**鍋に移し、よくかき混ぜながら中心まで沸騰**（**75℃以上で1分以上**）。電子レンジは加熱ムラが出るため、**途中でかき混ぜて再加熱**。
4. **食べる分だけ温める**。何度も温め直すほど菌は増えやすい。

- **冷凍の注意**：**じゃがいも・にんじん**は解凍で水分が抜けてスカスカに。**取り除くか、潰してから**冷凍。**ルウのカレーは1か月、生クリーム系のシチューは2〜3週間**が目安。
- **「二日目がおいしい」の科学**：一晩置くと**具材のうま味と水分がルウに移り、でんぷんの糊化が進んでとろみと一体感が増す**ため。これは**冷蔵庫で冷やしても同じ**に起きます。常温で置く必要はありません。
- **夏場（室温25℃以上）**は特に危険。**エアコンのない台所の一晩は、菌にとって最適温度が長く続く**時間です。
- **カレー以外も同じ**：**シチュー、煮物、スープ、麻婆豆腐、肉じゃが、炊き込みご飯**など、大量に作って冷めにくいものすべて。

> **【要検証】** ウェルシュ菌の分裂速度・食中毒統計は厚生労働省・東京都の資料で、冷却の時間目安（20℃以下2時間）は厚生労働省「大量調理施設衛生管理マニュアル」の記述に基づき確認してください。

## 誤解1｜しっかり煮込んだから菌は死んでいる

**ウェルシュ菌の芽胞は100℃でも死にません。** 加熱で死ぬのは他の菌で、ウェルシュ菌は冷める間に増えます。冷まし方が勝負です。

## 誤解2｜鍋のまま置いて自然に冷ませばいい

**鍋の中が12〜50℃の時間が長いほど菌が増えます。** 小分け・氷水・かき混ぜで、2時間以内に20℃以下へ。

## 誤解3｜翌朝、温め直せば安全

**加熱で菌の数は減りますが、大量に増えた菌と芽胞が残ります。** 前日に急冷しておくことが前提で、再加熱は「かき混ぜながら沸騰」まで。

## 誤解4｜二日目のおいしさは常温で寝かせるから

**うま味の移行ととろみの変化は冷蔵庫でも起きます。** 常温で寝かせる必要はまったくありません。

## 誤解5｜冷蔵庫に入れれば1週間は大丈夫

**冷蔵でも2〜3日が目安**。それ以上は冷凍を。冷蔵庫でも菌はゆっくり増えます。
