# Q. 家で刺身を食べるときの注意は？アニサキスはどう防ぐ？｜世界の質問箱 #500

- 棚：`trend` ／ URL：`/questions/sashimi-and-anisakis` ／ ステータス：**ドラフト（法務レビュー前・出典未検証）**

スーパーで買ったサバやアジを家でさばいて刺身に——日本ではよくある光景ですが、「アニサキス」による食中毒は届出件数で原因物質の上位に入り、実際の発生は届出の10倍以上と推定されています。刺身の家庭での扱いと、アニサキスの確実な予防法を整理します。

## A. アニサキスは体長2〜3cmの白い糸状の寄生虫で、サバ・アジ・イワシ・サンマ・カツオ・イカ・サケなどの内臓と身に潜んでいます。防げる方法は2つだけ——「−20℃で24時間以上の冷凍」か「70℃以上（または60℃で1分）の加熱」。酢・しょうゆ・わさび・塩では死にません。生で食べるなら「生食用」「刺身用」と表示された魚を、買った当日に、冷蔵で持ち帰ってすぐ食べる。自分でさばくなら内臓を早く取り除き、身を明るい場所で目視して取り除く。食後数時間〜十数時間で激しい腹痛・吐き気が出たら、内視鏡で取り出す治療があるので早めに受診してください。

## アニサキスの基本

| 項目 | 内容 |
|---|---|
| **正体** | **アニサキス（線虫）の幼虫**。**体長2〜3cm、幅0.5〜1mm**、白色か半透明の糸状。**渦巻き状**で身に埋まっていることも |
| **多い魚** | **サバ、アジ、イワシ、サンマ、カツオ、サケ、イカ、ヒラメ、ブリ**など。**天然魚**に多く、**養殖魚は少ない**（餌の管理） |
| **どこにいるか** | **主に内臓**。魚が死ぬと**内臓から身（筋肉）へ移動**する。**時間が経つほど身に移りやすい** |
| **症状** | **食後2〜8時間（胃）で激しい腹痛・吐き気・嘔吐**、または**十数時間〜数日後（腸）に下腹部痛**。**アレルギー（じんましん・まれにアナフィラキシー）**も |
| **治療** | **胃アニサキス症は内視鏡で虫体を摘出**すれば症状は速やかに軽快。腸の場合は対症療法 |
| **届出件数** | **2023年 432件**（食中毒統計。**細菌・ウイルスを含む原因物質別で最多**）。ただし研究による推計では**年間7,000件以上**が実際に起きているとされる |

## 予防できる方法・できない方法

| 方法 | 効果 |
|---|---|
| **−20℃で24時間以上冷凍** | **有効**。家庭の冷凍庫は−18℃設定が多く、**48時間以上**を目安に |
| **70℃以上、または60℃で1分の加熱** | **有効** |
| **目視で取り除く** | **有効だが完全ではない**。身の中に潜んだものは見落とす。明るい場所で、薄く切って確認 |
| **内臓を早く取る、鮮度を保つ** | **身への移動を減らす**。釣った魚は船上・購入後すぐに内臓を除去し、冷やす |
| **酢・しょうゆ・わさび・塩・レモン** | **効かない**。しめサバでも発症例が多い |
| **よく噛む** | **虫体が傷つけば死ぬが、確実ではない**。細く刻む（イカそうめんなど）は虫を切る効果がある程度 |

## 家で刺身を扱うときの基本

1. **「生食用」「刺身用」表示のものを買う**。加熱用のサバ・アジは刺身にしない。
2. **買い物は最後に**、保冷剤・保冷バッグで**持ち帰り、すぐ冷蔵（4℃以下）**。
3. **当日中に食べる**。刺身の消費期限は**当日〜翌日**が普通。
4. **調理器具**：**まな板・包丁は使う前後に洗剤で洗い、熱湯**。**生肉と同じ器具を使わない**。
5. **手洗い**、**盛り付けたら早く食べる**。**常温に2時間以上置いたものは加熱調理**に回す。
6. **自分でさばく場合**：**内臓を最初に除き、腹側（内臓に近い身）をよく確認**。**ブラックライト（紫外線）で虫体が光る**ため、釣り人の間では確認用に使われる。
7. **リスクの高い人**（**妊娠中、高齢者、幼児、免疫低下**）は**生の魚を控える**方が無難。**腸炎ビブリオ**（夏の海産物）など、アニサキス以外の食中毒もある。

> **【要検証】** 食中毒統計の件数（2023年432件）は厚生労働省の確定値で、推計値（年間7,000件超）は国立感染症研究所の報告に基づきます。原資料で確認してください。

## 誤解1｜しめサバや酢締めなら大丈夫

**酢ではアニサキスは死にません。** しめサバによる発症例は多く、生食用として冷凍処理された魚か、−20℃24時間の冷凍が必要です。

## 誤解2｜わさびやしょうゆをたっぷり付ければ殺せる

**効きません。** 調味料で死ぬ寄生虫ではありません。

## 誤解3｜新鮮な魚ならアニサキスはいない

**新鮮でも内臓にはいます。** 新鮮さは「身への移動が少ない」ことを意味するだけで、内臓近くの身は要確認。

## 誤解4｜見て取れば完全に防げる

**身の中に潜んだものは見落とします。** 目視は補助。確実なのは冷凍か加熱。

## 誤解5｜腹痛が出ても胃薬で様子を見ればいい

**胃アニサキス症は内視鏡で取り出せば速やかに治まります。** 刺身を食べた数時間後の激しい腹痛は、食べたものを伝えて早めに受診。
