# Q. 在日本可以租自行车吗？有哪些我可能没想到的规则？｜Japan Questions #501

- Shelf: `inbound` ／ URL: `/zh-cn/questions/cycling-rules-for-visitors` ／ Status: **草稿 — 出处未核实**

日本是一个自行车大国——1.25亿人口拥有约7,000万辆自行车——从京都到小岛上的城镇，处处都有租赁自行车和共享单车。但这里的规则与欧洲和北美不同，常让游客措手不及：可以在哪里骑、头盔、饮酒、手机，以及把车停错地方会发生什么。

## A. 可以，而且这是游览日本城镇最好的方式之一。在法律上，自行车属于"轻车辆"：要在道路左侧骑行，而不是人行道，除非有标识允许（很多地方都允许）。自2023年4月起，所有年龄段都建议佩戴头盔，但不佩戴不会被罚款。饮酒后骑车、使用手机、撑伞、并排骑行、夜间无灯骑行均属违法；自2024年11月起，使用手机和酒后骑车会被追究刑事责任；自2026年4月起，其他大多数违法行为（骑上人行道、撑伞、无灯、戴耳机）会对16岁以上的骑车人当场处以¥3,000–12,000的定额罚款。只能停在标有自行车停放标识的地方：在城市里把车停在繁忙的人行道上，几小时内就会被拖走，取回需要¥2,000–5,000。

## 让游客意外的规则

| 规则 | 详情 | 处罚（截至2026年4月） |
|---|---|---|
| **骑哪一侧** | **道路左侧**，与车流同向。**仅在有标识的地方**、13岁以下、70岁以上或道路危险时才可在人行道上骑行——且要慢行、让行行人 | 警告／罚款 |
| **头盔** | 自2023年4月起**建议所有年龄段佩戴**（"努力义务"）。不罚款，但越来越多的租车店会提供 | 无 |
| **饮酒** | **饮酒后骑车是犯罪**，与酒驾同等对待。自2024年11月起，"酒后骑行"可处**最高3年有期徒刑或¥500,000罚金** | 刑事 |
| **手机** | **骑行时手持手机**：自2024年11月起**最高6个月有期徒刑或¥100,000罚金**；造成危险的最高1年 | 刑事 |
| **雨伞** | 骑行时撑伞属违法（有固定式伞架，但在许多都道府县同样受限） | 罚款 |
| **车灯** | **天黑后必须开前灯**；后部需有反光片或尾灯 | 罚款 |
| **并排骑行／载人** | 除有标识的车道外不允许；**不得载成年人**。6岁以下儿童只能坐在经认证的儿童座椅上 | 罚款 |
| **耳机** | 各都道府县规定限制使用妨碍听觉的耳机 | 罚款 |
| **停车** | **只能停在指定自行车停放处**（收费：一般**¥100–200/天**）。"清除区域"内人行道上的自行车会被扣押 | **¥2,000–5,000** 取回费，需出示身份证件 |

- **租车选择**：**共享单车**（Docomo Bike Share、HELLO CYCLING、LUUP）通过应用和信用卡使用，**每30分钟¥130–165**或**¥1,500–2,000/天**；**游客租车店**¥1,000–2,500/天；**酒店自行车**通常免费。大多数共享电动车为脚踏助力型，限速24 km/h。
- **LUUP与电动滑板车**：自2023年7月起为单独类别（"特定小型原动机自行车"）——**16岁以上、限速20 km/h、建议戴头盔、无需驾照**；道路／人行道规则又有不同。请查看应用内的说明。
- **保险**：东京、大阪、京都及大多数都道府县**强制要求自行车责任保险**；租赁和共享方案均已包含——**请查看确认信息**。日本法院曾判决撞伤行人的骑车人赔偿**超过¥90,000,000（9,000万日元）**。
- **登记**：日本的自行车贴有**警方防盗登记贴纸**；没有手续文件的租赁车可能会被警察拦下盘问。**随身携带租车收据**。
- **礼仪**：只在有危险时才按铃，不要用铃驱赶行人；在设有"禁止骑行"时段的商店街（shōtengai／「商店街」）**推车步行**；不要把车锁在栏杆或树上。
- **岛波海道、琵琶一周（Biwaichi）、筑波—霞浦 Ring-Ring Road**：设有标识的国家自行车路线，两端均有租车点并提供异地还车服务；**岛波海道（70 km）**是最知名的游客骑行路线。

> **[待核实]** 2024年11月《道路交通法》修正案下的处罚金额；头盔规定（2023年4月）；各运营商应用中的共享单车价格。
