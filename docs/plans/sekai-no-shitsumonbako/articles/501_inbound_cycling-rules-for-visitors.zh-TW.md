# Q. 在日本可以租自行車嗎？有哪些我可能沒想到的規則？｜Japan Questions #501

- Shelf: `inbound` ／ URL: `/zh-tw/questions/cycling-rules-for-visitors` ／ Status: **草稿 — 出處未核實**

日本是自行車大國——1.25億人口擁有約7,000萬輛自行車——從京都到小島上的城鎮，到處都有租賃自行車與共享單車（類似台灣的 YouBike）。但這裡的規則與歐美不同，常讓旅客措手不及：可以在哪裡騎、安全帽、飲酒、手機，以及把車停錯地方會發生什麼事。

## A. 可以，而且這是遊覽日本城鎮最好的方式之一。在法律上，自行車屬於「輕車輛」：要在道路左側騎，而不是人行道，除非有標示允許（很多地方都允許）。自2023年4月起，所有年齡層都建議戴安全帽，但不戴不會被罰款。酒後騎車、使用手機、撐傘、並排騎行、夜間無燈騎行都屬違法；自2024年11月起，使用手機與酒後騎車會被追究刑事責任；自2026年4月起，其他大多數違規行為（騎上人行道、撐傘、無燈、戴耳機）會對16歲以上的騎士當場處以¥3,000–12,000的定額罰款。只能停在標有自行車停放標示的地方：在城市裡把車停在繁忙的人行道上，幾小時內就會被拖走，取回要¥2,000–5,000。

## 讓旅客意外的規則

| 規則 | 詳情 | 處罰（截至2026年4月） |
|---|---|---|
| **騎哪一側** | **道路左側**，與車流同向。**僅在有標示的地方**、13歲以下、70歲以上或道路危險時才可在人行道上騎——而且要慢行、讓行人優先 | 警告／罰款 |
| **安全帽** | 自2023年4月起**建議所有年齡層配戴**（「努力義務」）。不罰款，但越來越多租車店會提供 | 無 |
| **飲酒** | **酒後騎車是犯罪**，與酒駕同等看待。自2024年11月起，「酒後騎行」可處**最高3年有期徒刑或¥500,000罰金** | 刑事 |
| **手機** | **騎行時手持手機**：自2024年11月起**最高6個月有期徒刑或¥100,000罰金**；造成危險者最高1年 | 刑事 |
| **雨傘** | 騎行時撐傘屬違規（有固定式傘架，但在許多都道府縣同樣受限） | 罰款 |
| **車燈** | **天黑後必須開前燈**；後方需有反光片或尾燈 | 罰款 |
| **並排騎行／載人** | 除有標示的車道外不允許；**不得載成年人**。6歲以下兒童只能坐在經認證的兒童座椅上 | 罰款 |
| **耳機** | 各都道府縣規定限制使用妨礙聽覺的耳機 | 罰款 |
| **停車** | **只能停在指定自行車停放處**（收費：一般**¥100–200/天**）。「清除區域」內人行道上的自行車會被扣押 | **¥2,000–5,000** 取回費，需出示身分證件 |

- **租車選擇**：**共享單車**（Docomo Bike Share、HELLO CYCLING、LUUP）透過 App 與信用卡使用，**每30分鐘¥130–165**或**¥1,500–2,000/天**；**觀光客租車店**¥1,000–2,500/天；**飯店自行車**通常免費。大多數共享電動車為電動輔助型，限速24 km/h。
- **LUUP 與電動滑板車**：自2023年7月起為獨立類別（「特定小型原動機自行車」）——**16歲以上、限速20 km/h、建議戴安全帽、不需駕照**；道路／人行道規則又有不同。請查看 App 內的說明。
- **保險**：東京、大阪、京都及大多數都道府縣**強制要求自行車責任保險**；租賃與共享方案均已包含——**請查看確認資訊**。日本法院曾判決撞傷行人的騎士賠償**超過¥90,000,000（9,000萬日圓）**。
- **登記**：日本的自行車貼有**警方防盜登錄貼紙**；沒有相關文件的租賃車可能會被警察攔下盤問。**隨身攜帶租車收據**。
- **禮儀**：只在有危險時才按鈴，不要用鈴驅趕行人；在設有「禁止騎行」時段的商店街（shōtengai／「商店街」）**牽車步行**；不要把車鎖在欄杆或樹上。
- **島波海道、琵琶湖一周（Biwaichi）、筑波—霞浦 Ring-Ring Road**：設有標示的國家自行車路線，兩端均有租車點並提供甲地租乙地還服務；**島波海道（70 km）**是最知名的旅客騎行路線。

> **[待核實]** 2024年11月《道路交通法》修正案下的處罰金額；安全帽規定（2023年4月）；各營運商 App 中的共享單車價格。
