# Q. 任何人都能登富士山吗？初次登山者常犯什么错？｜Japan Questions #502

- Shelf: `inbound` ／ URL: `/zh-cn/questions/climbing-mount-fuji-safely` ／ Status: **草稿 — 出处未核实**

富士山（3,776 m）每年夏季约有20万人攀登（2025年约205,000人），其中许多是初次登山者；每年山岳救援队都会救助那些穿着运动鞋和T恤、深夜出发却没带头灯的游客。自2024年起，这座山有了闸门、收费和人数上限。以下是改变了的和没有改变的。

## A. 登山季很短——7月上旬至9月上旬——季外各条路线关闭，且极其危险。季内，健康的成年人可以登顶，但这是一次正经的高海拔徒步，不是散步：从五合目上山需5–7小时，下山3–5小时，即使在8月山顶气温也接近冰点，大约每三名登山者中就有一人出现高山反应。自2025年起，四条登山道均收取每次¥4,000的费用，并在14:00–03:00对没有山小屋预订的人关闭五合目闸门；吉田路线（山梨县）还设有每天4,000人的上限和在线预约（2026年预约于4月27日开放），静冈县的三条路线要求先完成简短的强制在线学习课程后才能领取登山许可。请预订山小屋，不要尝试通宵的"子弹登山"，天气变坏就下撤。

## 关键事实

| 项目 | 详情 |
|---|---|
| **登山季** | **7月上旬 – 9月10日**（日期因路线和年份而异）。**官方不鼓励季外登山**；山小屋和急救站关闭，每年都有人死亡 |
| **路线** | **吉田**（山梨县，最受欢迎，约占登山者的60%，山小屋最多）、**富士宫**、**须走**、**御殿场**（静冈县）。均从可乘巴士抵达的"五合目"出发 |
| **时间** | 五合目（2,300 m）至山顶：**上山5–7小时，下山3–5小时**。大多数人下午上山，在山小屋过夜，日出时到达山顶 |
| **费用与闸门（2026年）** | **四条路线均为每人每次¥4,000**。**所有路线在14:00–03:00对没有山小屋预订的人关闭闸门**。山梨（吉田）：**在线预约**、**每天4,000人上限**、闸门处检查装备。静冈（3条路线）：**强制在线学习**并通过 FUJI NAVI 登记后才发放许可 |
| **气温** | 夏季山顶**0–8°C**，风寒效应下低于零度；**比五合目低10°C**，比东京低20°C |
| **高山反应** | 3,000 m 以上，相当一部分登山者会头痛、恶心、头晕。症状加重请**下撤**；罐装氧气帮助有限 |
| **山小屋** | **必须预订**，含晚餐和早餐**¥10,000–15,000**，通铺，**无淋浴**，厕所每次¥200–300 |
| **救援** | 警察／消防救援目前**免费**，但静冈县正在研究对季外直升机救援收费（埼玉县已在指定山区按每5分钟飞行¥8,000收费）。季外救援缓慢、对救援人员危险，且可能根本无法到达 |

## 装备（各县公布的最低要求）

- **登山鞋**（不是运动鞋）、**雨衣和雨裤**（不要用雨披——风大）、**保暖层**（抓绒、羽绒、帽子、手套）、带备用电池的**头灯**、**2 L 水**、高热量食物、**现金**（山小屋、厕所、每瓶¥500的饮料）、防晒用品，以及**垃圾袋**——山上没有垃圾桶。
- **租赁**：河口湖和五合目的装备店出租全套装备，**¥5,000–10,000**。

## 常出的问题

- **"子弹登山"（弾丸登山／dangan tozan）**——傍晚从五合目出发、不睡觉直接赶在黎明前登顶——是大多数高山反应和体力耗尽案例的原因。闸门关闭（2024年为16:00，2025年起为14:00）就是为了阻止这种做法。
- **在恶劣天气出发**：雷电和台风季的降雨；山小屋会发布关闭通知。出发当天早上查看**富士山登山官方网站**。
- **在吉田路线的火山砂砾上下山过快**——膝盖受伤，以及在须走／吉田分岔口迷路（请沿自己路线的颜色标识走）。
- **登顶之后**：从五合目下山的最后一班巴士在傍晚较早时发车；错过就只能坐昂贵的出租车。

> **[待核实]** 2025年费用（¥4,000）及吉田路线闸门时间／人数上限，请以登山官方网站为准；登山人数及高山反应比例请以各县报告为准。
