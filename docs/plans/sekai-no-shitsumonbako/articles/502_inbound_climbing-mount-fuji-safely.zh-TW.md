# Q. 任何人都能登富士山嗎？初次登山者常犯什麼錯？｜Japan Questions #502

- Shelf: `inbound` ／ URL: `/zh-tw/questions/climbing-mount-fuji-safely` ／ Status: **草稿 — 出處未核實**

富士山（3,776 m）每年夏季約有20萬人攀登（2025年約205,000人），其中許多是初次登山者；每年山岳救難隊都會救助那些穿著球鞋和T恤、深夜出發卻沒帶頭燈的旅客。自2024年起，這座山有了閘門、收費和人數上限。以下是改變了的與沒有改變的。

## A. 登山季很短——7月上旬至9月上旬——季外各條路線封閉，而且極其危險。季內，健康的成年人可以登頂，但這是一次正經的高海拔健行，不是散步：從五合目上山要5–7小時，下山3–5小時，即使在8月山頂氣溫也接近冰點，大約每三名登山者就有一人出現高山症。自2025年起，四條登山道都收取每次¥4,000的費用，並在14:00–03:00對沒有山屋預約的人關閉五合目閘門；吉田路線（山梨縣）還設有每天4,000人的上限和線上預約（2026年預約於4月27日開放），靜岡縣的三條路線要求先完成簡短的強制線上學習課程，才能領取登山許可。請預約山屋，不要嘗試通宵的「子彈登山」，天氣變壞就撤退。

## 關鍵事實

| 項目 | 詳情 |
|---|---|
| **登山季** | **7月上旬 – 9月10日**（日期因路線和年份而異）。**官方不鼓勵季外登山**；山屋和救護站關閉，每年都有人死亡 |
| **路線** | **吉田**（山梨縣，最受歡迎，約占登山者的60%，山屋最多）、**富士宮**、**須走**、**御殿場**（靜岡縣）。均從可搭巴士抵達的「五合目」出發 |
| **時間** | 五合目（2,300 m）至山頂：**上山5–7小時，下山3–5小時**。大多數人下午上山，在山屋過夜，日出時抵達山頂 |
| **費用與閘門（2026年）** | **四條路線均為每人每次¥4,000**。**所有路線在14:00–03:00對沒有山屋預約的人關閉閘門**。山梨（吉田）：**線上預約**、**每天4,000人上限**、閘門處檢查裝備。靜岡（3條路線）：**強制線上學習**並透過 FUJI NAVI 登記後才發放許可 |
| **氣溫** | 夏季山頂**0–8°C**，風寒效應下低於零度；**比五合目低10°C**，比東京低20°C |
| **高山症** | 3,000 m 以上，相當一部分登山者會頭痛、噁心、頭暈。症狀加重請**下撤**；罐裝氧氣幫助有限 |
| **山屋** | **必須預約**，含晚餐和早餐**¥10,000–15,000**，大通鋪，**無淋浴**，廁所每次¥200–300 |
| **救援** | 警察／消防救援目前**免費**，但靜岡縣正在研究對季外直升機救援收費（埼玉縣已在指定山區按每5分鐘飛行¥8,000收費）。季外救援緩慢、對救難人員危險，而且可能根本無法到達 |

## 裝備（各縣公布的最低要求）

- **登山鞋**（不是球鞋）、**雨衣和雨褲**（不要用斗篷式雨衣——風大）、**保暖層**（刷毛、羽絨、帽子、手套）、附備用電池的**頭燈**、**2 L 水**、高熱量食物、**現金**（山屋、廁所、每瓶¥500的飲料）、防曬用品，以及**垃圾袋**——山上沒有垃圾桶。
- **租借**：河口湖和五合目的裝備店出租全套裝備，**¥5,000–10,000**。

## 常出的問題

- **「子彈登山」（弾丸登山／dangan tozan）**——傍晚從五合目出發、不睡覺直接趕在黎明前登頂——是大多數高山症和體力耗盡案例的原因。閘門關閉（2024年為16:00，2025年起為14:00）就是為了阻止這種做法。
- **在惡劣天氣出發**：雷擊和颱風季的降雨；山屋會發布關閉通知。出發當天早上查看**富士山登山官方網站**。
- **在吉田路線的火山碎石上下山過快**——膝蓋受傷，以及在須走／吉田分岔口迷路（請沿自己路線的顏色標示走）。
- **登頂之後**：從五合目下山的最後一班巴士在傍晚較早時發車；錯過就只能搭昂貴的計程車。

> **[待核實]** 2025年費用（¥4,000）及吉田路線閘門時間／人數上限，請以登山官方網站為準；登山人數及高山症比例請以各縣報告為準。
