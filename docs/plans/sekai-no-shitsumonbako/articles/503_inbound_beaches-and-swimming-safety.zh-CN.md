# Q. 日本的海滩适合游泳吗？水母、离岸流与规则｜Japan Questions #503

- Shelf: `inbound` ／ URL: `/zh-cn/questions/beaches-and-swimming-safety` ／ Status: **草稿 — 出处未核实**

日本有约35,000 km 的海岸线，海滩季节短暂而热烈。游客常常感到惊讶：除了夏天的几周之外"海是关闭的"；救生员会用哨子把离岸没几米的泳客叫回来；到了8月中旬，所有人都在同一时间离开海水。每一点都有原因。

## A. 只在指定的海水浴场（「海水浴場」／kaisuiyokujō）开放期间——大致为7月中旬至8月下旬——在有救生员值守、浮标围起的区域内游泳。离岸流是溺水的首要原因；水母大约从盂兰盆节（8月中旬）开始出现，这就是当地人那时停止游泳的原因；南部（冲绳）有箱水母和其他会刺人的动物，需要防护网和长袖。饮酒后游泳是另一大杀手。看旗子行动：红旗表示禁止游泳。

## 季节与规则

| 项目 | 详情 |
|---|---|
| **海滩季节** | 指定海滩于**7月中旬至8月下旬**开放（冲绳从4月起；北海道只有几周）。此外的日期：**没有救生员、没有设施，且常有禁止游泳的标识** |
| **指定海滩** | 约**1,000处官方海水浴场**，有水质检测、救生员、浮标游泳区、淋浴和储物柜（¥300–500）。请在**浮标内**游泳 |
| **旗子** | **红：禁止游泳。黄：注意。绿／白：可游泳。**救生员会在边界处吹哨叫您回来——请配合 |
| **溺水** | 日本每年约有**700–800人因水难死亡或失踪**（2025年为760人；约46%在海上，37%在河流）；**离岸流**是海滩溺水的主因，成年人案例中相当一部分涉及**饮酒** |
| **离岸流** | 快速流向外海的水道，常出现在浪看起来更平静的地方。**不要逆流游：漂浮、举手示意、平行于海岸游**，直到脱离水流 |
| **水母** | **行灯水母（andon-kurage，一种小型箱水母，*Carybdea brevipedalia*）**大约从**盂兰盆节（8月中旬）**起出现在本州海域——这就是"盂兰盆节后不下海"这句民间说法的由来。**冲绳的波布水母（habu-kurage，Chironex 属）**从6月起出现：**海滩设有防护网**；在这些海滩被刺后的急救是用**醋**，其他地方用海水 |
| **其他危险** | 岩石上的**海胆**、沙中的**鬼鲉（oni-okoze，石头鱼）**、南部的**蓝环章鱼**。在岩石上穿凉鞋；不要触碰动物 |
| **纹身** | 少数海滩及大多数**海滩边的泳池和淋浴间**限制外露的纹身；大海本身是公共的 |

## 沙滩上的规则

- 根据2014年前后的条例，**许多海滩禁止饮酒**（逗子、镰仓、冲绳部分地区）；**除指定区域外禁止烧烤**；**禁止大声播放音乐**。罚款少见，但被请离并不少见。
- **垃圾请带走**；垃圾桶很少。**烟花**只能在允许的地方、22:00之前燃放。
- **防晒**：8月的紫外线指数为**8–11**；日本的海滩游客用帐篷、防晒衣和长袖，而不是晒黑。遮阳设施租赁¥1,000–3,000。
- **更衣**：**海之家（「海の家」／umi-no-ie，海滩小屋）**出租储物柜、淋浴和空间，¥1,000–2,000；海滩上没有裸露更衣的习惯——请在海之家更衣。
- **河流与湖泊**：对游客来说**比海滩更危险**——水冷、深度突变、水库放水、没有救生员。大多数儿童溺水事故发生在河流。

## 有人遇险时

- **大声呼叫救生员、抛出能漂浮的东西，除非受过训练，不要下水去救。**紧急电话 **118**（海上保安厅）或 **119**（救护车）。
