# Q. 日本的海灘適合游泳嗎？水母、離岸流與規則｜Japan Questions #503

- Shelf: `inbound` ／ URL: `/zh-tw/questions/beaches-and-swimming-safety` ／ Status: **草稿 — 出處未核實**

日本有約35,000 km 的海岸線，海灘季節短暫而熱烈。旅客常常感到驚訝：除了夏天的幾週之外「海是關閉的」；救生員會用哨子把離岸沒幾公尺的泳客叫回來；到了8月中旬，所有人都在同一時間離開海水。每一點都有原因。

## A. 只在指定的海水浴場（「海水浴場」／kaisuiyokujō）開放期間——大致為7月中旬至8月下旬——在有救生員值守、浮標圍起的區域內游泳。離岸流是溺水的首要原因；水母大約從盂蘭盆節（8月中旬）開始出現，這就是當地人那時停止游泳的原因；南部（沖繩）有箱型水母和其他會刺人的動物，需要防護網和長袖。酒後游泳是另一大殺手。看旗子行動：紅旗表示禁止游泳。

## 季節與規則

| 項目 | 詳情 |
|---|---|
| **海灘季節** | 指定海灘於**7月中旬至8月下旬**開放（沖繩從4月起；北海道只有幾週）。此外的日期：**沒有救生員、沒有設施，而且常有禁止游泳的標示** |
| **指定海灘** | 約**1,000處官方海水浴場**，有水質檢測、救生員、浮標泳區、淋浴和置物櫃（¥300–500）。請在**浮標內**游泳 |
| **旗子** | **紅：禁止游泳。黃：注意。綠／白：可游泳。**救生員會在邊界處吹哨叫您回來——請配合 |
| **溺水** | 日本每年約有**700–800人因水難死亡或失蹤**（2025年為760人；約46%在海上，37%在河川）；**離岸流**是海灘溺水的主因，成人案例中相當一部分涉及**飲酒** |
| **離岸流** | 快速流向外海的水道，常出現在浪看起來比較平靜的地方。**不要逆流游：漂浮、舉手示意、平行於海岸游**，直到脫離水流 |
| **水母** | **行燈水母（andon-kurage，一種小型箱型水母，*Carybdea brevipedalia*）**大約從**盂蘭盆節（8月中旬）**起出現在本州海域——這就是「盂蘭盆節後不下海」這句民間說法的由來。**沖繩的波布水母（habu-kurage，Chironex 屬）**從6月起出現：**海灘設有防護網**；在這些海灘被刺後的急救是用**醋**，其他地方用海水 |
| **其他危險** | 岩石上的**海膽**、沙中的**鬼鮋（oni-okoze，石頭魚）**、南部的**藍環章魚**。在岩石上穿涼鞋；不要觸碰動物 |
| **刺青** | 少數海灘及大多數**海灘旁的泳池和淋浴間**限制外露的刺青；大海本身是公共的 |

## 沙灘上的規則

- 依據2014年前後的條例，**許多海灘禁止飲酒**（逗子、鎌倉、沖繩部分地區）；**除指定區域外禁止烤肉**；**禁止大聲播放音樂**。罰款少見，但被請離並不少見。
- **垃圾請帶走**；垃圾桶很少。**煙火**只能在允許的地方、22:00之前施放。
- **防曬**：8月的紫外線指數為**8–11**；日本的海灘遊客用帳篷、防曬衣和長袖，而不是曬黑。遮陽設施租借¥1,000–3,000。
- **更衣**：**海之家（「海の家」／umi-no-ie，海灘小屋）**出租置物櫃、淋浴和空間，¥1,000–2,000；海灘上沒有裸露更衣的習慣——請在海之家更衣。
- **河川與湖泊**：對旅客來說**比海灘更危險**——水冷、深度突變、水庫放水、沒有救生員。大多數兒童溺水事故發生在河川。

## 有人遇險時

- **大聲呼叫救生員、拋出能漂浮的東西，除非受過訓練，不要下水去救。**緊急電話 **118**（海上保安廳）或 **119**（救護車）。

> **[待核實]** 年度水難死亡人數請以警察廳統計為準；指定海水浴場數量請以環境省為準；水母急救方法請以沖繩縣指引為準。
