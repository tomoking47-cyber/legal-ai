# Q. 晚上8點半，餐廳為什麼不讓我進？日本的營業時間、最後點餐與公休日｜Japan Questions #505

- Shelf: `inbound` ／ URL: `/zh-tw/questions/restaurant-hours-and-last-orders` ／ Status: **草稿 — 出處未核實**

旅客把東京想像成一座24小時不打烊的城市，某種程度上確實如此——但許多餐廳停止接客的時間早得出乎意料，會在某個平日公休，還會在下午歇業一段時間。明明看起來還在營業卻被擋在門外，是日本旅行中最常見的小挫折之一。

## A. 日本餐廳是照「ラストオーダー」（最後點餐，last order）在運作的，通常在打烊前30–60分鐘截止；許多個人經營的店20:00–21:00就收，午餐時段14:00準時結束，之後一路休息到17:00或18:00。多數店家有固定的「定休日」（每週固定公休）——往往是星期一、星期二或星期三，而不是星期日——另外還有「不定休」（不固定的臨時公休）。請當天上網確認營業時間，至少在打烊前一小時到店；如果店家標明某個時間「L.O.」，那是點餐的截止時間，不是入座的截止時間。

## 營業時間是怎麼一回事

| 用語 | 意思 | 常見情況 |
|---|---|---|
| **營業時間（営業時間）** | 營業時段 | 午餐 **11:30–14:00**，晚餐 **17:30–22:00** |
| **L.O.／最後點餐（ラストオーダー）** | **點餐的最後時刻**——通常**餐點為打烊前30分鐘，飲料為15–30分鐘**。在L.O.前20分鐘到店常常會被婉拒，因為廚房已經開始收了 | 22:00打烊的店，L.O. 21:30 |
| **定休日（定休日）** | **每週固定公休日**——個人店常在**星期一、星期二或星期三**，因為週末生意忙 | 「星期二公休」 |
| **不定休（不定休）** | 不固定的臨時公休，會發在社群媒體或貼在門上 | 當天查看 Instagram／X |
| **準備中（準備中）** | 「準備中」的牌子——兩段營業之間的休息 | 14:00–17:30 |
| **滿席（満席）** | 「客滿」——包含已被預約、留給稍後客人的座位 | 候位或換一家 |

- **營業時間長的地方**：**連鎖餐廳**（家庭餐廳、牛丼、拉麵連鎖——常24小時或營業到02:00）、**居酒屋**（到23:00–午夜，鬧區更晚）、**百貨公司的餐廳樓層**（到22:00）、**便利商店**（24小時）。
- **營業時間短的地方**：**壽司吧台、懷石、蕎麥麵、天婦羅專門店**——常採**兩輪制**（18:00與20:00）並搭配固定套餐；許多店午餐13:30就結束，或當天的米用完就打烊（人氣拉麵店和炸豬排店常掛出「**售完**」的牌子）。
- **星期日與國定假日**：**商業區（丸之內、日本橋、新橋）會空下來**——許多做午餐生意的店週末公休。**黃金週、8月中旬的盂蘭盆節（お盆）和12月29日–1月3日**：個人經營的餐廳會休**數日到兩週**；這是旅客行程規劃中最大的一個盲點。
- **訂位**：許多頂級餐廳**只接受用日語打電話訂位**，或透過**飯店禮賓部（concierge）**；**TableCheck、Omakase、Pocket Concierge** 涵蓋的店家也在增加。**放鴿子（no-show）會被收費**（請見取消費用那一篇）。
- **用餐時間限制**：熱門居酒屋與咖啡廳為**90–120分鐘**，會印在菜單上。這不是失禮，而是經營模式。
- **廚房禮儀**：到L.O.時，店員會問「**ラストオーダーです**（最後點餐囉）」——要點的請一次點齊。**打烊後還端著酒繼續坐是不行的**，店家會請你結帳。
- **Google 地圖上的營業時間經常有誤**；**食べログ（Tabelog，日文）**通常準確，而**當天查看餐廳自己的社群媒體**才是最可靠的方法。

> **[待核實]** 典型營業時間模式為編輯部的一般歸納，請以最新的店家資訊核對。季節性休業期間（黃金週、盂蘭盆節、新年）因店而異。
