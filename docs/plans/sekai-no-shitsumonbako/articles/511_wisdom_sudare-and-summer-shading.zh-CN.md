# Q. 关于日本的夏季竹帘「すだれ」（簾），人们常有哪些误解？｜Japanese Everyday Wisdom #511

- Shelf: `wisdom` ／ URL: `/zh-cn/wisdom/sudare-and-summer-shading` ／ Status: **草稿 — 出处未核实**

在空调普及之前，日本的房屋靠一种悬挂的芦苇帘——簾（すだれ，sudare）——以及它的立式"表亲"葦簀（よしず，yoshizu）来保持凉爽。每年六月，各家家居建材中心（ホームセンター）仍以几百日元的价格出售它们；日本电力公司和大学的研究也一再得出同样的结论：玻璃外侧的遮阳胜过室内的任何窗帘。

## A. 常见的误解是把簾当作装饰品或窗帘的替代品。它其实是一种外部遮阳装置：挂在窗外、距玻璃 10–20 cm，可在太阳热量进入室内之前阻挡 50–80%；而室内窗帘只能在热量已经进入房间之后遮挡光线。实地测量显示，簾或绿色窗帘（植物帘）后面的房间表面温度低数度，空调用电量低 10–20%。挂在外侧、留出通风间隙、在最热的下午给它洒水，并在台风来临前收回。

## 簾、葦簀与数据

| 项目 | 详情 |
|---|---|
| **簾（すだれ）** | 用**剖开的竹子或芦苇**（现在常为塑料）制成的悬挂式卷帘，可上下卷放；家居建材中心售价 **88 × 180 cm 约 ¥500–1,500**。挂钩夹在窗框或阳台栏杆上 |
| **葦簀（よしず）** | **独立式芦苇屏**（高 2–3 m），斜靠在屋檐或檐廊上；可遮蔽整面墙和门口。¥2,000–5,000 |
| **挂在哪里** | **玻璃外侧**，留 **10–20 cm 的空气间隙**。挂在室内虽仍能减少眩光，但大部分热量已经进来了 |
| **效果（据报道）** | **阻挡 50–80% 的太阳辐射**；玻璃内表面**低 5–10°C**；晴天下午室内空气**低 1–3°C**；在电力公司和大学的试验中**空调用量下降 10–20%** |
| **对比** | 室内窗帘：约减少 30–40% 热量。**外部遮阳（簾、遮阳篷、绿色窗帘）：60–80%**。反射膜：30–60%，但是永久性的 |
| **打水（打ち水）** | 傍晚**给簾（或地面）洒水**可增加蒸发降温：穿过的空气温度下降 **1–2°C** |
| **保养** | 下雨时尽量卷起；**台风前收回**（它们会变成"帆"）；刷去灰尘；天然芦苇可用 **2–4 个夏季**，会因紫外线而变灰 |

- **哪些窗户**：**朝南和朝西**——朝西的午后阳光正是让卧室到傍晚仍然闷热的原因。**朝北的窗户不需要。**
- **通风**：簾能**让微风穿过**，同时**遮挡室内视线**——这是在密集街区开窗而不被人看见的传统方法。京都的町家至今仍悬挂簾就是这个原因。
- **阳台**：用 S 形挂钩或绳带固定在阳台栏杆上；**请确认所在楼宇的规定**——有些禁止在外立面放置任何物品。租房者：不要钻孔；使用伸缩杆或栏杆挂钩。
- **绿色窗帘**（爬在网上的苦瓜、牵牛花）是"活的"版本，遮阳效果相同，但**湿度更高，还能有收成**（参见阳台园艺一文）。
- **现代版本**：**铝涂层遮阳网**、**伸缩杆上的遮阳布**——原理相同，寿命更长，韵味略少。
- **冬季**：取下；冬天您需要阳光。

> **[待核实]** 太阳热量与空调用量的减少百分比来自经济产业省（METI）和环境省（MOE）资料中引用的电力公司/大学试验；发布前请确认具体数字。
