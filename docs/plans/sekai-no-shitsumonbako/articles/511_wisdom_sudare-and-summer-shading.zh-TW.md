# Q. 關於日本的夏季竹簾「すだれ」（簾），人們常有哪些誤解？｜Japanese Everyday Wisdom #511

- Shelf: `wisdom` ／ URL: `/zh-tw/wisdom/sudare-and-summer-shading` ／ Status: **草稿 — 出處未核實**

在冷氣普及之前，日本的房屋靠一種懸掛的蘆葦簾——簾（すだれ，sudare）——以及它的立式「表親」葦簀（よしず，yoshizu）來保持涼爽。每年六月，各家家庭五金賣場（ホームセンター）仍以幾百日圓的價格販售；日本電力公司與大學的研究也一再得出同樣的結論：玻璃外側的遮陽勝過室內的任何窗簾。

## A. 常見的誤解是把簾當作裝飾品或窗簾的替代品。它其實是一種外部遮陽裝置：掛在窗外、距玻璃 10–20 cm，可在太陽熱量進入室內之前阻擋 60–80%；而室內窗簾只能在熱量已經進入房間之後遮擋光線。實地量測顯示，簾或綠簾（植物簾）後面的房間表面溫度低數度，冷氣用電量低 10–20%。掛在外側、留出通風間隙、在最熱的下午替它灑水，並在颱風來臨前收回。

## 簾、葦簀與數據

| 項目 | 詳情 |
|---|---|
| **簾（すだれ）** | 用**剖開的竹子或蘆葦**（現在常為塑膠）製成的懸掛式捲簾，可上下捲放；家庭五金賣場售價 **88 × 180 cm 約 ¥500–1,500**。掛鉤夾在窗框或陽台欄杆上 |
| **葦簀（よしず）** | **獨立式蘆葦屏**（高 2–3 m），斜靠在屋簷或簷廊上；可遮蔽整面牆和門口。¥2,000–5,000 |
| **掛在哪裡** | **玻璃外側**，留 **10–20 cm 的空氣間隙**。掛在室內雖仍能減少眩光，但大部分熱量已經進來了 |
| **效果（據報告）** | **阻擋 60–80% 的太陽輻射**；玻璃內表面**低 5–10°C**；晴天下午室內空氣**低 1–3°C**；在電力公司與大學的試驗中**冷氣用量下降 10–20%** |
| **比較** | 室內窗簾：約減少 30–40% 熱量。**外部遮陽（簾、遮陽篷、綠簾）：60–80%**。反射隔熱膜：30–60%，但是永久性的 |
| **打水（打ち水）** | 傍晚**替簾（或地面）灑水**可增加蒸發降溫：穿過的空氣溫度下降 **1–2°C** |
| **保養** | 下雨時盡量捲起；**颱風前收回**（它們會變成「帆」）；刷去灰塵；天然蘆葦可用 **2–4 個夏季**，會因紫外線而變灰 |

- **哪些窗戶**：**朝南和朝西**——朝西的午後陽光正是讓臥室到傍晚仍然悶熱的原因。**朝北的窗戶不需要。**
- **通風**：簾能**讓微風穿過**，同時**遮擋室內視線**——這是在密集街區開窗而不被人看見的傳統方法。京都的町家至今仍懸掛簾就是這個原因。
- **陽台**：用 S 形掛鉤或繫帶固定在陽台欄杆上；**請確認所在大樓的規定**——有些禁止在外牆放置任何物品。租屋者：不要鑽孔；使用伸縮桿或欄杆掛鉤。
- **綠簾**（爬在網上的苦瓜、牽牛花）是「活的」版本，遮陽效果相同，但**濕度更高，還能有收成**（參見陽台園藝一文）。
- **現代版本**：**鋁塗層遮陽網**、**伸縮桿上的遮陽布**——原理相同，壽命更長，韻味略少。
- **冬季**：取下；冬天您需要陽光。

> **[待核實]** 太陽熱量與冷氣用量的減少百分比來自經濟產業省（METI）與環境省（MOE）資料中引用的電力公司／大學試驗；發布前請確認具體數字。
