# Q. 關於「打ち水」（打水，往地面灑水），人們常有哪些誤解？｜Japanese Everyday Wisdom #512

- Shelf: `wisdom` ／ URL: `/zh-tw/wisdom/uchimizu-water-sprinkling` ／ Status: **草稿 — 出處未核實**

在日本的夏日傍晚，您仍能看到店家和老奶奶們用勺子往家門前的路面潑一勺水。這看起來像是一種儀式——某種程度上確實如此——但打水（打ち水，uchimizu）是有 400 年實踐經驗的蒸發降溫法，而東京都政府自 2003 年起就一直舉辦全市規模的打水活動。不過，若在錯誤的時間進行，它只會讓傍晚更加潮濕，而不是更涼快。

## A. 常見的誤解是認為打水是透過濕潤空氣來降溫。它其實是靠蒸發降溫：灑在高溫表面上的水在變成水蒸氣時會帶走熱量，使表面溫度下降 10°C 以上，其上方的空氣下降 1–2°C。這只有在水確實能較快蒸發時才有效——清晨或 17:00 以後，在陰涼處或已經降溫的地面上，使用二次利用的水（洗澡水、雨水、冷氣滴水），每平方公尺一勺左右。若在 14:00 往被太陽曬燙的柏油路面潑水，水幾秒鐘內就會閃蒸掉，只會增加濕度而沒有持續的降溫。切勿在鄰居的晾曬衣物或門口附近打水，缺水時切勿使用飲用水。

## 原理與做法

| 項目 | 詳情 |
|---|---|
| **原理** | **1 公升水蒸發約吸收 2,400 kJ** 熱量——足以讓一大片路面降溫數度。降溫後的表面便不再向房間和街道輻射熱量 |
| **實測效果** | 東京的試驗：傍晚灑水後 30–60 分鐘內，**地表 −10 至 −15°C**，**1.5 m 高處空氣 −1 至 −2°C** |
| **最佳時間** | **清晨（6–8 點）**和**傍晚（17:00 以後，太陽已離開地面時）**。灑在仍處於烈日下的地面上，水蒸發太快，難以產生持續效果 |
| **在哪裡** | **陰涼或正在降溫的地面**：入口通道、陽台地面、北側、屋簷下。**陽台**：混凝土地面和冷氣室外機周圍（不是室外機本身） |
| **多少水** | **每平方公尺 1–2 公升**——一勺或一澆水壺。積水沒有用；薄薄一層水膜才有用 |
| **用什麼水** | **洗澡剩水、雨水桶裡的雨水、冷氣排水、沖洗用過的水**——活動的規則是**「僅用二次水」**。乾旱警戒期間切勿使用自來水 |
| **禁忌** | 不要灑在**鄰居的牆壁、門前台階或晾曬衣物**上；不要灑在**有車經過的道路**上（濺水）；不要**每天灑在木質露台**上（腐朽）；不要用**含肥皂的水**澆植物 |

- **禮儀起源**：打水最初是**淨化與迎客**之舉——在客人到來前濕潤入口通道——同時也用於未鋪裝街道的防塵。人們也早已理解其降溫作用；**江戶時代的手冊**就推薦用它來提升傍晚的舒適感。
- **冷氣周圍**：替**室外機周圍區域**降溫（遮陽、濕潤附近的混凝土）可略微提高其效率；但製造商**不建議直接向室外機噴水**。
- **陽台與簷廊的日常**：許多家庭在傍晚開冷氣前，會先組合使用**簾（遮陽）+ 打水（蒸發）+ 開窗對流通風**，並表示房間需要的冷房量減少了。
- **社區活動**：「**打水大作戰**」（打ち水大作戦，東京，2003 年起）以及八月各市町村的打水日；**學校和商店街**會在指定日期的 17:00 一起打水。
- **濕度注意**：在本已潮濕、無風的傍晚（**相對濕度 75% 以上**），降溫效果很小，濕地面反而會加重悶熱感——**此時請跳過打水，改為通風**。

> **[待核實]** 降溫數值來自東京都的打水試驗；潛熱值（2,400 kJ/L）為標準物理常數。
