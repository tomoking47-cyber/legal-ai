# Q. 关于「土用干し」——盛夏晾晒衣物与书籍的习俗，人们常有哪些误解？｜Japanese Everyday Wisdom #516

- Shelf: `wisdom` ／ URL: `/zh-cn/wisdom/doyō-boshi-airing-clothes-and-books` ／ Status: **草稿 — 出处未核实**

在梅雨结束后最炎热、最干燥的那段日子——7月下旬的"土用"期间——日本家庭传统上会把橱柜里的东西全部取出：和服、冬季被褥、书籍、卷轴——在阴凉处晾上一天。这看起来古雅有趣；实际上它是一套防霉防虫的例行程序，时间正好安排在一年中空气干燥到足以见效的那一周。

## A. 常见的误解是认为晾晒就意味着晒太阳。土用干し（土用晾晒）是在有微风的阴凉处进行的——阳光会使染料褪色、使纸张发黄——并选在湿度低于60%、且之前已连续两三天干燥的日子，此时织物和纸张才能释放它们在梅雨季吸收的水分。和服反面朝外挂在衣架上，书籍打开立放、书页扇开，被褥平铺在晾衣杆上，一切只需几个小时；过程中顺便检查霉点和虫蛀，然后所有东西放回时换上新的干燥剂和防虫剂。现代公寓用一台除湿机加一个下午敞开的抽屉就能完成同样的工作，但日历上的这个提醒依然重要。

## 传统及其缘由

| 项目 | 详情 |
|---|---|
| **何时** | 夏季的**土用**：**立秋（8月上旬）前的约18天**，即大约**7月20日–8月6日**；晾晒日选在**湿度低（低于60%）且有微风**、并且之前**连续2–3天干燥**的日子。**秋季（10月中旬）**和**隆冬（1月下旬–2月）**也会进行——所谓"三次晾晒" |
| **为何是这时** | 梅雨季（**6月–7月中旬**，室内湿度70–85%）之后，收纳的织物和纸张含有水分；**相对湿度超过60–65%时霉菌会萌发**，而**衣蛾和地毯甲虫在初夏产卵**。第一波干热正是把东西晾干、尽早发现损伤的窗口期 |
| **阴凉，而非阳光** | **紫外线会使丝绸和染料褪色，使纸张和木质素发黄，使皮革和漆器干裂**。挂在屋檐下、室内开着的窗边，或在有风扇的遮阴房间里 |
| **多长时间** | 当天**3–5小时**；**10:00–15:00**湿度最低 |
| **和服** | 挂在**和服衣架（衣桁，ikō）**上，袖子展开，**反面朝外**；检查**斑点（霉）、发黄、虫洞**；沿原有折痕重新折好；若有污渍则换新的**包装纸（畳紙，tatōshi）** |
| **被褥、布団** | 平铺在阴凉处或阳光下的晾衣杆上（棉被可以晒太阳；**羽绒和羊毛放阴凉处**）；轻拍或用吸尘器清理 |
| **书籍、卷轴、照片** | **将书打开立放并扇开书页**；在干燥的房间里**将卷轴部分展开**；更换盒中的干燥剂 |
| **之后** | 只在**完全冷却、干燥**后放回；加入**新的干燥剂**和**一种防虫剂**（见防虫文章）；盒中放一张**湿度指示卡** |

- **要查看什么**：**白色或绿色斑点**（霉——在户外刷掉，棉制品用稀释酒精擦拭，丝绸交给专业清洗），**小孔**和**虫壳**（衣蛾与甲虫——羊毛制品冷冻48小时或干洗，并清理抽屉），纸上的**褐斑（foxing）**（褐色斑点——靠干燥保存来稳定；不要擦拭）。
- **现代等效做法**：在关闭的房间里**打开抽屉和衣柜，让除湿机运转**一个下午（目标**相对湿度50%**），或者用**浴室干燥模式**处理被褥。**真空压缩不能替代**——它会把已经存在的水分封在里面（见压缩袋文章）。
- **没有阳台的公寓**：打开衣柜，用风扇吹过，把东西铺在床上。
- **记录**：有传家和服的家庭会记一本**晾晒日期与状态的笔记**——这是大多数人做过的最早的"藏品管理"。
- **土用与鳗鱼**：同一个历法用语，也是日本人在**土用丑日吃鳗鱼**的由来——那是熬过酷暑的传统，而不只是保护衣柜。

> **[待核实]** 霉菌萌发阈值（相对湿度60–65%）和衣蛾生命周期的时间请对照害虫防治参考资料；当年的土用日期请对照气象厅/国立天文台的历法。
