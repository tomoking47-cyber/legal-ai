# Q. 關於「土用干し」——盛夏晾曬衣物與書籍的習俗，大家常有哪些誤解？｜Japanese Everyday Wisdom #516

- Shelf: `wisdom` ／ URL: `/zh-tw/wisdom/doyō-boshi-airing-clothes-and-books` ／ Status: **草稿 — 出處未核實**

在梅雨結束後最炎熱、最乾燥的那段日子——7月下旬的「土用」期間——日本家庭傳統上會把櫥櫃裡的東西全部拿出來：和服、冬季寢具、書籍、掛軸——在陰涼處晾上一天。看起來古雅有趣；實際上這是一套防霉防蟲的例行程序，時間正好安排在一年中空氣乾燥到足以見效的那一週。

## A. 常見的誤解是以為晾曬就等於曬太陽。土用干し（土用晾曬）是在有微風的陰涼處進行的——陽光會讓染料褪色、讓紙張泛黃——並選在濕度低於60%、且之前已連續兩三天乾燥的日子，此時織物和紙張才能釋放它們在梅雨季吸收的水分。和服反面朝外掛在衣架上，書本打開立放、把書頁扇開，寢具平鋪在曬衣桿上，一切只需幾個小時；過程中順便檢查霉點和蟲蛀，然後所有東西放回時換上新的乾燥劑和防蟲劑。現代公寓用一台除濕機加上一個下午敞開的抽屜就能完成同樣的工作，但日曆上的這個提醒依然重要。

## 傳統及其緣由

| 項目 | 詳情 |
|---|---|
| **何時** | 夏季的**土用**：**立秋（8月上旬）前的約18天**，即大約**7月20日–8月6日**；晾曬日選在**濕度低（低於60%）且有微風**、並且之前**連續2–3天乾燥**的日子。**秋季（10月中旬）**和**隆冬（1月下旬–2月）**也會進行——所謂「三次晾曬」 |
| **為何是這時** | 梅雨季（**6月–7月中旬**，室內濕度70–85%）之後，收納的織物和紙張含有水分；**相對濕度超過60–65%時霉菌會萌發**，而**衣蛾和地毯甲蟲在初夏產卵**。第一波乾熱正是把東西晾乾、及早發現損傷的窗口 |
| **陰涼，而非陽光** | **紫外線會讓絲綢和染料褪色，讓紙張和木質素泛黃，讓皮革和漆器乾裂**。掛在屋簷下、室內開著的窗邊，或在有電扇的遮陰房間裡 |
| **多長時間** | 當天**3–5小時**；**10:00–15:00**濕度最低 |
| **和服** | 掛在**和服衣架（衣桁，ikō）**上，袖子展開，**反面朝外**；檢查**斑點（霉）、泛黃、蟲洞**；沿原有摺痕重新摺好；若有污漬則換新的**包裝紙（畳紙，tatōshi）** |
| **寢具、布団** | 平鋪在陰涼處或陽光下的曬衣桿上（棉被可以曬太陽；**羽絨和羊毛放陰涼處**）；輕拍或用吸塵器清理 |
| **書籍、掛軸、照片** | **將書打開立放並扇開書頁**；在乾燥的房間裡**將掛軸部分展開**；更換盒中的乾燥劑 |
| **之後** | 只在**完全冷卻、乾燥**後放回；加入**新的乾燥劑**和**一種防蟲劑**（見防蟲文章）；盒中放一張**濕度指示卡** |

- **要檢查什麼**：**白色或綠色斑點**（霉——在戶外刷掉，棉製品用稀釋酒精擦拭，絲綢交給專業清洗），**小孔**和**蟲殼**（衣蛾與甲蟲——羊毛製品冷凍48小時或乾洗，並清理抽屜），紙上的**褐斑（foxing）**（褐色斑點——靠乾燥保存來穩定；不要擦拭）。
- **現代等效做法**：在關閉的房間裡**打開抽屜和衣櫃，讓除濕機運轉**一個下午（目標**相對濕度50%**），或者用**浴室乾燥模式**處理寢具。**真空壓縮不能替代**——它會把已經存在的水分封在裡面（見壓縮袋文章）。
- **沒有陽台的公寓**：打開衣櫃，用電扇吹過，把東西鋪在床上。
- **記錄**：有傳家和服的家庭會記一本**晾曬日期與狀態的筆記**——這是大多數人做過的最早的「收藏管理」。
- **土用與鰻魚**：同一個曆法用語，也是日本人在**土用丑日吃鰻魚**的由來——那是熬過酷暑的傳統，而不只是保護衣櫃。

> **[待核實]** 霉菌萌發閾值（相對濕度60–65%）和衣蛾生命週期的時間請對照害蟲防治參考資料；當年的土用日期請對照氣象廳/國立天文台的曆法。
