# Q. 關於矽藻土浴室地墊及其召回事件，大家常有哪些誤解？｜Japanese Everyday Wisdom #518

- Shelf: `wisdom` ／ URL: `/zh-tw/wisdom/diatomaceous-earth-bath-mats` ／ Status: **草稿 — 出處未核實**

2015年前後，一塊堅硬、粉筆質感的板子取代了許多日本浴室裡的毛巾布地墊：那就是「珪藻土」（矽藻土）地墊，它能在幾秒內吸乾濕腳印，然後自行變乾。2020年，多個品牌因石棉污染被召回，這種產品的聲譽至今沒有完全恢復。它擅長什麼、出了什麼問題、以及如何安全使用，值得分開來談。

## A. 常見的誤解要麼是以為所有矽藻土地墊都很危險，要麼是以為那次召回沒什麼大不了。2020年的召回涉及的是特定產品——進口的地墊和杯墊，其中的矽藻土摻入了含石棉的材料——由大型零售商販售，零售商公布了批次清單並進行回收。清單上的地墊不應打磨或敲碎；請依指示退回或處理。召回之後在日本標示下生產的產品都經過石棉檢測，一塊完好無損、正常當地墊使用的地墊不會造成接觸。日常的問題是另一回事：皂垢堵住孔隙後地墊會不再吸水（在戶外用附贈的砂紙輕磨，或用刷子清洗），摔落或踩踏不均會開裂，放在潮濕的地板上會長霉。

## 它是什麼，以及發生了什麼

| 項目 | 詳情 |
|---|---|
| **材質** | **矽藻土（珪藻土，keisōdo）**——矽藻殼的化石，多孔的二氧化矽——與黏合劑一起壓製成板。**透過毛細作用瞬間吸水，再蒸發出去** |
| **大家為什麼喜歡它** | 沒有濕答答的毛巾布地墊、**不用洗**、乾得快、沒有異味、可用**2–3年** |
| **2020–2021年的召回** | **在部分產品中發現了石棉**（地墊、杯墊、湯匙），販售方包括**Nitori（ニトリ，宜得利）、Cainz（カインズ）、Nafco（ナフコ）、與 Canon 相關的品牌等**；矽藻土在海外工廠被摻入了含石棉的材料。零售商公布了**批號和產品清單**，提供**退款和回收**。厚生勞動省的指引：**不要打磨、切割或敲碎**可疑產品；**包好後退回** |
| **實際風險** | 石棉的危害在於**纖維飄散到空氣中**——來自**打磨、切割或敲碎**。**一塊完好的地墊正常當地墊使用**不會釋放纖維；令人擔憂的是有人**打磨被召回的地墊以恢復吸水力** |
| **現在** | 在日本販售的產品帶有**「未檢出石棉」的檢測聲明**；**勞動安全衛生法**禁止石棉含量超過0.1%的產品 |

## 用好它

- **恢復吸水力**：當腳印久久不乾時，表示**肥皂和皮脂堵住了孔隙**。**用水和刷子清洗**，陰乾；若仍不理想，**用附贈的細砂紙輕磨——在戶外、戴口罩、把表面弄濕**——且僅限於您確知是召回後生產、經過檢測的產品。**絕不要打磨召回清單上的地墊。**
- **霉**：用後**側立放置**（多數產品附有立架）；出現斑點時**用稀釋酒精擦拭**；底面一直潮濕的地墊會在溝槽裡長黑霉。
- **開裂**：放在**平整的地面**上，不要跨在磁磚邊緣上；**不要摔落**。有些地墊有**軟質版本（矽藻土混入泡棉墊中）**，可以避免開裂和打磨的問題。
- **廚房用途**：**瀝水板、杯墊、鹽糖匙**——同樣的材質，同樣的規則。
- **處理**：大多數市町村歸入**不可燃 / 陶瓷類垃圾**（請確認）；**被召回的物品退回零售商**，不要丟進垃圾桶。
- **替代品**：速乾超細纖維地墊（可洗）、杉木踏板（すのこ，傳統做法，需要晾乾），以及每週洗兩次的毛巾布地墊——多數家庭最後回歸的正是這一種。

> **[待核實]** 零售商名稱以及2020–2021年召回的確切範圍請對照厚生勞動省/經濟產業省的清單；石棉閾值（0.1%）請對照勞動安全衛生法。
