# Q. 關於「家計簿」——日本的家庭帳本，大家常有哪些誤解？｜Japanese Everyday Wisdom #520

- Shelf: `wisdom` ／ URL: `/zh-tw/wisdom/kakeibo-household-budget-book` ／ Status: **草稿 — 出處未核實**

每年一月，日本的書店都會堆滿當年的「家計簿」（kakeibo）——印製好的家庭帳本，附有信封、每月彙總頁，以及食品、水電費和「特別支出」等欄位。這個做法始於1904年和一本面向主婦的雜誌；2010年代，它作為一種帶有正念色彩的預算方法走向了世界。在日本，它依然是一件樸實的工具，而且大多數使用它的家庭，用法比國外那些書裡描述的要簡單得多。

## A. 常見的誤解是以為家計簿是一項嚴格的、逐項記帳的練習。長期堅持記帳的家庭做的恰恰相反：他們先確定當月的固定支出和儲蓄，把剩餘部分分到四五個大類（食品、日用品、休閒、服裝/醫療、其他），每天或每週根據收據記錄總額，月底只看一個數字——剩下了多少。價值在於每週的一瞥，而不在於精確。無論是用紙本帳本（每年¥500–1,500）、免費 App 還是試算表，流程都是：先扣除固定支出和儲蓄，每週的食品預算用現金或一張卡，每月回顧三四行數字。

## 家庭實際採用的方法

| 步驟 | 內容 | 日本的做法 |
|---|---|---|
| **1. 先算固定支出** | 房租/房貸、水電瓦斯、保險、電話費、學費、貸款還款 | 月初寫一次；**自動扣款**；不逐日追蹤 |
| **2. 再算儲蓄** | 發薪日轉出一筆固定金額——「先取り貯金」（sakidori chokin，先存後花） | 典型目標為**實領薪資的10–20%**；許多人使用**自動轉帳**或**公司儲蓄（財形貯蓄，zaikei）** |
| **3. 剩餘 = 生活預算** | 分為**4–5類**：**食品**、**日用品（日用品，nichiyōhin）**、**休閒/外食**、**服裝與醫療**、**特別支出（禮品、旅行）** | **每週食品預算**是最常用現金管理的一項——信封法（「封筒分け」，fūtō-wake）——或者只用一張卡 |
| **4. 記錄** | **每天或每週**根據收據記總額——按類別而非按項目 | 5分鐘；收據夾在夾子裡；**四捨五入到¥100是常態** |
| **5. 月底** | 將各類別總額與預算比較；**記下要改變的一件事**；結餘轉入儲蓄或下月 | 印製的帳本為此**每月留一頁** |
| **6. 特別支出** | 單獨的**年度清單**：汽車稅（5月）、固定資產稅、保險、新年紅包、學費、家電 | 除以12按月預留——這一步區分了「總有意外支出」的家庭與沒有的家庭 |

- **為什麼有效**：它把**生活預算攤開來**，並讓**食品預算按週計算**——這是大多數家庭真正能改變的僅有的兩個數字。其餘的都是固定的。
- **紙本 vs App**：紙本家計簿（**婦人之友社、高橋書店、講談社；¥500–1,500**）適合主要用現金消費的人；**App（Zaim、MoneyForward ME、Moneytree）**可連結銀行和信用卡帳戶並自動分類——**40歲以下的人多數用 App**，60歲以上多數用紙本。**收據掃描**可涵蓋現金部分。
- **婦人之友模式**（羽仁もと子，1904年）：**在年初**按類別制定預算，並**只對照這些類別記錄**；創辦人的那句話——「**重點不在於記錄，而在於計畫**」——至今仍印在第一頁。
- **日本家庭的典型數字**（兩人以上戶，總務省統計局，2025年平均）：月消費支出**約¥314,000**；**食品約29%**（恩格爾係數達 **28.6%**，為 44 年來最高）、**水電瓦斯約8%**、**交通/通訊約14%**、**休閒約10%**。家庭會把自己的比例與這些數字對照。
- **常見的失敗**：**類別太多**和**逐項記錄**——大家到三月就放棄了。四個類別加一個每週總額才能撐下去。
- **夫妻**：**家庭開支用一本共同的家計簿**，加上**各自的個人零用錢（おこづかい，okozukai）**，是日本的標準安排；零用錢調查（新生銀行，每年）是全國性的話題。
- **孩子**：面向零用錢的兒童家計簿（「おこづかい帳」，okozukai-chō）有售；學校在家政課上使用。

> **[待核實]** 家庭消費數字和各類別占比請對照總務省統計局所引年份的調查；儲蓄率目標是編輯部歸納的慣例，並非官方指引。
