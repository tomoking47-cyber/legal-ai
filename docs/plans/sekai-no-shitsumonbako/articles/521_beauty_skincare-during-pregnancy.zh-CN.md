# Q. 孕期护肤：有哪些成分是不该用的？｜Japan Questions #521

- Shelf: `beauty` ／ URL: `/zh-cn/beauty/skincare-during-pregnancy` ／ Status: **草稿 — 出处未核实**

很多人一得知怀孕，马上就会想：「我一直在用的护肤品还安全吗？」社交媒体上「视黄醇绝对不能碰」「防晒霜也要避开」之类的说法混在一起。如果您在日本怀孕，又没办法把每一张成分标签都读懂，就更加困惑了。这里我们依据日本的法规体系和皮肤科医生的一般说明，把「该避开的」和「不必担心的」分开来讲。

## A. 在日本作为化妆品（化粧品／keshōhin）销售的产品，原则上孕期都可以使用。需要留意的有三点：①高浓度视黄醇（维生素A衍生物）产品，以及口服和处方类视黄酸类药物（异维A酸、维A酸）——后者在孕期属于禁忌；②使用氢醌或高浓度水杨酸的美白（美白）与去角质产品（最稳妥的做法是避开）；③不要一次性新增多种产品，因为激素变化会让皮肤更敏感。防晒霜反而是推荐使用的，可以防护孕期更容易出现的色斑（黄褐斑）。如果拿不准，可以把产品带到妇产科（産婦人科／sanfujinka）或皮肤科诊所（可用日本医保）去问。

## 逐一来看各种成分

| 成分／产品 | 孕期 | 原因 |
|---|---|---|
| **处方与口服视黄酸类药物**（异维A酸、维A酸、阿维A酯） | **禁忌**（必须在受孕前停用；部分药物停用后还需要避孕一段规定的时间） | 其致畸能力已经确立 |
| **化妆品中的视黄醇、视黄醛** | **在日本化妆品所使用的浓度下，尚未有明确的危害被证实，但许多皮肤科医生建议「以防万一」还是避开** | 经皮吸收很少，但也没有非用不可的必要 |
| **氢醌**（美白） | **最稳妥的做法是避开** | 据称经皮吸收率相对较高（**约35～45%**），且缺乏安全性数据 |
| **高浓度水杨酸（BHA）去角质** | **避开。** 洁面产品中的低浓度通常不被视为问题 | 因为与口服阿司匹林相似，所以处理上比较谨慎 |
| **防晒霜** | **推荐。** SPF30以上、PA+++以上，勤于补涂 | 孕期黑色素增加，**黄褐斑和色斑更容易出现**。以物理性（矿物）防晒剂——氧化锌与二氧化钛（「紫外線散乱剤」／紫外线散射剂）为主体的产品对皮肤更温和 |
| **烟酰胺、维生素C衍生物、透明质酸、神经酰胺** | 一般被描述为**可以使用** | 孕期使用未见有担忧的报告 |
| **壬二酸** | 皮肤科医生常用于孕期痤疮 | 安全性数据相对较好 |
| **精油（芳香疗法）** | **避免高浓度和不稀释直接使用。** 迷迭香、快乐鼠尾草、茉莉等，常被列为孕期应避开的精油 | 担心对子宫收缩的影响（证据强度不一） |
| **染发** | 经头皮吸收很少，**海外的产科指导一般把正常使用描述为可以接受**。日本许多美发师建议**等到稳定期（安定期／从大约第16周起）、保持良好通风，并采用让染膏不接触头皮的上色手法** | 气味也可能引起恶心 |

- **孕期皮肤会有哪些变化**：**激素让干燥、敏感、痤疮和色斑（黄褐斑）**更容易出现，并且**有50～90%的人会在腹部、胸部或大腿出现妊娠纹（妊娠線／ninshin-sen）**。妊娠纹主要由**体重急剧增加**和**皮肤被拉伸**引起；保湿产品能否预防妊娠纹，被描述为**作用有限**（可以期待它缓解瘙痒）。
- **不要新增产品**：皮肤敏感的时候一次加入多种成分，出了反应也分不清是哪一种引起的。**简单的保湿加防晒**就是基本的护理流程。
- **痤疮用药**：**即使是非处方的祛痘产品，也可能需要根据成分确认一下。** 告诉皮肤科医生您怀孕了（妊娠中です／ninshin-chū desu），医生会为您选择可以使用的外用产品。
- **「孕期可用」这类标示**：**并没有法律上的定义**——这是厂商自己的措辞。更可靠的做法是阅读成分表，并对照上面的表格来确认。
- **哺乳期**同样适用这一思路。**涂抹在乳房上的任何东西，喂奶前都要擦掉。**

> **[待核实]** 氢醌的皮肤吸收率和妊娠纹的发生率，是基于海外文献与日本妇产科学会资料的一般数值。处方视黄酸类药物的禁忌和避孕期间，请在各药品的说明书中确认。

## 误解1｜孕期任何化妆品都不能用

**在日本作为化妆品销售的产品，绝大多数孕期都可以使用。** 需要避开的项目很少，而防晒霜和保湿产品比任何时候都更重要。

## 误解2｜我用了含视黄醇的化妆品，孩子会受影响

**没有任何报告显示化妆品浓度的视黄醇会对胎儿产生影响。** 如果担心，停用并告诉产科医生一声就够了。属于禁忌的是处方与口服的视黄酸类药物。

## 误解3｜防晒霜全是化学成分，孕期要避开

**孕期在紫外线下更容易形成色斑和黄褐斑，因此推荐使用防晒霜。** 如果有顾虑，可以选择以氧化锌或二氧化钛为主体的产品。

## 误解4｜保湿霜能预防妊娠纹

**没有确切证据表明单靠保湿就能预防妊娠纹；体重管理和皮肤被拉伸的速度才是主要因素。** 保湿确实有助于缓解瘙痒。宣称「预防妊娠纹」的化妆品，在《药机法》（日本的化妆品与药品法规）上也是有问题的。

## 误解5｜标签上写着「孕期安全」，那就什么都可以

**这一措辞没有法律定义。** 请查看成分表，如果某个成分让您在意，就拿给医生看。
