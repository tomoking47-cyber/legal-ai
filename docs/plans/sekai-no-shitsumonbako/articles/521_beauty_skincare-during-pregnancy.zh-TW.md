# Q. 孕期保養：有哪些成分是不該用的？｜Japan Questions #521

- Shelf: `beauty` ／ URL: `/zh-tw/beauty/skincare-during-pregnancy` ／ Status: **草稿 — 出處未核實**

許多人一得知懷孕，馬上就會想：「我一直在用的保養品還安全嗎？」社群媒體上「A醇絕對不能碰」「防曬也要避開」之類的說法混在一起。如果您在日本懷孕，又沒辦法把每一張成分標示都讀懂，那就更加令人困惑了。這裡我們依據日本的法規制度與皮膚科醫師的一般說明，把「該避開的」和「不必擔心的」分開來談。

## A. 在日本以化妝品（化粧品／keshōhin）名義販售的產品，原則上懷孕期間都可以使用。需要留意的有三點：①高濃度A醇（維生素A衍生物）產品，以及口服與處方的類視黃醇藥物（異維A酸、A酸）——後者在懷孕期間屬於禁忌；②使用對苯二酚或高濃度水楊酸的美白（美白）與去角質產品（最穩妥的做法是避開）；③不要一次新增多種產品，因為荷爾蒙變化會讓皮膚變得更敏感。防曬其實是建議使用的，可以防護懷孕期間更容易出現的色斑（肝斑）。如果拿不定主意，可以把產品帶到婦產科（産婦人科／sanfujinka）或皮膚科診所（可使用日本健保）詢問。

## 逐一來看各種成分

| 成分／產品 | 懷孕期間 | 原因 |
|---|---|---|
| **處方與口服的類視黃醇藥物**（異維A酸、A酸、依曲替酯） | **禁忌**（必須在受孕前停用；部分藥物停用後還需避孕一段規定的期間） | 其致畸能力已經確立 |
| **化妝品中的A醇、A醛** | **在日本化妝品所使用的濃度下，尚未有明確的危害被證實，但許多皮膚科醫師建議「以防萬一」還是避開** | 經皮吸收很少，但也沒有非用不可的必要 |
| **對苯二酚**（美白） | **最穩妥的做法是避開** | 據稱經皮吸收率相對較高（**約35～45%**），且缺乏安全性資料 |
| **高濃度水楊酸（BHA）換膚** | **避開。** 洗面產品中的低濃度通常不被視為問題 | 因為與口服阿斯匹靈相似，所以處理上比較謹慎 |
| **防曬** | **建議使用。** SPF30以上、PA+++以上，勤於補擦 | 懷孕期間黑色素增加，**肝斑與色斑更容易出現**。以物理性（礦物）防曬劑——氧化鋅與二氧化鈦（「紫外線散乱剤」／紫外線散射劑）為主體的產品對皮膚較溫和 |
| **菸鹼醯胺、維生素C衍生物、玻尿酸、神經醯胺** | 一般被描述為**可以使用** | 懷孕期間使用未見有疑慮的報告 |
| **杜鵑花酸** | 皮膚科醫師常用於懷孕期間的痘痘 | 安全性資料相對較好 |
| **精油（芳香療法）** | **避免高濃度與未稀釋直接使用。** 迷迭香、快樂鼠尾草、茉莉等，常被列為懷孕期間應避開的精油 | 擔心對子宮收縮的影響（證據強度不一） |
| **染髮** | 經頭皮吸收很少，**海外的產科指引一般把正常使用描述為可以接受**。日本許多美髮師建議**等到穩定期（安定期／從大約第16週起）、保持良好通風，並採用讓染劑不接觸頭皮的上色手法** | 氣味也可能引起噁心 |

- **懷孕期間皮膚會有哪些變化**：**荷爾蒙讓乾燥、敏感、痘痘與色斑（肝斑）**更容易出現，而且**有50～90%的人會在腹部、胸部或大腿出現妊娠紋（妊娠線／ninshin-sen）**。妊娠紋主要由**體重急遽增加**與**皮膚被拉扯**造成；保濕產品能否預防妊娠紋，被描述為**作用有限**（可以期待它緩解搔癢）。
- **不要新增產品**：皮膚敏感的時候一次加入多種成分，出了反應也分不清是哪一種引起的。**簡單的保濕加防曬**就是基本的保養流程。
- **痘痘用藥**：**即使是市售的抗痘產品，也可能需要依成分確認一下。** 告訴皮膚科醫師您懷孕了（妊娠中です／ninshin-chū desu），醫師會為您挑選可以使用的外用產品。
- **「孕期可用」這類標示**：**並沒有法律上的定義**——這是廠商自己的說法。更可靠的做法是閱讀成分表，並對照上面的表格來確認。
- **哺乳期間**同樣適用這個思路。**塗抹在乳房上的任何東西，餵奶前都要擦掉。**

> **[待核實]** 對苯二酚的皮膚吸收率與妊娠紋的發生率，是根據海外文獻與日本婦產科學會資料的一般數值。處方類視黃醇藥物的禁忌與避孕期間，請在各藥品的仿單中確認。

## 誤解1｜懷孕期間任何化妝品都不能用

**在日本以化妝品名義販售的產品，絕大多數懷孕期間都可以使用。** 需要避開的項目很少，而防曬與保濕比任何時候都更重要。

## 誤解2｜我用了含A醇的化妝品，寶寶會受影響

**沒有任何報告顯示化妝品濃度的A醇會對胎兒產生影響。** 如果擔心，停用並向產科醫師提一句就夠了。屬於禁忌的是處方與口服的類視黃醇藥物。

## 誤解3｜防曬全是化學成分，懷孕期間要避開

**懷孕期間在紫外線下更容易形成色斑與肝斑，因此建議使用防曬。** 如果有疑慮，可以選擇以氧化鋅或二氧化鈦為主體的產品。

## 誤解4｜保濕霜可以預防妊娠紋

**沒有確切證據顯示單靠保濕就能預防妊娠紋；體重管理與皮膚被拉扯的速度才是主要因素。** 保濕確實有助於緩解搔癢。宣稱「預防妊娠紋」的化妝品，在《藥機法》（日本的化妝品與藥品法規）上也是有問題的。

## 誤解5｜標示上寫著「孕期安全」，那就什麼都可以

**這個說法沒有法律定義。** 請查看成分表，如果某個成分讓您在意，就拿給醫師看。
