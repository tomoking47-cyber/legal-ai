# Q. 顔の産毛は剃った方がいい？肌への影響とやり方｜世界の質問箱 #523

- 棚：`beauty` ／ URL：`/questions/facial-shaving-for-women` ／ ステータス：**ドラフト（法務レビュー前・出典未検証）**

眉の周り、口元、頬の産毛。日本では女性が顔をカミソリで剃る習慣が古くからあり、理容室の「レディースシェービング」も定着しています。「剃ると濃くなる」「化粧ノリが良くなる」など、話はいろいろ。皮膚への影響と、やるならどうするかを整理します。

## A. 顔の産毛を剃ること自体に医学的な問題はなく、剃っても毛が濃くなることはありません（断面が平らになり太く見えるだけ）。ただし顔の皮膚は薄く、カミソリは角層の一部も削るため、頻度は2〜3週間に1回、必ず石けんやシェービングフォームで滑らせ、毛の流れに沿って一方向に、剃ったあとは保湿——が肌を傷めない条件です。ニキビ・かぶれ・日焼け直後の肌には当てない。剃った直後は紫外線に弱いので、日焼け止めを忘れずに。

## 剃ることの影響と手順

| 項目 | 内容 |
|---|---|
| **毛が濃くなる？** | **ならない。** 毛の太さ・本数は毛根で決まり、剃ることでは変わらない。剃ると**毛の断面が平らになって太く見える**、**先端が丸くなくなるのでチクチク感じる**だけ |
| **肌への影響** | カミソリは**角層の一部（垢や古い角質）を一緒に削る**。剃り過ぎ・頻繫な剃毛は**乾燥・赤み・ヒリヒリ**の原因。適切な頻度なら「古い角質が取れて化粧ノリが良くなる」と感じる人も |
| **頻度** | **2〜3週間に1回**が目安。**週1以上**は角層への負担が大きい |
| **道具** | **顔用のガード付きカミソリ（L型）**、または**電気シェーバー（顔用）**。**体用のT字カミソリは刃が鋭く不向き**。刃は**3〜5回使ったら交換** |
| **手順** | ①洗顔して清潔に ②**シェービングフォームか石けんの泡**をのせる（乾いた肌には当てない） ③**毛の流れに沿って一方向**、軽い力で ④ぬるま湯で流す ⑤**化粧水・乳液でしっかり保湿** ⑥**日中は日焼け止め** |
| **避けるべき肌** | **ニキビ・湿疹・日焼け直後・ピーリング直後**。**ほくろ・イボ**の上は剃らない |
| **時間帯** | **夜**が無難（剃った直後は紫外線に弱く、化粧品もしみやすい） |

- **眉毛**：**眉ばさみと毛抜き**で整えるのが基本で、カミソリは眉の周りの産毛のみ。**眉の内側を剃ると生えてこなくなることがある**（毛周期の乱れ）ため、抜く・剃るは最小限に。
- **理容室のシェービング**：理容師（免許）による**顔そり**は日本独自のサービスで、**3,000〜6,000円**。カミソリの扱いが専門的で、**肌への負担が家庭より少ない**と感じる人が多い。**ブライダル前**の利用が定番。
- **除毛クリーム**：**顔には使えない製品が多い**（表示を確認）。アルカリ性で刺激が強い。
- **脱毛（光・レーザー）**：産毛はメラニンが少なく**光脱毛の効果が出にくい**部位。医療脱毛で対応可能だが回数が必要。
- **「濃くなった」と感じる理由**：断面の見え方に加え、**成長期の毛が同時に生えてくる**ため一時的に密度が高く見える。**2〜3週間**で元の見え方に戻ります。

> **【要検証】** 「剃ると濃くなることはない」は皮膚科の一般的な説明で、日本皮膚科学会Q&Aの該当箇所を確認してください。理容室のシェービング料金は目安です。

## 誤解1｜剃ると毛が濃くなる

**毛の太さは毛根で決まり、剃ることでは変わりません。** 断面が平らになって太く見えるだけで、伸びれば元の見え方に戻ります。

## 誤解2｜化粧ノリが良くなるから毎週剃る

**週1以上の剃毛は角層を削り過ぎ、乾燥・赤みの原因**になります。2〜3週間に1回で十分。

## 誤解3｜体用のカミソリでそのまま顔も剃れる

**体用のT字は刃が鋭く、顔の薄い皮膚には不向き**です。顔用のガード付きか電気シェーバーで。

## 誤解4｜乾いた肌にさっと当てれば時短になる

**乾いた肌に刃を当てると角層が削れてヒリヒリの原因**です。必ず泡をのせて。

## 誤解5｜剃ったあとは何も付けない方が肌に優しい

**剃った直後の肌はバリアが弱く、保湿と日焼け止めが必要**です。乾燥・赤み・シミの予防になります。
