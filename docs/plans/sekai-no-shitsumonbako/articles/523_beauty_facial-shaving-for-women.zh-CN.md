# Q. 女性该不该刮脸部汗毛？对皮肤的影响与正确做法｜Japan Questions #523

- Shelf: `beauty` ／ URL: `/zh-cn/beauty/facial-shaving-for-women` ／ Status: **草稿 — 出处未核实**

眉毛周围、唇上、脸颊上的细软汗毛。在日本，女性用剃刀刮脸已经有好几代人的历史，理发店的「女士修面」也是一项固定服务——这让很多外国来客感到意外。您会听到各种说法：「刮了以后毛会长得更粗」「刮完上妆更服帖」。这里我们来看看它对皮肤到底做了什么，以及如果要刮，该怎么刮。

## A. 刮脸部汗毛在医学上没有问题，而且刮毛并不会让毛长得更粗（切口是平的，所以只是看起来更粗）。但脸部皮肤很薄，剃刀在刮毛的同时也会带走一部分皮肤的最外层（角质层）。不伤到皮肤的条件是：每2～3周最多刮一次、一定要在肥皂或剃须泡沫上滑动刀片、顺着毛流朝一个方向刮、刮完做好保湿。有痘痘、皮疹或刚晒伤的皮肤不要刮。刚刮过的皮肤对紫外线很脆弱，所以别忘了防晒。

## 影响与方法

| 项目 | 详细说明 |
|---|---|
| **毛会长得更粗吗？** | **不会。** 毛的粗细与数量由毛根决定，刮毛不会改变它们。刮完之后，**切口是平的，所以毛看起来更粗**，而且**毛尖不再是圆的，摸上去会扎手**——仅此而已 |
| **对皮肤的影响** | 剃刀**会连同毛一起刮掉一部分角质层（已经死去的皮肤细胞）。** 刮过头或刮得太频繁会造成**干燥、发红和刺痛。** 在合理的频率下，有些人觉得「陈旧的角质掉了，上妆更服帖」 |
| **频率** | 大致**每2～3周一次**。**每周一次或更频繁**对角质层来说负担太重 |
| **工具** | **带护刃的脸部专用剃刀（L形，顔用カミソリ，松本清、Welcia 等任何一家药妆店都有卖）** 或 **脸部用电动剃须刀。** **身体用的T字剃刀刀锋太利，不适合。** 刀片**每用3～5次**更换一次 |
| **步骤** | ①洗脸，让皮肤干净 ②涂上**剃须泡沫或肥皂泡沫**（绝不在干燥的皮肤上刮） ③**顺着毛流，朝一个方向**，轻轻用力 ④用温水冲洗 ⑤**用化妆水（化粧水）和乳液（乳液）好好保湿** ⑥**白天涂防晒** |
| **不该刮的皮肤** | **痘痘、湿疹、刚晒伤的皮肤、刚做完去角质之后。** **痣和疣**上面不要刮 |
| **时段** | **傍晚**最安全（刚刮过的皮肤对紫外线脆弱，化妆品也更容易刺痛） |

- **眉毛**：用**修眉剪和镊子**修形；剃刀只用在眉毛周围的细软汗毛上。**眉毛反复拔，可能会变得难以再长出来**（毛囊受损），所以拔和刮都尽量少做。刮本身并不会让毛根消失。
- **理发店的修面**：由**持证理发师（理容師／riyōshi）做的脸部修面（顔そり／kaosori）**是一项很有日本特色的服务，价格在**3,000～6,000日元**。剃刀的操作是专业的，很多人觉得**比在家里自己刮对皮肤更温和。** 它也是经典的**婚前**仪式。
- **脱毛膏**：**很多产品不可用于面部**（请看标签）。它们呈碱性，具有刺激性。
- **光子与激光脱毛**：脸上的细软汗毛含黑色素很少，所以**光子（IPL）脱毛对它效果很差**。医疗激光脱毛能处理，但需要多次疗程。
- **为什么「感觉变粗了」**：除了平的切口之外，**处于生长期的毛会同时冒出来**，所以有一阵子看起来密度更高。**2～3周**后就恢复正常。

> **[待核实]** 「刮毛不会让毛变粗」是皮肤科的标准说明，请核对日本皮肤科学会Q&A的相关章节。理发店修面的价格仅供参考。

## 误解1｜刮了毛会长得更粗

**毛的粗细由毛根决定，刮毛不会改变它。** 平的切口只是看起来更粗，随着毛长长就恢复正常了。

## 误解2｜上妆更服帖，那就每周刮一次

**每周一次或更频繁会刮掉太多角质层，造成干燥和发红。** 每2～3周一次就够了。

## 误解3｜身体用的剃刀刮脸也一样

**身体用的T字剃刀刀锋很利，不适合薄薄的面部皮肤。** 请用带护刃的脸部专用剃刀或电动剃须刀。

## 误解4｜快速干刮更省时间

**在干燥的皮肤上用刀片会把角质层刮掉，造成刺痛。** 一定要用泡沫。

## 误解5｜刮完什么都不涂对皮肤更好

**刚刮过的皮肤屏障变弱，需要保湿和防晒。** 它们能防止干燥、发红和色斑。
