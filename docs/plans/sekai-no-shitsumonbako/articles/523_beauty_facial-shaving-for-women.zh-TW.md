# Q. 女性該不該刮臉上的汗毛？對皮膚的影響與正確做法｜Japan Questions #523

- Shelf: `beauty` ／ URL: `/zh-tw/beauty/facial-shaving-for-women` ／ Status: **草稿 — 出處未核實**

眉毛周圍、唇上、臉頰上的細軟汗毛。在日本，女性用刮鬍刀刮臉已經有好幾代人的歷史，理髮廳的「女士修面」也是一項固定服務——這讓許多外國旅客感到意外。您會聽到各式各樣的說法：「刮了以後毛會長得更粗」「刮完上妝更服貼」。這裡我們來看看它對皮膚究竟做了什麼，以及如果要刮，該怎麼刮。

## A. 刮臉上的汗毛在醫學上沒有問題，而且刮毛並不會讓毛長得更粗（切口是平的，所以只是看起來比較粗）。但臉部皮膚很薄，刮鬍刀在刮毛的同時也會帶走一部分皮膚的最外層（角質層）。不傷到皮膚的條件是：每2～3週最多刮一次、一定要在肥皂或刮鬍泡上滑動刀片、順著毛流朝同一個方向刮、刮完做好保濕。有痘痘、疹子或剛曬傷的皮膚不要刮。剛刮過的皮膚對紫外線很脆弱，所以別忘了防曬。

## 影響與做法

| 項目 | 詳細說明 |
|---|---|
| **毛會長得更粗嗎？** | **不會。** 毛的粗細與數量由毛根決定，刮毛不會改變它們。刮完之後，**切口是平的，所以毛看起來比較粗**，而且**毛尖不再是圓的，摸起來會刺刺的**——僅此而已 |
| **對皮膚的影響** | 刮鬍刀**會連同毛一起刮掉一部分角質層（已經死去的皮膚細胞）。** 刮過頭或刮得太頻繁會造成**乾燥、泛紅與刺痛。** 在合理的頻率下，有些人覺得「老舊的角質掉了，上妝更服貼」 |
| **頻率** | 大致**每2～3週一次**。**每週一次或更頻繁**對角質層來說負擔太重 |
| **工具** | **附護刃的臉部專用刮刀（L形，顔用カミソリ，松本清、Welcia 等任何一家藥妝店都有賣）** 或 **臉部用電動刮鬍刀。** **身體用的T字刮刀刀鋒太利，不適合。** 刀片**每用3～5次**更換一次 |
| **步驟** | ①洗臉，讓皮膚乾淨 ②抹上**刮鬍泡或肥皂泡**（絕不在乾燥的皮膚上刮） ③**順著毛流，朝同一個方向**，輕輕施力 ④用溫水沖洗 ⑤**用化妝水（化粧水）與乳液（乳液）好好保濕** ⑥**白天擦防曬** |
| **不該刮的皮膚** | **痘痘、濕疹、剛曬傷的皮膚、剛做完換膚之後。** **痣與疣**上面不要刮 |
| **時段** | **傍晚**最安全（剛刮過的皮膚對紫外線脆弱，化妝品也比較容易刺痛） |

- **眉毛**：用**修眉剪與鑷子**修型；刮刀只用在眉毛周圍的細軟汗毛上。**在眉毛內側刮，可能讓毛長不回來**（生長週期被打亂），所以拔與刮都盡量少做。
- **理髮廳的修面**：由**有執照的理髮師（理容師／riyōshi）所做的臉部修面（顔そり／kaosori）**是一項很有日本特色的服務，價格在**3,000～6,000日圓**。刀具的操作是專業的，許多人覺得**比在家裡自己刮對皮膚更溫和。** 它也是經典的**婚前**儀式。
- **除毛霜**：**很多產品不可用於臉部**（請看標示）。它們呈鹼性，具有刺激性。
- **光療與雷射除毛**：臉上的細軟汗毛含黑色素很少，所以**光療（IPL）除毛對它效果很差**。醫療雷射除毛可以處理，但需要多次療程。
- **為什麼「摸起來變粗了」**：除了平整的切口之外，**處於生長期的毛會同時冒出來**，所以有一陣子看起來密度較高。**2～3週**後就恢復正常。

> **[待核實]** 「刮毛不會讓毛變粗」是皮膚科的標準說明，請核對日本皮膚科學會Q&A的相關章節。理髮廳修面的價格僅供參考。

## 誤解1｜刮了毛會長得更粗

**毛的粗細由毛根決定，刮毛不會改變它。** 平整的切口只是看起來比較粗，隨著毛長長就恢復正常了。

## 誤解2｜上妝更服貼，那就每週刮一次

**每週一次或更頻繁會刮掉太多角質層，造成乾燥與泛紅。** 每2～3週一次就夠了。

## 誤解3｜身體用的刮刀拿來刮臉也一樣

**身體用的T字刮刀刀鋒很利，不適合薄薄的臉部皮膚。** 請用附護刃的臉部專用刮刀或電動刮鬍刀。

## 誤解4｜快速乾刮比較省時間

**在乾燥的皮膚上用刀片會把角質層刮掉，造成刺痛。** 一定要用泡沫。

## 誤解5｜刮完什麼都不擦對皮膚比較好

**剛刮過的皮膚屏障變弱，需要保濕與防曬。** 它們可以預防乾燥、泛紅與色斑。
