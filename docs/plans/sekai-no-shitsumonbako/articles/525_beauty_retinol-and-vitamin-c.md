# Q. レチノールやビタミンCの化粧品、本当に効くの？使い方の注意は｜世界の質問箱 #525

- 棚：`beauty` ／ URL：`/questions/retinol-and-vitamin-c` ／ ステータス：**ドラフト（法務レビュー前・出典未検証）**

「シワ改善」「毛穴」「くすみ」を掲げる成分として、レチノール（ビタミンA誘導体）とビタミンC誘導体は日本でも定番になりました。国内では2017年に純粋レチノールが「シワを改善する」効能で医薬部外品として承認され、話題が広がりました。何が認められていて、何が期待し過ぎかを整理します。

## A. レチノールは日本で「シワを改善する」効能が認められた数少ない成分の一つ（医薬部外品、承認製品に限る）で、根拠のある成分です。ビタミンC誘導体は「メラニンの生成を抑えシミ・そばかすを防ぐ」効能で医薬部外品に多く配合され、こちらも根拠があります。ただしどちらも化粧品としては「使用上の刺激」が課題で、レチノールは赤み・皮むけ（A反応）、ビタミンCはピリピリ感が出やすい。低濃度から週2〜3回で始め、夜に使い、日中は必ず日焼け止め、妊娠中はレチノールを避ける、が使い方の基本です。「1本でシワが消える」は期待し過ぎです。

## 2つの成分の位置づけ

| 項目 | レチノール（ビタミンA誘導体） | ビタミンC誘導体 |
|---|---|---|
| **国内の承認効能（医薬部外品）** | **「シワを改善する」**（2017年、純粋レチノールで承認。承認製品にのみ表示可） | **「メラニンの生成を抑え、シミ・そばかすを防ぐ」**（アスコルビン酸グルコシド、リン酸アスコルビルMgなど） |
| **化粧品としての位置づけ** | 「乾燥による小じわを目立たなくする」まで（効能評価試験済みの場合） | 「肌にハリ・ツヤを与える」「キメを整える」まで |
| **働き（研究で示されているもの）** | 表皮のターンオーバー促進、真皮のコラーゲン産生の促進、皮脂分泌の調整 | 抗酸化、メラニン生成の抑制、コラーゲン合成の補助 |
| **刺激** | **赤み・皮むけ・乾燥（レチノイド反応、A反応）**が**使用開始1〜4週間**に出やすい | **ピリピリ感、乾燥**（酸性度が高い製品ほど） |
| **光・熱** | **光と酸素で分解**しやすい。夜用、遮光容器 | **酸化しやすい**（黄色〜茶色に変色したら劣化）。誘導体は比較的安定 |
| **併用注意** | **ピーリング（AHA/BHA）、高濃度ビタミンC、他のレチノイド**との同時使用は刺激が重なる | 同上。**ナイアシンアミドとの併用は問題ないとされる** |
| **妊娠・授乳** | **避ける**のが一般的な案内 | 問題ないとされる |
| **効果が見えるまで** | **8〜12週間**以上 | **4〜12週間** |

- **使い方（レチノール）**：**夜のみ**、**洗顔→保湿→レチノール（米粒〜パール大）→クリーム**。**週2〜3回から**、刺激がなければ毎晩へ。**目の周り・口角・鼻の脇**は刺激が出やすいので薄く。**皮むけが強ければ休む**。**日中はSPF30以上**——レチノール使用中は紫外線に弱くなります。
- **使い方（ビタミンC）**：**朝でも夜でも**。朝に使うなら**日焼け止めの前**。**濃度10%以上の製品はピリピリしやすい**。**開封後2〜3か月**で使い切る。
- **「濃度が高いほど効く」ではない**：レチノールは**0.1%程度でも効果が報告**され、高濃度は刺激が増えるだけのことが多い。**「〇%配合」の数字競争は日本の化粧品では表示が制限されている**ため、海外製品の話が中心。
- **海外製（トレチノイン、高濃度レチノール）**：**トレチノインは日本では処方薬**で、個人輸入品での皮むけ・色素沈着トラブルの相談があります。
- **医薬部外品の「シワ改善」表示**：**承認された製品だけ**が表示できる。承認のない化粧品が「シワ改善」と書くのは薬機法違反。

> **【要検証】** 2017年のレチノール承認、ビタミンC誘導体の効能表示は厚生労働省の医薬部外品承認情報で確認してください。効果までの期間は臨床試験の一般的な報告値です。

## 誤解1｜レチノールを塗ればシワが消える

**承認された効能は「シワを改善する」で、深いシワが消えるという意味ではありません。** 目尻の小じわ程度で、12週間以上の使用が前提です。

## 誤解2｜赤みや皮むけが出たら肌に合わない

**使い始めの数週間に出るレチノイド反応は多くの人に起きます。** 頻度を減らして様子を見る。ただし**腫れ・かゆみ・ヒリヒリが強ければ中止**。

## 誤解3｜ビタミンCは酸っぱいから朝使うと日焼けする

**ビタミンC誘導体に光毒性はなく、朝の使用は問題ないとされます。** 日焼け止めは別に必要です。

## 誤解4｜レチノールとピーリングを同時に使えば早く効く

**刺激が重なって肌のバリアを壊し、逆に赤み・色素沈着の原因**になります。どちらか一つから。

## 誤解5｜海外の高濃度品を個人輸入した方がお得

**トレチノインは処方薬で、自己判断の使用で皮膚炎・色素沈着のトラブルが報告されています。** 国内の承認製品か皮膚科で。
