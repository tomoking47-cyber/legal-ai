# Q. 视黄醇和维生素C化妆品真的有用吗？有哪些注意事项？｜Japan Questions #525

- Shelf: `beauty` ／ URL: `/zh-cn/beauty/retinol-and-vitamin-c` ／ Status: **草稿 — 出处未核实**

视黄醇（维生素A衍生物）和维生素C衍生物在日本也已成为标配成分，主打「改善皱纹」「毛孔」「暗沉」。2017年，纯视黄醇在日本作为医药部外品（医薬部外品，介于化妆品与药品之间的一个日本类别）获批，可以宣称「改善皱纹」，关注度自此飙升。如果您习惯了自己国家的规则，请注意这里允许宣称的内容是不一样的。我们来梳理一下哪些是被认可的，哪些属于期待过高。

## A. 视黄醇是日本少数几个拥有官方认可的「改善皱纹」宣称的成分之一（作为医药部外品，且仅限于获批产品），其背后的证据是扎实的。维生素C衍生物则被广泛用于医药部外品，宣称「抑制黑色素生成、预防色斑与雀斑」，同样有证据支持。但作为化妆品，两者有一个共同的问题：使用时的刺激。视黄醇容易引起发红和脱皮（「视黄醇反应」，在日本称为「A反応」／A-hannō），维生素C则容易刺痛。基本原则是：从低浓度、每周两三次开始，晚上使用，白天一定要涂防晒，孕期避开视黄醇。「用完一瓶皱纹就没了」属于期待过高。

## 两种成分各自的定位

| 项目 | 视黄醇（维生素A衍生物） | 维生素C衍生物 |
|---|---|---|
| **日本认可的宣称（医药部外品）** | **「改善皱纹」**（纯视黄醇于2017年获批；只有获批产品可以这样标示） | **「抑制黑色素生成、预防色斑与雀斑」**（抗坏血酸葡糖苷、抗坏血酸磷酸酯镁等） |
| **作为化妆品的定位** | 最多到「让干燥引起的细纹变得不明显」（前提是做过功效测试） | 最多到「让肌肤有弹润与光泽」「细致肤质」 |
| **作用（研究中显示）** | 加快表皮更新、促进真皮的胶原蛋白生成、调节皮脂 | 抗氧化、抑制黑色素生成、支持胶原蛋白合成 |
| **刺激** | **发红、脱皮、干燥（视黄醇反应／A反応）**，最容易出现在**最初的1～4周** | **刺痛、干燥**（产品越偏酸性越明显） |
| **光与热** | **遇光和氧气会分解。** 晚上使用，装在遮光容器里 | **容易氧化**（变黄发褐说明已经劣化）。衍生物相对稳定 |
| **要避免的搭配** | 与**去角质（AHA／BHA）、高浓度维生素C或其他视黄酸类**同时使用会叠加刺激 | 同上。**与烟酰胺搭配一般被描述为没有问题** |
| **孕期与哺乳期** | 标准建议是**避开** | 一般被描述为可以使用 |
| **多久能看到效果** | **8～12周**以上 | **4～12周** |

- **视黄醇怎么用**：**只在晚上**，顺序是**清洁 → 保湿 → 视黄醇（米粒到珍珠大小） → 面霜。** **从每周2～3次开始**，若无刺激再改成每晚。在容易出现刺激的**眼周、嘴角和鼻翼两侧**要薄薄地涂。**如果脱皮严重，就休息一段时间。** **白天用SPF30以上**——使用视黄醇期间，皮肤对紫外线更脆弱。
- **维生素C怎么用**：**早晚均可。** 早上要**在防晒之前**涂。**浓度10%以上的产品容易刺痛。** 开封后**2～3个月**内用完。
- **浓度越高不等于越好**：视黄醇**在0.1%左右就已显示出效果**，更高的浓度往往只是增加刺激。**日本的化妆品被限制宣传「浓度百分之几」**，所以拼数字主要发生在进口产品上。
- **进口产品（维A酸、高强度视黄醇）**：**维A酸在日本属于处方药**，个人代购买来的产品造成脱皮与色素沉着的消费者投诉是存在的。
- **医药部外品的「改善皱纹」宣称**：**只有获批产品**可以使用。未经批准的化妆品宣称「改善皱纹」，违反《药机法》（日本的化妆品与药品法规）。

> **[待核实]** 2017年视黄醇的批准与维生素C衍生物的宣称，请对照厚生劳动省的医药部外品批准记录确认。见效时间是临床试验中报告的典型数值。

## 误解1｜涂上视黄醇皱纹就会消失

**获批的宣称是「改善皱纹」，并不意味着深皱纹会消失。** 它针对的是眼角的细纹，而且前提是使用12周以上。

## 误解2｜发红或脱皮说明它不适合我的皮肤

**最初几周的视黄醇反应在很多人身上都会发生。** 减少使用频率再观察。但**如果出现明显的肿胀、瘙痒或刺痛，就要停用。**

## 误解3｜维生素C是酸性的，早上用会晒伤

**维生素C衍生物没有光毒性，早上使用一般被描述为没有问题。** 防晒仍然要单独做。

## 误解4｜视黄醇和去角质一起用见效更快

**刺激叠加会破坏皮肤屏障，反而造成发红与色素沉着。** 先从其中一样开始。

## 误解5｜从国外个人进口高强度产品更划算

**维A酸是处方药，自行使用引发皮炎与色素沉着的案例是有报告的。** 请使用日本获批的产品，或去皮肤科诊所就诊（可用日本医保）。
