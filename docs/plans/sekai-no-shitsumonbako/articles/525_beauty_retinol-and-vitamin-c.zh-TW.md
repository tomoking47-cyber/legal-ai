# Q. A醇與維生素C保養品真的有效嗎？有哪些注意事項？｜Japan Questions #525

- Shelf: `beauty` ／ URL: `/zh-tw/beauty/retinol-and-vitamin-c` ／ Status: **草稿 — 出處未核實**

A醇（維生素A衍生物）與維生素C衍生物在日本也已成為基本款成分，主打「改善皺紋」「毛孔」「暗沉」。2017年，純A醇在日本以醫藥部外品（医薬部外品，介於化妝品與藥品之間的日本分類）取得核准，可以標示「改善皺紋」，關注度也自此大增。如果您習慣了自己國家的規則，請注意這裡允許標示的內容並不一樣。我們來梳理一下哪些是被認可的，哪些屬於期待過高。

## A. A醇是日本少數幾個擁有官方認可的「改善皺紋」標示的成分之一（作為醫藥部外品，且僅限核准產品），背後的證據相當扎實。維生素C衍生物則廣泛用於醫藥部外品，標示「抑制黑色素生成、預防色斑與雀斑」，同樣有證據支持。但作為化妝品，兩者有一個共同的問題：使用時的刺激。A醇容易造成泛紅與脫皮（「A醇反應」，在日本稱為「A反応」／A-hannō），維生素C則容易刺痛。基本原則是：從低濃度、每週兩三次開始，晚上使用，白天一定要擦防曬，懷孕期間避開A醇。「用完一瓶皺紋就不見了」屬於期待過高。

## 兩種成分各自的定位

| 項目 | A醇（維生素A衍生物） | 維生素C衍生物 |
|---|---|---|
| **日本核准的標示（醫藥部外品）** | **「改善皺紋」**（純A醇於2017年核准；只有核准產品可以這樣標示） | **「抑制黑色素生成、預防色斑與雀斑」**（抗壞血酸葡萄糖苷、抗壞血酸磷酸酯鎂等） |
| **作為化妝品的定位** | 最多到「讓乾燥造成的細紋較不明顯」（前提是做過功效測試） | 最多到「讓肌膚有彈潤與光澤」「使膚質細緻」 |
| **作用（研究中顯示）** | 加快表皮更新、促進真皮的膠原蛋白生成、調節皮脂 | 抗氧化、抑制黑色素生成、支持膠原蛋白合成 |
| **刺激** | **泛紅、脫皮、乾燥（A醇反應／A反応）**，最容易出現在**最初的1～4週** | **刺痛、乾燥**（產品越偏酸性越明顯） |
| **光與熱** | **遇光與氧氣會分解。** 晚上使用，裝在遮光容器裡 | **容易氧化**（變黃發褐表示已經劣化）。衍生物相對穩定 |
| **要避免的搭配** | 與**換膚（AHA／BHA）、高濃度維生素C或其他類視黃醇**同時使用會疊加刺激 | 同上。**與菸鹼醯胺搭配一般被描述為沒有問題** |
| **懷孕與哺乳期間** | 標準建議是**避開** | 一般被描述為可以使用 |
| **多久才看得到效果** | **8～12週**以上 | **4～12週** |

- **A醇怎麼用**：**只在晚上**，順序是**清潔 → 保濕 → A醇（米粒到珍珠大小） → 乳霜。** **從每週2～3次開始**，若無刺激再改成每晚。在容易出現刺激的**眼周、嘴角與鼻翼兩側**要薄薄地擦。**如果脫皮嚴重，就休息一陣子。** **白天用SPF30以上**——使用A醇期間，皮膚對紫外線更脆弱。
- **維生素C怎麼用**：**早晚皆可。** 早上要**在防曬之前**擦。**濃度10%以上的產品容易刺痛。** 開封後**2～3個月**內用完。
- **濃度越高不等於越好**：A醇**在0.1%左右就已顯示出效果**，更高的濃度往往只是增加刺激。**日本的化妝品被限制宣傳「濃度百分之幾」**，所以拚數字主要發生在進口產品上。
- **進口產品（A酸、高強度A醇）**：**A酸在日本屬於處方藥**，個人代購買來的產品造成脫皮與色素沉澱的消費者申訴確實存在。
- **醫藥部外品的「改善皺紋」標示**：**只有核准產品**可以使用。未經核准的化妝品標示「改善皺紋」，就違反《藥機法》（日本的化妝品與藥品法規）。

> **[待核實]** 2017年A醇的核准與維生素C衍生物的標示，請對照厚生勞動省的醫藥部外品核准紀錄確認。見效時間是臨床試驗中報告的典型數值。

## 誤解1｜擦上A醇皺紋就會不見

**核准的標示是「改善皺紋」，並不代表深層皺紋會消失。** 它針對的是眼角的細紋，而且前提是使用12週以上。

## 誤解2｜泛紅或脫皮代表它不適合我的皮膚

**最初幾週的A醇反應在很多人身上都會發生。** 減少使用頻率再觀察。但**如果出現明顯的腫脹、搔癢或刺痛，就要停用。**

## 誤解3｜維生素C是酸性的，早上用會曬傷

**維生素C衍生物沒有光毒性，早上使用一般被描述為沒有問題。** 防曬仍然要另外做。

## 誤解4｜A醇與換膚一起用見效更快

**刺激疊加會破壞皮膚屏障，反而造成泛紅與色素沉澱。** 先從其中一樣開始。

## 誤解5｜從國外個人進口高強度產品比較划算

**A酸是處方藥，自行使用引發皮膚炎與色素沉澱的案例已有報告。** 請使用日本核准的產品，或到皮膚科診所就診（可使用日本健保）。
