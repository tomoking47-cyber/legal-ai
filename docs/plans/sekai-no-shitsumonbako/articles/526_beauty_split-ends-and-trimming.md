# Q. 枝毛や切れ毛は、どうすれば減る？トリートメントで直る？｜世界の質問箱 #526

- 棚：`beauty` ／ URL：`/questions/split-ends-and-trimming` ／ ステータス：**ドラフト（法務レビュー前・出典未検証）**

毛先を見ると二つに割れている、途中で切れて短い毛が飛び出す。枝毛・切れ毛はほとんどの人に多少はあり、「トリートメントで補修」「切るしかない」と情報が分かれます。髪の構造から、直るもの・直らないもの、増やさない方法を整理します。

## A. 枝毛・切れ毛は髪のキューティクルが摩耗して内部（コルテックス）が裂けた状態で、髪は死んだ細胞なので元には戻りません。トリートメントは表面を一時的にコーティングして手触りと見た目を整えるだけで、割れた毛先は切るしか解決策がありません。予防が対策のすべてで、①濡れた髪をこすらない・すぐ乾かす、②ドライヤーは20cm離す・アイロンは160℃以下、③ブラッシングは乾いた髪に毛先から、④紫外線を避ける、⑤カラー・ブリーチの頻度を下げる、⑥6〜8週間ごとに毛先を1〜2cm整える。この6つで、新しい枝毛の発生は目に見えて減ります。

## 枝毛・切れ毛の原因と対策

| 原因 | 何が起きるか | 対策 |
|---|---|---|
| **濡れた髪の摩擦** | 濡れるとキューティクルが開き、強度は乾燥時の**7〜8割**。タオルでこすったり、濡れたままブラッシングすると剥がれる | **押さえて水気を取る**、**濡れた髪は目の粗いコームで毛先から**、**すぐ乾かす** |
| **熱** | 髪のたんぱく質は**130℃前後から変性**、水分が急激に抜けて空洞化 | ドライヤー**20cm離す・同じ場所に3秒以上当てない**、アイロン**160℃以下・1か所2〜3秒・毎日は避ける** |
| **化学処理** | カラー・ブリーチ・パーマがキューティクルと内部結合を壊す。**ブリーチ1回でキューティクルの多くが損傷** | 頻度を下げる（全体カラーは2〜3か月に1回）、リタッチ中心、処理後1週間は熱と紫外線を避ける |
| **紫外線** | たんぱく質を分解、色素も分解 | 帽子・日傘・髪用UVスプレー |
| **ブラッシング** | 硬いブラシで乾いた髪を根元から一気にとくと、絡まりが引き裂ける | **毛先→中間→根元**の順、**天然毛かクッションブラシ**、1日に何度もとかない |
| **摩擦（枕・襟・マフラー）** | 寝ている間の摩擦、冬の襟・マフラーのこすれ | シルクやサテンの枕カバー、長い髪はゆるくまとめて寝る、マフラーの内側に髪を入れない |
| **栄養・体調** | 極端なダイエット、鉄不足、産後 | 通常の食事で改善。急な変化は医療機関へ |

- **トリートメントの役割**：**表面をコーティングして摩擦を減らし、水分の出入りを抑える**。これは「新しい枝毛を作りにくくする」予防効果で、**できた枝毛を接着して戻す効果はない**（一時的に見えにくくなるだけ）。「補修」という表現は薬機法上、「損傷を修復する」意味では使えず、「なめらかにする」「まとまりやすくする」までが化粧品の範囲です。
- **切る**：枝毛は放置すると**裂け目が上に進む**ため、**毛先1〜2cmを6〜8週間ごと**に整えるのが最も確実。自分で切る場合は**専用のはさみ（髪用）**で、**まっすぐ横に**。文房具のはさみは切り口が潰れて枝毛の原因に。
- **毛先の見分け**：**Y字に割れている（枝毛）**、**白い点がある（節、切れる直前）**、**ちりちりして短い毛が飛び出す（切れ毛）**。
- **髪の伸びる速さ**は**月に約1〜1.5cm**。毛先が肩に届く長さの髪は**2年以上前に生えた部分**で、それだけ摩擦と熱を受けています。ロングヘアに枝毛が多いのは当然で、手入れの累積が結果に出ます。
- **洗い流さないトリートメント（アウトバス）**：**タオルドライ後、毛先中心**に。**オイルタイプ**は熱から守り、**ミルクタイプ**は水分を補う。頭皮に付けない。

> **【要検証】** 髪のたんぱく質の変性温度、濡れた髪の強度低下は毛髪科学の一般的な説明値です。日本毛髪科学協会・化粧品工業会の資料で確認してください。

## 誤解1｜トリートメントで枝毛が直る

**髪は死んだ細胞で、割れた毛先は元に戻りません。** トリートメントは手触りと見た目を整え、新しい枝毛を予防する道具です。枝毛は切る。

## 誤解2｜枝毛だけ探して切ればいい

**枝毛の周りの髪も同じダメージを受けており、次の枝毛候補**です。毛先を全体的に1〜2cm切る方が効果的。

## 誤解3｜髪は自然乾燥が一番優しい

**濡れた時間が長いほどキューティクルが開いたまま摩擦を受けます。** 正しく使えばドライヤーの方が負担は小さい。

## 誤解4｜ブラッシングを増やせばツヤが出て枝毛が減る

**過度なブラッシングは摩擦で枝毛を増やします。** 1日1〜2回、毛先から、絡まりをほどくように。

## 誤解5｜高いシャンプーに替えれば解決する

**シャンプーの違いより、乾かし方・熱・ブラッシング・カラー頻度の影響がはるかに大きい**です。習慣を先に見直す。
