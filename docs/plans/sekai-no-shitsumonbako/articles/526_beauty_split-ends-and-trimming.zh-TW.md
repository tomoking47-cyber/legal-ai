# Q. 怎樣才能減少分岔和斷髮？護髮素（護髮膜）能修復它們嗎？｜Japan Questions #526

- Shelf: `beauty` ／ URL: `/zh-tw/beauty/split-ends-and-trimming` ／ Status: **草稿 — 出處未核實**

看向髮尾，發現頭髮裂成了兩半；髮中還翹出一根根斷掉的短髮。幾乎每個人都有一些分岔和斷髮，而聽到的建議總是分成兩派：一派說「用護髮膜修復」，一派說「唯一的辦法就是剪掉」。在日本，外來語「トリートメント」（torītomento）只是護髮素或護髮膜的日常叫法，讓人更加混亂。我們從頭髮的構造講起，理清什麼能補救、什麼不能，以及怎樣才能不再製造新的損傷。

## A. 分岔或斷髮，是毛鱗片（角質層）磨損脫落後，內部的皮質層被撕開的結果。頭髮是已經死亡的細胞，不會回到原來的樣子。護髮素或護髮膜只是在表面短暫地包覆一層，改善手感與外觀；分岔只能剪掉。預防才是全部：① 不要摩擦濕髮，並儘快吹乾；② 吹風機保持 20 公分距離，離子夾控制在 160℃ 以下；③ 在乾髮狀態下梳理，從髮尾開始；④ 避開紫外線；⑤ 減少染髮與漂髮的次數；⑥ 每 6～8 週把髮尾剪掉 1～2 公分。做到這六點，新的分岔會明顯減少。

## 成因與對策

| 成因 | 會發生什麼 | 怎麼做 |
|---|---|---|
| **濕髮時的摩擦** | 濕髮的毛鱗片是張開的，強度只有乾髮的 **70～80%**。用毛巾搓揉或在濕髮狀態下梳理，會把毛鱗片剝掉 | **按壓吸水，不要搓揉**；**濕髮用寬齒梳，從髮尾開始**；**儘快吹乾** |
| **熱** | 頭髮的蛋白質**在乾髮狀態下約 130～150℃ 開始變性，超過 150℃ 後變性加劇**（**濕髮則從 60～70℃ 開始**）；水分迅速流失，留下空洞 | 吹風機**距離 20 公分，同一處絕不超過 3 秒**；離子夾**只用於乾髮，最高 150～160℃，每一束 2～3 秒，不要每天使用**；**不要用在濕髮上** |
| **化學處理** | 染髮、漂髮和燙髮會破壞毛鱗片以及內部的鍵結。**僅一次漂髮就會損傷大部分毛鱗片** | 減少次數（全頭染髮每 2～3 個月一次），以補染髮根為主，之後一週避開高溫與紫外線 |
| **紫外線** | 分解蛋白質與色素 | 帽子、陽傘、頭髮用防曬噴霧 |
| **梳理** | 拿硬毛梳從髮根一口氣梳到底，會硬扯開打結處 | **髮尾 → 中段 → 髮根**，**天然鬃毛梳或氣墊梳**，一天不要梳很多次 |
| **摩擦（枕頭、衣領、圍巾）** | 睡眠中的摩擦；冬天衣領與圍巾的摩擦 | 真絲或緞面枕頭套，長髮鬆鬆地綁起來睡，不要把頭髮塞進圍巾裡 |
| **營養與健康狀況** | 極端節食、缺鐵、產後 | 恢復正常飲食即可改善。突然出現變化請就醫 |

- **護髮素或護髮膜的作用**：**包覆表面，減少摩擦，減緩水分進出的速度。** 這是一種預防性的效果——「讓新的分岔不易發生」——**它並不能把已經裂開的地方黏回去**（只是暫時遮住而已）。依據《藥機法》（醫藥品醫療器材等法，日本關於化妝品與藥品的法律），「補修」（「補修」）一詞不能用來表示「修復損傷」；化妝品最多只能說到「令頭髮柔順」「讓頭髮更好整理」。
- **剪**：放著不管，分岔會**沿著髮絲向上蔓延**，所以**每 6～8 週把髮尾剪掉 1～2 公分**是最可靠的辦法。若在家自己剪，請使用**理髮專用剪刀**，並且**平口剪斷。** 文具剪刀會壓壞切口，造成新的分岔。
- **看懂你的髮尾**：**分成 Y 字形（分岔）**、**出現白點（結節——即將斷裂）**、**翹出的毛躁短髮（斷髮）。**
- **頭髮每月長約 1～1.5 公分。** 長到肩膀的頭髮是**兩年多以前長出來的**，已經承受了那麼久的摩擦與高溫。長髮本來就更容易有分岔；日積月累的保養會體現在結果上。
- **免沖洗護髮產品**（「アウトバス」，日本店裡所說的「out-bath」＝出浴後使用的產品）：**用毛巾吸乾水分後使用，以髮尾為主。** **油類**能防熱；**乳液（milk）類**能補水。避開頭皮。

> **[待核實]** 頭髮蛋白質的變性溫度，以及濕髮強度下降的數值，是毛髮科學中的常用數據。請對照日本毛髮科學協會 [日本毛髪科学協会] 與日本化妝品工業會 [日本化粧品工業会] 的資料核實。

## 誤解1｜護髮膜能修復分岔

**頭髮是已經死亡的細胞，分岔不會復原。** 護髮素或護髮膜能改善手感與外觀，並幫助預防新的分岔。分岔是要剪掉的。

## 誤解2｜只要找出分岔的那幾根剪掉就好

**分岔周圍的頭髮受到了同樣的損傷，接下來就輪到它們。** 把所有髮尾修掉 1～2 公分更有效。

## 誤解3｜自然風乾對頭髮最溫和

**頭髮保持潮濕的時間越長，毛鱗片張開著承受摩擦的時間就越長。** 正確使用吹風機，損傷反而更小。

## 誤解4｜多梳頭能讓頭髮更亮、分岔更少

**過度梳理會增加摩擦，製造分岔。** 一天一到兩次，從髮尾開始，慢慢把結梳開。

## 誤解5｜換一款貴的洗髮精就能解決

**吹乾的方式、加熱、梳理，以及染髮的頻率，都比洗髮精重要得多。** 先改習慣。
