# Q. 赤ら顔・頬の赤み、化粧品で対処できる？皮膚科に行く目安は｜世界の質問箱 #528

- 棚：`beauty` ／ URL：`/questions/facial-redness` ／ ステータス：**ドラフト（法務レビュー前・出典未検証）**

頬や鼻の赤みが取れない、少し暑いとすぐ顔が真っ赤になる——「赤ら顔」は化粧品売り場でも皮膚科でもよく聞く悩みです。原因は皮膚が薄くて血管が透けるタイプから、酒さ（しゅさ）や皮膚炎まで幅があり、化粧品で対処できる範囲は限られます。

## A. 赤みの原因を分けると、①皮膚が薄く血管が透ける・気温差で拡張しやすい体質、②敏感肌・乾燥によるバリアの低下、③洗顔・スクラブ・ピーリングなどの刺激、④酒さや脂漏性皮膚炎、接触皮膚炎などの皮膚疾患。①②③は「刺激を減らす（洗い過ぎ・こすらない・熱い湯を避ける）＋保湿＋紫外線対策」で軽くなることが多く、化粧品の役割はここまで。ほてり・ブツブツ・血管の浮きが続く、皮がむける、かゆみがある場合は④の可能性があり、化粧品を変えるより皮膚科で診断を受ける方が近道です。酒さは日本でも診療ガイドラインができ（2023年）、治療薬が処方できます。

## 赤みの原因と対応

| 原因 | 特徴 | 対応 |
|---|---|---|
| **血管が透けやすい体質・気温差** | 暑い・寒い・緊張で一気に赤くなる。**冷めれば戻る**。皮膚が薄い人、色白の人に多い | 温度差を避ける（外から暖房の部屋へ入る時はマフラーをゆるめる等）、刺激の少ないスキンケア。**グリーン系の下地**で補色 |
| **乾燥・バリア低下（敏感肌）** | カサつき、ヒリヒリ、化粧水がしみる | **洗顔は1日2回まで、ぬるま湯、こすらない**、**保湿（セラミド等）**、**日焼け止め**。新製品を増やさない |
| **スキンケアの刺激** | スクラブ・ピーリング・高濃度ビタミンC・レチノール・アルコールの多い化粧水を使い始めてから | **その製品をやめて2〜4週間**様子を見る。それでも治まらなければ受診 |
| **酒さ（しゅさ）** | **頬・鼻・あご・額の中心に持続する赤み**、**ほてり**、**細い血管が浮く**、**ニキビのようなブツブツ**（膿疱）。**30〜50代の女性に多い**。**日光・アルコール・辛い食べ物・熱い風呂・ストレス**で悪化 | **皮膚科**。日本でも**2023年に「酒さ診療ガイドライン」**が公表され、**外用薬（メトロニダゾール、イベルメクチン）・内服薬**が使われる。化粧品では治まらない |
| **脂漏性皮膚炎** | **鼻の脇・眉間・生え際**の赤みと**皮むけ**、かゆみ | 皮膚科（抗真菌薬・ステロイド外用） |
| **接触皮膚炎（かぶれ）** | 特定の製品を使った部位に一致する赤み・かゆみ・小さなブツブツ | 原因製品を中止、皮膚科でパッチテスト |
| **ステロイド外用薬の長期使用** | 顔にステロイドを長く塗った後の赤み・血管拡張 | **自己判断で中止しない**。処方医に相談 |

- **化粧品でできること**：**刺激を足さない**（洗い過ぎない、こすらない、アルコール・香料・スクラブを避ける）、**保湿でバリアを整える**、**紫外線を避ける**（酒さも敏感肌も日光で悪化）、**赤みを補色でカバーする**（グリーンの下地・コントロールカラー）。**「赤みを改善する」効能は化粧品には認められていません。**
- **やってはいけないこと**：**赤みを取ろうとして洗顔を増やす・ピーリングする・冷水で引き締める**——いずれも刺激で悪化する方向。**熱い湯での洗顔・長風呂・サウナ**も血管を広げます。
- **皮膚科に行く目安**：**赤みが数週間以上続く**、**ほてりが頻繫**、**ブツブツ・膿を伴う**、**細い血管が浮いてきた**、**皮むけ・かゆみ**、**化粧品を変えても変わらない**。酒さは**早く治療を始めるほど血管の変化が進みにくい**とされます。
- **酒さの生活指導（ガイドラインで挙げられるもの）**：**日焼け止め（物理的散乱剤タイプが低刺激）**、**アルコール・辛いもの・熱い飲食物を控える**、**急な温度変化を避ける**、**低刺激のスキンケア**。

> **【要検証】** 「酒さ診療ガイドライン」の公表年（2023年）と推奨薬、酒さの好発年齢は日本皮膚科学会の資料で確認してください。

## 誤解1｜赤ら顔は化粧品で治せる

**化粧品ができるのは刺激を減らす・保湿・紫外線対策・カバーまで**です。持続する赤み、ブツブツ、血管の浮きは皮膚科の領域です。

## 誤解2｜赤みは血行が悪いからマッサージで流す

**赤みの多くは血管が拡張している状態で、マッサージの摩擦は悪化させます。** 触らない・こすらないが基本。

## 誤解3｜冷水で洗えば赤みが引く

**一時的に血管が縮んでも、反動で拡張しやすく、冷水の刺激自体も負担**です。ぬるま湯で。

## 誤解4｜ニキビだと思って市販のニキビ薬を塗っている

**頬・鼻を中心にほてりを伴うブツブツは酒さの可能性**があり、ニキビ薬では改善しません。皮膚科で診断を。

## 誤解5｜赤ら顔は体質だから諦めるしかない

**体質由来でも、刺激と温度差の管理、紫外線対策で見え方は変わります。** 酒さなら治療薬があり、血管の浮きには美容皮膚科のレーザー治療も選択肢です。
