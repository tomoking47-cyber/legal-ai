# Q. 拭き取りタイプのクレンジングシート、毎日使っても大丈夫？｜世界の質問箱 #529

- 棚：`beauty` ／ URL：`/questions/makeup-removal-wipes` ／ ステータス：**ドラフト（法務レビュー前・出典未検証）**

疲れて帰った夜、洗面所に行かずに済むクレンジングシート。旅行やジムでも便利で、日本のドラッグストアでは大容量パックが定番です。「肌に悪い」とも聞きますが、何が問題で、どう使えば負担が少ないのかを整理します。

## A. クレンジングシートは「こすって落とす」道具で、洗い流すタイプよりも肌への摩擦が大きくなりやすい点が最大の弱点です。毎日の使用は、色素沈着（茶クマ・くすみ）や乾燥の原因になり得るため、基本は「どうしてもの日」や旅行用と位置づけ、使うときは①肌に数秒当ててメイクを浮かせてから、②力を入れず一方向に滑らせ、③アイメイクは別のシートか綿棒で、④使用後はぬるま湯で洗い流すか、少なくとも化粧水で拭き取り成分を除いてから保湿。シートに含まれる洗浄成分やアルコールが肌に残るのを避けるのがポイントです。

## クレンジングシートの特徴

| 項目 | 内容 |
|---|---|
| **落とす仕組み** | 不織布に**洗浄成分（界面活性剤）・保湿剤・水またはアルコール**を含ませ、**物理的に拭き取る**。洗い流しタイプが「溶かして流す」のに対し「溶かして拭く」 |
| **最大の弱点** | **摩擦**。顔の皮膚、特に目の周り（約0.5mm）は薄く、繰り返しの摩擦で**色素沈着・小じわ・赤み**の原因に |
| **もう一つの弱点** | **洗浄成分が肌に残る**。洗い流さないと、界面活性剤・アルコール・防腐剤が肌に留まり、乾燥・刺激の原因 |
| **向く場面** | **旅行・出張、ジム、キャンプ、災害時**、**疲れてどうしても洗面所に立てない夜** |
| **向かない人** | **敏感肌、乾燥肌、ニキビが多い人、目元の色素沈着が気になる人**の毎日使用 |
| **使い方の目安** | **週1〜2回まで**を目安に。使う時は**1枚で顔全体をこすり回さず**、**Tゾーン→頬→目元と面を替えて** |

- **使い方の手順**：①**シートを顔に数秒当てて**メイクをなじませる（すぐ拭かない） ②**内から外へ、下から上へ、一方向に**軽く滑らせる ③**アイメイク・口紅は面を替えるか2枚目**。目元は**押さえて5〜10秒待ってから、まぶたの上をそっと滑らせる** ④**その後ぬるま湯で洗い流す**（洗顔料は不要な場合が多い） ⑤**保湿**。
- **アルコール（エタノール）**：清涼感・速乾のために配合されることが多く、**敏感肌には刺激**。**「アルコールフリー」**表示を選ぶ。
- **保存**：**乾くと洗浄成分が濃縮して刺激が増す**うえ、拭き取り力も落ちる。**開封後はフタをしっかり閉め、1〜2か月で使い切る**。
- **大きめのメイク（ウォータープルーフのマスカラ、ティントリップ）**はシートでは落ちにくく、**こすり過ぎの原因**。専用リムーバーを併用。
- **「洗い流し不要」表示について**：**表示上は不要でも、肌に成分を残さない方が負担は少ない**、というのが多くの皮膚科医の意見。可能なら流す。
- **災害時**：水が使えない状況では**肌の清潔を保つ有効な手段**。防災バッグに入れておく価値はあります。

> **【要検証】** 皮膚の厚さ、開封後の使用期限の目安は一般的な説明値です。製品ごとの表示に従ってください。

## 誤解1｜「洗い流し不要」だから、拭いてそのまま寝ていい

**洗浄成分が肌に残り、乾燥や刺激の原因になります。** 可能ならぬるま湯で流す、最低でも化粧水で拭き取ってから保湿。

## 誤解2｜シートは便利だから毎日でいい

**摩擦の蓄積で色素沈着やくすみの原因になり得ます。** 「どうしてもの日」と旅行用に。

## 誤解3｜しっかり落とすために強くこする

**摩擦が最大の弱点です。** 数秒当てて浮かせてから、軽く一方向に。落ちなければ専用リムーバーで。

## 誤解4｜1枚で全部落とせば経済的

**同じ面でこすり回すと、落としたメイクを塗り広げて摩擦も増えます。** 面を替える、目元は別に。

## 誤解5｜開封して半年たったシートでも問題ない

**乾いたシートは成分が濃くなり刺激が増え、雑菌の心配もあります。** 開封後1〜2か月で使い切る量を買う。
