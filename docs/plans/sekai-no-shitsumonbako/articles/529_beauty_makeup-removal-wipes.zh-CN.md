# Q. 卸妆湿巾：每天用也没关系吗？｜Japan Questions #529

- Shelf: `beauty` ／ URL: `/zh-cn/beauty/makeup-removal-wipes` ／ Status: **草稿 — 出处未核实**

累到家的时候，一张卸妆湿巾就省下了去洗手间的那一趟。旅行和健身房也很方便，日本的药妆店（松本清、Welcia 等）还成包地卖大容量装。你可能也听说过「它对皮肤不好」。这里我们看看问题究竟出在哪里，以及怎样用才对皮肤负担最小。

## A. 卸妆湿巾是靠「擦」来卸妆的，它最大的弱点是比冲洗型卸妆产品带来更多的摩擦。每天使用可能导致色素沉着（褐色黑眼圈、暗沉）与干燥，所以请把湿巾留给「实在撑不住的夜晚」和旅行。真的要用时：① 先贴在皮肤上停留几秒，让彩妆松动；② 不施力，朝一个方向滑动；③ 眼妆另用一张湿巾或棉签；④ 之后用温水冲洗，至少也要用化妆水把残留擦掉，然后保湿。关键是不要让湿巾里的清洁成分和酒精留在皮肤上。

## 卸妆湿巾是什么

| 项目 | 内容 |
|---|---|
| **作用原理** | 无纺布浸润了**清洁成分（表面活性剂）、保湿剂，以及水或酒精**，**用物理方式把彩妆擦掉。** 冲洗型卸妆是「溶解后冲掉」；湿巾是「溶解后擦掉」 |
| **最大的弱点** | **摩擦。** 面部皮肤，尤其眼周（约 0.5 毫米）很薄，反复摩擦会造成**色素沉着、细纹与泛红** |
| **第二个弱点** | **清洁成分留在皮肤上。** 若不冲洗，表面活性剂、酒精与防腐剂会残留，引起干燥与刺激 |
| **适合的场合** | **旅行与出差、健身房、露营、灾害时**，以及**累到站不到洗手台前的夜晚** |
| **不适合每天使用的人** | **敏感肌或干性肌、痘痘多、眼周有色素沉着的人** |
| **频率** | 大致**每周一到两次为限。** 使用时，**不要用一张湿巾擦遍整张脸**；**T 区 → 面颊 → 眼部，换面使用** |

- **步骤**：① **把湿巾贴在脸上停留几秒**，让彩妆松动（不要马上擦）② 轻轻地**由内向外、由下向上，朝一个方向**滑动 ③ **眼妆和口红要换面，或另用一张湿巾。** 眼部**先按压等待 5～10 秒，再轻轻滑过眼睑** ④ **然后用温水冲洗**（通常不需要再用洁面乳）⑤ **保湿。**
- **酒精（乙醇）**：常被添加以带来清凉感和快干，**对敏感肌是刺激。** 请选择标示**「无酒精」（アルコールフリー）**的湿巾。
- **保存**：**湿巾变干后，清洁成分会更浓、刺激更强**，清洁力也更差。**开封后请把盖子盖紧，并在 1～2 个月内用完。**
- **厚重的妆（防水睫毛膏、唇釉）**用湿巾不容易卸掉，**会导致过度擦拭。** 请同时使用专用卸妆产品。
- **关于「无需冲洗」的标示**：**即使标签说不必冲洗，多数皮肤科医生仍认为皮肤上不留残余更好。** 能冲就冲。
- **灾害时**：在没有水的情况下，湿巾是**保持皮肤清洁的有效方法。** 值得放进防灾包（「防災バッグ」，bōsai baggu——很多日本家庭都备有一个）。

> **[待核实]** 皮肤厚度的数值与开封后的使用期限指引均为一般值。请遵循各产品的标示。

## 误解1｜上面写着「无需冲洗」，所以擦完就能睡

**清洁成分会留在皮肤上，引起干燥与刺激。** 能用温水冲就冲；至少也要用化妆水擦掉，然后保湿。

## 误解2｜湿巾很方便，每天用也没关系

**累积的摩擦可能造成色素沉着与暗沉。** 请把它留给「实在撑不住的夜晚」和旅行。

## 误解3｜用力擦才能擦干净

**摩擦是最大的弱点。** 先贴几秒让彩妆松动，再朝一个方向轻轻滑过。卸不掉就用专用卸妆产品。

## 误解4｜一张湿巾擦完整张脸才划算

**用同一面反复擦，会把卸下来的彩妆抹开，还增加摩擦。** 请换面；眼部单独处理。

## 误解5｜半年前开封的那包还能用

**变干的湿巾成分更浓、刺激更强，还可能带菌。** 请买能在开封后 1～2 个月内用完的包装规格。
