# Q. 卸妝濕巾：每天用也沒關係嗎？｜Japan Questions #529

- Shelf: `beauty` ／ URL: `/zh-tw/beauty/makeup-removal-wipes` ／ Status: **草稿 — 出處未核實**

累到家的時候，一張卸妝濕巾就省下了去洗手間的那一趟。旅行和健身房也很方便，日本的藥妝店（松本清、Welcia 等）還成包地賣大容量裝。你可能也聽說過「它對皮膚不好」。這裡我們看看問題究竟出在哪裡，以及怎樣用才對皮膚負擔最小。

## A. 卸妝濕巾是靠「擦」來卸妝的，它最大的弱點是比沖洗型卸妝產品帶來更多的摩擦。每天使用可能導致色素沉澱（褐色黑眼圈、暗沉）與乾燥，所以請把濕巾留給「實在撐不住的夜晚」和旅行。真的要用時：① 先貼在皮膚上停留幾秒，讓彩妝鬆動；② 不施力，朝一個方向滑動；③ 眼妝另用一張濕巾或棉花棒；④ 之後用溫水沖洗，至少也要用化妝水把殘留擦掉，然後保濕。關鍵是不要讓濕巾裡的清潔成分和酒精留在皮膚上。

## 卸妝濕巾是什麼

| 項目 | 內容 |
|---|---|
| **作用原理** | 不織布浸潤了**清潔成分（界面活性劑）、保濕劑，以及水或酒精**，**用物理方式把彩妝擦掉。** 沖洗型卸妝是「溶解後沖掉」；濕巾是「溶解後擦掉」 |
| **最大的弱點** | **摩擦。** 臉部皮膚，尤其眼周（約 0.5 公釐）很薄，反覆摩擦會造成**色素沉澱、細紋與泛紅** |
| **第二個弱點** | **清潔成分留在皮膚上。** 若不沖洗，界面活性劑、酒精與防腐劑會殘留，引起乾燥與刺激 |
| **適合的場合** | **旅行與出差、健身房、露營、災害時**，以及**累到站不到洗臉台前的夜晚** |
| **不適合每天使用的人** | **敏感肌或乾性肌、痘痘多、眼周有色素沉澱的人** |
| **頻率** | 大致**每週一到兩次為限。** 使用時，**不要用一張濕巾擦遍整張臉**；**T 字部位 → 臉頰 → 眼部，換面使用** |

- **步驟**：① **把濕巾貼在臉上停留幾秒**，讓彩妝鬆動（不要馬上擦）② 輕輕地**由內向外、由下往上，朝一個方向**滑動 ③ **眼妝和唇膏要換面，或另用一張濕巾。** 眼部**先按壓等待 5～10 秒，再輕輕滑過眼皮** ④ **然後用溫水沖洗**（通常不需要再用洗面乳）⑤ **保濕。**
- **酒精（乙醇）**：常被添加以帶來清涼感和快乾，**對敏感肌是刺激。** 請選擇標示**「無酒精」（アルコールフリー）**的濕巾。
- **保存**：**濕巾變乾後，清潔成分會更濃、刺激更強**，清潔力也更差。**開封後請把蓋子蓋緊，並在 1～2 個月內用完。**
- **厚重的妝（防水睫毛膏、唇釉）**用濕巾不容易卸掉，**會導致過度擦拭。** 請同時使用專用卸妝產品。
- **關於「無需沖洗」的標示**：**即使標籤說不必沖洗，多數皮膚科醫師仍認為皮膚上不留殘餘比較好。** 能沖就沖。
- **災害時**：在沒有水的情況下，濕巾是**保持皮膚清潔的有效方法。** 值得放進防災包（「防災バッグ」，bōsai baggu——很多日本家庭都備有一個）。

> **[待核實]** 皮膚厚度的數值與開封後的使用期限指引均為一般值。請遵循各產品的標示。

## 誤解1｜上面寫著「無需沖洗」，所以擦完就能睡

**清潔成分會留在皮膚上，引起乾燥與刺激。** 能用溫水沖就沖；至少也要用化妝水擦掉，然後保濕。

## 誤解2｜濕巾很方便，每天用也沒關係

**累積的摩擦可能造成色素沉澱與暗沉。** 請把它留給「實在撐不住的夜晚」和旅行。

## 誤解3｜用力擦才能擦乾淨

**摩擦是最大的弱點。** 先貼幾秒讓彩妝鬆動，再朝一個方向輕輕滑過。卸不掉就用專用卸妝產品。

## 誤解4｜一張濕巾擦完整張臉才划算

**用同一面反覆擦，會把卸下來的彩妝抹開，還增加摩擦。** 請換面；眼部單獨處理。

## 誤解5｜半年前開封的那包還能用

**變乾的濕巾成分更濃、刺激更強，還可能帶菌。** 請買能在開封後 1～2 個月內用完的包裝規格。
