# Q. 古着を買ったら、着る前に洗うべき？においやダニは大丈夫？｜世界の質問箱 #533

- 棚：`fashion` ／ URL：`/questions/secondhand-clothing-hygiene` ／ ステータス：**ドラフト（法務レビュー前・出典未検証）**

メルカリやリユース店、古着屋で服を買うことが日本でも当たり前になりました。「新品じゃないから不衛生では」と気にする人と、「そのまま着る」人がいます。実際のリスクと、買ったあとの手入れを整理します。

## A. 古着は「着る前に一度洗う」が基本です。心配すべき主なものは、前の持ち主の皮脂・汗、保管中のほこり・カビ臭・防虫剤のにおい、まれにダニやトコジラミ（南京虫）の卵。洗濯できるものは表示に従って洗い（できれば40℃以上、または乾燥機の高温）、洗えないものはスチームか消臭スプレーと陰干し、革製品は拭いて乾かす。トコジラミが心配なら乾燥機の高温（60℃以上）で30分かけるのが有効とされます。保管臭は重曹水につけおき、酸素系漂白剤、風通しで大半が取れます。感染症のリスクは通常の使用では低く、洗うことでさらに下がります。

## 買ったあとの手入れ

| 品目 | 手入れ | 目的 |
|---|---|---|
| **綿・化繊のトップス、ボトム** | **洗濯表示に従い洗濯**。可能なら**40℃以上**か**乾燥機の高温**。においが強ければ**重曹（水1Lに大さじ1）や酸素系漂白剤の40〜50℃液に1時間つけおき**してから洗濯 | 皮脂・ほこり・においの除去、ダニ対策 |
| **ニット・ウール** | **おしゃれ着洗い（30℃以下、中性洗剤）**か**クリーニング**。**虫食いの穴がないか確認** | 虫の卵が付いていれば洗いで落ちる |
| **ジャケット・コート（洗濯不可）** | **クリーニング**、または**スチーム（アイロン・衣類スチーマー）を全体に当ててから陰干し**、**消臭スプレー** | においと表面のほこり |
| **革・スエード** | **乾いた布で拭き、革用クリーナー→保湿クリーム**。**陰干し** | カビ・においの除去 |
| **靴** | **中敷きを外して交換**、**内側をアルコールで拭く**、**除菌スプレー**、天日干し | 足の菌・においの除去 |
| **バッグ** | **内側のごみを取り、拭く**。布バッグは表示に従い洗濯 | — |
| **帽子・マフラー** | 表示に従い洗濯、または**スチーム＋陰干し** | 頭皮の皮脂は特に多い部位 |

- **トコジラミ（南京虫）対策**：近年、日本でも宿泊施設・中古品を介した発生が報告されています。**卵・幼虫・成虫とも60℃以上の熱で死滅**するため、**乾燥機の高温で30分**、または**アイロン・スチームを縫い目に当てる**。**冷凍（−18℃で4日以上）**も有効。買った服を**ビニール袋のまま持ち帰り、家の中に広げる前に処理**すると安心です。
- **ダニ**：布製品にいるのは主にヒョウヒダニで**咬まない**が、フンや死骸がアレルゲン。**洗濯で流れる**、**50℃以上で死滅**。
- **カビ臭・保管臭**（古着屋特有のにおい）：**ナフタリンなど防虫剤の残り香**と**湿気のこもったにおい**。**風通しの良い日陰に2〜3日**、**重曹水のつけおき**、**酸素系漂白剤**、**スチーム**で大半が取れる。取れなければクリーニング店に「におい」と伝える。
- **感染症**：**通常の古着からの感染リスクは低い**とされ、洗うことでさらに下がります。**水虫（白癬菌）は靴・靴下から移ることがある**ため、靴は内側の処理と中敷き交換を。
- **買う時のチェック**：**脇・襟の黄ばみ**（落ちにくい）、**虫食いの小さな穴**（ニット）、**カビの点**、**強い防虫剤臭**（ウール・カシミヤは長期保管品が多い）、**縫い目のほつれ**、**革のべたつき（合皮の加水分解＝寿命）**。
- **販売時の手入れ**（自分が売る側）：**洗って乾かしてから出す**のが日本のフリマ文化の基本。**「洗濯済み」と書く**と評価が上がります。

> **【要検証】** トコジラミの死滅温度・冷凍条件、ダニの死滅温度は害虫防除の一般的な資料に基づきます。自治体・厚生労働省の資料で確認してください。

## 誤解1｜クリーニング済み表示があれば洗わなくていい

**店頭に並んでから試着・保管を経ており、においや表面のほこりは付きます。** 家で一度洗うか、スチームと陰干しを。

## 誤解2｜古着は不衛生で危険

**通常の使用での感染リスクは低く、洗えばさらに下がります。** 気にすべきは皮脂・におい・虫の卵で、いずれも家庭の処理で対処できます。

## 誤解3｜においは日に当てれば取れる

**日光は退色の原因になり、防虫剤臭・カビ臭は風通しと洗いで取れます。** 陰干し＋つけおき。

## 誤解4｜トコジラミは海外の話

**近年、日本国内でも報告が増えています。** 乾燥機の高温30分か冷凍で確実に処理できます。

## 誤解5｜合皮のバッグや靴は磨けば復活する

**合皮（ポリウレタン）は製造から数年で加水分解が始まり、べたつき・剥がれは戻りません。** 買う時にべたつきがあれば避ける。
