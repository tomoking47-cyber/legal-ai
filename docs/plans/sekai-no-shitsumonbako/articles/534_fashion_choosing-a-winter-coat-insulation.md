# Q. ダウンと化繊の中綿、どちらが暖かい？コートの選び方｜世界の質問箱 #534

- 棚：`fashion` ／ URL：`/questions/choosing-a-winter-coat-insulation` ／ ステータス：**ドラフト（法務レビュー前・出典未検証）**

冬のアウターの表示を見ると「ダウン90% フェザー10%」「中わた：ポリエステル」「フィルパワー700」など、比べにくい数字が並びます。日本の冬は地域差が大きく、東京の通勤と北海道の屋外では正解が違います。数字の意味と、用途別の選び方を整理します。

## A. 同じ重さなら、ダウンは化繊わたより暖かく軽く、圧縮して小さくなります。ただし濡れると保温力が大きく落ち、洗濯や手入れに手間がかかる。化繊わた（ポリエステル）は濡れても保温力が落ちにくく、家で洗いやすく、価格も安い一方、同じ暖かさなら重くかさばります。首都圏の通勤や街歩き（0〜10℃）なら化繊わたやダウン量150g程度で十分、北国や屋外で長時間なら高フィルパワーのダウン、雨や湿雪の多い地域では化繊か撥水ダウン。「フィルパワー」は羽毛の膨らみ（質）、「ダウン量」は入っている量で、暖かさは両方で決まります。

## ダウンと化繊わたの比較

| 項目 | ダウン（羽毛） | 化繊わた（ポリエステル） |
|---|---|---|
| **暖かさ／重さ** | **同じ重さなら最も暖かい**。軽い | ダウンの**6〜8割程度**。同じ暖かさなら重い |
| **濡れたとき** | **保温力が大きく落ちる**（羽毛がつぶれる）。乾きにくい | **濡れても保温力が落ちにくい**。乾きやすい |
| **収納** | **小さく圧縮できる** | かさばる |
| **洗濯** | **手洗い・専用洗剤・乾燥機で羽をほぐす**手間（別記事参照）。クリーニング代 ¥2,000〜4,000 | **洗濯機で洗えるものが多い** |
| **耐久** | 手入れすれば**10年以上**。羽毛の偏り、羽抜け | **5〜10年**でへたる（圧縮回復力の低下） |
| **価格** | 高い（**¥20,000〜**が目安、ブランドで大差） | 安い（**¥5,000〜**） |
| **動物福祉・表示** | RDS（責任あるダウン基準）など認証あり | 動物由来ではない |
| **向く場面** | **寒冷地、乾いた寒さ、屋外で長時間、旅行（軽量）** | **雨・湿雪、通勤（電車内が暑い）、洗濯頻度が高い、子ども** |

## 表示の読み方

| 表示 | 意味 | 目安 |
|---|---|---|
| **ダウン90% フェザー10%** | 羽毛のうち**ダウン（綿毛）の割合**。ダウンが多いほど軽くて暖かい | **80/20以上**が一般的な品質。50/50はフェザー主体で重い |
| **フィルパワー（FP）** | **羽毛1オンス（約28g）が膨らむ体積**（立方インチ）。**質**の指標 | **600以上で良質、700〜800で高品質、900は最高級**。日本の表示義務はなくブランド任意 |
| **ダウン量（充填量）** | **入っている羽毛の重さ**（g） | **街用 100〜150g、寒冷地 200〜300g**。**FPが高くても量が少ないと暖かくない** |
| **表地の耐水・撥水** | 「撥水加工」「耐水圧〇mm」 | 雨対策には**耐水圧5,000mm以上**か、化繊を選ぶ |
| **家庭用品品質表示** | 詰め物の**種類と混率**（羽毛は「ダウン〇%・フェザー〇%」）、**表地・裏地の素材**、**洗濯表示** | 日本で販売される衣類には表示義務 |

- **東京の冬（最低0〜5℃、屋外は短時間、電車・店内は暖房）**：**ダウン量100〜150g**か**化繊わたの中厚**で十分。**脱ぎやすさ・軽さ・電車内の暑さ**の方が問題で、**厚すぎるダウンは持ち歩きが負担**。
- **北海道・東北・日本海側（−5℃以下、風・雪）**：**FP700以上・ダウン量200g以上**か、**化繊の厚手＋防風表地**。**フード**と**首元の密閉**が体感を大きく変える。
- **雨・湿雪の多い地域**：ダウンは濡れると弱いため、**化繊わた**か**撥水加工ダウン（羽毛自体に撥水処理）**。
- **子ども**：洗濯回数が多く、汚す、すぐサイズが変わる→**化繊わた**が現実的。
- **手入れ**：**ダウンはシーズン中に1〜2回、風通しの良い日陰で干す**（湿気で羽毛がつぶれる）。**シーズン終わりに洗ってから、圧縮せずにゆったり保管**（別記事「圧縮袋」参照）。
- **重ね着**：**アウターの暖かさより、中の空気の層（インナー＋薄手のフリースやセーター）**が体感を決めます。厚いコート1枚より、**薄手アウター＋中間着**の方が調節しやすい。

> **【要検証】** 化繊わたの保温力の比率、フィルパワーの区分、価格帯は業界の一般的な説明です。家庭用品品質表示法の羽毛表示ルールは消費者庁の資料で確認してください。

## 誤解1｜ダウンなら何でも暖かい

**暖かさは「フィルパワー（質）×ダウン量（量）」で決まります。** FPが高くても100gしか入っていなければ街用の薄手です。

## 誤解2｜化繊わたは安物で寒い

**濡れる環境・洗濯頻度・電車通勤では化繊わたの方が合理的**なことが多いです。同じ暖かさでの重さと収納性がダウンに劣るだけ。

## 誤解3｜厚いコート1枚あれば冬は乗り切れる

**日本の冬は屋外と室内の温度差が20℃以上**あり、厚い1枚は室内で持ち歩くのが負担です。薄手アウター＋中間着で調節する方が快適。

## 誤解4｜ダウンは洗えないからクリーニングに毎年出すしかない

**表示に手洗いマークがあれば家で洗えます**（手順は別記事）。洗わずに保管する方が、汗と皮脂で羽毛が傷みます。

## 誤解5｜ダウン90%と書いてあれば高品質

**ダウン比率は羽毛の「構成」で、フィルパワーと充填量が示されていなければ暖かさはわかりません。** 3つそろって初めて比較できます。
