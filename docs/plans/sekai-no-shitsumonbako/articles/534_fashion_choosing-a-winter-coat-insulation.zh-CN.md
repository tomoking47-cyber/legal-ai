# Q. 羽绒和化纤填充哪个更暖？在日本该怎么挑冬季外套｜Japan Questions #534

- Shelf: `fashion` ／ URL: `/zh-cn/fashion/choosing-a-winter-coat-insulation` ／ Status: **草稿 — 出处未核实**

日本冬季外套的标签上写着一堆很难比较的数字：「ダウン90%／フェザー10%」（羽绒 90%／羽毛 10%）、「填充物：聚酯纤维」、「蓬松度 700」。日本各地的冬天差异也极大，适合在东京通勤的外套，未必适合在北海道户外活动。下面说明这些数字的含义，以及按用途该怎么选。

## A. 同等重量下，羽绒比化纤填充更暖、更轻，压缩后体积也更小。但它被打湿后会损失大部分保暖性，清洗和保养也更费事。化纤填充（聚酯纤维）湿了仍能保住大部分保暖性，在家就能轻松清洗，价格也更低，但要达到同样的保暖度，它更重也更蓬。在东京一带通勤或逛街（0–10°C／32–50°F），化纤填充或约 150 克羽绒就够了。去雪国，或长时间待在户外，就选高蓬松度的羽绒；在多雨、多湿雪的地方，选化纤或经过拒水处理的羽绒。「蓬松度（Fill power）」是羽绒能膨起多少（品质）；「充绒量」是外套里装了多少（数量）。保暖性取决于两者。

## 羽绒 vs 化纤填充

| 项目 | 羽绒（羽毛） | 化纤填充（聚酯纤维） |
|---|---|---|
| **同等重量的保暖性** | **同等重量下最暖。** 轻 | **约为羽绒的 60–80%。** 同样保暖度下更重 |
| **打湿时** | **损失大部分保暖性**（绒朵塌陷）。干得慢 | **湿了仍保住大部分保暖性。** 干得快 |
| **收纳** | **可压缩得很小** | 体积大 |
| **清洗** | 手洗、专用洗涤剂，并且**要用烘干机把结团打散**（另见专文）。干洗 ¥2,000–4,000 | **很多可以直接机洗** |
| **寿命** | 保养得当可用 **10 年以上**。羽绒会跑位、钻绒 | **5–10 年**后变塌（压缩后回弹变差） |
| **价格** | 高（参考价 **¥20,000 起**；品牌之间差异极大） | 低（**¥5,000 起**） |
| **动物福利／认证** | 有 RDS（Responsible Down Standard）等认证 | 非动物来源 |
| **适合** | **寒冷地区、干冷、长时间户外、旅行（轻）** | **雨与湿雪、通勤（车厢很热）、经常清洗、儿童** |

## 看懂标签

| 标签 | 含义 | 参考 |
|---|---|---|
| **ダウン90%／フェザー10%（羽绒 90%／羽毛 10%）** | 填充物中**羽绒（蓬松的绒朵）所占的比例**。羽绒比例越高，越轻越暖 | **80/20 以上**属于正常品质。50/50 大部分是羽毛，且重 |
| **蓬松度（Fill power, FP）** | **一盎司（约 28 克）羽绒能膨起的体积**，单位为立方英寸。衡量的是**品质** | **600 以上算好，700–800 为高品质，900 是顶级。** 在日本不是强制标示，由品牌自愿公布 |
| **充绒量（fill weight）** | 外套中**羽绒的重量**（克） | **城市 100–150 克，寒冷地区 200–300 克。** **蓬松度高但绒量少，并不暖** |
| **面料防水性** | 「拒水加工」、「耐水压 X mm」 | 对付雨，选 **5,000 mm 以上**，或选化纤 |
| **家庭用品品质标示** | **填充物的种类与混合比**（羽绒标示为「ダウン X%／フェザー X%」）、**面料与里料**、**洗涤标识** | 在日本销售的服装为强制标示 |

- **东京的冬天（最低气温 0–5°C／32–41°F，在户外的时间短，电车和店内有暖气）**：**100–150 克羽绒**或**中等厚度的化纤**就够了。真正的问题是**好不好脱、重量，以及在电车上过热**；**厚重的羽绒服会变成拿在手上的负担**。
- **北海道、东北和日本海一侧（−5°C／23°F 以下，有风有雪）**：**FP 700 以上、充绒量 200 克以上**，或**厚化纤配防风面料**。**兜帽**和**能收紧的领口**对体感温度的影响，比你想象的大得多。
- **多雨、多湿雪的地区**：羽绒怕湿，所以选**化纤填充**或**拒水羽绒（对羽绒本身做拒水处理）**。
- **儿童**：要经常清洗、容易弄脏、长得又快，**化纤填充**是务实的选择。
- **保养**：**一季当中在通风的阴凉处晾一到两次**（潮气会让羽绒塌陷）。**季末清洗，然后宽松存放，切勿压缩**（参见本站关于真空压缩袋的文章）。
- **叠穿**：**决定体感温度的，是内部锁住的空气——打底层加一件薄抓绒或毛衣——比外套本身影响更大。** **薄外套加一件中间层**，比一件厚外套更好调节。

> **[待核实]** 化纤填充的保暖比例、蓬松度分级和价格区间，都是行业的一般数值。羽毛标示在《家庭用品品质表示法》下的规定，请向消费者厅确认。

## 误解1｜只要是羽绒就暖

**保暖性＝蓬松度（品质）× 充绒量（数量）。** 蓬松度再高，里面只有 100 克，那也只是一件轻便的城市夹克。

## 误解2｜化纤填充便宜又不暖

**在潮湿环境、需要经常清洗，或是电车通勤的场合，化纤往往是更合理的选择。** 它输给羽绒的，只有同等保暖度下的重量和收纳体积。

## 误解3｜一件厚外套就能过冬

**在日本，室外与室内的温差常常有 20°C（36°F）以上**，而厚外套在室内会变成负担。薄外套加中间层更舒服。

## 误解4｜羽绒不能洗，所以每年都得送干洗

**如果标识上有手洗符号，就可以在家洗**（方法另见专文）。不洗就收起来危害更大：汗和皮脂会让羽绒劣化。

## 误解5｜「羽绒 90%」就代表品质高

**羽绒比例说的是填充物的构成；没有蓬松度和充绒量，就无法判断它有多暖。** 三项齐全，才能拿来比较。
