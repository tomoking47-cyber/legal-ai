# Q. 羽絨和化纖填充哪個比較暖？在日本該怎麼挑冬季外套｜Japan Questions #534

- Shelf: `fashion` ／ URL: `/zh-tw/fashion/choosing-a-winter-coat-insulation` ／ Status: **草稿 — 出處未核實**

日本冬季外套的標籤上寫著一堆很難比較的數字：「ダウン90%／フェザー10%」（羽絨 90%／羽毛 10%）、「填充物：聚酯纖維」、「蓬鬆度 700」。日本各地的冬天差異也極大，適合在東京通勤的外套，未必適合在北海道戶外活動。以下說明這些數字的意思，以及依用途該怎麼挑。

## A. 同等重量下，羽絨比化纖填充更暖、更輕，壓縮後體積也更小。但它被打濕後會失去大部分保暖性，清洗和保養也更費事。化纖填充（聚酯纖維）濕了仍能保住大部分保暖性，在家就能輕鬆清洗，價格也較低，但要達到同樣的保暖度，它更重也更蓬。在東京一帶通勤或逛街（0–10°C／32–50°F），化纖填充或約 150 公克羽絨就夠了。要去雪國，或長時間待在戶外，就選高蓬鬆度的羽絨；在多雨、多濕雪的地方，選化纖或經過撥水處理的羽絨。「蓬鬆度（Fill power）」是羽絨能膨起多少（品質）；「充絨量」是外套裡裝了多少（數量）。保暖性取決於兩者。

## 羽絨 vs 化纖填充

| 項目 | 羽絨（羽毛） | 化纖填充（聚酯纖維） |
|---|---|---|
| **同等重量的保暖性** | **同等重量下最暖。** 輕 | **約為羽絨的 60–80%。** 同樣保暖度下更重 |
| **打濕時** | **失去大部分保暖性**（絨朵塌陷）。乾得慢 | **濕了仍保住大部分保暖性。** 乾得快 |
| **收納** | **可壓縮得很小** | 體積大 |
| **清洗** | 手洗、專用洗劑，而且**要用烘乾機把結塊打散**（另見專文）。乾洗 ¥2,000–4,000 | **很多可以直接機洗** |
| **壽命** | 保養得當可用 **10 年以上**。羽絨會位移、鑽絨 | **5–10 年**後變塌（壓縮後回彈變差） |
| **價格** | 高（參考價 **¥20,000 起**；品牌之間差異極大） | 低（**¥5,000 起**） |
| **動物福利／認證** | 有 RDS（Responsible Down Standard）等認證 | 非動物來源 |
| **適合** | **寒冷地區、乾冷、長時間戶外、旅行（輕）** | **雨與濕雪、通勤（車廂很熱）、經常清洗、兒童** |

## 看懂標籤

| 標籤 | 意思 | 參考 |
|---|---|---|
| **ダウン90%／フェザー10%（羽絨 90%／羽毛 10%）** | 填充物中**羽絨（蓬鬆的絨朵）所佔的比例**。羽絨比例越高，越輕越暖 | **80/20 以上**屬於正常品質。50/50 大部分是羽毛，而且重 |
| **蓬鬆度（Fill power, FP）** | **一盎司（約 28 公克）羽絨能膨起的體積**，單位為立方英吋。衡量的是**品質** | **600 以上算好，700–800 為高品質，900 是頂級。** 在日本不是強制標示，由品牌自願公布 |
| **充絨量（fill weight）** | 外套中**羽絨的重量**（公克） | **城市 100–150 公克，寒冷地區 200–300 公克。** **蓬鬆度高但絨量少，並不暖** |
| **表布防水性** | 「撥水加工」、「耐水壓 X mm」 | 要應付雨，選 **5,000 mm 以上**，或選化纖 |
| **家庭用品品質標示** | **填充物的種類與混合比**（羽絨標示為「ダウン X%／フェザー X%」）、**表布與裡布**、**洗滌標示** | 在日本販售的服飾為強制標示 |

- **東京的冬天（最低氣溫 0–5°C／32–41°F，在戶外的時間短，電車和店內有暖氣）**：**100–150 公克羽絨**或**中等厚度的化纖**就夠了。真正的問題是**好不好脫、重量，以及在電車上過熱**；**厚重的羽絨外套會變成拿在手上的負擔**。
- **北海道、東北和日本海側（−5°C／23°F 以下，有風有雪）**：**FP 700 以上、充絨量 200 公克以上**，或**厚化纖搭配防風表布**。**連帽**和**能收緊的領口**對體感溫度的影響，比你想像的大得多。
- **多雨、多濕雪的地區**：羽絨怕濕，所以選**化纖填充**或**撥水羽絨（對羽絨本身做撥水處理）**。
- **兒童**：要經常清洗、容易弄髒、長得又快，**化纖填充**是務實的選擇。
- **保養**：**一季當中在通風的陰涼處晾一到兩次**（濕氣會讓羽絨塌陷）。**季末清洗，然後寬鬆存放，切勿壓縮**（參見本站關於真空壓縮袋的文章）。
- **洋蔥式穿法**：**決定體感溫度的，是內部鎖住的空氣——內搭層加一件薄刷毛或毛衣——比外套本身影響更大。** **薄外套加一件中層**，比一件厚外套更好調節。

> **[待核實]** 化纖填充的保暖比例、蓬鬆度分級和價格區間，都是業界的一般數值。羽毛標示在《家庭用品品質表示法》下的規定，請向消費者廳確認。

## 誤解1｜只要是羽絨就暖

**保暖性＝蓬鬆度（品質）× 充絨量（數量）。** 蓬鬆度再高，裡面只有 100 公克，那也只是一件輕便的城市外套。

## 誤解2｜化纖填充便宜又不暖

**在潮濕環境、需要經常清洗，或是電車通勤的場合，化纖往往是更合理的選擇。** 它輸給羽絨的，只有同等保暖度下的重量和收納體積。

## 誤解3｜一件厚外套就能過冬

**在日本，室外與室內的溫差常常有 20°C（36°F）以上**，而厚外套在室內會變成負擔。薄外套加中層比較舒服。

## 誤解4｜羽絨不能洗，所以每年都得送乾洗

**如果標示上有手洗符號，就可以在家洗**（方法另見專文）。不洗就收起來危害更大：汗和皮脂會讓羽絨劣化。

## 誤解5｜「羽絨 90%」就代表品質高

**羽絨比例說的是填充物的組成；沒有蓬鬆度和充絨量，就無法判斷它有多暖。** 三項齊全，才能拿來比較。
