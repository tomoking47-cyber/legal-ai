# Q. ヒートテックなどの発熱インナー、本当に暖かい？肌が乾燥する人は｜世界の質問箱 #535

- 棚：`fashion` ／ URL：`/questions/functional-thermal-underwear` ／ ステータス：**ドラフト（法務レビュー前・出典未検証）**

冬になると日本の量販店の棚を埋める「発熱インナー」「吸湿発熱」の肌着。薄くて暖かいと感じる人が多い一方、「かゆくなる」「乾燥する」「汗をかくと逆に冷える」という声も定着しています。仕組みを知ると、向く人・向かない場面がはっきりします。

## A. 吸湿発熱インナーは、体から出る水蒸気（汗）を繊維（主にレーヨンやアクリル）が吸着する際に出る熱を利用する仕組みで、発熱量は小さいものの、薄い生地で空気の層を保ち、汗を吸うことで体感を上げています。効果が出るのは「じっとしている・軽い動きの寒い環境」で、大量に汗をかく運動や登山では汗を溜めて冷える方向に働くため不向き。乾燥肌・敏感肌の人は、レーヨンとアクリルが肌の水分も吸うことでかゆみ・乾燥を感じる場合があり、綿混タイプや「肌側が綿」の製品、ウール（メリノ）インナーが代わりになります。

## 吸湿発熱インナーの仕組みと限界

| 項目 | 内容 |
|---|---|
| **発熱の仕組み** | 繊維が**水蒸気を吸着する時に出る熱（吸着熱）**。**レーヨン・アクリル・ポリエステル**などの組み合わせ。**発熱量は小さく、体感で1〜2℃程度**とされる。**電気やカイロのように自ら発熱するわけではない** |
| **実際に暖かい理由** | ①**薄くて密な生地が肌に密着し、空気の層を保つ** ②**汗（水蒸気）を吸って肌をドライに保つ** ③**ストレッチで隙間ができない**。この3つの効果の方が「発熱」より大きい |
| **向く場面** | **通勤・通学・オフィス・街歩き・軽い家事**——**汗をかかない程度の活動** |
| **向かない場面** | **登山・ランニング・雪かき・スキー**など**大量に汗をかく運動**：吸った汗が乾かず**汗冷え**を起こす。スポーツ用は**速乾・撥水のポリエステル**、登山は**メリノウール**が定番 |
| **乾燥・かゆみ** | **レーヨン・アクリルは肌の水分も吸う**ため、**乾燥肌・敏感肌・高齢者・アトピーの人はかゆみや乾燥**を感じることがある。**化繊と皮膚の摩擦・静電気**も要因 |
| **対策** | **肌側が綿の製品**、**綿混タイプ**、**シルク・メリノウールのインナー**、**保湿してから着る**、**汗をかいたら着替える** |
| **表示** | 「吸湿発熱」は**JIS L1927（吸湿発熱性試験方法、2020年制定）**で測定方法が規格化され、**表示には根拠が必要**。**「〇℃上昇」の数値は試験条件下の値** |

- **選び方**：**綿主体**（肌に優しい・厚め）、**レーヨン・アクリル主体**（薄い・発熱表示・乾燥しやすい）、**ウール混**（温度調節に優れ、におわないが高い）、**シルク**（肌に優しい・吸湿性が高い・洗濯に注意）。**首・手首・足首**の「3首」を覆う設計（ハイネック、長袖、レギンス）で体感が大きく変わる。
- **重ね着の順番**：**インナー（吸湿）→中間着（保温：フリース・ニット）→アウター（防風）**。インナーを2枚重ねるより中間着を足す方が暖かい。
- **洗濯と寿命**：**洗濯で繊維が伸び、密着が落ちると効果も落ちる**。目安は**1〜2シーズン**。**柔軟剤は吸湿性を下げる**ため使用を控えるメーカー案内が多い。**乾燥機は縮み・劣化**。
- **汗をかいたら**：**吸湿発熱インナーは乾きが遅い**。汗をかく予定の日は**着替えを持つ**か、速乾素材を。
- **子ども**：体温が高く汗をかきやすいため、**薄手で汗を逃がす素材**が向く。厚着させ過ぎに注意。
- **高齢者**：乾燥肌が多く、**かゆみ→掻く→湿疹**の悪循環が起きやすい。**綿・シルク主体**か、**保湿を習慣に**。

> **【要検証】** JIS L1927の制定年と内容、吸湿発熱の体感温度の目安はメーカー・繊維業界の説明に基づきます。消費者庁・JISの資料で確認してください。

## 誤解1｜発熱インナーは電気毛布のように自分で熱を出す

**水蒸気を吸う時のわずかな熱を使うだけで、暖かさの主因は薄い生地の密着と空気の層です。** 発熱表示の数値は試験条件下のものです。

## 誤解2｜運動や登山でも暖かいから最適

**大量の汗を吸って乾かず、汗冷えの原因**になります。運動には速乾素材、登山にはメリノウールが向いています。

## 誤解3｜かゆいのは肌が弱いせいだから我慢する

**レーヨン・アクリルは肌の水分も吸うため、乾燥肌の人にかゆみが出やすい**素材です。肌側が綿の製品やシルク・ウールに替えれば解決することが多い。

## 誤解4｜2枚重ねればもっと暖かい

**インナーの重ね着より、中間着（フリース・ニット）を1枚足す方が空気の層が増えて暖かい**です。

## 誤解5｜何年でも同じ効果が続く

**洗濯で生地が伸び、密着が落ちると効果も落ちます。** 1〜2シーズンで買い替えが目安、柔軟剤は控える。
