# Q. Heattech 這類「發熱」保暖內衣真的暖嗎？會不會讓皮膚變乾？｜Japan Questions #535

- Shelf: `fashion` ／ URL: `/zh-tw/fashion/functional-thermal-underwear` ／ Status: **草稿 — 出處未核實**

每到冬天，日本大型服飾連鎖的貨架上就擺滿了「発熱」（hatsunetsu，發熱）與「吸湿発熱」（kyūshitsu hatsunetsu，吸濕發熱）的保暖內衣，其中最有名的是 UNIQLO 的 Heattech。多數人覺得它又薄又暖，但每年也照例會出現一批抱怨：發癢、皮膚乾燥、「流了汗反而更冷」。了解它的原理之後，就能看清它適合誰、在哪裡會失靈。

## A. 吸濕發熱型保暖內衣，利用的是纖維（主要是嫘縈和壓克力纖維）吸收身體散發的水蒸氣時釋放出的少量熱。這份熱很微弱；真正起作用的，是薄而貼身、能鎖住一層空氣並吸收汗液的布料。它最適合在寒冷中靜止或輕度活動時穿。跑步、登山這類大量流汗的活動中，它會把汗留住並讓你變冷，所以是錯誤的選擇。皮膚乾燥或敏感的人可能會發癢，因為嫘縈和壓克力纖維也會從皮膚吸走水分。替代選擇是含棉混紡款、內側為棉的產品，或美麗諾羊毛內衣。

## 吸濕發熱內衣的原理與極限

| 項目 | 內容 |
|---|---|
| **熱是怎麼產生的** | **纖維吸收水蒸氣時釋放的熱（吸附熱）。** 由**嫘縈、壓克力纖維、聚酯纖維**等混紡而成。**效果不大——一般說法是體感約 1–2°C（2–4°F）。** **它不像暖氣或暖暖包那樣自己產熱** |
| **為什麼真的會覺得暖** | ① **薄而緻密的布料貼合皮膚，鎖住一層空氣**；② **吸收汗（水蒸氣），讓皮膚保持乾爽**；③ **有彈性、不留縫隙**。這三點比「發熱」更重要 |
| **適合** | **通勤、上學、辦公室、逛街、輕家事——不會流汗的活動** |
| **不適合** | **登山、跑步、鏟雪、滑雪——任何會大量流汗的活動。** 吸進去的汗不乾，會造成**「汗冷え」**（ase-bie，流汗後發冷）。運動請用**快乾、撥水的聚酯纖維**；登山則以**美麗諾羊毛**為標準 |
| **乾燥與發癢** | **嫘縈和壓克力纖維也會從皮膚吸走水分**，所以**皮膚乾燥或敏感的人、年長者以及有異位性皮膚炎的人，可能會覺得發癢或乾燥**。**化纖與皮膚之間的摩擦和靜電**也有影響 |
| **有幫助的做法** | **內側為棉的產品**、**棉混紡**、**真絲或美麗諾羊毛內衣**、**穿之前先做保濕**、**流汗後及時更換** |
| **標示** | 「吸濕發熱」的測試方法已在 **JIS L1927（2020 年制定）**中標準化，**宣稱必須有依據**。**「+X°C」這類數值是測試條件下的值** |

- **怎麼挑**：**以棉為主**（對皮膚溫和，較厚）；**以嫘縈／壓克力纖維為主**（薄、有「發熱」宣稱、對皮膚偏乾）；**羊毛混紡**（調溫性極佳、不易有味、價格高）；**真絲**（溫和、吸濕性很好，清洗需留意）。把**「三個頸」——脖頸、手腕、腳踝**——蓋住（高領、長袖、內搭褲），對體感溫度的影響遠大於布料本身。
- **洋蔥式順序**：**內衣層（吸濕）→ 中層（保溫：刷毛、針織）→ 外層（擋風）**。加一件中層，比穿兩件內衣更暖。
- **清洗與壽命**：**清洗會讓纖維鬆弛，一旦貼身感消失，效果也就沒了。** 大致可用 **1–2 個冬季**。**柔軟精會降低吸濕性**，所以許多廠商不建議使用。**烘乾機會讓它縮水、劣化**。
- **流汗時**：**這類內衣乾得慢。** 預計會流汗的日子，請**帶一件替換的**，或穿快乾布料。
- **兒童**：他們體溫高、容易流汗，適合**讓汗透出去的薄布料**。不要給他們穿太多。
- **年長者**：皮膚乾燥常見，**發癢 → 抓 → 濕疹**的循環很容易開始。請選**以棉或真絲為主**的，並**養成保濕的習慣**。

> **[待核實]** JIS L1927 的年份與內容，以及體感溫度的參考數值，依據廠商與紡織業界的說明。請對照消費者廳與 JIS 的資料確認。

## 誤解1｜發熱內衣像電熱毯一樣自己產熱

**它只利用吸收水蒸氣時釋放的微弱熱量；暖意主要來自貼身的薄布料和它鎖住的空氣。** 任何「+X°C」都是測試條件下的數值。

## 誤解2｜既然暖，那運動和登山穿它最合適

**它會吸飽大量的汗，又乾不掉，造成汗冷。** 運動用快乾布料，登山用美麗諾羊毛。

## 誤解3｜會發癢代表我皮膚弱，忍一忍就好

**嫘縈和壓克力纖維會從皮膚吸走水分，所以皮膚乾燥的人穿它容易發癢。** 換成內側為棉的、真絲或羊毛的，通常就能改善。

## 誤解4｜穿兩件就暖一倍

**多加一件中層（刷毛或針織）比多穿一件內衣鎖住更多空氣，也更暖。**

## 誤解5｜它的效果能維持很多年

**清洗會讓布料鬆弛，一旦貼合度變差，效果就下降。** 1–2 個冬季後更換，並少用柔軟精。
