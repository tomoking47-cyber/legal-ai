# Q. 結婚式・お葬式の服装、日本ではどこまで守るべき？｜世界の質問箱 #536

- 棚：`fashion` ／ URL：`/questions/dress-codes-for-weddings-and-funerals` ／ ステータス：**ドラフト（法務レビュー前・出典未検証）**

日本の冠婚葬祭の服装には、明文化されていないのに全員が守っている決まりが多くあります。「黒なら何でもいい」「平服でと言われたから普段着」といった判断が、当日に気まずさを生みがちです。よく迷う点を、式の種類別に整理します。

## A. 結婚式（ゲスト）は、女性は膝が隠れる丈のワンピースかセットアップで白・オフホワイト以外、肩を出すなら羽織り、バッグは小さめ、靴はつま先の出ないパンプス。男性はダークスーツに白シャツ、ネクタイは白・シルバー・淡色で黒は避ける。お葬式・告別式は「喪服（ブラックフォーマル）」で、光沢のない黒のスーツかワンピース、黒ストッキング、黒の布か革の靴、アクセサリーは真珠一連まで、男性は黒無地ネクタイ・黒靴・黒靴下。お通夜は「急いで駆けつけた」意味で地味な平服でも許容されてきましたが、現在は喪服が多数派。「平服で」は「普段着」ではなく「略礼装（ダークスーツ・きれいめワンピース）」の意味です。

## 結婚式（ゲスト）

| 項目 | 女性 | 男性 |
|---|---|---|
| **基本** | **膝が隠れる丈**のワンピース・セットアップ・パンツドレス | **ダークスーツ（黒・濃紺・チャコール）**＋**白シャツ**。黒スーツなら小物で華やかに |
| **避ける色** | **白・オフホワイト・淡いベージュ**（花嫁の色）。**全身黒**は喪を連想させるので小物で色を足す | **黒ネクタイ**（弔事）。**白ネクタイ**は定番だが、近年は**シルバー・淡色・小紋**が主流 |
| **避ける素材・柄** | **殺生を連想するアニマル柄・ファー・革**（バッグ・靴のファーは避ける）。**肩・胸・背中の露出**は羽織りで調整 | 派手な柄シャツ、カジュアルなボタンダウン |
| **靴・バッグ** | **つま先の出ないパンプス（3〜7cm）**。**小さめのパーティバッグ**、大荷物はクロークへ | **黒の革靴（内羽根ストレートチップが最も正式）**、黒靴下 |
| **アクセサリー** | **真珠が定番**。**揺れるピアス・時計**は控えめに | ポケットチーフ（白かネクタイと同系色） |
| **和装** | 未婚は振袖、既婚は訪問着・色留袖。**黒留袖は親族のみ** | 親族以外の和装は少数 |
| **ご祝儀袋** | **袱紗（ふくさ）**に包んで持参 | 同 |

## 葬儀・告別式（一般参列）

| 項目 | 女性 | 男性 |
|---|---|---|
| **服** | **ブラックフォーマル**（光沢のない黒のワンピース・アンサンブル・スーツ）。**肌の露出を避け**、**丈は膝下** | **ブラックスーツ**（**礼服**。ビジネスの黒スーツより深い黒）＋**白無地シャツ**＋**黒無地ネクタイ**（**ディンプルは作らない**） |
| **足元** | **黒ストッキング（30デニール以下、肌が透ける程度）**、**黒のパンプス（飾りなし、光沢なし、ヒール3〜5cm）** | **黒の革靴（内羽根ストレートチップ・プレーントゥ）**、**黒靴下** |
| **アクセサリー** | **結婚指輪と真珠一連のネックレス・一粒ピアスまで**。**二連は「不幸が重なる」で避ける** | **時計は外すか地味に**。タイピンは着けない |
| **バッグ** | **黒の布製、小さめ、金具が目立たないもの**。革は殺生の意味で避ける考えもあるが、現在は許容 | — |
| **メイク・髪** | **控えめ（片化粧）**、**ラメ・赤い口紅は避ける**、髪は**低い位置でまとめる**。**ネイルは落とすか黒手袋** | 髭を整える |
| **子ども** | **制服が正装**。なければ黒・紺・グレーの地味な服 | 同 |
| **持ち物** | **数珠（宗派を問わない略式）**、**袱紗に包んだ香典**、**白か黒の無地のハンカチ** | 同 |

- **お通夜**：かつては「地味な平服（ダークスーツ・地味なワンピース）」で「訃報を聞いて急いで来た」を表すのが礼儀とされました。**現在は通夜のみ参列する人が増え、喪服が多数派**。地味な平服でも間違いではありません。
- **「平服でお越しください」**（法事・お別れの会・結婚式二次会など）：**「普段着」ではなく「略礼装」**。**ダークスーツ・地味な色のワンピース**。Tシャツ・ジーンズ・スニーカーは避ける。
- **法事（一周忌・三回忌）**：一周忌までは喪服、以降は施主の案内に従い**地味な平服**へ。
- **冬のコート**：**黒・紺・グレーで、毛皮・革・ファーは避ける**。**会場に入る前に脱ぐ**。**告別式では受付前に脱ぐ**のが礼儀。
- **雨の日**：**黒か地味な色の傘**。ビニール傘も許容されることが多い。
- **急な訃報で喪服がない**：**貸衣装（¥5,000〜10,000）**、**駅前の量販店で黒スーツ**、**通夜は地味な平服で参列し、告別式に喪服**。**喪服を1着持っておく**のが日本では大人の常識とされ、**20代で購入**する人が多い。

> **【要検証】** 服装の慣習は地域・宗派・世代で異なります。冠婚葬祭業界団体・葬祭ディレクター技能審査協会の資料で最新の一般的慣習を確認してください。

## 誤解1｜黒い服なら結婚式でも葬式でも兼用できる

**結婚式の全身黒は喪を連想させ、葬式にビジネスの黒スーツは「礼服の黒」より浅く目立ちます。** 用途で分けるのが日本の慣習です。

## 誤解2｜「平服で」と言われたら普段着でいい

**平服＝略礼装（ダークスーツ・きれいめワンピース）**です。普段着で行くと一人だけ浮きます。

## 誤解3｜お通夜は喪服で行くと「準備していた」ようで失礼

**かつての考え方で、現在は通夜のみの参列が多く喪服が多数派**です。どちらでも間違いではありません。

## 誤解4｜結婚式に白っぽい服でも、ベージュならセーフ

**淡いベージュ・オフホワイトは写真で白く見え、避けるのが無難**です。羽織りやバッグで色を足す。

## 誤解5｜葬式のストッキングは黒なら厚手でもよい

**30デニール以下の薄手が正式**とされ、厚手のタイツはカジュアルに見えます。真冬は厚手でも許容されつつありますが、可能なら薄手を。
