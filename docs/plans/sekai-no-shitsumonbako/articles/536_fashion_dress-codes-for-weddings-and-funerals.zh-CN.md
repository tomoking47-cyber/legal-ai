# Q. 日本婚丧场合的着装规范，必须严格遵守到什么程度？｜Japan Questions #536

- Shelf: `fashion` ／ URL: `/zh-cn/fashion/dress-codes-for-weddings-and-funerals` ／ Status: **草稿 — 出处未核实**

日本的礼仪着装有许多哪里都没写、却人人遵守的规矩。外国宾客常常栽在“黑色什么场合都行”，或者“请柬上写着「平服」（へいふく，意为‘平常服装’），所以我穿了休闲装”这两点上，当天感到尴尬。以下按场合类型，整理人们最容易弄错的要点。

## A. 作为婚礼宾客：女性穿过膝的连衣裙或套装，颜色除白色与米白色外皆可，裸露的肩膀用披肩遮住，拿小手包，穿包头高跟鞋。男性穿深色西装配白衬衫，领带用白色、银色或浅色——绝不用黑色。参加葬礼或「告別式」（kokubetsushiki，告别仪式）时，穿「喪服」（mofuku，黑色正式丧服）：无光泽的黑色西装或连衣裙、黑色丝袜、黑色布鞋或皮鞋，首饰不超过一串珍珠；男性系素黑领带、穿黑皮鞋与黑袜子。在「通夜」（tsuya，守灵）上，传统上素净的平常服装是可以接受的，表示你“听到消息就赶来了”，但如今多数人穿喪服。请柬上的「平服」并不是指日常便服，而是指半正式——深色西装或得体的连衣裙。

## 婚礼（作为宾客）

| 项目 | 女性 | 男性 |
|---|---|---|
| **基本** | **过膝**连衣裙、套装或长裤式礼服 | **深色西装（黑、藏青、炭灰）** + **白衬衫**。若穿黑色西装，用配饰提亮 |
| **应避免的颜色** | **白色、米白、浅米色**（新娘的颜色）。**全黑**会让人联想到丧事，请用配饰添色 | **黑色领带**（丧事用）。**白领带**是经典款，但**银色、浅色与小花纹**如今已是主流 |
| **应避免的面料与花纹** | **动物纹、毛皮与皮革，会联想到杀生**（包与鞋上的毛皮也要避开）。**用披肩遮住裸露的肩、胸与背** | 花哨的印花衬衫、休闲的纽扣领 |
| **鞋与包** | **包头高跟鞋（鞋跟 3–7 cm）**。**小号宴会包**；大件行李寄存在衣帽间 | **黑色皮鞋（内耳式横饰牛津鞋最正式）**、黑袜子 |
| **配饰** | **珍珠是标准配置。****垂坠耳环与手表**请低调 | 口袋巾（白色，或与领带呼应） |
| **和服** | 未婚女性：振袖（长袖）；已婚女性：訪問着或色留袖（正式的彩色和服）。**黑留袖仅限亲属穿着** | 亲属之外的男性很少穿和服 |
| **礼金（ご祝儀，goshūgi）** | 装礼金的信封要用**「袱紗」（fukusa，包裹用的布）**包好带去 | 同左 |

## 葬礼与告别仪式（作为一般吊唁者）

| 项目 | 女性 | 男性 |
|---|---|---|
| **服装** | **黑色正装**（无光泽的黑色连衣裙、套裙或西装）。**不露肌肤**，**裙长过膝** | **黑色西装**（**「礼服」，reifuku——比商务黑西装更深的黑**）+ **素白衬衫** + **素黑领带**（**领结不打凹褶**） |
| **鞋袜** | **黑色丝袜（30 丹尼尔以下，隐约透出肤色）**、**黑色高跟鞋（无装饰、无光泽、鞋跟 3–5 cm）** | **黑色皮鞋（内耳式横饰或素面）**、**黑袜子** |
| **配饰** | **最多只戴结婚戒指、一串珍珠与单粒耳钉。****避免两串——“悲伤加倍”** | **摘下手表，或戴素净的一只。** 不用领带夹 |
| **包** | **黑色布质、小号、没有显眼的金属件。** 有人因联想到杀生而避开皮革，但如今已被接受 | — |
| **妆容与发型** | **素净（「片化粧」，kata-keshō，半妆）**、**不用亮片与红色口红**，头发**低位束起**。**卸掉指甲油，或戴黑手套** | 修整面部胡须 |
| **儿童** | **校服就是正式服装。** 否则穿素净的黑、藏青或灰色 | 同左 |
| **需要带的东西** | **「数珠」（juzu，佛珠；略式的适用于各宗派）**、**用袱紗包好的「香典」（kōden，奠仪）**、**素白或黑色手帕** | 同左 |

- **「通夜」（守灵）**：旧礼仪是穿**素净的平常服装（深色西装、素色连衣裙）**，以示“听到消息就赶来了”。**如今只参加通夜的人增多，穿喪服的占多数。** 素净的平常服装依然不算错。
- **“请着平服出席”**（追思法事、告别聚会、婚礼二次会）：**指的是半正式，不是日常便服。****深色西装，或素净颜色的连衣裙。** 不要 T 恤、牛仔裤与运动鞋。
- **法事（「法事」，hōji——一周年忌与三周年忌）**：到一周年忌为止穿喪服；此后遵照主家的说明，改为**素净的平常服装**。
- **冬季外套**：**黑、藏青或灰色；不要毛皮、皮革与毛皮镶边。****进入会场前脱下**；在告别仪式上**要在走到接待处之前脱下**。
- **雨天**：**黑色或素色雨伞。** 透明塑料伞通常也被接受。
- **突然接到讣告而没有喪服时**：**租借（¥5,000–10,000）**、**在车站附近的连锁店买一套黑西装**，或**通夜穿素净服装出席、告别仪式穿喪服**。在日本，**拥有一套喪服被视为成年人的基本常识**，很多人**在二十几岁时购置**。

## 误解1｜一身黑色，婚礼与葬礼都能穿

**婚礼上全黑会让人联想到丧事；葬礼上商务黑西装的黑比“礼服的黑”浅，会很显眼。** 日本的习俗把两者分得很清楚。

## 误解2｜「平服」就是可以穿日常便服

**平服＝半正式（深色西装或得体的连衣裙）。** 穿休闲装去，你会是全场唯一的那一个。

## 误解3｜穿喪服去通夜很失礼，好像早就等着人去世

**那是旧观念；如今多数人只参加通夜，也多数人穿喪服。** 两者都可以接受。

## 误解4｜婚礼上白色不行，但米色没问题

**浅米色与米白色在照片上看起来就是白色，所以避开更保险。** 请用披肩或包来添色。

## 误解5｜葬礼的丝袜只要是黑色，厚一点也没关系

**一般说法是薄款、30 丹尼尔以下才正确**；厚裤袜显得随意。隆冬时节厚款渐渐被容许，但能穿薄款就穿薄款。
