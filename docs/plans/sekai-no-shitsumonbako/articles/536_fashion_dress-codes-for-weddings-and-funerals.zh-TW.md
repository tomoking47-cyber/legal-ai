# Q. 日本婚喪場合的服裝規範，必須嚴格遵守到什麼程度？｜Japan Questions #536

- Shelf: `fashion` ／ URL: `/zh-tw/fashion/dress-codes-for-weddings-and-funerals` ／ Status: **草稿 — 出處未核實**

日本的禮儀服裝有許多哪裡都沒寫、卻人人遵守的規矩。外國賓客常常栽在「黑色什麼場合都能穿」，或是「喜帖上寫著『平服』（へいふく，意為『平常的衣著』），所以我穿了休閒服」這兩點上，當天覺得尷尬。以下依場合類型，整理大家最容易搞錯的重點。

## A. 以婚禮賓客的身分出席：女性穿過膝的洋裝或套裝，顏色除了白色與米白色以外都可以，裸露的肩膀用披肩遮住，帶小手拿包，穿包頭的高跟鞋。男性穿深色西裝配白襯衫，領帶用白色、銀色或淺色——絕對不用黑色。參加葬禮或「告別式」（kokubetsushiki，告別儀式）時，穿「喪服」（mofuku，黑色正式喪服）：無光澤的黑色西裝或洋裝、黑色絲襪、黑色布鞋或皮鞋，首飾不超過一串珍珠；男性打素黑領帶、穿黑皮鞋與黑襪子。在「通夜」（tsuya，守靈）上，傳統上素淨的平常衣著是被接受的，代表你「一聽到消息就趕過來」，但如今多數人穿喪服。喜帖上的「平服」並不是指日常便服，而是指半正式——深色西裝或得體的洋裝。

## 婚禮（以賓客身分）

| 項目 | 女性 | 男性 |
|---|---|---|
| **基本** | **過膝**洋裝、套裝或長褲式禮服 | **深色西裝（黑、藏青、炭灰）** + **白襯衫**。若穿黑色西裝，用配件提亮 |
| **應避免的顏色** | **白色、米白、淺米色**（新娘的顏色）。**全黑**會讓人聯想到喪事，請用配件添色 | **黑色領帶**（喪事用）。**白領帶**是經典款，但**銀色、淺色與小碎花**如今已是主流 |
| **應避免的布料與花紋** | **動物紋、毛皮與皮革，會聯想到殺生**（包包與鞋上的毛皮也要避開）。**用披肩遮住裸露的肩、胸與背** | 花俏的印花襯衫、休閒的鈕扣領 |
| **鞋與包** | **包頭高跟鞋（鞋跟 3–7 cm）**。**小型宴會包**；大件行李寄放在衣帽間 | **黑色皮鞋（內耳式橫飾牛津鞋最正式）**、黑襪子 |
| **配件** | **珍珠是標準配置。****垂墜耳環與手錶**請低調 | 口袋巾（白色，或與領帶呼應） |
| **和服** | 未婚女性：振袖（長袖）；已婚女性：訪問著或色留袖（正式的彩色和服）。**黑留袖只有親屬能穿** | 親屬以外的男性很少穿和服 |
| **禮金（ご祝儀，goshūgi）** | 裝禮金的信封要用**「袱紗」（fukusa，包裹用的布）**包好帶去 | 同左 |

## 葬禮與告別儀式（以一般弔唁者身分）

| 項目 | 女性 | 男性 |
|---|---|---|
| **服裝** | **黑色正裝**（無光澤的黑色洋裝、套裝或西裝）。**不露肌膚**，**裙長過膝** | **黑色西裝**（**「禮服」，reifuku——比商務黑西裝更深的黑**）+ **素白襯衫** + **素黑領帶**（**領結不打凹褶**） |
| **鞋襪** | **黑色絲襪（30 丹尼以下，隱約透出膚色）**、**黑色高跟鞋（無裝飾、無光澤、鞋跟 3–5 cm）** | **黑色皮鞋（內耳式橫飾或素面）**、**黑襪子** |
| **配件** | **最多只戴結婚戒指、一串珍珠與單顆耳環。****避免兩串——「悲傷加倍」** | **拿下手錶，或戴素淨的一只。** 不用領帶夾 |
| **包** | **黑色布質、小型、沒有顯眼的金屬件。** 有人因為聯想到殺生而避開皮革，但如今已被接受 | — |
| **妝容與髮型** | **素淨（「片化粧」，kata-keshō，半妝）**、**不用亮片與紅色口紅**，頭髮**低位束起**。**卸掉指甲油，或戴黑手套** | 修整臉部鬍鬚 |
| **兒童** | **制服就是正式服裝。** 否則穿素淨的黑、藏青或灰色 | 同左 |
| **要帶的東西** | **「數珠」（juzu，念珠；略式的各宗派通用）**、**用袱紗包好的「香典」（kōden，奠儀）**、**素白或黑色手帕** | 同左 |

- **「通夜」（守靈）**：舊禮儀是穿**素淨的平常衣著（深色西裝、素色洋裝）**，表示「一聽到消息就趕過來」。**如今只參加通夜的人變多，穿喪服的占多數。** 素淨的平常衣著仍然不算錯。
- **「請著平服出席」**（追思法事、告別聚會、婚禮二次會）：**指的是半正式，不是日常便服。****深色西裝，或素淨顏色的洋裝。** 不要 T 恤、牛仔褲與球鞋。
- **法事（「法事」，hōji——一週年忌與三週年忌）**：到一週年忌為止穿喪服；之後依主家的說明，改為**素淨的平常衣著**。
- **冬季外套**：**黑、藏青或灰色；不要毛皮、皮革與毛皮滾邊。****進入會場前脫下**；在告別儀式上**要在走到報到處之前脫下**。
- **雨天**：**黑色或素色雨傘。** 透明塑膠傘通常也被接受。
- **突然接到訃聞而沒有喪服時**：**租借（¥5,000–10,000）**、**在車站前的量販店買一套黑西裝**，或**通夜穿素淨衣著出席、告別儀式穿喪服**。在日本，**擁有一套喪服被視為成年人的基本常識**，很多人**在二十幾歲時添購**。

> **[待核實]** 服裝習俗因地區、佛教宗派與世代而異。請對照禮儀服務業界團體與葬祭ディレクター技能審查協會的資料，確認目前的一般做法。

## 誤解1｜一身黑色，婚禮與葬禮都能穿

**婚禮上全黑會讓人聯想到喪事；葬禮上商務黑西裝的黑比「禮服的黑」淺，會很顯眼。** 日本的習俗把兩者分得很清楚。

## 誤解2｜「平服」就是可以穿日常便服

**平服＝半正式（深色西裝或得體的洋裝）。** 穿休閒服去，你會是全場唯一的那一個。

## 誤解3｜穿喪服去通夜很失禮，好像早就等著人過世

**那是舊觀念；如今多數人只參加通夜，也多數人穿喪服。** 兩者都可以接受。

## 誤解4｜婚禮上白色不行，但米色沒問題

**淺米色與米白色在照片上看起來就是白色，所以避開比較保險。** 請用披肩或包包來添色。

## 誤解5｜葬禮的絲襪只要是黑色，厚一點也沒關係

**一般說法是薄款、30 丹尼以下才正式**；厚褲襪看起來隨便。隆冬時節厚款漸漸被容許，但能穿薄款就穿薄款。
