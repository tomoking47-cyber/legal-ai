# Q. ブランドのバッグや服、偽物を見分けるには？海外通販で買ったら没収される？｜世界の質問箱 #539

- 棚：`fashion` ／ URL：`/questions/counterfeit-goods-and-customs` ／ ステータス：**ドラフト（法務レビュー前・出典未検証）**

高級ブランドの偽物は、海外通販やフリマアプリを通じて日本の消費者にも届いています。「安いから偽物でもいい」と思って買うと、税関で没収されるだけでなく、2023年の法改正で個人使用目的の輸入でも取り締まりの対象になりました。見分け方と、法律上の位置づけを整理します。

## A. 2021年改正の商標法・意匠法（2022年10月1日施行）で、海外の事業者から日本の個人へ偽ブランド品を送る行為は「個人使用目的でも」商標権侵害となり、税関で没収されます（買った側が罰せられることは通常ありませんが、代金は戻りません）。見分けの基本は「相場より極端に安い」「正規販路以外（SNS広告・無名サイト・フリマの新品未使用大量出品）」「ロゴ・縫製・金具の刻印・付属品の粗さ」の3点ですが、精巧な偽物は写真では判別できません。確実なのは正規店・正規代理店・鑑定付きの大手リユース店で買うこと。フリマで買う場合は、購入後に鑑定サービス（1点数千円）を使い、偽物なら取引キャンセルの手続きを。

## 法律と税関

| 項目 | 内容 |
|---|---|
| **税関での没収** | 偽ブランド品は**知的財産侵害物品として輸入禁止**。税関が認定すると**没収・廃棄**。**2023年度の差止件数は約2.9万件、約100万点**、**多くが中国・香港から** |
| **2022年10月施行の改正** | **海外事業者が日本の個人に郵送する行為も商標権侵害**に。従来は「個人使用なら業としての輸入ではない」という抜け道があったが、これが閉じられた |
| **買った人の責任** | **購入者が刑事罰を受けることは通常ない**が、**代金は戻らず、商品は没収**。**転売すれば商標法違反（10年以下の懲役または1,000万円以下の罰金）** |
| **フリマでの売買** | **偽物と知らずに出品しても商標法違反の可能性**。プラットフォームは出品削除・アカウント停止。**購入者は偽物と判明すれば返金対象**（各社の補償制度） |
| **税関からの通知** | 「認定手続開始通知書」が届いたら、**偽物であれば争わず「争わない」旨を回答**すると廃棄で終わる。**正規品と主張するなら証拠（購入証明）を提出** |

## 見分け方の目安

| 観点 | 偽物のサイン |
|---|---|
| **価格** | **定価の3〜5割以下の新品**は疑う。人気バッグは中古でも定価の7割前後が相場 |
| **販路** | **SNS広告経由の無名サイト**、**ドメインがブランド名＋数字**、**支払いが銀行振込のみ**、**日本語が不自然**、**「正規品」「本物保証」の強調** |
| **ロゴ・刻印** | **フォントの太さ・字間の違い**、**金具の刻印が浅い・不揃い**、**ファスナーの引き手の刻印がない** |
| **縫製** | **ステッチの間隔が不揃い**、**糸の始末が雑**、**左右非対称** |
| **素材・においや重さ** | **革のにおいが化学的**、**本革のシボが均一過ぎる**、**軽すぎる・重すぎる** |
| **付属品** | **箱・保存袋・ギャランティカード**は偽物にも付く。**シリアル番号は偽物も再現**するため決定打にならない |
| **出品者** | **同じ人気モデルを新品未使用で複数出品**、**評価が急に増えた新規アカウント** |

- **確実な方法**：**正規店・正規代理店・百貨店**、**鑑定士がいる大手リユース店**（コメ兵、大黒屋、ブランドオフなど。**古物商許可**を確認）。**フリマは「鑑定付き取引」オプション**を使う。
- **買った後に不安**：**真贋鑑定サービス**（¥3,000〜10,000／点、リアル・オンライン）。フリマの場合は**受取評価をする前に鑑定**し、偽物なら**事務局に申請**。
- **「並行輸入品」と偽物は別**：並行輸入は**正規品を正規代理店以外のルートで輸入**したもので合法。ただし**メーカー保証が受けられない**場合がある。
- **「スーパーコピー」「N級品」**と表示して売るサイトは**偽物であることを自認**しており、購入は没収前提。
- **旅行先での購入**：**露店・市場の「ブランド品」は偽物と考える**。**帰国時に税関で没収**され、**繰り返せば注意・記録**の対象。

> **【要検証】** 税関の差止件数（2023年度）、2022年10月施行の改正の内容は財務省・特許庁の公表資料で確認してください。鑑定サービスの料金は目安です。

## 誤解1｜自分で使うだけなら偽物を買っても問題ない

**2022年10月以降、海外からの個人向け発送も商標権侵害となり、税関で没収されます。** 代金は戻りません。

## 誤解2｜ギャランティカードとシリアル番号があれば本物

**偽物にも付属品とシリアルは付きます。** 決定打にはならず、販路と価格の方が信頼できる判断材料です。

## 誤解3｜フリマで「正規品」と書いてあるから安心

**出品者が偽物と知らないケースもあります。** 相場より安い・新品大量出品なら疑い、鑑定付き取引を使う。

## 誤解4｜偽物を買ってしまっても転売すれば取り返せる

**偽物の販売は商標法違反で、刑事罰の対象**です。フリマの補償制度で返金を求める方が正当な道です。

## 誤解5｜並行輸入品は偽物

**並行輸入は正規品の別ルート輸入で合法**です。保証の扱いが異なるだけ。「並行輸入」を名乗る極端に安い無名サイトは別問題です。
