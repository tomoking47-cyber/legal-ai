# Q. 新品の服は着る前に洗った方がいい？｜世界の質問箱 #540

- 棚：`fashion` ／ URL：`/questions/washing-new-clothes-before-wearing` ／ ステータス：**ドラフト（法務レビュー前・出典未検証）**

買ったばかりの服をそのまま着る人と、必ず一度洗う人。日本では「新品は一度洗う」派が多数ですが、理由を聞くと曖昧です。何が付いているのか、洗うべき服と洗わなくてもよい服の線を整理します。

## A. 肌に直接触れる服（肌着、Tシャツ、シャツ、子ども服、パジャマ、タオル、寝具）は着る前に一度洗うのが無難です。理由は3つ。①製造・流通での防シワ・防カビ処理や染料の残り（ホルムアルデヒドは日本で規制されているが、基準内でも敏感な人は反応することがある。輸入品は特に）、②店頭での試着・ほこり・染料の色移り（濃色のデニムなど）、③糊（のり）で硬くなった生地の風合いを整える。アウター、ニット、洗濯不可の服は洗わずに着てよく、代わりに陰干しで風を通す程度で十分。乳幼児の服は必ず洗い、大人の服とは分けて洗うのが日本の一般的な習慣です。

## 新品の服に付いているもの

| 何が | なぜ付いている | 洗う理由 | 規制・目安 |
|---|---|---|---|
| **ホルムアルデヒド（樹脂加工の残り）** | 防シワ・防縮・防カビの樹脂加工で使われることがある | **皮膚のかぶれ・アレルギー**の原因になり得る。**水に溶けやすく、1回の洗濯で大きく減る** | 日本では**家庭用品規制法**で**乳幼児用（24か月以下）は「検出されないこと」（16ppm以下）、大人用の肌着等は75ppm以下**。**輸入品でも国内販売なら同じ基準** |
| **染料の余剰** | 染色後に残った色素 | **色移り・肌への付着**。**濃色デニム・黒Tシャツ**で顕著 | 初回は**単独で洗う** |
| **糊（のり）・仕上げ剤** | 生地の張り・見栄えのため | **硬さ・ゴワつき**、汗を吸いにくい | 1回洗えば落ちる |
| **ほこり・手の汚れ** | 製造・輸送・店頭での試着 | 衛生 | — |
| **防虫・防カビ剤の残り香** | 輸送コンテナや倉庫での処理 | においが気になることがある | 洗う・風を通す |

## 洗う・洗わないの目安

| 服 | 判断 |
|---|---|
| **肌着・Tシャツ・シャツ・パジャマ・靴下** | **洗う**（直接肌に触れる、汗を吸う） |
| **乳幼児・子どもの服** | **必ず洗う**。**大人の服と分けて**、**洗剤は少なめ、すすぎしっかり**、**柔軟剤は不要** |
| **タオル・シーツ・枕カバー** | **洗う**（糊と毛羽落ち。タオルは初回に多く抜ける） |
| **デニム・濃色の服** | **単独で洗う**（色移り防止）。**裏返し** |
| **ニット・セーター** | **洗わなくてよい**。気になれば陰干しで風を通す。洗うなら表示に従っておしゃれ着洗い |
| **コート・ジャケット・洗濯不可の服** | **洗わない**。**陰干し・ブラッシング** |
| **下着・水着** | **洗う**（衛生） |
| **靴** | 洗わない。中敷きを拭く程度 |

- **洗い方**：**表示に従って普通に洗えば十分**。**洗剤は通常量**、**柔軟剤は初回は不要**（吸水性を下げる）。**色移りテスト**：濡らした白い布で押さえて色が付くなら単独洗い。
- **ホルムアルデヒドの実際**：日本で販売される製品は基準内ですが、**基準内でも敏感な人・乳幼児は反応する可能性**があり、**1回洗うと大半が除去**されます。**「ホルムアルデヒド不使用」表示**の製品も多い。
- **輸入通販（海外サイト直送）**：**日本の家庭用品規制法の検査を経ていない**ため、**必ず洗う**。においが強い製品は複数回。
- **乳幼児の服を分ける理由**：大人の服の**皮脂・洗剤残り・柔軟剤の香料**が赤ちゃんの肌に付くのを避けるため。**「赤ちゃん用洗剤」は必須ではなく、通常の洗剤を少なめにしてすすぎを十分**にすれば代替できるという意見が多い。
- **タグ・ピン**：**プラスチックのタグ止め（ロックス）は根元で切る**（引っぱると穴が広がる）、**待ち針・仕付け糸**（スーツ・コートのポケット・ベンツ）は外す。**ポケットの仕付け糸は「開けてよい」印**。

> **【要検証】** ホルムアルデヒドの規制値（乳幼児16ppm以下、大人75ppm以下）は家庭用品規制法の資料で確認してください。輸入品の扱いも同法の対象範囲を確認のこと。

## 誤解1｜新品はきれいだから洗う必要はない

**樹脂加工の残り、余剰染料、糊、試着のほこりが付いています。** 肌に直接触れる服は一度洗うのが無難。

## 誤解2｜日本の服は規制があるから洗わなくても安全

**基準内でも敏感な人や乳幼児は反応することがあり、1回の洗濯で大半が除去されます。** 海外通販の直送品は規制の検査を経ていません。

## 誤解3｜何でもかんでも洗うべき

**ニット・コート・洗濯不可の服は洗わず、陰干しで風を通す程度で十分**です。洗うことで傷む服もあります。

## 誤解4｜赤ちゃんの服は専用洗剤で洗わないといけない

**通常の洗剤を少なめにして、すすぎを十分にすれば代替できます。** 大人の服と分けて洗うこと、柔軟剤を使わないことの方が重要。

## 誤解5｜濃色の服は洗うと色が落ちるから洗わない方がいい

**初回に落ちる余剰染料は、洗わなければ肌や他の服に移ります。** 単独で裏返して洗い、以降は色止まりします。
