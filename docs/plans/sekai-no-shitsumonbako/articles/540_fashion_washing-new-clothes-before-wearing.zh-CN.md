# Q. 新买的衣服，穿之前应该先洗一次吗？｜Japan Questions #540

- Shelf: `fashion` ／ URL: `/zh-cn/fashion/washing-new-clothes-before-wearing` ／ Status: **草稿 — 出处未核实**

有人把新衣服从店里买回来就直接穿，也有人一定先洗一遍。在日本，“先洗一次”这一派是多数，不过很少有人说得清到底为什么。以下整理新衣服上究竟有什么，以及该洗与可以不洗的分界线。

## A. 贴身穿的东西——贴身内衣、T 恤、衬衫、童装、睡衣、毛巾、床上用品——最好在使用前先洗一次。理由有三个。① 制造与运输过程中留下的防皱、防霉加工残留与染料（甲醛在日本受到规制，但敏感的人即使在限值内也可能有反应，进口品尤其如此）。② 灰尘、店内其他人试穿留下的东西，以及染料转移（例如深色牛仔布）。③ 让上过浆而发硬的布料变软。外套、针织衫与标示“不可水洗”的衣物可以不洗直接穿；放在阴凉处通风即可。婴幼儿与儿童的衣服则一定要洗，而且与大人的衣服分开洗——这是日本一般的习惯。

## 新衣服上有什么

| 是什么 | 为什么会在上面 | 为什么要洗 | 规定与参考 |
|---|---|---|---|
| **甲醛（树脂加工的残留）** | 有时用于防皱、防缩、防霉的树脂加工 | 可能引起**皮肤起疹与过敏反应**。**极易溶于水，洗一次即可去除大部分** | 依日本**《含有有害物质的家庭用品规制法》**，**婴幼儿用品（24 个月以下）必须“不得检出”（16 ppm 以下）；成人贴身衣物等为 75 ppm 以下**。**在日本销售的进口品适用同样的限值** |
| **多余的染料** | 染色后残留的色素 | **会转移到皮肤与其他衣物上。****深色牛仔布与黑色 T 恤**尤其明显 | 第一次**单独洗** |
| **浆料与整理剂** | 为了挺括与货架卖相 | **手感发硬、粗糙**；吸汗性差 | 洗一次即可去除 |
| **灰尘与手上的脏污** | 制造、运输与店内试穿 | 卫生 | — |
| **杀虫剂或防霉剂的残留气味** | 运输集装箱与仓库的熏蒸处理 | 气味可能令人不适 | 洗，或通风晾一晾 |

## 洗还是不洗——一份指引

| 衣物 | 判断 |
|---|---|
| **贴身内衣、T 恤、衬衫、睡衣、袜子** | **洗**（直接接触皮肤，会吸汗） |
| **婴幼儿与儿童的衣服** | **一定要洗。****与大人的衣服分开洗**、**洗涤剂少放、彻底漂洗**、**不用柔顺剂** |
| **毛巾、床单、枕套** | **洗**（有浆料与掉落的绒毛；毛巾第一次掉得最多） |
| **牛仔布与深色衣物** | **单独洗**（防止串色）。**翻到反面** |
| **针织衫与毛衣** | **可以不洗。** 在意的话放阴凉处通风。若要洗，请遵循标签、使用轻柔程序 |
| **大衣、夹克、标示“不可水洗”的衣物** | **不要洗。****阴凉处通风并用衣刷刷理**  |
| **内衣与泳装** | **洗**（卫生） |
| **鞋** | 不要洗。最多擦一擦鞋垫 |

- **怎么洗**：**按洗涤标签普通地洗一次就够**（日本使用国际通用的 JIS L0001 符号）。**洗涤剂用平常的量**；**第一次不用柔顺剂**（会降低吸水性）。**串色测试**：用湿的白布按压布面，若沾上颜色就单独洗。
- **甲醛的实际情况**：在日本销售的产品都在限值内，但**敏感人群与婴幼儿仍可能有反应**，而且**洗一次就能去除大部分**。很多产品会标注**“无甲醛”**。
- **海外网店直邮**：**它们没有经过日本家庭用品规制法的检查**，所以**务必先洗**。气味重的要多洗几次。
- **婴儿衣物为什么要分开洗**：为了不让**大人衣物上的皮脂、洗涤剂残留与柔顺剂香味**沾到宝宝皮肤上。**“婴儿专用洗涤剂”并非必需**；一般认为**普通洗涤剂少放一点、彻底漂洗**就能达到目的。
- **吊牌与别针**：**塑料吊牌绳要从根部剪断**（硬拽会把孔撑大），并取下**别针与假缝线**（西装与大衣的口袋和开衩处）。**口袋上有假缝线，意思是“这个口袋可以拆开”。**

> **[待核实]** 甲醛的限值（婴幼儿 16 ppm 以下、成人 75 ppm 以下）请对照《含有有害物质的家庭用品规制法》确认。进口品如何纳入该法适用范围也请一并确认。

## 误解1｜新衣服是干净的，不用洗

**上面有树脂加工的残留、多余的染料、浆料，以及试穿带来的灰尘。** 贴身穿的东西最好先洗一次。

## 误解2｜日本的衣服受规制，不洗也安全

**敏感人群与婴幼儿即使在限值内也可能有反应，而且洗一次就能去除大部分残留。** 海外网店直邮的商品并未经过规制方面的检查。

## 误解3｜所有衣服都该洗

**针织衫、大衣与标示“不可水洗”的衣物，只要放在阴凉处通风就够了。** 有些衣物会因水洗而受损。

## 误解4｜婴儿衣物必须用专用的婴儿洗涤剂

**普通洗涤剂少放一点、彻底漂洗就能达到目的。** 与大人衣物分开洗、不用柔顺剂，才是更重要的事。

## 误解5｜深色衣服一洗就掉色，还是别洗

**第一次洗时掉出来的多余染料，不洗的话就会跑到你的皮肤和别的衣服上。** 请翻面单独洗；洗过之后颜色就稳定了。
