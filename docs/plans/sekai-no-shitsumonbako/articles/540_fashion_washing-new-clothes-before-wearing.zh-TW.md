# Q. 新買的衣服，穿之前應該先洗一次嗎？｜Japan Questions #540

- Shelf: `fashion` ／ URL: `/zh-tw/fashion/washing-new-clothes-before-wearing` ／ Status: **草稿 — 出處未核實**

有人把新衣服從店裡買回來就直接穿，也有人一定先洗過一遍。在日本，「先洗一次」這一派是多數，不過很少有人說得清究竟為什麼。以下整理新衣服上到底有什麼，以及該洗與可以不洗的分界。

## A. 貼身穿的東西——貼身內衣、T 恤、襯衫、童裝、睡衣、毛巾、寢具——最好在使用前先洗一次。理由有三個。① 製造與運送過程中留下的防皺、防黴加工殘留與染料（甲醛在日本受到規範，但敏感的人即使在限值內也可能有反應，進口品尤其如此）。② 灰塵、店內其他人試穿留下的東西，以及染料轉移（例如深色丹寧）。③ 讓上過漿而變硬的布料變柔軟。外套、針織衫與標示「不可水洗」的衣物可以不洗直接穿；放在陰涼處通風就夠了。嬰幼兒與兒童的衣服則一定要洗，而且與大人的衣服分開洗——這是日本一般的習慣。

## 新衣服上有什麼

| 是什麼 | 為什麼會在上面 | 為什麼要洗 | 規定與參考 |
|---|---|---|---|
| **甲醛（樹脂加工的殘留）** | 有時用於防皺、防縮、防黴的樹脂加工 | 可能引起**皮膚起疹與過敏反應**。**極易溶於水，洗一次即可去除大部分** | 依日本**《含有有害物質的家庭用品規制法》**，**嬰幼兒用品（24 個月以下）必須「不得檢出」（16 ppm 以下）；成人貼身衣物等為 75 ppm 以下**。**在日本販售的進口品適用同樣的限值** |
| **多餘的染料** | 染色後殘留的色素 | **會沾染到皮膚與其他衣物上。****深色丹寧與黑色 T 恤**尤其明顯 | 第一次**單獨洗** |
| **漿料與整理劑** | 為了挺括與貨架賣相 | **手感硬、粗糙**；吸汗性差 | 洗一次即可去除 |
| **灰塵與手上的髒污** | 製造、運送與店內試穿 | 衛生 | — |
| **殺蟲劑或防黴劑的殘留氣味** | 貨櫃與倉庫的燻蒸處理 | 氣味可能令人不適 | 洗，或通風晾一晾 |

## 洗還是不洗——一份指引

| 衣物 | 判斷 |
|---|---|
| **貼身內衣、T 恤、襯衫、睡衣、襪子** | **洗**（直接接觸皮膚，會吸汗） |
| **嬰幼兒與兒童的衣服** | **一定要洗。****與大人的衣服分開洗**、**洗劑少放、徹底沖洗**、**不用柔軟精** |
| **毛巾、床單、枕頭套** | **洗**（有漿料與掉落的棉絮；毛巾第一次掉得最多） |
| **丹寧與深色衣物** | **單獨洗**（防止染色）。**翻到反面** |
| **針織衫與毛衣** | **可以不洗。** 在意的話放陰涼處通風。若要洗，請依標示使用輕柔行程 |
| **大衣、外套、標示「不可水洗」的衣物** | **不要洗。****陰涼處通風並用衣刷刷理** |
| **內衣與泳衣** | **洗**（衛生） |
| **鞋** | 不要洗。頂多擦一擦鞋墊 |

- **怎麼洗**：**依洗滌標示普通地洗一次就夠**（日本使用國際通用的 JIS L0001 符號）。**洗劑用平常的量**；**第一次不用柔軟精**（會降低吸水性）。**染色測試**：用濕的白布按壓布面，若沾上顏色就單獨洗。
- **甲醛的實際情況**：在日本販售的產品都在限值內，但**敏感族群與嬰幼兒仍可能有反應**，而且**洗一次就能去除大部分**。很多產品會標示**「無甲醛」**。
- **海外網購直送**：**它們沒有經過日本家庭用品規制法的查核**，所以**務必先洗**。氣味重的要多洗幾次。
- **嬰兒衣物為什麼要分開洗**：為了不讓**大人衣物上的皮脂、洗劑殘留與柔軟精香味**沾到寶寶皮膚上。**「嬰兒專用洗劑」並非必要**；一般認為**普通洗劑少放一點、徹底沖洗**就能達到目的。
- **吊牌與別針**：**塑膠吊牌繩要從根部剪斷**（硬扯會把孔撐大），並取下**別針與假縫線**（西裝與大衣的口袋和開衩處）。**口袋上有假縫線，意思是「這個口袋可以拆開」。**

> **[待核實]** 甲醛的限值（嬰幼兒 16 ppm 以下、成人 75 ppm 以下）請對照《含有有害物質的家庭用品規制法》確認。進口品如何納入該法適用範圍也請一併確認。

## 誤解1｜新衣服是乾淨的，不用洗

**上面有樹脂加工的殘留、多餘的染料、漿料，以及試穿帶來的灰塵。** 貼身穿的東西最好先洗一次。

## 誤解2｜日本的衣服有規範，不洗也安全

**敏感族群與嬰幼兒即使在限值內也可能有反應，而且洗一次就能去除大部分殘留。** 海外網購直送的商品並未經過法規查核。

## 誤解3｜所有衣服都該洗

**針織衫、大衣與標示「不可水洗」的衣物，只要放在陰涼處通風就夠了。** 有些衣物會因水洗而受損。

## 誤解4｜嬰兒衣物一定要用專用的嬰兒洗劑

**普通洗劑少放一點、徹底沖洗就能達到目的。** 與大人衣物分開洗、不用柔軟精，才是更重要的事。

## 誤解5｜深色衣服一洗就掉色，還是別洗

**第一次洗時掉出來的多餘染料，不洗的話就會跑到你的皮膚和其他衣服上。** 請翻面單獨洗；洗過之後顏色就穩定了。
