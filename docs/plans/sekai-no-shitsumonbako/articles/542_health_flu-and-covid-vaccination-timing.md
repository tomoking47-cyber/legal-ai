# Q. インフルエンザや新型コロナのワクチン、いつ打つのが効果的？｜世界の質問箱 #542

- 棚：`health` ／ URL：`/questions/flu-and-covid-vaccination-timing` ／ ステータス：**ドラフト（法務レビュー前・出典未検証）**

毎年秋になると、インフルエンザワクチンの予約が始まります。「早く打つと冬の終わりに効かない」「12月でも間に合う」など、時期の話は毎年繰り返されます。定期接種の制度が2024年に変わった新型コロナも含めて、時期と対象の考え方を整理します。

## A. インフルエンザワクチンは接種後2週間ほどで効果が出て、およそ5か月続くとされるため、流行が本格化する12月〜1月に備えて「10月中旬〜12月上旬」に打つのが目安です。13歳未満は2〜4週間空けて2回。新型コロナワクチンは2024年度から「65歳以上と60〜64歳の重症化リスクの高い人」を対象とした秋冬の定期接種（自己負担あり）に変わり、それ以外の人は任意接種（全額自己負担）です。両方を同じ日に打つことは認められています。ワクチンは「かからない」ためより「重症化を防ぐ」効果が中心で、発症予防効果はインフルエンザで年により40〜60%程度と報告されています。

## インフルエンザワクチン

| 項目 | 内容 |
|---|---|
| **効果が出るまで** | 接種後**約2週間** |
| **効果の持続** | **約5か月**（個人差あり） |
| **接種時期の目安** | **10月中旬〜12月上旬**。流行は**12月〜3月**、ピークは**1月下旬〜2月** |
| **回数** | **13歳以上：1回**。**6か月〜13歳未満：2回（2〜4週間空ける）** |
| **費用** | 任意接種で**3,000〜5,000円**程度（医療機関で異なる）。**65歳以上は定期接種**で自治体の補助あり（自己負担1,000〜2,500円程度が多い） |
| **効果** | **発症予防効果は年により40〜60%程度**（流行株との一致度で変動）。**重症化・入院・死亡の予防効果**の方が安定している。高齢者施設での死亡リスク低下は**約80%**という報告 |
| **副反応** | 接種部位の**赤み・腫れ・痛み（10〜20%）**、**発熱・倦怠感（5〜10%）**、多くは2〜3日で治まる。**アナフィラキシーはまれ** |
| **打てない人・相談が必要な人** | **37.5℃以上の発熱**、**重い急性疾患**、**過去に強いアレルギー反応**。卵アレルギーは多くの場合接種可能（医師に相談） |

## 新型コロナワクチン（2024年度以降）

| 項目 | 内容 |
|---|---|
| **定期接種の対象** | **65歳以上**、**60〜64歳で心臓・腎臓・呼吸器の機能に重い障害がある人、HIVによる免疫機能障害がある人** |
| **時期** | **秋冬（自治体により10月〜翌年3月）**、**年1回** |
| **費用** | **原則自己負担あり（自治体により無料〜7,000円程度）**。**対象外の人は任意接種で全額自己負担（15,000円前後）** |
| **同時接種** | **インフルエンザワクチンと同時接種可**（同日、別部位） |
| **考え方** | **重症化予防**が中心。**流行株に合わせて毎年更新**される |

- **同時接種**：インフルエンザとコロナは**同じ日に打てる**。副反応がやや強く出ることがあるため、翌日に予定がない日を選ぶ人も。
- **早すぎる接種の心配**：10月上旬に打っても**3月まで効果は残ることが多い**。**「12月以降に打ちたい」より「打たないまま流行が来る」方が損失が大きい**ため、予約が取れる時に打つのが現実的。
- **妊娠中**：インフルエンザワクチンは**不活化ワクチンで妊娠中も接種可**、むしろ推奨されている。新型コロナワクチンも妊娠中の接種が推奨されている。
- **子ども**：**生後6か月から接種可**。**保育園・学校での流行**が家庭内感染の入り口になるため、家族全員で打つ考え方が一般的。
- **打ったのにかかった**：ワクチンの発症予防効果は完全ではないが、**症状が軽く済む**ことが多い。「打っても意味がない」とは言えません。
- **費用の補助**：**65歳以上は自治体、子どもは一部自治体で助成、企業の健康保険組合で補助**がある場合も。**確定申告の医療費控除**の対象になるのは**定期接種などの一部**で、任意接種は対象外。

> **【要検証】** 発症予防効果の数値、副反応の頻度は厚生労働省・国立感染症研究所の資料に基づきます。新型コロナワクチンの定期接種の対象・費用は2024年度の制度に基づくため、公開年度の制度を確認してください。

## 誤解1｜早く打つと流行の終わりに効かなくなる

**効果は約5か月続き、10月中旬の接種でも3月までカバーできることが多い**です。打てる時に打つ方が確実。

## 誤解2｜ワクチンを打てばインフルエンザにかからない

**発症予防効果は年により40〜60%程度で、完全ではありません。** 重症化を防ぐ効果の方が安定しています。

## 誤解3｜卵アレルギーがあると打てない

**現在のワクチンの卵成分は微量で、多くの場合接種できます。** 医師に伝えて相談すれば済みます。

## 誤解4｜新型コロナワクチンは今も全員無料

**2024年度から65歳以上などを対象とする定期接種（自己負担あり）に変わり、それ以外は任意接種で全額自己負担**です。

## 誤解5｜インフルエンザとコロナは別々の日に打たないと危ない

**同時接種は認められています。** 副反応がやや強く出る可能性があるので、翌日の予定に配慮を。
