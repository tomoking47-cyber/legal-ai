# Q. 頭痛はどこまで様子見でいい？危ない頭痛の見分け方｜世界の質問箱 #543

- 棚：`health` ／ URL：`/questions/headaches-when-to-worry` ／ ステータス：**ドラフト（法務レビュー前・出典未検証）**

頭痛は日本人の3〜4人に1人が慢性的に抱えるとされ、市販の鎮痛薬は薬局の主力商品です。ほとんどは命に関わらない「一次性頭痛（片頭痛・緊張型頭痛）」ですが、まれに脳の病気による頭痛が混ざります。見分け方と、薬の使い方の注意を整理します。

## A. 頭痛の大半は、片頭痛（ズキズキ、光や音がつらい、動くと悪化、4〜72時間）と緊張型頭痛（締めつけられる、肩こりを伴う、動いても悪化しない）で、休養・市販薬で対応できます。ただし「突然の今までにない激しい頭痛（数秒〜1分でピーク）」「発熱と首の硬直を伴う」「手足のしびれ・言葉が出にくい・意識がぼんやり」「50歳以降に初めて起きた頭痛」「頭を打った後」「日ごとに悪化する」——これらは危険なサインで、救急受診が必要です。もう一つの落とし穴が「薬物乱用頭痛」で、月10日以上鎮痛薬を飲む状態が3か月続くと、薬そのものが頭痛の原因になります。市販薬が月10日を超えるなら頭痛外来へ。

## よくある頭痛の見分け

| 種類 | 特徴 | 持続 | 対応 |
|---|---|---|---|
| **緊張型頭痛** | **後頭部〜頭全体が締めつけられる**。**肩・首のこり**を伴う。**動いても悪化しない**。**最も多い** | 30分〜数日 | 温める、ストレッチ、姿勢、睡眠。市販の鎮痛薬 |
| **片頭痛** | **片側または両側のズキズキ**。**光・音・においがつらい**、**吐き気**、**動くと悪化**。**前兆（ギザギザの光）**が出る人も。**女性は男性の3〜4倍**、月経・気圧・寝不足・空腹・チーズやワインが誘因に | **4〜72時間** | 暗く静かな場所で休む、冷やす。市販薬が効かなければ**処方薬（トリプタン、2021年以降は予防の注射薬も）** |
| **群発頭痛** | **片目の奥がえぐられるような激痛**、**涙・鼻水・目の充血**。**1〜2か月間、毎日同じ時刻**に。男性に多い | 15分〜3時間 | **頭痛外来**（酸素吸入、処方薬） |
| **薬物乱用頭痛** | **鎮痛薬を月10日以上（単純鎮痛薬は15日以上）、3か月以上**飲んでいる。**毎日のように頭が重い・痛い** | 慢性 | **頭痛外来で薬の調整**。自己判断で急にやめると悪化することも |

## 危険なサイン（すぐ受診・救急）

| サイン | 疑われるもの |
|---|---|
| **突然、数秒〜1分でピークになる「人生で一番」の激痛**（雷鳴頭痛） | **くも膜下出血** |
| **発熱＋首が硬くて曲げられない＋頭痛** | **髄膜炎** |
| **手足のしびれ・麻痺、言葉が出にくい、ろれつが回らない、視野の欠け、意識がぼんやり** | **脳卒中、脳腫瘍** |
| **頭を打った後の頭痛**（数時間〜数週間後でも） | **硬膜外・硬膜下血腫**（高齢者は数週間後の慢性硬膜下血腫も） |
| **50歳以降に初めて起きた頭痛、日ごとに悪化する頭痛** | **側頭動脈炎、腫瘍など** |
| **咳・いきみ・運動で誘発される頭痛** | 脳の構造の問題 |
| **妊娠中・産後の強い頭痛** | 妊娠高血圧症候群 |

- **市販薬の選び方**：**アセトアミノフェン**（胃に優しい、子ども・妊婦も使いやすい）、**イブプロフェン・ロキソプロフェン**（炎症を抑える、胃への負担あり）。**カフェイン配合**は効きが良く感じるが**乱用頭痛の原因になりやすい**。**「頭痛が始まったら早めに1回分」**が効かせ方の基本、**我慢して大きくなってから飲むと効きにくい**。
- **飲む頻度の目安**：**月10日以内**。超えるなら**頭痛外来・神経内科・脳神経外科**で予防薬の相談。
- **頭痛ダイアリー**：**日付、時間、痛みの程度、誘因（睡眠・月経・天候・食事）、飲んだ薬**を記録すると、受診時に診断が早くなる。アプリも多数。
- **片頭痛と生活**：**規則的な睡眠（寝過ぎも誘因）**、**空腹を避ける**、**カフェインを一定に**、**気圧の変化を予測（アプリ）**、**光をサングラス・画面の明るさで調整**。
- **子どもの頭痛**：**片頭痛は子どもにもあり、腹痛や吐き気が前面に出る**ことも。**朝方の頭痛と嘔吐が続く**場合は小児科へ。
- **受診先**：**頭痛外来**（日本頭痛学会の認定医リストあり）、**神経内科・脳神経内科**、**脳神経外科**。**危険なサインは救急（119）**。

> **【要検証】** 頭痛の有病率、片頭痛の男女比、薬物乱用頭痛の定義（月10日／15日）は日本頭痛学会「頭痛の診療ガイドライン2021」で確認してください。

## 誤解1｜頭痛はいつものことだから病院に行くほどではない

**多くはその通りですが、「突然の激痛」「発熱と首の硬直」「しびれ・言葉の異常」「50歳以降の初発」は例外**です。危険なサインだけは覚えておく価値があります。

## 誤解2｜市販の鎮痛薬は安全だから毎日飲んでもいい

**月10日以上を3か月続けると、薬自体が頭痛の原因（薬物乱用頭痛）になります。** 頻度が増えたら頭痛外来へ。

## 誤解3｜痛みが強くなってから薬を飲む方が効く

**片頭痛は始まりの早い段階で飲む方が効きます。** 我慢して大きくなってからでは効きにくい。

## 誤解4｜片頭痛は「頭痛持ちの体質」で治療法がない

**トリプタン系の処方薬、2021年以降は予防の注射薬（抗CGRP抗体）**があり、生活への影響を大きく減らせます。市販薬で対処し続けるより受診が近道。

## 誤解5｜頭を打った直後に何もなければ大丈夫

**高齢者では数週間後に慢性硬膜下血腫として頭痛・ふらつき・物忘れが出ることがあります。** 転倒後の変化は受診を。
