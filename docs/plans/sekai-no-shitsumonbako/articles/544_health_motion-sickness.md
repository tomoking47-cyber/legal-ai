# Q. 乗り物酔い、事前にできることは？酔い止めはいつ飲む？｜世界の質問箱 #544

- 棚：`health` ／ URL：`/questions/motion-sickness` ／ ステータス：**ドラフト（法務レビュー前・出典未検証）**

車・バス・船・飛行機、そして最近はVRゴーグル。乗り物酔いは子ども（特に4〜12歳）に多く、大人でも船やバスの後部座席で苦しむ人は少なくありません。日本の家庭で伝わる対策と、薬の正しい使い方を整理します。

## A. 乗り物酔いは、目で見ている情報と内耳（平衡感覚）が感じる揺れが食い違うことで起きます。対策の順番は、①揺れが少なく前方が見える席（車は前席、バスは前方、船は中央下層、飛行機は翼の上）、②遠くの景色を見て、スマホや読書をしない、③空腹・満腹・寝不足・強いにおいを避ける、④酔い止め薬は「乗る30分〜1時間前」に飲む（酔ってからでは効きにくい）、⑤酔い始めたら目を閉じて横になり、冷たい風を当てる。子どもは2歳未満はほとんど酔わず、成長とともに改善します。

## 対策の整理

| 対策 | 内容 | 根拠の程度 |
|---|---|---|
| **座席** | **車：前席（できれば運転席、次に助手席）**。**バス：前方・車輪の上を避ける**。**船：中央・低層・外が見える場所**。**飛行機：翼の上の窓側**。**電車：進行方向を向く** | 揺れの少ない位置は物理的に有利 |
| **視線** | **遠くの景色・進行方向を見る**。**スマホ・読書・下を向く作業は避ける**（目と内耳のズレが最大になる） | 高い |
| **運転する** | 運転者はほとんど酔わない（動きを予測できる） | 高い |
| **食事** | **空腹・満腹を避け、1〜2時間前に軽く**。**脂っこいもの・乳製品・炭酸・アルコールは避ける**。**しょうが**は吐き気軽減の報告あり | 中 |
| **睡眠・体調** | **寝不足・二日酔い・風邪気味は酔いやすい** | 高い |
| **におい・換気** | **排気ガス、芳香剤、食べ物のにおい**は誘因。**窓を開けて冷たい風** | 中 |
| **薬** | **乗る30分〜1時間前**に。**酔ってから飲んでも効きにくい**（吐いてしまう） | 高い |
| **リストバンド（ツボ押し）** | 手首の内側「内関」を押す。研究結果は分かれる | 低〜中 |
| **酔い始めたら** | **目を閉じる、横になる（頭を固定）、冷たい風、ベルトをゆるめる、飴やガム** | 経験的 |

## 市販の酔い止め薬

| 種類 | 成分の例 | 特徴 |
|---|---|---|
| **抗ヒスタミン薬** | ジメンヒドリナート、メクリジン、クロルフェニラミン | 最も一般的。**眠気**が出る。効果は**4〜6時間（メクリジンは長め）** |
| **抗コリン薬** | スコポラミン | 強い。**口の渇き・眠気**。子どもには使わない製品が多い |
| **配合薬** | 上記＋カフェイン、ビタミンB6 | 眠気を軽減する設計 |
| **子ども用** | 3歳以上（製品による）、5歳以上、チュアブル・ドロップ | **年齢と体重で用量が違う**。表示を必ず確認 |

- **飲むタイミング**：**30分〜1時間前**。**長時間の移動では追加服用の間隔を表示で確認**（多くは4〜6時間以上空ける）。
- **飲み合わせ**：**風邪薬・アレルギー薬（抗ヒスタミン）と重複**しやすい。**運転者は眠気の出る酔い止めを飲まない**。**緑内障・前立腺肥大**の人は抗コリン成分に注意。
- **子ども**：**2歳未満はほとんど酔わない**（平衡感覚が未発達）。**4〜12歳が最も酔いやすく**、思春期以降に改善する人が多い。**「酔うかも」という不安が誘因**になるため、**車内で歌う・しりとり・窓の外の看板探し**など、前を見る遊びが有効。**タブレットは最悪の組み合わせ**。
- **VR・3D酔い**：同じ仕組み（視覚と体感のズレ）。**20〜30分で休憩**、**フレームレートの高い機器**、**座って使う**。
- **受診の目安**：**乗り物に乗っていないのにめまい・吐き気が続く**、**片側の耳鳴り・難聴を伴う**（内耳の病気の可能性）、**強い頭痛**。**耳鼻咽喉科**へ。
- **旅行前の練習**：**短い乗車を繰り返すと慣れる（順応）**。船酔いは**2〜3日で治まる**ことが多い。

> **【要検証】** 酔い止め薬の成分・年齢制限は各製品の添付文書で、しょうが・リストバンドの効果に関する記述は臨床研究のレビューで確認してください。

## 誤解1｜酔ってから薬を飲めば楽になる

**酔い止めは予防薬で、乗る30分〜1時間前に飲むのが基本**です。酔ってからでは吐いてしまい効きにくい。

## 誤解2｜スマホで気を紛らわせれば酔わない

**近くの画面を見るのは目と内耳のズレを最大にする行為**で、最も酔いやすくなります。遠くの景色を。

## 誤解3｜何も食べずに乗れば吐かない

**空腹は酔いを悪化させます。** 1〜2時間前に軽く食べる。

## 誤解4｜子どもの乗り物酔いは気持ちの問題

**4〜12歳は生理的に酔いやすい時期**です。不安が誘因になる面はありますが、席・視線・薬で対処できます。

## 誤解5｜大人になったら酔わなくなる

**改善する人が多いが、船・バスの後部・寝不足・二日酔いでは大人も酔います。** 対策は同じ。
