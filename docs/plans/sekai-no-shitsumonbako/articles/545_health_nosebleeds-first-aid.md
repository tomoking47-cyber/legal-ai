# Q. 鼻血が出たとき、上を向く？ティッシュを詰める？正しい止め方｜世界の質問箱 #545

- 棚：`health` ／ URL：`/questions/nosebleeds-first-aid` ／ ステータス：**ドラフト（法務レビュー前・出典未検証）**

子どもの鼻血、乾燥した冬の朝の鼻血。「上を向いて」「首の後ろを叩いて」「ティッシュを詰めて」——日本の家庭で伝わってきた対処法の多くは、実は推奨されていません。耳鼻咽喉科が勧める止め方と、受診の目安を整理します。

## A. 正しい止め方は「座って、少し前かがみになり、小鼻（鼻の柔らかい部分）を親指と人差し指で両側からしっかりつまみ、10〜15分そのまま押さえ続ける」。上を向くと血がのどに流れて飲み込み、吐き気の原因になります。ティッシュを詰めると取るときに再出血しやすく、首の後ろを叩くのは意味がありません。鼻血の9割は鼻の入り口近く（キーゼルバッハ部位）からの出血で、この方法で止まります。20〜30分押さえても止まらない、大量、頻繫に繰り返す、血をサラサラにする薬を飲んでいる、けがの後——これらは耳鼻咽喉科か救急へ。

## 止め方の手順

| 手順 | やること | 理由 |
|---|---|---|
| **1. 座る** | **座って少し前かがみ**。寝かせない、上を向かない | 血をのどに流さない。飲み込むと吐き気・嘔吐 |
| **2. つまむ** | **小鼻（鼻の骨の下の柔らかい部分）を親指と人差し指で両側から強くつまむ** | 出血点の9割がある**キーゼルバッハ部位**（鼻の入り口から1〜2cm）を直接圧迫 |
| **3. 押さえ続ける** | **10〜15分、途中で離して確認しない** | 離すと固まりかけた血が崩れる |
| **4. 冷やす** | 鼻の根元・額を冷たいタオルで（補助） | 血管収縮 |
| **5. 口で呼吸** | 口から静かに呼吸。血が口に来たら吐き出す | — |
| **6. 止まったら** | **数時間は鼻をかまない・こすらない・強くいきまない・熱い風呂を避ける** | 再出血防止 |

## やってはいけないこと

| 行為 | 問題 |
|---|---|
| **上を向く・寝る** | 血がのどへ流れて**飲み込み、吐き気・嘔吐**の原因。量もわからなくなる |
| **ティッシュを詰める** | 取るときに**かさぶたが剥がれて再出血**。繊維が残る。詰めるなら**清潔なガーゼを浅く**、それより「つまむ」 |
| **首の後ろを叩く・冷やす** | **止血効果はない** |
| **鼻の硬い部分（鼻骨）を押す** | 出血点を押さえられない |
| **数分で離して確認** | 止まりかけを崩す |

## 受診の目安

- **20〜30分つまんでも止まらない**、**出血量が多い**（コップ半分以上、めまい・顔色が悪い）→**救急**。
- **週に何度も繰り返す**、**片側だけ繰り返す**（腫瘍や構造の問題の可能性）、**鼻以外（歯ぐき、皮下）にも出血しやすい**→**耳鼻咽喉科・内科**。
- **抗血小板薬・抗凝固薬（血をサラサラにする薬）を飲んでいる**、**高血圧で顔が赤くのぼせている**→止まりにくい。早めに受診。
- **顔をぶつけた後の鼻血**（骨折の可能性）、**頭を打った後の鼻血**（透明な液が混じる場合は緊急）。
- **子どもが異物を入れた可能性**（片側だけ、においのある鼻汁）。

## 予防

- **冬の乾燥**：**室内湿度40〜60%**、**鼻の入り口にワセリンを綿棒で薄く**（寝る前）。**鼻をほじる・強くかむ**が最大の誘因（子どもはほぼこれ）。
- **アレルギー性鼻炎**：かゆみでこする→出血。**点鼻薬・内服で炎症を抑える**方が止血より先。
- **のぼせ**：**熱い風呂の直後、激しい運動、飲酒後**は出やすい。
- **頻繫に出る子ども**：耳鼻咽喉科で**出血点を焼く処置（電気・薬品）**が可能。

> **【要検証】** キーゼルバッハ部位からの出血の割合、圧迫時間の目安は耳鼻咽喉科の一般的な指導内容です。日本耳鼻咽喉科頭頸部外科学会の資料で確認してください。

## 誤解1｜上を向いて血が垂れないようにする

**血がのどに流れて飲み込み、吐き気の原因になります。** 座って前かがみが正解。

## 誤解2｜ティッシュを詰めるのが一番

**取るときに再出血し、繊維も残ります。** 小鼻を10〜15分つまむ方が確実。

## 誤解3｜首の後ろを叩けば止まる

**止血効果はありません。** 昔からの俗説です。

## 誤解4｜鼻血が多いのは貧血や白血病のサイン

**子どもの頻繫な鼻血の大半は乾燥・鼻いじり・アレルギーが原因**です。ただし他の部位も出血しやすい、あざが増える場合は血液検査を。

## 誤解5｜止まったらすぐ普通に鼻をかんでいい

**数時間はかさぶたが弱く、かむ・こする・熱い風呂で再出血します。** その日は鼻を触らない。
