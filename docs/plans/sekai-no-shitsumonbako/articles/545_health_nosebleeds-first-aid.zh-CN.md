# Q. 流鼻血时该仰头吗？该塞纸巾吗？正确的止血方法｜Japan Questions #545

- Shelf: `health` ／ URL: `/zh-cn/health/nosebleeds-first-aid` ／ Status: **草稿 — 出处未核实**

孩子流鼻血，或是干燥的冬天早晨突然流鼻血。「把头仰起来」「拍拍后颈」「塞进纸巾」——日本家庭里代代相传的这些做法，其实很多都不被推荐。下面整理耳鼻喉科医生推荐的方法，以及什么时候该就医。

## A. 正确的方法是：坐下，身体稍微前倾，用拇指和食指从两侧牢牢捏住鼻子柔软的部分（鼻骨以下），持续按压 10～15 分钟。仰头会让血流进喉咙，咽下去会引起恶心。塞纸巾会在取出时容易再次出血，拍后颈则毫无作用。十次流鼻血中有九次来自鼻腔入口附近（利特尔区／Kiesselbach 区），用这个方法就能止住。按压 20～30 分钟仍止不住、出血量大、频繁反复、正在服用抗凝血药物、受伤后出血——这些情况请去耳鼻咽喉科（耳鼻咽喉科，即耳鼻喉科）或急诊。

## 止血步骤

| 步骤 | 怎么做 | 为什么 |
|---|---|---|
| **1. 坐下** | **坐着，身体稍微前倾**。不要躺下，也不要仰头 | 不让血流进喉咙。咽下去会引起恶心、呕吐 |
| **2. 捏住** | **用拇指和食指从两侧牢牢捏住鼻子柔软的部分（鼻骨以下）** | 直接压迫**利特尔区（Kiesselbach 区）**（鼻孔内 1～2 厘米），九成出血点都在这里 |
| **3. 持续按压** | **10～15 分钟，中途不要松手查看** | 松手会破坏正在形成的血凝块 |
| **4. 冷敷** | 用冷毛巾敷鼻根和额头（辅助） | 收缩血管 |
| **5. 用嘴呼吸** | 用嘴平静地呼吸。流到口中的血请吐出来 | — |
| **6. 止住之后** | **数小时内不要擤鼻、揉鼻，不要用力憋气，避免泡热水澡** | 防止再次出血 |

## 不该做的事

| 做法 | 问题 |
|---|---|
| **仰头或躺下** | 血流进喉咙并**被咽下，引起恶心、呕吐**。也无法掌握出血量 |
| **塞纸巾** | **取出时把血痂撕掉，出血重新开始**。还会留下纤维。若一定要填塞，请用**干净的纱布，浅浅地放**——但捏鼻更好 |
| **拍打或冷敷后颈** | **对止血没有任何作用** |
| **按压鼻子坚硬的部分（鼻骨）** | 压不到出血点 |
| **按几分钟就松手查看** | 破坏正在形成的血凝块 |

## 什么时候该就医

- **捏住 20～30 分钟仍在出血**，或**出血量大**（超过半杯、头晕、面色苍白）→ **急诊**。
- **每周数次**、**反复只在一侧出血**（可能有肿瘤或结构问题）、**其他部位也容易出血（牙龈、皮下）** → **耳鼻咽喉科或内科（内科）**。
- **正在服用抗血小板药或抗凝药（血液稀释药）**、**血压高且面部发红发热** → 更难止血。请尽早就医。
- **面部受撞击后流鼻血**（可能骨折）、**头部受撞击后流鼻血**（若混有清亮的液体，属于急症）。
- **可能把异物塞进鼻子的孩子**（只有一侧，分泌物有臭味）。

## 预防

- **冬季干燥**：**室内湿度 40～60%**，**用棉签在鼻孔入口薄薄涂一层凡士林**（睡前）。**抠鼻子和用力擤鼻**是最大的诱因（儿童几乎都是这个原因）。
- **过敏性鼻炎**：发痒 → 揉搓 → 出血。**先用鼻喷剂或口服药控制炎症**，比止血更优先。
- **脸部潮红**：**刚泡完热水澡、剧烈运动后和饮酒后**更容易出血。
- **经常流鼻血的孩子**：耳鼻咽喉科可以**对出血点进行烧灼（电烧或化学烧灼）**。

> **[待核实]** 利特尔区（Kiesselbach 区）出血所占比例与按压时间的参考值，属于耳鼻喉科的标准指导。请对照日本耳鼻咽喉科头颈部外科学会的资料核对。

## 误解1｜仰起头，血就不会滴下来

**血会流进喉咙被咽下去，引起恶心。** 请坐下并稍微前倾。

## 误解2｜塞纸巾是最好的办法

**取出时会重新出血，还会留下纤维。** 捏住鼻子柔软的部分 10～15 分钟更可靠。

## 误解3｜拍拍后颈就能止住

**这对出血没有任何作用。** 是一种流传已久的民间说法。

## 误解4｜经常流鼻血是贫血或白血病的征兆

**儿童频繁流鼻血，大多是干燥、抠鼻和过敏造成的。** 但如果其他部位也容易出血，或瘀青变多，请做血液检查。

## 误解5｜止住以后就可以照常擤鼻子

**数小时内血痂还很脆弱，擤鼻、揉鼻或泡热水澡都会让出血重新开始。** 当天请让鼻子好好休息。
