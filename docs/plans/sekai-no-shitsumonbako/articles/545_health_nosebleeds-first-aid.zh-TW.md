# Q. 流鼻血時該仰頭嗎？該塞衛生紙嗎？正確的止血方法｜Japan Questions #545

- Shelf: `health` ／ URL: `/zh-tw/health/nosebleeds-first-aid` ／ Status: **草稿 — 出處未核實**

孩子流鼻血，或是乾燥的冬天早晨突然流鼻血。「把頭仰起來」「拍拍後頸」「塞衛生紙」——日本家庭代代相傳的這些作法，其實很多都不被建議。以下整理耳鼻喉科醫師建議的方法，以及什麼時候該就醫。

## A. 正確的方法是：坐下，身體稍微前傾，用拇指與食指從兩側牢牢捏住鼻子柔軟的部分（鼻骨以下），持續按壓 10～15 分鐘。仰頭會讓血流進喉嚨，吞下去會引起噁心。塞衛生紙在取出時容易再次出血，拍後頸則完全沒有作用。十次流鼻血有九次來自鼻腔入口附近（利特爾氏區／Kiesselbach 區），用這個方法就能止住。按壓 20～30 分鐘仍止不住、出血量大、頻繁反覆、正在服用抗凝血藥物、受傷後出血——這些情況請前往耳鼻咽喉科（耳鼻咽喉科，即耳鼻喉科）或急診。

## 止血步驟

| 步驟 | 怎麼做 | 為什麼 |
|---|---|---|
| **1. 坐下** | **坐著，身體稍微前傾**。不要躺下，也不要仰頭 | 不讓血流進喉嚨。吞下去會引起噁心、嘔吐 |
| **2. 捏住** | **用拇指與食指從兩側牢牢捏住鼻子柔軟的部分（鼻骨以下）** | 直接壓迫**利特爾氏區（Kiesselbach 區）**（鼻孔內 1～2 公分），九成出血點都在這裡 |
| **3. 持續按壓** | **10～15 分鐘，中途不要放手查看** | 放手會破壞正在形成的血塊 |
| **4. 冰敷** | 用冷毛巾敷鼻根與額頭（輔助） | 收縮血管 |
| **5. 用嘴呼吸** | 用嘴平靜地呼吸。流到口中的血請吐出來 | — |
| **6. 止住之後** | **數小時內不要擤鼻、揉鼻，不要用力憋氣，避免泡熱水澡** | 防止再次出血 |

## 不該做的事

| 作法 | 問題 |
|---|---|
| **仰頭或躺下** | 血流進喉嚨並**被吞下，引起噁心、嘔吐**。也無法掌握出血量 |
| **塞衛生紙** | **取出時把血痂扯掉，出血重新開始**。還會留下纖維。若非填塞不可，請用**乾淨的紗布，淺淺地放**——但捏鼻更好 |
| **拍打或冰敷後頸** | **對止血完全沒有作用** |
| **按壓鼻子堅硬的部分（鼻骨）** | 壓不到出血點 |
| **按幾分鐘就放手查看** | 破壞正在形成的血塊 |

## 什麼時候該就醫

- **捏住 20～30 分鐘仍在出血**，或**出血量大**（超過半杯、頭暈、臉色蒼白）→ **急診**。
- **每週數次**、**反覆只在單側出血**（可能有腫瘤或結構問題）、**其他部位也容易出血（牙齦、皮下）** → **耳鼻咽喉科或內科（内科）**。
- **正在服用抗血小板藥或抗凝血藥（血液稀釋藥）**、**血壓高且臉部發紅發熱** → 更難止血。請及早就醫。
- **臉部受撞擊後流鼻血**（可能骨折）、**頭部受撞擊後流鼻血**（若混有透明的液體，屬於急症）。
- **可能把異物塞進鼻子的孩子**（只有單側，分泌物有臭味）。

## 預防

- **冬季乾燥**：**室內濕度 40～60%**，**用棉花棒在鼻孔入口薄薄塗一層凡士林**（睡前）。**摳鼻子與用力擤鼻**是最大的誘因（兒童幾乎都是這個原因）。
- **過敏性鼻炎**：發癢 → 搓揉 → 出血。**先用鼻噴劑或口服藥控制發炎**，比止血更優先。
- **臉部潮紅**：**剛泡完熱水澡、劇烈運動後與喝酒後**更容易出血。
- **經常流鼻血的孩子**：耳鼻咽喉科可以**對出血點做燒灼（電燒或化學燒灼）**。

> **[待核實]** 利特爾氏區（Kiesselbach 區）出血所占比例與按壓時間的參考值，屬於耳鼻喉科的標準指導。請對照日本耳鼻咽喉科頭頸部外科學會的資料核實。

## 誤解1｜仰起頭，血就不會滴下來

**血會流進喉嚨被吞下去，引起噁心。** 請坐下並稍微前傾。

## 誤解2｜塞衛生紙是最好的方法

**取出時會重新出血，還會留下纖維。** 捏住鼻子柔軟的部分 10～15 分鐘更可靠。

## 誤解3｜拍拍後頸就會止住

**這對出血完全沒有作用。** 是流傳已久的民間說法。

## 誤解4｜常流鼻血是貧血或白血病的徵兆

**兒童頻繁流鼻血，多半是乾燥、摳鼻與過敏造成的。** 但若其他部位也容易出血，或瘀青變多，請做血液檢查。

## 誤解5｜止住以後就可以照常擤鼻子

**數小時內血痂還很脆弱，擤鼻、揉鼻或泡熱水澡都會讓出血重新開始。** 當天請讓鼻子好好休息。
