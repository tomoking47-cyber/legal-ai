# Q. 生理痛、温めると楽になるのは本当？市販薬の使い方と受診の目安｜世界の質問箱 #546

- 棚：`health` ／ URL：`/questions/period-pain-self-care` ／ ステータス：**ドラフト（法務レビュー前・出典未検証）**

生理痛（月経困難症）は日本の女性の約7割が経験し、2〜3割は日常生活に支障が出るほどとされています。「我慢するもの」という考えがまだ根強く、温める・薬を飲むといった対処が遅れがちです。根拠のある対処法と、婦人科を受診する目安を整理します。

## A. 温めることには根拠があります。下腹部や腰を温めると子宮周囲の血流が改善し、痛みの原因物質（プロスタグランジン）による収縮がやわらぐことが示されています。市販の鎮痛薬（イブプロフェン、ロキソプロフェンなどNSAIDs）はプロスタグランジンの産生を抑えるため、「痛くなり始めたらすぐ」飲むのが効かせ方の基本で、我慢してからでは効きにくい。それでも寝込む、鎮痛薬が効かない、経血量が多い（夜用ナプキンが1〜2時間でいっぱい）、生理以外の時も痛む——こうした場合は子宮内膜症などの可能性があり、婦人科へ。低用量ピルや黄体ホルモン製剤は保険適用の治療で、痛みを大きく減らせます。

## 対処法と根拠

| 対処 | 内容 | 根拠の程度 |
|---|---|---|
| **温める** | **下腹部・腰にカイロ、湯たんぽ、腹巻き**、**38〜40℃の入浴**。海外の研究で**温熱パッチは鎮痛薬と同程度の効果**を示した報告 | 中〜高 |
| **鎮痛薬（NSAIDs）** | イブプロフェン、ロキソプロフェン、ナプロキセンなど。**痛み始めにすぐ**、または**毎月同じタイミングなら予測して直前に**。**プロスタグランジンの産生を抑える**ため、産生されてからでは効きにくい | 高 |
| **アセトアミノフェン** | 胃に優しいが、生理痛には**NSAIDsの方が効く**ことが多い | 中 |
| **運動・ストレッチ** | **軽い有酸素運動・ヨガ**で痛みが軽減する報告 | 中 |
| **食事** | **カフェイン・アルコール・冷たい飲み物を控える**、**鉄・マグネシウム・オメガ3**は補助的 | 低〜中 |
| **睡眠・ストレス** | 寝不足・ストレスで痛みが強く感じられる | 中 |
| **漢方** | 当帰芍薬散、加味逍遙散などが保険で処方されることがある | 中 |
| **低用量ピル（LEP）・黄体ホルモン製剤** | **保険適用**。排卵を抑え、内膜を薄くして**痛みと経血量を大きく減らす**。子宮内膜症の進行を抑える | 高 |
| **ミレーナ（子宮内黄体ホルモン放出システム）** | 保険適用、5年有効 | 高 |

## 婦人科を受診する目安

| サイン | 疑われること |
|---|---|
| **鎮痛薬を飲んでも寝込む、学校・仕事を休む** | 月経困難症として治療対象 |
| **年々痛みが強くなる** | **子宮内膜症**（20〜30代で増加、放置で不妊や卵巣の腫れ） |
| **生理以外の時も下腹部が痛い、排便痛・性交痛** | 子宮内膜症 |
| **経血量が多い（夜用ナプキンが1〜2時間でいっぱい、レバー状の塊が多い）、貧血** | **子宮筋腫、子宮腺筋症** |
| **周期が不規則、3か月以上来ない** | ホルモンの異常 |
| **40歳以降に急に痛み・量が変わった** | 筋腫、腺筋症、その他 |

- **市販薬の飲み方**：**痛み始めの早い段階で1回分**。**空腹時を避ける**（胃への負担）。**1日の上限回数**を守る。**月10日以上飲む状態が続くなら受診**。
- **「薬を飲むと効かなくなる」は誤解**：鎮痛薬に耐性はほぼ生じません。我慢する方が生活の質を下げます。
- **温める道具**：**貼るカイロを下着の上から下腹部と腰**（直接肌に貼らない・低温やけど注意）、**腹巻き**、**湯たんぽ**。**冷え**は痛みを強める方向なので、夏の冷房でも下腹部を冷やさない。
- **10代**：初経から数年は痛みが強い人が多く、**中学生・高校生でも婦人科受診は普通**。**低用量ピルは10代でも処方可能**。学校を休むほどなら親と一緒に受診を。
- **仕事と生理**：**労働基準法に生理休暇（68条）**があり、請求できる（無給の会社が多い）。
- **PMS（月経前症候群）**：生理前のイライラ・むくみ・頭痛は別の問題で、こちらも婦人科で相談できます。

> **【要検証】** 生理痛の経験率・支障の割合、温熱パッチの効果に関する研究は日本産科婦人科学会・関連研究で確認してください。低用量ピル等の保険適用範囲は最新の制度で確認を。

## 誤解1｜生理痛は我慢するもの

**寝込むほどの痛みは治療対象（月経困難症）で、保険で治療できます。** 我慢は美徳ではなく、子宮内膜症の発見を遅らせることもあります。

## 誤解2｜鎮痛薬は痛みが強くなってから飲む

**痛みの原因物質が作られる前に飲む方が効きます。** 痛み始めにすぐ、または予測して直前に。

## 誤解3｜鎮痛薬を毎月飲むと効かなくなる・体に悪い

**用量を守れば耐性はほぼ生じません。** ただし月10日以上必要なら根本の治療を婦人科で。

## 誤解4｜温めるのは気分の問題

**温熱で痛みが軽減することは研究でも示されています。** カイロ・腹巻き・入浴は根拠のある対処です。

## 誤解5｜ピルは避妊のための薬で、生理痛の治療には使わない

**低用量ピル（LEP製剤）は月経困難症・子宮内膜症の治療薬として保険適用**されています。10代でも処方できます。
