# Q. 生理痛：温暖真的有用吗？市售止痛药，以及何时该看妇科｜Japan Questions #546

- Shelf: `health` ／ URL: `/zh-cn/health/period-pain-self-care` ／ Status: **草稿 — 出处未核实**

一般认为，日本约有 70% 的女性经历过生理痛（月经困难症），其中 20–30% 严重到影响日常生活。「生理痛是要忍的」这种想法在日本仍然根深蒂固，因此温暖身体、服用止痛药这类简单的应对往往被拖延。以下整理有根据的应对方法，以及该去看妇科（婦人科，fujinka）的信号。

## A. 温暖是有根据的。温暖下腹部和腰部可以改善子宫周围的血流，已有研究显示这能缓解致痛物质（前列腺素）引起的收缩。市售止痛药（布洛芬、洛索洛芬等 NSAIDs）抑制的是前列腺素的生成，所以服用的原则是「一开始痛就吃」；忍过之后再吃，效果会变差。如果仍然卧床不起、止痛药无效、经血量多（夜用卫生巾一小时就满）、或者非经期也疼痛——这些情况可能是子宫内膜症等疾病，请去看妇科。低剂量避孕药和黄体激素制剂在日本属于医保适用的治疗，可以大幅减轻疼痛。

## 应对方法及其依据

| 方法 | 内容 | 证据强度 |
|---|---|---|
| **温暖** | 在下腹部和腰部使用**暖宝宝（使い捨てカイロ，一次性暖贴）、热水袋或腹卷（haramaki）**；**38–40°C（100–104°F）的泡澡**。海外研究报告称**发热贴的效果可与止痛药相当** | 中至高 |
| **止痛药（NSAIDs）** | 布洛芬、洛索洛芬、萘普生等。**一开始痛就服用**，或者**如果每月固定时间发作，可预判并提前服用一次**。它们**抑制前列腺素的生成**，因此在生成之后再吃效果会变差 | 高 |
| **对乙酰氨基酚（扑热息痛）** | 对胃较温和，但对生理痛而言**通常 NSAIDs 效果更好** | 中 |
| **运动与伸展** | **轻度有氧运动和瑜伽**有报告称可缓解疼痛 | 中 |
| **饮食** | **减少咖啡因、酒精和冷饮**；**铁、镁和 omega-3** 属于辅助 | 低至中 |
| **睡眠与压力** | 睡眠不足和压力会让疼痛感觉更强 | 中 |
| **汉方（传统草药）** | 当归芍药散、加味逍遥散等有时可在医保范围内开具 | 中 |
| **低剂量避孕药（LEP）与黄体激素制剂** | **医保适用**。抑制排卵、使内膜变薄，**大幅减少疼痛与出血量**。可延缓子宫内膜症的进展 | 高 |
| **曼月乐（子宫内黄体激素释放系统）** | 医保适用，有效期 5 年 | 高 |

## 该看妇科的信号

| 信号 | 可能提示 |
|---|---|
| **吃了止痛药仍然卧床不起；无法上学或上班** | 达到需要就医程度的月经困难症 |
| **疼痛逐年加重** | **子宫内膜症**（20–30 多岁人群中增加；放任不管可能导致不孕和卵巢肿大） |
| **非经期也有下腹痛；排便时或性行为时疼痛** | 子宫内膜症 |
| **出血量多（夜用卫生巾 1–2 小时就满，有很多像肝块一样的血块）、贫血** | **子宫肌瘤、子宫腺肌症** |
| **周期不规律；停经 3 个月以上** | 激素方面的问题 |
| **40 岁以后疼痛或出血突然变化** | 肌瘤、腺肌症等 |

- **服用市售止痛药**：**在疼痛刚开始时尽早服一次**。**不要空腹服用**（伤胃）。遵守**每日最大剂量**。**如果每月需要服用 10 天以上，请就医。**
- **「吃了就会不管用」是误解**：止痛药几乎不会产生耐受性。忍着疼痛反而会降低生活质量。
- **保暖用品**：**在内衣外侧的下腹部和腰部贴暖宝宝（カイロ）**（切勿直接贴在皮肤上——有低温烫伤的风险）、**腹卷（haramaki）**、**热水袋**。**受凉**会让疼痛往坏的方向走，所以即使在夏天开空调的环境里也要保持下腹部温暖。
- **青少年**：初潮后的最初几年疼痛往往较强，**初中生和高中生去看妇科是很正常的事**。**低剂量避孕药也可以开给青少年。** 如果因此无法上学，请与家长同行。
- **工作与生理期**：**《劳动基准法》规定了生理假（第 68 条）**，可以申请（在多数公司为无薪）。
- **PMS（经前综合征）**：经期前的烦躁、浮肿和头痛是另一个问题，也可以向妇科咨询。

> **[待核实]** 请对照日本妇产科学会及相关研究，核对经历生理痛的女性比例、日常生活受影响的比例，以及关于发热贴的研究。请核对低剂量避孕药等目前的医保适用范围。

## 误解1｜生理痛是要忍的

**痛到卧床不起就属于月经困难症，可以在医保范围内处理。** 忍耐不是美德，还可能延误子宫内膜症的发现。

## 误解2｜等痛得厉害了再吃止痛药

**在致痛物质生成之前服用效果更好。** 一开始痛就吃，或者预判并提前服一次。

## 误解3｜每月都吃止痛药会失效，或者对身体有害

**在正确剂量下几乎不会产生耐受性。** 但如果每月需要服用 10 天以上，请就妇科咨询背后的原因。

## 误解4｜温暖只是让人舒服而已

**已有研究显示温热可以缓解疼痛。** 暖宝宝、腹卷和泡澡都是有依据的方法。

## 误解5｜避孕药是用来避孕的，不是治生理痛的

**低剂量避孕药（LEP 制剂）针对月经困难症和子宫内膜症属于医保适用。** 也可以开给青少年。
