# Q. 生理痛：熱敷真的有用嗎？市售止痛藥，以及何時該看婦產科｜Japan Questions #546

- Shelf: `health` ／ URL: `/zh-tw/health/period-pain-self-care` ／ Status: **草稿 — 出處未核實**

一般認為，日本約有 70% 的女性經歷過生理痛（月經困難症），其中 20–30% 嚴重到影響日常生活。「生理痛是要忍的」這種想法在日本仍然根深蒂固，因此熱敷、服用止痛藥這類簡單的處理往往被拖延。以下整理有根據的處理方法，以及該去看婦產科（婦人科，fujinka）的訊號。

## A. 熱敷是有根據的。溫熱下腹部與腰部可以改善子宮周圍的血流，已有研究顯示這能緩解致痛物質（前列腺素）引起的收縮。市售止痛藥（布洛芬、洛索洛芬等 NSAIDs）抑制的是前列腺素的生成，所以服用的原則是「一開始痛就吃」；忍過之後再吃，效果會變差。如果仍然臥床不起、止痛藥無效、經血量多（夜用衛生棉一小時就滿）、或者非經期也會痛——這些情況可能是子宮內膜異位症等疾病，請去看婦產科。低劑量避孕藥與黃體素製劑在日本屬於健保給付的治療，可以大幅減輕疼痛。

## 處理方法及其依據

| 方法 | 內容 | 證據強度 |
|---|---|---|
| **熱敷** | 在下腹部與腰部使用**暖暖包（使い捨てカイロ，拋棄式暖暖包）、熱水袋或腹卷（haramaki）**；**38–40°C（100–104°F）的泡澡**。海外研究報告指出**發熱貼布的效果可與止痛藥相當** | 中至高 |
| **止痛藥（NSAIDs）** | 布洛芬、洛索洛芬、萘普生等。**一開始痛就服用**，或者**如果每月固定時間發作，可預判並提前服用一次**。它們**抑制前列腺素的生成**，因此在生成之後再吃效果會變差 | 高 |
| **乙醯胺酚（普拿疼類）** | 對胃較溫和，但對生理痛而言**通常 NSAIDs 效果更好** | 中 |
| **運動與伸展** | **輕度有氧運動與瑜伽**有報告指出可緩解疼痛 | 中 |
| **飲食** | **減少咖啡因、酒精與冷飲**；**鐵、鎂與 omega-3** 屬於輔助 | 低至中 |
| **睡眠與壓力** | 睡眠不足與壓力會讓疼痛感覺更強 | 中 |
| **漢方（傳統草藥）** | 當歸芍藥散、加味逍遙散等有時可在健保範圍內開立 | 中 |
| **低劑量避孕藥（LEP）與黃體素製劑** | **健保給付**。抑制排卵、使內膜變薄，**大幅減少疼痛與出血量**。可延緩子宮內膜異位症的進展 | 高 |
| **蜜蕊娜（子宮內黃體素釋放系統）** | 健保給付，有效期 5 年 | 高 |

## 該看婦產科的訊號

| 訊號 | 可能代表 |
|---|---|
| **吃了止痛藥仍然臥床不起；無法上學或上班** | 達到需要就醫程度的月經困難症 |
| **疼痛逐年加重** | **子宮內膜異位症**（20–30 多歲族群中增加；放著不管可能導致不孕與卵巢腫大） |
| **非經期也有下腹痛；排便時或性行為時疼痛** | 子宮內膜異位症 |
| **出血量多（夜用衛生棉 1–2 小時就滿，有很多像肝塊一樣的血塊）、貧血** | **子宮肌瘤、子宮腺肌症** |
| **週期不規律；停經 3 個月以上** | 荷爾蒙方面的問題 |
| **40 歲以後疼痛或出血突然改變** | 肌瘤、腺肌症等 |

- **服用市售止痛藥**：**在疼痛剛開始時盡早服一次**。**不要空腹服用**（傷胃）。遵守**每日最大劑量**。**如果每月需要服用 10 天以上，請就醫。**
- **「吃了就會沒效」是誤解**：止痛藥幾乎不會產生耐受性。忍著疼痛反而會降低生活品質。
- **保暖用品**：**在內衣外側的下腹部與腰部貼暖暖包（カイロ）**（切勿直接貼在皮膚上——有低溫燙傷的風險）、**腹卷（haramaki）**、**熱水袋**。**受寒**會讓疼痛往壞的方向走，所以即使在夏天開冷氣的環境裡也要保持下腹部溫暖。
- **青少年**：初經後的最初幾年疼痛往往較強，**國中生與高中生去看婦產科是很正常的事**。**低劑量避孕藥也可以開給青少年。** 如果因此無法上學，請與家長同行。
- **工作與生理期**：**《勞動基準法》規定了生理假（第 68 條）**，可以申請（在多數公司為無薪）。
- **PMS（經前症候群）**：經期前的煩躁、水腫與頭痛是另一個問題，也可以向婦產科諮詢。

> **[待核實]** 請對照日本婦產科學會及相關研究，核對經歷生理痛的女性比例、日常生活受影響的比例，以及關於發熱貼布的研究。請核對低劑量避孕藥等目前的健保給付範圍。

## 誤解1｜生理痛是要忍的

**痛到臥床不起就屬於月經困難症，可以在健保範圍內處理。** 忍耐不是美德，還可能延誤子宮內膜異位症的發現。

## 誤解2｜等痛得厲害了再吃止痛藥

**在致痛物質生成之前服用效果更好。** 一開始痛就吃，或者預判並提前服一次。

## 誤解3｜每月都吃止痛藥會沒效，或者對身體有害

**在正確劑量下幾乎不會產生耐受性。** 但如果每月需要服用 10 天以上，請就婦產科諮詢背後的原因。

## 誤解4｜熱敷只是讓人舒服而已

**已有研究顯示溫熱可以緩解疼痛。** 暖暖包、腹卷與泡澡都是有依據的方法。

## 誤解5｜避孕藥是用來避孕的，不是處理生理痛的

**低劑量避孕藥（LEP 製劑）針對月經困難症與子宮內膜異位症屬於健保給付。** 也可以開給青少年。
