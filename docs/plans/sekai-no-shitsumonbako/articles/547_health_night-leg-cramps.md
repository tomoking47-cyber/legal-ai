# Q. 夜中に足がつる（こむら返り）、予防法はある？｜世界の質問箱 #547

- 棚：`health` ／ URL：`/questions/night-leg-cramps` ／ ステータス：**ドラフト（法務レビュー前・出典未検証）**

寝ている時にふくらはぎが激しく痛んで目が覚める「こむら返り」。中高年の半数以上が経験し、妊婦や運動後の人にもよく起きます。「水分不足」「ミネラル不足」「冷え」など原因はいろいろ言われますが、はっきりしない部分も多い症状です。分かっていることと、その場の対処を整理します。

## A. こむら返りは、ふくらはぎの筋肉が意思に反して強く収縮した状態です。その場の対処は「つった筋肉をゆっくり伸ばす」——足の指を手前（すね側）に引き、膝を伸ばして20〜30秒保つ。予防で根拠がある程度あるのは、①寝る前のふくらはぎとふとももの裏のストレッチ、②日中の脱水を避ける（アルコール・利尿薬の影響も）、③足を冷やさない（レッグウォーマー、湯たんぽ）、④重い布団で足先が伸びきる姿勢を避ける。週に何度も起きる、日中も起きる、むくみやしびれを伴う、薬を飲み始めてから増えた——こうした場合は内科で、腰の病気・血管・甲状腺・薬の副作用などを確かめてもらいます。漢方の芍薬甘草湯は即効性があるとして処方されることが多いですが、連用には注意が必要です。

## その場の対処

| 手順 | 内容 |
|---|---|
| **1. 伸ばす** | **膝を伸ばし、足の指をすね側に引く**（手で引く、または壁に足の裏を押し付ける）。**20〜30秒**、ゆっくり |
| **2. 立つ** | 可能なら**立って、つった足に体重をかける**（アキレス腱を伸ばす） |
| **3. 温める・もむ** | 収縮が治まってから**軽くもむ、温める**。強くもむと筋肉を傷めることがある |
| **4. その後** | **翌日まで筋肉痛が残る**ことがある。ひどければ冷やす→翌日温める |

## 原因として挙げられるものと対策

| 要因 | 内容 | 対策 |
|---|---|---|
| **筋肉の疲労** | 日中の立ち仕事・運動、運動不足による筋力低下 | **寝る前のストレッチ**（ふくらはぎ・太もも裏を各30秒×2〜3回）。**週数回の軽い運動** |
| **脱水・電解質** | 汗、飲酒、利尿薬、下痢。**マグネシウム・カリウム・カルシウム**の不足が関係する可能性（**根拠は限定的**） | **日中に水分**、**夜の飲酒を控える**、バランスの取れた食事（**サプリの効果は研究で一致していない**） |
| **冷え** | 夜間の足の冷えで筋肉が緊張 | **レッグウォーマー・靴下**、**湯たんぽ**、**入浴で温めてから寝る** |
| **寝る姿勢** | **足先が布団の重みで伸びきる（底屈）**とふくらはぎが収縮しやすい | **軽い布団**、**足元に隙間**、**横向き** |
| **妊娠** | 後期に多い（**約3〜5割**が経験）。血流・ミネラルの変化 | ストレッチ、温める、産科に相談（マグネシウム製剤を処方されることも） |
| **薬** | **利尿薬、スタチン（脂質の薬）、一部の喘息薬**などで増えることがある | **飲み始めてから増えたなら処方医に相談**（自己判断で中止しない） |
| **病気** | **腰部脊柱管狭窄症・椎間板ヘルニア**（しびれを伴う）、**下肢静脈瘤・閉塞性動脈硬化症**（むくみ・歩くと痛い）、**糖尿病、甲状腺・腎臓・肝臓の病気** | **頻繫（週に数回以上）、日中も起きる、しびれ・むくみ・歩行時の痛みを伴う**なら内科・整形外科へ |

- **漢方・芍薬甘草湯**：**発作時に飲むと数分で効く**とされ、整形外科・内科でよく処方される。ただし**甘草を含み、連用で低カリウム血症・むくみ・血圧上昇（偽アルドステロン症）**の副作用があるため、**毎日の予防的な連用は避け、頓服**が原則。高齢者は特に注意。
- **マグネシウム**：妊婦以外では**効果を示す研究と示さない研究が混在**。**海藻・ナッツ・豆・玄米**など食事からで十分。サプリは腎機能が低下している人は避ける。
- **寝る前のストレッチのやり方**：**壁に手をつき、片足を後ろに引いてかかとを床に付け、ふくらはぎを30秒伸ばす**。**座って足を伸ばし、タオルを足の裏にかけて手前に引く**。左右各2〜3回。**就寝直前に行う**と夜間の発生が減ったという報告があります。
- **年齢**：**60歳以上の約半数**が月に1回以上経験。加齢で筋肉量・腱の柔軟性が落ちるため、**ストレッチと軽い筋トレ**が予防の中心になります。

> **【要検証】** 高齢者・妊婦の経験率、芍薬甘草湯の副作用の記述は関連学会・添付文書で確認してください。マグネシウムの効果に関する研究状況は最新のレビューで確認を。

## 誤解1｜つったら強くもんで治す

**収縮中に強くもむと筋肉を傷めることがあります。** まず「ゆっくり伸ばす」、治まってから軽くもむ・温める。

## 誤解2｜水を飲めば予防できる

**脱水は一因ですが、それだけではありません。** 寝る直前に大量に飲むと夜間のトイレが増えるだけ。日中の水分と、ストレッチ・冷え対策をセットで。

## 誤解3｜マグネシウムのサプリで防げる

**研究結果は一致しておらず、妊婦以外での効果は限定的**です。食事からで十分、腎機能が低下している人は避ける。

## 誤解4｜芍薬甘草湯を毎晩飲んでおけば安心

**甘草の副作用（低カリウム、むくみ、血圧上昇）があり、連用は避けるべき薬**です。発作時の頓服が原則。

## 誤解5｜年のせいだから仕方ない

**週に何度も起きる、日中も起きる、しびれ・むくみを伴うなら、腰・血管・代謝の病気や薬の副作用が背景にあることがあります。** 一度は内科で相談を。
