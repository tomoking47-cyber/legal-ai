# Q. 歯が痛くなくても歯医者に行くべき？定期健診の頻度と中身｜世界の質問箱 #550

- 棚：`health` ／ URL：`/questions/regular-dental-checkups` ／ ステータス：**ドラフト（法務レビュー前・出典未検証）**

日本では「歯医者は痛くなってから行く場所」という人がまだ多く、定期的に歯科健診を受ける人は成人の半数程度です。一方、スウェーデンなど定期健診が定着した国では80歳で残る歯の数が日本より多いことが知られています。定期健診で何をするのか、頻度と費用を整理します。

## A. 痛みがなくても、3〜6か月に1回の定期健診を受けるのが、歯を長く残すためにもっとも費用対効果の高い方法です。虫歯も歯周病も初期は無症状で、痛みが出た時にはかなり進んでいます。健診の中身は、①虫歯・歯周病のチェック（歯周ポケットの深さを測る）、②歯石除去とクリーニング（自分では取れない）、③磨き残しの指導、④必要に応じてレントゲン・フッ素塗布。保険適用で1回3,000〜4,000円程度（3割負担）。80歳で20本以上の歯を残す人は日本でも5割を超えるようになりましたが、定期健診を受けている人とそうでない人で差が大きいことが分かっています。

## 定期健診の中身と頻度

| 項目 | 内容 | 頻度の目安 |
|---|---|---|
| **虫歯のチェック** | 視診、必要ならレントゲン（初期の虫歯・歯と歯の間は見えない） | 健診ごと。レントゲンは**1〜2年に1回**程度 |
| **歯周病のチェック** | **歯周ポケットの深さ**を測る（**3mm以下が健康、4mm以上で歯周病**）、出血、歯のぐらつき | 健診ごと |
| **歯石除去（スケーリング）** | 歯ブラシでは取れない**歯石（プラークが石灰化したもの）**を器具で除去。**歯石は2週間程度で形成が始まる** | **3〜6か月に1回** |
| **クリーニング（PMTC）** | 専門的な機械清掃、着色除去 | 同上 |
| **ブラッシング指導** | 磨き残しの染め出し、自分に合った道具（歯間ブラシのサイズ、フロス） | 健診ごと |
| **フッ素塗布** | 高濃度フッ素で歯質を強化。**子どもは3〜6か月ごと**、大人も虫歯リスクが高ければ | 子ども中心 |
| **口腔がんのチェック** | 粘膜の視診 | 健診ごと（気づかれにくい効果） |

## 数字で見る歯の健康

| 項目 | 数値 |
|---|---|
| **80歳で20本以上の歯が残る人（8020達成者）** | **51.6%**（2022年 歯科疾患実態調査）。1989年の運動開始時は**約7%** |
| **定期健診受診率** | 過去1年に歯科健診を受けた成人は**約58%**（2022年）。年代・地域差が大きい |
| **歯を失う原因** | **歯周病 約37%、虫歯 約29%、破折 約18%**（8020推進財団調査） |
| **歯周病の有病** | **成人の約半数**に4mm以上の歯周ポケット。**45歳以上では過半数** |
| **費用** | 定期健診（歯周基本検査＋歯石除去）**3割負担で1回3,000〜4,000円**程度。**虫歯1本の治療（詰め物）で3,000〜10,000円、抜歯後のインプラントは自費で30〜50万円** |
| **国の方向** | 2022年、政府が「**国民皆歯科健診**」の検討を打ち出し、**2024年度（令和6年度）から歯周疾患検診の対象年齢に20歳・30歳が追加されました**（20・30・40・50・60・70歳） |

- **なぜ痛くなる前が重要か**：**初期の虫歯（エナメル質まで）は再石灰化で進行を止められる**ことがあり、削らずに済む。**歯周病は痛みがほぼなく進行**し、**歯がぐらつく段階では手遅れ**が多い。**歯周病は糖尿病・心血管疾患・誤嚥性肺炎・早産との関連**も報告されている。
- **健診の間隔**：**3か月**（歯周病がある、磨き残しが多い、喫煙）、**6か月**（安定している）、**1年**（最低限）。**歯科医が個別に提案**するので従うのが基本。
- **子ども**：**1歳半・3歳の自治体健診**、**学校歯科健診**に加え、**かかりつけ歯科で3〜6か月ごとのフッ素塗布と健診**。**乳歯の虫歯は永久歯にも影響**。
- **妊娠中**：ホルモンの影響で歯肉炎が起きやすく、**多くの自治体で妊婦歯科健診が無料**。安定期に受ける。
- **自治体の健診**：**歯周疾患検診**（健康増進法、自治体により無料〜数百円）。従来の**40・50・60・70歳**に加え、**20歳・30歳**も対象に拡大されました。案内が来たら受ける。**企業の健保に歯科健診の補助**がある場合も。
- **かかりつけ歯科の選び方**：**予防・メンテナンスに力を入れている**、**歯科衛生士が在籍**、**歯周ポケットを測って説明してくれる**、**レントゲンや写真で状態を見せてくれる**。

> **【要検証】** 8020達成者率、健診受診率、歯を失う原因の割合は厚生労働省「歯科疾患実態調査（2022年）」と8020推進財団の最新調査で確認してください。国民皆歯科健診の制度動向は最新の情報に更新を。

## 誤解1｜痛くないなら歯医者に行く必要はない

**虫歯も歯周病も初期は無症状で、痛みが出た時にはかなり進んでいます。** 3〜6か月の健診が結局いちばん安く済みます。

## 誤解2｜毎日しっかり磨いているから歯石は付かない

**歯石は磨き残しが2週間ほどで石灰化したもので、歯ブラシでは取れません。** 誰でも付くため、定期的な除去が必要。

## 誤解3｜歯周病は年寄りの病気

**30代からすでに歯周ポケットのある人がいて、45歳以上では過半数に達します。進行は静かです。** 若いうちからの健診で差が出ます。

## 誤解4｜歯を失うのは虫歯のせい

**最大の原因は歯周病（約37%）**です。痛みがなく進むため、健診での早期発見が要になります。

## 誤解5｜定期健診は高い

**3割負担で1回3,000〜4,000円、年2回でも1万円弱**。虫歯1本の治療や、歯を失った後のインプラント（自費30〜50万円）と比べれば、明確に安い投資です。
