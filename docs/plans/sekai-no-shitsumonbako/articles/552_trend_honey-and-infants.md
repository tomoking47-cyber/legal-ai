# Q. はちみつは1歳未満の赤ちゃんにあげてはいけないって本当？｜世界の質問箱 #552

- 棚：`trend` ／ URL：`/questions/honey-and-infants` ／ ステータス：**ドラフト（法務レビュー前・出典未検証）**

離乳食の甘みに、風邪の時に——はちみつは自然食品のイメージが強く、「少しなら」と考える人がいます。しかし日本では2017年に、はちみつを与えられた生後6か月の乳児が乳児ボツリヌス症で亡くなる事故があり、国が改めて注意喚起をしました。理由と範囲を整理します。

## A. はちみつは1歳未満の乳児には、量の多少・加熱の有無・国産か輸入かにかかわらず与えてはいけません。理由は、はちみつにボツリヌス菌の芽胞が含まれることがあり、腸内環境が未熟な1歳未満の乳児では腸内で菌が増えて毒素を作る「乳児ボツリヌス症」を起こすため。芽胞は家庭の加熱（100℃）では死なないので、「加熱すれば大丈夫」も成り立ちません。はちみつ入りの飲料・菓子・パン、黒糖・きび糖の一部、コーンシロップにも注意。1歳を過ぎれば腸内細菌が整い、通常の摂取で問題は起きないとされています。大人には無害です。

## 知っておくべきこと

| 項目 | 内容 |
|---|---|
| **原因** | **ボツリヌス菌の芽胞**。土壌中に広く存在し、**はちみつに混入することがある**（日本の調査で**約5〜10%のはちみつから検出**の報告） |
| **なぜ乳児だけ** | **1歳未満は腸内細菌が未発達**で、芽胞が腸内で発芽・増殖し**毒素を産生**する。**1歳以上・大人は腸内細菌が菌の増殖を抑える**ため、はちみつで発症することはまずない |
| **加熱** | **芽胞は100℃の加熱では死なない**（120℃・4分以上が必要）。**加熱したはちみつ、はちみつ入りの焼き菓子・パンも不可** |
| **国産・輸入・高級品** | **区別なく不可**。「純粋」「非加熱」「マヌカ」も同じ |
| **症状** | 摂取後**3〜30日**で**便秘（3日以上）→哺乳力の低下→泣き声が弱い・元気がない→首や手足のだらり（筋力低下）→呼吸困難**。**すぐ受診（小児科・救急）** |
| **国内の事例** | **2017年、東京都で生後6か月の乳児が死亡**（離乳食にはちみつ入りジュースを1か月間）。国内で**年間0〜数件**の報告 |
| **法令・表示** | **はちみつ製品には「1歳未満の乳児には与えないでください」の表示**が業界基準で義務化。**食品表示法上の義務ではなく、表示のない輸入品もある** |

## はちみつ以外で注意するもの

| 食品 | 理由 |
|---|---|
| **はちみつ入りの飲料・ヨーグルト・菓子・パン・ハニーローストナッツ** | はちみつを含む |
| **黒糖（黒砂糖）、きび糖の一部** | ボツリヌス菌の芽胞が検出された報告があり、**厚生労働省は1歳未満への黒糖を避けるよう案内** |
| **コーンシロップ** | 海外で芽胞の検出報告 |
| **井戸水・自家製の野菜ジュース（加熱不十分）** | 土壌由来の芽胞 |
| **自家製の瓶詰・真空パック食品** | 大人でもボツリヌス食中毒の原因になり得る（別記事「家庭の瓶詰め」参照） |

- **1歳になったら**：**腸内細菌が整い、通常量のはちみつは問題ない**とされます。**離乳食の甘みは、1歳までは果物・さつまいも・かぼちゃ**などで。
- **メープルシロップ**：樹液を煮詰めたもので、**ボツリヌス菌の心配は基本的にない**とされるが、**糖分が多いため離乳食期は控えめ**に。
- **のどの痛みへのはちみつ**：**1歳以上の子どもの咳に、はちみつが市販の咳止めと同程度の効果**を示した研究があり、海外の小児科ガイドでも紹介されています。**1歳未満は不可**。
- **保育園・祖父母**：「少しだけ」「昔はあげていた」という善意の事故が多い。**「1歳までははちみつ禁止」を家族・預け先で共有**する。
- **大人のボツリヌス食中毒**は別の話（はちみつではなく、**自家製の瓶詰・いずし・真空パックの加熱不十分**が原因）。

> **【要検証】** はちみつからの芽胞検出率、2017年の事例の詳細、黒糖に関する注意喚起は厚生労働省・東京都の公表資料で確認してください。

## 誤解1｜少しだけなら大丈夫

**量の問題ではなく、芽胞が1個でも腸で増える可能性があります。** 1歳未満はゼロで。

## 誤解2｜加熱すればボツリヌス菌は死ぬ

**芽胞は100℃では死にません。** はちみつ入りのパン・焼き菓子・煮物も不可。

## 誤解3｜国産の純粋はちみつなら安全

**産地・品質と芽胞の有無は無関係**です。表示のあるなしにかかわらず与えない。

## 誤解4｜昔はみんなあげていたから問題ない

**乳児ボツリヌス症が知られるようになったのは1970年代以降**で、以前は原因不明の突然死に含まれていた可能性があります。2017年の死亡事故は国内で実際に起きています。

## 誤解5｜1歳を過ぎてもはちみつは危ない

**1歳以上は腸内細菌が整い、通常の摂取で発症することはまずありません。** 1歳を過ぎたら、咳の緩和など有用な使い方もあります。
