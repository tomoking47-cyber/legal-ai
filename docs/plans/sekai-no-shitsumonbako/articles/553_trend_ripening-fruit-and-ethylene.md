# Q. 買ってきた果物、いつ食べる？追熟の見極めと保存のコツ｜世界の質問箱 #553

- 棚：`trend` ／ URL：`/questions/ripening-fruit-and-ethylene` ／ ステータス：**ドラフト（法務レビュー前・出典未検証）**

かたいキウイ、青いバナナ、まだ酸っぱい柿。「もう少し置いた方がいい」と言われる果物と、「買ったらすぐ食べる」果物があります。違いは「追熟するかどうか」で、これを知らないと冷蔵庫でいつまでも硬いままの果物ができます。

## A. 果物は「収穫後に熟す（追熟する）タイプ」と「木の上でしか熟さないタイプ」に分かれます。バナナ・キウイ・アボカド・洋なし・桃・マンゴー・柿は追熟するので、硬ければ常温で待ち、食べごろになったら冷蔵。追熟を早めたいときはリンゴやバナナと同じ袋に入れる（エチレンガスを出す）。一方、いちご・ぶどう・みかん・スイカ・パイナップル・さくらんぼは追熟しないので、買ったときが食べごろ、すぐ冷蔵で早めに食べる。リンゴはエチレンを多く出すため、他の果物・野菜と一緒に保存すると傷めやすい（葉物・キウイの隣は避ける）。

## 追熟する果物・しない果物

| 追熟する（常温で熟す） | 食べごろの見極め | 追熟しない（買ったときが食べごろ） |
|---|---|---|
| **バナナ** | 皮に**茶色い斑点（シュガースポット）** | **いちご** |
| **キウイ** | **軽く押してわずかにへこむ** | **ぶどう** |
| **アボカド** | **皮が黒っぽく、ヘタの周りが少し柔らかい** | **みかん・オレンジ・グレープフルーツ** |
| **洋なし（ラ・フランス）** | **軸の周りを押して柔らかい**、香りが出る | **スイカ・メロン（一部は追熟）** |
| **桃・プラム・すもも** | **香りが強くなり、全体がわずかに柔らかい** | **パイナップル** |
| **マンゴー・パパイヤ** | 香り、皮のつや、軽い弾力 | **さくらんぼ** |
| **柿（渋柿は追熟で甘くなる種類も）** | 全体がオレンジ〜赤、やや柔らかい | **ブルーベリー・ラズベリー** |
| **びわ、いちじく** | 香りと柔らかさ | **りんご**（収穫時に完成。保存で味は落ちる） |

## エチレンを使う・避ける

| 目的 | 方法 |
|---|---|
| **追熟を早める** | **りんご（または熟したバナナ）1個と一緒に紙袋に入れて常温**。**1〜3日**で柔らかくなる。**ビニール袋は密閉し過ぎるとカビ** |
| **追熟を遅らせる** | **冷蔵庫（低温でエチレンの働きが弱まる）**。ただし**バナナは13℃以下で皮が黒くなる**、**アボカドは硬いまま止まる** |
| **他の食品を守る** | **りんご・熟したバナナ・メロン・トマト**はエチレンを多く出す。**葉物野菜（しなびる）、きゅうり（黄変）、キウイ・アボカド（過熟）**の隣に置かない。**じゃがいもは逆に発芽が抑えられる**（別記事参照） |

- **エチレンとは**：果物が自分で出す**植物ホルモンのガス**で、熟成を進める。**傷んだ果物はエチレンを大量に出す**ため、**1個腐ると周りも早く傷む**。傷んだものはすぐ取り除く。
- **バナナ**：**房から1本ずつ離す**、**軸をラップで巻く**、**バナナスタンドで吊る**と黒ずみが遅れる。**食べごろになったら皮ごと冷凍**（スムージー用）も可。
- **アボカド**：**硬いものを買って常温で追熟（2〜5日）**、食べごろで冷蔵（2〜3日もつ）。**切った後は種を付けたままレモン汁を塗ってラップ**。
- **キウイ**：**硬いキウイはりんごと袋に入れて2〜3日**。**熟したキウイは冷蔵で1週間**。
- **桃**：**常温で1〜2日**追熟、**食べる2〜3時間前に冷蔵**（冷やし過ぎると甘みを感じにくい）。**紙で包んで日光を避ける**。
- **柿**：**渋柿はへたに焼酎を付けて袋で1週間**（渋抜き）。甘柿は買ってすぐ食べられる。
- **いちご・ぶどう**：**洗うのは食べる直前**（水分でカビ）、**パックのまま冷蔵、2〜3日以内**。
- **みかん**：**箱買いは底から傷む**ので**箱を開けて風を通し、傷んだものを取り除く**。**冷蔵より風通しの良い常温（5〜10℃）**。

> **【要検証】** 追熟の有無・エチレン産生量の分類は農業・食品科学の一般的な整理に基づきます。農林水産省・果樹研究機関の資料で確認してください。

## 誤解1｜果物は買ったらすぐ冷蔵庫に入れる

**追熟する果物は冷蔵すると熟成が止まり、硬いまま**です。食べごろまで常温、その後冷蔵。

## 誤解2｜いちごやぶどうは置いておけば甘くなる

**追熟しない果物は買ったときが食べごろ**で、置くと傷むだけです。すぐ冷蔵、早めに食べる。

## 誤解3｜りんごは何とでも一緒に保存していい

**りんごはエチレンを多く出し、葉物・きゅうり・キウイを早く傷めます。** 別の場所か袋で。じゃがいもとの同居は逆に有利。

## 誤解4｜バナナは冷蔵庫で長持ちする

**13℃以下で皮が黒くなり（低温障害）、見た目が悪くなります。** 常温で吊るし、熟したら皮ごと冷凍。

## 誤解5｜傷んだ果物は1個くらいそのままでいい

**傷んだ果物はエチレンを大量に出し、周りを一気に傷めます。** 見つけたらすぐ取り除く。
