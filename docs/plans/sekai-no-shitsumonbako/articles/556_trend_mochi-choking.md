# Q. お正月の餅、なぜ毎年事故が起きる？高齢者と子どもの食べ方｜世界の質問箱 #556

- 棚：`trend` ／ URL：`/questions/mochi-choking` ／ ステータス：**ドラフト（法務レビュー前・出典未検証）**

日本では毎年1月、餅による窒息で救急搬送される人が相次ぎ、死亡者も出ます。東京消防庁の管内だけで年間100人前後が搬送され、その9割が65歳以上。「よく噛めば大丈夫」と思われていますが、噛む力・飲み込む力が落ちた人には、餅は最も窒息しやすい食品の一つです。

## A. 餅は「粘りが強く、口の中で塊になり、体温で硬くなる」性質があり、噛む力と飲み込む力が弱い高齢者、噛み切れない乳幼児には窒息の危険が高い食品です。予防は、①小さく切る（1cm角程度）、②一口ずつ、よく噛んで、飲み込んでから次を、③食べる前にお茶や汁で口を潤す、④餅の代わりに白玉やおかゆ状の餅、市販の「やわらか餅」を使う、⑤一人で食べさせない。もし詰まったら、声が出せず苦しがる・顔色が変わる場合はすぐ119番し、背中を強く叩く（背部叩打法）か、腹部を突き上げる（ハイムリック法）。掃除機で吸う方法は推奨されていません。

## 数字で見る餅の事故

| 項目 | 内容 |
|---|---|
| **搬送者数** | 東京消防庁管内で**年間90〜130人前後**が餅による窒息で救急搬送。**うち1月が半数以上、元日〜3日に集中** |
| **年齢** | **約9割が65歳以上**。**80歳代が最多** |
| **死亡** | 全国の**窒息死は年間約3,500〜4,000人**（食物によるもの）、**餅はその中で最も多い食品の一つ**。消費者庁の分析で**餅による死亡は1月に集中し、年間の4割以上が1月** |
| **餅の特性** | **口の中の温度（37℃前後）で硬くなり、粘りが増す**。**唾液で溶けない**。**噛み切れずに丸のまま飲み込みやすい** |
| **子ども** | **3歳未満は餅の生食は避ける**のが一般的。**5歳以下の窒息事故の原因食品はナッツ・ぶどう・ミニトマト・餅** |

## 予防（高齢者・子どもがいる家庭）

| 対策 | 内容 |
|---|---|
| **切る** | **1cm角程度、または薄くスライス**。雑煮の餅も切ってから |
| **一口の量** | **一口ずつ、飲み込んでから次**。**話しながら・笑いながら食べない** |
| **口を潤す** | **食べる前にお茶・汁物**で口とのどを湿らせる。**食べている途中でお茶で流し込むのは逆効果**（餅が動いて詰まる） |
| **姿勢** | **座って、少し前かがみ**。寝ながら・寝起きに食べない |
| **代替** | **白玉団子（小さく）、餅入りおかゆ、市販の「やわらかい餅」「とろける餅」**、**餅の代わりにパン粥・すいとん** |
| **見守り** | **一人で食べさせない**。義歯（入れ歯）の不具合があれば餅は避ける |
| **時間帯** | **朝食・寝起きは飲み込む力が落ちている**。昼以降が無難という助言も |

## 詰まったときの対処

1. **「声が出せるか」確認**：**咳ができる・声が出る**なら、**咳を続けさせる**（自分で出せる可能性）。**背中を叩かない**（動いて完全閉塞することがある）。
2. **声が出ない・顔色が青い・両手でのどをつかむ**（窒息のサイン）：**すぐ119番**（周りの人に頼む）、同時に：
   - **背部叩打法**：**頭を低く前かがみ**にさせ、**肩甲骨の間を手のひらの付け根で強く数回叩く**。
   - **腹部突き上げ法（ハイムリック法）**：後ろから抱え、**へその上に握った拳を当て、斜め上に強く突き上げる**。**妊婦・乳児には行わない**（胸部突き上げ）。
   - 2つを交互に、取れるか意識がなくなるまで繰り返す。
3. **意識がなくなったら**：**心肺蘇生（胸骨圧迫）**を開始。口の中に見える異物は取る（見えないものを指で探らない）。
4. **掃除機での吸引**：消防・医師とも**推奨していない**（口内を傷める、時間を失う）。器具を探す間に上記を行う。
5. **取れた後も受診**：気道の損傷、残留の可能性。

- **乳幼児**：**背部叩打法（うつ伏せにして頭を低く、背中を叩く）と胸部突き上げ法**。**腹部突き上げは内臓を傷めるため乳児には行わない**。
- **義歯**：**合わない入れ歯は噛む力を落とす**。年末に歯科で調整を。
- **餅以外の窒息しやすい食品（高齢者）**：**こんにゃく、ゆで卵、パン、肉、団子、ミニトマト、ぶどう**。同じ対策が有効。

> **【要検証】** 搬送者数・年齢構成は東京消防庁の最新年、窒息死の全国統計は人口動態統計・消費者庁の分析で確認してください。応急手当の手順は日本赤十字社・消防庁の最新ガイドラインで確認を。

## 誤解1｜よく噛めば餅は安全

**噛む力・飲み込む力が落ちた高齢者は「噛んでも塊になる」餅が最も危険**です。切る・少量・見守りがセット。

## 誤解2｜お茶で流し込めば大丈夫

**食べている途中に水分で流し込むと、餅が動いて気道をふさぐことがあります。** 口を潤すのは食べる前。

## 誤解3｜詰まったらまず背中を叩く

**咳ができる・声が出るなら叩かず咳を続けさせる**（叩くと完全閉塞することがある）。**声が出ないなら背部叩打・腹部突き上げと119番**。

## 誤解4｜掃除機で吸えば取れる

**消防・医療は推奨していません。** 器具を探す時間で状態が悪化します。背部叩打と腹部突き上げを。

## 誤解5｜子どもには小さく切れば何歳でもいい

**3歳未満は噛み切る力が不十分で、餅は避けるのが一般的**です。白玉も同じ性質なので注意。
