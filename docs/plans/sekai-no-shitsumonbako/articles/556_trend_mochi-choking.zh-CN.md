# Q. 为什么每年新年都会发生年糕（餅）事故？老人和孩子该怎么吃｜Japan Questions #556

- Shelf: `trend` ／ URL: `/zh-cn/trend/mochi-choking` ／ Status: **草稿 — 出处未核实**

在日本，每年一到一月，就会接连有人因为「餅」(mochi，年糕)噎住而被送医，其中也有人死亡。仅东京消防厅辖区，每年就有约 100 人被救护车送医，其中 90% 是 65 岁以上。很多人以为「好好嚼就没事」，但对于咀嚼与吞咽能力已经变弱的人来说，年糕是最容易造成窒息的食物之一。如果你要和日本家庭一起过年，这些值得先知道。

## A. 年糕黏性极强，在口中会结成一团，还会在体温下变硬，因此对咀嚼与吞咽能力变弱的老年人、以及咬不断它的婴幼儿来说，窒息风险很高。预防方法：①切小（约 1 厘米见方）；②一次一块，充分咀嚼，咽下去之后再吃下一块；③吃之前先用茶或汤把口腔润湿；④改用「白玉」(白玉团子)、粥状年糕或市售的「やわらかい餅」(软年糕)；⑤绝不让人独自一人吃。如果噎住了，当事人发不出声音、表情痛苦或脸色改变时，请立即拨打 119（日本的救护车电话），并用力拍击背部或做腹部冲击（海姆立克急救法）。用吸尘器吸出的做法并不被推荐。

## 数字中的年糕事故

| 项目 | 内容 |
|---|---|
| **救护车出动** | 东京消防厅辖区内，因年糕窒息而被送医者**每年约 90～130 人**。**其中超过一半发生在 1 月，集中于 1 月 1 日～3 日** |
| **年龄** | **约 90% 为 65 岁以上**。**80 多岁者人数最多** |
| **死亡** | 全国因食物造成的**窒息死亡每年约 3,500～4,000 人**，**年糕是其中最常见的食物之一**。消费者厅的分析显示，**因年糕致死集中在 1 月，占全年的 40% 以上** |
| **年糕的性质** | **在口腔温度（约 37℃／99°F）下会变硬、黏性更强**。**唾液无法将其溶解**。**很容易在没有咬断的情况下整块吞下** |
| **儿童** | **一般不给未满 3 岁的孩子吃年糕**。**5 岁以下儿童窒息事故的食物依次是坚果、葡萄、圣女果和年糕** |

## 预防（家中有老人或孩子）

| 措施 | 内容 |
|---|---|
| **切** | **约 1 厘米见方，或切成薄片**。「お雑煮」(新年杂煮汤)里的年糕也要切 |
| **一口的量** | **一次一块，咽下去之后再吃下一块**。**不要边说话、边笑边吃** |
| **润湿口腔** | **吃之前先喝茶或汤**，把口腔和咽喉润湿。**嘴里含着年糕再用茶送下去反而更糟**（年糕会移位堵住气道） |
| **姿势** | **坐直，上身略微前倾**。不要躺着吃，也不要刚睡醒就吃 |
| **替代品** | **「白玉」(白玉团子，切小)、加了年糕的米粥、市售的「やわらかい餅」(软年糕)或「とろける餅」(入口即化年糕)**，**也可用面包粥或「すいとん」(面疙瘩汤)代替年糕** |
| **看护** | **绝不让人独自一人吃**。假牙不合适时避免吃年糕 |
| **时段** | **早餐时和刚睡醒时吞咽能力较弱**。也有建议说中午以后比较安全 |

## 噎住时怎么办

1. **先确认「能出声吗？」**：如果对方**还能咳嗽或说话**，**就让他继续咳**（可能自己咳出来）。**不要拍背**（年糕可能移动，反而完全堵住气道）。
2. **发不出声音、脸色发青、双手掐住喉咙**（窒息的信号）：**立即拨打 119**（请旁边的人帮忙），同时：
   - **背部叩击**：**让对方上身前倾、头低下**，**用掌根用力连续拍击两肩胛骨之间**。
   - **腹部冲击（海姆立克急救法）**：从背后**把拳头放在肚脐上方，向内、向上猛推**。**孕妇和婴儿不可使用**（改用胸部冲击）。
   - 交替进行这两种方法，直到异物排出或对方失去意识。
3. **如果失去意识**：**开始心肺复苏（胸外按压）**。取出口中看得见的东西（看不见的不要用手指去掏）。
4. **吸尘器**：消防部门与医生**均不推荐**（会伤到口腔，还会浪费时间）。请做上述处置，而不是去找器材。
5. **取出之后也要就医**：可能有气道损伤或残留碎片。

- **婴儿**：**背部叩击（脸朝下、头放低，拍背）和胸部冲击**。**婴儿不可做腹部冲击，会损伤内脏**。
- **假牙**：**不合适的假牙会削弱咬合力**。请在年底前到牙科调整。
- **对老年人风险较高的其他食物**：**「こんにゃく」(蒟蒻)、水煮蛋、面包、肉、「団子」(丸子)、圣女果、葡萄**。同样的措施适用。

## 误解1｜好好嚼年糕就安全

**对咀嚼与吞咽能力变弱的老年人来说，年糕正是因为「嚼了也会结成一团」才最危险。** 切小、少量与旁人看护要一起做到。

## 误解2｜用茶送下去就没事

**嘴里含着年糕时用液体往下送，可能让年糕移位并堵住气道。** 要在吃之前润湿口腔，而不是吃到一半时。

## 误解3｜噎住了先拍背

**如果对方还能咳嗽或说话，不要拍，让他继续咳**（拍打可能造成完全堵塞）。**如果发不出声音，就做背部叩击和腹部冲击，并拨打 119**。

## 误解4｜用吸尘器就能吸出来

**消防部门和医疗机构都不推荐。** 找机器所花的时间反而让情况更糟。请改做背部叩击和腹部冲击。

## 误解5｜切小了任何年龄的孩子都能吃

**未满 3 岁的孩子咬不断它，一般做法是不给年糕。** 「白玉」(白玉团子)有同样的性质，也要注意。
