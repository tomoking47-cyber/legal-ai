# Q. 為什麼每年新年都會發生麻糬（餅）事故？長輩與孩子該怎麼吃｜Japan Questions #556

- Shelf: `trend` ／ URL: `/zh-tw/trend/mochi-choking` ／ Status: **草稿 — 出處未核實**

在日本，每年一到一月，就會接連有人因為「餅」(mochi，麻糬)噎住而被送醫，其中也有人死亡。光是東京消防廳轄區，每年就有約 100 人被救護車送醫，其中 90% 是 65 歲以上。很多人以為「好好嚼就沒事」，但對於咀嚼與吞嚥能力已經變弱的人來說，麻糬是最容易造成窒息的食物之一。如果你要和日本家庭一起過年，這些值得先知道。

## A. 麻糬黏性極強，在口中會結成一團，還會在體溫下變硬，因此對咀嚼與吞嚥能力變弱的長輩、以及咬不斷它的嬰幼兒來說，窒息風險很高。預防方法：①切小（約 1 公分見方）；②一次一塊，充分咀嚼，嚥下去之後再吃下一塊；③吃之前先用茶或湯把口腔潤濕；④改用「白玉」(白玉湯圓)、粥狀麻糬或市售的「やわらかい餅」(軟麻糬)；⑤絕不讓人獨自一人吃。如果噎住了，當事人發不出聲音、表情痛苦或臉色改變時，請立刻撥打 119（日本的救護車電話），並用力拍擊背部或做腹部推擠（哈姆立克急救法）。用吸塵器吸出的做法並不被建議。

## 數字中的麻糬事故

| 項目 | 內容 |
|---|---|
| **救護車出動** | 東京消防廳轄區內，因麻糬窒息而被送醫者**每年約 90～130 人**。**其中超過一半發生在 1 月，集中於 1 月 1 日～3 日** |
| **年齡** | **約 90% 為 65 歲以上**。**80 多歲者人數最多** |
| **死亡** | 全國因食物造成的**窒息死亡每年約 3,500～4,000 人**，**麻糬是其中最常見的食物之一**。消費者廳的分析顯示，**因麻糬致死集中在 1 月，占全年的四成以上** |
| **麻糬的性質** | **在口腔溫度（約 37℃／99°F）下會變硬、黏性更強**。**唾液無法將它溶解**。**很容易在沒有咬斷的情況下整塊吞下** |
| **兒童** | **一般不給未滿 3 歲的孩子吃一般麻糬**。**5 歲以下兒童窒息事故的食物依序是堅果、葡萄、小番茄與麻糬** |

## 預防（家中有長輩或孩子）

| 措施 | 內容 |
|---|---|
| **切** | **約 1 公分見方，或切成薄片**。「お雑煮」(新年雜煮湯)裡的麻糬也要切 |
| **一口的量** | **一次一塊，嚥下去之後再吃下一塊**。**不要邊說話、邊笑邊吃** |
| **潤濕口腔** | **吃之前先喝茶或湯**，把口腔與咽喉潤濕。**嘴裡含著麻糬再用茶送下去反而更糟**（麻糬會移位堵住呼吸道） |
| **姿勢** | **坐直，上半身略微前傾**。不要躺著吃，也不要剛睡醒就吃 |
| **替代品** | **「白玉」(白玉湯圓，切小)、加了麻糬的米粥、市售的「やわらかい餅」(軟麻糬)或「とろける餅」(入口即化麻糬)**，**也可用麵包粥或「すいとん」(麵疙瘩湯)代替麻糬** |
| **看護** | **絕不讓人獨自一人吃**。假牙不合時避免吃麻糬 |
| **時段** | **早餐時與剛睡醒時吞嚥能力較弱**。也有建議說中午以後比較安全 |

## 噎住時怎麼辦

1. **先確認「能出聲嗎？」**：如果對方**還能咳嗽或說話**，**就讓他繼續咳**（可能自己咳出來）。**不要拍背**（麻糬可能移動，反而完全堵住呼吸道）。
2. **發不出聲音、臉色發青、雙手掐住喉嚨**（窒息的訊號）：**立刻撥打 119**（請旁邊的人幫忙），同時：
   - **背部拍擊**：**讓對方上半身前傾、頭低下**，**用掌根用力連續拍擊兩肩胛骨之間**。
   - **腹部推擠（哈姆立克急救法）**：從背後**把拳頭放在肚臍上方，向內、向上猛推**。**孕婦與嬰兒不可使用**（改用胸部推擠）。
   - 交替進行這兩種方法，直到異物排出或對方失去意識。
3. **如果失去意識**：**開始心肺復甦（胸外按壓）**。取出口中看得見的東西（看不見的不要用手指去挖）。
4. **吸塵器**：消防單位與醫師**都不建議**（會傷到口腔，還會浪費時間）。請做上述處置，而不是去找器材。
5. **取出之後也要就醫**：可能有呼吸道損傷或殘留碎片。

- **嬰兒**：**背部拍擊（臉朝下、頭放低，拍背）與胸部推擠**。**嬰兒不可做腹部推擠，會損傷內臟**。
- **假牙**：**不合的假牙會削弱咬合力**。請在年底前到牙科調整。
- **對長輩風險較高的其他食物**：**「こんにゃく」(蒟蒻)、水煮蛋、麵包、肉、「団子」(丸子)、小番茄、葡萄**。同樣的措施適用。

## 誤解1｜好好嚼麻糬就安全

**對咀嚼與吞嚥能力變弱的長輩來說，麻糬正是因為「嚼了也會結成一團」才最危險。** 切小、少量與旁人看護要一起做到。

## 誤解2｜用茶送下去就沒事

**嘴裡含著麻糬時用液體往下送，可能讓麻糬移位並堵住呼吸道。** 要在吃之前潤濕口腔，而不是吃到一半時。

## 誤解3｜噎住了先拍背

**如果對方還能咳嗽或說話，不要拍，讓他繼續咳**（拍打可能造成完全阻塞）。**如果發不出聲音，就做背部拍擊與腹部推擠，並撥打 119**。

## 誤解4｜用吸塵器就能吸出來

**消防單位與醫療機構都不建議。** 找機器所花的時間反而讓情況更糟。請改做背部拍擊與腹部推擠。

## 誤解5｜切小了任何年齡的孩子都能吃

**未滿 3 歲的孩子咬不斷它，一般做法是不給麻糬。** 「白玉」(白玉湯圓)有同樣的性質，也要注意。
