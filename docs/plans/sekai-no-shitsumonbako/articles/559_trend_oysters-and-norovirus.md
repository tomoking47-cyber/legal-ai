# Q. 生牡蠣は冬なら安全？「生食用」と「加熱用」の違いは｜世界の質問箱 #559

- 棚：`trend` ／ URL：`/questions/oysters-and-norovirus` ／ ステータス：**ドラフト（法務レビュー前・出典未検証）**

冬の生牡蠣、カキフライ、鍋。牡蠣は日本の冬の味ですが、ノロウイルス食中毒の原因食品としても知られています。「生食用は新鮮、加熱用は古い」と思っている人が多いのですが、違いは鮮度ではなく「採れた海域と処理」です。

## A. 「生食用」と「加熱用」の違いは鮮度ではなく、採れた海域と浄化処理の有無です。生食用は、県が指定した「生食用かき採取海域」（下水の影響が少なく大腸菌などの基準を満たす海域）で採れたもの、または紫外線殺菌海水で浄化したもので、食品衛生法の成分規格を満たします。加熱用はそれ以外の海域のもので、鮮度は同等以上のことも多く、加熱すればおいしく安全。ただし生食用でもノロウイルスのリスクはゼロにならず（浄化で除去しきれない）、冬（11〜3月）はノロの流行期と重なります。加熱は中心85〜90℃で90秒以上、フライは衣が付いた状態で中まで。高齢者・妊婦・子ども・免疫が低い人は生食を避けるのが安全です。

## 生食用と加熱用の違い

| 項目 | 生食用 | 加熱用 |
|---|---|---|
| **海域** | **都道府県が指定した「生食用かき採取海域」**（河口・下水の影響が少ない、細菌数の基準を満たす） | 指定海域以外（栄養豊富な河口近くが多く、**身が大きく味が濃いことも**） |
| **処理** | **紫外線殺菌した海水で18〜20時間程度浄化**（細菌を減らす）。**成分規格**（細菌数、大腸菌、腸炎ビブリオ）を満たす | 浄化なし。**成分規格なし** |
| **鮮度** | 同等 | **同等**（「古い」わけではない） |
| **ノロウイルス** | **浄化で細菌は減るが、ウイルスは除去しきれない**。リスクは下がるがゼロではない | 加熱前提のため加熱すれば問題なし |
| **表示** | 「生食用」「消費期限」「採取海域」「殻を外した日」 | 「加熱用」「加熱調理用」 |
| **価格** | 高め | 安め |

## ノロウイルスと加熱

| 項目 | 内容 |
|---|---|
| **なぜ牡蠣か** | 二枚貝は**海水を1日200L以上ろ過**して餌を取り、**海水中のウイルスを中腸腺に濃縮**する。ノロウイルスは**人の腸でしか増えず、下水から海へ**流れる |
| **季節** | **11〜3月**が流行期。**海水温が低いとウイルスが長く残る**うえ、人の流行と重なる |
| **加熱の条件** | **中心温度85〜90℃で90秒以上**（厚生労働省）。**表面が焼けていても中心が達していないことがある**（大粒のフライ、鍋にさっと通す） |
| **症状** | 食後**24〜48時間**で**嘔吐・下痢・腹痛・微熱**、**1〜2日で回復**。**吐物・便から二次感染**（家庭内で広がる） |
| **感染力** | **10〜100個で感染**。**アルコール消毒は効きにくく、次亜塩素酸ナトリウム（塩素系漂白剤）が有効** |
| **統計** | ノロウイルス食中毒は**年間100〜300件・患者5,000〜10,000人**で、**患者数では原因物質の1位**。牡蠣を含む二枚貝が原因の一部、**多くは調理者の手を介した汚染** |

- **家での扱い**：**生食用は消費期限内に、開封したらすぐ**。**加熱用は中心まで加熱**——**フライは170〜180℃で3〜4分、大粒は割って確認**、**鍋は身がふっくら縮んでから1〜2分**、**電子レンジは加熱ムラが出るので不向き**。
- **調理中の二次汚染**：**生牡蠣を触った手・まな板・包丁で他の食材を触らない**。**牡蠣を洗った水が飛んだシンク周りを洗剤で洗う**。**調理後は石けんで手洗い**。
- **殻付き牡蠣**：**「生食用」の表示がある殻付き**のみ生で。**殻付きでも加熱用は加熱**。**焼き牡蠣は殻が開いてからさらに2〜3分**。
- **レモン・酢・わさび**：**ノロウイルスには効きません**。
- **食べた後に具合が悪くなったら**：**水分補給**（経口補水液）、**吐物の処理は手袋・マスク・塩素系漂白剤の希釈液（0.1%）**、**症状が治まっても1週間程度は便にウイルス**が出るため手洗いを続ける。**調理の仕事の人は症状が治まっても数日は調理を控える**。
- **避けるべき人**：**高齢者、妊婦、乳幼児、免疫が低下している人、胃酸を抑える薬を飲んでいる人**は生牡蠣を避ける。**腸炎ビブリオ（夏）・A型肝炎ウイルス**のリスクもあるため。

> **【要検証】** 生食用かきの成分規格・浄化条件は食品衛生法の規格基準で、ノロウイルス食中毒の統計は厚生労働省の最新年で確認してください。

## 誤解1｜生食用の方が新鮮で、加熱用は古い

**違いは海域と浄化処理で、鮮度は同等**です。加熱用は河口近くで育ち、身が大きく味が濃いことも多い。

## 誤解2｜生食用ならノロウイルスの心配はない

**浄化で細菌は減りますが、ウイルスは除去しきれず、リスクはゼロになりません。** 冬の流行期は特に注意。

## 誤解3｜レモンや酢をかければ殺菌になる

**ノロウイルスは酸やアルコールに強く、加熱か塩素系でしか対処できません。**

## 誤解4｜鍋にさっと通せば加熱済み

**中心85〜90℃で90秒以上が必要**で、さっと通しただけでは達しません。身がふっくら縮んでからさらに1〜2分。

## 誤解5｜牡蠣を食べた人だけが具合が悪くなる

**ノロウイルスは吐物・便・手を介して家族に広がります。** 処理は手袋と塩素系漂白剤で、手洗いを徹底。
