# Q. 冬天的生蚝安全吗？「生食用」和「加热用」有什么区别？｜Japan Questions #559

- Shelf: `trend` ／ URL: `/zh-cn/trend/oysters-and-norovirus` ／ Status: **草稿 — 出处未核实**

冬天的生蚝、「カキフライ」(炸牡蛎)、牡蛎火锅——牡蛎是日本冬天的味道，同时也是众所周知的诺如病毒食物中毒的原因。在日本的商店里，牡蛎分为「生食用」(可生食)和「加熱用」(加热用)两种在卖。很多人以为「生食用是新鲜的，加热用是不新鲜的」，但两者的区别不在于新鲜度，而在于采捕的海域和加工方式。

## A. 「生食用」和「加熱用」的区别不是新鲜度，而是采捕海域和有没有做净化处理。生食用牡蛎来自都道府县指定的「生食用牡蛎采捕海域」（受生活污水影响小、符合大肠菌群等标准的海域），或者在经紫外线杀菌的海水中做过净化，并符合《食品卫生法》的成分规格。加热用牡蛎来自其他海域；它们的新鲜度往往同样好甚至更好，加热后既美味又安全。不过，即使是生食用牡蛎，诺如病毒的风险也不会归零（净化并不能除去全部病毒），而冬天（11 月至 3 月）正好与诺如病毒的流行期重叠。加热时请让中心温度达到 85～90℃（185～194°F）并保持 90 秒以上；油炸时要炸到裹粉里面的中心也熟透。老年人、孕妇、儿童和免疫力低下的人，避开生蚝最为稳妥。

## 生食用与加热用

| 项目 | 生食用（生食用） | 加热用（加熱用） |
|---|---|---|
| **海域** | **都道府县指定的「生食用牡蛎采捕海域」**（受河口或生活污水影响小；符合细菌数标准） | 非指定海域（多为营养丰富、靠近河口的水域；**蚝肉往往更大更肥美**） |
| **加工** | **在紫外线杀菌海水中净化约 18～20 小时**（以减少细菌）。符合**成分规格**（细菌数、大肠杆菌、副溶血性弧菌） | 不做净化。**没有成分规格** |
| **新鲜度** | 相同 | **相同**（并不是「不新鲜的」） |
| **诺如病毒** | **净化能减少细菌，但不能除去全部病毒**。风险较低，但不为零 | 以加热为前提销售，加热后即无问题 |
| **标示** | 「生食用」(可生食)、「消費期限」(消费期限)、「採取海域」(采捕海域)、「殻を外した日」(去壳日期) | 「加熱用」或「加熱調理用」(加热烹调用) |
| **价格** | 较高 | 较低 |

## 诺如病毒与加热

| 项目 | 内容 |
|---|---|
| **为什么是牡蛎** | 双壳贝为了摄食**每天过滤 200 L 以上的海水**，**把水中的病毒浓缩在中肠腺里**。诺如病毒**只在人的肠道内增殖，经由生活污水流入海中** |
| **季节** | **11 月至 3 月**是高峰。**病毒在冰冷的海水中存活更久**，又与人群的流行期重叠 |
| **加热条件** | **中心温度 85～90℃ 保持 90 秒以上**（厚生劳动省）。**表面已经上色而中心还没到温度的情况很常见**（大个的炸牡蛎、火锅里涮一下的牡蛎） |
| **症状** | 食用后 **24～48 小时**：**呕吐、腹泻、腹痛、微热**，**1～2 天内恢复**。**呕吐物与粪便会造成二次感染**（在家庭内扩散） |
| **传染性** | **10～100 个病毒颗粒就足以造成感染**。**酒精消毒效果差；次氯酸钠（含氯漂白剂）有效** |
| **统计** | 诺如病毒食物中毒：**每年 100～300 起、患者 5,000～10,000 人**，**按患者人数是第一位的病因物质**。包括牡蛎在内的双壳贝只占其中一部分；**多数病例来自经由厨房人员的手造成的污染** |

- **在家里**：**生食用牡蛎要在消费期限内食用，开封后立即食用**。**加热用牡蛎要加热到中心** ——**用 170～180℃ 炸 3～4 分钟，并掰开一个大的确认**；**火锅里在蚝肉鼓起收缩后再煮 1～2 分钟**；**微波炉加热不均匀，不适合**。
- **烹调时的交叉污染**：**碰过生牡蛎的手、砧板和刀不要再碰其他食材**。**洗牡蛎的水溅到的水槽周围要用洗涤剂清洗**。**做完菜后用肥皂洗手**。
- **带壳牡蛎**：只有**标示为「生食用」的带壳牡蛎**才能生吃。**加热用的带壳牡蛎必须加热**。**烤牡蛎在壳张开后要再烤 2～3 分钟**。
- **柠檬、醋、芥末**：**对诺如病毒没有作用**。
- **事后感觉不适时**：**注意补充水分**（口服补液盐），**清理呕吐物时戴手套和口罩，用稀释的含氯漂白剂（0.1%）**，并**持续洗手，因为症状消失后病毒仍会随粪便排出约一周**。**以做饭为职业的人，痊愈后仍应停止接触食品数日**。
- **应避免生蚝的人**：**老年人、孕妇、婴幼儿、免疫力低下者以及正在服用抑酸药物的人**。此外还有**副溶血性弧菌（夏季）和甲型肝炎病毒**的风险。

## 误解1｜生食用更新鲜，加热用是不新鲜的

**区别在于采捕海域和净化处理，新鲜度是一样的。** 加热用牡蛎多生长在河口附近，个头更大、味道更浓。

## 误解2｜生食用就不用担心诺如病毒

**净化能减少细菌，但不能除去全部病毒，风险不会归零。** 冬季流行期尤其要注意。

## 误解3｜柠檬或醋可以杀菌

**诺如病毒耐酸也耐酒精，只有加热或含氯消毒才能应对。**

## 误解4｜在火锅里涮一下就算加热了

**需要中心温度 85～90℃ 保持 90 秒以上**，涮一下达不到。请在蚝肉鼓起收缩后再煮 1～2 分钟。

## 误解5｜只有吃了牡蛎的人才会生病

**诺如病毒会经由呕吐物、粪便和手在家人之间传播。** 请戴手套、用含氯漂白剂清理，并彻底洗手。
