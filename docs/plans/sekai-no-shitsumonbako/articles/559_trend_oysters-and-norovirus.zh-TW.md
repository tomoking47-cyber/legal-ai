# Q. 冬天的生蠔安全嗎？「生食用」與「加熱用」有什麼不同？｜Japan Questions #559

- Shelf: `trend` ／ URL: `/zh-tw/trend/oysters-and-norovirus` ／ Status: **草稿 — 出處未核實**

冬天的生蠔、「カキフライ」(炸牡蠣)、牡蠣火鍋——牡蠣是日本冬天的味道，同時也是眾所周知的諾羅病毒食物中毒原因。在日本的店裡，牡蠣分成「生食用」(可生食)與「加熱用」(加熱用)兩種販售。很多人以為「生食用是新鮮的，加熱用是不新鮮的」，但兩者的差別不在新鮮度，而在採捕的海域與加工方式。

## A. 「生食用」與「加熱用」的差別不是新鮮度，而是採捕海域與有沒有做淨化處理。生食用牡蠣來自都道府縣指定的「生食用牡蠣採捕海域」（受生活污水影響小、符合大腸桿菌群等標準的海域），或是在經紫外線殺菌的海水中做過淨化，並符合《食品衛生法》的成分規格。加熱用牡蠣來自其他海域；它們的新鮮度往往同樣好甚至更好，加熱後既美味又安全。不過，即使是生食用牡蠣，諾羅病毒的風險也不會歸零（淨化並不能去除全部病毒），而冬天（11 月至 3 月）正好與諾羅病毒的流行期重疊。加熱時請讓中心溫度達到 85～90℃（185～194°F）並維持 90 秒以上；油炸時要炸到裹粉裡面的中心也熟透。長輩、孕婦、兒童與免疫力低下的人，避開生蠔最為穩妥。

## 生食用與加熱用

| 項目 | 生食用（生食用） | 加熱用（加熱用） |
|---|---|---|
| **海域** | **都道府縣指定的「生食用牡蠣採捕海域」**（受河口或生活污水影響小；符合細菌數標準） | 非指定海域（多為營養豐富、靠近河口的水域；**蠔肉往往更大更肥美**） |
| **加工** | **在紫外線殺菌海水中淨化約 18～20 小時**（以減少細菌）。符合**成分規格**（細菌數、大腸桿菌、腸炎弧菌） | 不做淨化。**沒有成分規格** |
| **新鮮度** | 相同 | **相同**（並不是「不新鮮的」） |
| **諾羅病毒** | **淨化能減少細菌，但無法去除全部病毒**。風險較低，但不為零 | 以加熱為前提販售，加熱後即無問題 |
| **標示** | 「生食用」(可生食)、「消費期限」(消費期限)、「採取海域」(採捕海域)、「殻を外した日」(去殼日期) | 「加熱用」或「加熱調理用」(加熱調理用) |
| **價格** | 較高 | 較低 |

## 諾羅病毒與加熱

| 項目 | 內容 |
|---|---|
| **為什麼是牡蠣** | 雙殼貝為了攝食**每天過濾 200 L 以上的海水**，**把水中的病毒濃縮在中腸腺裡**。諾羅病毒**只在人的腸道內增殖，經由生活污水流入海中** |
| **季節** | **11 月至 3 月**是高峰。**病毒在冰冷的海水中存活更久**，又與人群的流行期重疊 |
| **加熱條件** | **中心溫度 85～90℃ 維持 90 秒以上**（厚生勞動省）。**表面已經上色而中心還沒到溫度的情況很常見**（大顆的炸牡蠣、火鍋裡涮一下的牡蠣） |
| **症狀** | 食用後 **24～48 小時**：**嘔吐、腹瀉、腹痛、微燒**，**1～2 天內恢復**。**嘔吐物與糞便會造成二次感染**（在家庭內擴散） |
| **傳染性** | **10～100 個病毒顆粒就足以造成感染**。**酒精消毒效果差；次氯酸鈉（含氯漂白水）有效** |
| **統計** | 諾羅病毒食物中毒：**每年 100～300 件、患者 5,000～10,000 人**，**以患者人數計是第一名的病因物質**。包含牡蠣在內的雙殼貝只占其中一部分；**多數案例來自經由廚房人員的手造成的污染** |

- **在家裡**：**生食用牡蠣要在消費期限內食用，開封後立刻吃完**。**加熱用牡蠣要加熱到中心** ——**用 170～180℃ 炸 3～4 分鐘，並剝開一顆大的確認**；**火鍋裡在蠔肉鼓起收縮後再煮 1～2 分鐘**；**微波爐加熱不均勻，不適合**。
- **烹調時的交叉污染**：**碰過生牡蠣的手、砧板與刀不要再碰其他食材**。**洗牡蠣的水濺到的水槽周圍要用清潔劑清洗**。**做完菜後用肥皂洗手**。
- **帶殼牡蠣**：只有**標示為「生食用」的帶殼牡蠣**才能生吃。**加熱用的帶殼牡蠣必須加熱**。**烤牡蠣在殼張開後要再烤 2～3 分鐘**。
- **檸檬、醋、山葵**：**對諾羅病毒沒有作用**。
- **事後覺得不舒服時**：**注意補充水分**（口服電解質液），**清理嘔吐物時戴手套與口罩，用稀釋的含氯漂白水（0.1%）**，並**持續洗手，因為症狀消失後病毒仍會隨糞便排出約一週**。**以做菜為職業的人，痊癒後仍應停止接觸食品數日**。
- **應避免生蠔的人**：**長輩、孕婦、嬰幼兒、免疫力低下者以及正在服用抑制胃酸藥物的人**。此外還有**腸炎弧菌（夏季）與 A 型肝炎病毒**的風險。

> **[待核實]** 生食用牡蠣的成分規格與淨化條件請對照《食品衛生法》的規格基準核實，諾羅病毒的統計請對照厚生勞動省最新年度資料核實。

## 誤解1｜生食用比較新鮮，加熱用是不新鮮的

**差別在於採捕海域與淨化處理，新鮮度是一樣的。** 加熱用牡蠣多生長在河口附近，個頭更大、味道更濃。

## 誤解2｜生食用就不用擔心諾羅病毒

**淨化能減少細菌，但無法去除全部病毒，風險不會歸零。** 冬季流行期尤其要注意。

## 誤解3｜檸檬或醋可以殺菌

**諾羅病毒耐酸也耐酒精，只有加熱或含氯消毒才能應對。**

## 誤解4｜在火鍋裡涮一下就算加熱了

**需要中心溫度 85～90℃ 維持 90 秒以上**，涮一下達不到。請在蠔肉鼓起收縮後再煮 1～2 分鐘。

## 誤解5｜只有吃了牡蠣的人才會生病

**諾羅病毒會經由嘔吐物、糞便與手在家人之間傳播。** 請戴手套、用含氯漂白水清理，並徹底洗手。
