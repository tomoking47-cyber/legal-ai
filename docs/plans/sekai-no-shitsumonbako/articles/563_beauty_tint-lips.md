# Q. ティントリップは唇に悪い？色が落ちない仕組みと注意点｜世界の質問箱 #563

- 棚：`beauty` ／ URL：`/questions/tint-lips` ／ ステータス：**ドラフト（法務レビュー前・出典未検証）**

マスク生活で「落ちないリップ」として広まったティント。数時間たっても色が残る便利さの一方、「唇が乾く」「色が落とせない」「皮がむける」という声も多い製品です。仕組みと使い方を整理します。

## A. ティントは、唇の表面の角層に色素（染料）を染み込ませて発色させる仕組みで、通常の口紅（顔料が表面に乗る）とは違い、食事やマスクでも色が残ります。弱点は、①染料と揮発成分（アルコール系）が多く、油分が少ないため乾燥しやすい、②角層を染めるため皮むけが起きた部分だけ色が抜けてまだらになる、③落とすときにこすりやすい。使うなら、リップバームで保湿してから薄く塗り、落とすときはポイントメイクリムーバーを含ませたコットンを数秒当てて滑らせる。唇がひび割れているときは使わず、荒れが続くなら皮膚科（口唇炎）へ。日本国内で正規に流通する製品の着色料は、化粧品に配合できる範囲で認可されたものです（海外通販品には未認可の色素の例があります）。

## ティントと口紅の違い

| 項目 | ティント | 通常の口紅・グロス |
|---|---|---|
| **発色の仕組み** | **染料が角層に染み込む**（ステイン） | **顔料が表面に乗る** |
| **持ち** | **数時間〜半日**、食事・マスクでも残る | 食事で落ちる |
| **質感** | ウォーター系（さらさら）、オイル系、ベルベット系 | クリーミー、艶 |
| **乾燥** | **しやすい**（揮発成分、油分が少ない） | 油分・ワックスで保護 |
| **落とし方** | **専用リムーバーが必要なことが多い** | クレンジングで落ちる |
| **まだら** | **皮むけ部分だけ色が抜け、輪郭がにじむ** | 均一に落ちる |
| **成分の安全性** | **化粧品に配合できる着色料は法定色素（タール色素）など認可されたもの**。海外製の一部に日本で未認可の色素が使われた例あり | 同 |

- **使い方**：①**リップスクラブや蒸しタオルで皮むけを取ってから**（ただしこすり過ぎない） ②**リップバームで保湿し、なじませてから**（バームが多いとティントが定着しにくいので薄く） ③**中央から外へ薄く**、**輪郭はぼかす**（にじみ対策） ④**数秒置いて定着させてから唇を合わせる**。
- **落とし方**：**ポイントメイクリムーバー（オイル系）をコットンに含ませ、唇に5〜10秒当ててから、こすらずに滑らせる**。**綿棒で輪郭**。**落ちなければ翌日**——無理にこすると角層が剥がれて皮むけと色素沈着の原因。**寝る前には必ず落とす**（染料が長時間残るとくすみの一因になるとされる）。
- **乾燥対策**：**ティントの上からバームを重ねる**（艶と保護）、**夜はワセリンかリップバームをたっぷり**、**水分補給**。**ウォーターティントは特に乾く**ので、オイルティント・バームティントの方が乾燥肌向き。
- **唇の皮むけ・荒れ**：**なめる・皮をむく・こするをやめる**、**ワセリンで保護**、**紫外線対策（SPF入りバーム）**。**2週間以上赤み・ひび・かさぶたが続く**なら**口唇炎（接触皮膚炎、アトピー、カンジダ等）の可能性**があり皮膚科へ。
- **色素沈着**：**唇の色が濃くなる原因は、摩擦・紫外線・乾燥**で、ティントの染料そのものが沈着するという確かな根拠は乏しい。ただし**落とすときのこすりが摩擦になる**ため、リムーバーを使う。
- **海外通販のティント**：**日本で未認可の着色料や成分**を含む製品が国民生活センターの相談に上がっています。**日本語表示（全成分・製造販売元）のあるもの**を選ぶ。
- **子ども・10代**：唇の角層は薄く、**乾燥・荒れが出やすい**。使うならオイルティントを薄く、バームを重ねる。

> **【要検証】** ティントの発色機構と乾燥の説明は化粧品科学の一般的な説明です。着色料の規制（法定色素）は厚生労働省「医薬品等に使用することができるタール色素を定める省令」で確認してください。

## 誤解1｜ティントは唇を染めるから体に悪い

**配合できる着色料は認可された範囲のもので、染まるのは角層（数日で生え替わる層）**です。問題は乾燥と落とし方の摩擦。

## 誤解2｜落ちないから寝る前も落とさなくていい

**長時間残った染料と乾燥はくすみ・荒れの一因**になります。リムーバーで落として、ワセリンで保護。

## 誤解3｜落ちにくいからゴシゴシこすって落とす

**摩擦で角層が剥がれ、皮むけ・色素沈着の原因**になります。リムーバーを5〜10秒当てて滑らせる。落ちなければ翌日。

## 誤解4｜唇が荒れていてもティントで隠せばいい

**皮むけ部分だけ色が抜けてまだらになり、荒れも悪化します。** 荒れているときはバームだけにして、続くなら皮膚科。

## 誤解5｜海外で人気のティントは日本の製品より優秀

**日本で未認可の成分を含む製品の相談例があります。** 日本語の全成分表示があるものを選ぶ。
