# Q. 唇釉（染唇液）傷嘴唇嗎？顏色為什麼能留住，又該注意什麼｜Japan Questions #563

- Shelf: `beauty` ／ URL: `/zh-tw/beauty/tint-lips` ／ Status: **草稿 — 出處未核實**

唇釉（「ティントリップ」，染唇產品）在戴口罩的那幾年以「不掉色的口紅」之名在日本流行起來。顏色可以維持好幾個小時，但許多使用者也抱怨嘴唇乾燥、顏色洗不掉、脫皮。本文說明唇釉的原理與用法。

## A. 唇釉的原理，是讓染料滲入嘴唇最外層（角質層）。與色素停留在表面的一般口紅不同，顏色能撐過吃飯與口罩。它的弱點：①唇釉染料含量高、揮發性成分多（酒精類），油分少，嘴唇容易乾；②因為被染色的是表層本身，一旦哪裡脫皮，那塊就掉色，嘴唇看起來斑駁；③卸的時候人們往往用力搓。要用的話，先用護唇膏保濕，再薄薄地塗；卸妝時把浸了眼唇卸妝液的化妝棉在嘴唇上按幾秒，再滑開。嘴唇乾裂時不要用唇釉；如果疼痛持續，請就診皮膚科（日本健保適用）檢查唇炎。所用的著色劑都在化粧品允許的範圍內核准。

## 唇釉與口紅的比較

| 項目 | 唇釉 | 一般口紅或唇蜜 |
|---|---|---|
| **上色原理** | **染料滲入皮膚外層**（染著） | **色素停留在表面** |
| **持久度** | **數小時至半天**；能撐過吃飯與口罩 | 吃一頓飯就掉 |
| **質地** | 水感型（輕薄）、油感型、絲絨型 | 膏狀、有光澤 |
| **乾燥** | **容易乾**（揮發性成分多，油分少） | 有油脂與蠟的保護 |
| **卸除** | **常需專用卸妝液** | 用洗面產品即可卸掉 |
| **斑駁** | **脫皮的地方會掉色，輪廓也會暈開** | 均勻地變淡 |
| **成分安全性** | **化粧品可用的著色劑是法定色素（所謂焦油色素，「法定色素」）及其他核准物質。** 部分海外產品曾使用日本未核准的著色劑 | 同左 |

- **塗法**：①**先用唇部去角質或溫熱的濕毛巾去掉浮起的皮屑**（不要過度摩擦）②**用護唇膏保濕並等它穩定下來**（護唇膏太多會讓唇釉上不去，所以要薄）③**從中央向外薄塗，並把輪廓暈開**（防止暈染）④**等幾秒讓它定色後再抿嘴唇**。
- **卸法**：**把油性眼唇卸妝液浸在化妝棉上，在嘴唇上按 5–10 秒，然後不搓、直接滑開。** **輪廓處用棉花棒。** **如果卸不掉，就留到隔天**——硬搓會磨掉角質層，造成脫皮與色素沉澱。**睡前一定要卸掉**（一般認為染料長時間殘留是暗沉的原因之一）。
- **對付乾燥**：**在唇釉上疊一層護唇膏**（增添光澤與保護），**夜裡厚厚地塗上凡士林（「ワセリン」，Vaseline）或護唇膏**，**多喝水**。**水感型唇釉最乾**，因此乾唇的人更適合油感型唇釉與膏狀唇釉。
- **脫皮與嘴唇發炎**：**不要舔、不要撕皮、不要摩擦**，**用凡士林保護**，**做好防曬（含 SPF 的護唇膏）**。**發紅、乾裂或結痂持續超過 2 週**，可能是**唇炎（接觸性皮膚炎、異位性濕疹、念珠菌等）**——請就診皮膚科。
- **嘴唇發暗**：**常見原因是摩擦、紫外線與乾燥**；關於唇釉染料本身殘留在皮膚裡的證據很少。不過，**卸妝時的搓揉就是摩擦**，所以請使用卸妝液。
- **從海外網購買的唇釉**：含有**日本未核准的著色劑或成分**的產品，曾出現在日本國民生活中心的申訴中。請選擇**附有日文標示（全成分表與上市銷售負責企業名稱）**的產品。
- **兒童與青少年**：嘴唇的外層很薄，**容易乾燥與發炎**。若要使用，請選油感型唇釉薄塗，上面再疊護唇膏。

> **[待核實]** 關於唇釉如何上色以及為何使嘴唇乾燥的說明，是化粧品科學的一般解釋。著色劑法規（法定色素）請對照厚生勞動省省令「關於規定可用於醫藥品等的焦油色素之省令」核實。

## 誤解1｜唇釉會把嘴唇染色，所以一定對身體不好

**只能使用核准的著色劑，而被染色的是幾天內就會更新的外層。** 真正的問題是乾燥，以及卸妝時的摩擦。

## 誤解2｜反正掉不了，睡前不用卸

**染料長時間殘留加上乾燥，是暗沉與發炎的原因之一。** 請用卸妝液卸除，並用凡士林保護。

## 誤解3｜太頑固了，用力搓掉就好

**摩擦會磨掉外層，造成脫皮與色素沉澱。** 請把卸妝液按 5–10 秒再滑開。卸不掉就留到隔天。

## 誤解4｜嘴唇發炎可以用唇釉遮住

**脫皮的地方會掉色、顯得斑駁，發炎也會加重。** 嘴唇發炎時只用護唇膏；持續不好請看皮膚科。

## 誤解5｜國外流行的唇釉比日本的好

**曾有含日本未核准成分的產品被申訴。** 請選擇附有完整日文全成分表的產品。
