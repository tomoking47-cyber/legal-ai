# Q. 産後に髪がどんどん抜ける。いつまで続く？対策はある？｜世界の質問箱 #564

- 棚：`beauty` ／ URL：`/questions/postpartum-hair-loss` ／ ステータス：**ドラフト（法務レビュー前・出典未検証）**

出産後2〜4か月ごろから、シャンプーのたびに髪が束で抜ける——多くの母親が経験する「産後の抜け毛（分娩後脱毛症）」です。「このまま薄くなるのでは」と不安になりますが、生理的な現象で、多くは半年〜1年で自然に戻ります。仕組みと、気になるときの対処を整理します。

## A. 妊娠中は女性ホルモン（エストロゲン）の影響で髪が抜けずに留まり続け、出産後にホルモンが急に下がると、留まっていた髪が一斉に休止期に入って2〜4か月後にまとめて抜けます。1日100〜300本が半年ほど続くこともありますが、毛根自体は傷んでいないため、多くは産後6か月〜1年で生え替わりが進み、1年〜1年半で元の毛量に戻ります。特別な治療は不要で、①栄養（たんぱく質・鉄・亜鉛、授乳中は特に不足しやすい）、②睡眠（可能な範囲で）、③頭皮を清潔に、きつく結ばない、④育毛剤は医薬部外品なら使えるが必須ではない。1年〜1年半たっても戻らない、地肌が透ける、円形に抜ける場合は皮膚科で他の原因（甲状腺、鉄欠乏、円形脱毛症）を確かめてもらいます。

## 産後の抜け毛の経過

| 時期 | 何が起きているか |
|---|---|
| **妊娠中** | **エストロゲンが高く、成長期の髪が抜けずに留まる**。「妊娠中は髪が増えた・つやが出た」と感じる人が多い |
| **出産直後** | ホルモンが急降下し、**留まっていた髪が一斉に休止期へ** |
| **産後2〜4か月** | **抜け毛のピーク**。休止期に入った髪が抜ける（毛周期の休止期は約3か月）。**1日100〜300本**、通常の2〜3倍 |
| **産後6か月〜1年** | 新しい髪が生え、**短い毛（アホ毛）が生え際に目立つ**時期。毛量が戻ってくる |
| **1年〜1年半** | **多くは元の状態に**。長さがそろうまでにはさらに時間 |

- **経験する割合**：気になる程度の抜け毛は**産後の女性の4〜5割以上**が経験するとされ、**程度の差を含めればほぼ全員に起きる生理現象**。**2人目以降で強く出る**人も。
- **毛根は無事**：産後脱毛は「休止期脱毛」で、**毛根が破壊されるタイプ（瘢痕性）ではない**。したがって**生え替わる**。
- **やってよいこと**：**たんぱく質（体重1kgあたり1〜1.2g）、鉄（授乳中は不足しやすい。貧血があれば婦人科・内科で鉄剤）、亜鉛、ビタミンB群**を食事から。**授乳中の極端なダイエットは抜け毛を長引かせる**。**睡眠**は現実的に難しいが、**細切れでも横になる**。**頭皮を清潔に**（皮脂・汗）、**優しく洗い、すぐ乾かす**。**ヘアスタイル**：**きつく結ぶ・同じ位置で結ぶ**を避ける（牽引性脱毛）。**分け目を変える**、**前髪を作る**、**短くする**と生え際の短い毛が目立ちにくい。
- **育毛剤・発毛剤**：**医薬部外品の育毛剤（「発毛促進」「脱毛の予防」の効能）は授乳中も使えるものが多い**が、必須ではない。**ミノキシジル（第1類医薬品・発毛剤）は授乳中の使用は避ける**よう添付文書に記載。**サプリ**は食事で足りていれば不要。
- **カラー・パーマ**：**産後脱毛自体には影響しない**が、頭皮が敏感になっていることがあるため、様子を見ながら。**授乳への影響は通常ない**とされる。
- **受診の目安**：**産後1年〜1年半たっても戻らない**、**地肌が透けて見える**、**円形に抜ける（円形脱毛症）**、**眉毛・体毛も抜ける**、**疲れやすい・むくむ・体重が変わる（甲状腺）**、**めまい・動悸（鉄欠乏性貧血）**。**皮膚科**へ。産後は**甲状腺の機能異常（産後甲状腺炎）が5〜10%**で起きるとされ、抜け毛の背景になることがある。
- **パートナー・家族へ**：**「大丈夫、戻る」と言われることが本人の安心になる**現象。抜け毛の掃除を分担する。

> **【要検証】** 産後脱毛の経験割合、産後甲状腺炎の頻度は産婦人科・皮膚科の文献で確認してください。ミノキシジルの授乳中の注意は添付文書で確認を。

## 誤解1｜産後の抜け毛はこのまま薄毛になるサイン

**毛根は無事で、多くは半年〜1年で生え替わります。** 生理的な現象で、治療は基本的に不要。

## 誤解2｜シャンプーで抜けるから洗う回数を減らす

**抜ける髪は既に休止期に入っており、洗わなくても抜けます。** 頭皮の清潔を保つ方が新しい髪のためになります。

## 誤解3｜育毛剤を使わないと戻らない

**使わなくても戻ります。** 使うなら医薬部外品の育毛剤、ミノキシジルは授乳中は避ける。

## 誤解4｜ダイエットを急いで体型を戻したい

**授乳中の極端な食事制限は、抜け毛を長引かせ、授乳にも影響します。** たんぱく質・鉄を優先。

## 誤解5｜1年たっても戻らないのは体質

**1年〜1年半で戻らないなら、甲状腺・鉄欠乏・円形脱毛症などの可能性**があります。皮膚科で確認を。
