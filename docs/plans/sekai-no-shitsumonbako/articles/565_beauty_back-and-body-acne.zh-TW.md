# Q. 背上與胸前長痘——保養方式和臉一樣嗎？｜Japan Questions #565

- Shelf: `beauty` ／ URL: `/zh-tw/beauty/back-and-body-acne` ／ Status: **草稿 — 出處未核實**

日本的夏天想穿露背的衣服，背上卻全是小疙瘩。背部、胸前與肩膀這些皮脂分泌旺盛的地方，和臉一樣會長痘。但有時候原因根本不是痘痘，這時照臉部的方式保養就毫無作用。本文說明如何分辨，以及該怎麼做。

## A. 長在背上的一部分「痘痘」其實不是痘痘（痤瘡桿菌），而是由皮膚上原本就存在的一種酵母菌引起的**馬拉色菌毛囊炎**。兩者外觀相似，但抗痘藥物對它沒有幫助。如果出現大小均勻的小疙瘩並伴隨搔癢，就有馬拉色菌的可能，最快的途徑是就診皮膚科（日本健保適用）開抗黴菌藥。如果確實是痘痘：①洗髮與潤絲之後再洗身體（潤絲精的殘留會順著背部流下來），②流汗後沖澡或換衣服，③不要用尼龍澡巾用力搓，④穿棉質的貼身衣物，⑤用低油分的產品保濕，⑥可以試試醫藥部外品等級（日本介於化粧品與藥品之間的一個類別）的「薬用」（藥用）抗痘沐浴產品。如果想避免留痕，請及早就診皮膚科。

## 如何分辨這些疙瘩

| 情況 | 外觀 | 搔癢 | 部位 | 該怎麼做 |
|---|---|---|---|---|
| **痘痘（尋常性痤瘡）** | **大小不一**：白頭、黑頭、紅色丘疹與膿皰混雜 | 少 | 肩膀、上背部、胸前 | 管理皮脂與汗，市售抗痘藥，皮膚科的外用處方藥 |
| **馬拉色菌毛囊炎** | **許多大小均勻的紅色小疙瘩**，**帶光澤** | **有**（輕度） | 背部、胸前、肩膀；**流汗多的夏天與運動之後** | **抗黴菌藥（皮膚科處方）。** 抗痘藥無效 |
| **毛孔角化症（「さめ肌」，「鯊魚皮」）** | 細密粗糙、膚色至偏紅的小疙瘩，**不痛** | 無 | 上臂、背部、大腿 | 保濕（尿素或水楊酸產品）。屬體質，青少年常見，成年後減輕 |
| **接觸性皮膚炎（疹子）** | 發紅與小水泡，**與接觸部位一致** | **強** | 洗劑、柔軟精、沐浴乳、內衣的金屬扣 | 去除原因 |
| **痱子（「あせも」，miliaria）** | **流汗後立刻出現**的紅色小疙瘩 | 又癢又刺 | 頸部、背部、腋下 | 降溫並沖掉汗水 |

## 如果是痘痘該怎麼做

| 做法 | 細節 |
|---|---|
| **清洗順序** | **洗髮 → 潤絲 → 身體。** 留在背上的潤絲精殘留會堵塞毛孔。**洗身體前先把頭髮夾起來** |
| **怎麼洗** | **把肥皂或沐浴乳搓出泡沫，用手或棉質毛巾清洗。** **用尼龍澡巾（「ナイロンタオル」，日本賣的那種長條搓洗巾）用力搓會傷害皮膚外層，反而更糟。** **「薬用」（藥用，醫藥部外品）抗痘沐浴產品**核准的宣稱是「防止痘痘」 |
| **汗** | **流汗後沖澡，或者擦乾淨並換衣服。** **不要長時間穿著運動服或被汗浸濕的貼身衣物。** **夜裡流汗多的人，請保持寢具清潔** |
| **衣物與寢具** | **棉質貼身衣物**、**床單與枕頭套每週清洗**、**柔軟精的香料可能造成刺激** |
| **保濕** | **乾燥也會長痘。** **低油分的化粧水與凝膠**（標示 non-comedogenic 的） |
| **市售藥品** | **抗痘藥（布洛芬吡康醇、硫磺等）**，在藥妝店（松本清、Welcia 等）有售。**背部自己搆不到**，所以也有噴霧型 |
| **皮膚科** | **紅色痘痘多、開始留痕、用市售品保養 1–2 個月沒有改善** → **阿達帕林、過氧化苯甲醯、外用抗菌藥**等處方。**背部是痕跡（色素沉澱、疤痕）容易留下**的部位 |
| **紫外線** | 背部曬傷會**加深色素沉澱。** 請擦防曬或用衣物遮擋 |

- **認出馬拉色菌毛囊炎很重要**：**用抗痘藥一個月沒有變化、疙瘩大小均勻、會癢** → 就診皮膚科。**外用抗黴菌藥通常在 2–4 週內會改善。** **容易復發**，所以對汗的管理要照舊。
- **飲食**：和臉上的痘痘一樣，**尚未確立與特定食物的直接關聯**，不過有報告認為與高糖飲食有關。
- **壓力、睡眠與月經週期**會讓一部分人的情況變差（荷爾蒙的影響）。
- **背上的痕跡（色素沉澱）**：**通常在幾個月到一年內變淡。** **醫藥部外品等級的美白（美白，bihaku）有效成分獲准宣稱的是「抑制黑色素生成，防止斑點與雀斑」**，與**防曬**一起，有助於不讓痕跡變得更深。**凹陷性疤痕對化粧品沒有反應**，屬於醫美（自費）的範疇。
- **穿衣計畫**：**如果有露背的衣服或泳裝的安排，請提前 2–3 個月開始處理。** 這不是一夜之間就能平息的事。

> **[待核實]** 馬拉色菌毛囊炎的描述與處理，以及痤瘡指引中建議的藥物，請對照日本皮膚科學會的資料核實。

## 誤解1｜背上的每一個疙瘩都是痘痘

**馬拉色菌毛囊炎（一種皮膚酵母菌）、毛孔角化症、接觸性疹子與痱子都混在其中。** 如果用抗痘藥一個月毫無變化，請讓皮膚科幫忙分辨。

## 誤解2｜用尼龍澡巾好好搓一搓，毛孔就乾淨了

**這會傷害皮膚外層，讓情況更糟。** 搓出泡沫用手洗，再留意潤絲精的殘留，效果更好。

## 誤解3｜背上不會乾，所以不需要保濕

**乾燥是長痘的原因之一。** 請用低油分的化粧水或凝膠保濕。

## 誤解4｜曬一曬就能把痘痘曬乾、曬好

**紫外線會同時加重發炎與色素沉澱。** 請在背上擦防曬，或者用衣物遮擋。

## 誤解5｜痕跡放著不管自己就會淡掉

**紅色與褐色的痕跡會變淡，但凹陷性疤痕對化粧品沒有反應。** 及早就診皮膚科，是避免留痕最穩妥的辦法。
