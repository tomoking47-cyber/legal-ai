# Q. 머리카락은 한 달에 몇 센티미터 자랍니까? 자르면 더 빨리 자랍니까?｜Japan Questions #566

- Shelf: `beauty` ／ URL: `/ko/beauty/hair-growth-cycle` ／ Status: **초안 — 출처 미확인**

「머리를 기르고 싶은데 도무지 자라지 않는다.」「끝을 다듬으면 더 빨리 자란다.」「하루에 100개 빠지는 것은 정상인가?」 머리카락이 자라고 빠지는 일에는 일본에서도 세계 어디에서도 속설이 많습니다. 이 글은 모주기(모발의 성장 주기)의 기본에서 출발해, 근거가 있는 이야기와 없는 이야기를 나누어 봅니다.

## A. 머리카락은 한 달에 약 1~1.5cm(하루 약 0.3~0.4mm) 자랍니다. 유전, 나이, 영양에 따라 다소 달라지지만, 자르는 것으로는 전혀 달라지지 않습니다(끝을 다듬어도 모낭에는 아무 영향이 없습니다). 다듬은 뒤 「빨리 자라는 것 같다」고 느끼는 이유는 손상된 끝부분이 없어져 끊어짐이 줄고 길이가 유지되기 때문입니다. 하루에 50~100개가 빠지는 것은 정상이며, 가을에 조금 더 빠지는 사람이 많습니다. 머리카락 한 올의 수명은 2~6년이고, 성장기 → 퇴행기 → 휴지기의 주기를 돌며 새로 납니다. 이 주기가 흐트러지면(출산, 스트레스, 영양 부족, 질병) 빠지는 양이 일시적으로 늘어납니다. 길게 기르고 싶다면 **끊어짐과 갈라짐을 막는 것**이 가장 효과적인 방법입니다. 단백질·철·아연이 부족한 경우가 아니라면, 보충제가 성장을 빠르게 한다는 근거는 없습니다.

## 모발에 관한 기본 수치

| 항목 | 수치 |
|---|---|
| **성장 속도** | **하루 약 0.3~0.4mm, 한 달 1~1.5cm, 1년 12~15cm** |
| **모발 개수** | **약 10만 개**(사람과 머리 색에 따라 다름. 금발은 많은 편, 붉은 머리는 적은 편) |
| **하루 탈락 수** | **50~100개**가 정상. 많은 사람이 **가을(9~11월)에 조금 더 많음** |
| **머리카락 한 올의 수명** | **2~6년**(여성이 조금 더 김) |
| **모주기** | **성장기(2~6년, 전체의 85~90%) → 퇴행기(2~3주) → 휴지기(3~4개월, 10~15%) → 탈락 → 다시 성장기** |
| **굵기** | **약 0.05~0.1mm**(일본인의 모발은 굵은 편) |
| **성분** | **단백질(케라틴) 약 80~90%**, 수분 10~15%, 지질, 멜라닌 |

## 속설 점검

| 속설 | 실제 |
|---|---|
| **끝을 다듬으면 더 빨리 자란다** | **성장 속도는 모낭에서 정해지며 끝을 잘라도 달라지지 않습니다.** 끊어짐과 갈라짐이 줄어 길이가 「남기」 때문에 빠르게 느껴질 뿐입니다. **기르는 중이라면 2~3개월마다 1cm 다듬는 것은 합리적입니다** |
| **두피 마사지를 하면 빨리 자란다** | **혈류는 일시적으로 늘지만, 성장 속도가 달라진다는 근거는 제한적입니다.** 이완과 세정·피지 조절에는 도움이 됩니다. **세게 문지르면 오히려 해롭습니다** |
| **하루 100개가 빠지는 것은 비정상이다** | **정상 범위입니다.** **150~200개 이상이 계속되거나, 두피가 비쳐 보이거나, 뭉텅이로 빠지는 경우**가 진료를 받아야 할 신호입니다 |
| **샤워할 때 빠지니까 덜 감는 것이 좋다** | **빠지는 것은 휴지기 모발이며, 감지 않아도 빠집니다.** 감지 않으면 피지와 미생물로 두피 상태가 나빠집니다 |
| **흰머리를 뽑으면 더 많이 난다** | **그렇지 않습니다**(모낭 하나에 머리카락 하나). 다만 **뽑다가 모낭이 손상되어 다시 나지 않을 수 있으므로** 잘라내십시오 |
| **해조류를 먹으면 머리숱이 는다** | **요오드와 미네랄은 모발의 재료 중 하나이지만, 먹는다고 개수나 속도가 달라지지는 않습니다.** 단백질·철·아연의 부족이 훨씬 더 중요합니다 |
| **보충제(비오틴 등)가 성장을 빠르게 한다** | **부족하지 않다면 효과의 근거가 없습니다.** 결핍이 있는 경우(극단적인 다이어트, 철 결핍) 이를 바로잡으면 도움이 될 수 있습니다 |
| **모자를 쓰면 머리가 빠진다** | **통풍이 나쁜 모자를 몇 시간씩 쓰면 땀이 찬 두피 상태가 나빠지지만**, 모자 자체가 탈모의 원인은 아닙니다 |

- **현실적으로 머리를 기르는 방법**: **끊어짐과 갈라짐을 막기**(갈라진 모발에 관한 별도의 글 참조) — **젖은 머리를 문지르지 않기, 열기구는 적당히, 자외선 피하기, 염색과 탈색 횟수 줄이기, 2~3개월마다 1cm 다듬기.** **1년에 12~15cm가 한계**이므로, 어깨 길이에서 롱헤어까지는 **1년 반~2년**이 걸립니다.
- **영양**: **단백질(체중 1kg당 약 1g), 철(월경이 있는 여성은 부족하기 쉬움), 아연, 비타민 B군.** **극단적인 다이어트(한 달에 체중의 5% 이상 감량)는 몇 달 뒤 탈모로 이어집니다.**
- **나이**: **20~30대에 가장 빨리 자라며**, 나이가 들면 **가늘어지고, 느려지고, 성장기가 짧아집니다.** **여성은 폐경 이후 머리숱이 줄어드는 경우가 많습니다.**
- **진료가 필요한 경우**: **빠지는 양이 갑자기 늘어 2~3개월 지속**, **두피가 비쳐 보임**, **원형으로 빠진 부위**, **눈썹과 체모도 빠짐**, **두피의 붉어짐이나 딱지.** **피부과 의원**(일본 건강보험 적용)으로 가십시오. 남성형·여성형 탈모에는 **자비 진료 선택지**(미녹시딜, 피나스테리드 등)가 있습니다.

> **[확인 필요]** 성장 속도, 모발 개수, 모주기의 수치는 모발 과학의 일반적인 값입니다. 일본피부과학회 『남성형 및 여성형 탈모증 진료 가이드라인 2017』 [男性型および女性型脱毛症診療ガイドライン2017]과 대조해 확인해 주십시오.

## 오해 1｜끝을 다듬으면 더 빨리 자란다

**성장 속도는 모낭에서 정해지며 자른다고 달라지지 않습니다.** 끊어짐이 줄어 길이가 유지될 뿐입니다. 기르는 중이라면 정기적으로 다듬으십시오.

## 오해 2｜하루 100개가 빠지면 탈모의 시작이다

**하루 50~100개는 정상이고 가을에는 더 많습니다.** 150~200개 이상이 계속되거나 두피가 비쳐 보이면 진료를 받으십시오.

## 오해 3｜흰머리를 뽑으면 더 많이 난다

**그렇지 않지만, 뽑다가 모낭이 손상되어 다시 나지 않을 수 있습니다.** 뿌리 쪽에서 잘라내십시오.

## 오해 4｜보충제나 미역을 먹으면 머리숱이 늘고 빨리 자란다

**부족하지 않다면 근거가 없습니다.** 식사로 단백질·철·아연의 부족을 피하는 편이 더 중요합니다.

## 오해 5｜매일 두피 마사지를 하면 머리가 자란다

**성장 속도가 달라진다는 근거는 제한적이고, 세게 문지르면 해롭습니다.** 세정과 피지 조절, 이완 정도로 생각하십시오.
