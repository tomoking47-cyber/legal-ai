# Q. 髪は1か月で何cm伸びる？切ると早く伸びるって本当？｜世界の質問箱 #566

- 棚：`beauty` ／ URL：`/questions/hair-growth-cycle` ／ ステータス：**ドラフト（法務レビュー前・出典未検証）**

「髪を伸ばしたいのに全然伸びない」「毛先を切ると伸びが早くなる」「1日100本抜けるのは普通？」——髪の伸び方と抜け方には俗説が多くあります。毛周期の基本から、根拠のある話と俗説を分けます。

## A. 髪は1か月に約1〜1.5cm（1日約0.3〜0.4mm）伸び、これは遺伝・年齢・栄養で多少変わりますが、切ることでは変わりません（毛先を切っても毛根には何も起きない）。「切ると早く伸びる」と感じるのは、傷んだ毛先がなくなって切れ毛が減り、長さが保たれるからです。1日50〜100本の抜け毛は正常で、秋にやや増える人が多い。髪1本の寿命は2〜6年、生え替わりには「成長期→退行期→休止期」の毛周期があり、毛周期の乱れ（産後、ストレス、栄養不足、病気）で抜け毛が一時的に増えます。伸ばしたいなら「切れ毛・枝毛を防ぐ」ことが最も効果的で、たんぱく質・鉄・亜鉛の不足がなければ、サプリで伸びが速くなる根拠はありません。

## 髪の基本数値

| 項目 | 数値 |
|---|---|
| **伸びる速さ** | **1日約0.3〜0.4mm、1か月約1〜1.5cm、1年約12〜15cm** |
| **本数** | **約10万本**（個人差、髪色で差。金髪が多く、赤毛が少ない傾向） |
| **1日の抜け毛** | **50〜100本**が正常。**秋（9〜11月）はやや増える**人が多い |
| **1本の寿命** | **2〜6年**（女性はやや長い） |
| **毛周期** | **成長期（2〜6年、全体の85〜90%）→退行期（2〜3週間）→休止期（3〜4か月、10〜15%）→脱毛→再び成長期** |
| **太さ** | **約0.05〜0.1mm**（日本人は太めの傾向） |
| **成分** | **たんぱく質（ケラチン）約80〜90%**、水分10〜15%、脂質、メラニン |

## 俗説の検証

| 俗説 | 実際 |
|---|---|
| **毛先を切ると早く伸びる** | **伸びる速さは毛根で決まり、毛先を切っても変わらない。** 切れ毛・枝毛が減って長さが「保たれる」ため、伸びたように感じる。**伸ばしたい人ほど2〜3か月に1cm整える**のは理にかなっている |
| **頭皮マッサージで伸びが速くなる** | **血流は一時的に上がるが、伸びる速さが変わる根拠は限定的。** リラックス効果と、洗浄・皮脂管理の副次効果はある。**強い摩擦は逆効果** |
| **1日100本抜けるのは異常** | **正常範囲**。**150〜200本以上が続く、地肌が透ける、束で抜ける**なら受診の目安 |
| **シャンプーで抜けるから洗わない方がいい** | **抜けるのは休止期の髪で、洗わなくても抜ける。** 洗わないと皮脂・菌で頭皮環境が悪化 |
| **白髪を抜くと増える** | **増えない**（1つの毛穴から1本）。ただし**抜くと毛根を傷め、生えなくなることがある**ため切る |
| **海藻を食べると髪が増える** | **ヨウ素・ミネラルは髪の材料の一部だが、食べても本数・速さは変わらない。** たんぱく質・鉄・亜鉛の不足の方が影響大 |
| **サプリ（ビオチン等）で伸びが速くなる** | **欠乏がなければ効果の根拠はない。** 欠乏（極端なダイエット、鉄欠乏）があれば補正で改善 |
| **帽子をかぶると薄毛になる** | **通気性の悪い帽子を長時間かぶって蒸れると頭皮環境が悪化**するが、帽子自体で薄毛にはならない |

- **髪を伸ばす現実的な方法**：**切れ毛・枝毛を防ぐ**（別記事「枝毛」参照）＝**濡れた髪をこすらない、熱を控える、紫外線を避ける、カラー・ブリーチの頻度を下げる、毛先を2〜3か月に1cm整える**。**1年で12〜15cmが上限**なので、肩からロングまで**1年半〜2年**。
- **栄養**：**たんぱく質（体重1kgあたり1g前後）、鉄（月経のある女性は不足しがち）、亜鉛、ビタミンB群**。**極端なダイエット（1か月に体重の5%以上減）は数か月後の抜け毛の原因**。
- **年齢**：**伸びる速さは20〜30代がピーク**で、加齢とともに**細く、伸びも遅く、成長期が短く**なる。**女性は更年期以降に髪が細くなる**ことが多い。
- **受診の目安**：**抜け毛が急に増えて2〜3か月続く**、**地肌が透ける**、**円形に抜ける**、**眉毛・体毛も抜ける**、**頭皮の赤み・かさぶた**。**皮膚科**へ。男性型・女性型脱毛症には**保険外の治療**（ミノキシジル、フィナステリド等）がある。

> **【要検証】** 髪の伸びる速さ、本数、毛周期の数値は毛髪科学の一般的な値です。日本皮膚科学会「男性型および女性型脱毛症診療ガイドライン2017」の記述を確認してください。

## 誤解1｜毛先を切ると髪が早く伸びる

**伸びる速さは毛根で決まり、切っても変わりません。** 切れ毛が減って長さが保たれるだけ。伸ばすなら毛先を定期的に整える。

## 誤解2｜1日100本抜けたら薄毛の始まり

**50〜100本は正常で、秋は増えます。** 150〜200本以上が続く、地肌が透けるなら受診。

## 誤解3｜白髪は抜くと増える

**増えませんが、抜くと毛根を傷めて生えなくなることがあります。** 根元で切る。

## 誤解4｜サプリやわかめで髪が増える・速く伸びる

**欠乏がなければ根拠はありません。** たんぱく質・鉄・亜鉛の不足を食事で防ぐことの方が重要。

## 誤解5｜頭皮マッサージを毎日すれば伸びる

**伸びる速さが変わる根拠は限定的で、強い摩擦は逆効果**です。洗浄と皮脂管理、リラックスの範囲で。
