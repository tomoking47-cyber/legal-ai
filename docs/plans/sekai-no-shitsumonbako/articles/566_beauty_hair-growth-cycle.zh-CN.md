# Q. 头发一个月长几厘米？剪一剪会长得更快吗？｜Japan Questions #566

- Shelf: `beauty` ／ URL: `/zh-cn/beauty/hair-growth-cycle` ／ Status: **草稿 — 出处未核实**

「想留长发，可就是长不长。」「把发梢剪一剪，头发会长得更快。」「一天掉 100 根头发正常吗？」关于头发的生长与脱落，日本和世界各地一样，流传着大量说法。本文从毛周期（头发的生长周期）的基础讲起，把有依据的与没有依据的区分开来。

## A. 头发一个月大约长 1～1.2 厘米（每天约 0.3～0.4 毫米）。遗传、年龄和营养会带来一些差异，而剪头发完全不会改变生长速度（修剪发梢对毛囊没有任何作用）。剪过之后之所以「感觉」长得快，是因为受损的发梢没有了，断发减少，长度得以保留。一天掉 50～100 根头发属于正常，很多人在秋天会掉得多一些。一根头发的寿命为 2～6 年，按照生长期 → 退行期 → 休止期的周期不断更新。这个周期被打乱时（生产、压力、营养不良、疾病），脱发会暂时增加。如果想留长，**防止断发与分叉**是最有效的一步；除非蛋白质、铁或锌摄入不足，否则没有证据表明保健品能加快头发生长。

## 头发的基本数字

| 项目 | 数值 |
|---|---|
| **生长速度** | **每天约 0.3～0.4 毫米，一个月 1～1.2 厘米，一年 12～15 厘米** |
| **头发根数** | **约 10 万根**（因人和发色而异；金发的人偏多，红发的人偏少） |
| **每天脱发量** | **50～100 根**属于正常。很多人**在秋季（9～11 月）会略多** |
| **一根头发的寿命** | **2～6 年**（女性略长） |
| **毛周期** | **生长期（2～6 年，占全部头发的 85～90%）→ 退行期（2～3 周）→ 休止期（3～4 个月，占 10～15%）→ 脱落 → 再次进入生长期** |
| **粗细** | **约 0.05～0.1 毫米**（日本人的头发偏粗） |
| **成分** | **蛋白质（角蛋白）约 80～90%**，水分 10～15%，脂质，黑色素 |

## 逐条核对流传的说法

| 说法 | 实际情况 |
|---|---|
| **剪发梢头发会长得更快** | **生长速度取决于毛囊，剪发梢不会改变它。** 断发与分叉减少，长度得以「保留」，所以感觉变快了。**正在留长发的人，每 2～3 个月修剪 1 厘米是合理的做法** |
| **头皮按摩能加快头发生长** | **血流会短暂增加，但能改变生长速度的证据有限。** 它有助于放松，也有助于清洁与控油。**用力揉搓反而有害** |
| **一天掉 100 根头发不正常** | **仍在正常范围内。** **持续掉 150～200 根以上、能看见头皮、头发成撮脱落**，才是就医的信号 |
| **洗澡时会掉头发，所以少洗** | **掉的是处于休止期的头发，不洗也一样会掉。** 不洗会让皮脂和微生物使头皮状况变差 |
| **拔掉一根白头发会长出更多** | **不会**（一个毛囊只长一根头发）。但**拔的动作可能损伤毛囊，导致不再长出新发** —— 请改为剪断 |
| **吃海藻能让头发变多** | **碘和矿物质是头发的原料之一，但吃它们并不会改变头发的数量与生长速度。** 蛋白质、铁、锌的不足影响要大得多 |
| **保健品（生物素等）能加快生长** | **在不缺乏的情况下，没有证据显示有效。** 若确实缺乏（极端节食、缺铁），补足后会有帮助 |
| **戴帽子会导致头发变稀** | **通风差的帽子连戴几个小时，会让出汗的头皮状况变糟**，但帽子本身不会导致头发变稀 |

- **现实中留长发的方法**：**防止断发与分叉**（另见本站关于分叉的文章）——**头发湿时不要揉搓、少用热工具、避免紫外线、减少染发或漂色的次数、每 2～3 个月修剪 1 厘米。** **一年 12～15 厘米已是上限**，因此从齐肩长到长发需要 **1.5～2 年**。
- **营养**：**蛋白质（约每公斤体重 1 克）、铁（有月经的女性常常不足）、锌、B 族维生素。** **极端节食（一个月减掉超过体重 5%）会在几个月后引起脱发。**
- **年龄**：**生长最快的是 20～30 多岁**；随着年龄增长，头发会**变细、生长变慢、生长期变短。** **女性在更年期之后常出现头发变稀。**
- **该看医生的情况**：**脱发突然增多并持续 2～3 个月**、**能看见头皮**、**出现圆形脱发斑**、**眉毛和体毛也脱落**、**头皮发红或结痂。** 请前往**皮肤科诊所**（日本的健康保险适用）。对于男性型与女性型脱发，另有**自费选项**（米诺地尔、非那雄胺等）。

> **[待核实]** 生长速度、头发根数与毛周期的数字，是毛发科学的一般数值。请对照日本皮肤科学会《男性型及女性型脱发症诊疗指南 2017》[男性型および女性型脱毛症診療ガイドライン2017] 核查。

## 误解1｜剪发梢头发会长得更快

**生长速度取决于毛囊，剪了也不会改变。** 断发减少只是让长度得以保留。正在留长发的话，请定期修剪。

## 误解2｜一天掉 100 根头发是秃头的开始

**一天 50～100 根属于正常，秋天还会更多。** 若持续掉 150～200 根以上，或头皮透出来，请就医。

## 误解3｜拔掉白头发会长出更多

**不会，但拔的动作可能损伤毛囊，导致不再长出新发。** 请改为从根部剪断。

## 误解4｜保健品或裙带菜能让头发变多、长得更快

**在不缺乏的情况下没有证据。** 通过饮食避免蛋白质、铁、锌不足更为重要。

## 误解5｜每天做头皮按摩头发就会长

**能改变生长速度的证据有限，用力揉搓反而有害。** 请把它限定在清洁、控油与放松的范围内。
