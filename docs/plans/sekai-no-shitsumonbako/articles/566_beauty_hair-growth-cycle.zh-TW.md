# Q. 頭髮一個月長幾公分？剪一剪會長得更快嗎？｜Japan Questions #566

- Shelf: `beauty` ／ URL: `/zh-tw/beauty/hair-growth-cycle` ／ Status: **草稿 — 出處未核實**

「想留長髮，可就是留不長。」「把髮尾剪一剪，頭髮會長得更快。」「一天掉 100 根頭髮正常嗎？」關於頭髮的生長與掉落，日本和世界各地一樣，流傳著大量說法。本文從毛週期（頭髮的生長週期）的基礎談起，把有依據的與沒有依據的區分開來。

## A. 頭髮一個月大約長 1～1.5 公分（每天約 0.3～0.4 公釐）。遺傳、年齡與營養會帶來一些差異，而剪頭髮完全不會改變生長速度（修剪髮尾對毛囊沒有任何作用）。剪過之後之所以「感覺」長得快，是因為受損的髮尾沒有了，斷髮減少，長度得以保留。一天掉 50～100 根頭髮屬於正常，很多人在秋天會掉得多一些。一根頭髮的壽命為 2～6 年，依照生長期 → 退行期 → 休止期的週期不斷更新。這個週期被打亂時（生產、壓力、營養不良、疾病），掉髮會暫時增加。若想留長，**防止斷髮與分叉**是最有效的一步；除非蛋白質、鐵或鋅攝取不足，否則沒有證據顯示保健食品能加快頭髮生長。

## 頭髮的基本數字

| 項目 | 數值 |
|---|---|
| **生長速度** | **每天約 0.3～0.4 公釐，一個月 1～1.5 公分，一年 12～15 公分** |
| **頭髮根數** | **約 10 萬根**（因人與髮色而異；金髮的人偏多，紅髮的人偏少） |
| **每天掉髮量** | **50～100 根**屬於正常。很多人**在秋季（9～11 月）會略多** |
| **一根頭髮的壽命** | **2～6 年**（女性略長） |
| **毛週期** | **生長期（2～6 年，占全部頭髮的 85～90%）→ 退行期（2～3 週）→ 休止期（3～4 個月，占 10～15%）→ 掉落 → 再次進入生長期** |
| **粗細** | **約 0.05～0.1 公釐**（日本人的頭髮偏粗） |
| **成分** | **蛋白質（角蛋白）約 80～90%**，水分 10～15%，脂質，黑色素 |

## 逐條核對流傳的說法

| 說法 | 實際情況 |
|---|---|
| **剪髮尾頭髮會長得更快** | **生長速度取決於毛囊，剪髮尾不會改變它。** 斷髮與分叉減少，長度得以「保留」，所以感覺變快了。**正在留長髮的人，每 2～3 個月修剪 1 公分是合理的做法** |
| **頭皮按摩能加快頭髮生長** | **血流會短暫增加，但能改變生長速度的證據有限。** 它有助於放鬆，也有助於清潔與控油。**用力搓揉反而有害** |
| **一天掉 100 根頭髮不正常** | **仍在正常範圍內。** **持續掉 150～200 根以上、看得見頭皮、頭髮成撮掉落**，才是就醫的訊號 |
| **洗澡時會掉頭髮，所以少洗** | **掉的是處於休止期的頭髮，不洗也一樣會掉。** 不洗會讓皮脂與微生物使頭皮狀況變差 |
| **拔掉一根白頭髮會長出更多** | **不會**（一個毛囊只長一根頭髮）。但**拔的動作可能傷到毛囊，導致不再長出新髮** —— 請改為剪斷 |
| **吃海藻能讓頭髮變多** | **碘與礦物質是頭髮的原料之一，但吃它們並不會改變頭髮的數量與生長速度。** 蛋白質、鐵、鋅的不足影響要大得多 |
| **保健食品（生物素等）能加快生長** | **在不缺乏的情況下，沒有證據顯示有效。** 若確實缺乏（極端節食、缺鐵），補足後會有幫助 |
| **戴帽子會導致頭髮變稀疏** | **通風差的帽子連戴好幾個小時，會讓出汗的頭皮狀況變糟**，但帽子本身不會導致頭髮變稀疏 |

- **現實中留長髮的方法**：**防止斷髮與分叉**（另見本站關於分叉的文章）——**頭髮濕時不要搓揉、少用熱工具、避免紫外線、減少染髮或漂色的次數、每 2～3 個月修剪 1 公分。** **一年 12～15 公分已是上限**，因此從及肩長到長髮需要 **1.5～2 年**。
- **營養**：**蛋白質（約每公斤體重 1 公克）、鐵（有月經的女性常常不足）、鋅、B 群維生素。** **極端節食（一個月減掉超過體重 5%）會在幾個月後引起掉髮。**
- **年齡**：**生長最快的是 20～30 多歲**；隨著年齡增長，頭髮會**變細、生長變慢、生長期變短。** **女性在更年期之後常出現頭髮變稀疏。**
- **該看醫師的情況**：**掉髮突然增加並持續 2～3 個月**、**看得見頭皮**、**出現圓形禿斑**、**眉毛與體毛也掉落**、**頭皮發紅或結痂。** 請前往**皮膚科診所**（日本的健康保險適用）。針對男性型與女性型掉髮，另有**自費選項**（米諾地爾、非那雄胺等）。

> **[待核實]** 生長速度、頭髮根數與毛週期的數字，是毛髮科學的一般數值。請對照日本皮膚科學會《男性型及女性型脫髮症診療指引 2017》[男性型および女性型脱毛症診療ガイドライン2017] 核對。

## 誤解1｜剪髮尾頭髮會長得更快

**生長速度取決於毛囊，剪了也不會改變。** 斷髮減少只是讓長度得以保留。正在留長髮的話，請定期修剪。

## 誤解2｜一天掉 100 根頭髮是禿頭的開始

**一天 50～100 根屬於正常，秋天還會更多。** 若持續掉 150～200 根以上，或頭皮透出來，請就醫。

## 誤解3｜拔掉白頭髮會長出更多

**不會，但拔的動作可能傷到毛囊，導致不再長出新髮。** 請改為從根部剪斷。

## 誤解4｜保健食品或裙帶菜能讓頭髮變多、長得更快

**在不缺乏的情況下沒有證據。** 透過飲食避免蛋白質、鐵、鋅不足更為重要。

## 誤解5｜每天做頭皮按摩頭髮就會長

**能改變生長速度的證據有限，用力搓揉反而有害。** 請把它限定在清潔、控油與放鬆的範圍內。
