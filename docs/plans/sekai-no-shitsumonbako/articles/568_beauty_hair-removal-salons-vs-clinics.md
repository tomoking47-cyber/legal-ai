# Q. 脱毛サロンと医療脱毛、何が違う？契約で気をつけることは｜世界の質問箱 #568

- 棚：`beauty` ／ URL：`/questions/hair-removal-salons-vs-clinics` ／ ステータス：**ドラフト（法務レビュー前・出典未検証）**

脱毛は日本で最も広告の多い美容サービスの一つで、「サロン」と「クリニック（医療脱毛）」の違いがわかりにくいまま契約する人が多く、国民生活センターには解約・倒産・やけどの相談が毎年数千件寄せられています。仕組みと契約の注意を整理します。

## A. 医療脱毛はクリニックで医師・看護師がレーザーで毛根を破壊する「医療行為」で、永久脱毛に近い効果（毛が生えにくくなる）が見込めます。脱毛サロンは光（IPL）の出力を弱めた「減毛・抑毛」で、毛根の破壊は法律上できず、効果は一時的〜長期の減毛にとどまり、通う回数も多くなります。費用はサロンが安く見えますが、回数が多い・追加契約・倒産リスク（2022〜2023年に大手が相次いで破産）があり、総額では医療脱毛と大差ないこともあります。契約時の注意は、①総額と回数・期間・有効期限、②中途解約の条件（特定継続的役務提供でクーリングオフ8日・中途解約可）、③前払いを避ける（都度払いか回数を少なく）、④やけど・硬毛化・色素沈着のリスクと対応の説明を受ける。

## サロン脱毛と医療脱毛の比較

| 項目 | 脱毛サロン（エステ） | 医療脱毛（クリニック） |
|---|---|---|
| **施術者** | エステティシャン（資格不要） | **医師・看護師** |
| **機器・出力** | **光脱毛（IPL、SHR等）**。出力は**毛根を破壊できないレベル**に制限 | **医療レーザー（アレキサンドライト、ダイオード、ヤグ）**。**毛根を破壊できる出力** |
| **法的位置づけ** | **毛根を破壊する行為は医師法違反**（2001年厚生労働省通知）。「減毛」「抑毛」まで | **医療行為** |
| **効果** | **一時的〜長期の減毛**。**「永久脱毛」の表示は不可** | **永久脱毛に近い**（米国FDAの定義：施術後の再生毛が長期的に減少） |
| **回数** | **12〜18回以上**（2〜3年） | **5〜8回**（1〜1.5年） |
| **痛み** | 弱い | **強め**（麻酔クリームの選択肢） |
| **費用（全身の目安）** | **10〜30万円**（回数無制限プランも） | **20〜40万円**（5回程度） |
| **リスク** | やけど、色素沈着、**硬毛化**（うぶ毛が太くなる）、**倒産による返金トラブル** | やけど、色素沈着、硬毛化、毛嚢炎。**医師が対応できる** |
| **トラブル時** | 提携医療機関へ紹介（自己負担のことも） | **その場で医師が処置**、薬の処方 |

## 契約で確認すること

| 項目 | 確認内容 |
|---|---|
| **総額** | **回数・部位・期間・有効期限**を書面で。**「月額〇円」は総額の分割表示**であることが多い。**シェービング代・キャンセル料・麻酔代**の有無 |
| **クーリングオフ** | **5万円超・1か月超の契約は「特定継続的役務提供」**にあたり、**契約書面受領から8日間は無条件解約可**（特定商取引法） |
| **中途解約** | **8日を過ぎても中途解約可**。**解約料の上限：施術前は2万円、施術後は2万円か残額の10%のいずれか低い方**＋提供済みサービスの代金。**この上限はエステティックのもので、医療脱毛（美容医療）は別に定められています**（消費者庁の特定商取引法ガイドで確認を） |
| **前払い** | **倒産すると返金されない**ことが多い（2022〜2023年の大手破産で数万人が被害）。**都度払い・少ない回数・クレジットの分割（抗弁権）**でリスクを下げる |
| **勧誘** | **「今日契約すれば」「無料カウンセリングから高額契約」**は典型的なパターン。**その場で決めない** |
| **リスク説明** | **やけど・硬毛化・色素沈着**の説明と、起きたときの対応・費用負担 |
| **医療脱毛の場合** | **医師の診察があるか**、**看護師が施術するか**、**トラブル時の対応** |
| **日焼け・薬** | **日焼け肌は施術不可**（やけどのリスク）、**光線過敏の薬**を飲んでいる人は要相談 |

- **国民生活センターの相談**：脱毛サロンに関する相談は**年間数千件**、**解約・返金・倒産**が中心。**医療脱毛でも「効果がない」「やけど」「解約できない」**の相談がある。
- **「永久脱毛」の表示**：**サロンが「永久脱毛」と表示すると医師法・景表法上の問題**。「永久」と書いてあるサロンは避ける判断材料になる。
- **家庭用脱毛器**は出力がさらに低く、減毛の補助（別記事参照）。
- **VIO・顔**：**粘膜に近く、やけど・色素沈着のリスクが高い部位**。**医療脱毛の方が対応しやすい**。
- **未成年**：**保護者の同意が必要**。**成長期はホルモンで再生しやすい**ため、効果が持続しにくい面も。
- **ワキガ・多汗症**への効果をうたう脱毛は根拠が乏しい（脱毛でわき汗は減らない）。

> **【要検証】** 特定商取引法の中途解約料の上限、2001年の厚生労働省通知（医師法と脱毛）は法令原文で、国民生活センターの相談件数は最新年で確認してください。

## 誤解1｜サロンでも永久脱毛できる

**毛根を破壊する行為は医療行為で、サロンは「減毛・抑毛」までです。** 「永久脱毛」を掲げるサロンは法令上問題があります。

## 誤解2｜サロンは安い

**回数が多く、追加契約・倒産リスクを含めると総額は医療脱毛と大差ないことも。** 総額・回数・期限で比べる。

## 誤解3｜一度契約したら解約できない

**8日間はクーリングオフ、以降も中途解約が法律で認められ、解約料に上限があります。** 「解約不可」と言われたら消費生活センター（188）へ。

## 誤解4｜回数無制限・通い放題なら安心

**倒産すれば前払い分は戻らないことが多い**です。都度払いか少ない回数から。

## 誤解5｜医療脱毛なら副作用はない

**やけど・色素沈着・硬毛化・毛嚢炎は医療脱毛でも起きます。** 違いは「その場で医師が対応できる」こと。リスク説明を受けて契約を。
