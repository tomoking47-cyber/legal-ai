# Q. 日本的脱毛沙龙与医疗诊所有什么区别？签约前该确认什么？｜Japan Questions #568

- Shelf: `beauty` ／ URL: `/zh-cn/beauty/hair-removal-salons-vs-clinics` ／ Status: **草稿 — 出处未核实**

脱毛（「脱毛」，datsumō）是日本广告投放最密集的美容服务之一。很多人在没弄清「沙龙」（脱毛サロン）与「诊所」（医療脱毛，医疗脱毛）区别的情况下就签了合同，而日本国民生活中心每年都会收到数千件关于解约、公司破产和烫伤的投诉。本文说明两者各自的原理，以及合同中该确认的内容。

## A. 医疗脱毛属于**医疗行为**：在诊所里由医生或护士使用激光破坏毛囊，可以期待接近永久性的脱毛效果（毛不再长出来）。脱毛沙龙使用输出功率更低的光（IPL）来做「减毛・抑毛」；依法不得破坏毛囊，因此效果从暂时性到长期性减毛不等，所需次数也多得多。沙龙看上去更便宜，但加上更多的次数、追加合同以及破产风险（2022～2023 年有多家大型连锁破产），总额有时与医疗脱毛相差无几。签约前请确认：① 总价、次数、期限与有效期；② 解约条款（这类合同在日本法律上属于「特定继续性役务提供」，有 8 天的冷静期，并可中途解约）；③ 尽量不预付（按次付款或只购买少量次数）；④ 要求说明风险 —— 烫伤、硬毛化、色素沉着 —— 以及发生时如何处理。

## 沙龙脱毛与医疗脱毛的比较

| 项目 | 脱毛沙龙（美容） | 医疗脱毛（诊所） |
|---|---|---|
| **由谁操作** | 美容师（无需执照） | **医生或护士** |
| **设备与输出** | **光类设备（IPL、SHR 等）**。输出被限制在**无法破坏毛囊的水平** | **医用激光（翠绿宝石、半导体、Nd:YAG）**。**输出足以破坏毛囊** |
| **法律定位** | **无医师执照而破坏毛囊违反《医师法》**（厚生劳动省 2001 年通知）。只能做「减毛」或「抑毛」 | **医疗行为** |
| **效果** | **暂时性至长期性减毛。** **不得宣传「永久脱毛」** | **接近永久**（美国 FDA 的定义：处理后毛发再生的长期性减少） |
| **次数** | **12～18 次以上**（2～3 年） | **5～8 次**（1～1.5 年） |
| **疼痛** | 较轻 | **较强**（可使用麻醉膏） |
| **费用（全身，参考）** | **100,000～300,000 日元**（也有不限次数的方案） | **200,000～400,000 日元**（约 5 次） |
| **风险** | 烫伤、色素沉着、**硬毛化**（细毛变粗）、**公司破产时的退款问题** | 烫伤、色素沉着、硬毛化、毛囊炎。**有医生在场处理** |
| **出问题时** | 转介合作医疗机构（有时费用自理） | **医生当场处理**并开药 |

## 合同中该确认的内容

| 项目 | 需要确认的事项 |
|---|---|
| **总价** | 以书面确认**次数、部位、期限与有效期**。**「每月 X 日元」通常是总额的分期。** 是否另有**剃毛费、取消费、麻醉费** |
| **冷静期** | **金额超过 50,000 日元且期限超过一个月的合同属于「特定继续性役务提供」（特定継続的役務提供）**，因此**在收到书面合同后 8 天内可无条件解约**（《特定商取引法》） |
| **中途解约** | **过了 8 天仍可解约。** **解约费上限：尚未接受任何一次服务时为 20,000 日元；已开始接受服务后，为 20,000 日元与剩余金额的 10% 中较低者**，另加已接受服务部分的费用 |
| **预付款** | **公司破产时通常拿不回退款**（2022～2023 年的连锁破产中有数万名顾客蒙受损失）。可通过**按次付款、减少购买次数，或使用信用卡分期（对信用卡公司享有抗辩权）**来降低风险 |
| **推销压力** | **「只有今天签才有这个价」「免费咨询 → 高价合同」**是典型套路。**不要当场做决定** |
| **风险说明** | 关于**烫伤、硬毛化、色素沉着**的说明，以及发生时由谁处理、由谁承担费用 |
| **医疗脱毛方面** | **是否有医生诊察**、**是否由护士施术**、**出问题时如何处理** |
| **晒黑与用药** | **晒黑的皮肤不能做**（烫伤风险）；**正在服用光敏性药物的人**请先咨询 |

- **向国民生活中心提出的投诉**：关于脱毛沙龙**每年数千件**，主要是**解约、退款与破产。** 医疗脱毛也有**「没有效果」「烫伤」「无法解约」**等投诉。
- **「永久脱毛」这个词**：**沙龙宣传「永久脱毛」（永久脱毛），在《医师法》与《景品表示法》上都有问题。** 说「永久」的沙龙，就是该掉头走开的理由。
- **家用脱毛仪**输出更低，属于减毛的辅助手段（另见本站相关文章）。
- **VIO（比基尼线与私密部位，日语用语）与面部**：**靠近黏膜，烫伤与色素沉着的风险更高。** **医疗脱毛更有条件处理。**
- **未成年人**：**需要监护人同意。** **发育期激素会让毛容易重新长出**，因此效果可能无法持久。
- 以**腋臭或多汗**为卖点的脱毛宣传，缺乏依据（去除毛发并不会减少腋下出汗）。

## 误解1｜沙龙也能做永久脱毛

**破坏毛囊属于医疗行为，沙龙只能做到「减毛」。** 宣传「永久」的沙龙是在违规。

## 误解2｜沙龙便宜

**加上更多次数、追加合同与破产风险，总额有时与医疗脱毛相差无几。** 请比较总价、次数与有效期。

## 误解3｜一旦签约就不能解约

**有 8 天冷静期，之后法律也允许中途解约，且解约费有上限。** 若被告知「不能解约」，请拨打消费者热线 188。

## 误解4｜不限次数的方案最保险

**公司破产时，预付款通常拿不回来。** 请按次付款，或从少量次数开始。

## 误解5｜医疗脱毛没有副作用

**烫伤、色素沉着、硬毛化与毛囊炎在医疗脱毛中同样会发生。** 区别在于有医生在场处理。请在听完风险说明后再签约。
