# Q. 日本的除毛沙龍與醫療診所有什麼不同？簽約前該確認什麼？｜Japan Questions #568

- Shelf: `beauty` ／ URL: `/zh-tw/beauty/hair-removal-salons-vs-clinics` ／ Status: **草稿 — 出處未核實**

除毛（「脱毛」，datsumō）是日本廣告投放最密集的美容服務之一。許多人在沒弄清「沙龍」（脱毛サロン）與「診所」（医療脱毛，醫療除毛）差別的情況下就簽了約，而日本國民生活中心每年都收到數千件關於解約、公司倒閉與燙傷的申訴。本文說明兩者各自的原理，以及合約中該確認的內容。

## A. 醫療除毛屬於**醫療行為**：在診所由醫師或護理師使用雷射破壞毛囊，可以期待接近永久的除毛效果（毛不再長出來）。除毛沙龍使用輸出較低的光（IPL）進行「減毛・抑毛」；依法不得破壞毛囊，因此效果從暫時性到長期性減毛不等，所需次數也多得多。沙龍看起來較便宜，但加上更多次數、追加合約以及倒閉風險（2022～2023 年有多家大型連鎖倒閉），總額有時與醫療除毛相差無幾。簽約前請確認：① 總價、次數、期間與有效期限；② 解約條款（這類合約在日本法律上屬於「特定繼續性役務提供」，有 8 天的猶豫期，並可中途解約）；③ 盡量不預付（按次付款或只買少量次數）；④ 要求說明風險 —— 燙傷、硬毛化、色素沉澱 —— 以及發生時如何處理。

## 沙龍除毛與醫療除毛的比較

| 項目 | 除毛沙龍（美容） | 醫療除毛（診所） |
|---|---|---|
| **由誰操作** | 美容師（不需執照） | **醫師或護理師** |
| **設備與輸出** | **光類設備（IPL、SHR 等）**。輸出被限制在**無法破壞毛囊的程度** | **醫用雷射（亞歷山大、二極體、Nd:YAG）**。**輸出足以破壞毛囊** |
| **法律定位** | **無醫師執照而破壞毛囊違反《醫師法》**（厚生勞動省 2001 年通知）。只能做「減毛」或「抑毛」 | **醫療行為** |
| **效果** | **暫時性至長期性減毛。** **不得宣傳「永久除毛」** | **接近永久**（美國 FDA 的定義：處理後毛髮再生的長期性減少） |
| **次數** | **12～18 次以上**（2～3 年） | **5～8 次**（1～1.5 年） |
| **疼痛** | 較輕 | **較強**（可使用麻醉藥膏） |
| **費用（全身，參考）** | **100,000～300,000 日圓**（也有不限次數的方案） | **200,000～400,000 日圓**（約 5 次） |
| **風險** | 燙傷、色素沉澱、**硬毛化**（細毛變粗）、**公司倒閉時的退費問題** | 燙傷、色素沉澱、硬毛化、毛囊炎。**有醫師在場處理** |
| **出狀況時** | 轉介合作醫療機構（有時費用自付） | **醫師當場處理**並開藥 |

## 合約中該確認的內容

| 項目 | 需要確認的事項 |
|---|---|
| **總價** | 以書面確認**次數、部位、期間與有效期限**。**「每月 X 日圓」通常是總額的分期。** 是否另有**剃毛費、取消費、麻醉費** |
| **猶豫期** | **金額超過 50,000 日圓且期間超過一個月的合約屬於「特定繼續性役務提供」（特定継続的役務提供）**，因此**在收到書面合約後 8 天內可無條件解約**（《特定商取引法》） |
| **中途解約** | **過了 8 天仍可解約。** **解約費上限：尚未接受任何一次服務時為 20,000 日圓；已開始接受服務後，為 20,000 日圓與剩餘金額的 10% 中較低者**，另加已接受服務部分的費用 |
| **預付款** | **公司倒閉時通常拿不回退款**（2022～2023 年的連鎖倒閉中有數萬名顧客蒙受損失）。可透過**按次付款、減少購買次數，或使用信用卡分期（對信用卡公司享有抗辯權）**來降低風險 |
| **推銷壓力** | **「只有今天簽才有這個價」「免費諮詢 → 高價合約」**是典型套路。**不要當場做決定** |
| **風險說明** | 關於**燙傷、硬毛化、色素沉澱**的說明，以及發生時由誰處理、由誰負擔費用 |
| **醫療除毛方面** | **是否有醫師診察**、**是否由護理師施術**、**出狀況時如何處理** |
| **曬黑與用藥** | **曬黑的皮膚不能做**（燙傷風險）；**正在服用光敏性藥物的人**請先諮詢 |

- **向國民生活中心提出的申訴**：關於除毛沙龍**每年數千件**，主要是**解約、退費與倒閉。** 醫療除毛也有**「沒有效果」「燙傷」「無法解約」**等申訴。
- **「永久除毛」這個說法**：**沙龍宣傳「永久脱毛」（永久除毛），在《醫師法》與《景品表示法》上都有問題。** 說「永久」的沙龍，就是該掉頭走人的理由。
- **家用除毛儀**輸出更低，屬於減毛的輔助工具（另見本站相關文章）。
- **VIO（比基尼線與私密部位，日語用語）與臉部**：**靠近黏膜，燙傷與色素沉澱的風險更高。** **醫療除毛更有條件處理。**
- **未成年人**：**需要監護人同意。** **發育期荷爾蒙會讓毛容易重新長出**，因此效果可能無法持久。
- 以**腋下體味或多汗**為賣點的除毛宣傳，缺乏依據（除去毛髮並不會減少腋下出汗）。

> **[待核實]** 《特定商取引法》規定的解約費上限，以及厚生勞動省 2001 年通知（《醫師法》與除毛）請對照原文核對；國民生活中心的申訴數字請對照最新年度核對。

## 誤解1｜沙龍也能做永久除毛

**破壞毛囊屬於醫療行為，沙龍只能做到「減毛」。** 宣傳「永久」的沙龍是在違規。

## 誤解2｜沙龍比較便宜

**加上更多次數、追加合約與倒閉風險，總額有時與醫療除毛相差無幾。** 請比較總價、次數與有效期限。

## 誤解3｜一旦簽約就不能解約

**有 8 天猶豫期，之後法律也允許中途解約，且解約費有上限。** 若被告知「不能解約」，請撥打消費者專線 188。

## 誤解4｜不限次數的方案最保險

**公司倒閉時，預付款通常拿不回來。** 請按次付款，或從少量次數開始。

## 誤解5｜醫療除毛沒有副作用

**燙傷、色素沉澱、硬毛化與毛囊炎在醫療除毛同樣會發生。** 差別在於有醫師在場處理。請在聽完風險說明後再簽約。
