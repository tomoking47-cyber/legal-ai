# Q. 帶妝睡覺到底會發生什麼？隔天早上怎麼補救？｜Japan Questions #569

- Shelf: `beauty` ／ URL: `/zh-tw/beauty/sleeping-in-makeup` ／ Status: **草稿 — 出處未核實**

累到回家倒頭就睡，妝也沒卸。在日本常聽到「帶妝睡一晚，皮膚老化 X 天」的說法。本文冷靜地看看實際會發生什麼、隔天早上如何補救，以及在明知可能會睡著的夜晚，至少要做到什麼。

## A. 帶妝睡覺時，皮脂、汗水、灰塵與彩妝會在皮膚上停留整整一晚（6～8 小時），可能造成毛孔堵塞、痘痘、暗沉與乾燥。眼妝尤其可能引起眼周色素沉澱與睫毛根部的發炎（瞼板腺阻塞、針眼）。「老化 X 天」這類說法沒有科學依據；偶爾一次，只要隔天早上仔細卸妝並做好保濕，不會留下長期影響。但若成為習慣，差別就會顯現出來。在可能會睡著的夜晚，最低限度是：一到家就先卸妝（在換衣服之前），實在做不到，就至少用卸妝濕巾擦掉眼部與嘴部的妝。

## 帶妝睡覺時會發生什麼

| 部位 | 會發生什麼 | 影響 |
|---|---|---|
| **整張臉** | **皮脂、汗水、灰塵與彩妝形成的一層**在皮膚上停留 6～8 小時。**妨礙皮膚更新（夜間最活躍）** | **毛孔堵塞、痘痘、暗沉、乾燥（一方面油分擋住水分蒸發，另一方面彩妝中的界面活性劑與酒精又讓皮膚變乾）** |
| **眼部** | **眼線與睫毛膏堵住睫毛根部的油脂腺（瞼板腺）。** **與寢具摩擦造成色素沉澱** | **針眼、眼瞼發炎、乾眼、眼下褐色黑眼圈** |
| **嘴唇** | 口紅或唇釉使其變乾 | 脫皮 |
| **枕頭與寢具** | 彩妝沾上去，**皮脂與微生物孳生**，隔天晚上又睡在上面 | 臉部痘痘與刺激的間接原因 |
| **「老化 X 天」** | **沒有依據。** 一晚不會造成永久性改變 | **但作為習慣，毛孔與膚況的差異確實會出現** |

## 隔天早上的補救

1. **仔細卸妝**：**在乾燥的皮膚上使用卸妝油或卸妝膏，不搓揉，畫圈 40 秒至 1 分鐘直到乳化** → 用溫水沖淨。眼妝請**先用沾了眼唇卸妝液的化妝棉在眼上敷 5～10 秒**。
2. **洗臉**：溫和的泡沫。**用力搓、用熱水、連著洗兩次**都有害。
3. **保濕**：**先用化妝水（化粧水），再稍多用一些乳液（乳液）或乳霜。** 皮膚乾燥時用**面膜**也可以，但如果有發紅或刺痛感反而會刺激 —— 只做保濕。
4. **當天的妝**：**盡量清淡**，或**只擦防曬加局部彩妝**，讓皮膚休息。
5. **眼睛**：若有**發紅、發癢或異物感**，不要去碰；若持續不退，請就診眼科（日本的健康保險適用）。**用棉花棒沾溫水輕輕擦拭瞼緣**（眼瞼清潔）。
6. **更換枕頭套。**

## 可能會睡著的夜晚，最低限度要做的

| 情況 | 最低限度的動作 |
|---|---|
| **剛到家，還能動** | **在換衣服之前直接進浴室卸妝。** 「換完衣服再卸」從來都不會發生 |
| **癱在沙發上** | **眼部、嘴部與其餘部分各用一張卸妝濕巾**（另見本站相關文章），**擦上乳液再睡** |
| **喝了點酒** | **喝水，至少把眼妝擦掉。** 早上再好好卸妝 |
| **已經安排了晚上外出** | **從早上就化「好卸」的妝**（不用防水型，選口紅而不是唇釉）。**包包裡帶上濕巾與小瓶乳液** |

- **什麼時候卸妝**：**一到家**最理想，**晚餐前**也可以。皮膚科醫師的經驗法則**「妝不要帶超過 8～10 小時」**，是因為超過之後皮脂與彩妝的混合會進一步發展。
- **卸妝後還要再洗一次嗎**：卸妝之後洗一次臉就夠了。
- **不化妝的日子也要卸防曬**：**防曬乳算作彩妝**；洗面乳洗不掉的產品需要用卸妝產品。
- **和打瞌睡的小孩不同**，成人的皮膚**恢復得更慢**，所以偶爾一次沒關係，但不要變成習慣。

> **[待核實]** 瞼板腺阻塞與眼妝的關聯，是眼科的一般解釋。請對照日本眼科學會與日本皮膚科學會的資料核對。

## 誤解1｜帶妝睡一晚，皮膚會老化 X 天

**這個說法沒有依據。** 但皮脂與彩妝形成的一層確實會造成毛孔堵塞、痘痘與暗沉，作為習慣，差別會顯現出來。

## 誤解2｜偶爾一次完全不用管

**隔天早上仔細卸妝保濕，再換個枕頭套，就不會留下真正的損害。** 眼睛發紅時不要去碰。

## 誤解3｜隔天早上用力搓洗來補回來

**摩擦與過度清潔給皮膚的負擔，比殘留的彩妝更大。** 請用卸妝油或卸妝膏、不搓揉，再洗一次泡沫臉。

## 誤解4｜眼妝又不會跑進眼睛裡，留著也沒關係

**它會堵住睫毛根部的油脂腺，引起針眼、眼瞼發炎與乾眼。** 卸任何妝時，眼睛都排在第一位。

## 誤解5｜換完衣服再卸

**換衣服、坐下、睡著 —— 這是經典的順序。** 一到家，先進浴室，再開衣櫃。
