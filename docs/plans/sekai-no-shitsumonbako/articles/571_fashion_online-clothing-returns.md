# Q. ネット通販で買った服が合わない。返品できる？クーリングオフは？｜世界の質問箱 #571

- 棚：`fashion` ／ URL：`/questions/online-clothing-returns` ／ ステータス：**ドラフト（法務レビュー前・出典未検証）**

服はネットで買う時代になりましたが、「サイズが合わなかった」「色が違った」ときに返品できるかは、店ごとに違います。「ネット通販はクーリングオフできる」と思っている人が多いのですが、実は法律上の権利ではありません。ルールと、失敗を減らす買い方を整理します。

## A. ネット通販（通信販売）には法律上のクーリングオフはありません。返品できるかどうかは、各店が表示する「返品特約」に従います。特定商取引法では、返品特約を表示していない店の場合のみ「商品到着から8日以内なら送料自己負担で返品可」と定められています。多くの大手は「未使用・タグ付き・到着後7〜30日以内」で返品を受け付け、送料はサイズ交換なら無料、自己都合なら有料、と分かれます。下着・水着・セール品は返品不可が多い。失敗を減らすには、①持っている服の実寸（肩幅・身幅・着丈・袖丈）をメモして商品の実寸表と比べる、②レビューの「サイズ感」を読む、③返品特約を注文前に確認する、の3点です。

## 返品のルール

| 項目 | 内容 |
|---|---|
| **クーリングオフ** | **通信販売には法律上のクーリングオフ制度はない**（訪問販売・電話勧誘などが対象）。「ネット通販はクーリングオフできる」は誤解 |
| **返品特約** | **各店が表示する返品条件が優先**（特定商取引法11条・15条の3）。**注文前に「返品について」「特定商取引法に基づく表記」を確認** |
| **特約の表示がない場合** | **商品到着から8日以内、送料は購入者負担で返品可**（法定返品権） |
| **典型的な条件** | **未使用・タグ付き・付属品あり・到着後7〜30日以内**。**試着はOK、洗濯・着用・においが付いたものは不可**が一般的 |
| **返品不可が多いもの** | **下着・水着・靴下・セール品・受注生産・海外発送・名入れ** |
| **送料** | **サイズ・色交換は無料、自己都合返品は有料（500〜1,000円）、不良品・誤配は店負担**が多い |
| **不良品・誤配** | **返品特約に関係なく、契約不適合として交換・返金を求められる**（民法）。写真を撮って連絡 |
| **海外通販** | **日本の法律が適用されない**ことが多く、返品送料が商品代を超えることも。**関税・消費税**も別途 |

## サイズ選びで失敗を減らす

| 手順 | 内容 |
|---|---|
| **1. 持っている服を測る** | 気に入っている服の**肩幅・身幅（胸囲÷2）・着丈・袖丈**、パンツは**ウエスト・ヒップ・股上・股下・わたり幅・裾幅**を平置きで測ってメモ |
| **2. 商品の「実寸」と比べる** | **「M」「9号」ではなく実寸表**を見る。ブランドで**同じSでも2〜5cm違う**。**ヌード寸法（体のサイズ）と製品寸法（服のサイズ）**を混同しない（別記事「サイズ表示」参照） |
| **3. レビュー** | **「普段Mだが大きめ」「生地が薄い」**などのサイズ感・素材感。**身長・体重を書いたレビュー**が参考になる |
| **4. 素材と伸縮** | **綿だけの生地は伸びない、ポリウレタン混は伸びる、ニットは伸びる**。**洗濯での縮み**（綿・麻・レーヨンは縮む）も考慮 |
| **5. 試着サービス** | **自宅試着（Amazonのプライム・トライ、ZOZOの返品無料期間）**、**店舗受け取り・店舗返品**があるブランド |
| **6. 返品特約を注文前に読む** | **期限、送料、状態の条件、返金方法（ポイント返金のみの店も）** |

- **試着の作法**：**タグを外さない、化粧・香水が付かないよう注意、室内で短時間、床を歩かない（靴）**。**返品を前提に複数サイズを注文**する人もいるが、店によっては**返品率が高い客のアカウント制限**の例もある。
- **返品の手順**：**店のマイページか連絡先から申請→返送方法の指示→期限内に発送→返金（1〜2週間）**。**着払い可否、伝票番号の保管**。**申請なしで送り返すと受け取られないことがある**。
- **フリマ・個人間売買（メルカリ等）**：**返品は原則不可**（「ノークレーム・ノーリターン」）。**説明と違う・不良の場合は事務局を通す**。
- **定期購入・サブスク**：**「初回無料」から定期契約になる**トラブルが多い。**解約条件を確認**、**特定商取引法で最終確認画面の表示義務**（2021年改正・2022年6月1日施行）。
- **困ったら**：**消費生活センター（188）**。**返品特約を表示していないのに返品を拒む**、**不良品の交換を拒む**は相談対象。

> **【要検証】** 特定商取引法の法定返品権（8日）、返品特約の表示義務、2022年改正の最終確認画面の規定は消費者庁の資料で確認してください。

## 誤解1｜ネット通販はクーリングオフできる

**法律上のクーリングオフは通信販売にはありません。** 返品できるかは店の返品特約次第。注文前に確認。

## 誤解2｜サイズが合わなければ必ず返品できる

**自己都合の返品は店のルールに従います。** 特約の表示がない店だけ、8日以内・送料自己負担で返品可。

## 誤解3｜「M」なら他のブランドのMと同じ

**同じ表記でも実寸が2〜5cm違います。** 持っている服の実寸と、商品の実寸表を比べる。

## 誤解4｜不良品でも「返品不可」と書いてあれば諦める

**不良品・誤配は返品特約に関係なく交換・返金を求められます。** 写真を撮って連絡、応じなければ消費生活センター。

## 誤解5｜海外通販も日本と同じように返品できる

**日本の法律が及ばず、返品送料や関税で損をすることが多い**です。返品前提の買い方は避ける。
