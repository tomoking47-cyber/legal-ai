# Q. 网上买的衣服不合身。能退货吗？有冷静期吗？｜Japan Questions #571

- Shelf: `fashion` ／ URL: `/zh-cn/fashion/online-clothing-returns` ／ Status: **草稿 — 出处未核实**

现在大多数人都在网上买衣服，但尺码或颜色不对的商品能不能退回去，要看店家。日本有很多人以为网购在法律上享有「冷静期」（cooling-off）。其实并没有。以下整理真正适用的规则，以及怎么买才能少退货。

## A. 网购（日本法律上称「通信販売」，即邮购销售）没有法定冷静期。能不能退货，取决于店家公示的「返品特約」（henpin tokuyaku，退货特约）。根据《特定商业交易法》（特定商取引法，日本针对远程销售与上门销售的消费者法律），只有在店家没有公示退货特约时，您才享有在收货后 8 天内自付退货运费退货的法定权利。多数大型零售商接受「未使用、吊牌完好、收货后 7–30 天内」的退货；换尺码往往免运费，个人原因退货则要收费。内衣、泳装和特价品通常不可退。要减少失败：（1）量下自己已有衣服的实际尺寸（肩宽、胸宽、衣长、袖长），与商品的尺寸表对照；（2）看评论里关于尺码感受的留言；（3）下单前先读退货特约。

## 退货规则

| 项目 | 内容 |
|---|---|
| **冷静期** | **网购／邮购销售没有法定冷静期**（适用对象是上门销售与电话推销）。「网购可以冷静期退货」是误解 |
| **退货特约（返品特約）** | **各店公示的退货条件优先**（《特定商业交易法》第 11 条、第 15 条之 3）。**下单前请查看「退货说明」页与「特定商取引法に基づく表記」（基于特定商业交易法的标示）页** |
| **没有公示特约时** | **可在收货后 8 天内退货，退货运费由购买者自付**（法定退货权） |
| **典型条件** | **未使用、吊牌完好、附件齐全、收货后 7–30 天内**。通常是**可以试穿，但洗过、穿过或沾上气味的不予受理** |
| **常见不可退的商品** | **内衣、泳装、袜子、特价品、订制生产、海外发货、刻字定制品** |
| **运费** | 常见做法是**换尺码或换颜色免运费；个人原因退货收费（¥500–1,000）；次品或发错货由店家承担** |
| **次品或发错货** | **无论退货特约如何，都可以以不符合合同为由要求换货或退款**（民法）。请拍照后联系店家 |
| **海外网店** | **日本法律往往不适用**，退货运费还可能超过商品本身的价格。**关税与消费税**也另计 |

## 减少尺码失误

| 步骤 | 内容 |
|---|---|
| **1. 量一量自己已有的衣服** | 把一件喜欢的衣服平铺，量**肩宽、胸宽（胸围÷2）、衣长、袖长**；裤子量**腰围、臀围、前裆、内长、大腿宽、裤口宽** |
| **2. 与商品的「实际尺寸」对照** | **看尺寸表，而不是「M」或「9 号」**。**同样是 S，不同品牌能差 2–5 cm**。不要把**净体尺寸（人体）与成衣尺寸（衣服）**弄混（参见我们关于尺码标示的文章） |
| **3. 评论** | 关于版型和面料的留言，例如**「我平时穿 M，这件偏大」「面料偏薄」**。**写明身高体重的评论**最有参考价值 |
| **4. 面料与弹性** | **纯棉面料不伸缩；含聚氨酯的会伸缩；针织会伸缩**。还要考虑**洗涤缩水**（棉、麻、粘胶纤维会缩） |
| **5. 试穿服务** | **在家试穿（Amazon Prime Try Before You Buy、ZOZO 的免费退货期）**；提供**门店取货与门店退货**的品牌 |
| **6. 下单前读退货特约** | **期限、运费、状态要求、退款方式（有的店只退积分）** |

- **试穿的规矩**：**不要摘吊牌；注意别蹭上化妆品或香水；在室内短时间试；试鞋时不要穿着在地上走**。有人**一次订几个尺码，打算把其余的退掉**，但有些店已经**对退货率高的顾客限制账号**。
- **退货流程**：**通过店家的个人页面或联系方式申请 → 按退货指示操作 → 在期限内寄出 → 退款（1–2 周）**。请确认**退货是否可以到付，并保留运单号**。**未先申请就寄回的包裹可能被拒收**。
- **二手交易 App 与个人间买卖（Mercari 等）**：**原则上不接受退货**（「不投诉、不退货」）。**若商品与描述不符或有瑕疵，请通过平台的客服窗口处理**。
- **定期购买与订阅**：很多纠纷源于**「首单免费」的优惠变成了持续合同**。**请确认解约条件**；**《特定商业交易法》要求设置最终确认页面**（2022 年修订）。
- **遇到麻烦时**：拨打**消费生活中心热线（188）**（消費生活センター，地方消费者咨询服务）。店家**没有公示退货特约却拒绝退货**，或**拒绝更换次品**，都属于可以咨询的情形。

> **[待核实]** 《特定商业交易法》的法定退货权（8 天）、退货特约的公示义务，以及 2022 年修订的最终确认页面规定，请对照消费者厅的资料确认。

## 误解1｜网购有冷静期

**邮购销售没有法定冷静期。** 能否退货取决于店家的退货特约。下单前先确认。

## 误解2｜尺码不对总归能退

**个人原因的退货要遵守店家的规则。** 只有在店家没有公示特约时，才能在 8 天内自付运费退货。

## 误解3｜「M」和别的品牌的 M 一样大

**同样的标示，实际尺寸能差 2–5 cm。** 请把自己已有衣服的实际尺寸和商品的尺寸表对照。

## 误解4｜写了「不可退货」，次品也只能认了

**次品或发错货，无论退货特约如何都可以要求换货或退款。** 拍照后联系店家；对方不予受理就打给消费生活中心。

## 误解5｜海外网店和日本的一样可以退货

**日本法律管不到，退货运费和关税常常让人吃亏。** 不要抱着「反正能退」的心态下单。
