# Q. 網購買的衣服不合身。可以退貨嗎？有猶豫期嗎？｜Japan Questions #571

- Shelf: `fashion` ／ URL: `/zh-tw/fashion/online-clothing-returns` ／ Status: **草稿 — 出處未核實**

現在大多數人都在網路上買衣服，但尺寸或顏色不對的商品能不能退回去，要看店家。日本有很多人以為網購在法律上享有「猶豫期」（冷靜期，cooling-off）。其實並沒有。以下整理真正適用的規則，以及怎麼買才能少退貨。

## A. 網購（日本法律上稱「通信販売」，即通信販售）沒有法定猶豫期。能不能退貨，取決於店家公告的「返品特約」（henpin tokuyaku，退貨特約）。依《特定商業交易法》（特定商取引法，日本針對遠距銷售與登門銷售的消費者法律），只有在店家沒有公告退貨特約時，您才享有在收到商品後 8 天內自付退貨運費退貨的法定權利。多數大型零售商接受「未使用、吊牌完好、收到後 7–30 天內」的退貨；換尺寸通常免運費，個人因素退貨則要付費。內衣、泳衣和特價品通常不可退。要減少失敗：（1）量一下自己已有衣服的實際尺寸（肩寬、胸寬、衣長、袖長），與商品的尺寸表對照；（2）看評論裡關於尺寸感受的留言；（3）下單前先讀退貨特約。

## 退貨規則

| 項目 | 內容 |
|---|---|
| **猶豫期（冷靜期）** | **網購／通信販售沒有法定猶豫期**（適用對象是登門銷售與電話推銷）。「網購可以主張冷靜期退貨」是誤解 |
| **退貨特約（返品特約）** | **各店公告的退貨條件優先**（《特定商業交易法》第 11 條、第 15 條之 3）。**下單前請查看「退貨說明」頁與「特定商取引法に基づく表記」（依特定商業交易法之標示）頁** |
| **沒有公告特約時** | **可在收到商品後 8 天內退貨，退貨運費由購買者自付**（法定退貨權） |
| **典型條件** | **未使用、吊牌完好、附件齊全、收到後 7–30 天內**。通常是**可以試穿，但洗過、穿過或沾上氣味的不予受理** |
| **常見不可退的商品** | **內衣、泳衣、襪子、特價品、訂製生產、海外出貨、刻字客製品** |
| **運費** | 常見做法是**換尺寸或換顏色免運費；個人因素退貨要付費（¥500–1,000）；瑕疵品或出錯貨由店家負擔** |
| **瑕疵品或出錯貨** | **無論退貨特約如何，都可以以不符合契約為由要求換貨或退款**（民法）。請拍照後聯絡店家 |
| **海外網購** | **日本法律往往不適用**，退貨運費還可能超過商品本身的價格。**關稅與消費稅**也另計 |

## 減少尺寸挑錯

| 步驟 | 內容 |
|---|---|
| **1. 量一量自己已有的衣服** | 把一件喜歡的衣服平放，量**肩寬、胸寬（胸圍÷2）、衣長、袖長**；褲子量**腰圍、臀圍、前檔、內長、大腿寬、褲口寬** |
| **2. 與商品的「實際尺寸」對照** | **看尺寸表，而不是「M」或「9 號」**。**同樣是 S，不同品牌可以差 2–5 cm**。不要把**淨體尺寸（人體）與成衣尺寸（衣服）**搞混（參見我們關於尺寸標示的文章） |
| **3. 評論** | 關於版型與布料的留言，例如**「我平常穿 M，這件偏大」「布料偏薄」**。**寫明身高體重的評論**最有參考價值 |
| **4. 布料與彈性** | **純棉布料不會伸縮；含聚氨酯的會伸縮；針織會伸縮**。還要考慮**洗滌縮水**（棉、麻、嫘縈會縮） |
| **5. 試穿服務** | **在家試穿（Amazon Prime Try Before You Buy、ZOZO 的免費退貨期間）**；提供**門市取貨與門市退貨**的品牌 |
| **6. 下單前讀退貨特約** | **期限、運費、狀態要求、退款方式（有些店只退點數）** |

- **試穿的規矩**：**不要拆吊牌；小心別沾上化妝品或香水；在室內短時間試；試鞋時不要穿著在地板上走**。有人**一次訂好幾個尺寸，打算把其餘的退掉**，但有些店已經**對退貨率高的顧客限制帳號**。
- **退貨流程**：**透過店家的會員頁面或聯絡窗口申請 → 依退貨指示操作 → 在期限內寄出 → 退款（1–2 週）**。請確認**退貨是否可以貨到付款，並保留託運單號**。**沒有先申請就寄回的包裹可能被拒收**。
- **二手交易 App 與個人間交易（Mercari 等）**：**原則上不接受退貨**（「不客訴、不退貨」）。**若商品與說明不符或有瑕疵，請透過平台的客服窗口處理**。
- **定期購買與訂閱**：很多糾紛源自**「首單免費」的優惠變成了持續契約**。**請確認解約條件**；**《特定商業交易法》要求設置最終確認畫面**（2022 年修正）。
- **遇到麻煩時**：撥打**消費生活中心專線（188）**（消費生活センター，地方的消費者諮詢服務）。店家**沒有公告退貨特約卻拒絕退貨**，或**拒絕更換瑕疵品**，都屬於可以諮詢的情形。

> **[待核實]** 《特定商業交易法》的法定退貨權（8 天）、退貨特約的公告義務，以及 2022 年修正的最終確認畫面規定，請對照消費者廳的資料確認。

## 誤解1｜網購有猶豫期

**通信販售沒有法定猶豫期。** 能否退貨取決於店家的退貨特約。下單前先確認。

## 誤解2｜尺寸不對總是可以退

**個人因素的退貨要遵守店家的規則。** 只有在店家沒有公告特約時，才能在 8 天內自付運費退貨。

## 誤解3｜「M」和別的品牌的 M 一樣大

**同樣的標示，實際尺寸可以差 2–5 cm。** 請把自己已有衣服的實際尺寸和商品的尺寸表對照。

## 誤解4｜寫了「不可退貨」，瑕疵品也只能認了

**瑕疵品或出錯貨，無論退貨特約如何都可以要求換貨或退款。** 拍照後聯絡店家；對方不受理就打給消費生活中心。

## 誤解5｜海外網購和日本一樣可以退貨

**日本法律管不到，退貨運費和關稅常常讓人吃虧。** 不要抱著「反正可以退」的心態下單。
