# Q. 靴のサイズ、どう選べば足が痛くならない？試着のコツ｜世界の質問箱 #575

- 棚：`fashion` ／ URL：`/questions/shoe-fit` ／ ステータス：**ドラフト（法務レビュー前・出典未検証）**

「サイズは合っているのに痛い」「夕方になると靴がきつい」。足の形は長さだけでなく幅・甲の高さ・指の形で違い、日本の靴には「E・2E・3E」という幅の表示もあります。試着のコツと、痛みの原因別の対処を整理します。

## A. 靴は「長さ」「幅（ウィズ）」「かかとの収まり」「つま先の余裕」の4点で選びます。試着は足がむくむ夕方に、普段はく靴下で、両足を履いて店内を歩き、かかとが浮かない・指先に1cm前後の余裕（捨て寸）がある・幅が横から押されない・甲が痛くないことを確認。日本人は幅広・甲高が多いと言われますが、実際は個人差が大きく、幅が合っていない靴を「サイズを上げて」買うと、長すぎてかかとが浮き、別の痛みが出ます。幅で困るなら、同じ長さで幅の違うサイズ（2E・3E・4E）を出しているブランドや、紐で調整できるデザインを。夕方むくむ人は朝と夕方で0.5cm前後変わることを前提に。

## 試着の手順

| 手順 | 内容 | 理由 |
|---|---|---|
| **1. 時間帯** | **夕方以降**（足は夕方に**0.5〜1cm近く**むくむ人も） | 朝に合わせると夕方きつい |
| **2. 靴下** | **その靴と合わせる靴下**（厚手なら厚手） | 厚さで**0.5cm**変わる |
| **3. 両足で** | **左右で大きさが違う**（多くの人で数mm）ので**大きい方に合わせる** | 片足だけの試着は失敗のもと |
| **4. かかと** | **かかとを合わせて紐・ストラップを締める**。**歩いてかかとが浮かない** | かかとが浮く＝長い、または幅が広すぎる |
| **5. つま先** | **一番長い指の先に0.5〜1cm（捨て寸）の余裕**。**指が動く** | 歩くと足は前に**1cm**ほどずれる |
| **6. 幅** | **小指の付け根・親指の付け根が横から押されない**。**甲が締まらない** | 幅が合わないと**外反母趾・タコ**の原因 |
| **7. 歩く** | **店内を数分歩く**、**しゃがむ・階段**（あれば） | 立っているだけではわからない |
| **8. 足長を測る** | **年に1回、店のフットゲージで計測**（**大人でも足のサイズは加齢・体重・妊娠で変わる**） | 「昔から24cm」は当てにならない |

## 幅（ウィズ）の表示

| 表示 | 意味 | 目安 |
|---|---|---|
| **JIS（日本）** | **A〜E、2E（EE）、3E、4E、F、G**の順に幅広。**E〜2Eが標準的**、**3E以上が幅広** | 足囲（親指と小指の付け根を通る周囲）と足長で決まる |
| **海外** | **B（女性標準）、D（男性標準）、W・EE（幅広）**など | 日本の表示と対応は目安 |
| **表示がない靴** | 多くのファッション靴・スニーカーは幅表示なし | 試着で確認。**ブランドごとに木型が違う** |

## 痛みの原因と対処

| 症状 | 原因 | 対処 |
|---|---|---|
| **かかとが擦れる・靴擦れ** | かかとが浮く（長い・幅広い）、硬い素材 | **かかとパッド**、**絆創膏・靴擦れ防止テープを事前に**、**革は履き慣らす（短時間から）** |
| **小指・親指の付け根が痛い** | **幅が狭い** | 幅の広いサイズ、**ストレッチャー**（革のみ）、**サイズアップは不可**（長くなるだけ） |
| **つま先が当たる** | 長さが短い、**捨て寸不足**、**下り坂・むくみ** | 0.5cm上、**紐をしっかり締めて足を後ろに** |
| **甲が痛い** | 甲が低い靴、紐の締め過ぎ | 甲の高いモデル、**紐の通し方を変える（甲の部分を飛ばす）** |
| **足裏・かかとが痛い** | クッション不足、**アーチのサポート不足**、履き過ぎ | **インソール**（別記事参照）、靴底の減りを確認 |
| **夕方きつい** | むくみ | 夕方に試着、紐・ストラップで調整できる靴、**足を上げて休む** |
| **タコ・魚の目** | 幅・形が合わない靴の**繰り返し** | 靴を見直す、皮膚科で削る |

- **子どもの靴**：**3〜6か月ごとにサイズ確認**（**年に1〜2cm**伸びる）。**大きめを買う**と転倒・足の変形の原因。**捨て寸は0.5〜1cm**、**かかとがしっかり、つま先が広い、曲がる位置が指の付け根**。
- **ヒール**：**3〜5cm**が足への負担が少ない目安。**前滑り**で指が痛むなら**つま先のクッション**。
- **ネット購入**：**同じブランド・同じモデルの経験がある場合以外は試着**を。**返品可の店**で（別記事参照）。
- **足のトラブルが続く**：**外反母趾、扁平足、開張足**は靴選びだけでは解決しないことがある。**整形外科（足の外科）**で相談、**靴の専門店（シューフィッター在籍）**で計測。

> **【要検証】** 足のむくみ幅、捨て寸の目安、JISの足囲表示区分はシューフィッター協会・JIS S5037の資料で確認してください。

## 誤解1｜サイズ（cm）が合えば靴は合う

**長さだけでなく幅・甲・かかとの収まりが合わないと痛みます。** 4点で試着。

## 誤解2｜幅がきついならサイズを上げればいい

**長くなってかかとが浮き、別の痛みが出ます。** 幅の違うサイズ（2E・3E）か、別のブランドを。

## 誤解3｜朝に試着した方が正確

**足は夕方にむくむため、夕方の試着が現実に近い**です。

## 誤解4｜革靴は最初きつくても伸びるから小さめを買う

**幅は多少伸びますが長さは伸びません。** 捨て寸がない靴は伸びても指が当たり続けます。

## 誤解5｜自分の足のサイズは変わらない

**加齢・体重・妊娠・筋力低下で足長・幅は変わります。** 年に1回は計測を。
