# Q. 怎么挑鞋才不会磨脚？试穿的窍门｜Japan Questions #575

- Shelf: `fashion` ／ URL: `/zh-cn/fashion/shoe-fit` ／ Status: **草稿 — 出处未核实**

「尺码是对的，可就是疼。」「到了傍晚鞋子就变紧。」脚的差异不只在长度，还有宽度、脚背高度和脚趾形状。日本的鞋按脚长的厘米数标注尺码，很多鞋还带一个您在别处可能没见过的宽度代号——「E、2E、3E」。以下是试穿的窍门，以及按原因分类的疼痛对策。

## A. 挑鞋看四点：长度、宽度（ウィズ，「width」）、后跟的贴合，以及脚趾的余量。请在脚会肿的傍晚试穿，穿上您实际会配的袜子，两只脚都穿上，并在店里走一走。确认后跟不会脱出、脚趾前方有 1 cm 左右的余量（捨て寸 sute-zun，即「余量」）、宽度不会被从两侧挤压、脚背不疼。人们常说日本人的脚宽而脚背高，但实际上个体差异很大。如果宽度不合适却「往上加一码」，鞋就会变得太长，后跟脱出，换来另一种疼。宽度有问题时，请找同一长度提供不同宽度（2E、3E、4E）的品牌，或者可以用鞋带调节的款式。如果您的脚会肿，请预设它在早晚之间会变化 0.5 cm 左右。

## 试穿的步骤

| 步骤 | 做什么 | 原因 |
|---|---|---|
| **1. 时间段** | **傍晚以后**（有些人的脚会肿 **0.5 到接近 1 cm**） | 早上试合脚，傍晚就紧 |
| **2. 袜子** | **穿会与这双鞋搭配的袜子**（厚的就穿厚的） | 袜子厚度会让合脚度差 **0.5 cm** |
| **3. 两只脚** | **左右脚不一样大**（多数人差几毫米），所以**以大的那只为准** | 只试一只脚是失败的根源 |
| **4. 后跟** | **把脚跟顶到后面，再系鞋带或扣带**。**走一走，后跟不应脱出** | 后跟脱出 ＝ 太长，或者太宽 |
| **5. 脚趾** | **最长的脚趾前方留 0.5–1 cm 余量（捨て寸）**。**脚趾能活动** | 走路时脚会向前滑约 **1 cm** |
| **6. 宽度** | **小趾根部与拇趾根部没有被从两侧挤压**。**脚背没有被勒紧** | 宽度不对会造成**拇外翻与老茧** |
| **7. 走一走** | **在店里走几分钟**；**蹲下、试试台阶**（如果有的话） | 只是站着看不出问题 |
| **8. 量脚** | **每年一次，用店里的量脚器测量**（**成年人的脚也会随年龄、体重和怀孕而变化**） | 「我一直都是 24 cm」并不可靠 |

## 宽度代号

| 代号 | 含义 | 参考 |
|---|---|---|
| **JIS（日本）** | **A 到 E、2E（EE）、3E、4E、F、G**，依次变宽。**E–2E 是标准**；**3E 以上算宽** | 由足围（绕过拇趾与小趾根部的周长）与脚长决定 |
| **海外** | **B（女款标准）、D（男款标准）、W 或 EE（宽）**等 | 与日本代号的对应只是大致参考 |
| **没有代号** | 多数时装鞋和运动鞋没有宽度代号 | 靠试穿确认。**每个品牌用的楦型都不一样** |

## 疼痛的原因与对策

| 症状 | 原因 | 对策 |
|---|---|---|
| **后跟磨、起水泡** | 后跟脱出（太长或太宽）；材质偏硬 | **后跟垫**；**事先贴创可贴或防磨脚贴**；**皮鞋慢慢穿开（先短时间穿）** |
| **小趾或拇趾根部疼** | **太窄** | 换更宽的宽度尺码；**用撑鞋器**（仅限皮革）；**不要往上加一码**（那只会变长） |
| **脚趾顶到前面** | 太短；**捨て寸不够**；**下坡或水肿** | 大 0.5 cm；**把鞋带系紧，把脚固定在后面** |
| **脚背疼** | 鞋背太低；鞋带系太紧 | 换脚背较高的款式；**改变穿鞋带的方式（跳过脚背处的孔）** |
| **脚掌或脚跟疼** | 缓冲不足；**足弓支撑不足**；穿得太久 | **鞋垫**（另见相关文章）；检查鞋底磨损 |
| **傍晚变紧** | 水肿 | 傍晚试穿；选可以用鞋带或扣带调节的鞋；**把脚抬高休息** |
| **老茧、鸡眼** | **反复**穿宽度或形状不合的鞋 | 重新考虑鞋子；到皮肤科修掉（日本的医保可以覆盖） |

- **儿童鞋**：**每 3–6 个月确认一次尺码**（脚**每年长 1–2 cm**）。**买大了**会绊倒，也会造成足部变形。**捨て寸 0.5–1 cm**；**后跟要牢固，前掌要宽，弯折处要在脚趾根部**。
- **高跟鞋**：**3–5 cm** 是对脚负担较小的常见参考值。如果因为**向前滑**而脚趾疼，请用**前掌垫**。
- **网上买鞋**：**除非您已经熟悉同一品牌同一款式，否则请试穿**。选**接受退货的店**（另见相关文章）。
- **脚的问题持续存在**：**拇外翻、扁平足与开张足**未必靠选鞋就能解决。请去**整形外科（整形外科，足外科）**看诊，并到**有认证鞋类专家（shoe fitter）的专业鞋店**测量。

> **[待核实]** 水肿的幅度、捨て寸的参考值，以及 JIS 的足围宽度分级，请对照鞋类专家协会（FHA）的资料与 JIS S5037 确认。

## 误解1｜尺码（cm）对了鞋就合脚

**宽度、脚背和后跟贴合也得合适，否则就会疼。** 试穿时四点都要确认。

## 误解2｜宽度紧就往上加一码

**鞋会变长，后跟脱出，换来另一种疼。** 请试更宽的宽度（2E、3E）或换个品牌。

## 误解3｜早上试穿更准

**脚到傍晚会肿，所以傍晚试穿更接近实际情况。**

## 误解4｜皮革会撑开，所以买紧一点

**宽度会撑开一点，长度不会。** 没有捨て寸的话，就算皮革撑开了，脚趾还是会一直顶到前面。

## 误解5｜我的脚尺码从来不变

**年龄、体重、怀孕和肌肉流失都会改变脚长与脚宽。** 每年量一次。
