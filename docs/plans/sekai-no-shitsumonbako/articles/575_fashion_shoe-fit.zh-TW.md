# Q. 怎麼挑鞋才不會磨腳？試穿的訣竅｜Japan Questions #575

- Shelf: `fashion` ／ URL: `/zh-tw/fashion/shoe-fit` ／ Status: **草稿 — 出處未核實**

「尺寸是對的，可是就是痛。」「到了傍晚鞋子就變緊。」腳的差異不只在長度，還有寬度、腳背高度與腳趾形狀。日本的鞋以腳長的公分數標示尺寸，很多鞋還帶一個您在別處可能沒看過的寬度代號——「E、2E、3E」。以下是試穿的訣竅，以及依原因分類的疼痛對策。

## A. 挑鞋看四點：長度、寬度（ウィズ，「width」）、後跟的貼合，以及腳趾的餘裕。請在腳會腫的傍晚試穿，穿上您實際會搭配的襪子，兩隻腳都穿上，並在店裡走一走。確認後跟不會脫出、腳趾前方有 1 cm 左右的餘裕（捨て寸 sute-zun，即「餘裕」）、寬度不會被從兩側擠壓、腳背不痛。大家常說日本人的腳寬又腳背高，但實際上個人差異很大。如果寬度不合卻「往上加一號」，鞋就會太長，後跟脫出，換來另一種痛。寬度有問題時，請找同一長度提供不同寬度（2E、3E、4E）的品牌，或者可以用鞋帶調整的款式。如果您的腳會腫，請預設它在早晚之間會變化 0.5 cm 左右。

## 試穿的步驟

| 步驟 | 做什麼 | 理由 |
|---|---|---|
| **1. 時段** | **傍晚以後**（有些人的腳會腫 **0.5 到接近 1 cm**） | 早上合腳，傍晚就緊 |
| **2. 襪子** | **穿會跟這雙鞋搭配的襪子**（厚的就穿厚的） | 襪子厚度會讓合腳度差 **0.5 cm** |
| **3. 兩隻腳** | **左右腳不一樣大**（多數人差幾公釐），所以**以大的那隻為準** | 只試一隻腳是失敗的根源 |
| **4. 後跟** | **把腳跟頂到後面，再繫鞋帶或扣帶**。**走一走，後跟不應脫出** | 後跟脫出 ＝ 太長，或者太寬 |
| **5. 腳趾** | **最長的腳趾前方留 0.5–1 cm 餘裕（捨て寸）**。**腳趾能活動** | 走路時腳會向前滑約 **1 cm** |
| **6. 寬度** | **小趾根部與大拇趾根部沒有被從兩側擠壓**。**腳背沒有被勒緊** | 寬度不對會造成**拇趾外翻與繭** |
| **7. 走一走** | **在店裡走幾分鐘**；**蹲下、試試樓梯**（若有的話） | 只是站著看不出問題 |
| **8. 量腳** | **每年一次，用店裡的量腳器測量**（**成年人的腳也會隨年齡、體重與懷孕而改變**） | 「我一直都是 24 cm」並不可靠 |

## 寬度代號

| 代號 | 意義 | 參考 |
|---|---|---|
| **JIS（日本）** | **A 到 E、2E（EE）、3E、4E、F、G**，依序變寬。**E–2E 是標準**；**3E 以上算寬** | 由足圍（繞過大拇趾與小趾根部的周長）與腳長決定 |
| **海外** | **B（女款標準）、D（男款標準）、W 或 EE（寬）**等 | 與日本代號的對應只是大致參考 |
| **沒有代號** | 多數時裝鞋與運動鞋沒有寬度代號 | 靠試穿確認。**每個品牌用的楦頭都不一樣** |

## 疼痛的原因與對策

| 症狀 | 原因 | 對策 |
|---|---|---|
| **後跟摩擦、起水泡** | 後跟脫出（太長或太寬）；材質偏硬 | **後跟墊**；**事先貼 OK 繃或防磨腳貼**；**皮鞋慢慢穿開（先短時間穿）** |
| **小趾或大拇趾根部痛** | **太窄** | 換更寬的寬度尺寸；**用撐鞋器**（僅限皮革）；**不要往上加一號**（那只會變長） |
| **腳趾頂到前面** | 太短；**捨て寸不足**；**下坡或水腫** | 大 0.5 cm；**把鞋帶繫緊，把腳固定在後面** |
| **腳背痛** | 鞋背太低；鞋帶繫太緊 | 換腳背較高的款式；**改變鞋帶的穿法（跳過腳背處的孔）** |
| **腳掌或腳跟痛** | 緩衝不足；**足弓支撐不足**；穿得太久 | **鞋墊**（另見相關文章）；檢查鞋底磨損 |
| **傍晚變緊** | 水腫 | 傍晚試穿；選可以用鞋帶或扣帶調整的鞋；**把腳抬高休息** |
| **繭、雞眼** | **反覆**穿寬度或形狀不合的鞋 | 重新檢視鞋子；到皮膚科削掉（日本的健保有給付） |

- **兒童鞋**：**每 3–6 個月確認一次尺寸**（腳**每年長 1–2 cm**）。**買大了**會絆倒，也會造成足部變形。**捨て寸 0.5–1 cm**；**後跟要穩固，前掌要寬，彎折處要在腳趾根部**。
- **高跟鞋**：**3–5 cm** 是對腳負擔較小的常見參考值。若因為**往前滑**而腳趾痛，請用**前掌墊**。
- **網路買鞋**：**除非您已經熟悉同一品牌同一款式，否則請試穿**。選**接受退貨的店家**（另見相關文章）。
- **腳的問題持續存在**：**拇趾外翻、扁平足與開張足**未必靠選鞋就能解決。請到**整形外科（整形外科，足部外科）**看診，並到**有認證鞋類專家（shoe fitter）的專業鞋店**測量。

> **[待核實]** 水腫的幅度、捨て寸的參考值，以及 JIS 的足圍寬度分級，請對照鞋類專家協會（FHA）的資料與 JIS S5037 確認。

## 誤解1｜尺寸（cm）對了鞋就合腳

**寬度、腳背與後跟貼合也要合適，否則就會痛。** 試穿時四點都要確認。

## 誤解2｜寬度緊就往上加一號

**鞋會變長，後跟脫出，換來另一種痛。** 請試更寬的寬度（2E、3E）或換個品牌。

## 誤解3｜早上試穿比較準

**腳到傍晚會腫，所以傍晚試穿更接近實際情況。**

## 誤解4｜皮革會撐開，所以買緊一點

**寬度會撐開一點，長度不會。** 沒有捨て寸的話，就算皮革撐開了，腳趾還是會一直頂到前面。

## 誤解5｜我的腳尺寸從來不變

**年齡、體重、懷孕與肌肉流失都會改變腳長與腳寬。** 每年量一次。
