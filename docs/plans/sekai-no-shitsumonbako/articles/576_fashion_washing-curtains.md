# Q. カーテンは洗える？頻度と、縮ませない洗い方｜世界の質問箱 #576

- 棚：`fashion` ／ URL：`/questions/washing-curtains` ／ ステータス：**ドラフト（法務レビュー前・出典未検証）**

カーテンは「洗うもの」という意識が薄い家庭用品で、何年も洗っていない家が多いようです。しかしカーテンはほこり・花粉・排気ガス・結露のカビ・たばこの煙を吸い込む大きな布。洗い方と頻度を整理します。

## A. 多くのカーテンは家で洗えます。洗濯表示を確認し、洗濯可ならフックを外して（またはフック部分を折り込んで）大きめのネットにたたんで入れ、弱水流・おしゃれ着コースで洗い、脱水は短く（30秒〜1分）、濡れたまますぐカーテンレールに吊って乾かす——これが最も縮みとシワを防ぐ方法です。頻度はレースが年2〜3回、厚地（ドレープ）が年1回が目安。縮みやすいのは綿・麻・レーヨン、縮みにくいのはポリエステル。カビは酸素系漂白剤で落ち、遮光・防炎・形状記憶加工は洗うと弱まることがあります。洗濯不可の表示、絹・ベルベット・裏地付きの厚手はクリーニングへ。

## 洗う頻度と手順

| カーテン | 頻度 | 理由 |
|---|---|---|
| **レースカーテン** | **年2〜3回**（花粉シーズン後、梅雨明け、年末） | 窓側で**花粉・排気ガス・結露のカビ**を最も受ける |
| **厚地（ドレープ）** | **年1回**（年末や春） | ほこり・においの吸着 |
| **キッチン・喫煙者の部屋** | **頻度を上げる** | 油・煙のにおい |
| **カビが出た** | すぐ | 放置で繊維に根を張る |

### 手順

1. **洗濯表示を確認**。**洗濯不可、絹・ベルベット・裏地付き**はクリーニング。
2. **フックを外す**（面倒なら**フック部分を内側に折り込んで輪ゴム**で留める方法も。ただし外す方が安全）。**ほこりを払う**（外で軽く振る、掃除機のブラシ）。
3. **たたんで大きめのネットに**（**じゃばら折り**にするとムラが減る）。**1枚ずつ**。
4. **弱水流・おしゃれ着（ドライ）コース**、**中性のおしゃれ着用洗剤**。**水温30℃以下**。
5. **脱水30秒〜1分**。
6. **濡れたまま元のレールに吊って乾かす**。**重みでシワが伸び、乾燥機・日光の縮みも避けられる**。**窓を開けて風を通す**。厚地は**下にタオルや新聞紙**（水滴）。
7. **完全に乾くまで（半日〜1日）**触らない。

## 素材・加工別の注意

| 素材・加工 | 注意 |
|---|---|
| **ポリエステル** | **縮みにくく、洗いやすい**。大半のカーテンがこれ |
| **綿・麻** | **縮む（2〜5%）**。**丈に余裕がない場合はクリーニング**か、洗う前に**縮み分を考えて裾を調整** |
| **レーヨン・アセテート** | **水に弱く縮む・シワ**。クリーニング推奨 |
| **遮光・遮熱・防炎加工** | **洗濯で効果が徐々に弱まる**製品がある。表示に「洗濯後も効果維持」の記載を確認。**防炎ラベル付き**は洗濯回数の制限が書かれていることも |
| **形状記憶（ウェーブ）加工** | **洗うとウェーブが弱まる**ことがある。**脱水せずに吊る**と保ちやすい |
| **刺繍・レース（繊細）** | ネット必須、手洗いコース |
| **カビ** | **酸素系漂白剤を40℃の湯に溶かして30分〜1時間つけおき**（**色柄テスト後**）→洗濯。**塩素系はポリエステルの黄変・色抜け**の原因になるので白いレースのみ、短時間 |

- **フック**：**アジャスターフック**は外して**洗剤液で洗う**とほこりが落ちる。**金属フックはさびに注意**。
- **レールの掃除**：カーテンを外している間に**レール・窓枠の結露カビを拭く**。
- **タバコ・料理のにおい**：**重曹水に30分つけおき**→洗濯で軽減。
- **カーテンの寿命**：**5〜10年**。**日光で裏側が劣化して裂ける**、**遮光が落ちる**が買い替えの目安。**紫外線で傷むのは窓側の面**なので、レースは特に。
- **買い替え時に洗いやすさを選ぶ**：**「ウォッシャブル」表示、ポリエステルだけの生地、フックが外しやすい**、**丈に2〜3cmの余裕**（縮み対策）。
- **賃貸**：カーテンは入居者のもので、**退去時に持ち帰る**（レールは設備）。

> **【要検証】** 縮み率の目安、防炎・遮光加工の洗濯耐久はメーカー表示に従ってください。洗濯表示の読み方は消費者庁の資料で確認を。

## 誤解1｜カーテンは洗わなくていい

**花粉・排気ガス・カビ・においを吸った大きな布です。** レースは年2〜3回、厚地は年1回。

## 誤解2｜洗うと縮むから洗えない

**ポリエステルは縮みにくく、大半のカーテンは家で洗えます。** 綿・麻・レーヨンは表示と丈の余裕で判断。

## 誤解3｜乾燥機で乾かせば早い

**縮み・シワ・加工の劣化の原因**です。濡れたままレールに吊るのが最も楽で仕上がりが良い。

## 誤解4｜カビは塩素系漂白剤で一気に

**ポリエステルの黄変・色抜けの原因**になります。酸素系のつけおきで。

## 誤解5｜遮光カーテンは何度洗っても効果は変わらない

**加工によっては洗濯で徐々に弱まります。** 表示の「洗濯後の効果」を確認し、頻度を抑える。
