# Q. 窗帘可以洗吗？多久洗一次，怎样才不缩水？｜Japan Questions #576

- Shelf: `fashion` ／ URL: `/zh-cn/fashion/washing-curtains` ／ Status: **草稿 — 出处未核实**

窗帘是家里很少被想到「可以洗」的东西之一，不少家庭好几年都没洗过。可窗帘毕竟是一大块布，它吸附着灰尘、花粉、汽车尾气、窗户结露带来的霉，还有香烟的烟味。在日本，租住公寓里的窗帘通常属于住户而不是房东，所以保养也归你自己。下面说说怎么洗、多久洗一次。

## A. 大多数窗帘可以在家里洗。先看洗涤标签；如果标签允许水洗，就取下挂钩（或把挂钩布带向内折好），把窗帘叠好放进大号洗衣网袋，用轻柔或精细衣物程序洗涤，短时间脱水（30秒到1分钟），然后趁湿直接挂回窗帘轨道上晾干。这是避免缩水和折痕最好的办法。频率：蕾丝窗帘（纱帘）一年2～3次，厚窗帘（遮光帘）一年1次。棉、麻和粘胶纤维会缩水，涤纶几乎不缩。霉斑可用氧系漂白剂去除；遮光、阻燃和形状记忆等加工可能因洗涤而减弱。标注「不可水洗」的窗帘、真丝、天鹅绒和带衬里的厚窗帘请送干洗店。

## 多久洗一次，怎么洗

| 窗帘 | 频率 | 原因 |
|---|---|---|
| **蕾丝窗帘（纱帘）** | **一年2～3次**（花粉季之后、梅雨季之后、年末） | 离窗户最近，最容易沾上**花粉、汽车尾气和结露产生的霉** |
| **厚窗帘（遮光帘）** | **一年1次**（年末或春天） | 灰尘与气味的累积 |
| **厨房、吸烟的房间** | **更勤一些** | 油烟与烟味 |
| **已经长霉** | 立刻处理 | 放着不管，霉会扎进纤维里 |

### 步骤

1. **确认洗涤标签**。**标注「不可水洗」的、真丝、天鹅绒和带衬里的窗帘**送干洗店。
2. **取下挂钩**（如果嫌麻烦，也可以**把挂钩布带向内折起、用橡皮筋固定**；取下更稳妥）。**抖掉灰尘**（拿到外面轻轻抖一抖，或用吸尘器的刷头）。
3. **叠好放进大号洗衣网袋**（**折成手风琴状**可以减少洗不匀）。**一次洗一片**。
4. **轻柔或精细衣物（「干洗」）程序**，**中性精细衣物洗涤剂**。**水温30℃以下**。
5. **脱水30秒到1分钟**。
6. **趁湿挂回原来的轨道上晾干**。**布本身的重量会把折痕拉平，也避免了烘干机或日晒造成的缩水**。**打开窗户通风**。厚窗帘下面**垫上毛巾或报纸**（防滴水）。
7. **放到完全干透（半天到一天）**。

## 按面料与加工的注意事项

| 面料／加工 | 注意事项 |
|---|---|
| **涤纶** | **几乎不缩水，好洗**。多数窗帘都是涤纶 |
| **棉、麻** | **会缩水（2～5%）**。**如果长度没有富余，请送干洗**，或者**在洗之前先按缩水量调整下摆** |
| **粘胶纤维、醋酸纤维** | **不耐水，会缩会皱**。建议干洗 |
| **遮光、隔热、阻燃加工** | 有些产品**会随着洗涤逐渐失去效果**。请确认标签上是否写着「洗涤后效果保持」。**阻燃标签**可能会注明可洗涤的次数上限 |
| **形状记忆（波浪）加工** | **波浪形状可能因洗涤而变弱**。**不脱水直接晾**有助于保持 |
| **刺绣、精细蕾丝** | 必须用网袋；用手洗程序 |
| **霉斑** | **把「酸素系漂白剤」(氧系漂白剂，sanso-kei hyōhakuzai) 溶于40℃的水中，浸泡30分钟到1小时**（**先做色牢度测试**）→ 再洗。**氯系漂白剂会使涤纶发黄、把颜色洗掉**，所以只用于白色蕾丝，且时间要短 |

- **挂钩**：取下**可调式挂钩**，**放进洗涤剂溶液里洗**，把灰尘泡下来。**金属挂钩要注意生锈**。
- **清理轨道**：趁窗帘取下来的时候，**把轨道和窗框上结露长出的霉擦掉**。
- **烟味和油烟味**：**在「重曹」(小苏打，jūsō) 水中浸泡30分钟** → 再洗，可以减轻。
- **窗帘的寿命**：**5～10年**。**背面会被日晒晒坏、开裂**，**遮光性能也会减弱** —— 这些都是该换的信号。**紫外线会伤到朝窗那一面**，蕾丝窗帘尤其如此。
- **换新时，按「好洗」来买**：**带「可水洗」标签、全涤纶面料、挂钩容易取下**，并留**2～3cm的富余长度**（给缩水留出余地）。
- **租房**：窗帘属于承租人，**搬走时要带走**（轨道属于房屋附属设备）。

> **[待核实]** 缩水率以及阻燃、遮光加工的耐洗性，请以厂商标签为准。洗涤标签的读法请对照消费者厅的资料核实。

## 误解1｜窗帘不需要洗

**它是一大块布，吸满了花粉、汽车尾气、霉和气味。** 蕾丝窗帘一年2～3次，厚窗帘一年1次。

## 误解2｜会缩水，所以不能洗

**涤纶几乎不缩水，大多数窗帘都能在家里洗。** 棉、麻和粘胶纤维则要看标签和长度富余来判断。

## 误解3｜用烘干机更快

**它会造成缩水、折痕，并损伤加工层。** 趁湿挂回轨道是最省事、成品也最好的办法。

## 误解4｜用氯系漂白剂猛攻霉斑

**它会使涤纶发黄、把颜色洗掉。** 请改用氧系漂白剂浸泡。

## 误解5｜遮光窗帘怎么洗效果都一样

**有些加工会随着洗涤逐渐减弱。** 请确认标签上关于「洗涤后效果」的说明，并减少洗涤次数。
