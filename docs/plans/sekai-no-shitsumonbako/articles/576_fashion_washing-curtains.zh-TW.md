# Q. 窗簾可以洗嗎？多久洗一次，怎樣才不縮水？｜Japan Questions #576

- Shelf: `fashion` ／ URL: `/zh-tw/fashion/washing-curtains` ／ Status: **草稿 — 出處未核實**

窗簾是家裡很少被想到「可以洗」的東西之一，不少家庭好幾年都沒洗過。可是窗簾畢竟是一大塊布，它吸附著灰塵、花粉、汽車廢氣、窗戶結露帶來的黴，還有香菸的菸味。在日本，租屋處的窗簾通常屬於住戶而不是房東，所以保養也歸你自己。以下談談怎麼洗、多久洗一次。

## A. 大多數窗簾可以在家裡洗。先看洗滌標籤；若標籤允許水洗，就取下掛鉤（或把掛鉤布帶往內摺好），把窗簾摺好放進大型洗衣網袋，用輕柔或精緻衣物行程洗滌，短時間脫水（30秒到1分鐘），然後趁濕直接掛回窗簾軌道上晾乾。這是避免縮水與摺痕最好的辦法。頻率：蕾絲窗簾（紗簾）一年2～3次，厚窗簾（遮光簾）一年1次。棉、麻與嫘縈會縮水，聚酯纖維幾乎不縮。黴斑可用氧系漂白劑處理；遮光、防焰與形狀記憶等加工可能因洗滌而減弱。標示「不可水洗」的窗簾、絲、天鵝絨與有襯裡的厚窗簾請送洗衣店乾洗。

## 多久洗一次，怎麼洗

| 窗簾 | 頻率 | 原因 |
|---|---|---|
| **蕾絲窗簾（紗簾）** | **一年2～3次**（花粉季之後、梅雨季之後、年底） | 離窗戶最近，最容易沾上**花粉、汽車廢氣與結露產生的黴** |
| **厚窗簾（遮光簾）** | **一年1次**（年底或春天） | 灰塵與氣味的累積 |
| **廚房、吸菸的房間** | **更勤一些** | 油煙與菸味 |
| **已經長黴** | 立刻處理 | 放著不管，黴會扎進纖維裡 |

### 步驟

1. **確認洗滌標籤**。**標示「不可水洗」的、絲、天鵝絨與有襯裡的窗簾**送洗衣店。
2. **取下掛鉤**（若嫌麻煩，也可以**把掛鉤布帶往內摺起、用橡皮筋固定**；取下比較穩妥）。**抖掉灰塵**（拿到外面輕輕抖一抖，或用吸塵器的刷頭）。
3. **摺好放進大型洗衣網袋**（**摺成手風琴狀**可以減少洗不勻）。**一次洗一片**。
4. **輕柔或精緻衣物（「乾洗」）行程**，**中性精緻衣物洗衣精**。**水溫30℃以下**。
5. **脫水30秒到1分鐘**。
6. **趁濕掛回原本的軌道上晾乾**。**布本身的重量會把摺痕拉平，也避免了烘衣機或日曬造成的縮水**。**打開窗戶通風**。厚窗簾下面**墊上毛巾或報紙**（防滴水）。
7. **放到完全乾透（半天到一天）**。

## 依布料與加工的注意事項

| 布料／加工 | 注意事項 |
|---|---|
| **聚酯纖維** | **幾乎不縮水，好洗**。多數窗簾都是聚酯纖維 |
| **棉、麻** | **會縮水（2～5%）**。**若長度沒有餘裕，請送乾洗**，或者**在洗之前先依縮水量調整下襬** |
| **嫘縈、醋酸纖維** | **不耐水，會縮會皺**。建議乾洗 |
| **遮光、隔熱、防焰加工** | 有些產品**會隨著洗滌逐漸失去效果**。請確認標籤上是否寫著「洗滌後效果保持」。**防焰標籤**可能會註明可洗滌的次數上限 |
| **形狀記憶（波浪）加工** | **波浪形狀可能因洗滌而變弱**。**不脫水直接晾**有助於保持 |
| **刺繡、精緻蕾絲** | 必須用網袋；用手洗行程 |
| **黴斑** | **把「酸素系漂白剤」(氧系漂白劑，sanso-kei hyōhakuzai) 溶於40℃的水中，浸泡30分鐘到1小時**（**先做色牢度測試**）→ 再洗。**氯系漂白劑會使聚酯纖維泛黃、把顏色洗掉**，所以只用於白色蕾絲，且時間要短 |

- **掛鉤**：取下**可調式掛鉤**，**放進洗衣精溶液裡洗**，把灰塵泡下來。**金屬掛鉤要注意生鏽**。
- **清理軌道**：趁窗簾取下來的時候，**把軌道與窗框上結露長出的黴擦掉**。
- **菸味與油煙味**：**在「重曹」(小蘇打，jūsō) 水中浸泡30分鐘** → 再洗，可以減輕。
- **窗簾的壽命**：**5～10年**。**背面會被日曬曬壞、裂開**，**遮光性也會減弱** —— 這些都是該換的訊號。**紫外線會傷到朝窗那一面**，蕾絲窗簾尤其如此。
- **換新時，依「好洗」來挑**：**有「可水洗」標示、全聚酯纖維布料、掛鉤容易取下**，並留**2～3cm的餘裕長度**（給縮水留空間）。
- **租屋**：窗簾屬於承租人，**搬走時要帶走**（軌道屬於房屋附屬設備）。

> **[待核實]** 縮水率以及防焰、遮光加工的耐洗性，請以廠商標籤為準。洗滌標籤的判讀方式請對照消費者廳的資料核實。

## 誤解1｜窗簾不需要洗

**它是一大塊布，吸滿了花粉、汽車廢氣、黴與氣味。** 蕾絲窗簾一年2～3次，厚窗簾一年1次。

## 誤解2｜會縮水，所以不能洗

**聚酯纖維幾乎不縮水，大多數窗簾都能在家裡洗。** 棉、麻與嫘縈則要看標籤與長度餘裕來判斷。

## 誤解3｜用烘衣機比較快

**它會造成縮水、摺痕，並損傷加工層。** 趁濕掛回軌道是最省事、成品也最好的辦法。

## 誤解4｜用氯系漂白劑猛攻黴斑

**它會使聚酯纖維泛黃、把顏色洗掉。** 請改用氧系漂白劑浸泡。

## 誤解5｜遮光窗簾怎麼洗效果都一樣

**有些加工會隨著洗滌逐漸減弱。** 請確認標籤上關於「洗滌後效果」的說明，並減少洗滌次數。
