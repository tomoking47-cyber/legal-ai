# Q. 정장이나 교복의 엉덩이와 팔꿈치가 번들거립니다. 되돌릴 수 있나요? 예방법은?｜Japan Questions #577

- Shelf: `fashion` ／ URL: `/ko/fashion/suit-shine-and-wear` ／ Status: **초안 — 출처 미확인**

하루 종일 책상에 앉아 있으면 정장의 엉덩이, 팔꿈치, 무릎이 번들거리기 시작합니다. 이 "번들거림"(テカリ, tekari)은 원단 표면의 잔털이 눌려 평평해지면서 빛을 반사하는 상태로, 일본의 회사원 정장과 학생 교복에는 피하기 어려운 골칫거리입니다. 어디까지 되돌릴 수 있고, 어떻게 늦출 수 있는지 정리했습니다.

## A. 번들거림은 원단의 잔털(섬유 끝)이 마찰로 눌려 평평해진 상태입니다. 초기에서 중기까지는 스팀(다리미를 천 위에 띄우고 스팀만 쐬거나 스팀다리미 사용)으로 섬유를 일으키고 옷솔로 결을 세우면 광택이 옅어집니다. 예로부터 전해지는 방법은 희석한 식초(물 1에 식초 1~2)를 분무한 뒤 솔질하고 스팀을 쐬는 것으로, 산이 섬유를 세우는 데 도움이 된다고 흔히 설명됩니다. 섬유 자체가 얇게 닳아 버린 뒤(원단이 비쳐 보이고 광택이 전체에 고정된 상태)에는 돌아오지 않으며, 여분의 바지를 사거나 세탁소의 "번들거림 제거" 서비스를 이용해도 일시적인 개선에 그칩니다. 예방하려면 같은 정장을 이틀 연속 입지 말고, 앉기 전에 재킷 자락을 옆으로 젖히고, 의자에 방석이나 천을 깔고, 입은 뒤에는 솔질을 하고 바지를 걸어 두십시오.

## 번들거림의 단계와 대처

| 단계 | 상태 | 대처 | 되돌릴 수 있나 |
|---|---|---|---|
| **초기** | 각도에 따라 살짝 광택. 원단은 아직 두껍다 | **스팀(천 위에 띄우고 스팀만) → 옷솔로 결 세우기** | **가능** |
| **중기** | 늘 번들거림. 만지면 매끈하다 | **희석 식초(물 1 : 식초 1~2) 분무 → 솔질 → 스팀**. 또는 **암모니아수(물에 몇 방울)**. **덧천을 대고 저온으로 가볍게 다리는 것**은 오히려 악화시킬 수 있으므로 스팀만 사용 | **대체로 가능** |
| **후기** | 원단이 얇아져 비치고 색이 바래 보인다 | **섬유가 닳아 없어져 회복되지 않습니다**. **세탁소의 "번들거림 제거"(テカリ直し)**(기모를 세우는 처리, 1,000~3,000엔)로 일시적인 개선 | **불가** |

## 예방하기

| 대책 | 내용 |
|---|---|
| **연속으로 입지 않기** | **정장 2~3벌을 돌려 입기**; **한 번 입으면 1~2일 쉬게 하기**. 울 섬유는 쉬는 동안 회복됩니다 |
| **앉는 방법** | **앉기 전에 재킷 자락을 젖히고 깔고 앉지 않기**(등 부분의 번들거림과 구김); **앉을 때 바지 무릎을 살짝 집어 올리기**; **뒷주머니에 지갑이나 휴대전화를 넣지 않기**(마찰과 변형) |
| **의자** | **인조가죽과 딱딱한 좌면은 마찰이 큽니다**. **천 방석이나 시트 커버를 쓰십시오**. 자동차 시트도 마찬가지입니다 |
| **일상 손질** | **귀가 후 옷솔질**(결을 따라); **바지는 바지걸이에**; **주 1회 스팀** |
| **원단 선택** | **울 100%는 회복되고, 폴리에스터 혼방은 더 쉽게 번들거립니다**. **촘촘하게 짠 원단(서지, 개버딘)은 번들거리기 쉽고, 플란넬과 트위드는 덜 드러납니다** |
| **바지 두 벌** | **바지가 재킷보다 먼저 상합니다**. **투 팬츠 정장**을 사거나, 같은 원단의 여분 바지를 파는 가게에서 구입하십시오 |
| **교복** | **학생 교복(울·폴리에스터 혼방)은 특히 잘 번들거립니다**. **여분의 바지나 치마를 준비**하고 **하교 후 솔질**하십시오. **덧천을 대고 저온으로 다립니다** |

- **번들거리는 이유**: **마찰 → 잔털이 눕는다 → 표면이 매끄러워진다 → 빛을 한 방향으로 반사한다**. **열과 압력(과한 다림질, 앉는 압력)**이 이를 앞당깁니다. **폴리에스터는 열에 살짝 녹아 고정되므로** 되돌리기가 더 어렵습니다.
- **스팀 쐬는 법**: **스팀다리미나 다리미의 스팀을 천에서 2~3cm 띄우고**, **천에 닿지 않게 스팀을 스며들게 한 뒤** → **바로 결을 솔로 세우고** → **걸어서 말립니다**. **덧천을 대고 직접 다리면 더 눌리므로** 피하십시오.
- **식초 방법**: **물과 식초(곡물식초, 穀物酢)를 1:1~1:2로**, **눈에 띄지 않는 곳에서 색빠짐을 확인한 뒤**, **분무 → 몇 분 두기 → 솔질 → 스팀 → 그늘에서 건조**합니다. **마르면 냄새는 사라집니다**. **암모니아수**도 같은 역할을 합니다(환기하십시오).
- **세탁소**: 일부 매장은 **"テカリ直し"(번들거림 제거)나 "毛羽起こし"(기모 세우기)**를 옵션으로 제공합니다. **프레스는 번들거림을 악화시키므로**, **번들거림이 신경 쓰인다고 말하고 "가볍게만 프레스"해 달라고 요청하십시오**.
- **교체 시기**: **후기 단계의 번들거림, 비쳐 보이는 원단, 엉덩이 솔기가 터진 경우**. **주 2~3회 입는 정장의 수명은 약 3~5년**입니다.

> **[확인 필요]** 식초나 암모니아수로 기모를 세우는 것은 세탁업계와 가정에서 전해져 온 방법이며, 원단에 미치는 영향은 섬유에 따라 다릅니다. 전국클리닝생활위생동업조합연합회(全ク連) 자료와 대조해 확인하십시오.

## 오해 1｜번들거림은 때이므로 빨면 없어진다

**잔털이 눌린 물리적인 상태여서 세탁으로는 되돌아가지 않습니다.** 스팀과 솔로 결을 세우십시오.

## 오해 2｜세게 다리면 번들거림이 사라진다

**열과 압력이야말로 번들거림의 가장 큰 원인입니다.** 위에서 스팀을 쐰 뒤 솔질하십시오.

## 오해 3｜같은 정장을 매일 입어도 괜찮다

**매일 입으면 섬유가 회복할 시간이 없습니다.** 2~3벌을 돌려 입으면 수명이 몇 년 늘어납니다.

## 오해 4｜후기의 번들거림도 고칠 수 있다

**섬유가 얇게 닳으면 돌아오지 않습니다.** 세탁소의 처리는 일시적입니다. 여분의 바지를 마련하십시오.

## 오해 5｜폴리에스터 혼방은 튼튼하니까 번들거리지 않는다

**폴리에스터 혼방은 잔털이 열로 고정되어 잘 번들거리고 회복도 잘 되지 않습니다.** 울 100% 원단이 회복력이 좋습니다.
