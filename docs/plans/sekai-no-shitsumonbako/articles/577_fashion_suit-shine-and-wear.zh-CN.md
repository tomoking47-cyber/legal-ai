# Q. 西装或制服的臀部和手肘处发亮了。能修复吗？能预防吗？｜Japan Questions #577

- Shelf: `fashion` ／ URL: `/zh-cn/fashion/suit-shine-and-wear` ／ Status: **草稿 — 出处未核实**

在办公桌前坐上一整天，西装的臀部、手肘和膝盖就开始发亮。这种「发亮」（テカリ，tekari）是布面的绒毛被压平、把光线反射出去的结果，对日本的上班族西装和学生制服来说，是躲不掉的烦恼。下面说说哪些能挽回、怎样才能让它来得慢一些。

## A. 发亮是布料的绒毛（纤维末端）被摩擦压平造成的。在早期到中期，用蒸汽（把熨斗悬在布面上方、只出蒸汽，或者用挂烫机）可以把纤维重新立起来，再用衣物刷把绒毛刷起来，光泽就会淡下去。传统做法是喷一层稀释的醋（水1份对醋1～2份），然后刷、再蒸汽；一般认为酸有助于纤维立起来。一旦纤维本身已经磨薄（布变得透光、光泽整片固定下来），就回不来了；多买一条备用裤子，或者干洗店的「去光泽」服务，最多只能带来暂时的改善。预防办法：不要连续两天穿同一套西装，坐下前把上衣的后摆拨开，在椅面上放个坐垫或垫块布，每次穿完都刷一刷、把裤子挂好。

## 发亮的阶段与对策

| 阶段 | 状态 | 对策 | 能否挽回？ |
|---|---|---|---|
| **早期** | 某些角度略有光泽。布还很厚实 | **蒸汽（悬在布面上方，只出蒸汽）→ 用衣物刷把绒毛立起来** | **能** |
| **中期** | 一直发亮。摸上去很滑 | **喷稀释的醋（水1：醋1～2）→ 刷 → 蒸汽**。或者用**氨水（几滴兑水）**。**垫布低温轻熨**反而可能加重，所以只用蒸汽 | **大体能** |
| **后期** | 布变薄透光，看起来发白褪色 | **纤维已经磨损，无法恢复**。可用**干洗店的「去光泽」（テカリ直し）**（一种起绒工艺，1,000～3,000日元）做暂时性处理 | **不能** |

## 怎样预防

| 措施 | 具体做法 |
|---|---|
| **不要连着穿** | **轮换2～3套西装**；**每穿一次让它休息1～2天**。羊毛纤维在休息中会恢复 |
| **坐姿** | **坐下前把上衣后摆拨开，不要坐在上面**（背部会发亮、起皱）；**坐下时把裤子膝盖处轻轻提一下**；**后口袋里不要放钱包和手机**（摩擦与变形） |
| **椅子** | **人造革和硬座面摩擦更大**。**用布面坐垫或椅套**。车座同理 |
| **日常保养** | **回家后用衣物刷刷一刷**（顺着绒毛方向）；**裤子挂在裤架上**；**每周蒸汽处理一次** |
| **面料选择** | **全羊毛面料能恢复；涤纶混纺更容易发亮**。**织得紧密的面料（哔叽、华达呢）容易发亮；法兰绒和粗花呢不明显** |
| **两条裤子** | **裤子比上衣先坏**。买**双裤西装**，或者在能单独买同料备用裤的店里买 |
| **制服** | **学生制服（羊毛涤纶混纺）特别容易发亮**。**备一条裤子或一条裙子**；**放学回家后刷一刷**。**垫布低温熨烫** |

- **为什么会发亮**：**摩擦 → 绒毛倒伏 → 表面变得平滑 → 朝同一方向反射光线**。**热和压力（熨过头、坐压）**会加速这个过程。**涤纶受热会略微熔化并定形**，所以更难挽回。
- **蒸汽的做法**：**把挂烫机，或熨斗的蒸汽，悬在布面上方2～3cm处**，**让蒸汽渗进去，不要碰到布面** → **马上把绒毛刷起来** → **挂起来晾干**。**隔着垫布直接熨会把它压得更平**，请避免。
- **醋的做法**：**水和醋（谷物醋，穀物酢）按1:1到1:2**，**先在不显眼处测试色牢度**，**喷 → 放几分钟 → 刷 → 蒸汽 → 阴干**。**干了之后气味就没了**。**氨水**作用相同（注意通风）。
- **干洗店**：有些店提供**「テカリ直し」（去光泽）或「毛羽起こし」（起绒）**作为可选项目。**压烫会加重发亮**，所以**请说明你在意的是发亮，并要求「只做轻压」**。
- **什么时候该换**：**后期的发亮、布已透光、臀部接缝开裂**。**一周穿2～3次的西装大约能穿3～5年**。

> **[待核实]** 用醋或氨水起绒是干洗行业与家庭中流传下来的做法，对布料的作用因纤维而异。请对照全国干洗业协会联合会（全ク連）的资料核实。

## 误解1｜发亮是脏，洗一洗就没了

**它是一种物理状态 —— 绒毛被压平 —— 洗涤无法把它逆转。** 请用蒸汽和刷子把绒毛立起来。

## 误解2｜使劲熨一熨，光泽就没了

**热和压力正是发亮最主要的原因。** 请从上方给蒸汽，然后刷。

## 误解3｜每天穿同一套西装没关系

**天天穿会让纤维没有时间恢复。** 轮换2～3套能让它们多穿好几年。

## 误解4｜后期的发亮也修得好

**纤维一旦磨薄就回不来了。** 干洗店的工艺是暂时性的。请另买备用裤子。

## 误解5｜涤纶混纺更结实，所以不会发亮

**涤纶混纺的绒毛会被热定形，所以容易发亮而且难恢复。** 全羊毛面料的恢复力更好。
