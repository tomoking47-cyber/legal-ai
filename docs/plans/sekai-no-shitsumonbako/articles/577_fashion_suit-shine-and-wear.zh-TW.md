# Q. 西裝或制服的臀部與手肘處發亮了。修得回來嗎？能預防嗎？｜Japan Questions #577

- Shelf: `fashion` ／ URL: `/zh-tw/fashion/suit-shine-and-wear` ／ Status: **草稿 — 出處未核實**

在辦公桌前坐上一整天，西裝的臀部、手肘與膝蓋就開始發亮。這種「發亮」（テカリ，tekari）是布面的絨毛被壓平、把光線反射出去的結果，對日本的上班族西裝與學生制服來說，是躲不掉的麻煩。以下談談哪些救得回來、怎樣才能讓它來得慢一些。

## A. 發亮是布料的絨毛（纖維末端）被摩擦壓平造成的。在初期到中期，用蒸氣（把熨斗懸在布面上方、只出蒸氣，或者用掛燙機）可以把纖維重新立起來，再用衣物刷把絨毛刷起來，光澤就會變淡。傳統做法是噴一層稀釋過的醋（水1份對醋1～2份），然後刷、再蒸氣；一般認為酸有助於纖維立起。一旦纖維本身已經磨薄（布變得透光、光澤整片固定下來），就回不來了；多買一條備用長褲，或者洗衣店的「去光澤」服務，頂多只能帶來暫時的改善。預防辦法：不要連續兩天穿同一套西裝，坐下前把上衣的後襬撥開，在椅面上放個坐墊或墊塊布，每次穿完都刷一刷、把長褲掛好。

## 發亮的階段與對策

| 階段 | 狀態 | 對策 | 救得回來嗎？ |
|---|---|---|---|
| **初期** | 某些角度略有光澤。布還很厚實 | **蒸氣（懸在布面上方，只出蒸氣）→ 用衣物刷把絨毛立起來** | **可以** |
| **中期** | 一直發亮。摸起來很滑 | **噴稀釋過的醋（水1：醋1～2）→ 刷 → 蒸氣**。或者用**氨水（幾滴兌水）**。**墊布低溫輕燙**反而可能加重，所以只用蒸氣 | **大致可以** |
| **後期** | 布變薄透光，看起來褪色 | **纖維已經磨損，無法恢復**。可用**洗衣店的「去光澤」（テカリ直し）**（一種起絨處理，1,000～3,000日圓）做暫時性處理 | **不行** |

## 怎麼預防

| 措施 | 具體做法 |
|---|---|
| **不要連著穿** | **輪流換穿2～3套西裝**；**每穿一次讓它休息1～2天**。羊毛纖維在休息中會恢復 |
| **坐姿** | **坐下前把上衣後襬撥開，不要坐在上面**（背部會發亮、起皺）；**坐下時把長褲膝蓋處輕輕提一下**；**後口袋裡不要放皮夾與手機**（摩擦與變形） |
| **椅子** | **合成皮與硬椅面摩擦更大**。**用布面坐墊或椅套**。車椅同理 |
| **日常保養** | **回家後用衣物刷刷一刷**（順著絨毛方向）；**長褲掛在褲架上**；**每週蒸氣處理一次** |
| **布料選擇** | **全羊毛布料會恢復；聚酯纖維混紡更容易發亮**。**織得緊密的布料（嗶嘰、華達呢）容易發亮；法蘭絨與粗花呢比較看不出來** |
| **兩條長褲** | **長褲比上衣先壞**。買**雙褲西裝**，或者在能單獨買同布料備用褲的店家購買 |
| **制服** | **學生制服（羊毛聚酯混紡）特別容易發亮**。**多備一條長褲或裙子**；**放學回家後刷一刷**。**墊布低溫熨燙** |

- **為什麼會發亮**：**摩擦 → 絨毛倒伏 → 表面變得平滑 → 朝同一方向反射光線**。**熱與壓力（燙過頭、坐壓）**會加速這個過程。**聚酯纖維受熱會稍微熔化並定型**，所以更難救回。
- **蒸氣的做法**：**把掛燙機，或熨斗的蒸氣，懸在布面上方2～3cm處**，**讓蒸氣滲進去，不要碰到布面** → **馬上把絨毛刷起來** → **掛起來晾乾**。**隔著墊布直接燙會把它壓得更平**，請避免。
- **醋的做法**：**水與醋（穀物醋，穀物酢）以1:1到1:2**，**先在不顯眼處測試色牢度**，**噴 → 放幾分鐘 → 刷 → 蒸氣 → 陰乾**。**乾了之後味道就沒了**。**氨水**作用相同（注意通風）。
- **洗衣店**：有些店家提供**「テカリ直し」（去光澤）或「毛羽起こし」（起絨）**作為加選項目。**壓燙會加重發亮**，所以**請說明你在意的是發亮，並要求「只做輕壓」**。
- **什麼時候該換**：**後期的發亮、布已透光、臀部接縫裂開**。**一週穿2～3次的西裝大約可以穿3～5年**。

> **[待核實]** 用醋或氨水起絨是洗衣業與家庭中流傳下來的做法，對布料的作用因纖維而異。請對照全國洗衣業協會聯合會（全ク連）的資料核實。

## 誤解1｜發亮是髒污，洗一洗就沒了

**它是一種物理狀態 —— 絨毛被壓平 —— 洗滌無法把它逆轉。** 請用蒸氣與刷子把絨毛立起來。

## 誤解2｜用力燙一燙，光澤就消失了

**熱與壓力正是發亮最主要的原因。** 請從上方給蒸氣，然後刷。

## 誤解3｜每天穿同一套西裝沒關係

**天天穿會讓纖維沒有時間恢復。** 輪流換穿2～3套能讓它們多穿好幾年。

## 誤解4｜後期的發亮也修得好

**纖維一旦磨薄就回不來了。** 洗衣店的處理是暫時性的。請另外買備用長褲。

## 誤解5｜聚酯混紡比較耐用，所以不會發亮

**聚酯混紡的絨毛會被熱定型，所以容易發亮而且難恢復。** 全羊毛布料的恢復力更好。
