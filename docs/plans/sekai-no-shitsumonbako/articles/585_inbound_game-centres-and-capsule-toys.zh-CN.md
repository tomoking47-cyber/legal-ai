# Q. 游戏厅、抓娃娃机和扭蛋：游客怎样玩才不浪费钱？｜Japan Questions #585

- Shelf: `inbound` ／ URL: `/zh-cn/questions/game-centres-and-capsule-toys` ／ Status: **草稿 — 出处未核实**

日本的4,000家游戏厅和30多万台扭蛋机是货真价实的景点，也是游客花¥5,000去抓一个隔壁店¥1,500就能买到的毛绒玩具的地方。这些机器不是西方意义上的"作弊机"——它们受监管——但技巧和机器设置都是真实存在的。

## A. 抓娃娃机（UFO catcher）是合法的娱乐机器，不是赌博；根据警察厅的指导，奖品价值上限约为¥1,000（2022年从¥800上调），而且店员理应帮忙——问一句"ちょっと手伝ってもらえますか"（能帮我一下吗），他们常会把奖品重新摆到好抓的位置，或示范那台机器的窍门。给每个奖品设一个预算（¥500–1,000），先看别人玩几局，学会两三种标准技巧（推、勾标签、把盒子从边缘滑下来），到了预算就停。扭蛋（gachapon）每次¥300–500，不需要技巧；在有您想要的那一套的地方买，而不是在看到的第一台机器买。大头贴机（purikura）和音乐游戏是另外两个游客最爱；注意吸烟规定和关门时间（大多数游戏厅23:00–24:00关门，未成年人视年龄须在18:00–22:00前离场）。

## 抓娃娃机（UFO catcher）

| 事实 | 详情 |
|---|---|
| **法律地位** | 《风俗营业法》下的娱乐机器；**奖品价值须在约¥1,000以下**（业界对法定上限的指导）——所以机器里的毛绒玩具不是¥5,000的东西 |
| **费用** | **每局¥100–200**，常有**¥500玩6局**；大型机器¥200–300 |
| **它们"作弊"吗？** | **爪子的力度和设置可调，因机器而异**；运营者会设定目标派奖率。**并非随机**——一台机器要么一直强要么一直弱，所以先观察有用 |
| **店员帮忙** | **找店员**（店員さん）。玩几局之后，他们**把奖品移到可以抓到的位置**或**示范预期的技巧**很正常。有些连锁店有"**投入¥X后我们会帮忙**"的标示 |
| **技巧** | **推（押し）**：把盒子推过边缘。**勾（フック）**：用一个爪尖勾住标签／吊环。**滑（ずらし）**：分几步把盒子沿边缘挪过去。**桥渡（橋渡し）**：盒子横跨两根杆——一次翘起一端 |
| **预算规则** | **决定每个奖品¥500–1,000；花完了还看不出明显接近，就停**——或者找店员，他们常常能帮您抓完 |
| **奖品哪里更便宜** | **隔壁的商店（唐吉诃德、二手店）以¥800–2,000出售同样的奖品** |

## 其他机器

| 机器 | 费用 | 备注 |
|---|---|---|
| **扭蛋（胶囊玩具）** | **每次¥300–500**（老机器¥100–200） | **不需要技巧**。一套有5–8种款式；**重复是代价**。大型扭蛋馆（池袋Sunshine City的Gashapon百货店、秋叶原的Gachapon会馆）有数千台机器。只收硬币——附近有**兑币机**；现在有些接受IC卡 |
| **大头贴机（purikura）** | **¥400–500**，4–6张照片打印成贴纸；可数字下载 | 东京的**大头贴区常常仅限女性／情侣**（单独男性禁入）；**不用脱鞋**；**浓重的美肤滤镜**是这里的审美 |
| **音乐游戏（太鼓达人、maimai、Chunithm、DDR）** | **每局¥100–200** | **排队等候（放一枚硬币或卡片排队）**；**玩完擦拭机器**（有提供湿巾）。娱乐IC卡（Aime、Banapass）可保存成绩 |
| **奖章游戏（Medal games）** | ¥100买10–20枚奖章 | **不能换成钱或奖品**——纯粹消磨时间。这是法律规定 |
| **复古街机（高田马场Mikado）** | ¥50–100 | 格斗游戏文化；注意礼仪（没有点头示意不要加入陌生人的对局） |

- **营业时间与未成年人**：大多数游戏厅**10:00–24:00**；根据各都道府县的青少年条例，**16岁以下18:00前、18岁以下22:00前离场**（有家长陪同时部分规定不同）。**吸烟**：自2020年起设独立吸烟室或室内禁烟。
- **礼仪**：**不要一个人占着机器让朋友围观**，**不拍其他玩家**，**不靠在机台上**，**归还篓子／鼓槌**。
- **大型连锁**：**GiGO（原Sega）、Taito Station、Round1（附保龄球）、Namco**。**秋叶原、池袋（Sunshine City）、大阪日本桥、名古屋大须**是主要聚集地。
- **把奖品带回家**：**毛绒玩具很占地方**——大型游戏厅的寄送柜台可以**在国内寄送奖品**；寄往国外请用日本邮政。
- **价值核算**：**一个奖品¥1,000的预算**大致就是该物品的零售上限；**超过这个数您付的是玩游戏的钱——如果您享受这个过程，那也没问题**。

> **[待核实]** 奖品价值指导数字（约¥1,000）及其法律依据；各都道府县的青少年宵禁时间；主要连锁店目前的游玩价格。
