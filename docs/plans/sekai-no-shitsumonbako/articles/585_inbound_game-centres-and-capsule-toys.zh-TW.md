# Q. 遊戲中心、夾娃娃機和轉蛋：旅客怎麼玩才不浪費錢？｜Japan Questions #585

- Shelf: `inbound` ／ URL: `/zh-tw/questions/game-centres-and-capsule-toys` ／ Status: **草稿 — 出處未核實**

日本的4,000家遊戲中心和30多萬台轉蛋機是名副其實的景點，也是旅客花¥5,000去夾一個隔壁店¥1,500就能買到的絨毛玩偶的地方。這些機器不是西方意義上的「作弊機」——它們受到監管——但技巧和機台設定都是真實存在的。

## A. 夾娃娃機（UFO catcher）是合法的娛樂機器，不是賭博；依據警察廳的指導，獎品價值上限約為¥1,000（2022年從¥800上調），而且店員理應幫忙——問一句「ちょっと手伝ってもらえますか」（可以幫我一下嗎），他們常會把獎品重新擺到好夾的位置，或示範那台機器的訣竅。給每個獎品設一個預算（¥500–1,000），先看別人玩幾局，學會兩三種標準技巧（推、勾標籤、把盒子從邊緣滑下來），到了預算就停。轉蛋（gachapon）每次¥300–500，不需要技巧；在有您想要的那一套的地方買，而不是在看到的第一台機器買。拍貼機（purikura）和音樂遊戲是另外兩個旅客最愛；注意吸菸規定和關門時間（大多數遊戲中心23:00–24:00關門，未成年人依年齡須在18:00–22:00前離場）。

## 夾娃娃機（UFO catcher）

| 事實 | 詳情 |
|---|---|
| **法律地位** | 《風俗營業法》下的娛樂機器；**獎品價值須在約¥1,000以下**（業界對法定上限的指導）——所以機器裡的絨毛玩偶不是¥5,000的東西 |
| **費用** | **每局¥100–200**，常有**¥500玩6局**；大型機台¥200–300 |
| **它們「作弊」嗎？** | **爪子的力度和設定可調，因機台而異**；業者會設定目標出獎率。**並非隨機**——一台機器要嘛一直強要嘛一直弱，所以先觀察有用 |
| **店員幫忙** | **找店員**（店員さん）。玩幾局之後，他們**把獎品移到夾得到的位置**或**示範預期的技巧**很正常。有些連鎖店有「**投入¥X後我們會幫忙**」的標示 |
| **技巧** | **推（押し）**：把盒子推過邊緣。**勾（フック）**：用一個爪尖勾住標籤／吊環。**滑（ずらし）**：分幾步把盒子沿邊緣挪過去。**橋渡（橋渡し）**：盒子橫跨兩根桿子——一次翹起一端 |
| **預算規則** | **決定每個獎品¥500–1,000；花完了還看不出明顯接近，就停**——或者找店員，他們常常能幫您夾完 |
| **獎品哪裡更便宜** | **隔壁的商店（唐吉訶德、二手店）以¥800–2,000販售同樣的獎品** |

## 其他機台

| 機台 | 費用 | 備註 |
|---|---|---|
| **轉蛋（膠囊玩具）** | **每次¥300–500**（舊機台¥100–200） | **不需要技巧**。一套有5–8種款式；**重複是代價**。大型轉蛋館（池袋Sunshine City的Gashapon百貨店、秋葉原的Gachapon會館）有數千台機器。只收硬幣——附近有**兌幣機**；現在有些接受IC卡 |
| **拍貼機（purikura）** | **¥400–500**，4–6張照片印成貼紙；可數位下載 | 東京的**拍貼區常常僅限女性／情侶**（單獨男性禁入）；**不用脫鞋**；**濃重的美肌濾鏡**是這裡的美學 |
| **音樂遊戲（太鼓達人、maimai、Chunithm、DDR）** | **每局¥100–200** | **排隊等候（放一枚硬幣或卡片排隊）**；**玩完擦拭機台**（有提供濕紙巾）。娛樂IC卡（Aime、Banapass）可保存成績 |
| **獎章遊戲（Medal games）** | ¥100買10–20枚獎章 | **不能換成錢或獎品**——純粹消磨時間。這是法律規定 |
| **復古機台（高田馬場Mikado）** | ¥50–100 | 格鬥遊戲文化；注意禮儀（沒有點頭示意不要加入陌生人的對局） |

- **營業時間與未成年人**：大多數遊戲中心**10:00–24:00**；依據各都道府縣的青少年條例，**16歲以下18:00前、18歲以下22:00前離場**（有家長陪同時部分規定不同）。**吸菸**：自2020年起設獨立吸菸室或室內禁菸。
- **禮儀**：**不要一個人占著機台讓朋友圍觀**，**不拍其他玩家**，**不靠在機台上**，**歸還籃子／鼓棒**。
- **大型連鎖**：**GiGO（原Sega）、Taito Station、Round1（附保齡球）、Namco**。**秋葉原、池袋（Sunshine City）、大阪日本橋、名古屋大須**是主要聚集地。
- **把獎品帶回家**：**絨毛玩偶很占空間**——大型遊戲中心的寄送櫃台可以**在國內寄送獎品**；寄往國外請用日本郵局。
- **價值核算**：**一個獎品¥1,000的預算**大致就是該物品的零售上限；**超過這個數您付的是玩遊戲的錢——如果您享受這個過程，那也沒問題**。

> **[待核實]** 獎品價值指導數字（約¥1,000）及其法律依據；各都道府縣的青少年宵禁時間；主要連鎖店目前的遊玩價格。
