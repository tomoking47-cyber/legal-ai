# Q. 在日本如何买到相扑和棒球的门票？现场是什么样的？｜Japan Questions #586

- Shelf: `inbound` ／ URL: `/zh-cn/questions/watching-sumo-and-baseball` ／ Status: **草稿 — 出处未核实**

大相扑和职业棒球是游客最想看的两大现场赛事，而两者都常被误解：相扑一年有六场各 15 天的本场所，门票几小时内售罄；棒球则是每晚上演的大秀，有组织有序的应援区、背着酒桶的啤酒小贩，还有第七局的气球放飞。只要了解赛程，进场其实比传言中容易得多。

## A. 相扑：大相扑本场所（本場所）每场 15 天，1 月、5 月、9 月在东京，3 月在大阪，7 月在名古屋，11 月在福冈。门票约在开幕前一个月通过日本相扑协会的官方售票网站（Ticket Oosumo，有英文页面）开售，周末和最后几天的票一天内售罄；工作日的椅子席（¥4,000–9,000）是现实的目标，包厢席（升席，¥10,000–15,000/人，4 人共用一间）需要抢速度或找转售渠道。请在 14:00 前到场，约 15:40 观看幕内力士的土俵入，比赛持续到 18:00。棒球：12 支球队，3 月至 10 月，门票 ¥2,000–8,000，可在球队官网或 Lawson/7-Eleven 的售票机购买，除巨人/阪神/软银的强强对决和季后赛外很少售罄。想感受应援文化就坐外野，想专心看比赛就坐本垒后方。

## 相扑

| 项目 | 详情 |
|---|---|
| **赛历** | **1 月、5 月、9 月：东京（两国国技馆）。3 月：大阪（Edion Arena）。7 月：名古屋（IG Arena，2025 年起）。11 月：福冈（福冈国际中心）。** 每场 **15 天，从周日开始** |
| **开售时间** | **开幕日前约 4–5 周**，日本时间 10:00，在 **Ticket Oosumo（官方，有英文）**、便利店终端机和旅行社发售。**周末和第 13–15 天的票几小时内售罄**；**工作日的椅子席能撑好几天** |
| **座位类型** | **土俵边（溜席，¥20,000）**：坐在地上的坐垫上，力士可能摔到你身上，**禁止拍照、禁止饮食**。**包厢席（升席，¥10,000–15,000/人，按 4 人一间出售）**：地上的坐垫，需脱鞋，可以吃东西。**椅子席（¥3,500–9,000）**：2 楼，性价比最高，也是外国人通常能买到的唯一票种 |
| **时间表** | **08:00** 开门；上午起为低级别力士的比赛；**十两（第二级）土俵入约 14:15**；**幕内（最高级）土俵入约 15:40**；**横纲土俵入约 15:45**；**顶级对决 16:00–18:00**。想感受气氛请 **14:00–15:00** 到场 |
| **饮食** | 馆内出售 **烤鸡串（国技馆地下现制）、便当、啤酒**；**允许自带食物** |
| **礼仪** | **比赛期间请保持坐着**，**禁止闪光灯**，**不要扔坐垫**（国技馆在冷门出现后的传统，但严格来说是被禁止的），**不必向任何东西行礼——安心观看即可**。提前离场没问题 |
| **买不到票时** | 通过旅行团参观相扑部屋的 **早晨训练（朝稽古）**（¥10,000–15,000，需严格保持安静），**非比赛期间国技馆内的相扑博物馆（免费）**，其他月份在各地举办的 **巡回演出（巡业）** |

## 棒球（NPB）

| 项目 | 详情 |
|---|---|
| **赛季** | **3 月下旬至 10 月上旬**，季后赛（Climax Series）和日本大赛在 **10–11 月**。比赛大多 **平日 18:00、周末 14:00** 开始 |
| **门票** | **外野 ¥2,000–4,000，内野 ¥4,000–8,000，高级席 ¥10,000 起**。可通过 **球队官网（部分有英文）、Lawson Ticket、Ticket Pia、7-Eleven 终端机** 以及 **当天的球场售票处（常常有票）** 购买。**巨人（东京巨蛋）、阪神（甲子园）、软银（福冈）的强强对决会售罄** |
| **球场** | **东京巨蛋（巨人）、神宫（养乐多燕子——露天，啤酒花园氛围）、横滨、甲子园（阪神——棒球圣地）、京瓷巨蛋大阪（欧力士猛牛）、福冈 PayPay 巨蛋、札幌 Escon Field（新建，附温泉）、广岛 Mazda 球场（2009 年建成，有草坪席和野餐席）、名古屋 Vantelin 巨蛋** |
| **现场表演** | **外野的应援团** 带领 **为每位打者唱的助威歌、小号、旗帜**；**第七局的"Lucky 7"**：球队歌曲和 **气球放飞（甲子园的阪神、PayPay 巨蛋的软银及其他几个球场——广岛鲤鱼 2019 年后没有恢复气球，东京巨蛋的巨人也没有）**——气球在摊位购买。背着酒桶的 **啤酒销售员（売り子）**：**每杯 ¥800–900**，可付现金或刷卡 |
| **饮食** | **球队便当、炸鸡、炒面、"球场咖喱"**；**大多数球场允许自带食物**（罐装/瓶装饮料需在门口倒入纸杯） |
| **礼仪** | **坐在自己支持球队的球迷区**；**如果在外野，助威时请起立**；**接界外球时注意安全**（可以留作纪念）；**离场时保持座位整洁**——球迷会把垃圾装袋带走 |
| **节奏** | **一场比赛 3–3.5 小时**；常规赛 **12 局后允许平局**；神宫/甲子园的夜场比赛要注意 **末班车** |

- **其他运动**：**J 联赛足球**（¥2,500–6,000，适合家庭，大俱乐部之间的德比会售罄）、**B 联赛篮球**、**橄榄球（Japan Rugby League One，12 月至 5 月）**——门票都很好买。**甲子园高中棒球（8 月）** 是全国性盛事，票价便宜（2022 年起全部座位对号入座且收费——外野约 ¥700 起，内野 ¥2,000–4,000，提前在线出售），气氛堪称传奇。
- **转售**：相扑（Ticket Oosumo）和部分球队有官方转售平台；**黄牛倒票属违法（2019 年法律）**，场馆外的黄牛卖的是假票。
- **带孩子**：棒球非常合适；相扑的下午时长更适合年龄稍大的孩子。

> **[待核实]** 开售日期和票价请以当期比赛公告为准；各球场关于外带食物和气球的具体规定；当年 NPB 赛季日期。
