# Q. 在日本要怎麼買相撲和棒球的票？現場會是什麼樣子？｜Japan Questions #586

- Shelf: `inbound` ／ URL: `/zh-tw/questions/watching-sumo-and-baseball` ／ Status: **草稿 — 出處未核實**

大相撲和職業棒球是旅客最想看的兩大現場賽事，而兩者都常被誤解：相撲一年有六場各 15 天的本場所，門票幾小時內就賣完；棒球則是每晚上演的大秀，有組織的應援區、背著酒桶的啤酒小販，還有第七局的氣球施放。只要掌握賽程，進場其實比傳言中容易得多。

## A. 相撲：大相撲本場所（本場所）每場 15 天，1 月、5 月、9 月在東京，3 月在大阪，7 月在名古屋，11 月在福岡。門票約在開幕前一個月透過日本相撲協會的官方售票網站（Ticket Oosumo，有英文頁面）開賣，週末和最後幾天的票一天內就售完；平日的椅子席（¥4,000–9,000）是實際可行的目標，包廂席（升席，¥10,000–15,000/人，4 人共用一間）得比手速或找轉售管道。請在 14:00 前到場，約 15:40 觀看幕內力士的土俵入，比賽持續到 18:00。棒球：12 支球隊，3 月至 10 月，門票 ¥2,000–8,000，可在球隊官網或 Lawson/7-Eleven 的售票機購買，除了巨人/阪神/軟銀的強強對決和季後賽之外很少售完。想感受應援文化就坐外野，想專心看球就坐本壘後方。

## 相撲

| 項目 | 詳情 |
|---|---|
| **賽曆** | **1 月、5 月、9 月：東京（兩國國技館）。3 月：大阪（Edion Arena）。7 月：名古屋（IG Arena，2025 年起）。11 月：福岡（福岡國際中心）。** 每場 **15 天，從星期日開始** |
| **開賣時間** | **開幕日前約 4–5 週**，日本時間 10:00，在 **Ticket Oosumo（官方，有英文）**、便利商店機台和旅行社發售。**週末和第 13–15 天的票幾小時內售完**；**平日的椅子席可以撐好幾天** |
| **座位種類** | **土俵邊（溜席，¥20,000）**：坐在地上的坐墊，力士可能摔到你身上，**禁止拍照、禁止飲食**。**包廂席（升席，¥10,000–15,000/人，以 4 人一間出售）**：地上的坐墊，要脫鞋，可以吃東西。**椅子席（¥3,500–9,000）**：2 樓，CP 值最高，也是外國人通常唯一買得到的票種 |
| **時間表** | **08:00** 開門；上午起為低階力士的比賽；**十兩（第二級）土俵入約 14:15**；**幕內（最高級）土俵入約 15:40**；**橫綱土俵入約 15:45**；**頂級對決 16:00–18:00**。想感受氣氛請 **14:00–15:00** 到場 |
| **飲食** | 館內販售 **烤雞串（國技館地下現做）、便當、啤酒**；**可以自帶食物入場** |
| **禮儀** | **比賽期間請保持坐著**，**禁用閃光燈**，**不要丟坐墊**（國技館在冷門出現後的傳統，但嚴格來說是被禁止的），**不必向任何東西行禮——安心觀賞即可**。提早離場沒問題 |
| **買不到票時** | 透過旅行團參觀相撲部屋的 **早晨練習（朝稽古）**（¥10,000–15,000，須嚴格保持安靜），**非比賽期間國技館內的相撲博物館（免費）**，其他月份在各地舉辦的 **巡迴演出（巡業）** |

## 棒球（NPB）

| 項目 | 詳情 |
|---|---|
| **賽季** | **3 月下旬至 10 月上旬**，季後賽（Climax Series）和日本大賽在 **10–11 月**。比賽大多 **平日 18:00、週末 14:00** 開打 |
| **門票** | **外野 ¥2,000–4,000，內野 ¥4,000–8,000，高級席 ¥10,000 起**。可透過 **球隊官網（部分有英文）、Lawson Ticket、Ticket Pia、7-Eleven 機台** 以及 **當天的球場售票口（常常有票）** 購買。**巨人（東京巨蛋）、阪神（甲子園）、軟銀（福岡）的強強對決會售完** |
| **球場** | **東京巨蛋（巨人）、神宮（養樂多燕子——露天，啤酒花園氛圍）、橫濱、甲子園（阪神——棒球聖地）、京瓷巨蛋大阪（歐力士猛牛）、福岡 PayPay 巨蛋、札幌 Escon Field（新建，附溫泉）、廣島 Mazda 球場（2009 年落成，有草坪席和野餐席）、名古屋 Vantelin 巨蛋** |
| **現場表演** | **外野的應援團** 帶領 **每位打者專屬的應援歌、小號、旗幟**；**第七局的「Lucky 7」**：球隊歌曲和 **氣球施放（甲子園的阪神、PayPay 巨蛋的軟銀及其他幾座球場——廣島鯉魚 2019 年後沒有恢復氣球，東京巨蛋的巨人也沒有）**——氣球在攤位購買。背著酒桶的 **啤酒販售員（売り子）**：**每杯 ¥800–900**，可付現或刷卡 |
| **飲食** | **球隊便當、炸雞、炒麵、「球場咖哩」**；**大多數球場允許自帶食物**（罐裝/瓶裝飲料要在門口倒入紙杯） |
| **禮儀** | **坐在自己支持球隊的球迷區**；**如果在外野，應援時請起立**；**接界外球時注意安全**（可以留作紀念）；**離場時保持座位整潔**——球迷會把垃圾裝袋帶走 |
| **節奏** | **一場比賽 3–3.5 小時**；例行賽 **12 局後允許和局**；神宮/甲子園的夜間比賽要注意 **末班車** |

- **其他運動**：**J 聯賽足球**（¥2,500–6,000，適合家庭，大球會之間的德比會售完）、**B 聯賽籃球**、**橄欖球（Japan Rugby League One，12 月至 5 月）**——票都很好買。**甲子園高中棒球（8 月）** 是全國性盛事，票價便宜（2022 年起全部座位對號入座且收費——外野約 ¥700 起，內野 ¥2,000–4,000，事先線上販售），氣氛堪稱傳奇。
- **轉售**：相撲（Ticket Oosumo）和部分球隊有官方轉售平台；**黃牛轉售屬違法（2019 年法律）**，場館外的黃牛賣的是假票。
- **帶小孩**：棒球非常合適；相撲的下午時長比較適合年紀稍大的小孩。

> **[待核實]** 開賣日期和票價請以當期比賽公告為準；各球場關於外帶食物和氣球的具體規定；當年 NPB 賽季日期。
