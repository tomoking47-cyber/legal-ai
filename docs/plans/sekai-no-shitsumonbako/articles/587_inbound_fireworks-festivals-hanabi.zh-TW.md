# Q. 日本的花火大會是怎麼運作的？旅客要怎麼找到好位置？｜Japan Questions #587

- Shelf: `inbound` ／ URL: `/zh-tw/questions/fireworks-festivals-hanabi` ／ Status: **草稿 — 出處未核實**

日本每年夏天舉辦 1,000 多場花火大會（花火大会），有些在 90 分鐘內向上百萬觀眾發射 20,000 發煙火。它們免費、壯觀，而且在後勤上極為艱苦——散場後的交通擠壓是每位旅客都會低估的部分。

## A. 花火季從 7 月下旬到 8 月下旬（秋冬也有少數場次）。大型花火大會——隅田川（東京，7 月最後一個星期六，約 95 萬人）、長岡（新潟，8 月 2–3 日）、大曲（秋田，8 月下旬，全國競技大會）、琵琶湖、大阪淀川、PL（大阪，8 月上旬）——大多可在指定的公共區域免費觀賞（長岡的主會場現在已全面收費），但想要好視野，要嘛買付費預約席（¥3,000–15,000，6 月開賣，會售完），要嘛提早 4–6 小時帶著墊子去佔位。散場後的電車才是真正的擠壓：進站預計要 60–90 分鐘。喜歡的話可以穿浴衣（當地人就是這麼穿），帶墊子、水、防蚊液和在小吃攤用的現金，查清雨天順延規則，並把垃圾帶走。

## 怎樣看得好

| 項目 | 建議 |
|---|---|
| **座位** | **預約席 5–6 月在 Lawson Ticket / Ticket Pia / 各花火大會官網開賣**，常為抽籤制；**JTB 和飯店方案** 會搭配座位。長岡、大曲、大阪值得買 |
| **免費位置** | **提早 4–6 小時到**，鋪一張 **墊子（任何百圓商店都有的藍色防水布）**，**一個人可以幫一小群人佔位**（別用膠帶圈出大片區域——當地人會反對）。隅田川的橋上禁止站立觀賞 |
| **要帶的東西** | **墊子、水（每人 2 L）、防蚊液、隨身電扇、現金（小吃攤只收現金）、垃圾袋、濕紙巾、手電筒、行動電源**（網路壅塞很耗電） |
| **穿著** | **歡迎穿浴衣**（淺草租一套 ¥3,000–6,000）；走路多，要穿 **舒服的鞋**；**20:00 仍有 28–30°C** |
| **飲食** | **小吃攤（屋台）**：炒麵、刨冰、章魚燒、啤酒，每份 ¥500–800。**開場前排隊很長，要早點吃** |
| **交通** | **壓軸煙火結束後：進站要 60–90 分鐘**；**站務人員會實施入場管制**。可選：**壓軸前 10 分鐘離場**、**走到 2–3 站以外**、**訂步行可達的飯店**、**留下喝一杯，晚點再走（22:30 以後）** |
| **雨天** | 每場花火大會都有 **順延日（順延）** 或 **取消規則**；**小雨照常舉行**；**15:00 前查看官網/X** |
| **廁所** | **流動廁所要排 20–30 分鐘**；坐下前先去；會場附近的便利商店會關閉廁所 |
| **垃圾** | **帶回家** 或拿到指定回收點；隔天早上的垃圾是花火大會最大的問題 |
| **拍照** | 三腳架僅限指定區域；**禁止無人機**（在花火大會屬違法） |

- **規模較小的花火大會**（5,000–10,000 發，觀眾數萬人）：**熱海（每年夏天多個日期）、鎌倉、調布、板橋**；神戶現在以連續幾晚各 10 分鐘的短場（「Minato HANABI」）取代一晚的大場——它們能帶來 **90% 的觀賞體驗，而擠壓程度只有一小部分**，帶小孩時是不錯的選擇。
- **為什麼日本的煙火不一樣**：**日本煙火彈是球形的，炸開時對稱（菊花形）**，依尺寸以 **尺（30 cm）** 分級；**長岡的正三尺玉（3 尺，90 cm）炸開直徑達 650 m**。
- **現場的花火禮儀**：**表演期間不要站起來**，喜歡的話可以喊 **「玉屋！」（たまや，江戶時代傳下來的歡呼）**，**關掉閃光燈**。
- **安全**：熱衰竭是主要風險（見相關文章）；**把小孩扛在肩上會擋住別人的視線**——帶一個小踏凳。

> **[待核實]** 日期、發數和觀眾人數請以各花火大會當年官網為準；預約席的販售時間和價格。
