# Q. 到日本出差：名片、会议，以及真正重要的礼仪｜Japan Questions #589

- Shelf: `inbound` ／ URL: `/zh-cn/questions/business-etiquette-meishi` ／ Status: **草稿 — 出处未核实**

到日本出差的人收到的建议远多于他们用得上的——鞠躬的角度、座次、双手递名片。大部分只是锦上添花。真正会改变一场会议走向的只有少数几点，其余的，只要外国人看得出在努力，都会被原谅。

## A. 三件事承担了大部分分量：带足名片（名刺，meishi）并正确交换——起身，双手递出，姓名和公司朝向对方，双手接过，读一读，会议期间把名片摆在自己面前的桌上，绝不放进后裤袋；守时，也就是提前 5–10 分钟到；以及理解会议往往是为了确认事先已经谈妥的事情，因此决定是在会议之间由那些负责协调共识的人（根回し，nemawashi）做出的，而「我们会研究一下」（検討します，kentō shimasu）经常意味着不行。着装保守，按照对方给你的引导入座（客人坐离门最远的位置），让对方那边职位最高的人主导寒暄。首次见面送礼并非必须；一件来自家乡的、包装好的小小地方特产会很受欢迎。

## 名片（名刺）

| 该做的 | 不该做的 |
|---|---|
| 一周的会议 **准备 50–100 张**；**背面印有日文的名片** 会受到欣赏（日本的印刷店一天就能做好，¥3,000–5,000） | 用完了——这会被看作没有准备 |
| **起身**，**一次一位、从职位高的人开始** 交换；**双手递出**，文字朝向对方，**报出自己的姓名和公司** | 单手递出，或把名片从桌面滑过去 |
| **双手接过**，**读一读（姓名、职务）**，说「ありがとうございます」或「よろしくお願いします」 | 马上塞进口袋 |
| **把收到的名片摆在自己面前的桌上**，按座次排列（最上面那张 = 职位最高的人），**整场会议都这样放着** | 在上面写字、把它折弯、放进后裤袋，或者忘了带走 |
| **名片夹**（¥1,000–3,000）——会后再把名片收进名片夹 | 放钱包里或散在包里 |

## 会议

| 项目 | 会是什么样 |
|---|---|
| **时间** | **提前 5–10 分钟到**；哪怕只迟到 5 分钟，也应当事先打电话致歉、见面后再当面致歉 |
| **座次** | **等对方引导**；客人坐 **离门最远的位置（上座，kamiza）**，主人坐离门最近的位置。受邀后再坐下 |
| **谈话顺序** | 由对方的资深者主导 **寒暄（天气、你的行程、他们的城市）**；然后进入议程。**资深者说话时，他们团队的其他人可能一言不发**——沉默是在思考，不是不同意 |
| **决定** | **很少在会议室里做出。** 提案会事先在内部流转（**根回し**），并通过 **稟議（りんぎ，ringi，逐级会签）** 获得批准。请 **提前 3–5 天发送资料**；预料会听到 **「我们会研究一下」（検討します）**，这往往是委婉的拒绝或「还不到时候」 |
| **「是」** | 「**はい**」的意思是「我在听」，不是「我同意」。真正的信号是 **具体的下一步** |
| **口译** | 用 **短句** 说话，留出停顿；**看着对方，而不是口译员** |
| **资料** | **给每个人准备纸质讲义**（现在仍然常见），**内容详细、有数字**；日方会仔细阅读幻灯片 |
| **结束** | 主人可能会 **送你到电梯或大楼门口，并一直鞠躬到电梯门关上**——请转身回礼 |
| **后续** | **当天用邮件致谢**；详细的会议纪要很受重视 |

## 着装、礼物、餐叙

- **着装**：男性 **深色西装、白色或浅色衬衫、保守的领带**；女性 **套装或连衣裙加外套、低跟鞋、首饰从简**。**Cool Biz（清凉商务，5–9 月）意味着许多公司可以不穿外套、不打领带**——跟着主人的做法走。**进办公室前先脱掉大衣**。
- **礼物**：**并非必须**；在结束时递上一件来自家乡的 **小巧、包装好的地方特产**（点心、茶、当地手工艺品），并说「**つまらないものですが**」（不成敬意）。避免 **四件一套**、**刀具**，以及 **过于贵重的东西**（会造成人情负担）。
- **餐叙（接待，settai）**：**由主人点菜、由主人斟酒，就让他们来**；**别人给你斟酒时把杯子端起来**；**也为别人斟酒**；**等到干杯（乾杯）再喝**；**不要直接拒绝食物——吃一小份就可以**；**由主人买单**——不要抢着付账；**回到自己的主场时再回请**。喝酒并非必须，如今拒绝也是可以接受的。
- **称呼与职务**：**姓氏 + さん**（「田中さん」）；**职务（部长 buchō ＝部门负责人，课长 kachō ＝科室主管，社长 shachō ＝公司总裁）** 会被他们的下属用来代替姓名。**商务场合不使用名字（first name）**。
- **鞠躬**：**打招呼时点头式鞠躬（15°），致谢或致歉时 30°**；**与外国人握手也很常见**——跟着对方来，不要别扭地把鞠躬和握手混在一起。没有人指望你鞠躬鞠得标准。
- **语言**：几句话——**はじめまして（初次见面）、よろしくお願いします（今后请多关照）、お世話になります（承蒙关照）**——能带来远超其分量的善意。
- **印章与合同**：许多公司仍然用 **公司印章（判子，hanko）** 签署合同；**电子签名** 自 2020 年起在普及。**日本的合同比西方的短，关系本身有分量**——会前建立的关系比逐条谈判更重要。
- **对外国人的宽容度**：只要努力看得出来，**失误是会被原谅的**。不可原谅的是 **迟到、随便对待名片，以及在会议室里逼对方当场做决定**。
