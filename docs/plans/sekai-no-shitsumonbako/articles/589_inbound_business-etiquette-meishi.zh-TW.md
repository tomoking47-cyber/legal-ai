# Q. 到日本出差：名片、會議，以及真正重要的禮儀｜Japan Questions #589

- Shelf: `inbound` ／ URL: `/zh-tw/questions/business-etiquette-meishi` ／ Status: **草稿 — 出處未核實**

到日本出差的人收到的建議遠多於他們用得上的——鞠躬的角度、座次、雙手遞名片。大部分只是錦上添花。真正會改變一場會議走向的只有少數幾點，其餘的，只要外國人看得出在努力，都會被原諒。

## A. 三件事承擔了大部分的分量：帶足名片（名刺，meishi）並正確交換——起身，雙手遞出，姓名與公司朝向對方，雙手接過，讀一讀，會議期間把名片擺在自己面前的桌上，絕不放進後褲袋；守時，也就是提早 5–10 分鐘到；以及理解會議往往是為了確認事前已經談妥的事，因此決定是在會議與會議之間，由負責協調共識的人（根回し，nemawashi）做出的，而「我們會研究一下」（検討します，kentō shimasu）經常等於不行。穿著保守，依對方給你的引導入座（客人坐離門最遠的位置），讓對方那邊職位最高的人主導寒暄。第一次見面送禮並非必要；一件來自家鄉、包裝好的小小地方特產會很受歡迎。

## 名片（名刺）

| 該做的 | 不該做的 |
|---|---|
| 一週的會議 **準備 50–100 張**；**背面印有日文的名片** 會受到欣賞（日本的印刷店一天就能做好，¥3,000–5,000） | 用完了——這會被看成沒有準備 |
| **起身**，**一次一位、從職位高的人開始** 交換；**雙手遞出**，文字朝向對方，**報上自己的姓名與公司** | 單手遞出，或把名片從桌面滑過去 |
| **雙手接過**，**讀一讀（姓名、職稱）**，說「ありがとうございます」或「よろしくお願いします」 | 馬上塞進口袋 |
| **把收到的名片擺在自己面前的桌上**，依座次排列（最上面那張 = 職位最高的人），**整場會議都這樣放著** | 在上面寫字、把它折彎、放進後褲袋，或者忘了帶走 |
| **名片夾**（¥1,000–3,000）——會後再把名片收進名片夾 | 放皮夾裡或散在包包裡 |

## 會議

| 項目 | 會是什麼樣 |
|---|---|
| **時間** | **提早 5–10 分鐘到**；就算只遲到 5 分鐘，也應該事先打電話致歉、見面後再當面致歉 |
| **座次** | **等對方引導**；客人坐 **離門最遠的位置（上座，kamiza）**，主人坐離門最近的位置。受邀後再坐下 |
| **談話順序** | 由對方的資深者主導 **寒暄（天氣、你的行程、他們的城市）**；接著進入議程。**資深者說話時，他們團隊的其他人可能一言不發**——沉默是在思考，不是不同意 |
| **決定** | **很少在會議室裡做出。** 提案會事先在內部流轉（**根回し**），並透過 **稟議（りんぎ，ringi，逐級會簽）** 取得核可。請 **提前 3–5 天寄出資料**；預期會聽到 **「我們會研究一下」（検討します）**，這往往是委婉的拒絕或「還不到時候」 |
| **「是」** | 「**はい**」的意思是「我在聽」，不是「我同意」。真正的訊號是 **具體的下一步** |
| **口譯** | 用 **短句** 說話，留出停頓；**看著對方，而不是口譯員** |
| **資料** | **為每個人準備紙本講義**（現在仍然常見），**內容詳細、有數字**；日方會仔細閱讀簡報 |
| **結束** | 主人可能會 **送你到電梯或大樓門口，並一直鞠躬到電梯門關上**——請轉身回禮 |
| **後續** | **當天以電子郵件致謝**；詳細的會議紀錄很受重視 |

## 穿著、禮物、餐敘

- **穿著**：男性 **深色西裝、白色或淺色襯衫、保守的領帶**；女性 **套裝或洋裝加外套、低跟鞋、首飾從簡**。**Cool Biz（清涼商務，5–9 月）意味著許多公司可以不穿外套、不打領帶**——跟著主人的做法走。**進辦公室前先脫掉大衣**。
- **禮物**：**並非必要**；在結束時遞上一件來自家鄉的 **小巧、包裝好的地方特產**（點心、茶、當地工藝品），並說「**つまらないものですが**」（不成敬意）。避免 **四件一組**、**刀具**，以及 **過於貴重的東西**（會造成人情負擔）。
- **餐敘（接待，settai）**：**由主人點菜、由主人斟酒，就讓他們來**；**別人替你斟酒時把杯子端起來**；**也替別人斟酒**；**等到乾杯（乾杯）再喝**；**不要直接拒絕食物——吃一小份就好**；**由主人買單**——不要搶著付帳；**回到自己的主場時再回請**。喝酒並非必要，如今婉拒也是可以接受的。
- **稱呼與職稱**：**姓氏 + さん**（「田中さん」）；**職稱（部長 buchō ＝部門主管，課長 kachō ＝科室主管，社長 shachō ＝公司負責人）** 會被他們的部屬拿來代替姓名。**商務場合不使用名字（first name）**。
- **鞠躬**：**打招呼時點頭式鞠躬（15°），致謝或致歉時 30°**；**與外國人握手也很常見**——跟著對方來，不要彆扭地把鞠躬和握手混在一起。沒有人期待你鞠躬鞠得標準。
- **語言**：幾句話——**はじめまして（初次見面）、よろしくお願いします（今後請多指教）、お世話になります（承蒙關照）**——能帶來遠超其分量的善意。
- **印章與合約**：許多公司仍然用 **公司印章（判子，hanko）** 簽署合約；**電子簽名** 自 2020 年起在普及。**日本的合約比西方的短，關係本身有分量**——會前建立的關係比逐條談判更重要。
- **對外國人的寬容度**：只要努力看得出來，**失誤是會被原諒的**。不可原諒的是 **遲到、隨便對待名片，以及在會議室裡逼對方當場做決定**。
