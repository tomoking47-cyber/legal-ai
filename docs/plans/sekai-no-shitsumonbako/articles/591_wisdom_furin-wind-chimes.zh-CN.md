# Q. 关于日本夏天的风铃（風鈴），人们常有哪些误解？｜Japanese Everyday Wisdom #591

- Shelf: `wisdom` ／ URL: `/zh-cn/wisdom/furin-wind-chimes` ／ Status: **草稿 — 出处未核实**

一只玻璃或铁制的小钟，钟舌下垂着一条纸条，在屋檐下叮当作响：风铃（風鈴）是日本夏天的声音，在 7 月的庙会上出售，在第一个炎热的星期挂起。它看上去像装饰品。其实它是一种作用于心理的"降温装置"、一种提醒空气在流动的信号——而在现代公寓楼里，它也是一桩随时可能发生的噪音投诉。

## A. 常见的误解是认为风铃根本不能降温。日本的研究测到，人们听到风铃声时，体感温度和皮肤温度会略有下降——声音传递"有风"的信号，大脑随之反应——因此风铃应该挂在有风的地方，而不是好看的地方。第二个误解是以为人人都喜欢这个声音：在密集的住宅区，凌晨 03:00 邻居家的风铃是经典的投诉对象，许多楼宇会要求住户在夜间或台风季把风铃收进屋内。把它挂在屋内听得见、又有风的位置，风大时收进来，9 月就收起——按江户的传统，过了季节还挂着风铃是失礼的。

## 风铃是什么、怎么用

| 项目 | 说明 |
|---|---|
| **种类** | **江户风铃（江戸風鈴）**：手工吹制玻璃、内侧彩绘，**¥1,500–4,000**；**南部铁器（南部鉄器）**：铸铁（岩手），余音清亮悠长，¥2,000–5,000；**陶瓷、青铜（高冈）、竹制**。每种音高与余韵各不相同 |
| **纸条（短册）** | 承接风力、带动钟舌；**上面常写有诗句或心愿**。破损即更换——没有短册的风铃几乎不响 |
| **所谓"降温"** | 2010 年代日本的一项实验发现，在温暖的房间里听到风铃声的受试者，**皮肤温度下降约 0.5–1°C**；**体感温度下降更多**。**这是联想效应，不是物理降温**——但真实到空调厂商也曾用过风铃声 |
| **挂在哪里** | **屋檐下，或有傍晚凉风吹过的窗边**，**南侧或东侧**；**住公寓的话挂在窗内**；**切勿挂在邻居阳台上方** |
| **什么时候挂** | **6 月下旬/7 月（梅雨结束后）到 8 月底**；**9 月收起**——挂到秋天会被看作疏于打理 |
| **风** | **风力超过微风就收进来**：强风中的风铃会不停地响（这正是投诉的来源），**玻璃风铃还会撞上窗框破碎** |
| **夜间** | 在密集住宅区，**22:00 以后收进屋内或固定钟舌**；许多公寓的管理规约明确提到风铃 |
| **保养** | **玻璃用干布擦拭**；**南部铁器沾水会生锈——雨后要擦干**；用纸包好收纳 |

- **噪音礼节**：**夜间声音能传到 20–30 米远**；**在无风的静夜里持续作响的风铃，说明有 1–2 m/s 的风只吹到你家阳台，而没有吹到别处**——先确认是不是自己家的。**每年 7 月，公寓管理组合的通讯里都会出现关于风铃的投诉。** 许多人采取的折中办法是：**只在自己在家且醒着的时候挂**。
- **起源**：**佛寺的风铎（風鐸）**挂在塔的四角用来驱除灾厄；**江户时代的玻璃吹制**使其成为家庭用品；**卖风铃的小贩（風鈴売り）**扛着货架穿行街巷——那声音就是夏天的广告。
- **哪里买**：**川崎大师风铃市（7 月，汇集全国 30,000 只风铃）**、**西新井大师（东京，7 月）**、**不忍池及浅草一带的店铺**，以及**可以自己描绘图案的江户风铃工坊（篠原，¥1,500–2,500）**。
- **现代替代品**：**太阳能风铃、手机应用**——关键在于与凉风的联想，所以只有真正有风时才响的窗挂式风铃效果最好。
- **儿童与宠物**：挂在 **1.8 米以上**；阳台上的玻璃碎片是最常见的事故。
