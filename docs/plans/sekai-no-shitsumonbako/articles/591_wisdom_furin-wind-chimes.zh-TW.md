# Q. 關於日本夏天的風鈴（風鈴），人們常有哪些誤解？｜Japanese Everyday Wisdom #591

- Shelf: `wisdom` ／ URL: `/zh-tw/wisdom/furin-wind-chimes` ／ Status: **草稿 — 出處未核實**

一個玻璃或鐵製的小鐘，鐘舌下垂著一條紙片，在屋簷下叮叮作響：風鈴（風鈴）是日本夏天的聲音，在 7 月的廟會上販售，在第一個炎熱的星期掛起。它看起來像裝飾品。其實它是一種作用於心理的「降溫裝置」、一種提醒空氣在流動的訊號——而在現代公寓大樓裡，它也是一樁隨時可能發生的噪音投訴。

## A. 常見的誤解是認為風鈴根本不能降溫。日本的研究測到，人們聽到風鈴聲時，體感溫度與皮膚溫度會略為下降——聲音傳遞「有風」的訊號，大腦隨之反應——因此風鈴應該掛在有風的地方，而不是好看的地方。第二個誤解是以為人人都喜歡這個聲音：在密集的住宅區，凌晨 03:00 鄰居家的風鈴是經典的投訴對象，許多大樓會要求住戶在夜間或颱風季把風鈴收進屋內。把它掛在屋內聽得到、又有風的位置，風大時收進來，9 月就收起——按江戶的傳統，過了季節還掛著風鈴是失禮的。

## 風鈴是什麼、怎麼用

| 項目 | 說明 |
|---|---|
| **種類** | **江戶風鈴（江戸風鈴）**：手工吹製玻璃、內側彩繪，**¥1,500–4,000**；**南部鐵器（南部鉄器）**：鑄鐵（岩手），餘音清亮悠長，¥2,000–5,000；**陶瓷、青銅（高岡）、竹製**。每種音高與餘韻各不相同 |
| **紙片（短冊）** | 承接風力、帶動鐘舌；**上面常寫有詩句或心願**。破損即更換——沒有短冊的風鈴幾乎不響 |
| **所謂「降溫」** | 2010 年代日本的一項實驗發現，在溫暖的房間裡聽到風鈴聲的受試者，**皮膚溫度下降約 0.5–1°C**；**體感溫度下降更多**。**這是聯想效應，不是物理降溫**——但真實到冷氣廠商也曾用過風鈴聲 |
| **掛在哪裡** | **屋簷下，或有傍晚涼風吹過的窗邊**，**南側或東側**；**住公寓的話掛在窗內**；**切勿掛在鄰居陽台上方** |
| **什麼時候掛** | **6 月下旬/7 月（梅雨結束後）到 8 月底**；**9 月收起**——掛到秋天會被看作疏於打理 |
| **風** | **風力超過微風就收進來**：強風中的風鈴會不停地響（這正是投訴的來源），**玻璃風鈴還會撞上窗框破裂** |
| **夜間** | 在密集住宅區，**22:00 以後收進屋內或固定鐘舌**；許多大樓的管理規約明確提到風鈴 |
| **保養** | **玻璃用乾布擦拭**；**南部鐵器沾水會生鏽——雨後要擦乾**；用紙包好收納 |

- **噪音禮節**：**夜間聲音能傳到 20–30 公尺遠**；**在無風的靜夜裡持續作響的風鈴，代表有 1–2 m/s 的風只吹到你家陽台、沒有吹到別處**——先確認是不是自己家的。**每年 7 月，大樓管理委員會的通訊裡都會出現關於風鈴的投訴。** 許多人採取的折衷辦法是：**只在自己在家且醒著的時候掛**。
- **起源**：**佛寺的風鐸（風鐸）**掛在塔的四角用來驅除災厄；**江戶時代的玻璃吹製**使其成為家庭用品；**賣風鈴的小販（風鈴売り）**扛著貨架穿行街巷——那聲音就是夏天的廣告。
- **哪裡買**：**川崎大師風鈴市（7 月，匯集全國 30,000 個風鈴）**、**西新井大師（東京，7 月）**、**不忍池及淺草一帶的店家**，以及**可以自己彩繪圖案的江戶風鈴工坊（篠原，¥1,500–2,500）**。
- **現代替代品**：**太陽能風鈴、手機 App**——關鍵在於與涼風的聯想，所以只有真正有風時才響的窗掛式風鈴效果最好。
- **兒童與寵物**：掛在 **1.8 公尺以上**；陽台上的玻璃碎片是最常見的事故。

> **[待核實]** 皮膚溫度研究（日本大學/冷氣廠商研究，2010 年代）應精確引用；季節習俗部分為編輯意見。
