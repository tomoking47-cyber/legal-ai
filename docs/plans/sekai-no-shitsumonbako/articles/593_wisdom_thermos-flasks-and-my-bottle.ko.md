# Q. 일본의 「마이 보틀(マイボトル)」 습관과 보온병에 대해 사람들이 흔히 오해하는 것은?｜Japanese Everyday Wisdom #593

- Shelf: `wisdom` ／ URL: `/ko/wisdom/thermos-flasks-and-my-bottle` ／ Status: **초안 — 출처 미확인**

진공 보온병을 발명한 것은 일본이 아닙니다 — 1892년 제임스 듀어(James Dewar)가 처음 만들었고, 써모스〈Thermos〉 브랜드는 1904년 독일에서 시작했습니다 — 다만 일본이 이를 집집마다 쓰는 생활용품으로 만들었고(써모스는 1989년부터 일본 기업 소유이며, 조지루시〈Zojirushi〉와 타이거〈Tiger〉는 오사카 회사입니다), 일본 사람들은 이를 어디든 들고 다닙니다. 직장인은 350ml의 뜨거운 차를, 아이들은 800ml의 차가운 보리차를, 등산객은 컵라면용 끓는 물 500ml를 챙깁니다. 이 습관은 돈과 플라스틱을 아껴 주지만, 대부분의 사용자가 무시하는 위생 문제도 안고 있습니다.

## A. 흔한 오해는 보온병을 「한 번 채우면 신경 쓸 필요 없는 물건」으로 여기는 것입니다. 스테인리스 진공 보온병은 음료를 6시간 동안 뜨겁게(60°C 이상), 6–8시간 동안 차갑게(10°C 이하) 유지하는데, 바로 그 때문에 잘못된 내용물에는 위험합니다. 우유, 국, 주스, 스포츠 음료가 미지근한 온도에 머물면 세균이 번식하고, 탄산 음료나 발효하는 음료는 압력이 찹니다. 물, 차, 커피, 맹물 끓인 것에만 사용하고, 뚜껑 패킹과 내부를 매일 병 세척 브러시로 씻고, 주 1회 희석한 산소계 표백제에 담가 두고(염소계는 절대 금물 — 강철을 부식시킵니다), 패킹은 1–2년마다 교체하십시오. 스포츠 음료와 염분이 든 음료에는 「스포츠 음료 대응」 모델이 필요하고, 아이용 보틀은 빨대 부품을 매일 분해해야 합니다.

## 보온병과 그 한계

| 항목 | 내용 |
|---|---|
| **성능** | 일반적인 500ml 스테인리스 보온병: **뜨거운 물 95°C → 6시간 후 70°C 이상; 찬물 4°C → 6시간 후 8°C 이하**(제조사 표시 기준). 미리 뜨거운 물/찬물로 예열·예냉하면 더 좋음 |
| **용량** | **200–350ml(사무실, 핸드백), 500ml(표준), 750–1,000ml(학교, 운동, 등산)**. **물 1L는 1kg** — 아이의 가방이 무거워짐 |
| **넣어도 되는 것** | **물, 차(보리차〈麦茶, 무기차〉, 녹차), 커피, 라면용 뜨거운 물**; **스포츠 음료는 「スポーツドリンク対応」(스포츠 음료 대응) 표시 모델에만**(내부 코팅 — 염분이 일반 강철을 부식시킴) |
| **넣지 말아야 할 것** | **우유, 유제품, 국, 미소시루, 주스, 스무디**(미지근한 온도에서 세균 번식; 약간의 압력) — **푸드 자(スープジャー) 모델**에 펄펄 끓는 상태로 담아 **6시간 이내**에 먹는 경우는 예외; **탄산 음료, 술, 발효하는 음료**(압력, 뚜껑이 튀어나갈 수 있음); **드라이아이스** |
| **매일 세척** | **뚜껑을 분해**(패킹, 고무 링, 빨대 부품)해서 **중성 세제와 병 브러시로 씻고**, **뚜껑을 열어 뒤집어 말리기**. **패킹 홈**이 검은 곰팡이가 사는 곳 |
| **매주** | **본체와 부품을 산소계 표백제에 담가 두기(40°C, 30분)** — 찻물 얼룩과 냄새 제거. **염소계 표백제는 절대 금물**(스테인리스에 점 부식) **금속 수세미도 금물**(내부에 흠집 → 세균) |
| **패킹** | **1–2년마다** 또는 변색·갈라짐이 보이면 교체; 제조사가 모델 번호별로 부품 판매(¥300–800) |
| **식기세척기** | **대부분의 보온병은 식기세척기 사용 불가**(진공 밀봉과 도장); 뚜껑은 가능한 경우가 많음 — 설명서 확인 |
| **찌그러짐** | 찌그러진 보온병은 **진공이 깨졌을** 수 있음 — 뜨거운 내용물을 넣었을 때 바깥이 따뜻해지면 단열이 사라진 것 |

- **「마이 보틀」 문화**: 카페는 개인 컵을 가져오면 **¥20–50 할인**(스타벅스 재팬 ¥22); **사무실에는 리필용 온수기와 차 코너**가 있음; **학교는 이름을 붙인 보틀을 요구**하고 넣을 수 있는 것을 정함(물 또는 보리차, 주스 금지). **무기차(보리차)**는 카페인이 없고 끓이는 비용이 싸서 여름의 기본 음료.
- **수분 보충과 열사병**: **여름 야외에서는 2–3시간마다 500ml**, 일할 때는 더 많이; 페트병은 한 시간이면 30°C에 이르는데 **차가운 보온병은 물을 마실 만한 온도로 유지**(열사병 글 참조).
- **산에서의 뜨거운 물**: **95°C로 채운 500ml 보온병은 4–5시간 뒤에도 컵라면 하나와 커피 한 잔에 충분** — 등산객의 표준.
- **아이용 보틀**: **빨대형은 우유와 주스 잔여물이 남으므로 매일 분해**; **빨대는 몇 달마다 교체**; **어깨끈 커버는 떨어뜨렸을 때 진공을 보호**.
- **냄새**: 차와 커피 냄새는 **산소계 표백제나 베이킹소다 반죽**으로 제거; **구연산**은 물때(흰 침전물)를 제거 — **표백제와 동시에 쓰지 말 것**.
- **재활용**: **스테인리스 보온병은 금속 쓰레기(不燃 또는 金属)**, 뚜껑은 플라스틱 — 분리 배출; 일부 제조사는 회수 제도를 운영.

> **[확인 필요]** 성능 수치는 특정 제조사 사양과, 카페 할인은 각 체인의 현행 정책과, 스포츠 음료 부식 안내는 제조사 설명서와 대조하십시오.
