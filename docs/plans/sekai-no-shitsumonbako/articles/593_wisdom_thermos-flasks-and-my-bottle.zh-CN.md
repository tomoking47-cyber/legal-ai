# Q. 关于日本的"自带水杯（マイボトル）"习惯和保温杯，人们常有哪些误解？｜Japanese Everyday Wisdom #593

- Shelf: `wisdom` ／ URL: `/zh-cn/wisdom/thermos-flasks-and-my-bottle` ／ Status: **草稿 — 出处未核实**

真空保温瓶并非日本发明——詹姆斯·杜瓦（James Dewar）于 1892 年做出第一只，膳魔师〈Thermos〉这个品牌 1904 年始于德国——但日本把它变成了家家户户的日用品（膳魔师自 1989 年起由日本企业持有；象印〈Zojirushi〉和虎牌〈Tiger〉都是大阪企业），而且日本人随身带着它走到哪里：上班族带 350 ml 热茶，孩子带 800 ml 冰麦茶，登山者带 500 ml 沸水泡杯面。这个习惯省钱又省塑料，但它也有一个大多数使用者忽略的卫生问题。

## A. 常见的误解是把保温杯当成一件"装好就不用管"的东西。不锈钢真空瓶能让饮品保持 6 小时热（60°C 以上）或 6–8 小时冷（10°C 以下），正因如此，装错东西就很危险：牛奶、汤、果汁或运动饮料在温热状态下会滋生细菌，碳酸饮料或会发酵的饮料则会积聚压力。只用它装水、茶、咖啡和白开水；每天用瓶刷清洗盖子的密封圈和内壁；每周用稀释的氧系漂白剂浸泡一次（切勿用含氯漂白剂——会腐蚀不锈钢）；密封圈每一两年更换一次。运动饮料和含盐饮料需要标注"可装运动饮料"的型号，儿童水杯的吸管部件则要每天拆开清洗。

## 保温杯及其限制

| 项目 | 说明 |
|---|---|
| **性能** | 典型的 500 ml 不锈钢保温杯：**热饮 95°C → 6 小时后仍在 70°C 以上；冷饮 4°C → 6 小时后仍在 8°C 以下**（厂商标称值）。先用热水/冰水预热/预冷效果更好 |
| **容量** | **200–350 ml（办公室、手提包）、500 ml（标准）、750–1,000 ml（学校、运动、登山）**。**1 L 水重 1 kg**——孩子的书包会变重 |
| **可以装什么** | **水、茶（麦茶〈麦茶〉、绿茶）、咖啡、泡面用的热水**；**运动饮料仅限标有"スポーツドリンク対応"（可装运动饮料）的型号**（内壁有涂层——盐分会腐蚀普通不锈钢） |
| **不能装什么** | **牛奶、乳制品、汤、味噌汤、果汁、果昔**（温热状态下滋生细菌；并有一定压力）——除非是**焖烧罐（スープジャー）型号**、装入时滚烫并在 **6 小时内**吃完；**碳酸饮料、酒精、会发酵的饮料**（压力，盖子可能弹飞）；**干冰** |
| **每日清洁** | **把盖子拆开**（密封圈、垫圈、吸管部件），**用中性洗涤剂和瓶刷清洗**，**倒置敞开晾干**。**密封圈的凹槽**是黑霉滋生的地方 |
| **每周** | **瓶身和零件用氧系漂白剂浸泡（40°C，30 分钟）**去除茶渍和气味。**切勿用含氯漂白剂**（会使不锈钢出现点蚀）或**金属刷球**（刮伤内壁 → 滋生细菌） |
| **密封圈** | **每 1–2 年更换**，或在变色/开裂时更换；厂商按型号编号出售零件（¥300–800） |
| **洗碗机** | **大多数保温杯不能进洗碗机**（真空密封和涂装）；盖子通常可以——查看说明书 |
| **凹陷** | 有凹陷的保温杯可能已**失去真空**——如果装热饮时外壁发热，说明保温层已失效 |

- **"自带水杯（マイボトル）"文化**：咖啡店对自带杯子**优惠 ¥20–50**（日本星巴克 ¥22）；**办公室设有热水机和茶水角**供续水；**学校要求带贴有名字的水杯**，并规定可以装什么（水或麦茶，不能装果汁）。**麦茶**是夏天的默认选择，因为不含咖啡因，泡起来也便宜。
- **补水与中暑**：**夏天在户外每 2–3 小时 500 ml**，劳动时更多；塑料瓶一小时就会升到 30°C，而**冷保温杯能让水保持可饮用的温度**（参见中暑一文）。
- **登山用热水**：**一个 500 ml 保温杯装满 95°C 热水，4–5 小时后足够泡一个杯面再冲一杯咖啡**——登山者的标准配置。
- **儿童水杯**：**吸管式会残留牛奶和果汁——每天拆开**；**吸管每几个月更换**；**肩带套可以保护真空层不因摔落受损**。
- **气味**：茶和咖啡的味道可以用**氧系漂白剂或小苏打糊**去除；**柠檬酸**能去除水垢（白色沉积物）——**切勿与漂白剂同时使用**。
- **回收**：**不锈钢保温杯属于金属垃圾（不燃或金属）**，盖子属于塑料——分开丢弃；部分厂商有回收计划。

> **[待核实]** 性能数值请对照具体厂商规格；咖啡店优惠请对照各连锁店的现行政策；运动饮料腐蚀的说明请对照厂商使用手册。
