# Q. 關於日本的「自備水瓶（マイボトル）」習慣和保溫瓶，人們常有哪些誤解？｜Japanese Everyday Wisdom #593

- Shelf: `wisdom` ／ URL: `/zh-tw/wisdom/thermos-flasks-and-my-bottle` ／ Status: **草稿 — 出處未核實**

家用真空保溫瓶是日本發明的（膳魔師〈Thermos〉曾數十年由日本公司持有；象印〈Zojirushi〉和虎牌〈Tiger〉都是大阪企業），而且日本人隨身帶著它走到哪裡：上班族帶 350 ml 熱茶，孩子帶 800 ml 冰麥茶，登山者帶 500 ml 沸水泡杯麵。這個習慣省錢又省塑膠，但它也有一個大多數使用者忽略的衛生問題。

## A. 常見的誤解是把保溫瓶當成一件「裝好就不用管」的東西。不鏽鋼真空瓶能讓飲品保持 6 小時熱（60°C 以上）或 6–8 小時冷（10°C 以下），正因如此，裝錯東西就很危險：牛奶、湯、果汁或運動飲料在溫熱狀態下會滋生細菌，碳酸飲料或會發酵的飲料則會累積壓力。只用它裝水、茶、咖啡和白開水；每天用瓶刷清洗瓶蓋的密封圈和內壁；每週用稀釋的氧系漂白劑浸泡一次（切勿用含氯漂白劑——會腐蝕不鏽鋼）；密封圈每一兩年更換一次。運動飲料和含鹽飲料需要標示「可裝運動飲料」的型號，兒童水瓶的吸管零件則要每天拆開清洗。

## 保溫瓶及其限制

| 項目 | 說明 |
|---|---|
| **性能** | 典型的 500 ml 不鏽鋼保溫瓶：**熱飲 95°C → 6 小時後仍在 70°C 以上；冷飲 4°C → 6 小時後仍在 8°C 以下**（廠商標示值）。先用熱水/冰水預熱/預冷效果更好 |
| **容量** | **200–350 ml（辦公室、手提包）、500 ml（標準）、750–1,000 ml（學校、運動、登山）**。**1 L 水重 1 kg**——孩子的書包會變重 |
| **可以裝什麼** | **水、茶（麥茶〈麦茶〉、綠茶）、咖啡、泡麵用的熱水**；**運動飲料僅限標有「スポーツドリンク対応」（可裝運動飲料）的型號**（內壁有塗層——鹽分會腐蝕一般不鏽鋼） |
| **不能裝什麼** | **牛奶、乳製品、湯、味噌湯、果汁、果昔**（溫熱狀態下滋生細菌；並有一定壓力）——除非是**悶燒罐（スープジャー）型號**、裝入時滾燙並在 **6 小時內**吃完；**碳酸飲料、酒精、會發酵的飲料**（壓力，瓶蓋可能彈飛）；**乾冰** |
| **每日清潔** | **把瓶蓋拆開**（密封圈、墊圈、吸管零件），**用中性清潔劑和瓶刷清洗**，**倒置敞開晾乾**。**密封圈的凹槽**是黑黴滋生的地方 |
| **每週** | **瓶身和零件用氧系漂白劑浸泡（40°C，30 分鐘）**去除茶垢和氣味。**切勿用含氯漂白劑**（會使不鏽鋼出現點蝕）或**金屬刷球**（刮傷內壁 → 滋生細菌） |
| **密封圈** | **每 1–2 年更換**，或在變色/龜裂時更換；廠商按型號編號販售零件（¥300–800） |
| **洗碗機** | **大多數保溫瓶不能進洗碗機**（真空密封和塗裝）；瓶蓋通常可以——查看說明書 |
| **凹陷** | 有凹陷的保溫瓶可能已**失去真空**——如果裝熱飲時外壁發熱，代表保溫層已失效 |

- **「自備水瓶（マイボトル）」文化**：咖啡店對自備杯子**折扣 ¥20–50**（日本星巴克 ¥22）；**辦公室設有熱水機和茶水區**供續水；**學校要求帶貼有名字的水瓶**，並規定可以裝什麼（水或麥茶，不能裝果汁）。**麥茶**是夏天的預設選擇，因為不含咖啡因，泡起來也便宜。
- **補水與熱衰竭**：**夏天在戶外每 2–3 小時 500 ml**，勞動時更多；寶特瓶一小時就會升到 30°C，而**冰的保溫瓶能讓水保持可飲用的溫度**（參見中暑一文）。
- **登山用熱水**：**一個 500 ml 保溫瓶裝滿 95°C 熱水，4–5 小時後足夠泡一個杯麵再沖一杯咖啡**——登山者的標準配備。
- **兒童水瓶**：**吸管式會殘留牛奶和果汁——每天拆開**；**吸管每幾個月更換**；**背帶套可以保護真空層不因摔落受損**。
- **氣味**：茶和咖啡的味道可以用**氧系漂白劑或小蘇打糊**去除；**檸檬酸**能去除水垢（白色沉積物）——**切勿與漂白劑同時使用**。
- **回收**：**不鏽鋼保溫瓶屬於金屬垃圾（不燃或金属）**，瓶蓋屬於塑膠——分開丟棄；部分廠商有回收計畫。

> **[待核實]** 性能數值請對照具體廠商規格；咖啡店折扣請對照各連鎖店的現行政策；運動飲料腐蝕的說明請對照廠商使用手冊。
