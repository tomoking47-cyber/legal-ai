# Q. 關於日本的町內會（鄰里自治組織），人們常有哪些誤解？｜Japanese Everyday Wisdom #594

- Shelf: `wisdom` ／ URL: `/zh-tw/wisdom/chonaikai-neighbourhood-associations` ／ Status: **草稿 — 出處未核實**

搬進日本的社區——透天厝也好，低層公寓也好——不出幾週，就會有人拿著寫字板來敲門：您要不要加入町內會（或自治會）？每月幾百日圓，輪流打掃垃圾站，秋天有祭典，9 月有防災演練。新住戶，尤其是外國人，往往把它誤讀成兩種東西：不是強制徵收的稅，就是可以無視的社交俱樂部。兩者都不是。

## A. 常見的誤解是認為加入是強制的。町內會是自願性團體（最高法院在 2005 年確認了退出的權利），會費通常為每月 ¥200–1,000，用於部分地區的路燈、祭典開支、公佈欄、防災物資，以及本社區分攤的垃圾站維護。加入是可選的；不可選的是隨之而來的善意：町內會是防災資訊、垃圾站規則、回覽板（回覧板）的傳遞管道，也是地震時會來看看你的鄰居。若您是只住一兩年的租屋者，繳會費、大部分活動不參加即可；若您是屋主，就加入，輪到自己時承擔一份輕鬆的角色。直接拒絕是合法的，在都市裡也越來越常見，但代價是失去資訊，以及在危急時刻失去一張人際網絡。

## 它究竟是什麼

| 項目 | 內容 |
|---|---|
| **名稱** | 城鎮與都市裡稱 **町內會（ちょうないかい）**，較新的郊區與住宅社區稱 **自治會（じちかい）**；全國約有 **30 萬個**組織 |
| **會員資格** | **自願**（最高法院，2005 年：居民可隨時退出）。**參加率：全國約 70%，東京與大阪市中心不到 50%，鄉村地區 90% 以上** |
| **會費** | **每月 ¥200–1,000**（每年 ¥2,000–12,000），有時按年收取，或與公寓管理費一併收取。**部分町內會還會代收紅十字會與共同募金的捐款——那些是另行自願的** |
| **這筆錢的用途** | **路燈**（在許多市町村，電費由町內會負擔）、**垃圾站的防鳥網與清掃**、**祭典與神社的捐獻**、**防災儲備（飲用水、帳篷、發電機）**、**公佈欄、回覽板、兒童與長者活動**、**防犯巡邏** |
| **職務** | **班長（組長）由各戶每年輪替**——傳遞回覽板、收會費、參加每月例會；**會長等幹部**通常由退休人士擔任。**租屋者常被免除輪值**，但也有不免的 |
| **期待承擔的義務** | **垃圾站清掃輪值**（每幾個月一次）、**秋季祭典**、**9 月的防災演練**、**新年裝飾**、**偶爾的街道清掃** |

## 在現實中為什麼重要

- **災害**：在 1995 年阪神與 2011 年東日本大地震中，**最初數小時內的救援大多由鄰居完成**；町內會負責**避難所的開設**，掌握**需要協助的居民名冊**，並管理**儲備物資**。**非會員也可以使用避難所——但町內會知道誰住在哪裡。**
- **資訊**：**回覽板**（請參見該篇文章）與公佈欄傳遞**垃圾清運變更、停水、道路施工、治安警示、學校活動**。非會員常常是從被留在原地的垃圾袋，才知道清運日改了。
- **垃圾站**：**在許多地區，垃圾站屬於町內會的財產**；少數町內會會限制非會員使用，市町村並不鼓勵，卻未必總能阻止。**先問清楚，不要想當然。**
- **外國居民**：**許多市町村發行多語版指南，並鼓勵町內會歡迎新住戶**；敲門是邀請，不是要求。「**我是租屋的，會費我繳，但沒辦法承擔職務**」是一個正常的回答。
- **拒絕時**：說一句「**結構です（不用了，謝謝）**」並鞠個躬就夠了；**在部分地區，對方仍可能請您分擔路燈的費用**——請視情況逐一決定。
- **集合住宅**：**管理組合（管理組合）是法律規定必須加入的**（因為您擁有一份共有權），它與町內會不同；社區有可能整棟集體加入町內會——請確認您的管理費裡是否已包含這筆錢。

## 取捨（編輯部觀點）

| 加入 | 不加入 |
|---|---|
| 防災網絡、資訊、參加祭典的管道、會替您看著房子的鄰居 | 每年省下 ¥2,000–12,000，以及若干個星期天 |
| 偶爾的義務（對多數會員而言一年幾個小時；輪到當班長那一年會重一些） | 可能在垃圾站問題上產生摩擦；成為無人認識的那一戶 |
