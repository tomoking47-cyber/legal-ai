# Q. 关于冬至的柚子浴（ゆず湯），人们常有哪些误解？｜Japanese Everyday Wisdom #596

- Shelf: `wisdom` ／ URL: `/zh-cn/wisdom/yuzu-bath-winter-solstice` ／ Status: **草稿 — 出处未核实**

在一年中白昼最短的一天——12 月 21 日前后——日本的澡堂和家庭会把黄色的柚子（ゆず，日本香橙）漂浮在热水浴池里。这是日本保留得最好的季节习俗之一，有一句谚语作为依据（冬至泡柚子浴，整个冬天不感冒），同时它也附带一堂关于柑橘精油与皮肤的真实化学课。

## A. 常见的误解是认为柚子浴（ゆず湯）只是一种民间习俗，要么毫无作用，要么能防住感冒。两者都不对：香气与温暖才是重点——睡前泡温水浴能提高核心体温、有助于入睡，柑橘的香味也令人放松——而柚子皮中的精油（柠檬烯、柑醛）可能刺激破损或敏感的皮肤，对儿童和特应性皮肤则可能引起发红。在 40°C 的浴池中放入 3–5 个完整柚子，全家泡 10–15 分钟；除非您已准备好应对精油，否则不要把柚子切开或挤进水里；一岁以下的婴儿以及湿疹发作期的人请跳过。之后冲洗浴缸——精油会留下污渍和油膜——而且切勿把柚子浴的水再加热，也不要再用来洗衣。

## 习俗与化学

| 项目 | 详情 |
|---|---|
| **时间** | **冬至（とうじ），12 月 21 日或 22 日**。公共澡堂（銭湯，sentō）和许多温泉当天提供柚子浴，儿童常可免费入浴 |
| **谚语** | "**冬至に柚子湯に入ると風邪をひかない**"——冬至泡柚子浴，不会感冒。还有一个谐音：**ゆず（柚子）↔ 融通（ゆうずう，灵活变通）**，冬至（とうじ）↔ **湯治（とうじ，为健康而进行的温泉疗养）** |
| **柚子** | **Citrus junos**，12 月成熟变黄；**每个 ¥100–200**，冬至前一周超市有网袋装的"浴用"柚子出售 |
| **放几个** | 200 L 的家用浴池放 **3–5 个完整柚子**；澡堂用网袋装几十个 |
| **整个还是切开？** | **整个**：香气温和、不刺痛；**切开/挤压**：释放果皮精油和果汁 → 香味浓，**对皮肤刺激更大**，也更难清理。折中办法：**把完整柚子装进网袋**，或**划几道浅口** |
| **皮肤** | 果皮精油（**柠檬烯、柑醛，部分柑橘还含呋喃香豆素**）可能引起**刺痛、发红、发痒**，尤其是**冬季干燥皮肤、湿疹、刚剃过毛的皮肤、婴儿**。敏感者**泡后请用清水淋浴冲洗**。**切开的柑橘＋阳光在理论上有光敏风险，对晚间入浴影响很小** |
| **健康效果** | **睡前 1–2 小时泡 40°C、10–15 分钟的温水浴可改善入睡**（温水浴的一般证据存在）；**柑橘香气有放松作用**；**预防感冒：没有特定证据**——冬季泡澡的习惯和柚子与维生素 C 的联想解释了这句谚语的由来 |
| **水** | **不要再用来洗衣，也不要留到第二天**（含精油，且果实会变软、散开）；**不要带着柚子再加热**（精油浓缩；热水器的过滤网会堵塞） |
| **浴缸** | **泡后冲洗并擦拭**——柚子精油会留下油膜；**亚克力浴缸可能染色**；请使用浴缸专用清洁剂 |

- **其他季节浴**：**5 月 5 日（儿童节）的菖蒲浴（菖蒲湯）**，秋天的**红叶浴或橘子皮浴**，**桧木（ひのき）块**。澡堂的日程表上会列出。
- **冬至吃南瓜**：这一天的另一个习俗——**吃南瓜（かぼちゃ）和名字里带"ん"音的食物（なんきん（南瓜）、にんじん（胡萝卜）、れんこん（莲藕）、ぎんなん（银杏）、きんかん（金橘）、かんてん（寒天）、うどん（乌冬）——"七个ん"）**，以求好运并补充过冬的维生素。
- **儿童**：**1 岁左右以上的孩子使用完整柚子没有问题**，需有人看护；**1 岁以下不要泡**；**幼儿要更小心——泡的时间短一些，泡完用清水冲一下**；**皮肤发红就停止**。
- **去澡堂**：**12 月 21 日是社区澡堂一年中最热闹的夜晚**；许多澡堂会**送柚子让您带回家**。先洗净身体再入池；把柚子留在水里，不要放在地上（容易滑倒）。
- **剩下的柚子**：泡过澡的柚子**不能再吃**（沾了肥皂、经过高温）；做**柚子醋（ゆずポン）、柚子果酱、柚子胡椒**请另外购买食用柚子。

> **[待核实]** 皮肤刺激相关表述需以皮肤科资料为依据；泡澡与睡眠的证据需引用具体综述；澡堂柚子浴的做法需向东京都浴场组合核实。
