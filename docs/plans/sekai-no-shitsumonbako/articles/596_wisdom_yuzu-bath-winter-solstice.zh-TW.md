# Q. 關於冬至的柚子浴（ゆず湯），人們常有哪些誤解？｜Japanese Everyday Wisdom #596

- Shelf: `wisdom` ／ URL: `/zh-tw/wisdom/yuzu-bath-winter-solstice` ／ Status: **草稿 — 出處未核實**

在一年中白晝最短的一天——12 月 21 日前後——日本的澡堂和家庭會把黃色的柚子（ゆず，日本香橙）漂浮在熱水浴池裡。這是日本保留得最好的季節習俗之一，有一句諺語作為依據（冬至泡柚子浴，整個冬天不感冒），同時它也附帶一堂關於柑橘精油與皮膚的真實化學課。

## A. 常見的誤解是認為柚子浴（ゆず湯）只是一種民間習俗，要麼毫無作用，要麼能防住感冒。兩者都不對：香氣與溫暖才是重點——睡前泡溫水浴能提高核心體溫、有助於入睡，柑橘的香味也令人放鬆——而柚子皮中的精油（檸檬烯、檸檬醛）可能刺激破損或敏感的皮膚，對兒童和異位性皮膚則可能引起發紅。在 40°C 的浴池中放入 3–5 顆完整柚子，全家泡 10–15 分鐘；除非您已準備好應對精油，否則不要把柚子切開或擠進水裡；一歲以下的嬰兒以及濕疹發作期的人請跳過。之後沖洗浴缸——精油會留下污漬和油膜——而且切勿把柚子浴的水再加熱，也不要再用來洗衣。

## 習俗與化學

| 項目 | 詳情 |
|---|---|
| **時間** | **冬至（とうじ），12 月 21 日或 22 日**。公共澡堂（銭湯，sentō）和許多溫泉當天提供柚子浴，兒童常可免費入浴 |
| **諺語** | 「**冬至に柚子湯に入ると風邪をひかない**」——冬至泡柚子浴，不會感冒。還有一個諧音：**ゆず（柚子）↔ 融通（ゆうずう，靈活變通）**，冬至（とうじ）↔ **湯治（とうじ，為健康而進行的溫泉療養）** |
| **柚子** | **Citrus junos**，12 月成熟變黃；**每顆 ¥100–200**，冬至前一週超市有網袋裝的「浴用」柚子出售 |
| **放幾顆** | 200 L 的家用浴池放 **3–5 顆完整柚子**；澡堂用網袋裝幾十顆 |
| **整顆還是切開？** | **整顆**：香氣溫和、不刺痛；**切開／擠壓**：釋放果皮精油和果汁 → 香味濃，**對皮膚刺激更大**，也更難清理。折衷辦法：**把完整柚子裝進網袋**，或**劃幾道淺口** |
| **皮膚** | 果皮精油（**檸檬烯、檸檬醛，部分柑橘還含呋喃香豆素**）可能引起**刺痛、發紅、發癢**，尤其是**冬季乾燥皮膚、濕疹、剛除過毛的皮膚、嬰兒**。敏感者**泡後請用清水淋浴沖洗**。**切開的柑橘＋陽光在理論上有光敏風險，對晚間入浴影響很小** |
| **健康效果** | **睡前 1–2 小時泡 40°C、10–15 分鐘的溫水浴可改善入睡**（溫水浴的一般證據存在）；**柑橘香氣有放鬆作用**；**預防感冒：沒有特定證據**——冬季泡澡的習慣和柚子與維生素 C 的聯想解釋了這句諺語的由來 |
| **水** | **不要再用來洗衣，也不要留到第二天**（含精油，且果實會變軟、散開）；**不要帶著柚子再加熱**（精油濃縮；熱水器的濾網會堵塞） |
| **浴缸** | **泡後沖洗並擦拭**——柚子精油會留下油膜；**壓克力浴缸可能染色**；請使用浴缸專用清潔劑 |

- **其他季節浴**：**5 月 5 日（兒童節）的菖蒲浴（菖蒲湯）**，秋天的**楓葉浴或橘子皮浴**，**檜木（ひのき）塊**。澡堂的日程表上會列出。
- **冬至吃南瓜**：這一天的另一個習俗——**吃南瓜（かぼちゃ）和名字裡帶「ん」音的食物（なんきん（南瓜）、にんじん（紅蘿蔔）、れんこん（蓮藕）、ぎんなん（銀杏）、きんかん（金桔）、かんてん（寒天）、うどん（烏龍麵）——「七個ん」）**，以求好運並補充過冬的維生素。
- **兒童**：**1 歲左右以上的孩子使用完整柚子沒有問題**，需有人看護；**1 歲以下不要泡**；**幼兒要更小心——泡的時間短一些，泡完用清水沖一下**；**皮膚發紅就停止**。
- **去澡堂**：**12 月 21 日是社區澡堂一年中最熱鬧的夜晚**；許多澡堂會**送柚子讓您帶回家**。先洗淨身體再入池；把柚子留在水裡，不要放在地上（容易滑倒）。
- **剩下的柚子**：泡過澡的柚子**不能再吃**（沾了肥皂、經過高溫）；做**柚子醋（ゆずポン）、柚子果醬、柚子胡椒**請另外購買食用柚子。

> **[待核實]** 皮膚刺激相關表述需以皮膚科資料為依據；泡澡與睡眠的證據需引用具體綜述；澡堂柚子浴的做法需向東京都浴場組合核實。
