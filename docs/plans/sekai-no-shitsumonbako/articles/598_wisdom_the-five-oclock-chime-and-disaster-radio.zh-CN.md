# Q. 关于下午 5 点的报时音乐和街区里的高音喇叭，人们常有哪些误解？｜Japanese Everyday Wisdom #598

- Shelf: `wisdom` ／ URL: `/zh-cn/wisdom/the-five-oclock-chime-and-disaster-radio` ／ Status: **草稿 — 出处未核实**

每天 17:00（有些城镇冬天是 16:30，另一些夏天是 18:00），日本各地街头的杆子上会传出一段旋律——《夕焼小焼》、《绿袖子》、当地的校歌。游客以为这是宵禁，或者是一种可爱的地方特色。其实这是市町村防灾广播系统的每日测试，而同一批喇叭总有一天会播出您必须听懂的内容。

## A. 常见的误解是把这段音乐当成叫小孩「回家」的信号。非正式地说它确实也是，但它的用途是测试「防災行政無線」——市町村的防灾行政无线系统，由室外高音喇叭和室内接收机组成，负责传送海啸警报、避难指示、中暑警示、走失人口通知，在农村地区还会播报熊出没和疫苗接种的消息。请记住您所在城镇的报时音乐是什么样，也记住这些喇叭在播的不是音乐时是什么样：警笛之后接一段口播，意味着该查看手机上的紧急速报邮件和市町村官网；海啸警报有特定的警笛节奏；而每天的「小朋友该回家了」和「天热请多留意老人」这类广播，正是这套系统在按设计运作。

## 这套系统

| 项目 | 内容 |
|---|---|
| **名称** | **防災行政無線（ぼうさいぎょうせいむせん）**——市町村防灾行政无线：**室外扩音子局（屋外拡声子局）** 以及许多农村住宅里的**户别接收机（戸別受信機）** |
| **覆盖范围** | 几乎**所有市町村**；**约 90% 配有同步的室外系统**；人口密集的城市更依赖手机 |
| **每日的报时音乐** | **测试广播**（「時報」），通常在 **17:00**，有些城镇还有**正午**和／或**早上**；**随季节调整（冬天 16:30，夏天 18:00）**；**旋律由当地选定**——《夕焼小焼》、《故乡》、威斯敏斯特钟声、市町歌 |
| **非正式功能** | **「小朋友该回家了」**——学校和家长把它当成户外玩耍的截止时间；**老人以此为关窗板的时间** |
| **还播什么** | **海啸／地震警报**、**避难信息（警戒级别 3–5）**、**暴雨和台风通知**、**中暑警示**（「请补充水分并使用空调」）、**走失人口**（尤其是认知症走失）、**熊和野猪出没**、**计划停电停水**、**疫苗接种与体检提醒**、**正午的「午饭」报时音**、**消防演习通知**，小城镇里还有**新年和盂兰盆节的问候** |
| **警笛** | **海啸警报：特定的警笛节奏**（例如 3 秒一响），随后播报「**津波警報**」；**避难：报时音 + 口播指示**；**J-Alert（导弹、大地震）**：全国统一的警报音。**这些声音模式印在市町村的防灾手册上** |
| **听不清** | **雨和风会盖住声音**，而另一方面很多投诉是说夜里**太吵**——所以市町村还会同时提供**手机 App、紧急速报邮件、电话回放专线（テレホンサービス）和有线电视**。**请登记您所在城镇的邮件／LINE 提醒** |

- **为什么用旋律**：为了在**不惊动任何人**的前提下测试喇叭；17:00 这个时间点源自 **1960–70 年代**，正好与孩子们回家的时间吻合。有些城镇会**投票选定旋律**。
- **投诉与调整**：一边是**噪音投诉**（尤其来自刚搬到喇叭杆附近的新住户），一边是老人说**「我们听不见」**；许多城镇因此**调低了音量、移动了喇叭杆，或把冬季的报时提前**。**但不会停播**——测试本身就是目的。
- **方言和语速的问题**：**口播语速慢、用词正式**，而且常带当地口音；**外国居民应登记多语种提醒**（许多市町村通过 App 或邮件提供**英语／中文／越南语**），不要指望听懂高音喇叭。
- **当播的不是报时音乐时该怎么办**：**停下来听关键词——津波（海啸）、避難（避难）、警報（警报）、洪水（洪水）**；**查看手机上的紧急速报邮件和市町村网站**；**看看邻居在做什么**。**如果在沿海地区经历强震后拿不准：不要等广播，立即前往高处。**
- **户别接收机**：农村住宅墙上的小盒子，遇到紧急广播时**无法关闭**；租房的人会连房子一起继承它——**请不要拔掉插头**。
- **对游客而言**：这段音乐是**方便的时钟**，也是**公园和游乐场开始清场**的信号；如果您在沿海城镇听到警笛和口播，**可以问旁人「何がありましたか？」（发生什么事了？）** 并照着做。
