# Q. 關於下午 5 點的報時音樂和街區裡的擴音喇叭，人們常有哪些誤解？｜Japanese Everyday Wisdom #598

- Shelf: `wisdom` ／ URL: `/zh-tw/wisdom/the-five-oclock-chime-and-disaster-radio` ／ Status: **草稿 — 出處未核實**

每天 17:00（有些城鎮冬天是 16:30，另一些夏天是 18:00），日本各地街頭的桿子上會傳出一段旋律——〈夕燒小燒〉、〈綠袖子〉、當地的校歌。旅客以為那是宵禁，或是一種可愛的地方特色。其實那是市町村防災廣播系統的每日測試，而同一批喇叭總有一天會播出您必須聽懂的內容。

## A. 常見的誤解是把這段音樂當成叫小孩「回家」的訊號。非正式地說它確實也是，但它的用途是測試「防災行政無線」——市町村的防災行政無線系統，由室外擴音喇叭和室內接收機組成，負責傳送海嘯警報、避難指示、中暑警示、協尋失蹤者的通知，在鄉間還會播報熊出沒和疫苗接種的消息。請記住您所在城鎮的報時音樂是什麼樣，也記住這些喇叭在播的不是音樂時是什麼樣：警報聲之後接一段口播，就代表該查看手機上的緊急速報郵件和市町村官網；海嘯警報有特定的警報聲節奏；而每天的「小朋友該回家了」和「天熱請多留意長輩」這類廣播，正是這套系統照設計在運作。

## 這套系統

| 項目 | 內容 |
|---|---|
| **名稱** | **防災行政無線（ぼうさいぎょうせいむせん）**——市町村防災行政無線：**室外擴音子局（屋外拡声子局）** 以及許多鄉間住宅裡的**戶別接收機（戸別受信機）** |
| **涵蓋範圍** | 幾乎**所有市町村**；**約 90% 配有同步的室外系統**；人口密集的城市更依賴手機 |
| **每日的報時音樂** | **測試廣播**（「時報」），通常在 **17:00**，有些城鎮還有**正午**和／或**早上**；**隨季節調整（冬天 16:30，夏天 18:00）**；**旋律由當地選定**——〈夕燒小燒〉、〈故鄉〉、西敏鐘聲、市町歌 |
| **非正式功能** | **「小朋友該回家了」**——學校和家長把它當成在外面玩耍的截止時間；**長輩以此為關窗板的時間** |
| **還播什麼** | **海嘯／地震警報**、**避難資訊（警戒等級 3–5）**、**豪雨和颱風通知**、**中暑警示**（「請補充水分並使用冷氣」）、**協尋失蹤者**（尤其是失智走失）、**熊和野豬出沒**、**計畫停電停水**、**疫苗接種與健檢提醒**、**正午的「午餐」報時音**、**消防演習通知**，小城鎮裡還有**新年和盂蘭盆節的問候** |
| **警報聲** | **海嘯警報：特定的警報聲節奏**（例如 3 秒一響），隨後播報「**津波警報**」；**避難：報時音 + 口播指示**；**J-Alert（飛彈、大地震）**：全國統一的警報音。**這些聲音模式印在市町村的防災手冊上** |
| **聽不清楚** | **雨和風會蓋住聲音**，而另一方面很多投訴是說夜裡**太吵**——所以市町村也同時提供**手機 App、緊急速報郵件、電話回播專線（テレホンサービス）和有線電視**。**請登記您所在城鎮的郵件／LINE 通知** |

- **為什麼用旋律**：為了在**不驚動任何人**的前提下測試喇叭；17:00 這個時間點源自 **1960–70 年代**，正好與孩子們回家的時間吻合。有些城鎮會**投票選定旋律**。
- **投訴與調整**：一邊是**噪音投訴**（尤其來自剛搬到喇叭桿附近的新住戶），一邊是長輩說**「我們聽不見」**；許多城鎮因此**調低了音量、移動了喇叭桿，或把冬季的報時提前**。**但不會停播**——測試本身就是目的。
- **方言和語速的問題**：**口播語速慢、用詞正式**，而且常帶當地口音；**外國居民應登記多語種通知**（許多市町村透過 App 或郵件提供**英語／中文／越南語**），不要指望聽懂擴音喇叭。
- **當播的不是報時音樂時該怎麼辦**：**停下來聽關鍵詞——津波（海嘯）、避難（避難）、警報（警報）、洪水（洪水）**；**查看手機上的緊急速報郵件和市町村網站**；**看看鄰居在做什麼**。**如果在沿海地區經歷強震後拿不準：不要等廣播，立刻前往高處。**
- **戶別接收機**：鄉間住宅牆上的小盒子，遇到緊急廣播時**無法關閉**；租屋的人會連房子一起繼承它——**請不要拔掉插頭**。
- **對旅客而言**：這段音樂是**方便的時鐘**，也是**公園和遊樂場開始淨空**的訊號；如果您在沿海城鎮聽到警報聲和口播，**可以問旁人「何がありましたか？」（發生什麼事了？）** 並照著做。

> **[待核實]** 涵蓋率數字請對照總務省最新調查；警報聲節奏因市町村而異——請引用相關城鎮的防災手冊。
