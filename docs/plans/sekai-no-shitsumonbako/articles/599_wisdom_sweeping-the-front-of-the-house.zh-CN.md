# Q. 关于打扫自家门前那段路，人们常有哪些误解？｜Japanese Everyday Wisdom #599

- Shelf: `wisdom` ／ URL: `/zh-cn/wisdom/sweeping-the-front-of-the-house` ／ Status: **草稿 — 出处未核实**

清早，日本各地的店主和住户会拿着扫帚站在门外，打扫自家门前那段人行道——落叶、烟头、邻居家飘落的花瓣——有时还洒上一点水。这不是市政部门的工作，法律也没有规定，但它比垃圾桶的数量更能解释日本的街道。

## A. 常见的误解是以为日本街道干净是因为有人拿钱在打扫。市政的清扫队负责主干道和车站；住宅区的街道和商店街，是由门前属于自己的那些人按惯例（門前掃き，「扫门前」）维持的，其中有一条不成文的规矩：扫到两侧的地界线，再稍微多扫一点，但绝不能把自己的落叶扫到邻居那一段去。请在早上做，有店铺的话在 08:00 之前；用软毛的户外扫帚配簸箕；把扫起来的东西装袋当可燃垃圾（多数城镇把落叶算作可燃垃圾，有些地方秋天会单独收集）；夏天扫完再来一次「打ち水」（うちみず，洒水）。这件事只花五分钟，却是您能做的最显眼的睦邻举动；在一个新社区里，人们就是这样记住您这张脸的。

## 这项惯例

| 项目 | 内容 |
|---|---|
| **谁来做** | **门前属于谁，就由那户人家或那家店来做**；商店街里是**各家店在开门前打扫**；公寓楼则是**管理公司或住户轮值** |
| **扫多大范围** | **自家门前，扫到两侧地界，再加上排水沟和路边那一条**；**稍微越到邻居那边是礼貌，越得太多则显得多事** |
| **什么时候** | **早上**（店铺在 **08:00 之前**，住家在起床后或早饭后）；**刮风下雨之后**；**落叶季（11–12 月）和樱花季（4 月）每天扫**，其他时候每周一次 |
| **工具** | **户外扫帚（软毛或竹扫帚 take-bōki，¥500–1,500）**、**长柄簸箕（¥300–800）**、**垃圾袋**、**手套**；在住宅区里**吹叶机被认为既吵又偷懒** |
| **扫些什么** | **落叶、落花、垃圾、烟头、碎石**；**不包括**狗的粪便（那是狗主人的事，屡犯的话可以举报），**也不包括**危险物品（玻璃——请小心捡起） |
| **怎么丢** | 多数市町村里**落叶和垃圾 → 可燃垃圾**；**有些城镇秋天设有落叶专项收集，或在指定日期接收装在透明袋里的落叶**；**绝不可扫进雨水口或排水沟**（会堵塞，而且属于违法倾倒） |
| **水** | 夏天**扫完之后打ち水**（参见那篇文章）——降温并压住灰尘 |
| **雪** | 在雪国，同样的惯例适用于**清扫自家门前的积雪**，**要赶在通勤者出门前的清早** |

- **为什么有效**：**干净的街道会一直干净**——垃圾招来垃圾（破窗效应反过来用）；**早上有邻居在门外，本身就能震慑犯罪**；**商店街的商会可能有明文规定**（「09:00 前扫完」）。
- **睦邻礼节**：**向路过的人打招呼（「おはようございます」）**；**如果年迈的邻居已经扫不动了，就安静地把他那一段也扫了**；**不要把自己的落叶扫到隔壁门前或路中间**；**邻居家办丧事期间不要扫，星期天一大早也别扫得太吵**。
- **新搬来的人**：搬来第一周就扫自家门前，是**最快让人认出「12 号新搬来的那家人」的方式**，也能顺便打听到装落叶的袋子该放哪儿。
- **住公寓的人**：**门厅和垃圾站就是共用的「门前」**——由住户轮值负责；**进楼时顺手捡起一片垃圾**，就是个人版的做法。
- **市政这一侧**：**道路清扫车负责主干道**；**志愿者的「ゴミゼロ」（零垃圾，5 月 30 日，「530」谐音 gomi zero）清洁日**和**学校的清扫活动**覆盖公园；城市里还有**认养道路（adopt-a-road）计划**。
- **关于扫帚**：**竹扫帚（take-bōki）适合在粗糙地面上扫落叶**，**棕毛或塑料软毛适合人行道**；**竖着放或挂起来**，让刷毛保持形状；**扫过湿落叶后要冲洗**。

> **[待核实]** 落叶的处理规则因市町村而异——请引用相关城镇的规定；530 日与认养道路计划请对照环境省／国土交通省的页面。
