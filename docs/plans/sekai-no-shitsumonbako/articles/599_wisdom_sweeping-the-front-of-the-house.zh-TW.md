# Q. 關於打掃自家門前那段路，人們常有哪些誤解？｜Japanese Everyday Wisdom #599

- Shelf: `wisdom` ／ URL: `/zh-tw/wisdom/sweeping-the-front-of-the-house` ／ Status: **草稿 — 出處未核實**

清早，日本各地的店家和住戶會拿著掃把站在門外，打掃自家門前那段人行道——落葉、菸蒂、鄰居家飄落的花瓣——有時還灑上一點水。這不是市政單位的工作，法律也沒有規定，但它比垃圾桶的數量更能解釋日本的街道。

## A. 常見的誤解是以為日本街道乾淨是因為有人拿錢在打掃。市政的清掃隊負責主要幹道和車站；住宅區的街道和商店街，是由門前屬於自己的那些人依慣例（門前掃き，「掃門前」）維持的，其中有一條不成文的規矩：掃到兩側的地界線，再稍微多掃一點，但絕不能把自己的落葉掃到鄰居那一段去。請在早上做，有店面的話在 08:00 之前；用軟毛的戶外掃把配畚箕；把掃起來的東西裝袋當可燃垃圾（多數城鎮把落葉算作可燃垃圾，有些地方秋天會另外收集）；夏天掃完再來一次「打ち水」（うちみず，灑水）。這件事只花五分鐘，卻是您能做的最顯眼的敦親睦鄰之舉；在一個新社區裡，人們就是這樣記住您這張臉的。

## 這項慣例

| 項目 | 內容 |
|---|---|
| **誰來做** | **門前屬於誰，就由那戶人家或那家店來做**；商店街裡是**各家店在開門前打掃**；公寓大樓則是**管理公司或住戶輪值** |
| **掃多大範圍** | **自家門前，掃到兩側地界，再加上排水溝和路邊那一條**；**稍微越到鄰居那邊是禮貌，越得太多則顯得多事** |
| **什麼時候** | **早上**（店家在 **08:00 之前**，住家在起床後或早餐後）；**颳風下雨之後**；**落葉季（11–12 月）和櫻花季（4 月）每天掃**，其他時候每週一次 |
| **工具** | **戶外掃把（軟毛或竹掃把 take-bōki，¥500–1,500）**、**長柄畚箕（¥300–800）**、**垃圾袋**、**手套**；在住宅區裡**吹葉機被認為既吵又偷懶** |
| **掃些什麼** | **落葉、落花、垃圾、菸蒂、碎石**；**不包括**狗的糞便（那是飼主的事，屢犯的話可以通報），**也不包括**危險物品（玻璃——請小心撿起） |
| **怎麼丟** | 多數市町村裡**落葉和垃圾 → 可燃垃圾**；**有些城鎮秋天設有落葉專案收集，或在指定日期接收裝在透明袋裡的落葉**；**絕不可掃進雨水孔或排水溝**（會堵塞，而且屬於違法傾倒） |
| **水** | 夏天**掃完之後打ち水**（參見那篇文章）——降溫並壓住灰塵 |
| **雪** | 在雪國，同樣的慣例適用於**清除自家門前的積雪**，**要趕在通勤者出門前的清早** |

- **為什麼有效**：**乾淨的街道會一直乾淨**——垃圾招來垃圾（破窗效應反過來用）；**早上有鄰居在門外，本身就能嚇阻犯罪**；**商店街的商會可能訂有規則**（「09:00 前掃完」）。
- **敦親睦鄰的禮節**：**向路過的人打招呼（「おはようございます」）**；**如果年邁的鄰居已經掃不動了，就安靜地把他那一段也掃了**；**不要把自己的落葉掃到隔壁門前或路中間**；**鄰居家辦喪事期間不要掃，星期天一大早也別掃得太吵**。
- **新搬來的人**：搬來第一週就掃自家門前，是**最快讓人認出「12 號新搬來的那家人」的方式**，也能順便打聽到裝落葉的袋子該放哪裡。
- **住公寓大樓的人**：**門廳和垃圾集中處就是共用的「門前」**——由住戶輪值負責；**進大樓時順手撿起一片垃圾**，就是個人版的做法。
- **市政這一側**：**道路清掃車負責主要幹道**；**志工的「ゴミゼロ」（零垃圾，5 月 30 日，「530」諧音 gomi zero）清潔日**和**學校的清掃活動**涵蓋公園；都市裡還有**認養道路（adopt-a-road）計畫**。
- **關於掃把**：**竹掃把（take-bōki）適合在粗糙地面上掃落葉**，**棕毛或塑膠軟毛適合人行道**；**直立放置或吊掛起來**，讓刷毛保持形狀；**掃過濕落葉後要沖洗**。

> **[待核實]** 落葉的處理規則因市町村而異——請引用相關城鎮的規定；530 日與認養道路計畫請對照環境省／國土交通省的頁面。
