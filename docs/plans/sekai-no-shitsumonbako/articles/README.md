# 記事フォルダ — 100本の進捗

`tools/question_generator/output/priority_top100.csv` の優先順位順に、記事ファイルを作成しています。

| 状態 | 本数 |
|---|---|
| **本文完成（法務レビュー前）** | **100本**（#1〜#100） |
| 雛形のみ（未執筆） | **0本** |

## 雛形に最初から入っているもの

執筆者は**本文だけ**書けばよく、体裁で事故が起きないようにしてあります。

- タイトル・通し番号・棚・タグ・URLスラッグ
- **棚に応じた定型の注記**（`17_standard_disclaimers.md` の正本どおり）
- 法務チェックの要否
- 公開前チェックリスト

## 検査のしかた

```
# 日本語記事
python translation_checker.py --ja 記事.md

# 英語記事（inbound / wisdom）
python translation_checker.py --en 記事.md
```

**言語の指定を間違えると、必須記述の欠落として誤検出されます。**
`--ja` は「ご自身の判断」を、`--en` は "your own judgement" を探すためです。

現在：**100本すべて重大0件**（雛形を含む）。

## 話題の重複について

**1話題につき記事は1本だけ**にしています。

当初のランキングは同じ話題の言い換えで埋まっており（クレンジングが #1・#11・#21…）、
そのまま書くと**中身がほぼ同じ記事が並び、検索でも共食い**します。
`rank.py` に1話題1本の制約を入れて作り直しました。

## まだ終わっていないこと

完成10本も、**このままでは公開できません。**

- [ ] 3ソース原則の確認（編集部が実際に観察して記録する）
- [ ] **出典URLを開いて、記載内容と一致するか確認する**
- [ ] 薬機法の法務レビュー（fashion・health 棚）

## samples/ フォルダとの重複について

企画初期に `samples/` へ書いた記事のうち、以下は `articles/` の記事と話題が近接します。
**公開時はどちらか一方に統合してください。両方出すと検索で共食いします。**

| samples/ | articles/ |
|---|---|
| `02_wellness_morning_light.md` | `022_health_morning-light.md` |
| `08_phone_before_bed.md` | `017_health_phone-before-bed.md` |
| `10_cosmetics_fridge.md` | `011_fashion_storing-cosmetics.md` |
| `en/02_sunscreen_label_*.md` | （重複なし。そのまま使えます） |

`samples/` は企画時の見本、`articles/` が実際の制作ラインです。**迷ったら `articles/` を優先してください。**

## 重複に注意する記事

同じ領域を扱う記事が複数あります。**公開時は役割分担を守り、内容を重ねないでください。**
