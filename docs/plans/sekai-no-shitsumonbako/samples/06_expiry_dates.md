# Q. 賞味期限と消費期限は、何が違うの？｜世界の質問箱 #6

- ステータス：**ドラフト（法務レビュー前）** ／ ⚠️ **表示制度に関する記事のため、公開前に消費者庁・農林水産省の一次資料で必ず確認すること**

海外のコミュニティでも、食品の期限表示をどう扱うべきかという疑問は、世界中で議論されています。国によって表示の考え方が違うため、話が噛み合わないことも多いテーマです。

## A. 消費期限は「安全に食べられる期限」、賞味期限は「おいしく食べられる期限」です。意味がまったく違います。

同じ「期限」でも、**過ぎたときの意味が違う**というのが最大のポイントです。

## なぜそうなのか

### 2つの期限の違い

| | 消費期限 | 賞味期限 |
|---|---|---|
| 意味 | **安全に食べられる**期限 | **おいしく食べられる**期限 |
| 対象 | 傷みやすい食品 | 比較的傷みにくい食品 |
| 例 | 弁当、生菓子、食肉 など | スナック菓子、カップめん、缶詰 など |
| 過ぎたら | **食べないほうがよい** | **すぐに食べられなくなるわけではない** |

**消費期限を過ぎたものは食べない。** これははっきりしています。

一方、**賞味期限は「おいしさの保証期限」**です。過ぎた瞬間に食べられなくなるわけではありません。ただし、風味は落ちていきますし、**どこまで大丈夫かは食品や保存状態によって変わる**ため、見た目やにおいを確認し、少しでも異常を感じたら食べないでください。

### 【重要】どちらにも共通する大前提が2つあります

ここが最も見落とされる点です。両方の期限は、次の条件を満たしている場合の話です。

1. **開封していないこと**
2. **表示された保存方法を守っていること**（要冷蔵なら冷蔵で、など）

**一度開封したら、期限表示は意味を持ちません。** 「賞味期限まであと1か月あるから大丈夫」は、開封後には通用しません。開封後はできるだけ早く食べきってください。

また、**表示された温度で保存していなければ、期限内でも安全とは限りません。** 夏場に常温で持ち歩いた要冷蔵品などが典型です。

### なぜこの制度があるのか

食品の期限表示は、食品表示法に基づき、**製造した事業者が科学的・合理的な根拠をもって設定する**ことになっています。事業者が試験を行い、安全性に余裕を持たせたうえで決めています。

つまり期限は、**勘で決められた数字ではありません。** 同時に、**余裕を見込んだ数字でもあります。** 賞味期限が「過ぎた瞬間にアウト」ではないのは、このためです。

### 食品ロスとの関係

賞味期限の意味が正しく理解されていないことは、まだ食べられる食品が捨てられる一因になっているとされています。**消費期限は守る。賞味期限は状態を見て判断する。** この使い分けができるだけで、無駄は確実に減ります。

## VVの考え方

VVは、食べ物を「不安だから捨てる」判断が、少しでも減ればいいと考えています。**守るべき線と、自分で判断していい線を、正しく知ること。** それが、食べ物を大切にすることにつながると思っています。
