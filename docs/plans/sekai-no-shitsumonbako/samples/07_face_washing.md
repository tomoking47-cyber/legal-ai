# Q. 洗顔は1日2回が正解なの？｜世界の質問箱 #7

海外のコミュニティでも、「朝は洗うべきか、水だけでいいのか」という議論は、世界中で繰り返されています。朝晩2回が常識という声と、朝は洗いすぎだという声が、どちらも根強くあります。

## A. 「1日2回が正解」という一律の根拠はありません。皮脂の量と、洗ったあとの感触で決めるのが現実的です。

回数そのものより、**洗ったあとに肌がつっぱるかどうか**のほうが、判断材料として役に立ちます。

## なぜそうなのか

### 洗顔で落としているものは2種類ある

洗顔で落とすのは、大きく分けて次の2つです。

1. **外から付いたもの**（汚れ、日焼け止め、メイク、ほこり）
2. **自分の肌から出たもの**（皮脂、汗、古い角質）

夜は①も②もあるため、洗う必要があります。**議論になるのは朝です。** 朝の顔にあるのは、基本的に②と寝具由来のわずかな汚れだけだからです。

### 洗いすぎると、肌の負担になる

肌の表面には、水分を保ち、外からの刺激を防ぐはたらきをする層があります。皮脂もその一部です。

**必要な皮脂まで落としすぎると、この機能に負担がかかります。** 洗顔後に強くつっぱる感じがあるなら、その洗い方は自分の肌に対して強すぎる可能性があります。

一方で、**皮脂が多いのに洗わずにいると、それはそれで肌トラブルにつながることがあります。** つまり、**どちらに振っても行きすぎはよくない**、というのが正確なところです。

### 「回数」ではなく「状態」で決める

| 朝の肌の状態 | 考え方 |
|---|---|
| 起きたときに顔がべたつく | 洗顔料を使って洗う |
| 特にべたつかない | ぬるま湯だけでも成立する |
| 洗顔後に強くつっぱる | 回数か洗浄力を見直す |
| 乾燥が気になる季節 | 朝の洗顔料を控えめにする選択もある |

**季節や体調で変わるので、一年中同じにしなくて構いません。**

### 回数より大切なこと

正直に書くと、**回数の議論より、洗い方のほうが影響が大きい**可能性があります。

- **こすらない**：泡でなでるように洗い、タオルは押し当てて水気を取る
- **お湯が熱すぎない**：熱いお湯は必要な皮脂まで落としやすい
- **すすぎ残さない**：生え際・あごの下に残りやすい
- **時間をかけすぎない**：長く洗えばきれいになる、というものではない

### 肌トラブルが続いているときは

**ニキビや湿疹が続く場合、洗顔の回数を変えることで解決しようとしないでください。** 原因が別にあることがあります。皮膚科専門医にご相談ください。

## VVの考え方

VVは、スキンケアに「正解の回数」があるとは考えていません。**自分の肌の状態を見て、その日の判断ができること。** 誰かが決めた回数より、そちらのほうがずっと確かだと思っています。
