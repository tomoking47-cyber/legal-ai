# Relativity を訴えられるか ─ 選択肢の整理

## 結論

**可能性はある。しかも BCA §10.6 により、通常の米国訴訟より格段に速く安い道が用意されている。**
**ただし、最も強い2枚のカードは「当社が訴える話」ではない。**

---

## 1. まず整理 ─ 誰が誰を訴えられるのか

| 論点 | 訴える主体 | 当社は原告になれるか |
|---|---|---|
| **Rule 144(i) / Section 5 違反** | **株を買った投資家**（Section 12(a)(1) 取消請求権） | **なれない** |
| **Schedule 13D 未提出** | SEC（規制） | **なれない**（発行体に損害賠償請求権はない） |
| **BCA 違反** | **当社（Pubco）** | **なれる** ← ここが当社の請求権 |
| BCA 表明保証違反（§3.5） | 当社 | なれる（Schedule 次第） |

**→ Rule 144(i) と 13D は「当局に持ち込む札」であって「訴状に書く札」ではない。
   だが相手にとっては、訴訟より遥かに怖い。費用も当社はほぼ負担しない。**

| 条項 | 要求されていたこと | 実際 |

| **§7.2(k)** | Sponsor Shares と Escrow Shares をエスクローに預託し、**証拠を当社に提出** | **エスクロー口座が存在しない** |

## 3. 【重要】BCA §10.6 ─ 紛争解決手続が非常に有利

| 項目 | 内容 |
|---|---|
| 手続 | **AAA 商事仲裁規則の Expedited Procedures（迅速手続）** |
| 仲裁人 | **1名。申立後5営業日以内に AAA が指名** |
| 方式 | **ファイナルオファー仲裁**。双方が案を1つずつ提出し、**仲裁人はどちらか一方を選ぶだけ** |
| 場所 | ニューヨーク市マンハッタン |
| 準拠法 | デラウェア州法 |
| 言語 | 英語 |
| **除外** | **差止め（TRO・仮処分・恒久的差止め）等の衡平法上の救済は仲裁の対象外** |

### なぜ有利か

1. **速い。** 通常の米国訴訟は2〜4年。Expedited 仲裁は数か月。
2. **安い。** 陪審なし、証拠開示も限定的。
3. **ファイナルオファー仲裁は、不合理な主張を罰する。**
   相手に防御がなければ、相手の提案は当社の合理的な提案の隣で不合理に見える。
   仲裁人は中間を取れない。**どちらか一方を選ぶしかない。**
4. **差止めは仲裁の外。** 残存株式の凍結が必要なら、
   **デラウェア衡平裁判所（§10.7 専属管轄）に直行できる。**

### 手続の順番（契約で決まっている）

1. **Dispute Notice** ── 紛争内容を合理的に詳細に記載した書面通知
2. **Resolution Period 10営業日** ── 友好的解決の試み
3. **AAA へ申立** ── 以後は迅速手続

**→ 「内容証明を送る」ことが、契約上の第一歩そのものである。**

## 4. ⚠️ 正直な懸念 3つ

### ① 仲裁で届くのは Relativity Acquisition Sponsor, LLC のみ

BCA の当事者は Purchaser / Pubco / Merger Sub / Target Company / Founder /
**Relativity Acquisition Sponsor, LLC（Purchaser Representative）** / Seller Representative。

**BRACS・Paramount・MGMTT・Relativity II・Hithos II は BCA の当事者ではない。**
→ 仲裁条項は及ばない。これらへの請求は別構成（不当利得・幇助等）が必要で、
  デラウェアの裁判管轄に服するかも別途検討を要する。

**ただし §7.2(k) を破ったのは Sponsor 本人であり、その請求は直接届く。**

### ② 回収可能性 ── これが最大の実務リスク

相手はいずれも SPV（特別目的会社）とみられる。
**空の LLC に対する勝訴判決・仲裁判断は、紙切れになりうる。**

→ 提訴前に必ず確認すること：
- 資産があるか
- 保険（D&O・E&O）があるか
- 法人格否認（veil piercing）や背後の個人・運用者に届くか

**回収可能性の確認をせずに費用をかけるのは、それはNG。**

### ③ 証拠開示は双方向

仲裁・訴訟に入れば、**BRACS・Paramount への 2,006,350 株の新規発行**について、
当社側の記録も相手方に開示される。

**発行を承認したのが誰かを、社内で先に把握しておくこと。**

## 5. 推奨する順番

| 順 | 手段 | 費用 | 相手への圧力 | 時期 |
|---|---|---|---|---|
| **1** | **規制当局**（Nasdaq/FINRA → SEC） | ほぼゼロ | **最大** | 明日〜今週 |
| **2** | **Dispute Notice（§10.6）** | 小 | 大 | 弁護士確保後 |
| **3** | **AAA 迅速仲裁** | 中 | 大 | ①②が効かなければ |
| 4 | デラウェア衡平裁判所（差止めが必要な場合のみ） | 大 | 大 | 必要時 |

**規制を先に置く理由：**
Rule 144(i) と 13D の問題は、当社が金を払わずに相手へ圧力をかけられる唯一の手段であり、
かつ相手にとって最も重い（購入者からの取消請求は無過失責任）。
**①が効けば、②の交渉で解決する可能性が高い。③まで行かずに済む。**

## 6. 今週やること

1. **米国証券弁護士を確保する**（最優先。これがないと何も始まらない）

3. **相手方の資産・保険を調査**（回収可能性の見極め。②③に進む前提条件）
