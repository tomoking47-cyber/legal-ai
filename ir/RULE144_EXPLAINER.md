# Rule 144 とは ─ 本件における意味

## 1. 出発点：米国では「登録しない限り売れない」

Securities Act of 1933 Section 5：
**米国で証券を売るには、SEC に登録するか、免除規定に当てはまるかのいずれかが必要。**

登録せずに（私募で）発行された株式は **restricted securities（制限付証券）** と呼ばれ、
株券や記録に「制限」の表示（legend）が付き、自由に売却できない。

## 2. Rule 144 は「制限を外すための標準ルート」

制限付証券を売れるようにする実務上の標準手段が **Rule 144**。
条件を満たせば「引受人（underwriter）ではない」とみなされ、売却できる。

### 一般株主（アフィリエイトでない者）の条件
| 条件 | 内容 |
|---|---|
| 保有期間 | 6か月（発行体が Exchange Act 報告会社で報告が最新の場合）／それ以外は12か月 |
| 情報 | 発行体の公開情報が最新であること |

### アフィリエイト（役員・取締役・10%超保有者など支配的立場の者）の条件
上記に加えて：

| 条件 | 内容 |
|---|---|
| **数量制限**（Rule 144(e)） | 3か月間に「発行済株式の1%」と「直近4週間の平均週間出来高」の**大きい方**まで |
| 売却方法 | ブローカー経由の通常取引に限る |
| **Form 144 提出** | 3か月間に 5,000株超 または 5万ドル超を売る場合 |

**BIOT の場合、発行済 28,794,472 株の1% = 288,097 株。**

---

## 3. 【本件の核心】Rule 144(i) ─ 元シェル会社の特則

**Rule 144 は、シェル会社（またはかつてシェル会社だった会社）の証券には原則として
使えない。** 使えるようになるのは、次の**すべて**を満たしたとき：

1. 発行体がシェル会社でなくなっていること
2. 発行体が Exchange Act の報告会社であること
3. 直近12か月の必要な報告をすべて提出していること
4. **Form 10 相当情報の提出から、少なくとも1年が経過していること**

**SPAC はシェル会社である。したがって de-SPAC 後は、誰も1年間 Rule 144 を使えない。**

### BIOT に当てはめると

| | |
|---|---|
| 上場（de-SPAC 完了） | **2026年7月24日** |
| Rule 144 が使えるようになる時期 | **2027年7月頃** |
| 問題の売却が行われた時期 | **2026年7月〜8月** |

**→ 当時、Rule 144 は誰にも使えなかった。**

したがって適法に売却するには、**有効な再販売登録届出書（resale registration
statement）が存在する**しかない。存在しなければ：

- **Securities Act Section 5 違反（無登録の売出し）**
- 購入者に **Section 12(a)(1) の取消請求権（rescission）** が発生
  ＝「代金を返せ、株は返す」と言える権利。**無過失責任**。時効1年。

## 4. なぜこれが最強の札なのか

| | ロックアップ | **Rule 144(i)** |
|---|---|---|
| 性質 | 契約 | **法律** |
| 契約がなければ | 制限なし | **無関係に適用される** |
| 相手の反論余地 | 「契約していない」 | **「登録届出書があった」以外にない** |
| 判定 | 解釈が要る | **有るか無いか。二択** |

**争点にならない。有効な登録届出書が存在するか、しないか。それだけ。**

## 5. ⚠️ 注意点1：「制限なし（DRS）」という表示は、法的結論ではない

Transfer Journal 上、BRACS と Paramount の 1,003,175 株ずつは
**「新規発行・DRS（制限なし）」** と記録されている。

**しかし、名義書換代理人の記録上「制限なし」と表示されていることと、
その株式が法律上自由に売却できることは、別の話である。**

登録もされず免除にも当たらない株式は、**表示がどうであれ restricted securities である。**
制限表示（legend）が付いていないことは、法的な自由譲渡性を意味しない。

**→ したがって問いは常に同じ：「F-4 の登録範囲に含まれていたか」。**

## 6. ⚠️ 注意点2：日本の登録株主にも及ぶ

Rule 144(i) は**発行体の証券**に及ぶ規定であり、保有者を選ばない。

日本の登録株主 656 口座・約 1,066 万株についても、
**その株式が F-4 で登録されていない限り、2027年7月頃までは Rule 144 で売却できない。**

**→ 当社として、日本の株主の保有株が登録済みかどうかを確認しておくこと。
   株主から「売りたい」と言われたときに答えられなければならない。**
