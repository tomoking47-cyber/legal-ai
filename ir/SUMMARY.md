## 3. 論点は4つ。強い順

### ① Rule 144(i) ── 最強。ここが崩れない

**米国では、登録されていない株は原則として売れない。**
その制限を外す標準ルートが Rule 144 だが、**SPAC の承継会社には1年間使えない。**

| | |
|---|---|
| 上場 | 2026年7月24日 |
| Rule 144 が使えるようになる | **2027年7月頃** |
| 実際に売られた時期 | **2026年7月〜8月** |

**→ 当時、Rule 144 は誰にも使えなかった。**
適法に売るには有効な再販売登録届出書が必要。無ければ **Securities Act Section 5 違反**。
購入者に **「代金を返せ」と言える権利（取消請求権）** が発生する。**無過失責任。**

**なぜ最強か：契約ではなく法律だから。「ロックアップが無かった」は反論にならない。
争点は「登録届出書があったか、なかったか」の二択のみ。**

### ② Schedule 13D 未提出

20-F は Relativity Acquisition Sponsor, LLC を 19.15% と報告している。
**その株を他の5社に移した行為そのものが、1%超の「処分」であり報告事由。**
**報告義務の対象物を手放すことで、報告義務は消えない。**

6社に分けても Section 13(d)(3) の「グループ」として合算される。証拠：

- **7/29、MGMTT と Paramount が同じブローカー（Pershing #443）で、Receipt 番号連番
  （2070304 / 2070305）、DTC Control 番号も連番で処理されている**
  → 独立した第三者同士では起こらない
- BRACS と Paramount は **1,003,175 株で完全に同額**
- Relativity II は **5% まであと 4,724 株**

### ③ BCA 違反

| BCA の要求 | 実際 |
|---|---|
| Recital J・§7.2(j)：**Sponsor もロックアップ契約を締結** | **締結されていない** |
| §7.2(k)：**Sponsor Shares と Escrow Shares をエスクローに預託し、証拠を当社に提出** | **7/24 の名簿にエスクロー口座が存在しない** |

**§7.2 は当社の利益のための条件。放棄できるのは当社側だけ。**
→ **放棄書はあるか。あるなら誰の署名か。** これが最大の内部論点。

## 4. ⚠️ 絶対に混ぜてはいけないこと

**「スポンサーが売ったから暴落した」とは、書面でも口頭でも言わないこと。**

**総下落幅 $15.60 のうち $13.26 ── 85.0% ── は 7/27 の終値までに起きている。
その時点でスポンサーの株は1株も DTC になかった。物理的に売れない。**

| | 第1局面：暴落 | 第2局面：離脱 |
|---|---|---|
| 期間 | 7/24〜7/27 | 7/28〜8/24 |
| スポンサー | **売却不能** | 預託後に離脱 |
| 論点 | Regulation SHO | Rule 144(i)・13D・BCA |
| 提出先 | **Nasdaq / FINRA** | **SEC** |

**両者をつなぐ仮説（スポンサー側が空売りに関与していた可能性）は「主張」ではなく
「照会」として、Nasdaq レター第8項(j) に既に含まれている。**
**当社には口座レベルのデータが見えない。FINRA と Nasdaq には見える。**
