# 質問候補 自動抽出ツール（question_miner）

**VVに実際に来た人が「何を知りたがっていたか」を、自社データから自動で取り出すツールです。**

連載『世界の質問箱』『世界のいいニュース』『世界にひらく郷土レシピ』の
ネタ出しを自動化するために作りました。

---

## このツールが使うデータ

| 情報源 | 中身 | 権利 |
|---|---|---|
| **Google Search Console の検索クエリ** | VVにたどり着いた人が実際に打った検索語 | **すべて自社のデータ** |
| **サイト内検索ログ**（任意） | サイトに来た人がサイト内で探したもの | **すべて自社のデータ** |
| **カスタマーサポートの問い合わせ**（任意） | 顧客が実際に困っていること | **すべて自社のデータ** |

> **他社サイトからは、一切データを取りません。**
> 判断の根拠は `docs/plans/sekai-no-shitsumonbako/14_data_sourcing_decision.md` に記載しています。

---

## まず動かしてみる（設定不要・1分）

**認証も設定も要りません。** サンプルデータで動きを確認できます。

**Windows の場合** — コマンドプロンプトを開いて、次の2行を順に実行：

```
cd （このフォルダの場所）
python question_miner.py --demo
```

**Mac の場合** — ターミナルを開いて：

```
cd （このフォルダの場所）
python3 question_miner.py --demo
```

`output` フォルダに次の2つができていれば成功です。

- `questions_2026-XX-XX.csv` … 質問候補の一覧（**そのままExcelで開けます**）
- `report_2026-XX-XX.md`     … 上位30件のサマリー

**ここまで動けば、あとは本番データにつなぐだけです。**

# 本番セットアップ（全4ステップ・所要30分）

## STEP 1｜Pythonと必要な部品を入れる

### Pythonが入っているか確認

コマンドプロンプト（Mac はターミナル）で：

```
python --version
```

`Python 3.9` 以上と表示されればOKです。
`command not found` と出たら、https://www.python.org/downloads/ から最新版を入れてください。

> **Windowsでインストールするときの注意**：インストーラーの最初の画面にある
> **「Add Python to PATH」に必ずチェックを入れてください。** これを忘れると動きません。

### 部品を入れる

このフォルダで、次を1回だけ実行します。

```
pip install -r requirements.txt
```

（Mac で `pip` が見つからない場合は `pip3` に読み替えてください）

---

## STEP 2｜Googleの認証ファイルを取得する

Search Console のデータを読み出す許可を、Googleから受け取る作業です。**1回だけ**必要です。

1. https://console.cloud.google.com/ を開く（**VVのSearch Consoleを見られるGoogleアカウント**でログイン）
2. 画面上部でプロジェクトを新規作成（名前は `vv-question-miner` など何でも構いません）
3. 左メニュー「**APIとサービス**」→「**ライブラリ**」
4. 検索窓に `Search Console API` と入力し、出てきたものを開いて「**有効にする**」
5. 左メニュー「**APIとサービス**」→「**OAuth同意画面**」
   - User Type：**外部**（社内利用でもこれで問題ありません）
   - アプリ名・サポートメール・連絡先を入力して保存
   - 「**テストユーザー**」に、**ご自身のGoogleアカウントを追加**（← これを忘れると認証で弾かれます）
6. 左メニュー「**APIとサービス**」→「**認証情報**」
   - 「**認証情報を作成**」→「**OAuth クライアント ID**」
   - アプリケーションの種類：「**デスクトップアプリ**」
   - 作成すると **JSONファイルをダウンロード**できます
7. ダウンロードしたJSONファイルを、**このフォルダに `client_secrets.json` という名前で置く**

> **このファイルは鍵です。** 誰にも渡さず、GitHubにも上げないでください。
> （`.gitignore` で除外済みですが、念のため）

---

## STEP 3｜設定ファイルを作る

1. `config.example.json` をコピーして、**`config.json`** という名前にする
2. メモ帳などで開いて、`site_url` を書き換える

**`site_url` の書き方**（Search Console でVVサイトをどう登録しているかで変わります）

| 登録の方式 | 書き方の例 |
|---|---|
| ドメイン全体で登録している | `"site_url": "sc-domain:valuevillage.jp"` |
| URLで登録している | `"site_url": "https://valuevillage.jp/"` （**末尾の `/` まで正確に**） |

わからない場合は、Search Console の左上に表示されているプロパティ名をそのまま見てください。

3. サイト内検索ログ・CS問い合わせログがある場合は、CSVを `input` フォルダに置き、
   `config.json` のファイル名と列名を合わせてください。
   （**無い場合は、その4行を削除するだけでOK**です）

CSVの形式は `sample_data` フォルダの見本を参考にしてください。必要な列は1つだけです。

---

## STEP 4｜実行する

**Windows** — `run.bat` を**ダブルクリック**するだけです。

**Mac** — ターミナルで `./run.sh`

初回だけブラウザが開いて、Googleの許可画面が出ます。
**VVのGoogleアカウントでログインして「許可」**してください。

> 「このアプリは確認されていません」と警告が出ることがあります。
> これは自社で作ったアプリのため出るもので、問題ありません。
> 「**詳細**」→「**（アプリ名）に移動**」を選んで進んでください。

2回目以降は、許可画面は出ません（`token.json` に記録されるため）。

## 出てくるもの

### `output/questions_YYYY-MM-DD.csv`

Excelでそのまま開けます。編集部に渡すのはこちらです。

| 列 | 意味 |
|---|---|
| **優先スコア** | **この順に着手すればよい、という指標**（下記参照） |
| 質問候補 | 実際に打たれた検索語・問い合わせ文 |
| 推定棚 | fashion / health / trend / 要判断（**最終判断は編集部**） |
| 表示回数 | 検索結果に何回出たか |
| 平均掲載順位 | VVが何位に出ているか |
| 直接の声 | サイト内検索・CS問い合わせでの件数 |
| 情報源 | どのデータから来たか |
| **法務チェック** | **「必須」なら、執筆前に必ず法務レビューへ** |

### `output/report_YYYY-MM-DD.md`

上位30件のサマリー。会議でそのまま見られる形式です。

## 優先スコアの考え方

```
優先スコア ＝ 需要の大きさ（表示回数） × 伸びしろ（順位の低さ） ＋ 自社への直接の声
```

**いちばん高くなるのは「表示回数は多いのに、順位が20位前後に沈んでいる質問」です。**

これは何を意味するか。

> **読者は明らかにそれを知りたがっている。しかしVVは、まだ十分に答えられていない。**

つまり、**書けば必ず読者がいて、しかも競合がまだ取り切っていない場所**です。ここを埋めるのが最短距離です。

逆に、すでに1〜3位を取れている質問はスコアが下がります。**すでに勝っている場所に、もう一度書く必要はないからです。**

## 運用の目安

| 頻度 | やること |
|---|---|
| **週1回** | ツールを実行し、CSVを編集部に渡す |
| 週1回 | 編集部が上位から**棚を偏らせずに**2〜3本選ぶ（fashion → health → trend の順で回す） |
| 月1回 | スコア上位だが未着手のものを棚卸しする |

### 選ぶときの注意

- **上から順に取らないでください。** 棚が偏るとKPIの棚別比較が成立しなくなります。
- **法務チェック「必須」のものは、執筆前に法務へ回してください。**
- **推定棚が「要判断」のものは、編集部が決めてください。** 機械の判定は目安です。

---

## うまくいかないとき

| 症状 | 対処 |
|---|---|
| `python が見つかりません` | Pythonが未インストール、またはPATH未設定。STEP 1をやり直す |
| `Google関連のライブラリが入っていません` | `pip install -r requirements.txt` を実行する |
| `client_secrets.json が見つかりません` | STEP 2で取得したファイルを、このフォルダに正しい名前で置く |
| 認証画面で弾かれる | OAuth同意画面の「テストユーザー」に自分のアカウントを追加したか確認（STEP 2-5） |
| データが0件 | `site_url` の書き方が違う可能性が高い。Search Console の表示と1文字ずつ照合する |
| 質問が少なすぎる | `--days 180` のように期間を延ばす |

## コマンドの選択肢

```
python question_miner.py --demo              サンプルデータで動作確認
python question_miner.py --days 180          過去180日ぶんを対象にする（既定は90日）
python question_miner.py --limit 500         CSVに500件まで出す（既定は300件）
python question_miner.py --top 50            レポートに50件出す（既定は30件）
python question_miner.py --outdir 保存先      出力先フォルダを変える
```

## 取り扱いの注意

- **`client_secrets.json` `token.json` `config.json` は鍵と設定です。** 社外に出さないでください。
- **CS問い合わせログには個人情報が含まれます。**
  - `input` フォルダに置くのは**本文列だけ**にし、氏名・メールアドレス・電話番号・注文番号は**事前に削除**してください。
  - 出力されたCSVをそのまま社外共有しないでください。
  - `input` `output` フォルダはGit管理から除外済みです。
- 出力された質問候補を記事にする際も、**編集部の言葉で書き直してください。** 検索語をそのまま見出しにしない。
