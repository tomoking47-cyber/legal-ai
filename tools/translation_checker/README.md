# 翻訳チェックツール（translation_checker）

**AIに何度翻訳させても見つからない種類の間違いを、機械で検査するツールです。**

---

## なぜ必要か

AI翻訳の品質は高くなりました。しかし、**AIが「問題ない」と判断してしまう間違い**があります。

| AIが見逃しやすいもの | なぜ危険か |
|---|---|
| 薬機法・広告規制に触れる英語表現 | 意味は正しいので、AIは問題と認識しない |
| **アレルゲン（そば・小麦など）の記載漏れ** | **誤訳・欠落は健康被害に直結する** |
| 分量・温度・時間の数字のずれ | 文章として自然なので気づかれない |
| 「消費期限／賞味期限」の訳のぶれ | どちらも date なので混同されやすい |

**これらは「意味は通っているが、公開してはいけない」状態です。** だから機械で検査します。

---

## 使い方

### まず動かしてみる

```
python translation_checker.py --demo
```

わざと問題を仕込んだサンプルを検査します。重大3件・警告3件が出れば正常です。

### 本番

```
python translation_checker.py --ja 記事_日本語.md --en 記事_英語.md
```

英語だけの記事（日本語版がない場合）：

```
python translation_checker.py --en 記事_英語.md
```

※ 日本語版がないと、アレルゲン照合と数字照合はできません。

---

## 判定の意味

| 印 | 区分 | 対応 |
|---|---|---|
| 🛑 | **重大** | **1件でもあれば公開しない。** 必ず直す |
| ⚠️ | 警告 | 直すか、直さない理由を編集長が説明できること |
| 🔎 | 要確認 | 目視で確認する。単位換算による数字の差なら問題なし |

---

## 用語集（glossary.csv）の育て方

**このツールの精度は、用語集の充実度で決まります。**

| 区分 | 意味 | 書き方 |
|---|---|---|
| `禁止` | 英語版に出てはいけない表現 | 英語列だけ埋める |
| `アレルゲン` | 日本語にあれば英語にも必須 | 日本語・英語の両方を埋める |
| `固定訳` | 訳がぶれてはいけない語 | 日本語・英語の両方を埋める |

**運用ルール：**

- **翻訳で1回でも事故が起きたら、その語を必ず用語集に追加する。** 同じ事故は二度と起きなくなります。
- 新しい商品カテゴリーを扱い始めたら、その分野の禁止表現を追加する。
- 用語集は**そのままAIへのプロンプトに貼り付けて使えます**（手順は `16_translation_protocol.md`）。

---

## このツールで**わからない**こと

正直に書いておきます。**このツールは、文章が自然かどうかを判断できません。**

- 英語として不自然でないか
- 読者に意図が伝わるか
- 文化的に失礼な表現になっていないか

これらは検査できません。**必ず逆翻訳（バックトランスレーション）と併用してください。**
手順は `docs/plans/sekai-no-shitsumonbako/16_translation_protocol.md` の STEP 2 にあります。
